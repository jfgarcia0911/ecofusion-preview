# Course 401: Aquaponics System Design Specialist

## Course Overview

**Course Description:**
Achieve professional certification in aquaponics system design. This intensive program covers advanced engineering principles, complex system design, client consultation, and project management for aquaponics installations of any scale.

**Learning Outcomes:**
Upon successful completion, learners will be able to:
1. Design aquaponic systems for any scale or application
2. Provide professional consultation services
3. Manage design projects from concept to commissioning
4. Develop client-ready design documentation
5. Troubleshoot complex design challenges

**Duration:** 24 hours total
- Online: 12 hours self-paced technical content
- Live: 12 hours intensive workshops and practicum
- Hybrid synchronous required for certification exam

**Prerequisites:** Course 301 (Advanced System Design)

**Maximum Class Size:** 12 (ensures individual attention)

**Certification Earned:** EcoFusion Certified Aquaponics System Designer (ECASD)

- Develop design requirements documents
- Manage stakeholder expectations
- Create professional proposals

**Professional Ethics Framework:**

| Principle | Application |
|-----------|-------------|
| **Competence** | Only take projects within capability |
| **Integrity** | Honest representation of outcomes |
| **Objectivity** | Unbiased equipment/supplier recommendations |
| **Confidentiality** | Protect client proprietary information |
| **Professional Development** | Continuous learning commitment |

**Client Consultation Protocol:**

```
CONSULTATION FRAMEWORK

1. DISCOVER (30-60 minutes)
   □ Client background and experience
   □ Goals and objectives
   □ Site characteristics
   □ Budget parameters
   □ Timeline expectations
   □ Constraints and concerns

2. ASSESS (On-site visit)
   □ Site survey and measurements
   □ Utility evaluation
   □ Environmental analysis
   □ Regulatory check
   □ Photo documentation

3. PROPOSE (Written document)
   □ Design concept options
   □ Preliminary specifications
   □ Budget estimates
   □ Timeline projections
   □ Risk assessment

4. REFINE (Review meeting)
   □ Present options
   □ Gather feedback
   □ Answer questions
   □ Revise as needed
   □ Confirm direction

5. DELIVER (Final package)
   □ Complete design documents
   □ Equipment specifications
   □ Construction guidance
   □ Operations overview
   □ Support plan
```

```

   │

   │
   ▼

What activities will help them learn?
```

**Learning Objective Development (Bloom's Taxonomy):**

| Level | Verbs | Example Objective |
|-------|-------|-------------------|
| **Remember** | Define, list, recall | List the components of an aquaponic system |
| **Understand** | Explain, describe, summarize | Explain the nitrogen cycle in aquaponics |
| **Apply** | Use, demonstrate, calculate | Calculate pump sizing for a given system |
| **Analyze** | Compare, contrast, diagnose | Diagnose nutrient deficiency from leaf symptoms |
| **Evaluate** | Assess, judge, recommend | Evaluate the feasibility of a proposed design |
| **Create** | Design, develop, construct | Design a complete aquaponic system |

**Handling Challenging Situations:**

| Situation | Strategy |
|-----------|----------|

| Silent participants | Small groups, written responses first |

| Resistant learners | Understand concerns, find relevance |
| Technical difficulties | Backup plans, stay calm, adapt |
| Incorrect information | Gently correct, praise effort |
