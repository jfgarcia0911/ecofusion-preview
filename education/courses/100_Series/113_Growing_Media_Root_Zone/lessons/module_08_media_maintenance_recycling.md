### 8.1 Media Lifespan and Degradation

#### How Long Does Media Last?

```
MEDIA LIFESPAN BY MATERIAL

Material              Lifespan    Degradation Pattern
─────────────────────────────────────────────────────
Perlite              Permanent   Minimal (may crush)
Rock wool            1-2 years   Breaks down slowly
Sand                 Permanent   None
Coco coir            2-3 years   Slow decomposition
Peat moss            1-2 years   Compaction, breakdown
Pine bark (aged)     1-2 years   Moderate decomposition
Compost              <1 year     Rapid breakdown
Vermiculite          2-5 years   Compaction

TYPICAL BLENDS
Peat-perlite         1-2 years   Peat degrades first
Coco-perlite         2-3 years   Very durable
Bark-based           1-2 years   Bark decomposes
```

#### Signs of Media Degradation

```
WHEN TO REPLACE MEDIA

PHYSICAL DEGRADATION
┌────────────────────────────────┐
│ ✗ Reduced volume (compaction)  │
│ ✗ Loss of structure            │
│ ✗ Poor drainage                │
│ ✗ Water repellency             │
│ ✗ Fine particle accumulation   │
│ ✗ Reduced air porosity         │
└────────────────────────────────┘

CHEMICAL ISSUES
┌────────────────────────────────┐
│ ✗ Persistent high EC           │
│ ✗ Extreme pH (can't correct)   │
│ ✗ Salt crusting on surface     │
│ ✗ Nutrient imbalances          │
│ ✗ Toxic compound buildup       │
└────────────────────────────────┘

BIOLOGICAL PROBLEMS
┌────────────────────────────────┐
│ ✗ Persistent disease problems  │
│ ✗ Weed seed contamination      │
│ ✗ Pest infestations            │
│ ✗ Algae growth throughout      │
│ ✗ Foul odors (anaerobic)       │
└────────────────────────────────┘
```

#### Measuring Media Quality Over Time

```
MEDIA QUALITY ASSESSMENT

TEST                Initial   3 months  6 months  Replace?
────────────────────────────────────────────────────────
Bulk Density       0.12      0.14      0.18      If >0.25
AFP (%)            25        22        18        If <15
pH                 6.0       6.2       6.5       If <5.0 or >7.5
EC (dS/m)          1.2       1.5       2.0       If >3.0
Disease incidence  None      1%        5%        If >10%
Root quality       Excellent Good      Fair      If Poor

Track these parameters to make replacement decisions
```

#### Factors Affecting Lifespan

| Factor | Effect on Lifespan |
|--------|-------------------|
| **Irrigation frequency** | High frequency = faster breakdown |
| **Fertilizer salts** | High EC = degradation, crusting |
| **Crop type** | Heavy feeders = more stress on media |
| **Temperature** | High temps = faster decomposition |
| **Initial quality** | Better media = longer life |
| **pH extremes** | Accelerates breakdown |
| **Microbial activity** | Organic media breaks down faster |

### 8.2 Media Reconditioning and Reuse

#### Can You Reuse Growing Media?

```
REUSE DECISION MATRIX

┌────────────────────────────────────────────┐
│              CONSIDER REUSE IF:            │
├────────────────────────────────────────────┤
│ ✓ Media still has good structure           │
│ ✓ No disease problems in previous crop     │
│ ✓ AFP still >15%                           │
│ ✓ Can be sterilized effectively            │
│ ✓ High-value production justifies cost     │
│ ✓ Media disposal is expensive/difficult    │
└────────────────────────────────────────────┘

┌────────────────────────────────────────────┐
│           DO NOT REUSE IF:                 │
├────────────────────────────────────────────┤
│ ✗ Severe disease problems occurred         │
│ ✗ Media heavily compacted                  │
│ ✗ Persistent weed seeds                    │
│ ✗ Chemical contamination                   │
│ ✗ Cost of reconditioning > new media       │
│ ✗ Low-value crops (not economical)         │
└────────────────────────────────────────────┘
```

#### Sterilization Methods

```
MEDIA STERILIZATION OPTIONS

1. STEAM STERILIZATION
┌─────────────────────────────────────┐
│ Method: Heat to 180°F for 30 min   │
│ Effectiveness: Excellent (kills all)│
│ Cost: Moderate-high                 │
│ Scale: Medium to large operations   │
│ Pros: Complete sterilization        │
│ Cons: Equipment needed, energy use  │
└─────────────────────────────────────┘

2. SOLARIZATION
┌─────────────────────────────────────┐
│ Method: Cover with clear plastic,   │
│         sun heats media to 120-140°F│
│ Effectiveness: Moderate             │
│ Cost: Very low                      │
│ Scale: Small to medium              │
│ Pros: Simple, no equipment          │
│ Cons: Slow (4-6 weeks), climate-    │
│       dependent, incomplete kill    │
└─────────────────────────────────────┘

3. CHEMICAL STERILIZATION
┌─────────────────────────────────────┐
│ Method: Hydrogen peroxide, bleach,  │
│         or commercial sterilants    │
│ Effectiveness: Good to excellent    │
│ Cost: Moderate                      │
│ Scale: Small to medium              │
│ Pros: Quick, effective              │
│ Cons: Chemical residues, handling   │
│       safety, environmental concerns│
└─────────────────────────────────────┘

4. BIOLOGICAL TREATMENT
┌─────────────────────────────────────┐
│ Method: Add beneficial microbes     │
│         (Trichoderma, etc.)         │
│ Effectiveness: Moderate             │
│ Cost: Low-moderate                  │
│ Scale: Any                          │
│ Pros: Sustainable, adds beneficials │
│ Cons: Not complete sterilization,   │
│       requires time to establish    │
└─────────────────────────────────────┘
```

#### Reconditioning Steps

```
MEDIA RECONDITIONING PROCESS

STEP 1: REMOVE OLD PLANTS & ROOTS
├─ Shake out or screen media
├─ Remove large root masses
└─ Discard heavily diseased media

STEP 2: STERILIZE (if needed)
├─ Choose method based on resources
├─ Steam, solarize, or chemical treat
└─ Allow to cool/air out completely

STEP 3: TEST PROPERTIES
├─ pH (adjust if needed)
├─ EC (leach if high)
├─ Physical structure (add amendments if compacted)
└─ Lab analysis for nutrients

STEP 4: AMEND & RECONDITION
├─ Add fresh perlite/peat (10-30%)
├─ Incorporate limestone if pH low
├─ Add gypsum for structure
├─ Mix in compost or amendments
└─ Blend thoroughly

STEP 5: RE-TEST
├─ Verify pH in target range
├─ Confirm EC <1.0 dS/m
├─ Test AFP if possible
└─ Visual inspection for uniformity

STEP 6: USE FOR APPROPRIATE CROPS
├─ Reconditioned media → less sensitive crops
├─ New media → high-value or sensitive crops
└─ Monitor closely for first few weeks
```

#### Economics of Reuse

```
COST COMPARISON EXAMPLE (per cubic yard)

NEW MEDIA
├─ Materials cost:        $75
├─ Labor (mixing):        $10
├─ Total:                 $85/cu yd

RECONDITIONED MEDIA
├─ Labor (screening):     $15
├─ Sterilization:         $20
├─ Amendments (30% fresh): $25
├─ Testing:               $10
├─ Total:                 $70/cu yd

Savings: $15/cu yd (18%)

BUT CONSIDER:
├─ Risk of disease carry-over
├─ Reduced performance
├─ Labor time/availability
├─ Equipment investment
└─ Crop value (worth the risk?)

Generally economical for:
• Large operations (>50 cu yd/year)
• Expensive disposal costs
• Low disease pressure
• Medium to long-term crops
```

#### Separating Media Components

**Some materials can be separated and reused:**

```
COMPONENT SEPARATION

PERLITE
├─ Screen out (floats in water)
├─ Wash and dry
├─ Can reuse indefinitely
└─ Mix into new batches (30-50%)

BARK (large pieces)
├─ Screen out large chunks
├─ Compost or use as mulch
└─ Not suitable for reuse in media

COCO/PEAT
├─ Cannot separate economically
├─ Compost or dispose
└─ Fast-degrading anyway

ROCKWOOL
├─ Difficult to recycle
├─ Check with manufacturer programs
├─ Some can be reprocessed into insulation
└─ Otherwise landfill
```

#### Composting Used Media

```
MEDIA COMPOSTING PROCESS

STEP 1: SEGREGATE CLEAN MEDIA
└─ No disease, no pesticide residues

STEP 2: BUILD COMPOST PILE
┌────────────────────────────┐
│ Layer 1: Used media (6")   │
│ Layer 2: N source (2")     │ (manure, grass)
│ Layer 3: Used media (6")   │
│ Layer 4: N source (2")     │
│         Repeat...          │
└────────────────────────────┘
Target C:N ratio: 25-30:1

STEP 3: MANAGE PILE
├─ Moisture: 50-60% (like wrung sponge)
├─ Temperature: 130-150°F for 2 weeks
├─ Turn weekly to aerate
└─ Monitor for odors

STEP 4: CURE
├─ After active phase, let sit 4-8 weeks
├─ Temperature drops to ambient
└─ Dark, crumbly, earthy smell

STEP 5: USE
├─ Soil amendment (gardens, landscapes)
├─ Compost component in new media (10-20%)
└─ Mulch for pathways
```

### 8.4 Closed-Loop Media Systems

#### Circular Economy Approach

```
CLOSED-LOOP MEDIA MANAGEMENT

┌──────────────────────────────────────────┐
│                                          │
│    1. NEW MEDIA                          │
│         ↓                                │
│    2. PRODUCTION USE                     │
│         ↓                                │
│    3. COLLECTION AFTER CROP              │
│         ↓                                │
│    4. SEGREGATION                        │
│    ├─→ Clean/Good → Recondition         │
│    └─→ Disease/Poor → Compost           │
│         ↓                ↓               │
│    5. STERILIZE    6. COMPOST            │
│         ↓                ↓               │
│    7. AMEND        8. CURE               │
│         ↓                ↓               │
│    ←────┴────────────────┘               │
│    9. REUSE or Land Application          │
│                                          │
└──────────────────────────────────────────┘

GOALS:
• 80% reuse/recondition
• 15% compost
• 5% or less to landfill
```

#### Zero-Waste Media Program

```
IMPLEMENTING ZERO-WASTE

PREVENT WASTE
├─ Buy quality media (lasts longer)
├─ Proper irrigation (prevent degradation)
├─ Disease prevention (avoid contamination)
└─ Right-size batches (no excess)

REUSE MATERIALS
├─ Sterilize and recondition clean media
├─ Separate reusable components
├─ Use for less sensitive crops
└─ Trail beds or school gardens

RECYCLE/COMPOST
├─ Compost organic components
├─ Partner with local composters
├─ Return to soil as amendment
└─ Create value-added products

TRACK & IMPROVE
├─ Measure waste rates
├─ Set reduction targets
├─ Train staff on protocols
└─ Continuously optimize
```

## Vocabulary

| Term | Definition |
|------|------------|
| **Media Degradation** | Breakdown of physical structure and properties over time |
| **Reconditioning** | Process of restoring used media to usable condition |
| **Sterilization** | Elimination of pathogens through heat, chemicals, or other means |
| **Solarization** | Using sun's heat under plastic to kill pathogens in media |
| **Closed-Loop System** | Circular process where materials are reused rather than discarded |
| **Tipping Fee** | Cost to dispose of material at landfill |
| **Land Application** | Spreading used media on agricultural land |
| **Biochar** | Charcoal produced from organic matter for use in growing media |
| **Composting** | Controlled decomposition of organic matter |
| **Zero-Waste** | Goal of eliminating all waste to landfill |
