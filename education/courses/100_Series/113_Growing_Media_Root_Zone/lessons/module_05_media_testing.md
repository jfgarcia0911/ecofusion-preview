### 5.2 Testing Methods

#### A. Pour-Through Method

**Most practical for routine testing** - measures solution in root zone

```
POUR-THROUGH PROCEDURE

STEP 1: Water container to saturation
┌──────────────────┐
│  Water plants    │ Irrigate thoroughly
│      ↓↓↓         │ 1-2 hours before test
│   ▒▒▒▒▒▒▒▒      │
└──────────────────┘

STEP 2: Wait 30-60 minutes
        (allow drainage)

STEP 3: Place collection saucer
┌──────────────────┐
│   ▒▒▒▒▒▒▒▒      │
└──────┬───────────┘
       ↓
┌──────────────────┐
│   Catch saucer   │
└──────────────────┘

STEP 4: Apply 50-100 ml distilled water
┌──────────────────┐
│   75 ml H₂O      │ Pour evenly
│      ↓↓↓         │ across surface
│   ▒▒▒▒▒▒▒▒      │
└──────┬───────────┘
       ↓ Leachate
┌──────────────────┐
│  ▒▒▒▒▒ Collect   │ Test this solution
│    30-50 ml      │ for pH and EC
└──────────────────┘

STEP 5: Measure pH and EC immediately
```

**Advantages:**
✓ Non-destructive
✓ Quick and easy
✓ Minimal equipment
✓ Represents actual root zone
✓ Can test multiple containers

**Limitations:**
✗ Less accurate than lab extraction
✗ Requires recent irrigation
✗ Results vary by timing
✗ Difficult in small containers

**Best Practices:**
- Test at same time of day
- Test 1-2 hours after irrigation
- Use distilled water for application
- Test multiple containers (5-10)
- Calibrate meters before use

#### B. Saturated Media Extract (SME)

**Laboratory method** - most accurate

```
SATURATED MEDIA EXTRACT PROCEDURE

1. Collect media sample
   ┌────────────┐
   │  Fresh     │ 100-200 ml media
   │  media     │ from root zone
   └────────────┘

2. Add distilled water to saturation
   ┌────────────┐
   │ Media + H₂O│ Paste consistency
   │  ▒▒▒▒▒▒░░  │ (glistening surface)
   └────────────┘

3. Let equilibrate 30-60 minutes

4. Extract solution through filter
   ┌────────────┐
   │    ↓↓↓     │ Vacuum filtration
   │  ▒▒▒▒▒▒   │ or centrifuge
   └─────┬──────┘
         ↓
   ┌────────────┐
   │  Clear     │ Test this
   │  extract   │
   └────────────┘

5. Analyze pH, EC, nutrients
```

**Advantages:**
✓ Most accurate method
✓ Can test nutrients
✓ Standardized procedure
✓ Used by professional labs

**Limitations:**
✗ Requires lab equipment
✗ Destructive (uses media)
✗ Slower (send to lab)
✗ More expensive

#### C. 1:2 Dilution Method

**Simplified method** for on-site testing

```
1:2 DILUTION PROCEDURE

1. Mix 1 part media : 2 parts distilled water
   ┌──────────────────────┐
   │ 50 ml    100 ml      │
   │ media  + water       │
   └──────────────────────┘

2. Shake vigorously 1 minute

3. Let settle 10-15 minutes

4. Test clear supernatant for pH and EC
   ┌──────────────────────┐
   │ Clear liquid ← Test  │
   │ ─────────────        │
   │ ▒▒▒▒▒▒▒▒▒ Settled    │
   └──────────────────────┘

5. Multiply EC result by 2 for actual concentration
```

#### D. Direct Insertion

**Quickest method** - insert probe directly into media

**Limitations:**
- Very inaccurate
- Depends on moisture level
- Inconsistent results
- Not recommended for critical decisions

**Only use for:**
- Quick spot checks
- Relative comparisons
- Teaching demonstrations

### 5.3 Understanding Test Results

#### pH Interpretation

```
pH RESULT ASSESSMENT

Test Result    Status              Action Needed
─────────────────────────────────────────────────
< 5.0         Too acidic          Add limestone or use
                                  alkaline fertilizer

5.0-5.4       Low side            Monitor; may need
                                  minor adjustment

5.5-6.5       OPTIMAL             ✓ No action needed

6.6-7.0       Slightly high       Monitor; reduce
                                  alkalinity in water

7.1-7.5       High                Reduce water alkalinity;
                                  use acidic fertilizer

> 7.5         Too alkaline        Immediate correction:
                                  acid injection, sulfur
```

**Crop-Specific Targets:**

| Crop Type | Optimal pH Range |
|-----------|-----------------|
| Most vegetables | 5.8-6.3 |
| Leafy greens | 6.0-6.5 |
| Tomatoes, peppers | 5.8-6.5 |
| Blueberries | 4.5-5.5 |
| Herbs (basil, mint) | 6.0-7.0 |
| Succulents | 6.0-7.0 |

#### EC Interpretation

```
EC RESULT ASSESSMENT

Test Result    Status              Action Needed
(dS/m)
─────────────────────────────────────────────────
< 0.5         Very low            Increase fertilizer
                                  concentration

0.5-1.0       Low                 Good for seedlings;
                                  increase for mature plants

1.0-2.5       OPTIMAL             ✓ No action needed
              (mature plants)

2.5-3.5       Moderately high     Reduce fertilizer 25%;
                                  monitor sensitive crops

3.5-5.0       High                Reduce fertilizer 50%;
                                  leach with clear water

> 5.0         Excessive           Immediate leaching;
                                  discontinue fertilizer
```

**Growth Stage Targets:**

```
EC BY GROWTH STAGE

Stage           Target EC    Reasoning
────────────────────────────────────────────
Seed/cutting    0.5-1.0     Minimize salt stress
                            during establishment

Young plant     1.0-1.5     Building vegetative
                            growth

Mature veg      1.5-2.5     Active growth and
                            production

Flowering       2.0-3.0     Higher nutrient
                            demand

Finishing       1.0-1.5     Reduce to harden off
```

#### Nutrient Levels

**Key Nutrients to Monitor:**

| Nutrient | Sufficient Range (ppm) | Deficient (<) | Excessive (>) |
|----------|----------------------|--------------|--------------|
| **Nitrogen (N)** | 100-200 | 50 | 300 |
| **Phosphorus (P)** | 5-15 | 3 | 25 |
| **Potassium (K)** | 100-250 | 75 | 400 |
| **Calcium (Ca)** | 80-150 | 50 | 250 |
| **Magnesium (Mg)** | 30-70 | 20 | 100 |
| **Sulfur (S)** | 25-75 | 15 | 150 |
| **Iron (Fe)** | 2-5 | 1 | 10 |

**Conversion Note:**
- ppm = mg/L (milligrams per liter)
- To convert from % to ppm: multiply by 10,000
  - Example: 0.5% = 5,000 ppm

```
╚═══════════════════════════════════════════════════╝
```

#### Interpreting the Report

**Step 1: Check pH and EC**
- Are they in optimal range?
- If not, these need immediate attention

**Step 2: Review Nutrient Balance**
- Identify any deficiencies or excesses
- Note patterns (all nutrients low/high?)

**Step 3: Consider Relationships**
```
NUTRIENT INTERACTIONS

High K can reduce:        High Ca can reduce:
├─ Ca uptake              ├─ Mg uptake
└─ Mg uptake              └─ K uptake

High NH₄⁺ can reduce:     High Mg can reduce:
├─ Ca uptake              └─ Ca uptake
└─ Mg uptake
```

**Step 4: Make Decisions**
- What changes to fertilizer program?
- Need to adjust pH or EC first?
- When to retest?

### 5.5 Troubleshooting with Test Data

#### Problem-Solving Framework

```
DIAGNOSTIC PROCESS

1. OBSERVE SYMPTOMS
   ↓
   Yellowing, stunting, tip burn, etc.

2. TEST MEDIA
   ↓
   pH, EC, nutrients

3. COMPARE TO TARGETS
   ↓
   Identify what's out of range

4. DETERMINE CAUSE
   ↓
   Deficiency? Toxicity? pH lockout?

5. TAKE CORRECTIVE ACTION
   ↓
   Adjust fertilizer, pH, irrigation

6. RETEST & VERIFY
   ↓
   Confirm problem solved
```

#### Common Scenarios

**Scenario 1: Low pH, Normal EC**

```
Test Results:
├─ pH: 4.8 (low)
├─ EC: 1.8 dS/m (normal)
└─ Nutrients: Low Ca, Mg; normal others

Diagnosis: Acidic media affecting Ca/Mg availability

Action:
├─ Add limestone to media (long-term)
├─ Use alkaline fertilizer (immediate)
├─ Increase Ca-Mg in feed solution
└─ Retest in 1 week
```

**Scenario 2: High EC, Stunted Growth**

```
Test Results:
├─ pH: 6.3 (normal)
├─ EC: 5.2 dS/m (very high)
└─ Nutrients: All high

Diagnosis: Salt accumulation (over-fertilization)

Action:
├─ Leach containers with clear water
├─ Apply 2-3× container volume
├─ Reduce fertilizer concentration by 50%
├─ Increase leaching fraction to 20-30%
└─ Retest in 3-5 days
```

**Scenario 3: Normal EC, Deficiency Symptoms**

```
Test Results:
├─ pH: 7.8 (high)
├─ EC: 2.0 dS/m (normal)
└─ Iron: Very low; other nutrients normal

Diagnosis: pH-induced iron lockout

Action:
├─ Lower pH to 5.8-6.2 (critical!)
├─ Use acidic fertilizer
├─ Inject citric/sulfuric acid
├─ Foliar spray with chelated iron (temporary)
└─ Retest pH in 3-5 days
```

### 5.6 Developing a Testing Schedule

#### Frequency Recommendations

```
TESTING SCHEDULE BY OPERATION SIZE

SMALL OPERATION (<1000 containers)
├─ Weekly: Spot-check pH/EC (pour-through)
├─ Monthly: Lab analysis of representative samples
└─ As needed: Diagnostic testing for problems

MEDIUM OPERATION (1000-10,000 containers)
├─ 2-3× weekly: Pour-through on multiple samples
├─ Bi-weekly: Lab analysis by crop/area
├─ Monthly: Complete nutrient analysis
└─ As needed: Diagnostic testing

LARGE OPERATION (>10,000 containers)
├─ Daily: Automated or spot-check monitoring
├─ Weekly: Lab analysis by zone/crop
├─ Monthly: Comprehensive testing & audits
└─ Continuous: Sensor-based monitoring systems
```

#### Testing Calendar

| Growth Stage | Test Frequency | Parameters | Method |
|--------------|---------------|------------|--------|
| **Before planting** | Once | pH, EC, physical properties | Lab analysis |
| **Week 1-2** (establishment) | Weekly | pH, EC | Pour-through |
| **Week 3-8** (active growth) | Bi-weekly | pH, EC, N-P-K | Pour-through + lab |
| **Week 9+** (mature) | Weekly | pH, EC | Pour-through |
| **Problem diagnosis** | As needed | Full nutrient panel | Lab analysis |

#### Sample Size Guidelines

**How Many Samples to Test?**

| Situation | Number of Samples |
|-----------|------------------|
| **Routine monitoring** | 5-10 containers per area/crop |
| **Problem diagnosis** | 3 affected + 3 healthy plants |
| **Quality check** | 1 sample per 1000 ft² or crop batch |
| **Pre-plant verification** | 3 samples from different locations |

#### Meter Maintenance

**Daily:**
- Rinse probes with distilled water
- Store pH probe in storage solution
- Wipe EC probe dry

**Weekly:**
- Check calibration
- Clean probes gently

**Monthly:**
- Full calibration (2-3 point)
- Replace storage solution
- Check for damaged probes

**Annually:**
- Replace pH probe (expected lifespan)
- Professional calibration check

## Vocabulary

| Term | Definition |
|------|------------|
| **Pour-Through Method** | Testing technique collecting solution from bottom of container |
| **Saturated Media Extract (SME)** | Lab method using saturated paste to extract solution |
| **Leachate** | Solution that drains through growing media |
| **Calibration** | Adjusting meter to match known standard solutions |
| **Buffer Solution** | Standard pH solution for meter calibration |
| **Conductivity Standard** | Known EC solution for meter calibration |
| **Representative Sample** | Sample typical of larger batch or area |
| **Nutrient Lockout** | Nutrients unavailable due to pH or antagonism |
| **Leaching Fraction** | Percentage of applied water that drains through |
| **Temperature Compensation** | Automatic adjustment for temperature effects on readings |
