### 4.1 Sphagnum Peat Moss

#### Origin and Production

**Source:** Partially decomposed sphagnum moss from peat bogs

```
PEAT BOG FORMATION

Surface: Living Sphagnum Moss
         ↓ Dies and sinks
         ┌──────────────────┐
Year 0   │ Fresh plant matter│
         ├──────────────────┤
Year 50  │ Partial decomp   │ ← Fibrous peat
         ├──────────────────┤
Year 100 │ More decomposed  │ ← Medium peat
         ├──────────────────┤
Year 500 │ Well decomposed  │ ← Fine peat
         ├──────────────────┤
1000+    │ Highly decomposed│ ← Muck
         └──────────────────┘

Takes 1000+ years to form commercial peat layer
```

**Major Sources:**
- Canada (largest producer)
- Northern Europe (Finland, Ireland, Russia)
- Limited U.S. production (Michigan, Minnesota)

#### Physical Properties

| Property | Value | Rating |
|----------|-------|--------|
| **Bulk Density** | 6-12 lb/ft³ (0.10-0.19 g/cm³) | Very light |
| **Total Porosity** | 85-95% | Excellent |
| **Air-Filled Porosity** | 10-30% (depends on grade) | Variable |
| **Water Holding Capacity** | 60-80% | Excellent |
| **Available Water** | 35-45% | Very good |
| **Particle Size** | Fine to coarse (by grade) | Variable |

```
PEAT MOSS GRADES

FINE/MILLED               MEDIUM                COARSE
┌───────────┐            ┌───────────┐         ┌───────────┐
│ ░░░░░░░░░ │            │ ▓▓░▓░▓▓░░ │         │ █░░█░░░█░ │
│ ░░░░░░░░░ │            │ ░▓▓░░▓░▓▓ │         │ ░█░░█░█░░ │
│ ░░░░░░░░░ │            │ ▓░▓▓░░░▓░ │         │ ░░█░░█░█░ │
└───────────┘            └───────────┘         └───────────┘
Seed starting            General purpose       Orchids, epiphytes
High water retention     Balanced              High drainage
```

#### Chemical Properties

| Property | Value | Notes |
|----------|-------|-------|
| **pH** | 3.5-4.5 | Very acidic - requires lime |
| **CEC** | 100-200 meq/100g | Excellent nutrient holding |
| **Initial EC** | <0.5 dS/m | Very low salts |
| **Initial Nutrients** | None | Completely inert |

#### Advantages

✓ Excellent water retention
✓ Good aeration when fresh
✓ High CEC - holds nutrients well
✓ Consistent quality
✓ Lightweight
✓ Disease-free when new
✓ Well-researched and understood

#### Disadvantages

✗ Very acidic pH - must add lime
✗ Non-renewable resource (slow formation)
✗ Environmental concerns (habitat destruction)
✗ Degrades over time (6-24 months)
✗ Hydrophobic when dry
✗ Compacts with age
✗ Dusty to handle

#### Best Uses

- General-purpose container mixes
- Seed starting (fine grades)
- Plug production
- Bedding plants
- Hanging baskets
- Blended with perlite/vermiculite

#### Management Tips

```
PEAT MOSS PREPARATION

1. ADD LIMESTONE
   ┌────────────────────────┐
   │ Peat + 3-10 lb lime/yd³│  Target pH 5.5-6.5
   └────────────────────────┘

2. HYDRATE PROPERLY
   ┌────────────────────────┐
   │ Add water slowly       │  Difficult when dry
   │ Mix thoroughly         │  Add wetting agent
   └────────────────────────┘

3. PRE-MOISTEN BEFORE USE
   ┌────────────────────────┐
   │ Never use dry peat     │  Won't rewet easily
   │ Moisten 24 hrs before  │  in containers
   └────────────────────────┘
```

### 4.2 Coco Coir (Coconut Fiber)

#### Origin and Production

**Source:** Fibrous mesocarp (husk) of coconuts

```
COCONUT ANATOMY

┌─────────────────────┐
│   Outer Skin        │
├─────────────────────┤
│   Fibrous Husk      │ ← COCO COIR from this layer
│   (Mesocarp)        │   (between shell and skin)
├─────────────────────┤
│   Hard Shell        │
├─────────────────────┤
│   Coconut Meat      │
│   & Water           │
└─────────────────────┘
```

**Production Process:**
1. Husks removed from coconuts
2. Soaked in water (retting process)
3. Fibers mechanically separated
4. Composted/aged 6-18 months
5. Washed to remove salts
6. Compressed into bricks/bales

**Major Producers:**
- India, Sri Lanka, Philippines, Indonesia

#### Physical Properties

| Property | Value | Rating |
|----------|-------|--------|
| **Bulk Density** | 8-10 lb/ft³ (0.13-0.16 g/cm³) | Light |
| **Total Porosity** | 85-90% | Excellent |
| **Air-Filled Porosity** | 20-30% | Very good |
| **Water Holding Capacity** | 60-70% | Excellent |
| **Available Water** | 40-50% | Excellent |
| **Structural Stability** | Excellent (2-3 years) | Long-lasting |

#### Chemical Properties

| Property | Value | Notes |
|----------|-------|-------|
| **pH** | 5.5-6.5 | Near-neutral (ideal) |
| **CEC** | 60-130 meq/100g | Very good |
| **Initial EC** | 0.5-3.0 dS/m | **Variable - must be washed** |
| **Natural K Content** | High | May need Ca/Mg supplement |

#### Advantages

✓ Renewable resource (annual production)
✓ Excellent water/air balance
✓ Near-neutral pH
✓ Good CEC
✓ Resists compaction
✓ Long-lasting (2-3 years)
✓ Rewets easily (not hydrophobic)
✓ Supports beneficial microbes

#### Disadvantages

✗ Variable quality (source dependent)
✗ Must be properly washed (salt removal)
✗ High in potassium, low in calcium
✗ May contain Na if not washed
✗ Sometimes contaminated with sand
✗ Long-distance shipping (from tropics)
✗ Variable particle size

#### Types of Coco Products

```
COCO COIR PRODUCT FORMS

┌────────────────────────────────────────┐
│  COCO PITH/PEAT (Fine)                │
│  ░░░░░░░░░░░░░░░░░░░░                 │
│  • 75% of product                      │
│  • High water retention                │
│  • Similar to peat moss                │
├────────────────────────────────────────┤
│  COCO FIBER (Coarse)                  │
│  ▓▓░░▓▓░░▓▓░░▓▓                       │
│  • 15% of product                      │
│  • Improves aeration                   │
│  • Longer fibers                       │
├────────────────────────────────────────┤
│  COCO CHIPS (Very Coarse)             │
│  ██░░██░░██░░██                       │
│  • 10% of product                      │
│  • Excellent drainage                  │
│  • For orchids, succulents             │
└────────────────────────────────────────┘

Most products are BLENDS of these
```

#### Quality Indicators

**High-Quality Coco Coir:**
- EC < 1.0 dS/m (properly washed)
- pH 5.5-6.5
- Brown color (fully composted)
- No salt crystals visible
- Consistent particle size
- Clean smell (not sour)
- Certification (RHP, OMRI, etc.)

#### Best Uses

- Hydroponic systems
- Container production
- Seed starting
- Rooting cuttings
- Mix component (replacement for peat)
- Straight coco or blended with perlite

#### Management Tips

```
COCO COIR NUTRIENT MANAGEMENT

ISSUE: Natural sodium and potassium content

SOLUTION:
┌─────────────────────────────────────┐
│ Use Cal-Mag supplement              │
│ • Add 150-200 ppm Ca                │
│ • Add 50-75 ppm Mg                  │
│                                     │
│ Reduce K in base fertilizer         │
│ • Coco already high in K            │
│                                     │
│ Buffer new coco before use          │
│ • Soak with Ca/Mg solution          │
│ • Prevents Ca deficiency            │
└─────────────────────────────────────┘
```

### 4.3 Perlite

#### Origin and Production

**Source:** Volcanic glass (amorphous aluminum silicate)

**Processing:**
1. Mine perlite ore
2. Crush to particle size
3. Heat to 1600°F (871°C)
4. Expands like popcorn (4-20× volume)
5. Cool and grade by size

```
PERLITE EXPANSION PROCESS

Raw Perlite Ore        Heated to 1600°F       Expanded Perlite
┌──────────┐           →  →  →  →  →         ┌──────────┐
│  Dense   │                                  │ ○  ○  ○  │
│  ▓▓▓▓▓   │         Steam escapes           │  ○  ○  ○ │
│  ▓▓▓▓▓   │         creates bubbles         │ ○  ○  ○  │
└──────────┘                                  └──────────┘
  Heavy                                       Very light
  Small volume                                Large volume
```

#### Physical Properties

| Property | Value | Rating |
|----------|-------|--------|
| **Bulk Density** | 6-9 lb/ft³ (0.10-0.14 g/cm³) | Very light |
| **Total Porosity** | 60-75% | Good |
| **Air-Filled Porosity** | 35-50% | Excellent |
| **Water Holding Capacity** | 25-35% | Moderate |
| **Available Water** | 15-25% | Moderate |
| **Structural Stability** | Permanent | Excellent |

#### Chemical Properties

| Property | Value | Notes |
|----------|-------|-------|
| **pH** | 6.5-7.5 | Neutral to slightly alkaline |
| **CEC** | 0-2 meq/100g | Very low (inert) |
| **Initial EC** | <0.2 dS/m | Inert |
| **Initial Nutrients** | None | Completely inert |

#### Grades Available

```
PERLITE PARTICLE SIZES

FINE (#1-2)              MEDIUM (#3-4)           COARSE (#5)
0.5-2 mm                 2-4 mm                  4-6 mm
┌──────────┐            ┌──────────┐            ┌──────────┐
│ ○○○○○○○  │            │ ○  ○  ○  │            │ ●    ●   │
│ ○○○○○○○  │            │  ○  ○  ○ │            │   ●    ● │
│ ○○○○○○○  │            │ ○  ○  ○  │            │ ●    ●   │
└──────────┘            └──────────┘            └──────────┘
Seed starting           General purpose         Drainage layer
```

#### Advantages

✓ Excellent aeration
✓ Lightweight
✓ Sterile and inert
✓ Permanent (doesn't break down)
✓ Improves drainage
✓ Neutral pH
✓ No nutrient tie-up
✓ Affordable

#### Disadvantages

✗ Low water holding capacity
✗ No CEC (can't hold nutrients)
✗ Floats when watered
✗ Dusty (silica dust hazard - wear mask)
✗ Bright white color (visible in media)
✗ Can crush if compacted
✗ Non-renewable resource

#### Best Uses

- **Mix Component** (10-50% of blend)
  - Improves aeration
  - Lightens heavy mixes
  - Prevents compaction

- **Hydroponic Systems**
  - Aggregate hydroponics
  - Drainage layer

- **Seed Starting** (fine grades)

- **Rooting Cuttings** (mixed with peat/coco)

#### Typical Blend Ratios

| Use | Peat/Coco | Perlite | Properties |
|-----|-----------|---------|------------|
| **Seed starting** | 70-80% | 20-30% | High water retention |
| **General purpose** | 50-70% | 30-50% | Balanced |
| **Succulents** | 20-40% | 60-80% | Excellent drainage |
| **Orchids** | 0% | 100% | Pure drainage |

### 4.4 Vermiculite

#### Origin and Production

**Source:** Mica minerals (hydrated magnesium-aluminum-iron silicate)

**Processing:**
1. Mine vermiculite ore
2. Grade by size
3. Heat to 1400-2000°F
4. Expands into accordion-like layers
5. Cool and package

```
VERMICULITE EXPANSION

Raw Vermiculite         Heated                Expanded Vermiculite
┌──────────┐           →  →  →  →           ┌──────────┐
│ ▓▓▓▓▓▓▓  │                                │ ═══════  │
│ ▓▓▓▓▓▓▓  │         Layers separate        │ ═══════  │
│ ▓▓▓▓▓▓▓  │         and expand             │ ═══════  │
└──────────┘                                 └──────────┘
Flat layers                                  Accordion structure
                                            Traps water/air
```

#### Physical Properties

| Property | Value | Rating |
|----------|-------|--------|
| **Bulk Density** | 10-15 lb/ft³ (0.16-0.24 g/cm³) | Light |
| **Total Porosity** | 75-85% | Excellent |
| **Air-Filled Porosity** | 15-25% | Good |
| **Water Holding Capacity** | 50-65% | Excellent |
| **Available Water** | 30-40% | Very good |
| **Structural Stability** | Fair (compacts over time) | Moderate |

#### Chemical Properties

| Property | Value | Notes |
|----------|-------|-------|
| **pH** | 6.5-7.5 | Neutral to slightly alkaline |
| **CEC** | 100-150 meq/100g | Excellent |
| **Initial EC** | <0.5 dS/m | Very low |
| **Natural Mg & K** | Small amounts | Minimal nutrient contribution |

#### Advantages

✓ Excellent water retention
✓ High CEC (holds nutrients)
✓ Lightweight
✓ Sterile
✓ Provides some Mg and K
✓ Insulates roots (temperature buffering)
✓ Good aeration when fresh

#### Disadvantages

✗ Compacts over time
✗ Loses structure with handling
✗ Expensive compared to perlite
✗ Can hold too much water in wet climates
✗ Non-renewable resource
✗ Limited reusability

#### Grades Available

| Grade | Size | Best Use |
|-------|------|----------|
| **Superfine** | <1 mm | Seed germination |
| **Fine** | 1-2 mm | Seed starting, mixing |
| **Medium** | 2-4 mm | General purpose |
| **Coarse** | 4-8 mm | Rooting, drainage |

#### Best Uses

- **Seed Starting** (especially fine grades)
  - Holds moisture evenly
  - Good seed-to-medium contact

- **Rooting Cuttings**
  - Retains moisture
  - Provides aeration

- **Mix Component** (10-30%)
  - Increases water retention
  - Adds CEC
  - Lightens mix

- **Hydroponic Systems** (coarse grades)
  - Wick systems
  - Aggregate culture

#### Perlite vs. Vermiculite

```

Property         Perlite      Vermiculite
────────────────────────────────────────────
```

### 4.5 Pine Bark

#### Origin and Production

**Source:** Bark from pine trees (forestry byproduct)

**Processing:**
1. Remove bark from harvested logs
2. Age/compost 6-12 months (critical!)
3. Screen to particle size
4. Grade and bag

```
BARK AGING PROCESS

Fresh Bark                 Aged/Composted Bark
(DO NOT USE)               (Ready to use)
┌──────────┐              ┌──────────┐
│ ████████ │              │ ▓▓▓▓▓▓▓▓ │
│ Contains │              │ Stable   │
│ resins,  │  →6-12 mo→   │ pH       │
│ tannins  │              │ Dark     │
│ Ties up N│              │ color    │
└──────────┘              └──────────┘
High C:N ratio            Lower C:N ratio
```

#### Physical Properties

| Property | Value | Rating |
|----------|-------|--------|
| **Bulk Density** | 12-18 lb/ft³ (0.19-0.29 g/cm³) | Moderate |
| **Total Porosity** | 65-75% | Good |
| **Air-Filled Porosity** | 25-40% | Excellent |
| **Water Holding Capacity** | 35-50% | Moderate-good |
| **Available Water** | 20-35% | Moderate |
| **Structural Stability** | Good (1-2 years) | Good |

#### Chemical Properties

| Property | Value | Notes |
|----------|-------|-------|
| **pH** | 4.0-5.5 (fresh) to 5.5-6.5 (aged) | Becomes neutral with composting |
| **CEC** | 10-40 meq/100g | Moderate |
| **Initial EC** | <1.0 dS/m | Low |
| **C:N Ratio** | High when fresh | Needs N supplementation initially |

#### Particle Sizes

```
BARK PARTICLE SIZES

FINE (<6 mm)             MEDIUM (6-12 mm)        COARSE (>12 mm)
┌──────────┐            ┌──────────┐            ┌──────────┐
│ ▓▓▓▓▓▓▓  │            │ █  █  █  │            │ ██    ██ │
│ ▓▓▓▓▓▓▓  │            │  █  █  █ │            │    ██    │
│ ▓▓▓▓▓▓▓  │            │ █  █  █  │            │ ██    ██ │
└──────────┘            └──────────┘            └──────────┘
Mix component           General container       Mulch, orchids
Higher water            Balanced                High drainage
```

#### Advantages

✓ Byproduct (sustainable sourcing)
✓ Excellent drainage
✓ Good structure (resists compaction)
✓ Affordable
✓ Readily available (in timber regions)
✓ Long-lasting
✓ Good for perennials

#### Disadvantages

✗ **MUST be composted** before use
✗ Variable quality (source dependent)
✗ May contain wood chips (lower quality)
✗ Can tie up nitrogen initially
✗ Moderate water retention (may dry quickly)
✗ Heavy when wet
✗ Acidic pH (may need lime)

#### Quality Indicators

**High-Quality Bark:**
- Dark brown color (well-composted)
- Consistent particle size
- No wood chips
- No green material
- Aged 6-12+ months
- Neutral smell

**Low-Quality Bark:**
- Light tan/yellow color (fresh)
- Variable particle sizes
- Contains wood pieces
- Sour/ammonia smell
- Not aged adequately

#### Best Uses

- **Container Production** (30-80% of mix)
  - Nursery containers
  - Perennials
  - Shrubs and trees

- **Mix Component**
  - Adds structure
  - Improves drainage
  - Reduces cost

- **Coarse Grades**
  - Orchid mixes
  - Mulch

#### Nitrogen Management with Bark

```
NITROGEN DYNAMICS IN BARK MIXES

Problem: Microbes consume N while
         decomposing bark

Solution:
┌────────────────────────────────────┐
│ ADD EXTRA NITROGEN                 │
│ • 1-2 lb actual N per yard³        │
│ • Use slow-release N source        │
│ • Or increase liquid feed by 25%   │
│                                    │
│ Only needed for FRESH bark         │
│ Composted bark = minimal issue     │
└────────────────────────────────────┘
```

### 4.6 Other Media Materials

#### Rock Wool (Mineral Wool)

**Source:** Molten rock (basalt) spun into fibers

| Property | Value |
|----------|-------|
| **Use** | Hydroponics, seed starting |
| **Porosity** | 95-97% (excellent) |
| **pH** | 7.0-8.0 (pre-soak to 5.5-6.0) |
| **CEC** | Very low (inert) |
| **Advantages** | Uniform, sterile, excellent air/water |
| **Disadvantages** | Non-renewable, disposal issues, dusty, must pre-soak |

#### Composted Materials

**Types:** Garden compost, mushroom compost, worm castings

| Property | Consideration |
|----------|---------------|
| **Advantages** | Adds nutrients, improves structure, sustainable |
| **Disadvantages** | Variable quality, may contain salts/weed seeds/pathogens |
| **Use** | 10-30% of mix (test first) |
| **Testing** | Always test pH, EC, nutrients before use |

#### Sand

**Source:** Crushed rock (use coarse horticultural sand, not fine builder's sand)

| Property | Value |
|----------|-------|
| **Bulk Density** | 90-100 lb/ft³ (very heavy!) |
| **Use** | Weight/ballast, drainage, propagation |
| **Advantages** | Permanent, sterile, improves drainage |
| **Disadvantages** | Very heavy, no water retention, no CEC |
| **Application** | 10-25% in mixes needing weight or drainage |

#### Expanded Clay Pellets (LECA)

**Source:** Clay heated until it expands

| Property | Value |
|----------|-------|
| **Use** | Hydroponics, drainage layer |
| **Advantages** | Lightweight, reusable, pH neutral, excellent drainage |
| **Disadvantages** | Expensive, no water retention, no CEC |
| **Application** | Hydroponic systems, orchids, drainage |

### 4.7 Sustainability Comparison

```
ENVIRONMENTAL IMPACT ASSESSMENT

Material        Renewable  Carbon     Sourcing   Overall
                          Footprint   Distance   Rating
────────────────────────────────────────────────────────
Coco Coir       ★★★★★    ★★★        ★★         ★★★★
Peat Moss       ★         ★★         ★★★★       ★★
Compost         ★★★★★    ★★★★★      ★★★★★      ★★★★★
Pine Bark       ★★★★     ★★★★       ★★★★       ★★★★
Perlite         ★         ★          ★★★        ★★
Vermiculite     ★         ★          ★★         ★★

Sand (local)    ★         ★★★★       ★★★★★      ★★★

Rating: ★ = Poor/Low    ★★★★★ = Excellent/High
```

**Most Sustainable Choices:**
1. **Local compost** - Renewable, local, recycled
2. **Composted bark** - Byproduct, renewable
3. **Coco coir** - Renewable, but long transport
4. **Worm castings** - Renewable, recycled

**Least Sustainable:**
1. **Peat moss** - Non-renewable, habitat destruction
2. **Rock wool** - Non-renewable, disposal issues
3. **Mined minerals** (perlite, vermiculite) - Non-renewable

## Vocabulary

| Term | Definition |
|------|------------|
| **Sphagnum Peat Moss** | Partially decomposed moss from peat bogs |
| **Coco Coir** | Coconut husk fiber used as growing medium |
| **Perlite** | Expanded volcanic glass used for aeration |
| **Vermiculite** | Expanded mica mineral with high water retention |
| **Pine Bark** | Composted tree bark used as media component |
| **Rock Wool** | Spun mineral fibers used in hydroponics |
| **Hydrophobic** | Repels water (characteristic of dry peat) |
| **Composting** | Aging process that stabilizes organic materials |
| **Inert Media** | Material with no nutrient content or chemical activity |
| **Aggregate** | Chunky material creating pore space |
| **Buffering** | Resistance to chemical change (pH, nutrients) |
| **LECA** | Lightweight Expanded Clay Aggregate |
