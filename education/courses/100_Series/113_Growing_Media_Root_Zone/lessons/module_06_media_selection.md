#### Matching Media to Crops

**High Water Need Crops:**
```
Lettuce, Herbs, Seedlings
↓
Need HIGH water retention
↓
Increase peat/coco, reduce perlite
Example: 70% coco coir + 30% perlite
```

**Low Water Need Crops:**
```
Succulents, Cacti, Orchids
↓
Need HIGH drainage
↓
Increase perlite/bark, reduce peat/coco
Example: 30% coco coir + 70% perlite
```

**Standard Vegetables:**
```
Tomatoes, Peppers, Cucumbers
↓
Need BALANCED water/air
↓
Moderate components
Example: 60% coco + 30% perlite + 10% bark
```

#### Container Size Considerations

```
CONTAINER DEPTH vs MEDIA PROPERTIES

SHALLOW CONTAINERS (< 6")
┌────────────┐
│    Media   │ • Higher water retention needed
│   ▒▒▒▒▒   │ • Dries quickly
└────────────┘ • Use finer particles
                • More peat/coco

MEDIUM CONTAINERS (6-12")
┌────────────┐
│            │
│    Media   │ • Balanced mix
│   ▒▒▒▒▒   │ • Standard formulations
│            │
└────────────┘

DEEP CONTAINERS (> 12")
┌────────────┐
│            │
│            │ • Add drainage materials
│    Media   │ • Coarser particles
│   ▒▒▒▒▒   │ • More perlite/bark
│            │ • Prevent perched water
│            │
└────────────┘
```

| Container Depth | Water Retention Component | Drainage Component |
|----------------|--------------------------|-------------------|
| **< 6 inches** | 70-80% | 20-30% |
| **6-12 inches** | 60-70% | 30-40% |
| **> 12 inches** | 50-60% | 40-50% |

#### Irrigation System Impact

```
MEDIA ADJUSTMENTS BY IRRIGATION TYPE

HAND WATERING (1x daily)
├─ Need: High water retention
├─ AFP target: 15-25%
└─ Recipe: 70% peat/coco, 30% perlite

DRIP IRRIGATION (2-4x daily)
├─ Need: Moderate water retention
├─ AFP target: 20-30%
└─ Recipe: 60% peat/coco, 40% perlite

EBB & FLOW (4-6x daily)
├─ Need: Good drainage critical
├─ AFP target: 25-35%
└─ Recipe: 50% peat/coco, 50% perlite

CONSTANT FEED/HYDROPONICS
├─ Need: Maximum drainage
├─ AFP target: 30-50%
└─ Recipe: 100% inert (perlite, rockwool, clay)
```

### 6.3 Creating Custom Blends

#### Step-by-Step Blending Process

```
MEDIA BLENDING PROCEDURE

STEP 1: DEFINE REQUIREMENTS
┌───────────────────────────┐
│ Crop: Tomatoes            │
│ Container: 5-gallon       │
│ Irrigation: Drip, 2x/day  │
│ Target AFP: 25%           │
└───────────────────────────┘
         ↓
STEP 2: SELECT COMPONENTS
┌───────────────────────────┐
│ Base: Coco coir           │
│ Drainage: Perlite         │
│ Structure: Pine bark      │
└───────────────────────────┘
         ↓
STEP 3: DETERMINE RATIOS
┌───────────────────────────┐
│ 60% Coco coir            │
│ 30% Perlite              │
│ 10% Pine bark            │
└───────────────────────────┘
         ↓
STEP 4: CALCULATE AMOUNTS
┌───────────────────────────┐
│ For 10 cubic feet:        │
│ 6 cu ft coco coir        │
│ 3 cu ft perlite          │
│ 1 cu ft pine bark        │
└───────────────────────────┘
         ↓
STEP 5: ADD AMENDMENTS
┌───────────────────────────┐
│ Limestone: 3 lbs          │
│ Gypsum: 2 lbs            │
│ Wetting agent: 1 oz       │
└───────────────────────────┘
         ↓
STEP 6: MIX THOROUGHLY
┌───────────────────────────┐
│ Layer components          │
│ Turn/blend 3-5 times      │
│ Ensure uniform mixture    │
└───────────────────────────┘
```

#### Volumetric Measurement

**Always measure by VOLUME, not weight**

```
MEASURING METHODS

SMALL BATCHES (< 10 gallons)
├─ Use buckets or measuring cups
├─ Level off each measurement
└─ Mix in wheelbarrow or tub

MEDIUM BATCHES (10-100 gallons)
├─ Use 5-gallon buckets
├─ Mark ratios on bucket
└─ Mix in large bin or on tarp

LARGE BATCHES (> 100 gallons)
├─ Measure in cubic feet/yards
├─ Use front-end loader
└─ Mix with mechanical mixer
```

**Conversion Reference:**
```
VOLUME CONVERSIONS

1 cubic yard = 27 cubic feet
1 cubic foot = 7.48 gallons
1 gallon = 4 quarts = 16 cups
1 cubic yard ≈ 200 gallons
```

#### Testing Your Blend

**Before using new blend:**

```
BLEND VERIFICATION TESTS

1. PHYSICAL INSPECTION
   ├─ Uniform mixing? (no layers)
   ├─ Appropriate moisture?
   └─ Consistent particle distribution?

2. LABORATORY TESTING
   ├─ pH (target: 5.5-6.5)
   ├─ EC (target: < 1.0 dS/m)
   ├─ Air-filled porosity
   └─ Water holding capacity

3. GROW TRIAL
   ├─ Plant test crop in small sample
   ├─ Monitor for 2-4 weeks
   ├─ Compare to standard mix
   └─ Adjust recipe if needed
```

### 6.4 Scaling Recipes

#### From Small to Large Scale

**Example: Scaling a Recipe**

```
ORIGINAL RECIPE (1 gallon):
├─ 3 cups coco coir
├─ 2 cups perlite
└─ 1 cup pine bark

SCALED TO 1 CUBIC YARD (200 gallons):

Method 1: Direct multiplication
├─ 200 × 3 cups = 600 cups coco = 37.5 gallons
├─ 200 × 2 cups = 400 cups perlite = 25 gallons
└─ 200 × 1 cup = 200 cups bark = 12.5 gallons

Method 2: Convert to percentages
├─ 50% coco coir = 13.5 cu ft
├─ 33% perlite = 9 cu ft
└─ 17% bark = 4.5 cu ft
   TOTAL = 27 cu ft (1 cu yd)
```

```
GROWING MEDIA COMPONENT COSTS
```

#### Cost Comparison Example

```
RECIPE COMPARISON: 1 CUBIC YARD

RECIPE A: Peat-Perlite (Cornell Mix)
├─ 13.5 cu ft peat @ $3.50/ft     = $47.25
├─ 13.5 cu ft perlite @ $2.00/ft  = $27.00
├─ Limestone (7 lbs @ $0.50)      = $3.50
└─ TOTAL                          = $77.75/cu yd
                                   = $0.39/gallon

RECIPE B: Coco-Perlite
├─ 18.9 cu ft coco @ $2.75/ft     = $51.98
├─ 8.1 cu ft perlite @ $2.00/ft   = $16.20
├─ Gypsum (2 lbs @ $0.60)         = $1.20
└─ TOTAL                          = $69.38/cu yd
                                   = $0.35/gallon

RECIPE C: Bark-Based Mix
├─ 16.2 cu ft bark @ $1.50/ft     = $24.30
├─ 8.1 cu ft perlite @ $2.00/ft   = $16.20
├─ 2.7 cu ft compost @ $1.00/ft   = $2.70
├─ Limestone (5 lbs @ $0.50)      = $2.50
└─ TOTAL                          = $45.70/cu yd
                                   = $0.23/gallon

COMMERCIAL PRE-MIX
├─ Premium bagged mix             = $120-180/cu yd
└─ TOTAL                          = $0.60-0.90/gallon
```

**Cost Factors to Consider:**
```
TOTAL COST OF OWNERSHIP

Direct Costs:
├─ Materials
├─ Amendments
├─ Shipping/delivery
└─ Storage containers

Labor Costs:
├─ Mixing time
├─ Quality control
├─ Container filling
└─ Cleanup

Overhead:
├─ Storage space
├─ Equipment (mixer, loader)
└─ Waste/spoilage

Compare to pre-mix:
├─ Higher material cost
├─ Lower labor
├─ Consistent quality
└─ Convenience
```

#### Break-Even Analysis

```
WHEN TO MIX YOUR OWN MEDIA?

Small Operation (< 500 containers/year)
└─ Recommendation: Buy pre-mix
   • Labor cost exceeds savings
   • Quality control easier
   • Storage challenges

Medium Operation (500-5,000 containers/year)
└─ Recommendation: Evaluate both
   • May save 30-50% on materials
   • Need mixing equipment
   • Quality control critical

Large Operation (> 5,000 containers/year)
└─ Recommendation: Mix your own
   • Save 40-60% on materials
   • Can customize for crops
   • Justify equipment investment
   • Better quality control
```

### 6.6 Pre-Mixed vs. Custom Media

#### Commercial Media Evaluation

```
EVALUATING PRE-MIXED MEDIA

CHECK LABEL FOR:
┌────────────────────────────────┐
│ ✓ Ingredient list              │
│ ✓ Guaranteed analysis          │
│ ✓ pH range                     │
│ ✓ Fertilizer content           │
│ ✓ Batch/lot number             │
│ ✓ Production date              │
│ ✓ Manufacturer info            │
└────────────────────────────────┘

PHYSICAL INSPECTION:
├─ Color (consistent?)
├─ Moisture (not too wet/dry)
├─ Particle size (uniform?)
├─ Foreign materials (none)
├─ Smell (earthy, not sour)
└─ Texture (appropriate for use)
```

#### Pros and Cons Summary

| Factor | Custom Blending | Pre-Mixed Commercial |
|--------|----------------|---------------------|
| **Cost** | Lower (bulk) | Higher per unit |
| **Quality Control** | Your responsibility | Manufacturer's responsibility |
| **Consistency** | Variable | Very consistent |
| **Customization** | Complete control | Limited options |
| **Labor** | Significant | Minimal |
| **Storage** | Need space for components | Less space needed |
| **Expertise** | Required | Not required |
| **Flexibility** | Can adjust batches | Fixed formulation |
| **Risk** | Higher (mixing errors) | Lower |
