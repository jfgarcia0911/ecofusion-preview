### 2.1 Particle Size Distribution

#### What is Particle Size?

**Particle size** refers to the diameter of individual pieces in the growing media. Size dramatically affects how media performs.

```
PARTICLE SIZE CLASSIFICATION

┌────────────────────────────────────────────────┐
│  VERY FINE    FINE      MEDIUM     COARSE      │
│                                                │
│    ·         ●          ◆          ■           │
│  <0.5mm    0.5-1mm    1-3mm      3-6mm        │
│                                                │
│  Examples:                                     │
│  Peat       Fine       Medium     Bark         │
│  dust       perlite    perlite    chips        │
│                                                │
│  Water: ████████  ██████    ████      ██       │
│  Air:   ██        ████      ██████    ████████ │
└────────────────────────────────────────────────┘
```

#### Particle Size Impact

| Particle Size | Water Retention | Air Space | Drainage | Best For |
|---------------|----------------|-----------|----------|----------|
| **Very Fine** (<0.5mm) | Excellent | Poor | Slow | Seed starting |
| **Fine** (0.5-1mm) | Very good | Fair | Moderate | Rooting cuttings |
| **Medium** (1-3mm) | Good | Good | Good | General purpose |
| **Coarse** (3-6mm) | Fair | Excellent | Fast | Orchids, drainage |
| **Very Coarse** (>6mm) | Poor | Excellent | Very fast | Structural amendment |

#### Particle Size Distribution

**Most effective media** contain a **mixture of particle sizes**:

```
IDEAL PARTICLE SIZE DISTRIBUTION

┌─────────────────────────────────────────┐
│   Percentage by Volume                  │
│                                         │
│   Fine (0.5-1mm):    20-30%  ████      │
│   Medium (1-3mm):    50-60%  ██████    │
│   Coarse (3-6mm):    10-20%  ██        │
│                                         │
│   Result: Balance of water/air space   │
└─────────────────────────────────────────┘
```

**Why Mix Sizes?**
- Small particles hold water
- Large particles create air pores
- Medium particles provide structure
- Mix prevents compaction

#### Measuring Particle Size

**Sieve Analysis Method:**

```
SIEVE STACK FOR PARTICLE SIZING

        ┌─────────────┐
        │  6mm mesh   │  Removes very coarse
        ├─────────────┤
        │  3mm mesh   │  Removes coarse
        ├─────────────┤
        │  1mm mesh   │  Removes medium
        ├─────────────┤
        │  0.5mm mesh │  Removes fine
        ├─────────────┤
        │ Collection  │  Very fine particles
        │    Pan      │
        └─────────────┘

Weigh each fraction to determine distribution
```

### 2.2 Porosity: The Critical Property

#### Understanding Porosity

**Porosity** is the percentage of media volume that is **empty space** (not solid particles). This space fills with water and/or air.

**Formula:**
```
Total Porosity (%) = (1 - Bulk Density/Particle Density) × 100

Or by water saturation:
Total Porosity (%) = Volume of water needed to saturate / Total media volume × 100
```

#### Three Types of Porosity

```
POROSITY BREAKDOWN

┌──────────────────────────────────────────────┐
│                                              │
│  TOTAL POROSITY = 100%                       │
│  ├─ WATER-FILLED PORES (after saturation)   │
│  │  └─ Container Capacity (after drainage)  │
│  │     └─ Available Water (plant accessible)│
│  │     └─ Unavailable Water (held tightly)  │
│  │                                           │
│  └─ AIR-FILLED PORES (after drainage)       │
│     └─ Critical for root respiration        │
│                                              │
└──────────────────────────────────────────────┘
```

#### A. Total Porosity

**Total space available** for air and water combined.

| Media Type | Total Porosity | Quality |
|------------|----------------|---------|
| Peat moss | 85-95% | Excellent |
| Coco coir | 85-90% | Excellent |
| Perlite | 60-75% | Good |
| Rock wool | 95-97% | Excellent |
| Bark | 65-75% | Good |
| Pine bark:peat 50:50 | 75-85% | Very good |

**Ideal Range:** 50-85% total porosity

#### B. Air-Filled Porosity (AFP)

**Percentage of volume filled with AIR after drainage** (most critical measurement).

```
AIR-FILLED POROSITY AT CONTAINER CAPACITY

┌────────────────────────────────────────┐
│         Media Container                │
│  ┌──────────────────────────────┐     │
│  │  Air Space (AFP) 10-30%      │     │
│  │  ░░░░░░░░░░░░░░░░░░░░░░░░░░ │     │
│  ├──────────────────────────────┤     │
│  │  Water 30-60%                │     │
│  │  ████████████████████████    │     │
│  ├──────────────────────────────┤     │
│  │  Solid particles 10-40%      │     │
│  │  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓   │     │
│  └──────────────────────────────┘     │
│     After irrigation & drainage        │
└────────────────────────────────────────┘
```

**Critical Ranges:**

| AFP Level | Impact on Plant Growth |
|-----------|------------------------|
| **<10%** | Insufficient oxygen - root suffocation, disease |
| **10-20%** | Adequate for most crops |
| **20-30%** | Ideal for rapid growth |
| **30-45%** | Excellent for drainage-loving crops |
| **>45%** | May dry too quickly, frequent irrigation needed |

**Target for Most Crops:** 15-30% AFP

#### C. Water-Filled Porosity

**Percentage of volume filled with WATER after drainage.**

**Components:**
1. **Available Water** - Plants can extract (tension 10-100 kPa)
2. **Unavailable Water** - Held too tightly to roots (>100 kPa)

| Media Type | Container Capacity | Available Water | Unavailable Water |
|------------|-------------------|-----------------|-------------------|
| Peat moss | 60-75% | 35-45% | 25-30% |
| Coco coir | 55-65% | 40-50% | 15-20% |
| Perlite | 15-30% | 10-20% | 5-10% |
| Rock wool | 60-70% | 45-55% | 15-20% |
| Bark | 30-45% | 20-30% | 10-15% |

### 2.3 Bulk Density

#### Definition

**Bulk density** is the weight of dry media per unit volume (including pore space).

**Formula:**
```
Bulk Density (lb/ft³) = Dry weight of media / Total volume

Or metric:
Bulk Density (g/cm³) = Dry weight (g) / Total volume (cm³)
```

#### Typical Bulk Densities

```
BULK DENSITY COMPARISON

Material              lb/ft³    g/cm³    Handling
─────────────────────────────────────────────────
Rock wool             6-8       0.10     Very light
Perlite               6-9       0.10     Very light
Coco coir             8-10      0.13     Light
Peat moss             10-12     0.16     Light
Vermiculite           10-15     0.18     Light
Pine bark             12-18     0.20     Moderate
Peat:perlite 50:50    8-11      0.14     Light
Sand                  90-100    1.50     Very heavy
Field soil            75-100    1.25     Heavy
```

#### Why Bulk Density Matters

**For Growers:**

| Concern | Impact of Density |
|---------|-------------------|
| **Shipping** | Low density = lower transport costs |
| **Handling** | Light media easier for workers |
| **Rooftop Growing** | Weight limits require low density |
| **Stability** | Very low density = plants tip over |
| **Watering** | Density affects water retention |

**Ideal Range:** 0.10-0.40 g/cm³ (6-25 lb/ft³)

#### Measuring Bulk Density

```
BULK DENSITY MEASUREMENT PROCEDURE

1. Take container of known volume (e.g., 1000 cm³)
   ┌─────────────┐
   │             │  1000 cm³
   │             │  container
   └─────────────┘

2. Fill with media using standard method
   ┌─────────────┐
   │▒▒▒▒▒▒▒▒▒▒▒▒▒│  Fill & level
   │▒▒▒▒▒▒▒▒▒▒▒▒▒│  (don't pack)
   └─────────────┘

3. Dry media at 105°C until constant weight
   [oven] → [scale]

4. Calculate:
   Bulk Density = 150g / 1000cm³ = 0.15 g/cm³
```

### 2.4 Water-Air Relationships

#### The Critical Balance

**Roots need BOTH water and oxygen**. The relationship between these is determined by physical properties.

```
WATER-AIR RELATIONSHIP IN ROOT ZONE

AFTER IRRIGATION                HOURS LATER
(Saturated)                     (Container Capacity)

┌──────────────┐               ┌──────────────┐
│Water: 80-90% │               │Water: 40-60% │
│Air:   10-20% │               │Air:   20-40% │
│Solids: 10%   │               │Solids: 10%   │
└──────────────┘               └──────────────┘
  Root stress!                   Ideal balance
  (brief OK)                     (maintain this)

        │                              │
        └──────────Drainage────────────┘
                   (minutes to hours)
```

#### Container Capacity

**Container capacity** (also called field capacity) is the water content after free drainage stops.

**This is the most important measurement** because it represents the media condition between waterings.

**At Container Capacity:**
- Gravity drainage has stopped
- Water and air are balanced
- Roots can access both easily

```
ACHIEVING CONTAINER CAPACITY

Time after irrigation:

0 min   ████████████████████  100% water (saturated)
        ░░░░░░░░░░░░░░░░░░░░  0% air

30 min  ██████████████░░░░░░  70% water
        ▒▒▒▒▒▒░░░░░░░░░░░░░░  30% air (draining)

60 min  ████████░░░░░░░░░░░░  40% water ← Container
        ▒▒▒▒▒▒▒▒▒▒▒▒░░░░░░░░  60% air     Capacity

No further drainage occurs - equilibrium reached
```

#### Easily Available Water (EAW)

**The portion of water** that plants can extract with minimal effort.

**Measurements:**
- **Container Capacity** = 100% available water
- **Wilting Point** = 0% available water
- **EAW** = Usually first 25-50% extracted

```
WATER AVAILABILITY CURVE

Water Content (%)
     100│ ████████████  Container Capacity
        │ ████████████  (after drainage)
        │ ████████████
      75│ ████████░░░░
        │ ██████░░░░░░  Easily Available
        │ ████░░░░░░░░  Water (EAW)
      50│ ██░░░░░░░░░░
        │ █░░░░░░░░░░░  Increasingly difficult
        │ ░░░░░░░░░░░░  for plant to extract
      25│ ░░░░░░░░░░░░
        │ ░░░░░░░░░░░░
        │ ░░░░░░░░░░░░  Wilting Point
       0└─────────────  (permanent damage)
```

**Management Strategy:**
- Irrigate when 40-50% of available water depleted
- Maintains EAW range
- Prevents stress

### 2.5 Structure and Stability

#### Media Structure

**Structure** refers to how particles arrange and hold together.

```
MEDIA STRUCTURE TYPES

WELL-STRUCTURED                 POORLY-STRUCTURED
┌──────────────┐               ┌──────────────┐
│ ●  ●  ●  ●  │               │●●●●●●●●●●●●●│
│  ●  ●  ●  ● │               │●●●●●●●●●●●●●│
│ ●  ●  ●  ●  │               │●●●●●●●●●●●●●│
│  ●  ●  ●  ● │               │●●●●●●●●●●●●●│
└──────────────┘               └──────────────┘
Pore spaces                    Compacted
maintained                     No pore space
Stable over time               Degrades quickly
```

#### Structural Stability

**Good media maintains structure** despite:
- Repeated wetting/drying cycles
- Physical handling
- Microbial decomposition
- Root growth pressure

**Stability Ratings:**

| Material | Structural Stability | Lifespan in Use |
|----------|---------------------|-----------------|
| Perlite | Excellent (permanent) | Years |
| Rock wool | Excellent | 1-2 years |
| Sand | Excellent (permanent) | Years |
| Coco coir | Very good | 1-3 years |
| Peat moss | Good | 1-2 years |
| Pine bark (composted) | Good | 1-2 years |
| Uncomposted bark | Fair | <1 year (decomposes) |
| Compost | Poor | Months (breaks down) |

#### Compaction

**Compaction** = Loss of pore space due to particle settling.

**Causes:**
1. Mechanical pressure (weight, handling)
2. Particle breakdown
3. Repeated wetting/drying
4. Vibration during transport

**Effects of Compaction:**

```
BEFORE vs AFTER COMPACTION

INITIAL                        AFTER 6 MONTHS
(New media)                    (Compacted)

Height: 100%                   Height: 80%
┌──────────┐                  ┌──────────┐
│Air:  30% │                  │Air:  15% │ ← Reduced
│Water:50% │                  │Water:60% │ ← Increased
│Solid:20% │                  │Solid:25% │ ← Increased
└──────────┘                  └──────────┘
Good growth                    Poor growth
                              Drainage issues
                              Low oxygen
```

**Preventing Compaction:**
- Use structurally stable materials
- Include coarse particles (bark, perlite)
- Avoid over-handling
- Don't overfill containers
- Replace media when compacted

### 2.6 Practical Applications

#### Selecting Media for Water/Air Balance

**Consider irrigation frequency:**

| Irrigation System | Recommended AFP | Media Strategy |
|-------------------|----------------|----------------|
| Hand watering (daily) | 25-35% | Add perlite, bark for drainage |
| Drip (2-3x/day) | 15-25% | Balanced mix |
| Ebb & flood (3-4x/day) | 20-30% | Good drainage critical |
| Sub-irrigation (constant) | 30-40% | High AFP essential |

#### Container Depth Effects

**Depth changes water/air relationship:**

```
CONTAINER HEIGHT EFFECT ON DRAINAGE

SHALLOW (4 inches)              DEEP (12 inches)
┌──────────┐                   ┌──────────┐
│          │ Air: 35%          │          │
│  ░░░░░░  │ High AFP          │          │
│  ████    │ Water: 45%        │  ░░░░░░  │ Air: 25%
└──────────┘ Drains well       │  ░░░░░░  │ Medium AFP
                                │  ████    │ Water: 55%
                                │  ████    │ More water
                                │  ████    │ at bottom
                                └──────────┘ (perched water)
```

**Depth Guidelines:**

| Container Depth | Media Adjustment |
|-----------------|------------------|
| **Shallow (<6")** | Use finer particles, increase water retention |
| **Medium (6-12")** | Standard balanced mix |
| **Deep (>12")** | Add coarse materials at bottom for drainage |

#### Crop-Specific Requirements

| Crop Type | AFP Need | Water Need | Recommended Media |
|-----------|----------|------------|-------------------|
| Lettuce, herbs | Moderate (20-25%) | High | 70% peat/coco, 30% perlite |
| Tomatoes | Moderate (20-30%) | High | 60% peat/coco, 30% perlite, 10% bark |
| Orchids | High (40-50%) | Low | 50% bark, 50% perlite |
| Succulents | Very high (50%+) | Very low | 30% coco, 70% perlite/sand |
| Seedlings | Low (10-15%) | High | Fine peat or coco coir |

## Vocabulary

| Term | Definition |
|------|------------|
| **Particle Size Distribution** | Percentage of particles in different size ranges |
| **Total Porosity** | Percentage of media volume that is pore space (air + water) |
| **Air-Filled Porosity (AFP)** | Percentage of volume containing air after drainage |
| **Container Capacity** | Water content of media after gravity drainage stops |
| **Bulk Density** | Dry weight of media per unit volume |
| **Particle Density** | Weight of solid particles only (excluding pores) |
| **Available Water** | Water that plants can readily extract from media |
| **Easily Available Water** | Portion of water requiring minimal plant effort |
| **Wilting Point** | Moisture level where plants can no longer extract water |
| **Compaction** | Loss of pore space due to particle settling |
| **Structural Stability** | Ability of media to maintain pore space over time |
| **Perched Water** | Water held in bottom of container above drainage layer |
