# Assignment 5: Growing Media Research Project

## Course 107: Growing Media & Root Zone

**Type:** Final Project | **Points:** 15 | **Time:** 2-4 hours

## Project Overview
Compare growing media options for specific application with cost-benefit analysis.

## Project Components

### 1. Media Comparison (5 pts)
Select 3-4 media types and compare:
- Physical properties
- Chemical properties
- Performance characteristics
- Environmental impact

### 2. Application Analysis (4 pts)
For your chosen growing system:
- Crop requirements
- System compatibility
- Management considerations
- Performance expectations

### 3. Economic Analysis (3 pts)
- Initial cost per cubic foot
- Expected lifespan
- Replacement costs
- Total cost of ownership (3 years)

### 4. Recommendation (3 pts)
- Best media choice with justification
- Alternative options
- Implementation plan
