## Why Urban Agriculture?

```
    THE URBAN OPPORTUNITY

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │   By 2050:                                                          │
    │   • 68% of world population will live in cities                    │
    │   • 80% of food consumed in urban areas                            │
    │   • Yet nearly all food produced outside cities                    │
    │                                                                     │
    │   Urban agriculture can:                                            │
    │   ✓ Reduce food miles to ZERO                                      │

    │   ✓ Increase food security                                         │
```

## Challenges & Solutions

| Challenge | Potential Solutions |
|-----------|---------------------|
| **Land access** | Vacant lot programs, rooftop agreements, policy advocacy |
| **Soil contamination** | Raised beds, container growing, soil testing/remediation |
| **Water access** | Rainwater harvesting, greywater, city partnerships |
| **Zoning restrictions** | Advocacy, urban ag policy, variances |
| **Theft/vandalism** | Community engagement, fencing, visibility |
| **Lack of knowledge** | Training programs, extension services, mentorship |
| **Seasonality** | Season extension, greenhouses, indoor growing |
| **Funding** | Grants, crowdfunding, social enterprise models |

## Action Steps

```
    YOUR URBAN AGRICULTURE JOURNEY

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │   STEP 1: ASSESS YOUR SITUATION                                    │
    │   □ What space do you have? (window, balcony, yard, community)     │
    │   □ How much time can you commit?                                  │
    │   □ What's your budget?                                            │
    │   □ What do you want to grow?                                      │
    │                                                                     │
    │   STEP 2: START SMALL                                              │
    │   □ Begin with easy crops (herbs, salad greens)                    │
    │   □ Learn basic techniques                                         │
    │   □ Connect with local gardeners                                   │
    │                                                                     │
    │   STEP 3: EXPAND GRADUALLY                                         │
    │   □ Add variety as you gain confidence                             │
    │   □ Try new techniques (containers, hydroponics)                   │
    │   □ Consider season extension                                      │
    │                                                                     │
    │   STEP 4: CONNECT & CONTRIBUTE                                     │
    │   □ Share surplus with neighbors                                   │
    │   □ Join or start community garden                                 │
    │   □ Teach others what you've learned                               │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘
```
