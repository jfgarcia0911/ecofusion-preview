## Lesson Content

### 6.1 What is Controlled Environment Agriculture?

#### Definition

**Controlled Environment Agriculture (CEA):** A technology-based approach to agriculture where environmental variables are regulated to optimize plant growth and resource efficiency.

```
TRADITIONAL vs. CONTROLLED ENVIRONMENT

TRADITIONAL FIELD AGRICULTURE
┌──────────────────────────────────────┐
│  Dependent on:                       │
│  • Weather (uncontrollable)          │
│  • Season (limiting)                 │
│  • Soil quality (variable)           │
│  • Pests & diseases (challenging)    │
│  • Location (fixed)                  │
└──────────────────────────────────────┘

CONTROLLED ENVIRONMENT AGRICULTURE
┌──────────────────────────────────────┐
│  Control over:                       │
│  • Temperature ✓                     │
│  • Light ✓                           │
│  • Humidity ✓                        │
│  • CO2 ✓                             │
│  • Nutrients ✓                       │
│  • Water ✓                           │
│  • Pests ✓                           │
└──────────────────────────────────────┘
```

#### Core Principle

**Optimize Everything:** By controlling environmental variables, we can:
- Maximize photosynthesis
- Minimize plant stress
- Accelerate growth rates
- Produce year-round
- Reduce resource waste
- Predict outcomes consistently

### 6.2 The CEA Spectrum

```
CEA TECHNOLOGY SPECTRUM

LOW-TECH ←──────────────────────────────→ HIGH-TECH

Cold Frame → Hoop House → Greenhouse → Vertical → Indoor
                          (heated)      Farm      Farm
    │            │            │           │          │
    ▼            ▼            ▼           ▼          ▼
  Minimal    Some temp    Full climate  Stacked   Complete
  control    protection   control       systems   control

  $100s      $1,000s      $10,000s     $100,000s  $Millions
```

#### Types of CEA Systems

**1. Low-Tech: Season Extension**

| Type | Description | Cost | Control Level |
|------|-------------|------|---------------|
| **Cold Frame** | Box with transparent lid | $ | Minimal (passive solar) |
| **Row Covers** | Fabric draped over crops | $ | Temperature only |
| **Low Tunnel** | Hoops with plastic | $$ | Temperature, some moisture |
| **High Tunnel** | Walk-in unheated structure | $$$ | Temperature, wind, rain |

**2. Mid-Tech: Greenhouses**

```
GREENHOUSE STRUCTURE

        Transparent Covering
       /‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\
      /                      \
     /    [Plants growing]    \
    /_________________________ \
    │                         │
    │  Heating                │
    │  Ventilation            │
    │  Irrigation             │
    │  (Some automation)      │
    └─────────────────────────┘
```

| Feature | Details |
|---------|---------|
| **Structure** | Glass or plastic covering, natural light |
| **Heating** | Boilers, heaters, or passive solar |
| **Cooling** | Ventilation, evaporative cooling, shade |
| **Water** | Drip irrigation, overhead |
| **Cost** | $10,000-$500,000+ |
| **Uses** | Commercial vegetables, flowers, nurseries |

**3. High-Tech: Vertical Farms**

```
VERTICAL FARM LAYOUT

Floor 5  [═══════════════] ← LED lights
         [Plant racks]
Floor 4  [═══════════════]
         [Plant racks]
Floor 3  [═══════════════]
         [Plant racks]
Floor 2  [═══════════════]
         [Plant racks]
Floor 1  [Control room][Equipment]

Features:
• Stacked growing (10-20 levels)
• LED lighting (no sunlight needed)
• Hydroponic/aeroponic systems
• Climate control
• Automation & sensors
• Data-driven optimization
```

| Characteristic | Details |
|----------------|---------|
| **Location** | Warehouses, shipping containers, purpose-built |
| **Light** | 100% artificial (LED) |
| **Production** | Leafy greens, herbs, microgreens |
| **Efficiency** | 100x+ yield per sq ft vs. field |
| **Cost** | $1M-$100M+ |
| **Examples** | AeroFarms, Bowery, Plenty |

**4. Indoor Farms (Plant Factories)**

Complete control of all environmental factors:
- Temperature: ±1°F precision
- Humidity: 50-70% controlled
- CO2: Enriched to 800-1,200 ppm
- Light: Spectrum-optimized LEDs
- Nutrients: Precise delivery
- Airflow: HVAC managed

### 6.3 Environmental Control Parameters

```
THE SIX KEY PARAMETERS

┌─────────────────────────────────────────────┐
│  1. LIGHT                                   │
│     • Intensity (PPFD)                      │
│     • Duration (photoperiod)                │
│     • Spectrum (colors)                     │
├─────────────────────────────────────────────┤
│  2. TEMPERATURE                             │
│     • Day temperature                       │
│     • Night temperature                     │
│     • Root zone temperature                 │
├─────────────────────────────────────────────┤
│  3. HUMIDITY                                │
│     • Relative humidity %                   │
│     • Vapor Pressure Deficit (VPD)          │
├─────────────────────────────────────────────┤
│  4. CO2                                     │
│     • Ambient: ~400 ppm                     │
│     • Enriched: 800-1,200 ppm              │
├─────────────────────────────────────────────┤
│  5. WATER & NUTRIENTS                       │
│     • pH, EC/TDS                            │
│     • Nutrient ratios                       │
│     • Irrigation timing                     │
├─────────────────────────────────────────────┤
│  6. AIR MOVEMENT                            │
│     • Circulation                           │
│     • Gas exchange                          │
│     • Temperature uniformity                │
└─────────────────────────────────────────────┘
```

#### Parameter Details

**Light Requirements**

| Crop Type | Daily Light Integral (DLI) | Photoperiod |
|-----------|---------------------------|-------------|
| **Leafy Greens** | 12-17 mol/m²/day | 16-18 hours |
| **Herbs** | 15-20 mol/m²/day | 16-20 hours |
| **Fruiting Crops** | 20-30+ mol/m²/day | 12-14 hours |
| **Seedlings** | 8-12 mol/m²/day | 16-18 hours |

**Temperature Ranges**

```

(lettuce, herbs)

(tomatoes)

Cool Season:     50-65°F  [████████░░░░]

```

**Humidity & VPD**

| Growth Stage | Relative Humidity | VPD (kPa) |
|--------------|-------------------|-----------|
| **Seedling** | 70-80% | 0.4-0.8 |
| **Vegetative** | 60-70% | 0.8-1.2 |
| **Flowering/Fruiting** | 50-60% | 1.0-1.5 |

**CO2 Enrichment**

```

                          ▓▓▓▓▓▓▓▓▓▓
```

### 6.4 Technology in CEA

#### Sensors and Monitoring

**Essential Sensors:**

| Sensor Type | Measures | Why Important |
|-------------|----------|---------------|
| **Temperature** | Air and root temp | Growth rate optimization |
| **Humidity** | Moisture in air | Disease prevention, VPD |
| **Light** | PPFD, DLI | Ensure adequate photosynthesis |
| **CO2** | CO2 concentration | Optimize enrichment |
| **pH** | Water acidity | Nutrient availability |
| **EC/TDS** | Nutrient strength | Prevent deficiency/toxicity |

#### Climate Control Systems

```
AUTOMATED CLIMATE CONTROL

┌──────────────────────────────────────────┐
│         SENSORS MONITOR:                 │
│  Temperature │ Humidity │ CO2 │ Light   │
└───────┬──────────────────────────────────┘
        │
        ▼
┌──────────────────────────────────────────┐
│      CONTROLLER PROCESSES DATA           │
│   Compares to setpoints, decides action  │
└───────┬──────────────────────────────────┘
        │
        ▼
┌──────────────────────────────────────────┐
│        ACTUATORS RESPOND:                │
│  • Heater/AC    • Vents     • CO2        │
│  • Lights       • Fogger    • Fans       │
└──────────────────────────────────────────┘
        │
        └──→ Continuous feedback loop
```

#### Automation Levels

| Level | Description | Example |
|-------|-------------|---------|
| **Manual** | Human operation of all systems | Home greenhouse |
| **Semi-Automated** | Timers, simple thermostats | Small commercial |
| **Automated** | Integrated control, data logging | Advanced greenhouse |
| **AI-Driven** | Machine learning optimization | Vertical farms |

#### Quality and Safety

**Food Safety Advantages:**

| Factor | CEA Benefit |
|--------|-------------|
| **Pest Exclusion** | Sealed environment, fewer pests |
| **No Soil** | Eliminates soil-borne pathogens |
| **Controlled Water** | Filtered, treated water |
| **Traceability** | Complete tracking from seed to sale |
| **Reduced Contamination** | Controlled access, biosecurity |
| **Minimal Processing** | Clean enough to skip washing |

**Quality Benefits:**

- Consistent size and appearance
- Optimal nutrient content
- Extended shelf life (minimal transport)
- No weather damage
- Predictable harvest dates

### 6.6 CEA Challenges

#### Economic Challenges

**Capital Costs:**

| System | Initial Investment | Payback Period |
|--------|-------------------|----------------|
| **Hoop House** | $5,000-$20,000 | 2-5 years |
| **Greenhouse** | $50,000-$500,000 | 5-10 years |
| **Small Vertical** | $250,000-$1M | 7-12 years |
| **Large Vertical** | $10M-$100M+ | 10-20 years |

**Operating Costs:**

```
OPERATING COST BREAKDOWN (Typical Indoor Farm)

Energy (40%)         ████████
Labor (30%)          ██████
Seeds/Supplies (15%) ███
Maintenance (10%)    ██
Other (5%)           █

Energy is the biggest challenge for CEA profitability
```

#### Technical Challenges

| Challenge | Description | Solutions |
|-----------|-------------|-----------|
| **Energy Cost** | Lights, HVAC consume significant power | LED efficiency, solar, grid optimization |
| **Complexity** | Multiple systems must work together | Training, automation, remote monitoring |
| **Crop Limitations** | Not all crops viable (grains, root crops) | Focus on high-value crops |
| **Technology Risk** | Equipment failure impacts entire crop | Redundancy, maintenance programs |
| **Knowledge Gap** | New field, limited expertise | Education, research, mentorship |

#### Environmental Concerns

**The Sustainability Paradox:**

```
CEA SUSTAINABILITY TRADE-OFFS

POSITIVE ✓                       NEGATIVE ✗
• Water conservation             • High energy use
• No pesticides                  • Manufacturing impact
• Land efficiency                • E-waste from tech
• Local production               • Plastic waste
• Reduced transport              • Grid dependence
• Year-round availability        • Limited crop types

NET IMPACT depends on:
• Energy source (renewable vs. fossil fuel)
• Crops grown (replacing what?)
• Local context (climate, food system)
```
