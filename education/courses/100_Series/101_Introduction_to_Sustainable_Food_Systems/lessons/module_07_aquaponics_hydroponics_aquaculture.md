### 7.2 Hydroponics in Detail

#### How Hydroponics Works

```
HYDROPONIC SYSTEM BASICS

    PLANTS IN NET POTS
         │ │ │
         ▼ ▼ ▼
    ═════════════════    ← Growing channel/container
    ~~~~~~~~~~~~~~~~~    ← Nutrient solution
         │
         ▼
    RESERVOIR
    ┌─────────────┐
    │  Water +    │
    │  Nutrients  │
    │  (mixed by  │
    │   grower)   │
    └─────────────┘
         ▲
         │
    Pump recirculates
```

#### Major Hydroponic System Types

**1. Deep Water Culture (DWC)**

```
DWC SYSTEM

Plant ──┬── Net pot
        │
    ════╪════ ← Floating platform
    ████████ ← Deep nutrient solution (6-12")
    │ ○ ○ ○ │ ← Air stones providing oxygen
    └────────┘

Pros: Simple, low cost, fast growth
Cons: Root disease risk, power dependent
Best for: Lettuce, herbs, beginners
```

**2. Nutrient Film Technique (NFT)**

```
NFT SYSTEM

Plants in channels
    │ │ │ │
    ▼ ▼ ▼ ▼
═══════════════════ ← Sloped channel
~~~~ (thin film)    ← 1/8" nutrient film
    │
    ▼
Drain to reservoir → Pump back to top

Pros: Water efficient, good aeration
Cons: Clog risk, power dependent
Best for: Leafy greens, commercial
```

**3. Ebb and Flow (Flood and Drain)**

```
EBB AND FLOW

FLOOD CYCLE              DRAIN CYCLE
┌──────────┐            ┌──────────┐
│ ▓▓▓▓▓▓▓▓ │            │ ░░░░░░░░ │
│ ████████ │  ──→       │          │
│   │      │            │   │      │
│   ▼      │            │   ▼      │
└──────────┘            └──────────┘
Reservoir fills bed     Drains back

Pros: Versatile, forgiving
Cons: More complex plumbing
Best for: Variety of crops
```

**4. Drip Systems**

| Type | Description | Recovery |
|------|-------------|----------|
| **Recovery** | Excess drains back to reservoir | Reused |
| **Non-Recovery** | Drains to waste | More nutrients used |

**5. Aeroponics**

```
AEROPONIC SYSTEM

    Plants suspended in air
         │ │ │
         ▼ ▼ ▼
    ┌────────────┐
    │            │
    │  ○   ○   ○ │ ← Misting nozzles
    │            │
    │  Roots in  │
    │    air     │
    └──────┬─────┘
           │
    High-pressure pump

Pros: Maximum oxygen, fast growth
Cons: Complex, clog risk, expensive
Best for: Advanced growers, research
```

#### Hydroponic Nutrients

**Essential Elements Provided:**

| Type | Elements | Function |
|------|----------|----------|
| **Macronutrients** | N, P, K, Ca, Mg, S | Primary plant needs |
| **Micronutrients** | Fe, Mn, Zn, Cu, B, Mo, Cl | Trace requirements |

**Commercial Nutrient Formulas:**
- Two-part (A & B) most common
- Three-part allows more customization
- Organic options available (less common)

**Key Parameters:**

```
HYDROPONIC SOLUTION MANAGEMENT

pH:        5.5 ━━━━━━ 6.5
           (optimal range for nutrient uptake)

EC:        1.2 ━━━━━━ 2.4 mS/cm
           (varies by crop and stage)

Temperature: 65°F ━━━━ 72°F
             (root zone optimum)
```

### 7.3 Aquaculture Basics

#### What is Aquaculture?

**Aquaculture:** The breeding, rearing, and harvesting of aquatic organisms (fish, shellfish, aquatic plants) in controlled environments.

```
AQUACULTURE PRODUCTION SYSTEMS

┌────────────────────────────────────────────┐
│  EXTENSIVE (low density, natural feed)     │
│  • Ponds                                   │
│  • Minimal inputs                          │
│  • Traditional methods                     │
└────────────┬───────────────────────────────┘
             │
┌────────────▼───────────────────────────────┐
│  SEMI-INTENSIVE (moderate density)         │
│  • Aerated ponds                           │
│  • Supplemental feed                       │
│  • Some management                         │
└────────────┬───────────────────────────────┘
             │
┌────────────▼───────────────────────────────┐
│  INTENSIVE (high density, controlled)      │
│  • Tanks, raceways                         │
│  • Complete feed                           │
│  • Active management                       │
│  • Recirculating systems (RAS)             │
└────────────────────────────────────────────┘
```

#### Popular Aquaculture Species

**Freshwater:**

| Species | Growth Rate | Temperature | Market |
|---------|-------------|-------------|--------|
| **Tilapia** | Fast (6-8 months) | 75-85°F | Strong, growing |
| **Catfish** | Moderate (12-18 months) | 75-85°F | Established |
| **Trout** | Moderate (12-18 months) | 55-65°F | Premium |
| **Bass** | Slow (18-24 months) | 70-80°F | High-value |
| **Carp** | Fast (6-12 months) | 65-75°F | Global demand |

**Saltwater:**

| Species | Type | Notes |
|---------|------|-------|
| **Salmon** | Marine | High-value, intensive |
| **Shrimp** | Shellfish | Major global industry |
| **Oysters** | Shellfish | Filter feeders, sustainable |

#### Recirculating Aquaculture Systems (RAS)

```
RAS SYSTEM FLOW

┌──────────────┐
│  FISH TANK   │
│   🐟 🐟 🐟   │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ SOLID WASTE  │
│   REMOVAL    │ ← Mechanical filtration
│  (Settling)  │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  BIOFILTER   │
│  (Bacteria   │ ← Biological filtration
│   convert    │   (ammonia → nitrate)
│   ammonia)   │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  AERATION    │
│  (Add O2)    │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  RETURN TO   │
│  FISH TANK   │
└──────────────┘
       ▲
       │
       └──── Loop repeats
```

**RAS Advantages:**
- 90-99% water recirculation
- Location independent
- Disease control
- High density production

**RAS Challenges:**
- High capital cost
- Energy intensive
- Technical expertise required
- Waste concentration

### 7.4 Aquaponics: The Integration

#### The Magic of Symbiosis

```
THE AQUAPONIC CYCLE

┌──────────────┐
│     FISH     │
│              │
│  Eat feed    │
│  Produce     │
│  ammonia     │
└──────┬───────┘
       │ NH₃ (toxic to fish)
       ▼
┌──────────────┐
│  BACTERIA    │
│              │
│  Nitrosomonas│ NH₃ → NO₂ (nitrite)
│  Nitrobacter │ NO₂ → NO₃ (nitrate)
│              │
└──────┬───────┘
       │ NO₃ (plant food)
       ▼
┌──────────────┐
│   PLANTS     │
│              │
│  Absorb NO₃  │
│  Clean water │
│              │
└──────┬───────┘
       │ Clean H₂O
       ▼
┌──────────────┐
│  RETURN TO   │
│     FISH     │
└──────────────┘
```

#### The Nitrogen Cycle in Aquaponics

**Critical Process:**

| Stage | Chemical | Bacteria | Result |
|-------|----------|----------|--------|
| 1 | Ammonia (NH₃/NH₄⁺) | Fish waste | Toxic to fish |
| 2 | Nitrite (NO₂⁻) | Nitrosomonas | Very toxic |
| 3 | Nitrate (NO₃⁻) | Nitrobacter | Safe, plant food |

**Cycling a New System:**

```
SYSTEM CYCLING (4-6 weeks)

Week 1-2: Adding Ammonia
         │
         ▼
Week 2-3: Nitrite Spike
         │
         ▼
Week 3-4: Nitrate Appears
         │
         ▼
Week 4-6: System Balanced
         │
         ▼
    READY FOR FULL STOCKING!

Daily testing essential during cycling
```

#### Aquaponic System Types

**Media Bed (Flood & Drain):**
```
┌──────────────────────────────┐
│     Media Bed (gravel)       │
│     ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓        │ ← Plants grow here
│     [Bacteria on media]      │ ← Built-in biofilter
└────────────┬─────────────────┘
             │
┌────────────▼─────────────────┐
│        Fish Tank             │
│        🐟 🐟 🐟              │
└──────────────────────────────┘

Best for: Beginners, small scale
```

**NFT with Biofilter:**
```
┌──────────────────────────────┐
│    NFT Channels              │
│    ════════════════          │
└────────────┬─────────────────┘
             │
┌────────────▼─────────────────┐
│    Separate Biofilter        │
│    (Media or moving bed)     │
└────────────┬─────────────────┘
             │
┌────────────▼─────────────────┐
│        Fish Tank             │
└──────────────────────────────┘

Best for: Leafy greens, commercial
```

**Deep Water Culture (Raft):**
```
┌──────────────────────────────┐
│    Floating Rafts            │
│    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓         │
│    ~~~~~~~~~~~~~~~~~~~       │ ← 8-12" deep
└────────────┬─────────────────┘
             │
┌────────────▼─────────────────┐
│    Biofilter                 │
└────────────┬─────────────────┘
             │
┌────────────▼─────────────────┐
│        Fish Tank             │
└──────────────────────────────┘

Best for: Commercial scale
```

#### Balancing the System

**The Ratios:**

```
AQUAPONIC BALANCE

Fish Feed (input)
      │
      ▼
┌─────────────────────────────┐
│  FISH BIOMASS : PLANT AREA  │
│                             │
│  General Rule:              │
│  1 lb fish : 1-2 sq ft      │
│  of growing area            │
│                             │
│  Feed Rate:                 │
│  1-3% of fish biomass/day   │
└─────────────────────────────┘
```

**Example System:**
- 100 gallons water
- 25-50 lbs of fish (mature)
- 25-50 sq ft growing area
- 0.25-1.5 lbs feed per day

### 7.5 System Comparison

#### Comprehensive Comparison

| Factor | Hydroponics | Aquaculture | Aquaponics |
|--------|-------------|-------------|------------|
| **Products** | Plants only | Fish only | Plants + Fish |
| **Nutrient Source** | Purchased | Fish feed | Fish feed → fish waste |
| **Water Use** | Low | Medium-High | Very Low |
| **Complexity** | Medium | Medium | High |
| **Startup Time** | Immediate | Weeks | 4-6 weeks (cycling) |
| **Ongoing Cost** | Nutrients | Feed, water changes | Feed only |
| **pH Management** | Easy (5.5-6.5) | Moderate (7.0-8.0) | Challenging (6.8-7.2) |
| **Organic Certified** | Difficult | Possible | Possible |
| **Scalability** | Very flexible | Flexible | More rigid ratios |
| **Best For** | Maximize plant growth | Protein production | Dual production |

#### When to Choose Each System

**Choose HYDROPONICS when:**
- Maximum plant production is goal
- Only interested in vegetables/herbs
- Want fastest harvest cycles
- Need ultimate control over nutrition
- Operating in very controlled environment

**Choose AQUACULTURE when:**
- Protein production is priority
- Fish market is strong
- Have water treatment capability
- Comfortable with animal husbandry
- Can manage waste stream

**Choose AQUAPONICS when:**
- Want both fish and plants
- Seek closed-loop system
- Value sustainability messaging
- Have time for system maturation
- Willing to learn complex system
- Want educational component

### 7.7 Integration and Hybrid Systems

#### Combining Systems

**IAVS (Integrated Aqua-Vegeculture System):**
- Aquaculture waste used for hydroponics
- Separate but connected
- Easier management than true aquaponics

**Aquaponics with Supplementation:**
- Base aquaponic system
- Supplement nutrients as needed
- Optimize both fish and plants

**Multi-System Approach:**
- Run separate hydro + aqua
- Share infrastructure
- Flexibility in management

## Vocabulary

| Term | Definition |
|------|------------|
| **Hydroponics** | Growing plants without soil using nutrient solution |
| **Aquaculture** | Farming aquatic organisms in controlled environments |
| **Aquaponics** | Integration of aquaculture and hydroponics |
| **Nitrogen Cycle** | Bacterial conversion of ammonia to nitrate |
| **Nitrification** | Process of converting ammonia to nitrite to nitrate |
| **Biofilter** | Media where beneficial bacteria colonize |
| **RAS** | Recirculating Aquaculture System |
| **Cycling** | Process of establishing bacterial colonies in new system |
| **NFT** | Nutrient Film Technique |
| **DWC** | Deep Water Culture |
| **Stocking Density** | Amount of fish per volume of water |
| **Feed Conversion Ratio** | Feed input vs. fish growth output |
