## QUICK DEFINITIONS

### Must-Know Terms

| Term | One-Line Definition |
|------|---------------------|
| **Food System** | All processes from farm to fork to waste |
| **Food Miles** | Distance food travels to consumer |
| **Carbon Footprint** | GHG emissions from a product/activity |
| **Sustainability** | Meeting present needs without compromising future |
| **Three Pillars** | Environmental + Economic + Social |
| **Food Desert** | Area lacking affordable, nutritious food |
| **Food Security** | Reliable access to sufficient, safe food |

| **Dead Zone** | Water area too low in oxygen for life |
| **Monoculture** | Single crop over large area |
| **CSA** | Community Supported Agriculture |
| **CEA** | Controlled Environment Agriculture |
| **Aquaponics** | Fish + hydroponics integrated system |
| **Hydroponics** | Growing plants without soil |
| **Aquaculture** | Farming aquatic organisms |
| **Biofilter** | Bacterial conversion system (NH3→NO3) |

## THE NITROGEN CYCLE (AQUAPONICS)

```
┌─────────────────────────────────────────────────────────┐
│                  THE NITROGEN CYCLE                     │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   FISH produce AMMONIA (NH3) ──► TOXIC to fish!        │
│              │                                          │
│              ▼                                          │
│   NITROSOMONAS bacteria convert to                     │
│   NITRITE (NO2) ──► Still TOXIC!                       │
│              │                                          │
│              ▼                                          │
│   NITROBACTER bacteria convert to                      │
│   NITRATE (NO3) ──► SAFE, plant food!                  │
│              │                                          │
│              ▼                                          │
│   PLANTS absorb NITRATE for growth                     │
│              │                                          │
│              ▼                                          │
│   CLEAN WATER returns to fish ──► Cycle repeats        │
│                                                         │
└─────────────────────────────────────────────────────────┘

KEY POINTS:
• Ammonia > 0.5 ppm = DANGER
• Nitrite > 1 ppm = DANGER
• Nitrate safe up to ~150 ppm
• Target pH: 6.8-7.2
```

## SYSTEM COMPARISONS

### Growing Methods Comparison

| System | Soil? | Water Use | Complexity | Best For |
|--------|-------|-----------|------------|----------|
| Traditional | Yes | High | Low | Large scale outdoor |
| Hydroponics | No | Medium | Medium | Leafy greens |
| Aquaponics | No | Very Low | High | Integrated production |
| Aeroponics | No | Very Low | Very High | Research, specialty |

### Aquaponics System Types

| Type | Description | Pros | Cons |
|------|-------------|------|------|
| **Media Bed** | Plants in gravel/clay | Simple, biofilter built-in | Heavy |
| **NFT** | Thin film channels | Lightweight, efficient | Needs separate biofilter |
| **DWC/Raft** | Floating on deep water | High volume, easy harvest | Space, disease risk |

## CONVENTIONAL VS. SUSTAINABLE

| Factor | Conventional | Sustainable |
|--------|--------------|-------------|
| **Inputs** | High external | Low external, cycling |
| **Diversity** | Monoculture | Polyculture |
| **Soil** | Depletes | Builds |
| **Water** | Wastes, pollutes | Conserves, recycles |
| **Energy** | Fossil fuel dependent | Efficient, renewable |
| **Chemicals** | Heavy use | Minimal, organic |
| **Scale** | Large, centralized | Various, distributed |
| **Resilience** | Low | High |
| **Timeline** | Short-term profit | Long-term viability |

## CEA PARAMETERS

### What's Controlled in Controlled Environment Agriculture

|-----------|---------------|---------------|

| **Nutrients** | Plant nutrition | System-specific |
| **pH** | Nutrient availability | 5.5-6.5 (hydro), 6.8-7.2 (aqua) |
| **Airflow** | Stem strength, disease | Continuous |

## STUDY TIPS FOR SUCCESS

### For Module Quizzes:
1. Review lesson summary/key takeaways
2. Know definitions of all vocabulary terms
3. Focus on statistics and numbers
4. Understand cause and effect relationships

### For Final Exam:
1. Use this cheat sheet to review key facts
2. Practice explaining concepts in your own words
3. Connect ideas across modules
4. Focus on "why" not just "what"

### Memory Tricks:
- **Food system components:** "PPDCW" = Production, Processing, Distribution, Consumption, Waste
- **Three pillars:** "EES" = Environmental, Economic, Social
- **Nitrogen cycle:** "Fish → Ammonia → Nitrite → Nitrate → Plants → Fish"
- **Water use:** "70-33-33" = 70% water for ag, 33% soil degraded, 33% food wasted
