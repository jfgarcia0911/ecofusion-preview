### 7.2 System Cycling (Nitrogen Cycle Establishment)

#### Understanding the Cycling Process

```
SYSTEM CYCLING STAGES

WEEK 1-2: AMMONIA SPIKE
   NH₃/NH₄⁺ rises
        ↓
   Fish waste accumulates
        ↓
   Nitrosomonas bacteria growing

WEEK 2-3: NITRITE SPIKE
   NO₂⁻ rises as NH₃ converts
        ↓
   Nitrobacter bacteria growing
        ↓
   Most critical period

WEEK 3-4: NITRATE RISE
   NO₃⁻ accumulates
        ↓
   System stabilizing
        ↓
   Cycle approaching completion

WEEK 4-6: STABLE
   Bacteria colony established
        ↓
   NH₃ and NO₂⁻ near zero
        ↓
   NO₃⁻ present, plants removing
```

#### Cycling Methods

**Method 1: Fishless Cycling (Recommended)**

```
FISHLESS CYCLING PROCEDURE

WEEK 1:
□ Set up system, fill with water
□ Dechlorinate if needed
□ Add ammonia source:
  • Pure ammonia (4-5 ppm), OR
  • Fish food (handful daily)
□ Test daily: NH₃, NO₂⁻, NO₃⁻
□ Keep temperature 75-80°F

WEEK 2-3:
□ Continue ammonia additions
□ Watch for nitrite spike
□ DO NOT water change yet
□ Be patient

WEEK 3-4:
□ Ammonia converts quickly (<24 hrs)
□ Nitrite dropping
□ Nitrate rising
□ Test daily

WEEK 4-6:
□ Add ammonia, check next day
□ If NH₃ and NO₂⁻ both <0.5 ppm:
   ✓ SYSTEM CYCLED
□ Perform water change
□ Add fish gradually

ADVANTAGES:
• No fish stress/death
• Can use higher ammonia
• Faster cycling
• Recommended for beginners
```

**Method 2: Fish-In Cycling**

```
FISH-IN CYCLING (Use with caution)

START:
□ Add VERY FEW hardy fish
  (1/10 of final stocking)
□ Use extremely hardy species:
  • Goldfish
  • Guppies
  • Zebra danios (not for aquaponics)

DAILY:
□ Test NH₃ and NO₂⁻
□ If >1 ppm: Water change 25-50%
□ Feed sparingly
□ Monitor fish closely

THROUGHOUT:
□ Watch for stress signs
□ Be prepared for losses
□ Takes 4-8 weeks

DISADVANTAGES:
• Stressful/harmful to fish
• Slower process
• Requires intensive monitoring
• Not recommended
```

**Method 3: Seeding/Jump-Starting**

```
ACCELERATED CYCLING

ADD BACTERIA FROM:
• Established filter media
• Gravel from cycled system
• Commercial bacteria products

PROCESS:
1. Set up system
2. Add bacterial seed
3. Add small ammonia source
4. Test daily
5. Cycle in 1-3 weeks

COMMERCIAL PRODUCTS:
• Bottled nitrifying bacteria
• Results vary by product
• Some work well, some don't
• Read reviews, follow directions
```

### 7.3 Water Changes

#### Why and When to Change Water

```
REASONS FOR WATER CHANGES

DILUTE                    REPLENISH                RESET
     ↓                         ↓                       ↓
┌──────────────┐         ┌──────────────┐       ┌──────────────┐
│• Nitrate     │         │• Minerals    │       │• Start fresh │
│• Phosphate   │         │• Trace       │       │• After        │
│• Dissolved   │         │  elements    │       │  treatment   │
│  organics    │         │• Buffer      │       │• Major       │
│• Excess salts│         │  capacity    │       │  problem     │
└──────────────┘         └──────────────┘       └──────────────┘
```

**Water Change Schedule:**

| System Type | Frequency | Amount | Reason |
|-------------|-----------|--------|--------|
| **Aquaponics** | Monthly | 10-25% | Dilute nitrate if too high |
| **Hydroponics (recirculating)** | Bi-weekly | Complete exchange | Prevent imbalances |
| **Fish-only (moderate density)** | Weekly | 25-30% | Waste removal |
| **High-density systems** | 2-3x/week | 20-30% | Ammonia/nitrite control |

#### Proper Water Change Procedure

```
STEP-BY-STEP WATER CHANGE

BEFORE:
□ Test current water quality
□ Record parameters
□ Prepare new water:
  • Same temperature (±3°F)
  • Dechlorinated
  • pH matched if possible

DURING:
1. Turn off pumps/heaters
2. Remove water (siphon from bottom)
3. Clean debris from bottom (if appropriate)
4. Add new water slowly
5. Match temperature
6. Restart equipment

AFTER:
□ Test water quality again
□ Observe fish/plants
□ Record water change in log
□ Monitor for 24-48 hours

CAUTION:
• Never change >50% at once
• Match temperature closely
• Gradual is better than fast
• Watch for fish stress
```

### 7.4 Optimizing Water Quality

#### For Aquaponics Systems

```
AQUAPONICS OPTIMIZATION

CHALLENGE: Balance fish and plant needs

TARGET RANGES:
┌──────────────────────────────────────┐
│ pH:         6.8-7.2 (compromise)     │
│ NH₃:        <0.5 mg/L (ideally <0.25)│
│ NO₂⁻:       <0.5 mg/L (ideally 0)    │
│ NO₃⁻:       5-150 mg/L               │
│ DO:         >5 mg/L                  │
│ Temp:       75-82°F (tilapia)        │
│ Alkalinity: 80-150 mg/L              │
│ Hardness:   100-150 mg/L             │
└──────────────────────────────────────┘

OPTIMIZATION STRATEGIES:
1. Maintain 1:1 or 2:1 plant:fish ratio
2. Supplement calcium, iron as needed
3. Keep pH in sweet spot (6.8-7.2)
4. Strong biological filtration
5. Adequate aeration
6. Regular monitoring
```

#### For Hydroponic Systems

```
HYDROPONICS OPTIMIZATION

ADVANTAGE: Control all variables

TARGET RANGES (General vegetables):
┌──────────────────────────────────────┐
│ pH:         5.8-6.2                  │
│ EC:         1.5-2.5 mS/cm            │
│ DO:         >6 mg/L                  │
│ Temp:       65-75°F                  │
│ Individual nutrients: Recipe-dependent│
└──────────────────────────────────────┘

OPTIMIZATION STRATEGIES:
1. Use complete nutrient formula
2. Monitor and adjust EC/pH daily
3. Change solution bi-weekly
4. Keep reservoir cool and dark
5. Ensure adequate aeration
6. Match nutrients to crop stage
```

### 7.6 Emergency Response

#### Water Quality Crisis Protocol

```
EMERGENCY RESPONSE CHECKLIST

IMMEDIATE (First 15 minutes):
□ Assess severity (How bad? How fast?)
□ Fish behavior (Gasping? Dying?)
□ Quick test: DO, NH₃, pH minimum
□ Increase aeration IMMEDIATELY
□ STOP FEEDING

SHORT-TERM (1-4 hours):
□ Identify root cause
□ Emergency water change (25-50%)
□ Match temperature
□ Dechlorinate new water
□ Add aeration to new water
□ Retest parameters

MID-TERM (4-24 hours):
□ Monitor fish/plants every 2 hours
□ Additional water changes if needed
□ Begin treatment if disease-related
□ Check all equipment function
□ Document everything

LONG-TERM (1-7 days):
□ Identify what went wrong
□ Prevent recurrence
□ Repair/replace equipment
□ Gradual return to normal
□ Resume feeding cautiously
```

#### Common Emergencies

```
EMERGENCY 1: Ammonia Spike

SIGNS: Fish gasping, lethargy, red gills
TEST SHOWS: NH₃ >2 ppm

ACTIONS:
1. Immediate 50% water change
2. Stop feeding
3. Add extra aeration
4. Add ammonia binder (temporary)
5. Check biofilter function
6. Reduce stocking if overstocked

EMERGENCY 2: DO Crash

SIGNS: All fish at surface, gasping
TEST SHOWS: DO <3 mg/L

ACTIONS:
1. Maximize aeration immediately
2. Add emergency aerator
3. Reduce temperature if possible
4. Stop feeding
5. Identify cause:
   • Equipment failure?
   • Overstocked?
   • Algae die-off?
   • Heat wave?

EMERGENCY 3: pH Crash

SIGNS: Erratic swimming, stress
TEST SHOWS: pH <6.0 or >8.5

ACTIONS:
1. Small water changes (25%) frequently
2. Adjust pH SLOWLY (0.2 units/day max)
3. DO NOT overcorrect
4. Add buffer if low alkalinity
5. Find and fix root cause
```

### 7.7 Seasonal Management

```
SEASONAL CONSIDERATIONS

SUMMER (Heat challenges)
┌────────────────────────────────────┐
│ ISSUES:                            │
│ • High temperature                 │
│ • Low DO                           │
│ • Faster bacterial growth          │
│ • Higher fish metabolism           │
│                                    │
│ MANAGEMENT:                        │
│ □ Increase aeration               │
│ □ Shade system                    │
│ □ Consider chiller                │

│ □ Monitor DO closely (early AM)   │
└────────────────────────────────────┘

WINTER (Cold challenges)
┌────────────────────────────────────┐
│ ISSUES:                            │
│ • Low temperature                  │
│ • Slower bacterial activity        │
│ • Reduced fish metabolism          │
│ • Potential freezing               │
│                                    │
│ MANAGEMENT:                        │
│ □ Heater if needed                │
│ □ Insulate pipes                  │
│ □ Reduce feeding                  │
│ □ Monitor ammonia (slower cycling)│
```

### 7.8 Best Management Practices (BMPs)

```
WATER QUALITY BMP CHECKLIST

DAILY:
□ Visual observation of fish and plants
□ Check equipment operation
□ Test critical parameters (DO, pH, temp)
□ Feed appropriate amount
□ Remove any dead fish immediately

WEEKLY:
□ Test full panel (NH₃, NO₂⁻, NO₃⁻)
□ Record all data
□ Clean pre-filters
□ Check for leaks
□ Observe trends

MONTHLY:
□ Water change (if needed)
□ Test alkalinity and hardness
□ Clean filters thoroughly
□ Calibrate meters
□ Review and analyze data

QUARTERLY:
□ Deep clean system components
□ Replace filter media
□ Service pumps
□ Review management plan
□ Adjust protocols as needed

ANNUALLY:
□ Complete system audit
□ Source water baseline test
□ Replace aging equipment
□ Update SOPs
□ Plan improvements
```

### 7.9 System-Specific Management

```
SMALL SYSTEM (<500 gal)
• Daily observation
• Weekly testing
• Simple record keeping
• Less automation needed
• Hands-on management

MEDIUM SYSTEM (500-5,000 gal)
• Daily testing
• Detailed records
• Some automation helpful
• Regular maintenance schedule
• More investment in equipment

LARGE SYSTEM (>5,000 gal)
• Multiple daily checks
• Automated monitoring
• Backup systems critical
• Staff training essential
• Professional management
```
