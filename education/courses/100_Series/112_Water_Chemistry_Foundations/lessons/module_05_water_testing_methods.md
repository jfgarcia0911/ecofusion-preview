### 5.2 Testing Equipment Options

#### Test Strips

```
TEST STRIP CHARACTERISTICS

ADVANTAGES                  DISADVANTAGES
• Fastest (30-60 seconds)  • Least accurate (±0.5-1.0)
• Cheapest per test        • Subjective color matching
• No equipment needed      • Limited shelf life
• Multiple parameters      • Temperature sensitive
• Portable                 • Moisture degrades strips

BEST FOR:
• Quick screening
• Field testing
• Emergency checks
• Backup testing
```

#### Liquid Test Kits (Colorimetric)

```
LIQUID TEST KIT PROCESS

1. Collect water sample (5-10 mL)
   ↓
2. Add reagent drops (count carefully)
   ↓
3. Mix thoroughly
   ↓
4. Wait for color development (1-5 min)
   ↓
5. Compare to color chart
   ↓
6. Record result

ADVANTAGES                  DISADVANTAGES
• Moderate accuracy        • Color matching needed
  (±0.1-0.5)              • Reagent shelf life
• Affordable               • Multiple steps
• No calibration           • Water color interference
• Widely available         • Some lighting dependent

BEST FOR:
• Regular monitoring
• Most parameters
• Budget operations
• Hobby/small commercial
```

#### Electronic Meters

```
ELECTRONIC METER TYPES

pH METER                    DO METER
• Accuracy: ±0.01          • Accuracy: ±0.1 mg/L
• Cost: $50-$500+          • Cost: $200-$2,000+
• Calibrate: Weekly        • Calibrate: Weekly-Monthly
• Probe life: 1-2 years    • Membrane: 6-12 months

EC/TDS METER               MULTI-PARAMETER
• Accuracy: ±2%            • Measures: pH, EC, DO, temp
• Cost: $25-$300           • Cost: $500-$5,000+
• Calibrate: Monthly       • Professional grade
• Very durable             • Lab/commercial use

ADVANTAGES                  DISADVANTAGES
• Most accurate            • Expensive initial cost
• Easy to read             • Requires calibration
• Digital display          • Probe maintenance
• Logging capability       • Battery/power needed

BEST FOR:
• Commercial operations
• Precise work
• Frequent testing
• Professional standards
```

#### Photometers and Lab Equipment

```
ADVANCED TESTING

PHOTOMETER (Colorimeter)
```

### 5.3 Performing Accurate Tests

#### Sample Collection Best Practices

```
PROPER SAMPLING TECHNIQUE

BEFORE COLLECTION:
□ Clean container (no soap residue!)
□ Rinse 3x with sample water
□ Identify sampling location
□ Record time, location, conditions

DURING COLLECTION:
□ Collect from representative location
  • Mid-depth (not surface scum)
  • Away from inlet/outlet
  • Well-mixed area
□ Avoid contamination
  • Don't touch inside of container
  • Don't stir up sediment
  • Minimize air contact (DO tests)

TESTING TIMING:
□ Test immediately if possible
□ If delayed:
  • Refrigerate (except DO)
  • Test within 24 hours
  • Note storage time
```

#### Step-by-Step Testing Procedures

**Example: Ammonia Test (Liquid Kit)**

```
AMMONIA TESTING PROCEDURE

EQUIPMENT:
• Test tube
• Ammonia reagent #1
• Ammonia reagent #2
• Color comparison chart

STEPS:
1. Rinse test tube 3x with sample water

2. Fill to 5 mL line with sample water

3. Add 8 drops Reagent #1
   • Hold bottle vertically
   • Count drops carefully

4. Cap and shake 5 seconds

5. Add 8 drops Reagent #2
   • Hold bottle vertically
   • Count drops carefully

6. Cap and shake 5 seconds

7. Wait 5 minutes for color development
   • Set timer
   • Keep at room temperature

8. Compare to color chart
   • Natural light or white background
   • View from side
   • Match closest color

9. Record result immediately
   • Include units (mg/L or ppm)
   • Note any observations

COMMON ERRORS:
❌ Wrong drop count
❌ Not shaking enough
❌ Not waiting full time
❌ Poor lighting for comparison
❌ Using old/expired reagents
```

### 5.4 Quality Control and Accuracy

#### Ensuring Accurate Results

```
QUALITY ASSURANCE STEPS

1. CALIBRATION (Electronic meters)
   • Use fresh calibration solutions
   • Multi-point calibration
   • Regular schedule

2. BLANKS (Chemical tests)
   • Test distilled water
   • Should read 0 or very low
   • Detects contamination

3. STANDARDS (Known concentration)
   • Test solution with known value
   • Should match expected result
   • Verifies accuracy

4. DUPLICATES (Replicate samples)
   • Test same sample twice
   • Results should be close
   • Checks precision

5. CONTROLS (Regular checks)
   • Same sample tested regularly
   • Track instrument drift
   • Maintain records
```

**Test Kit Maintenance:**

| Item | Maintenance | Frequency |
|------|-------------|-----------|
| **Reagents** | Check expiration, store cool/dark | Before each use |
| **Test tubes** | Rinse with distilled water, air dry | After each use |
| **pH meter** | Calibrate, clean electrode, store wet | Weekly |
| **DO meter** | Replace membrane, refill electrolyte | Monthly-Annually |
| **EC meter** | Calibrate, clean probe | Monthly |
| **Color charts** | Keep clean, avoid fading | Protect from sunlight |

### 5.7 Interpreting Test Results

#### Understanding Trends

```
TREND ANALYSIS EXAMPLE

pH OVER 30 DAYS

8.0 │         * Rise detected
7.5 │      *  ← Week 3
7.2 │─ ─ * ─ ─ ─ Target range
7.0 │  *
6.8 │*
6.5 │
    └─────────────────────────
    W1  W2  W3  W4

INTERPRETATION:
• Started in range (Week 1)
• Steady increase (Weeks 2-4)
• Above target by Week 4

POSSIBLE CAUSES:
• Alkalinity too high
• Low feeding rate (less acid)
• Algae bloom (photosynthesis)
• Water source change

ACTION:
• Test alkalinity
• Consider acid addition
• Check for algae
• Monitor closely
```

#### Correlation Analysis

```
CONNECTING PARAMETERS

EXAMPLE: Fish stress event

Date: June 15

High temperature (88°F)
        ↓
Low DO (4.2 mg/L) ←─── CONNECTED
        ↓
High ammonia (1.5 ppm) ←─ More toxic at high temp
        ↓
Fish gasping, not eating

ROOT CAUSE: Temperature spike
CASCADING EFFECTS: DO ↓, NH₃ toxicity ↑
SOLUTION: Cool water, increase aeration
```

### 5.8 Troubleshooting Test Problems

```
COMMON TESTING ISSUES

PROBLEM: Inconsistent results

CAUSES & SOLUTIONS:
❌ Poor sampling → Take representative samples
❌ Old reagents → Check expiration, replace
❌ Uncalibrated meter → Calibrate regularly
❌ Contaminated tubes → Clean thoroughly
❌ User error → Follow procedure exactly

PROBLEM: Unexpected readings

CAUSES & SOLUTIONS:
❌ Sample degraded → Test immediately
❌ Interfering substances → Use specific methods
❌ Equipment malfunction → Verify with duplicate
❌ Math error → Double-check calculations
❌ Wrong units → Confirm mg/L vs ppm vs %

PROBLEM: Can't match color chart

CAUSES & SOLUTIONS:
❌ Poor lighting → Use natural light or white LED
❌ Faded chart → Replace test kit
❌ Water color → Dilute sample or use meter
❌ Reading at wrong time → Follow timing exactly
```

### 5.9 Cost-Effective Testing Strategies

#### Balancing Accuracy and Budget

```
TESTING STRATEGY BY SYSTEM SIZE

HOBBY/SMALL (<500 gal)
• Test strips for quick checks
• Liquid kits for key parameters
• 1 good pH meter
• Cost: $100-300/year

SMALL COMMERCIAL (500-5,000 gal)
• Liquid kits primary method
• pH and EC meters
• Consider DO meter
• Cost: $300-1,000/year

LARGE COMMERCIAL (>5,000 gal)
• Multi-parameter meters
• Backup test kits
• Lab testing periodically
• Automated monitoring (optional)
• Cost: $1,000-5,000+/year

SHARED RESOURCES:
• Group purchases (bulk discount)
• Shared lab equipment
• Cooperative testing programs
• Extension laboratory services
```
