### 6.2 Chlorine and Chloramine Removal

#### Understanding Disinfectants

```
CHLORINE vs CHLORAMINE

CHLORINE (Cl₂)              CHLORAMINE (NH₂Cl)
      ↓                            ↓
┌──────────────┐            ┌──────────────┐
│• Traditional │            │• Newer       │
│  disinfectant│            │  alternative │
│• Volatile    │            │• More stable │
│• Dissipates  │            │• Longer      │
│  on own      │            │  lasting     │
│• Easy to     │            │• Harder to   │
│  remove      │            │  remove      │
└──────────────┘            └──────────────┘
       ↓                            ↓
TOXIC TO FISH               TOXIC TO FISH
AND BENEFICIAL BACTERIA     AND BENEFICIAL BACTERIA

Both MUST be removed for aquaponics/hydroponics
```

**Chlorine Testing:**
- Use chlorine test kit or test strips
- Total chlorine should be 0 ppm for fish
- Most municipalities: 0.5-2.0 ppm chlorine

#### Chlorine Removal Methods

```
METHOD 1: OFF-GASSING (Chlorine only)
┌────────────────────────────────────┐
│  Let water sit 24-48 hours         │
│  ↓                                 │
│  Chlorine evaporates naturally     │
│  ↓                                 │
│  Aeration speeds process           │
│  (use air stone)                   │
│                                    │
│  ADVANTAGES:                       │
│  • Free                            │
│  • No chemicals                    │
│                                    │
│  DISADVANTAGES:                    │
│  • Slow                            │
│  • Requires storage                │
│  • Doesn't work on chloramine      │
└────────────────────────────────────┘

METHOD 2: ASCORBIC ACID (Vitamin C)
┌────────────────────────────────────┐
│  Add Vitamin C powder              │
│  ↓                                 │
│  Neutralizes chlorine/chloramine   │
│  ↓                                 │
│  Instant removal                   │
│                                    │
│  DOSAGE:                           │
│  • 1 gram per 100 gallons          │
│  • Cheap, safe, effective          │
│                                    │
│  ADVANTAGES:                       │
│  • Works on both Cl₂ and NH₂Cl    │
│  • Fast (instant)                  │
│  • Inexpensive                     │
│  • Safe for fish                   │
│                                    │
│  DISADVANTAGES:                    │
│  • Must measure dose               │
│  • Adds small amount organic       │
└────────────────────────────────────┘

METHOD 3: SODIUM THIOSULFATE
┌────────────────────────────────────┐
│  Commercial dechlorinator          │
│  ↓                                 │
│  Follow product instructions       │
│                                    │
│  DOSAGE:                           │
│  • Varies by product               │
│  • Usually 1 drop per gallon       │
│                                    │
│  ADVANTAGES:                       │
│  • Works on both                   │
│  • Precise dosing                  │
│  • Pet store availability          │
│                                    │
│  DISADVANTAGES:                    │
│  • More expensive                  │
│  • Some contain additives          │
└────────────────────────────────────┘

METHOD 4: ACTIVATED CARBON FILTER
┌────────────────────────────────────┐
│  Water flows through carbon        │
│  ↓                                 │
│  Chlorine adsorbed by carbon       │
│                                    │
│  ADVANTAGES:                       │
│  • Automatic                       │
│  • No dosing needed                │
│  • Also removes organics           │
│                                    │
│  DISADVANTAGES:                    │
│  • Initial cost                    │
│  • Replace carbon periodically     │
│  • Slower for chloramine           │
└────────────────────────────────────┘
```

#### Chloramine Removal (Special Considerations)

```
CHLORAMINE IS MORE DIFFICULT

Standard carbon filter: May not be sufficient
Catalytic carbon: More effective
UV light: Breaks down chloramine

BEST METHODS FOR CHLORAMINE:
1. Ascorbic acid (most reliable)
2. Catalytic carbon filter
3. Campden tablets (potassium metabisulfite)

VERIFY REMOVAL:
• Test with chlorine/chloramine test kit
• Must read 0 ppm before adding fish
• Chloramine releases ammonia when broken down
  (test and monitor ammonia levels)
```

### 6.3 Filtration Methods

#### Mechanical Filtration

```
SEDIMENT/PARTICLE REMOVAL

SEDIMENT FILTERS
      ↓
┌─────────────────────────────────┐
│ 5 micron: Removes fine sediment │
│ 1 micron: Removes very fine     │
│ 0.5 micron: Near sterile        │
└─────────────────────────────────┘

USE CASES:
• Well water with sediment
• Surface water
• Prevent clogging of pumps
• Pre-filter for other treatment

MAINTENANCE:
• Replace when pressure drops
• Every 3-6 months typical
• More often with dirty water
```

#### Chemical Filtration

```
ACTIVATED CARBON FILTRATION

HOW IT WORKS:
Water flows through porous carbon
    ↓
Contaminants adsorb to carbon surface
    ↓
Clean water flows out

REMOVES:
✓ Chlorine
✓ Chloramine (catalytic carbon)
✓ Organic chemicals
✓ Bad tastes/odors
✓ Some heavy metals

DOES NOT REMOVE:
✗ Dissolved minerals
✗ Nitrate
✗ Phosphate
✗ Hardness
✗ Most salts

MAINTENANCE:
• Replace every 6-12 months
• Flow rate decreases when saturated
• Test effluent to verify performance
```

#### Reverse Osmosis (RO)

```
REVERSE OSMOSIS SYSTEM

TAP WATER → [Sediment] → [Carbon] → [RO Membrane] → PURE WATER
                                          ↓
                                      WASTE WATER
                                      (3:1 ratio)

REMOVES: 95-99% of everything
• Dissolved solids
• Minerals
• Salts
• Heavy metals
• Bacteria
• Viruses

ADVANTAGES:
• Purest water possible
• Consistent quality
• Removes all issues

DISADVANTAGES:
• Expensive ($150-$1,000+)
• Wastes 3 gallons per 1 gallon produced
• Removes beneficial minerals too
• Must remineralize for use

WHEN TO USE RO:
• Extremely poor source water
• Very hard water (>300 mg/L)
• Heavy metals present
• Want complete control
• Willing to remineralize
```

### 6.4 UV Sterilization

```
ULTRAVIOLET (UV) DISINFECTION

HOW IT WORKS:
Water flows past UV lamp
    ↓
UV-C light (254 nm) damages DNA
    ↓
Kills/inactivates pathogens
    ↓
Sterilized water flows out

EFFECTIVENESS:
✓ Bacteria: 99.99% kill rate
✓ Viruses: 99.99% kill rate
✓ Algae: Prevents reproduction
✓ Some parasites: Effective

DOES NOT AFFECT:
• Water chemistry
• Dissolved substances
• Taste or odor
• Beneficial bacteria (if not exposed)

SYSTEM COMPONENTS:
┌─────────────────────────────┐
│ UV Lamp (254 nm)            │
│ Quartz Sleeve               │
│ Flow Chamber                │
│ Power Supply (Ballast)      │
└─────────────────────────────┘

SIZING:
• Flow rate vs Contact time
• Higher flow = larger unit needed
• 30,000 μWs/cm² for sterilization

MAINTENANCE:
□ Replace bulb annually
□ Clean quartz sleeve monthly
□ Verify lamp is on (indicator light)

APPLICATIONS:
• Protect against pathogens
• Algae control in reservoirs
• Post-filter sterilization
• Recirculating systems
```

### 6.5 Iron and Manganese Removal

```
IRON/MANGANESE IN WELL WATER

PROBLEM:
• Stains equipment, grows media
• Can harm fish/plants at high levels
• Feeds iron bacteria

FORMS:
Ferrous (Fe²⁺) - Dissolved, clear water
Ferric (Fe³⁺) - Oxidized, rust-colored

REMOVAL METHODS:

1. AERATION + FILTRATION
   Expose to air → Iron oxidizes → Filter out

2. GREENSAND FILTER
   Manganese-coated sand oxidizes & filters iron

3. CHEMICAL OXIDATION
   Add oxidizer (H₂O₂, chlorine) → Filter

4. WATER SOFTENER
   Can remove some iron (not best method)

TARGET LEVELS:
• Iron: <0.3 mg/L
• Manganese: <0.05 mg/L
```

### 6.6 Water Softening

```
WATER SOFTENER (Ion Exchange)

Ca²⁺ and Mg²⁺ (hard water)
        ↓
  [Resin Bed with Na⁺]
        ↓
Na⁺ released, Ca²⁺/Mg²⁺ captured
        ↓
Soft water (high sodium)

RESULT:
✓ Removes hardness
✓ Prevents scaling

⚠ WARNING FOR AQUAPONICS/HYDROPONICS:
✗ Adds sodium (Na⁺)
✗ Removes calcium & magnesium (needed nutrients!)
✗ NOT RECOMMENDED for growing systems

ALTERNATIVE:
Use reverse osmosis instead, then remineralize
```

### 6.7 Conditioning Water for Use

#### Starting from Different Sources

```
SCENARIO 1: Municipal Tap Water
     (Hardness 150 mg/L, pH 7.5, Chlorinated)

TREATMENT PLAN:
□ Remove chlorine (vitamin C or carbon filter)
□ Test and adjust pH if needed
□ Use as-is or supplement nutrients
   ✓ Ready to use

SCENARIO 2: Very Hard Well Water
     (Hardness 350 mg/L, pH 8.2, Iron 2 mg/L)

TREATMENT PLAN:
□ Option A: RO system → Remineralize
□ Option B: Blend with RO water
□ Remove iron (oxidation + filter)
□ Lower pH gradually
   ✓ Requires treatment

SCENARIO 3: Rainwater
     (Hardness <10 mg/L, pH 5.5-6.5, Pure)

TREATMENT PLAN:
□ Filter debris
□ Add calcium and magnesium
□ Raise alkalinity for buffering
□ Adjust pH if needed
   ✓ Needs mineralization

SCENARIO 4: Surface Water (Pond/Stream)
     (Variable, Contains organisms)

TREATMENT PLAN:
□ Sediment filtration
□ UV sterilization
□ Test for contaminants
□ Adjust chemistry as needed
   ⚠ Requires most treatment
```

### 6.8 Treatment System Design

```
EXAMPLE: Complete Treatment System
(For municipal water with chlorine)

INCOMING TAP WATER
        ↓
  [SEDIMENT FILTER]
     5 micron
        ↓
  [CARBON FILTER]
   Chlorine removal
        ↓
     [UV LIGHT]
    Sterilization
        ↓
  [STORAGE TANK]
    De-gassed, treated
        ↓
   TO SYSTEM
```

**Component Selection Guide:**

| Source Issue | Treatment Needed | Equipment |
|--------------|------------------|-----------|
| **Chlorine** | Removal | Carbon filter or Vitamin C |
| **Chloramine** | Removal | Catalytic carbon or chemical |
| **Sediment** | Filtration | 5-50 micron sediment filter |
| **Pathogens** | Disinfection | UV sterilizer |
| **High hardness** | Reduction | RO system or dilution |
| **Iron/Manganese** | Removal | Aeration + filter or greensand |
| **Low minerals** | Addition | Calcium/magnesium supplements |

### 6.9 Cost-Benefit Analysis

```
TREATMENT INVESTMENT

BASIC SYSTEM ($100-300)
• Sediment filter
• Carbon block filter
• Dechlorinator chemical
└─ Suitable for: Good source water, small systems

INTERMEDIATE ($300-1,000)
• Multi-stage filtration
• UV sterilizer
• Basic monitoring
└─ Suitable for: Moderate issues, medium systems

ADVANCED ($1,000-5,000+)
• RO system
• UV sterilizer
• Automated monitoring
• Backup systems
└─ Suitable for: Poor source water, commercial

CONSIDER:
• Replacement filter costs (ongoing)
• Energy costs (UV, RO pump)
• Maintenance time
• Water waste (RO)
• Value of fish/crops protected
```

## Vocabulary

| Term | Definition |
|------|------------|
| **Chlorine (Cl₂)** | Disinfectant added to municipal water; toxic to fish |
| **Chloramine (NH₂Cl)** | Stable disinfectant; chlorine + ammonia compound |
| **Dechlorination** | Process of removing chlorine from water |
| **Activated Carbon** | Porous material that adsorbs contaminants |
| **Reverse Osmosis (RO)** | Membrane filtration removing 95-99% of dissolved solids |
| **UV Sterilization** | Use of ultraviolet light to kill microorganisms |
| **Sediment Filter** | Mechanical filter removing particles by size |
| **Ion Exchange** | Process swapping ions (e.g., water softener) |
