## Two Stages of Photosynthesis

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                         TWO-STAGE PROCESS                                  │
    │                                                                             │
    │    ╔═══════════════════════════════════════════════════════════════════╗   │
    │    ║                                                                   ║   │
    │    ║   STAGE 1: LIGHT REACTIONS                                       ║   │
    │    ║   Location: Thylakoid Membrane                                   ║   │
    │    ║   ────────────────────────────                                   ║   │
    │    ║                                                                   ║   │
    │    ║   ☀️ Light + 💧 Water  ───────►  ⚡ ATP + 🔋 NADPH + 💨 O₂       ║   │
    │    ║                                                                   ║   │
    │    ║   • Chlorophyll absorbs light                                    ║   │
    │    ║   • Water is split (releasing O₂)                                ║   │
    │    ║   • Energy stored in ATP and NADPH                               ║   │
    │    ║                                                                   ║   │
    │    ╚═══════════════════════════════════════════════════════════════════╝   │
    │                                                                             │
    │                          │ ATP and NADPH │                                 │
    │                          ▼               ▼                                 │
    │                                                                             │
    │    ╔═══════════════════════════════════════════════════════════════════╗   │
    │    ║                                                                   ║   │
    │    ║   STAGE 2: CALVIN CYCLE (Dark Reactions)                         ║   │
    │    ║   Location: Stroma                                               ║   │
    │    ║   ──────────────────                                             ║   │
    │    ║                                                                   ║   │
    │    ║   💨 CO₂ + ⚡ ATP + 🔋 NADPH  ───────►  🍬 Glucose (Sugar)        ║   │
    │    ║                                                                   ║   │
    │    ║   • CO₂ is "fixed" by RuBisCO enzyme                             ║   │
    │    ║   • ATP provides energy                                          ║   │
    │    ║   • NADPH provides electrons                                     ║   │
    │    ║   • Sugar molecules are built                                    ║   │
    │    ║                                                                   ║   │
    │    ╚═══════════════════════════════════════════════════════════════════╝   │
    │                                                                             │
```

## C3, C4, and CAM Plants

```
    ╔═══════════════════════════════════════════════════════════════════════════╗
    ║                                                                           ║
    ║                THREE PHOTOSYNTHETIC STRATEGIES                            ║
    ║                                                                           ║
    ║   ┌─────────────────────────────────────────────────────────────────┐    ║
    ║   │   C3 PLANTS (Most common - 95% of plants)                       │    ║
    ║   │   ═══════════════════════════════════                           │    ║
    ║   │   • Direct CO₂ fixation by RuBisCO                              │    ║
    ║   │   • Best in cool, moist conditions                              │    ║
    ║   │   • Examples: Rice, wheat, lettuce, tomatoes                    │    ║
    ║   └─────────────────────────────────────────────────────────────────┘    ║
    ║                                                                           ║
    ║   ┌─────────────────────────────────────────────────────────────────┐    ║
    ║   │   C4 PLANTS (Tropical efficiency)                               │    ║
    ║   │   ═══════════════════════════════                               │    ║
    ║   │   • CO₂ concentrated before Calvin cycle                        │    ║
    ║   │   • Best in hot, sunny conditions                               │    ║
    ║   │   • Examples: Corn, sugarcane, sorghum                          │    ║
    ║   └─────────────────────────────────────────────────────────────────┘    ║
    ║                                                                           ║
    ║   ┌─────────────────────────────────────────────────────────────────┐    ║
    ║   │   CAM PLANTS (Desert adaptation)                                │    ║
    ║   │   ════════════════════════════                                  │    ║
    ║   │   • Stomata open at NIGHT (store CO₂)                           │    ║
    ║   │   • Calvin cycle runs during DAY                                │    ║
    ║   │   • Maximum water conservation                                  │    ║
    ║   │   • Examples: Cacti, succulents, pineapple                      │    ║
    ║   └─────────────────────────────────────────────────────────────────┘    ║
    ║                                                                           ║
    ╚═══════════════════════════════════════════════════════════════════════════╝
```

## Key Takeaways

```
    ╔═══════════════════════════════════════════════════════════════════════════╗
    ║                                                                           ║
    ║                      REMEMBER THESE KEY POINTS                            ║
    ║                                                                           ║
    ║   ✓ Photosynthesis converts light energy into chemical energy (sugar)   ║
    ║                                                                           ║
    ║   ✓ It happens in two stages: Light Reactions → Calvin Cycle            ║
    ║                                                                           ║
    ║   ✓ The oxygen we breathe comes from water split during photosynthesis  ║
    ║                                                                           ║
    ║   ✓ Plants appear green because they REFLECT green light                ║
    ║                                                                           ║
    ║   ✓ Light, CO₂, temperature, and water all affect the rate              ║
    ║                                                                           ║
    ║   ✓ Growth requires photosynthesis to exceed respiration                ║
    ║                                                                           ║
    ║   ✓ Different plants (C3, C4, CAM) have different strategies            ║
    ║                                                                           ║
    ╚═══════════════════════════════════════════════════════════════════════════╝
```
