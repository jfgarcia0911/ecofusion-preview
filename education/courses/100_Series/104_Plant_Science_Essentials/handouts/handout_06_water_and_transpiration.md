## The Big Picture: Water Movement in Plants

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                    WATER'S JOURNEY THROUGH A PLANT                         │
    │                                                                             │
    │                                                                             │
    │                        ☀️ SUNLIGHT + HEAT                                  │
    │                              │                                              │
    │                              ▼                                              │
    │                    ┌─────────────────┐                                     │
    │         💨 Wind → │   🌿 LEAVES     │ ← Vapor exits                       │
    │                    │    (Stomata)    │   through stomata                   │
    │                    └────────┬────────┘                                     │
    │                              │                                              │
    │                              │  TRANSPIRATION                              │
    │                              │  creates "pull"                              │
    │                              │                                              │
    │                      ┌───────┴───────┐                                     │
    │                      │               │                                     │
    │                      │    STEM       │  XYLEM vessels                      │
    │                      │    (Xylem)    │  carry water UP                     │
    │                      │               │                                     │
    │                      │       ↑       │                                     │
    │                      │       ↑       │  Water column                       │
    │                      │       ↑       │  under TENSION                      │
    │                      │       ↑       │                                     │
    │                      └───────┬───────┘                                     │
    │                              │                                              │
    │              ═════════════════╪═══════════════  SOIL LINE                  │
    │                              │                                              │
    │                    ┌─────────┴─────────┐                                   │
    │                    │                   │                                   │
    │                    │   🌱 ROOTS       │  Water enters                      │
    │                    │   (Absorption)    │  through root hairs               │
    │                    │                   │                                   │
    │                    └─────────┬─────────┘                                   │
    │                              │                                              │
    │                        💧 SOIL WATER                                       │
    │                                                                             │
    │   ─────────────────────────────────────────────────────────────────────    │
    │                                                                             │
    │   KEY CONCEPT: Water is "PULLED" up by evaporation at the top,            │
    │   not "pushed" up from the roots. This is called the                       │

## Transpiration: The Driving Force

```
    ╔═══════════════════════════════════════════════════════════════════════════╗
    ║                                                                           ║
    ║                    TRANSPIRATION EXPLAINED                                ║
    ║                                                                           ║
    ║   DEFINITION: The loss of water vapor from plant surfaces                ║
    ║               (primarily through stomata on leaves)                       ║
    ║                                                                           ║
    ║   ┌─────────────────────────────────────────────────────────────────┐    ║
    ║   │                                                                 │    ║
    ║   │                     STOMATA CLOSE-UP                            │    ║
    ║   │                                                                 │    ║
    ║   │         OPEN STOMATA              CLOSED STOMATA               │    ║
    ║   │                                                                 │    ║
    ║   │            ○    ○                    ○○○○                      │    ║
    ║   │           (  ●  )                    (●)                       │    ║
    ║   │            ○    ○                    ○○○○                      │    ║
    ║   │                                                                 │    ║
    ║   │        Water vapor                 Stomata seal                 │    ║
    ║   │        escapes  ↑                  to conserve                  │    ║
    ║   │        CO₂ enters ↓                water                        │    ║
    ║   │                                                                 │    ║
    ║   │   Guard Cells:  Turgid (full)      Flaccid (deflated)          │    ║
    ║   │                                                                 │    ║
    ║   │   ● = Stomatal pore   ○ = Guard cells                          │    ║
    ║   │                                                                 │    ║
    ║   └─────────────────────────────────────────────────────────────────┘    ║
    ║                                                                           ║
    ║   TRANSPIRATION SERVES MULTIPLE PURPOSES:                                ║
    ║   ═══════════════════════════════════════                                 ║
    ║                                                                           ║
    ║   1. WATER TRANSPORT    Pulls water & dissolved minerals from roots      ║
    ║   2. COOLING            Evaporation removes heat (like sweating)         ║
    ║   3. GAS EXCHANGE       Opens pathway for CO₂ to enter for photosynthesis║
    ║   4. TURGOR PRESSURE    Keeps cells rigid, plant structure upright       ║
    ║                                                                           ║
    ╚═══════════════════════════════════════════════════════════════════════════╝
```

## Vapor Pressure Deficit (VPD)

```
    ╔═══════════════════════════════════════════════════════════════════════════╗
    ║                                                                           ║
    ║              VAPOR PRESSURE DEFICIT: THE KEY TO TRANSPIRATION             ║
    ║                                                                           ║
    ║   VPD = The "drying power" of the air                                    ║
    ║   The difference between how much moisture air holds vs. CAN hold        ║
    ║                                                                           ║
    ║   ┌─────────────────────────────────────────────────────────────────┐    ║
    ║   │                                                                 │    ║
    ║   │   LOW VPD (High Humidity)         HIGH VPD (Low Humidity)      │    ║
    ║   │                                                                 │    ║
    ║   │   Air nearly saturated            Air very "thirsty"           │    ║
    ║   │   💧💧💧💧💧💧💧                   💧 · · · ·                    │    ║
    ║   │                                                                 │    ║
    ║   │   • Slow transpiration            • Rapid transpiration        │    ║
    ║   │   • Risk of disease (wet)         • Risk of wilting            │    ║
    ║   │   • Poor nutrient transport       • Stomata may close          │    ║
    ║   │   • Good for propagation          • Plants struggle            │    ║
    ║   │                                                                 │    ║
    ║   │        VPD < 0.4 kPa                    VPD > 1.6 kPa          │    ║
    ║   │                                                                 │    ║
    ║   └─────────────────────────────────────────────────────────────────┘    ║
    ║                                                                           ║
    ║   OPTIMAL VPD BY GROWTH STAGE:                                           ║
    ║   ═════════════════════════════                                           ║
    ║                                                                           ║
    ║   VPD (kPa)    0.4    0.8    1.0    1.2    1.6    2.0+                   ║
    ║                 │      │      │      │      │      │                     ║
    ║                 ▼      ▼      ▼      ▼      ▼      ▼                     ║
    ║                [░░░░░░░▒▒▒▒▒▒▒▓▓▓▓▓▓▓█████████████████]                 ║
    ║                 │             │             │                            ║
    ║              CLONES/     VEGETATIVE    FLOWERING                         ║
    ║              SEEDLINGS                                                   ║
    ║              0.4-0.8      0.8-1.2      1.0-1.5                           ║
    ║                                                                           ║
    ║   GENERAL RULE: Raise VPD as plants mature                               ║
    ║                                                                           ║
    ╚═══════════════════════════════════════════════════════════════════════════╝
```

## Water Potential and Osmosis

```
    ╔═══════════════════════════════════════════════════════════════════════════╗
    ║                                                                           ║
    ║              WATER POTENTIAL: WHY WATER MOVES                             ║
    ║                                                                           ║
    ║   Water ALWAYS moves from HIGH water potential to LOW water potential    ║
    ║                                                                           ║
    ║   ┌─────────────────────────────────────────────────────────────────┐    ║
    ║   │                                                                 │    ║
    ║   │   WATER POTENTIAL GRADIENT (normal conditions):                │    ║
    ║   │                                                                 │    ║
    ║   │   SOIL → ROOT → STEM → LEAF → AIR                              │    ║
    ║   │                                                                 │    ║
    ║   │   -0.3   -0.5   -0.8   -1.5    -100   (MPa)                    │    ║
    ║   │   HIGH ───────────────────────→ LOW                            │    ║
    ║   │                                                                 │    ║
    ║   │   Water flows "downhill" in terms of water potential           │    ║
    ║   │   Even though it's moving UP the plant physically!             │    ║
    ║   │                                                                 │    ║
    ║   └─────────────────────────────────────────────────────────────────┘    ║
    ║                                                                           ║
    ║   WHAT DETERMINES WATER POTENTIAL:                                       ║
    ║   ═══════════════════════════════════                                     ║
    ║                                                                           ║
    ║   Ψ (Water Potential) = Ψs (Solute) + Ψp (Pressure)                     ║
    ║                                                                           ║
    ║   SOLUTE POTENTIAL (Ψs):                                                 ║
    ║   • More dissolved solutes = LOWER (more negative) water potential       ║
    ║   • This is why salt damages roots (draws water OUT of root cells)       ║
    ║                                                                           ║
    ║   PRESSURE POTENTIAL (Ψp):                                               ║
    ║   • Turgor pressure in cells (positive)                                  ║
    ║   • Tension in xylem vessels (negative)                                  ║
    ║                                                                           ║
    ╚═══════════════════════════════════════════════════════════════════════════╝
```

```

    │                                                                             │
    │                    UNDERSTANDING WILTING                                   │

    │                                                                             │
    │   ┌──────────────┐          ┌──────────────┐                               │
    │   │▓▓▓▓▓▓▓▓▓▓▓▓▓▓│          │              │                               │
    │   │▓▓▓▓▓▓▓▓▓▓▓▓▓▓│          │   ┌──────┐   │                               │
    │   │▓▓▓▓▓▓▓▓▓▓▓▓▓▓│          │   │▓▓▓▓▓▓│   │                               │
    │   │▓▓▓▓▓▓▓▓▓▓▓▓▓▓│          │   │▓▓▓▓▓▓│   │                               │

    │                                                                             │
    │   Vacuole full,             Vacuole shrunk,                                │
    │   cell wall pushed          membrane pulled away                           │
    │   outward = TURGOR          from cell wall = FLACCID                       │
    │                                                                             │
    │   ─────────────────────────────────────────────────────────────────────    │
    │                                                                             │
    │   TYPES OF WILTING:                                                        │
    │   ═════════════════                                                        │
    │                                                                             │
    │   TEMPORARY WILTING                     PERMANENT WILTING                  │
    │   ───────────────────                   ─────────────────────               │
    │   • Occurs during peak heat             • Soil water depleted              │
    │   • Recovers overnight                  • Does NOT recover                 │
    │   • Transpiration > uptake              • Past permanent wilting point     │
    │   • Usually not harmful                 • Cell damage occurring            │
    │                                                                             │
    │   FIX: Often nothing                    FIX: Water immediately!            │
    │   needed - plant is                     May be too late if severe.         │
    │   managing itself                       Prevention is key.                 │
    │                                                                             │
    │   ─────────────────────────────────────────────────────────────────────    │
    │                                                                             │
    │   SALT-INDUCED WILTING:                                                    │
    │   ══════════════════════                                                   │
    │                                                                             │
    │   • Water present BUT unavailable                                          │
    │   • EC too high = water can't enter roots                                  │
    │   • "Physiological drought"                                                │
    │   • Plants wilt even in wet media!                                         │
    │                                                                             │
    │   FIX: Flush with fresh water, lower nutrient concentration               │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘
```

## The Cohesion-Tension Theory

```
    ╔═══════════════════════════════════════════════════════════════════════════╗
    ║                                                                           ║
    ║              HOW WATER DEFIES GRAVITY IN PLANTS                           ║
    ║                                                                           ║
    ║   THE COHESION-TENSION THEORY (How water gets to the top of tall trees)  ║
    ║                                                                           ║
    ║   ┌─────────────────────────────────────────────────────────────────┐    ║
    ║   │                                                                 │    ║
    ║   │   STEP 1: EVAPORATION (Creates tension)                        │    ║
    ║   │                                                                 │    ║
    ║   │           ☀️                                                    │    ║
    ║   │          ↑↑↑  Water vapor escapes                              │    ║
    ║   │       ┌─────────┐                                               │    ║
    ║   │       │  LEAF   │ ← Mesophyll cells lose water                 │    ║
    ║   │       └────┬────┘   Creates negative pressure (suction)        │    ║
    ║   │            │                                                    │    ║
    ║   │                                                                 │    ║
    ║   │   STEP 2: COHESION (Water sticks together)                     │    ║
    ║   │                                                                 │    ║
    ║   │        │ ↑ │      Water molecules                               │    ║
    ║   │        │ ↑ │      hydrogen-bond to each other                  │    ║
    ║   │        │ ↑ │      = continuous "water chain"                   │    ║
    ║   │        │ ↑ │                                                    │    ║
    ║   │        │ ↑ │  ← XYLEM vessels                                  │    ║
    ║   │        │ ↑ │     (tiny tubes)                                  │    ║
    ║   │        │ ↑ │                                                    │    ║
    ║   │                                                                 │    ║
    ║   │   STEP 3: ADHESION (Water sticks to walls)                     │    ║
    ║   │                                                                 │    ║
    ║   │        │ ↑ │     Water molecules also                          │    ║
    ║   │        │ ↑ │     stick to xylem walls                          │    ║
    ║   │        │ ↑ │     preventing column collapse                    │    ║
    ║   │            │                                                    │    ║
    ║   │   ═════════╪═════════  SOIL LINE                               │    ║
    ║   │            │                                                    │    ║
    ║   │       ┌────┴────┐                                               │    ║
    ║   │       │  ROOT   │ ← Water enters to replace                    │    ║
    ║   │       └─────────┘   what was lost at top                       │    ║
    ║   │                                                                 │    ║
    ║   └─────────────────────────────────────────────────────────────────┘    ║
    ║                                                                           ║
    ║   AMAZING FACT: This system can pull water 100+ meters up!               ║
    ║   (The height of the tallest trees)                                      ║
    ║                                                                           ║
    ╚═══════════════════════════════════════════════════════════════════════════╝
```

## Practical Water Management

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                    WATER MANAGEMENT IN CONTROLLED ENVIRONMENT              │
    │                                                                             │
    │   ╔═══════════════════════════════════════════════════════════════════╗   │
    │   ║                                                                   ║   │
    │   ║   SIGNS OF OVERWATERING:                                         ║   │
    │   ║   ══════════════════════                                          ║   │
    │   ║   • Yellowing leaves (starting at bottom)                        ║   │
    │   ║   • Drooping despite wet soil                                    ║   │
    │   ║   • Slow growth                                                  ║   │
    │   ║   • Root rot (brown, mushy roots)                                ║   │
