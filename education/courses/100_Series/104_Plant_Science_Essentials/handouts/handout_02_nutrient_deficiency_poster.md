## The First Rule: Location, Location, Location

```
    ╔═══════════════════════════════════════════════════════════════════════════╗
    ║                                                                           ║
    ║                    MOBILE vs. IMMOBILE NUTRIENTS                          ║
    ║                                                                           ║
    ║      SYMPTOMS IN OLD LEAVES          SYMPTOMS IN NEW LEAVES              ║
    ║      ══════════════════════          ═══════════════════════              ║
    ║                                                                           ║
    ║           🌿🌿🌿                           🌿🌿🌿                         ║
    ║          ▓▓▓▓▓▓▓▓                        ░░░░░░░░                        ║
    ║          NEW = OK                        NEW = PROBLEM                    ║
    ║                                                                           ║
    ║          🍂🍂🍂                           🌿🌿🌿                         ║
    ║          ░░░░░░░░                        ▓▓▓▓▓▓▓▓                        ║
    ║          OLD = PROBLEM                   OLD = OK                         ║
    ║                                                                           ║
    ║      MOBILE NUTRIENTS:               IMMOBILE NUTRIENTS:                  ║
    ║      • Nitrogen (N)                  • Calcium (Ca)                       ║

    ║      • Potassium (K)                 • Iron (Fe)                          ║

    ║      these to new growth             these - stuck where they are         ║
    ║                                                                           ║
    ╚═══════════════════════════════════════════════════════════════════════════╝

## Immobile Nutrients - New Leaves First

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                            CALCIUM (Ca)                                    │
    │                            ════════════                                     │
    │                                                                             │
    │        HEALTHY              DEFICIENT            DESCRIPTION               │
    │                                                                             │
    │         🌿🌿🌿               ░▒▒▒▒░              • Tip burn, distortion    │
    │        ▓▓▓▓▓▓▓▓             ░▒▒▒▒░              • NEW leaves affected     │
    │                             NEW = BAD            • Blossom end rot (fruit) │
    │         🌿🌿🌿               🌿🌿🌿              • Tip burn in lettuce     │
    │        ▓▓▓▓▓▓▓▓             ▓▓▓▓▓▓▓▓            • Death of growing points │
    │                             OLD = OK                                       │
    │         🌿🌿🌿               🌿🌿🌿              COMMON CAUSE: High humidity│
    │        ▓▓▓▓▓▓▓▓             ▓▓▓▓▓▓▓▓            (low transpiration)       │
    │                                                  FIX: Improve airflow      │
    │                                                                             │
    ├─────────────────────────────────────────────────────────────────────────────┤
    │                                                                             │
    │                             IRON (Fe)                                      │
    │                             ═════════                                       │
    │                                                                             │
    │        HEALTHY              DEFICIENT            DESCRIPTION               │
    │                                                                             │
    │         🌿🌿🌿               ░▓░▓░▓░             • INTERVEINAL chlorosis   │
    │        ▓▓▓▓▓▓▓▓             ░▓░▓░▓░             • In NEW leaves!          │
    │                             NEW = BAD            • Veins stay green        │
    │         🌿🌿🌿               🌿🌿🌿              • Very similar to Mg      │
    │        ▓▓▓▓▓▓▓▓             ▓▓▓▓▓▓▓▓               BUT in young leaves    │
    │                             OLD = OK                                       │
    │         🌿🌿🌿               🌿🌿🌿              COMMON CAUSE: High pH!    │
    │        ▓▓▓▓▓▓▓▓             ▓▓▓▓▓▓▓▓            FIX: Lower pH to 5.8-6.2  │
    │                                                                             │
    ├─────────────────────────────────────────────────────────────────────────────┤
    │                                                                             │

    │        ▓▓▓▓▓▓▓▓             ░░░░░░░░            • UNIFORM (like N)        │

    │         🌿🌿🌿               🌿🌿🌿              • Distinguish from N by   │
    │        ▓▓▓▓▓▓▓▓             ▓▓▓▓▓▓▓▓               location               │

    │         🌿🌿🌿               🌿🌿🌿              FIX: Sulfate fertilizer   │

    │                             OLD = OK                                       │
    │                                                  FIX: Borax (carefully!)   │
    │                                                  Toxic line is close       │
    │                                                                             │

## Critical First Step

```
    ╔═══════════════════════════════════════════════════════════════════════════╗
    ║                                                                           ║
    ║   ⚠️  BEFORE DIAGNOSING ANY DEFICIENCY, CHECK pH FIRST!  ⚠️             ║
    ║                                                                           ║
    ║   Most "deficiencies" are actually pH LOCKOUT problems                   ║
    ║                                                                           ║
    ║   OPTIMAL pH: 5.5 - 6.5 (hydroponics) | 6.0 - 7.0 (soil)                ║
    ║                                                                           ║
    ║   Even if nutrients are present, wrong pH = plants can't absorb them!    ║
    ║                                                                           ║
    ╚═══════════════════════════════════════════════════════════════════════════╝
```
