## Root Hairs: The Real Absorbers

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                    ROOT HAIRS MAGNIFIED                                    │
    │                                                                             │
    │   Cross-section of root with soil particles:                               │
    │                                                                             │

    │           ┌───────────────────────┐     ~ = Water film                    │
    │           │~~~~~~~~~~~~~~~~~~~~~~~│     → = Nutrient uptake               │
    │           │  ←─────────── ROOT    │                                       │
    │      ○    │~~~~│ │ │ │ │ │~~~~~~~│  ○                                    │
    │           │~~~~│ │ │ │ │ │~~~~~~~│                                        │
    │        ○  │~~~~│ │ │ │ │ │~~~~~~~│    ○                                   │
    │           │~~~~│→│→│→│→│→│~~~~~~~│                                        │
    │           │~~~~│ ROOT HAIRS │~~~~│                                        │
    │      ○    │~~~~│ │ │ │ │ │~~~~~~~│                                        │
    │           │~~~~~~~~~~~~~~~~~~~~~~~│     ○                                 │
    │           └───────────────────────┘                                       │
    │                   ○        ○                                              │
    │                                                                             │
    │   ─────────────────────────────────────────────────────────────────────    │
    │                                                                             │
    │   ROOT HAIR FACTS:                                                         │
    │   ═══════════════════                                                      │
    │                                                                             │
    │   • Increase surface area by 100-1000x                                    │
    │   • Only 0.01-0.02mm diameter                                             │
    │   • Live only 1-3 weeks, constantly replaced                              │
    │   • Responsible for 90%+ of water uptake                                  │
    │   • Damaged by transplanting, salt, dry conditions                        │
    │                                                                             │
    │   WHY ROOT HAIRS MATTER FOR HYDROPONICS:                                  │
    │   • Need oxygenated solution - root hairs need O₂!                        │
    │   • Gentle handling during transplant                                     │
    │   • Consistent moisture prevents die-off                                  │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘
```
