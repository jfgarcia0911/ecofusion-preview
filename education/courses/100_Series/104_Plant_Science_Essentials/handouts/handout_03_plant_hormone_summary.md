## 1. AUXIN

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                              AUXIN                                         │
    │                     "The Growth Director"                                  │
    │                                                                             │
    │   WHERE PRODUCED:  Shoot tips (apical meristem), young leaves              │
    │                                                                             │
    │   KEY FUNCTIONS:                                                           │
    │   ────────────────                                                         │
    │                                                                             │
    │   1. CELL ELONGATION           2. APICAL DOMINANCE                         │
    │      ──────────────               ─────────────────                         │
    │      ┌──┐   →   ┌────────┐         Tip produces auxin                      │
    │      │  │       │        │              ↓                                  │
    │      └──┘       └────────┘         Flows down stem                         │
    │      small         long                 ↓                                  │
    │                                    Suppresses lateral buds                 │
    │                                                                             │
    │   3. ROOT INITIATION           4. PHOTOTROPISM                             │
    │      ────────────────             ─────────────                             │
    │      Rooting hormone!             Light → Auxin moves to dark side         │
    │      Used in propagation               → Dark side grows faster            │
    │                                        → Plant bends toward light          │
    │                                                                             │
    │   PRACTICAL APPLICATIONS:                                                  │
    │   • IBA/NAA rooting powders      • Topping to release lateral buds        │
    │   • Fruit drop prevention        • Herbicides (2,4-D at high doses)       │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘
```

## 2. CYTOKININ

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                            CYTOKININ                                       │
    │                      "The Cell Divider"                                    │
    │                                                                             │
    │   WHERE PRODUCED:  Root tips, transported UP to shoots                     │
    │                                                                             │
    │   KEY FUNCTIONS:                                                           │
    │   ────────────────                                                         │
    │                                                                             │
    │   1. CELL DIVISION             2. SHOOT PROMOTION                          │
    │      ─────────────                ────────────────                          │
    │      ┌──┐   →   ┌──┬──┐          Counteracts auxin                        │
    │      │  │       │  │  │          Promotes lateral bud growth              │
    │      └──┘       └──┴──┘          More cytokinin = bushier plant           │
    │      1 cell     2 cells                                                   │
    │                                                                             │
    │   3. DELAYS SENESCENCE         4. CHLOROPLAST DEVELOPMENT                  │
    │      ──────────────────           ────────────────────────                  │
    │      Keeps leaves green          Promotes chlorophyll synthesis            │
    │      "Anti-aging" hormone        Essential for greening                    │
    │                                                                             │
    │   THE AUXIN:CYTOKININ RATIO:                                               │
    │   ──────────────────────────                                               │
    │   High Auxin + Low CK  →  ROOTS                                           │
    │   Low Auxin + High CK  →  SHOOTS                                          │
    │   Equal ratio          →  CALLUS (undifferentiated)                       │
    │                                                                             │
    │   PRACTICAL APPLICATIONS:                                                  │
    │   • Tissue culture multiplication  • Extending cut flower life            │
    │   • Breaking lateral bud dormancy  • Delaying leaf senescence             │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘
```

## 3. GIBBERELLIN

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                           GIBBERELLIN                                      │
    │                        "The Stretcher"                                     │
    │                                                                             │
    │   WHERE PRODUCED:  Young leaves, roots, developing seeds                   │
    │                                                                             │
    │   KEY FUNCTIONS:                                                           │
    │   ────────────────                                                         │
    │                                                                             │
    │   1. STEM ELONGATION           2. SEED GERMINATION                         │
    │      ────────────────             ─────────────────                         │
    │                                                                             │
    │      WITHOUT GA    WITH GA       GA triggers enzymes that                  │
    │        ┌─┐          ┌─┐          break down stored starch                  │
    │       ┌┘ └┐        ┌┘ └┐                                                   │
    │       │   │        │   │         Seed dormancy → Germination               │
    │       │───│        │   │                                                   │
    │       │───│        │   │                                                   │
    │       │   │        │───│                                                   │
    │       └───┘        │───│                                                   │
    │      Dwarf         │   │                                                   │
    │                    │───│                                                   │
    │                    └───┘                                                   │
    │                    Tall                                                    │
    │                                                                             │
    │   3. FLOWERING (bolting)       4. FRUIT DEVELOPMENT                        │
    │      ───────────────────          ─────────────────                         │
    │      Triggers bolting            Increases grape berry size                │
    │      in rosette plants           Produces seedless fruit                   │
    │                                                                             │
    │   PRACTICAL APPLICATIONS:                                                  │
    │   • Grape sizing/elongation      • Breaking seed dormancy                  │
    │   • Seedless fruit production    • Malting (beer production)              │
    │                                                                             │
    │   GA INHIBITORS (growth retardants):                                       │
    │   • Paclobutrazol (Bonzi)  →  Compact potted plants                       │
    │   • Cycocel               →  Prevent wheat lodging                        │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘
```

## 4. ABSCISIC ACID (ABA)

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                        ABSCISIC ACID (ABA)                                 │
    │                       "The Stress Manager"                                 │
    │                                                                             │
    │   WHERE PRODUCED:  Leaves, roots (increases during stress)                 │
    │                                                                             │
    │   KEY FUNCTIONS:                                                           │
    │   ────────────────                                                         │
    │                                                                             │
    │   1. STOMATAL CLOSURE          2. DORMANCY MAINTENANCE                     │
    │      ─────────────────            ────────────────────                      │
    │                                                                             │
    │      Water stress detected       Keeps seeds dormant                       │
    │           ↓                      Prevents premature germination            │
    │      ABA increases                                                         │
    │           ↓                      High ABA = Dormant                        │
    │      Stomata CLOSE               Low ABA = Can germinate                   │
    │           ↓                                                                │
    │      Water conserved             (GA opposes ABA for germination)          │
    │                                                                             │
    │   3. STRESS RESPONSES          4. SEED MATURATION                          │
    │      ────────────────             ─────────────────                         │
    │      Cold, drought, salt →       Promotes storage compound                 │
    │      ABA accumulates             accumulation in seeds                     │
    │      Protective responses        Prevents vivipary                         │
    │      activated                   (sprouting on plant)                      │
    │                                                                             │
    │   PRACTICAL APPLICATIONS:                                                  │
    │   • Anti-transpirants           • Understanding dormancy                   │
    │   • Stress tolerance research   • Seed development studies                │
    │                                                                             │
    │   KEY BALANCE: ABA vs. GA                                                  │
    │   High ABA : Low GA  →  Dormant                                           │
    │   Low ABA : High GA  →  Growing                                           │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘
```

## 5. ETHYLENE

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                            ETHYLENE                                        │
    │                        "The Ripener"                                       │
    │                                                                             │
    │   UNIQUE: It's a GAS! (C₂H₄)                                               │
    │   WHERE PRODUCED:  All tissues, especially ripening fruit, wounded tissue  │
    │                                                                             │
    │   KEY FUNCTIONS:                                                           │
    │   ────────────────                                                         │
    │                                                                             │
    │   1. FRUIT RIPENING            2. ABSCISSION (Leaf/Fruit Drop)             │
    │      ──────────────               ───────────────────────────               │
    │                                                                             │
    │      🍌 → 🍌 → 🍌               Triggers formation of                       │
    │      Green  Ripe  Overripe      separation layer                           │
    │                                                                             │
    │      Climacteric fruits:        Allows clean break from plant              │
    │      Banana, tomato, apple                                                 │
    │                                                                             │
    │   3. SENESCENCE                4. TRIPLE RESPONSE (seedling)               │
    │      ───────────                  ──────────────────────────                │
    │      Accelerates aging          • Shortened stem                           │
    │      Leaf yellowing             • Thickened stem                           │
    │      Flower fading              • Horizontal growth                        │
    │                                 (helps push through soil)                  │
    │                                                                             │
    │   PRACTICAL APPLICATIONS:                                                  │
    │   ───────────────────────                                                  │
    │   • Ripen bananas commercially  • Degreen citrus (orange peel color)       │
    │   • Induce pineapple flowering  • Synchronize crop ripening                │
    │                                                                             │
    │   PROBLEMS TO AVOID:                                                       │
    │   • One ripe apple ripens the whole bunch!                                 │
    │   • Exhaust fumes damage plants (contain ethylene)                         │
    │   • Cut flowers senesce faster with ethylene exposure                      │
    │                                                                             │
    │   PREVENTION:                                                              │
    │   • Ventilation                 • 1-MCP (ethylene blocker)                 │
    │   • KMnO₄ sachets (absorbs)     • Separate ethylene producers              │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘
```
