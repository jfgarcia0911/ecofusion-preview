## Quick Diagnosis: Where Do Symptoms Appear?

```
    ┌──────────────────────────────────────────────────────────────┐
    │                                                              │
    │    NEW GROWTH AFFECTED          OLD GROWTH AFFECTED          │
    │    (Immobile nutrients)         (Mobile nutrients)           │
    │                                                              │
    │    • Calcium (Ca)               • Nitrogen (N)               │
    │    • Sulfur (S)                 • Phosphorus (P)             │
    │    • Iron (Fe)                  • Potassium (K)              │
    │    • Manganese (Mn)             • Magnesium (Mg)             │
    │    • Zinc (Zn)                  • Molybdenum (Mo)            │
    │    • Copper (Cu)                • Chlorine (Cl)              │
    │    • Boron (B)                                               │
    │                                                              │
    └──────────────────────────────────────────────────────────────┘
```

## Mobile Nutrients - Deficiency in OLD Leaves First

### Nitrogen (N)
| Symptom | Description |
|---------|-------------|
| **Color** | General yellowing (chlorosis), pale green |
| **Location** | Starts at bottom, moves up |
| **Pattern** | Uniform yellowing across entire leaf |
| **Other** | Stunted growth, early senescence |

### Phosphorus (P)
| Symptom | Description |
|---------|-------------|
| **Color** | Dark green, purple/red stems and undersides |
| **Location** | Old leaves, stems |
| **Pattern** | Dark coloration, may have red/purple tint |
| **Other** | Stunted growth, poor root development |

### Potassium (K)
| Symptom | Description |
|---------|-------------|
| **Color** | Browning/necrosis at leaf EDGES |
| **Location** | Old leaves |
| **Pattern** | Marginal (edge) scorch, "burnt" appearance |
| **Other** | Weak stems, drought susceptibility |

### Magnesium (Mg)
| Symptom | Description |
|---------|-------------|
| **Color** | Yellow BETWEEN veins, veins stay green |
| **Location** | Old leaves |
| **Pattern** | Interveinal chlorosis (classic pattern) |
| **Other** | May progress to necrotic spots |

## Immobile Nutrients - Deficiency in NEW Leaves First

### Calcium (Ca)
| Symptom | Description |
|---------|-------------|
| **Color** | Browning at tips and margins |
| **Location** | New leaves, growing points, fruit |
| **Pattern** | Tip burn, distorted growth |
| **Disorders** | Blossom end rot, tip burn, hollow heart |

### Sulfur (S)
| Symptom | Description |
|---------|-------------|
| **Color** | Light green to yellow (uniform) |
| **Location** | New leaves |
| **Pattern** | Similar to N but in NEW leaves |
| **Other** | Older leaves may remain darker |

### Iron (Fe)
| Symptom | Description |
|---------|-------------|
| **Color** | Yellow BETWEEN veins on new leaves |
| **Location** | Youngest leaves |
| **Pattern** | Interveinal chlorosis, veins stay green |
| **Note** | Often pH-related (high pH) |

### Manganese (Mn)
| Symptom | Description |
|---------|-------------|
| **Color** | Interveinal chlorosis with tan/gray spots |
| **Location** | New to middle leaves |
| **Pattern** | Similar to Fe but with necrotic spots |
| **Note** | Often pH-related |

### Zinc (Zn)
| Symptom | Description |
|---------|-------------|
| **Color** | Interveinal chlorosis |
| **Location** | New growth |
| **Pattern** | Small leaves, shortened internodes |
| **Other** | "Little leaf" appearance |

### Boron (B)
| Symptom | Description |
|---------|-------------|
| **Color** | Death of growing points |
| **Location** | New growth, meristems |
| **Pattern** | Hollow stems, distorted/thick leaves |
| **Other** | Cracked stems, poor fruit development |

### Copper (Cu)
| Symptom | Description |
|---------|-------------|
| **Color** | Light green, wilting |
| **Location** | New growth |
| **Pattern** | Die-back of shoot tips |
| **Other** | Poor lignification |

## Troubleshooting Flowchart

```
    STEP 1: Check pH FIRST!
    ════════════════════════
    Many "deficiencies" are actually pH lockout

    Optimal pH: 5.5-6.5 (hydro) | 6.0-7.0 (soil)

    STEP 2: Note symptom location
    ═════════════════════════════
    Old leaves → Mobile nutrient (N, P, K, Mg)
    New leaves → Immobile nutrient (Ca, S, Fe, Mn, Zn, Cu, B)

    STEP 3: Identify pattern
    ═══════════════════════
    Uniform chlorosis → N or S
    Interveinal chlorosis → Mg or Fe
    Edge browning → K
    Tip burn/distortion → Ca or B
    Purple color → P
```

## Quick Reference: Optimal Ranges (Hydroponics)

| Nutrient | ppm Range | Form |
|----------|-----------|------|
| N | 150-250 | NO₃⁻ |
| P | 30-50 | H₂PO₄⁻ |
| K | 150-300 | K⁺ |
| Ca | 150-250 | Ca²⁺ |
| Mg | 40-80 | Mg²⁺ |
| S | 50-100 | SO₄²⁻ |
| Fe | 2-5 | Chelated |
| Mn | 0.5-2 | Mn²⁺ |
| Zn | 0.2-0.5 | Zn²⁺ |
| Cu | 0.05-0.1 | Cu²⁺ |
| B | 0.2-0.5 | H₃BO₃ |
| Mo | 0.05-0.1 | MoO₄²⁻ |

## Common Nutrient Interactions

| If HIGH... | May Cause Deficiency of... |
|------------|---------------------------|
| Potassium | Calcium, Magnesium |
| Calcium | Potassium, Magnesium |
| Phosphorus | Zinc, Iron |
| Nitrogen | Potassium |
| Manganese | Iron |

---

## Emergency Actions

| Problem | Quick Fix |
|---------|-----------|
| General yellowing (old) | Check pH; foliar N spray |
| Interveinal chlorosis (old) | Epsom salt (MgSO₄) |
| Interveinal chlorosis (new) | Lower pH; chelated Fe |
| Brown edges (old) | K supplement |
| Tip burn (new) | Increase airflow; check Ca |
| Purple stems | Warm root zone; check pH |

---

**Remember: Always verify pH is correct before adding nutrients!**
