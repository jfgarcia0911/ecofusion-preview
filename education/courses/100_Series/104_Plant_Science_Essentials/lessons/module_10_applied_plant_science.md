### Symptom Location Guide

```
    WHERE SYMPTOMS APPEAR = DIAGNOSTIC CLUE

    SYMPTOMS IN NEW/YOUNG GROWTH
    ════════════════════════════
    Immobile nutrients:
    • Calcium, Sulfur
    • Iron, Manganese, Zinc, Copper, Boron

    Environmental:
    • Recent stress event
    • Current conditions

    ─────────────────────────────────────

    SYMPTOMS IN OLD/LOWER GROWTH
    ════════════════════════════
    Mobile nutrients:
    • Nitrogen, Phosphorus, Potassium
    • Magnesium, Chlorine, Molybdenum

    Environmental:
    • Light deficiency (shading)
    • Normal senescence

    ─────────────────────────────────────

    SYMPTOMS THROUGHOUT PLANT
    ═════════════════════════
    • Systemic disease
    • Root zone problem
    • Severe environmental stress
    • pH lockout affecting multiple nutrients
```

### Common Problem Matrix

| Symptom | Likely Causes | First Checks |
|---------|--------------|--------------|
| Yellow old leaves | N deficiency, overwatering | pH, N levels, drainage |
| Purple leaves/stems | P deficiency, cold | Root zone temp, pH |
| Brown leaf edges | K deficiency, salt stress | EC, K levels |
| Interveinal chlorosis (old) | Mg deficiency | pH, Mg:K ratio |
| Interveinal chlorosis (new) | Fe deficiency | pH (usually too high) |
| Tip burn | Ca deficiency | VPD, humidity, Ca levels |
| Wilting when wet | Root rot, low O₂ | Roots, drainage, aeration |
| Stretching | Low light | DLI, light intensity |
| Leaf curl up | Heat stress, low humidity | Temperature, VPD |
| Slow growth | Multiple factors | Systematic evaluation |

## 5. Common Production Issues and Solutions

### Environmental Issues

```
    ENVIRONMENTAL PROBLEM-SOLVING

    STRETCHING / LEGGY GROWTH
    ═════════════════════════
    Cause: Insufficient light, high temperature, low blue light
    Solution:
    • Increase light intensity
    • Reduce day temperature
    • Add blue wavelengths
    • Implement negative DIF

    TIP BURN (Lettuce)
    ══════════════════
    Cause: Calcium not reaching leaf margins
    Solution:
    • Increase VPD (reduce humidity slightly)
    • Improve airflow around plants
    • Ensure adequate Ca in solution
    • Reduce light if excessive

    BLOSSOM END ROT (Tomato, Pepper)
    ═════════════════════════════════
    Cause: Calcium deficiency in fruit
    Solution:
    • Maintain consistent watering
    • Avoid high EC swings
    • Moderate plant stress
    • Adequate but not excessive nitrogen

    BOLTING (Premature Flowering)
    ═════════════════════════════
    Cause: High temperature, long days, stress
    Solution:
    • Temperature control
    • Harvest before bolting
    • Choose bolt-resistant varieties
    • Avoid water stress
```

### Nutrient Issues

```
    NUTRIENT TROUBLESHOOTING

    "I'VE ADDED MORE BUT SYMPTOMS PERSIST"
    ══════════════════════════════════════

    CHECK FIRST:
    1. pH - Is nutrient actually available?
       • Low pH: Micronutrient toxicity
       • High pH: Fe, Mn, Zn lockout

    2. EC - Is overall concentration balanced?
       • Too high: Can cause deficiency symptoms
       • Too low: Multiple deficiencies possible

    3. Antagonism - Is another nutrient blocking?
       • High K → Ca, Mg problems
       • High P → Zn, Fe problems
       • High Ca → K, Mg problems

    4. Root health - Can plants take up anything?
       • Check for root rot
       • Check dissolved oxygen
       • Check root zone temperature
```

### Root Zone Issues

```
    ROOT ZONE TROUBLESHOOTING

    SYMPTOMS:
    • Wilting despite adequate moisture
    • Stunted growth
    • Yellowing throughout plant
    • Roots brown/mushy instead of white

    CHECKLIST:
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │  □ OXYGEN                                                   │
    │    Is dissolved O₂ > 6 mg/L?                               │
    │    Are air stones/pumps working?                           │
    │    Is drainage adequate?                                   │
    │                                                             │
    │  □ TEMPERATURE                                              │
    │    Is root zone 18-22°C?                                   │
    │    Is solution getting too warm?                           │
    │                                                             │
    │  □ pH                                                       │
    │    Is pH in range (5.5-6.5)?                               │
    │    Is pH stable or swinging wildly?                        │
    │                                                             │
    │  □ PATHOGENS                                               │
    │    Pythium, Phytophthora?                                  │
    │    Sanitation practices adequate?                          │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

## 7. System Design Principles

### Designing with Plant Science in Mind

```
    DESIGN CONSIDERATIONS

    LIGHT SYSTEM
    ════════════
    • Match DLI to crop requirements
    • Uniform distribution (light mapping)
    • Spectrum appropriate for growth stage
    • Height adjustability for canopy management

    CLIMATE CONTROL
    ════════════════
    • Independent day/night temperature
    • Humidity control (VPD management)
    • Air circulation for uniformity
    • CO₂ supplementation if cost-effective

    IRRIGATION/NUTRITION
    ════════════════════
    • Appropriate system for crop type
    • Monitoring points (pH, EC)
    • Backup/redundancy for critical systems
    • Easy to clean and maintain

    ROOT ZONE
    ═════════
    • Adequate oxygen supply
    • Temperature control
    • Proper drainage
    • Disease prevention design
```

## 8. Putting It All Together

### Case Study: Solving Slow Lettuce Growth

```
    SCENARIO: Lettuce growing slowly, pale color

    STEP 1: GATHER INFORMATION
    ══════════════════════════
    • When did problem start?
    • Which plants affected?
    • Recent changes made?

    STEP 2: CHECK FUNDAMENTALS
    ══════════════════════════
    □ pH: 7.2 (TOO HIGH)
    □ EC: 1.4 (OK)
    □ Water temp: 24°C (slightly warm)
    □ Light: 250 PPFD × 16h = 14.4 DLI (OK)
    □ Air temp: 20°C day/18°C night (OK)

    STEP 3: IDENTIFY LIKELY CAUSE
    ═════════════════════════════
    pH 7.2 is too high!
    At this pH: Iron, manganese, zinc all limited
    Pale color suggests Fe chlorosis

    STEP 4: APPLY CORRECTION
    ════════════════════════
    • Lower pH to 5.8-6.2
    • May need foliar Fe spray for quick response
    • Check pH daily until stable

    STEP 5: MONITOR RESULTS
    ═══════════════════════
    • New growth should green up in 5-7 days
    • Continue monitoring pH
    • Track improvement
```
