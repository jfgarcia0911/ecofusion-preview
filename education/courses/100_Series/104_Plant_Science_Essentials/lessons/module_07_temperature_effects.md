# Module 7: Temperature Effects
## Course 104: Plant Science Essentials

## Introduction

Temperature touches every aspect of plant life. It determines how fast enzymes work, when plants flower, how quickly they grow, and whether they survive. Mastering temperature management is essential for successful cultivation in any environment.

---

## Learning Objectives

By the end of this module, you will be able to:
- Explain how temperature affects enzymatic and metabolic processes
- Describe cardinal temperatures and their significance
- Understand vernalization and stratification
- Manage day/night temperature differentials (DIF)
- Apply temperature strategies to optimize plant growth

## 1. Temperature and Metabolism

### The Enzyme Connection

All plant processes depend on enzymes, and enzymes are highly temperature-sensitive.

```
    ENZYME ACTIVITY vs. TEMPERATURE

    Activity
    Level
        │
        │                    ●
        │                   ╱ ╲
        │                  ╱   ╲
        │                 ╱     ╲ Denaturation
        │                ╱       ╲ (protein damage)
        │               ╱         ╲
        │              ╱           ╲
        │             ╱             ╲
        │            ╱               ╲
        │           ╱                 ╲
        │          ╱                   ╲
        │         ╱                     ╲
        │________╱                       ╲________
        │
        └───────────────────────────────────────────
              10    20    30    40    50   Temperature (°C)

                         ↑
                    Optimum
                    Temperature
```

### The Q10 Rule

For every 10°C increase, metabolic rate approximately doubles (within normal range).

```
    Q10 EFFECT ON METABOLIC PROCESSES

    Temperature     Relative Rate
    ───────────────────────────────
    10°C            1x (baseline)
    20°C            2x
    30°C            4x
    40°C            8x (if not damaged)

    ⚠️ This works UNTIL proteins start denaturing
       (typically above 35-40°C for most plants)
```

## 2. Cardinal Temperatures

### Minimum, Optimum, Maximum

Every plant process has three cardinal temperatures:

```
    CARDINAL TEMPERATURES

    Process
    Rate
        │
        │           OPTIMUM
        │              ●
        │             ╱│╲
        │            ╱ │ ╲
        │           ╱  │  ╲
        │          ╱   │   ╲
        │         ╱    │    ╲
        │        ╱     │     ╲
        │       ╱      │      ╲
        │______╱       │       ╲______
        │
        └─────────────────────────────────────
             ↑         ↑         ↑
          MINIMUM   OPTIMUM   MAXIMUM

    Below minimum: Process stops
    At optimum: Process at maximum rate
    Above maximum: Process stops (damage)
```

## 3. Day/Night Temperature Differential (DIF)

### What is DIF?

**DIF = Day Temperature - Night Temperature**

```
    DIF EFFECTS ON STEM ELONGATION

    POSITIVE DIF (+10°C)         ZERO DIF (0°C)          NEGATIVE DIF (-5°C)
    Day 25°C / Night 15°C        Day 20°C / Night 20°C   Day 18°C / Night 23°C

         │                            │                        │
         │                            │                        │
         │                           ┌┴┐                      ┌┴┐
        ┌┴┐                         ┌┘ └┐                    ┌┘ └┐
       ┌┘ └┐                       ┌┘   └┐                  ┌┘   └┐
      ┌┘   └┐  TALL              ┌┘     └┐  NORMAL       ┌┘     └┐  COMPACT
     ┌┘     └┐ INTERNODES       ┌┘       └┐              ─┘       └─
    ─┘       └─                ─┘         └─

    Increased                   Balanced                  Reduced
    Elongation                  Growth                    Elongation
```

### Using DIF for Growth Control

| DIF Strategy | Effect | Application |
|--------------|--------|-------------|
| Large + DIF (+8-12°C) | Maximum stem elongation | Vine crops needing height |
| Moderate + DIF (+4-7°C) | Normal growth | Standard production |
| Zero DIF (0°C) | Reduced elongation | Compact plants |
| Negative DIF (-2-5°C) | Minimum elongation | Height control without chemicals |

### The "Cool Morning" Strategy

```
    DROP TECHNIQUE (Morning Temperature Drop)

    Temperature
         │
    25°C │            ●●●●●●●●●●●●●●●●●●●●●
         │           ╱                      ╲
    20°C │●●●●●●●●●●╱                        ╲●●●●●●●●●●
         │        ╱                          ╲
    15°C │       ╱                            ╲
         │      ╱                              ╲
    10°C │_____●  ← 2-hour DROP                 ╲_____
         │
         └─────────────────────────────────────────────
              │    │                              │
           Sunrise  │                          Sunset
                 2h after sunrise

    DROP reduces stem elongation WITHOUT affecting
    photosynthesis significantly
```

## 4. Root Zone Temperature

### Critical but Often Overlooked

Root zone temperature significantly impacts nutrient uptake and plant health.

```
    ROOT ZONE TEMPERATURE EFFECTS

    Temperature    Effect
    ─────────────────────────────────────────────────
    < 10°C         • Nutrient uptake severely reduced
                   • P and K especially affected
                   • Root growth minimal
                   • Transplant shock prolonged

    10-15°C        • Suboptimal uptake
                   • Slow root growth
                   • May show deficiency symptoms

    15-22°C        • OPTIMAL RANGE for most crops
                   • Maximum nutrient uptake
                   • Best root development

    22-26°C        • Still good for warm-season crops
                   • Tropicals thrive

    > 26°C         • Dissolved oxygen decreases
                   • Root disease risk increases
                   • Stress symptoms may appear
```

### Root Zone vs. Air Temperature

Different temperatures can be optimal for roots vs. shoots:

| Crop | Optimal Air | Optimal Root Zone |
|------|-------------|-------------------|
| Lettuce | 18-22°C | 18-22°C |
| Tomato | 21-27°C | 20-24°C |
| Cucumber | 24-28°C | 22-26°C |
| Strawberry | 18-24°C | 15-18°C |

## 5. Vernalization

### Flowering Triggered by Cold

Some plants require a period of cold (vernalization) before they can flower.

```
    VERNALIZATION PROCESS

    STEP 1: Cold Exposure
    ══════════════════════
    Plant experiences temperatures of 1-10°C
    Duration: Weeks to months (species dependent)

    ┌─────────────────────────────────────────┐
    │   ❄️  Cold Period  ❄️                    │
    │                                         │
    │   Plant "counts" hours of cold          │
    │   Accumulated cold = "chill units"      │
    │   Once requirement met, plant is        │
    │   "vernalized"                          │
    └─────────────────────────────────────────┘
                    │
                    ▼
    STEP 2: Warm Temperatures Return
    ════════════════════════════════
    Vernalized plant can now flower
    when conditions are right

    ┌─────────────────────────────────────────┐
    │   🌸  Flowering Enabled  🌸              │
    │                                         │
    │   Without vernalization:                │
    │   Plant stays vegetative indefinitely   │
    └─────────────────────────────────────────┘
```

### Vernalization Requirements

| Plant | Vernalization Temp | Duration | Notes |
|-------|-------------------|----------|-------|
| Winter wheat | 0-7°C | 4-8 weeks | Planted in fall |
| Strawberry (June-bearing) | 0-7°C | 2-4 weeks | Triggers flowering |
| Onion | 7-13°C | 4-8 weeks | For bulb formation |
| Biennial crops | 0-10°C | 8-12 weeks | Carrots, beets, cabbage |
| Tulips | 2-9°C | 12-16 weeks | For forcing |

### Devernalization

High temperatures can reverse vernalization:

```
    DEVERNALIZATION RISK

    If temperatures exceed 25-30°C for extended periods
    AFTER cold exposure but BEFORE flowering commitment:

    ┌─────────────────────────────────────────┐
    │                                         │
    │   ❄️ Cold ──► ☀️ Warm ──► ❄️ Need Cold Again
    │             (too hot)                   │
    │                                         │
    │   Vernalization "reset"                 │
    │   Flowering delayed or prevented        │
    │                                         │
    └─────────────────────────────────────────┘
```

## 6. Stratification

### Cold Treatment for Seeds

Stratification is cold treatment that breaks seed dormancy.

```
    STRATIFICATION vs. VERNALIZATION

    STRATIFICATION                    VERNALIZATION
    ═══════════════                   ══════════════

    Applied to: SEEDS                 Applied to: PLANTS
    Purpose: Break dormancy           Purpose: Enable flowering
    Temp: 1-5°C (moist)              Temp: 0-10°C
    Duration: Weeks to months         Duration: Weeks to months

    Both involve cold exposure, but different life stages
```

### Common Seeds Requiring Stratification

| Seed | Stratification Time | Temperature |
|------|---------------------|-------------|
| Apple | 60-90 days | 1-5°C |
| Lavender | 30-40 days | 1-5°C |
| Echinacea | 30-90 days | 1-5°C |
| Many native perennials | 60-120 days | 1-5°C |

## 7. Temperature Stress

### Chilling Injury (Above Freezing)

Tropical and subtropical plants can be damaged by cold temperatures even above freezing.

```
    CHILLING INJURY SYMPTOMS

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │  SENSITIVE CROPS: Tomato, pepper, cucumber, basil, beans   │
    │                                                             │
    │  Exposure to 0-12°C can cause:                              │
    │                                                             │
    │  • Wilting (even when water available)                     │
    │  • Water-soaked spots on leaves                            │
    │  • Surface pitting on fruit                                │
    │  • Discoloration (yellowing, browning)                     │
    │  • Accelerated decay                                       │
    │  • Loss of flavor/aroma                                    │
    │  • Failure to ripen properly                               │
    │                                                             │
    │  DAMAGE SEVERITY depends on:                                │
    │  • Temperature (lower = worse)                              │
    │  • Duration of exposure                                     │
    │  • Species/variety sensitivity                              │
    │  • Plant health/stage                                       │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

### Heat Stress

```
    HEAT STRESS SYMPTOMS

    Temperature > 35-40°C (species dependent)

    IMMEDIATE EFFECTS:
    • Stomata close ──► Reduced CO₂ uptake
    • Transpiration increases ──► Wilting
    • Photosynthesis decreases
    • Respiration increases ──► Carbon loss

    VISIBLE SYMPTOMS:
    ┌─────────────────────────────────────────┐
    │  • Leaf curling (especially upward)     │
    │  • Leaf scorching/bleaching             │
    │  • Flower drop                          │
    │  • Poor fruit set                       │
    │  • Blossom end rot                      │
    │  • Bolting (premature flowering)        │
    │  • Reduced growth                       │
    │  • Bitter flavor (lettuce)              │
    └─────────────────────────────────────────┘
```

### Critical Thresholds for Common Crops

| Crop | Chilling Injury Threshold | Heat Stress Threshold |
|------|--------------------------|----------------------|
| Tomato | 10°C | 35°C |
| Pepper | 12°C | 32°C |
| Cucumber | 12°C | 35°C |
| Lettuce | 0°C (frost) | 25-28°C |
| Basil | 10°C | 32°C |
| Strawberry | -6°C (frost) | 30°C |

## 8. Temperature in Controlled Environments

### Heating Strategies

```
    HEATING METHODS COMPARISON

    METHOD              PROS                    CONS
    ──────────────────────────────────────────────────────────
    Natural Gas         • Efficient             • CO₂ buildup
    Heaters             • Inexpensive fuel      • Fire risk
                        • Can capture CO₂

    Electric            • Clean                 • High operating cost
    Heaters             • Easy to install       • No CO₂ benefit
                        • Precise control

    Hot Water           • Uniform heat          • High installation cost
    Systems             • Root zone heating     • Slow response
                        • Very efficient

    Heat Pumps          • Very efficient        • High capital cost
                        • Can cool too          • Complex
                        • Low operating cost
```

### Cooling Strategies

```
    COOLING METHODS

    EVAPORATIVE COOLING (Pad & Fan, Fog)
    ═══════════════════════════════════
    • Uses water evaporation to cool air
    • Works best in dry climates
    • Can lower temp 10-15°C
    • Increases humidity

    VENTILATION
    ═══════════
    • Natural or forced air exchange
    • Free when outside is cool
    • Limited cooling capacity
    • Brings in fresh CO₂

    AIR CONDITIONING
    ════════════════
    • Most effective cooling
    • Works in any climate
    • Highest energy cost
    • Dehumidifies

    SHADE/REFLECTIVE COATINGS
    ═════════════════════════
    • Reduces heat gain
    • Simple and cheap
    • Reduces light (trade-off)
```

### Temperature Control Priorities

```
    TEMPERATURE MANAGEMENT HIERARCHY

    1. ROOT ZONE TEMPERATURE
       └─► Most critical for plant function
       └─► Harder to change than air temp
       └─► Often overlooked

    2. NIGHT TEMPERATURE
       └─► Affects respiration rate
       └─► Impacts DIF and morphology
       └─► Energy consumption significant

    3. DAY TEMPERATURE
       └─► Must match photosynthetic optimum
       └─► Balance with light levels
       └─► Easier to manage with ventilation

    4. TEMPERATURE UNIFORMITY
       └─► Avoid hot/cold spots
       └─► Air circulation critical
       └─► Monitor multiple locations
```

## 9. Temperature Integration

### Average Temperature Matters

Plants respond to average temperature over time, not just instantaneous temperature.

```
    TEMPERATURE INTEGRATION CONCEPT

    Scenario A: Constant 20°C
    ────────────────────────
    │▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│ 20°C constant
    │                    │
    Average: 20°C

    Scenario B: Variable (15-25°C)
    ──────────────────────────────
    │        ▓▓▓▓▓▓▓▓      │ 25°C
    │      ▓▓        ▓▓    │
    │    ▓▓            ▓▓  │
    │▓▓▓▓                ▓▓│ 15°C

    Average: 20°C

    SAME AVERAGE = SIMILAR GROWTH (within limits)

    This allows energy savings:
    • Run cooler when energy is expensive
    • Compensate with warmer periods later
```

### Using Temperature Integration

| Application | Strategy | Benefit |
|-------------|----------|---------|
| Energy savings | Cooler nights | Lower heating costs |
| Peak demand | Reduce heating during expensive hours | Cost savings |
| Weather fluctuations | Let temp vary naturally | Less energy use |
| CO₂ interaction | Higher temp with higher CO₂ | Synergistic growth |

## Summary

### Key Takeaways

1. **Temperature affects all enzymes** - Every process has cardinal temperatures
2. **DIF controls plant height** - Positive DIF = tall; negative DIF = compact
3. **Root zone temperature** is often more critical than air temperature
4. **Vernalization** is cold requirement for flowering in some plants
5. **Chilling injury** occurs above freezing in sensitive crops
6. **Temperature integration** allows averaging over time

### Temperature Management Checklist

```
    ✓ Know your crop's optimal temperature range
    ✓ Monitor both air and root zone temperatures
    ✓ Manage DIF for growth habit control
    ✓ Understand vernalization needs (if any)
    ✓ Protect sensitive crops from chilling
    ✓ Have cooling strategy for heat events
    ✓ Consider temperature integration for efficiency
```
