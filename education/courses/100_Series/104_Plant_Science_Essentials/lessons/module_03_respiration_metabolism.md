# Module 3: Plant Respiration & Metabolism
## Course 104: Plant Science Essentials

## Introduction

While photosynthesis captures energy, respiration releases it. Every living cell in a plant—roots, stems, leaves, fruits—continuously respires 24/7 to power life processes. Understanding respiration helps you manage temperature, oxygen levels, and overall plant health for optimal growth.

---

## Learning Objectives

By the end of this module, you will be able to:
- Explain the purpose and overall equation of cellular respiration
- Describe the three stages of aerobic respiration
- Compare photosynthesis and respiration
- Understand why oxygen in the root zone matters
- Explain how temperature affects respiration and growth

## 1. What Is Cellular Respiration?

### The Energy Release Process

Respiration is essentially photosynthesis in reverse—it breaks down glucose to release stored energy.

```
              CELLULAR RESPIRATION

    C₆H₁₂O₆  +  6 O₂  ───────►  6 CO₂  +  6 H₂O  +  ENERGY (ATP)

    Glucose    Oxygen           Carbon   Water     36-38 ATP
                                Dioxide
```

### Key Distinctions

| Aspect | Photosynthesis | Respiration |
|--------|----------------|-------------|
| **Purpose** | Capture energy | Release energy |
| **Occurs in** | Chloroplasts | Mitochondria |
| **Requires** | Light | No light needed |
| **Timing** | Day only | 24/7 |
| **Uses** | CO₂, H₂O | Glucose, O₂ |
| **Produces** | Glucose, O₂ | CO₂, H₂O, ATP |
| **Plant parts** | Green tissues | ALL cells |

## 2. Why Plants Respire

### Energy Currency: ATP

ATP (adenosine triphosphate) is the "energy currency" of cells. Every energy-requiring process uses ATP.

```
    WHAT ATP POWERS IN PLANTS

    ┌─────────────────────────────────────────┐
    │                                         │
    │  GROWTH                                 │
    │  • Cell division                        │
    │  • Cell elongation                      │
    │  • Protein synthesis                    │
    │                                         │
    │  TRANSPORT                              │
    │  • Nutrient uptake (active transport)   │
    │  • Phloem loading                       │
    │  • Ion pumps                            │
    │                                         │
    │  MAINTENANCE                            │
    │  • Membrane repair                      │
    │  • Defense compounds                    │
    │  • Enzyme replacement                   │
    │                                         │
    │  REPRODUCTION                           │
    │  • Flower development                   │
    │  • Seed filling                         │
    │  • Fruit ripening                       │
    │                                         │
    └─────────────────────────────────────────┘
```

### Respiration Rates Vary by Tissue

| Plant Part | Respiration Rate | Why |
|------------|------------------|-----|
| Root tips | Very high | Active growth, nutrient uptake |
| Young leaves | High | Growing, high protein synthesis |
| Mature leaves | Moderate | Maintenance |
| Flowers | High | Reproduction, scent production |
| Fruits | Variable | Increases dramatically during ripening |
| Seeds (dry) | Very low | Dormant, minimal metabolism |

## 3. The Three Stages of Aerobic Respiration

### Overview

```
    CELLULAR RESPIRATION: THREE STAGES

    ┌─────────────────────────────────────────────────────┐
    │                                                     │
    │    GLUCOSE (C₆H₁₂O₆)                               │
    │         │                                          │
    │         ▼                                          │
    │    ╔═══════════════╗     Location: Cytoplasm       │
    │    ║  GLYCOLYSIS   ║     ATP produced: 2          │
    │    ╚═══════════════╝     NADH produced: 2         │
    │         │                                          │
    │         ▼                                          │
    │      Pyruvate (2x)                                │
    │         │                                          │
    │         ▼                                          │
    │    ╔═══════════════╗     Location: Mitochondria   │
    │    ║  KREBS CYCLE  ║     ATP produced: 2          │
    │    ╚═══════════════╝     NADH produced: 8         │
    │         │                FADH₂ produced: 2        │
    │         ▼                                          │
    │    ╔═══════════════════╗ Location: Mito membrane  │
    │    ║ ELECTRON TRANSPORT ║ ATP produced: 32-34    │
    │    ║      CHAIN         ║                        │
    │    ╚═══════════════════╝                         │
    │         │                                          │
    │         ▼                                          │
    │    TOTAL: 36-38 ATP per glucose                   │
    │                                                     │
    └─────────────────────────────────────────────────────┘
```

### Stage 1: Glycolysis

**Location:** Cytoplasm
**Meaning:** "Sugar splitting"

```
    GLYCOLYSIS OVERVIEW

    Glucose (6C)
         │
         ▼ (uses 2 ATP)
    [Intermediate steps]
         │
         ▼ (produces 4 ATP)
    2 × Pyruvate (3C each)

    NET ATP: 4 - 2 = 2 ATP
    NADH: 2 molecules
```

**Key Points:**
- Occurs in ALL cells (even without oxygen)
- No oxygen required
- Small energy payoff (2 ATP net)
- Produces 2 pyruvate molecules

### Stage 2: Krebs Cycle (Citric Acid Cycle)

**Location:** Mitochondrial matrix

```
    KREBS CYCLE SIMPLIFIED

              Pyruvate
                 │
                 ▼
            Acetyl-CoA (2C) + CO₂
                 │
         ┌───────┴───────┐
         │               │
         ▼               │
    ┌─────────┐         │
    │ Citrate │         │
    │  (6C)   │         │
    └────┬────┘         │
         │              │
         ▼              │
    [Cycle continues]   │
         │              │
         ▼              │
    CO₂ released        │
    NADH produced       │
    FADH₂ produced      │
    ATP produced        │
         │              │
         └──────────────┘
              (cycle repeats)
```

**Per Glucose (2 pyruvate):**
- 6 NADH
- 2 FADH₂
- 2 ATP
- 4 CO₂ (released as waste)

### Stage 3: Electron Transport Chain (ETC)

**Location:** Inner mitochondrial membrane

```
    ELECTRON TRANSPORT CHAIN

    NADH ─┐
          │
    FADH₂─┤───► [Complex I]──►[Complex II]──►[Complex III]──►[Complex IV]
          │           │             │              │              │
          │           ▼             ▼              ▼              ▼
          │        H⁺ pumped    H⁺ pumped      H⁺ pumped       O₂ → H₂O
          │                                                   (final acceptor)
          │
          │     H⁺ gradient drives ATP Synthase
          │              │
          │              ▼
          │         32-34 ATP
          │
    TOTAL FROM ETC: ~90% of ATP from respiration
```

**Key Points:**
- Requires oxygen (this is why we breathe)
- Oxygen is the final electron acceptor
- Produces most of the ATP
- Water is produced as byproduct

## 4. Aerobic vs. Anaerobic Respiration

### When Oxygen Is Present (Aerobic)

```
    AEROBIC RESPIRATION

    Glucose + O₂ ──► CO₂ + H₂O + 36-38 ATP

    EFFICIENT: Full energy extraction
```

### When Oxygen Is Absent (Anaerobic/Fermentation)

```
    ANAEROBIC RESPIRATION IN PLANTS

    Glucose ──► Ethanol + CO₂ + 2 ATP

    INEFFICIENT: Only ~5% of available energy
    TOXIC: Ethanol damages cells
```

### Why This Matters: Root Zone Oxygen

**Waterlogged Roots:**
1. Water fills air spaces in soil
2. Oxygen depleted
3. Roots switch to anaerobic respiration
4. Ethanol accumulates (toxic)
5. Root cells die
6. Nutrient uptake stops
7. Plant wilts despite being in water!

> **This is why drainage is critical and why hydroponic systems need aeration!**

### Oxygen Requirements by Growing System

| System | O₂ Challenge | Solution |
|--------|--------------|----------|
| Soil | Poor drainage | Perlite, drainage holes |
| DWC | Stagnant water | Air pumps, air stones |
| NFT | Thin film OK | Natural air exposure |
| Aeroponics | Excellent O₂ | Roots in air |
| Media-based | Can compact | Proper media choice |

## 5. The Carbon Balance: Photosynthesis vs. Respiration

### 24-Hour Carbon Economy

```
    DAILY CARBON BUDGET

    ┌─────────────────────────────────────────────────┐
    │                                                 │
    │  DAYTIME                                        │
    │  ─────────                                      │
    │  Photosynthesis: +100 units carbon (example)   │
    │  Respiration:    -30 units carbon              │
    │  NET:            +70 units carbon (GROWTH!)    │
    │                                                 │
    │  NIGHTTIME                                      │
    │  ──────────                                     │
    │  Photosynthesis:  0 units                      │
    │  Respiration:    -15 units carbon              │
    │  NET:            -15 units carbon (loss)       │
    │                                                 │
    │  24-HOUR NET:    +55 units carbon (GROWTH!)    │
    │                                                 │
    └─────────────────────────────────────────────────┘
```

### What Affects the Balance?

| Factor | Effect on Photosynthesis | Effect on Respiration |
|--------|-------------------------|----------------------|
| More light | Increases | No direct effect |
| Higher temp | Increases then decreases | Always increases |
| More CO₂ | Increases (to a point) | No effect |
| Night length | Decreases (less time) | Increases (more time) |

### Temperature: The Critical Factor

```
    TEMPERATURE EFFECTS ON PS AND RESPIRATION

    Rate
      │
      │         /\
      │        /  \    Photosynthesis
      │       /    \
      │      /      \
      │     /        ────────────────
      │    /              ___________
      │   /          ____/           Respiration
      │  /     _____/
      │ / ____/
      │/
      └─────────────────────────────────────
        5    15    25    35    45   Temperature (°C)
```

**Critical Insight:**
- Both increase with temperature
- But respiration keeps increasing while photosynthesis peaks and declines
- At high temperatures, respiration can exceed photosynthesis = NET LOSS

## 6. Day/Night Temperature Differential (DIF)

### The Concept

**DIF = Day Temperature - Night Temperature**

```
    DIF EXAMPLES

    Positive DIF: Day 25°C, Night 18°C → DIF = +7°C
    (Promotes stem elongation)

    Zero DIF: Day 22°C, Night 22°C → DIF = 0°C
    (Compact growth)

    Negative DIF: Day 18°C, Night 22°C → DIF = -4°C
    (Very compact, can stress plants)
```

### Effects of DIF

| DIF | Stem Growth | Plant Form | Energy Efficiency |
|-----|-------------|------------|-------------------|
| Large positive (+10°C) | Tall | Leggy | Lower (high night respiration) |
| Moderate positive (+5°C) | Normal | Balanced | Good |
| Zero (0°C) | Reduced | Compact | Variable |
| Negative (-5°C) | Minimal | Very compact | Best (low night respiration) |

### Practical Applications

**Warm Days, Cool Nights:**
- Maximizes photosynthesis during day
- Minimizes respiration at night
- More net carbon gain
- Standard recommendation: 5-8°C difference

**Cool Nights Save Money:**
- Lower heating costs
- Less respiration = more stored sugars
- Sweeter fruits and vegetables
- Better keeping quality

## 7. Respiration in Plant Products

### Post-Harvest Respiration

Harvested produce continues respiring, using stored sugars:

```
    POST-HARVEST RESPIRATION

    Stored Sugars + O₂ ──► CO₂ + H₂O + Heat + Quality Loss

    HIGH RESPIRATION = RAPID DETERIORATION
```

### Respiration Rates of Produce

| Category | Examples | Respiration Rate | Shelf Life |
|----------|----------|------------------|------------|
| Very high | Asparagus, broccoli, mushrooms | 60-180 | Days |
| High | Lettuce, spinach, strawberries | 20-60 | 1-2 weeks |
| Moderate | Tomatoes, peppers, cucumbers | 10-20 | 2-3 weeks |
| Low | Apples, carrots, cabbage | 5-10 | Weeks-months |
| Very low | Onions, potatoes, winter squash | <5 | Months |

### Controlling Post-Harvest Respiration

1. **Temperature:** Cold slows respiration (primary method)
2. **Oxygen:** Low O₂ environments slow respiration
3. **CO₂:** High CO₂ suppresses respiration
4. **Humidity:** High humidity prevents water loss

> **This is why refrigeration is so important for produce storage!**

## 8. Special Metabolic Processes

### Crassulacean Acid Metabolism (CAM) - Revisited

CAM plants have unusual respiration/photosynthesis timing:

```
    CAM METABOLISM (24-HOUR CYCLE)

    NIGHT:
    • Stomata open
    • CO₂ absorbed and stored as malic acid
    • Normal respiration continues

    DAY:
    • Stomata closed
    • Malic acid releases CO₂
    • Calvin cycle operates with stored CO₂
    • No water loss!
```

### Fruit Ripening: The Climacteric

Some fruits show a dramatic respiration spike during ripening:

```
    CLIMACTERIC RIPENING PATTERN

    Respiration
    Rate
        │              ╱╲
        │             ╱  ╲
        │            ╱    ╲
        │           ╱      ╲ Peak
        │          ╱        ╲
        │         ╱          ╲
        │        ╱            ╲____
        │_______╱
        └─────────────────────────────
          Mature    Ripe    Over-ripe
          Green
```

**Climacteric Fruits:** Tomatoes, bananas, apples, avocados
**Non-Climacteric:** Strawberries, grapes, citrus, peppers

> **Ethylene gas triggers climacteric ripening. One ripe banana can ripen all the fruit in a bowl!**

## 9. Optimizing the Respiration-Photosynthesis Balance

### Growing Recommendations

| Goal | Strategy |
|------|----------|
| Maximize growth | Optimize light AND temperature; cool nights |
| Compact plants | Reduce DIF, cooler temperatures |
| Sweet fruits | Cool nights before harvest |
| Extended harvest | Cool storage immediately |
| Root health | Ensure adequate oxygen |

### Common Mistakes

| Mistake | Problem | Solution |
|---------|---------|----------|
| Hot nights | Excessive respiration, reduced net growth | Cool greenhouse at night |
| Overwatering | Root oxygen deprivation | Improve drainage, let dry between |
| Poor ventilation | CO₂ depletion, O₂ buildup | Improve air circulation |
| Warm storage | Rapid quality loss | Refrigerate immediately |

## Summary

### Key Takeaways

1. **Respiration** breaks down sugars to release ATP for all life processes
2. **Three stages:** Glycolysis → Krebs Cycle → Electron Transport Chain
3. **Oxygen is essential** for efficient respiration; anaerobic produces toxins
4. **Temperature affects respiration** exponentially—cool nights preserve sugars
5. **DIF management** allows control of plant form and energy efficiency
6. **Post-harvest respiration** determines produce shelf life

### The Carbon Balance Equation

```
    DAILY NET CARBON = (Photosynthesis - Day Respiration) - Night Respiration

    GROWTH REQUIRES NET POSITIVE CARBON!
```
