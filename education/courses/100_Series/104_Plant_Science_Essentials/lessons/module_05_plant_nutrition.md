# Module 5: Plant Nutrition Fundamentals
## Course 104: Plant Science Essentials

---

## Introduction

Plants require 17 essential elements to complete their life cycle. Understanding plant nutrition allows you to diagnose problems, optimize growth, and prevent costly mistakes. This module provides the foundation for feeding your plants correctly in any growing system.

---

## Learning Objectives

By the end of this module, you will be able to:
- List the 17 essential plant nutrients and their categories
- Describe the function of each macronutrient and micronutrient
- Recognize visual symptoms of nutrient deficiencies and toxicities
- Understand nutrient mobility and its diagnostic significance
- Apply nutrition principles to different growing systems

---

## 1. The 17 Essential Elements

### What Makes an Element "Essential"?

An element is essential if:
1. The plant cannot complete its life cycle without it
2. No other element can substitute for it
3. The element is directly involved in plant metabolism

## 2. Primary Macronutrients: N-P-K

### Nitrogen (N) - The Growth Driver

**Functions:**
- Component of chlorophyll (green pigment)
- Essential for protein and amino acid synthesis
- Part of DNA and RNA
- Required for all growth processes

**Forms Absorbed:**
- Nitrate (NO₃⁻) - most common
- Ammonium (NH₄⁺) - acidifying

```
    NITROGEN DEFICIENCY

    VISUAL SYMPTOMS:
    ┌─────────────────────────────────────┐
    │                                     │
    │    Starts in OLDER leaves           │
    │    (N is mobile - moves to          │
    │     new growth)                     │
    │                                     │
    │    ┌───────────────────┐            │
    │    │  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │ New: Green │
    │    │  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │            │
    │    │  ░░░░░░░░░░░░░░░ │ Mid: Pale  │
    │    │  ░░░░░░░░░░░░░░░ │            │
    │    │  ░░░░░░░░░░░░░░░ │            │
    │    │   ▒▒▒▒▒▒▒▒▒▒▒▒▒  │ Old: Yellow│
    │    │    ▒▒▒▒▒▒▒▒▒▒▒   │            │
    │    └───────────────────┘            │
    │                                     │
    │    • General yellowing (chlorosis)  │
    │    • Stunted growth                 │
    │    • Early senescence               │
    │                                     │
    └─────────────────────────────────────┘
```

**Nitrogen Toxicity:**
- Dark green, lush foliage
- Weak, soft growth
- Delayed flowering
- Increased pest susceptibility

### Phosphorus (P) - Energy & Reproduction

**Functions:**
- ATP (energy transfer molecule)
- DNA and RNA structure
- Root development
- Flowering and fruiting
- Seed formation

**Form Absorbed:**
- Phosphate (H₂PO₄⁻ and HPO₄²⁻)

```
    PHOSPHORUS DEFICIENCY

    VISUAL SYMPTOMS:
    ┌─────────────────────────────────────┐
    │                                     │
    │    Starts in OLDER leaves           │
    │    (P is mobile)                    │
    │                                     │
    │    ┌───────────────────┐            │
    │    │  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │            │
    │    │  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │            │
    │    │  ░░░░░░░░░░░░░░░ │            │
    │    │  ████████████████ │ Purple/Red │
    │    │  ████████████████ │ stems &    │
    │    │   ██████████████  │ undersides │
    │    │    ████████████   │            │
    │    └───────────────────┘            │
    │                                     │
    │    • Purple/red coloration          │
    │    • Dark green (almost blue-green) │
    │    • Stunted growth                 │
    │    • Poor root development          │
    │    • Delayed maturity               │
    │                                     │
    └─────────────────────────────────────┘
```

**P Availability Note:** Phosphorus is easily "locked out" at high and low pH. Optimal pH: 6.0-7.0

### Potassium (K) - The Quality Element

**Functions:**
- Enzyme activation (60+ enzymes)
- Water regulation (stomatal control)
- Photosynthesis and sugar transport
- Disease resistance
- Fruit quality and flavor

**Form Absorbed:**
- Potassium ion (K⁺)

```
    POTASSIUM DEFICIENCY

    VISUAL SYMPTOMS:
    ┌─────────────────────────────────────┐
    │                                     │
    │    Starts in OLDER leaves           │
    │    (K is mobile)                    │
    │                                     │
    │    ┌───────────────────┐            │
    │    │  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │            │
    │    │  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │            │
    │    │  ░░░░░░░░░░░░░░░ │            │

## 3. Secondary Macronutrients

### Calcium (Ca) - The Builder

**Functions:**
- Cell wall structure (calcium pectate)
- Cell membrane stability
- Root tip growth
- Enzyme activation
- Signal transduction

**Form Absorbed:**
- Calcium ion (Ca²⁺)

```
    CALCIUM DEFICIENCY

    VISUAL SYMPTOMS:
    ┌─────────────────────────────────────┐
    │                                     │
    │    Starts in NEW leaves/tips        │
    │    (Ca is IMMOBILE)                 │
    │                                     │
    │    ┌───────────────────┐            │
    │    │   █████████████   │ Distorted, │
    │    │  ████▒▒▒▒▒████   │ curled,    │
    │    │  ███▒▒▒▒▒▒▒███   │ tip burn   │
    │    │  ░░░░░░░░░░░░░░░ │            │
    │    │  ░░░░░░░░░░░░░░░ │            │
    │    │   ░░░░░░░░░░░░   │ Old leaves │
    │    │    ░░░░░░░░░░    │ look OK    │
    │    └───────────────────┘            │
    │                                     │
    │    COMMON DISORDERS:                │
    │    • Blossom end rot (tomato)       │
    │    • Tip burn (lettuce)             │
    │    • Bitter pit (apple)             │
    │    • Hollow heart (potato)          │
    │                                     │
    └─────────────────────────────────────┘
```

**Critical Note:** Ca deficiency is often caused by poor transpiration (high humidity), not lack of Ca in solution.

## 4. Micronutrients

### The Essential Trace Elements

Despite being needed in tiny amounts, micronutrients are just as essential as macronutrients.

```
    MICRONUTRIENT SUMMARY

    ┌───────────┬────────────────────────┬─────────────────────────┐
    │ Nutrient  │ Key Functions          │ Deficiency Symptoms     │
    ├───────────┼────────────────────────┼─────────────────────────┤
    │ Iron (Fe) │ Chlorophyll synthesis  │ Interveinal chlorosis   │
    │           │ Electron transport     │ on NEW leaves           │
    ├───────────┼────────────────────────┼─────────────────────────┤
    │ Manganese │ Photosynthesis         │ Interveinal chlorosis   │
    │ (Mn)      │ Enzyme activation      │ with tan/gray spots     │
    ├───────────┼────────────────────────┼─────────────────────────┤
    │ Zinc (Zn) │ Auxin synthesis        │ Small leaves            │
    │           │ Enzyme activation      │ Short internodes        │
    ├───────────┼────────────────────────┼─────────────────────────┤
    │ Copper    │ Photosynthesis         │ Wilting, light green    │
    │ (Cu)      │ Lignin synthesis       │ Die-back of tips        │
    ├───────────┼────────────────────────┼─────────────────────────┤
    │ Boron (B) │ Cell wall formation    │ Hollow stems/petioles   │
    │           │ Sugar transport        │ Distorted new growth    │
    ├───────────┼────────────────────────┼─────────────────────────┤
    │ Molybdenum│ Nitrogen metabolism    │ Marginal scorch         │
    │ (Mo)      │ (nitrate reduction)    │ Cupped leaves           │
    ├───────────┼────────────────────────┼─────────────────────────┤
    │ Chlorine  │ Photosynthesis         │ Wilting, chlorosis      │
    │ (Cl)      │ Osmotic regulation     │ (rarely deficient)      │
    ├───────────┼────────────────────────┼─────────────────────────┤
    │ Nickel    │ Urease enzyme          │ Leaf tip necrosis       │
    │ (Ni)      │ Nitrogen metabolism    │ (very rare)             │
    └───────────┴────────────────────────┴─────────────────────────┘
```

### Iron Deficiency: Common Problem

Iron is frequently deficient despite being abundant in soil/solution because:
- Unavailable at high pH (>7.0)
- Easily oxidized to unusable form
- Poor translocation in plant

```
    IRON vs MAGNESIUM DEFICIENCY

    IRON (Immobile)              MAGNESIUM (Mobile)
    ─────────────────           ─────────────────────

    New leaves affected          Old leaves affected
         ┌───┐                        ┌───┐
         │░░░│ ← Chlorotic            │▓▓▓│ ← Green
         │░░░│                        │▓▓▓│
         ├───┤                        ├───┤
         │▓▓▓│ ← Green                │░░░│ ← Chlorotic
         │▓▓▓│                        │░░░│
         └───┘                        └───┘
```

## 5. Nutrient Mobility

### Why Mobility Matters

Mobile nutrients can be moved from old to new growth. Immobile nutrients cannot.

```
    NUTRIENT MOBILITY CHART

    ╔══════════════════════════════════════════════════════════╗
    ║                                                          ║
    ║   MOBILE                        IMMOBILE                 ║
    ║   (Deficiency in OLD leaves)    (Deficiency in NEW)      ║
    ║                                                          ║
    ║   • Nitrogen (N)                • Calcium (Ca)           ║
    ║   • Phosphorus (P)              • Sulfur (S)             ║
    ║   • Potassium (K)               • Iron (Fe)              ║
    ║   • Magnesium (Mg)              • Manganese (Mn)         ║
    ║   • Chlorine (Cl)               • Zinc (Zn)              ║
    ║   • Molybdenum (Mo)             • Copper (Cu)            ║
    ║                                 • Boron (B)              ║
    ║                                                          ║
    ╚══════════════════════════════════════════════════════════╝
```

### Diagnostic Flowchart

```
    DEFICIENCY DIAGNOSIS

                    Problem Observed
                          │
            ┌─────────────┴─────────────┐
            │                           │
        OLD leaves                  NEW leaves
        affected                    affected
            │                           │
      ┌─────┴─────┐               ┌─────┴─────┐
      │           │               │           │
    Uniform    Interveinal     Uniform    Interveinal
    yellowing  chlorosis       yellowing  chlorosis

## 6. Nutrient Interactions

### Antagonisms and Synergisms

Nutrients can help or hinder each other's uptake:

```
    NUTRIENT INTERACTIONS MAP

    ANTAGONISM (one blocks the other):
    ──────────────────────────────────

    High K ────► blocks ────► Ca, Mg uptake
    High Ca ───► blocks ────► K, Mg, Fe uptake
    High P ────► blocks ────► Zn, Fe uptake
    High N ────► blocks ────► K uptake (sometimes)
    High Mn ───► blocks ────► Fe uptake

    SYNERGISM (one helps the other):
    ────────────────────────────────

    N + P + K ─► balanced ─► optimal growth
    Ca + B ────► together ─► better uptake
    N + Mo ────► together ─► nitrogen metabolism
```

### Balance is Key

```
    THE IMPORTANCE OF BALANCE

    ┌─────────────────────────────────────────────────┐
    │                                                 │
    │   Excess of ONE nutrient can cause deficiency  │
    │   of ANOTHER even when both are present        │
    │                                                 │
    │   Example:                                      │
    │   • Too much potassium                          │
    │   • Calcium in solution: ADEQUATE               │
    │   • Calcium in plant: DEFICIENT                 │
    │   • Result: Tip burn, blossom end rot           │
    │                                                 │
    │   Solution: Don't just add more - BALANCE      │
    │                                                 │
    └─────────────────────────────────────────────────┘
```

## 7. Nutrition in Different Systems

### Soil vs. Hydroponic Nutrition

| Aspect | Soil | Hydroponics |
|--------|------|-------------|
| Buffer capacity | High | None |
| pH stability | Moderate | Must monitor |
| Nutrient availability | Variable | Controlled |
| Error forgiveness | High | Low |
| Response speed | Slow | Fast |
| Microbiology | Rich | Limited |

### Hydroponic Nutrient Management

```
    HYDROPONIC NUTRIENT SOLUTION TARGETS

    Parameter          Typical Range
    ────────────────────────────────────
    pH                 5.5 - 6.5
    EC (total)         1.2 - 2.5 mS/cm

    MACROS (ppm):
    N (as NO₃)         150 - 250
    P                  30 - 50
    K                  150 - 300
    Ca                 150 - 250
    Mg                 40 - 80
    S                  50 - 100

    MICROS (ppm):
    Fe                 2 - 5
    Mn                 0.5 - 2
    B                  0.2 - 0.5
    Zn                 0.2 - 0.5
    Cu                 0.05 - 0.1
    Mo                 0.05 - 0.1
```

### Aquaponic Nutrition

```
    AQUAPONIC NUTRIENT CONSIDERATIONS

    FROM FISH WASTE (usually adequate):
    ✓ Nitrogen
    ✓ Phosphorus (variable)
    ✓ Potassium (sometimes)

    OFTEN NEED SUPPLEMENTATION:
    ✗ Iron (chelated Fe)
    ✗ Calcium (if soft water)
    ✗ Potassium (potassium sulfate)

    pH CHALLENGE:
    • Plants prefer: 5.5 - 6.5
    • Fish prefer: 7.0 - 8.0
    • Bacteria prefer: 7.0 - 8.0
    • Compromise: 6.8 - 7.0
```

## 8. Practical Nutrition Guidelines

### Prevention is Better Than Cure

```
    NUTRITIONAL MANAGEMENT HIERARCHY

    ┌─────────────────────────────────────────────────┐
    │  1. START WITH BALANCED NUTRITION               │
    │     • Use complete fertilizers                  │
    │     • Follow proven recipes                     │
    │                                                 │
    │  2. MONITOR REGULARLY                           │
    │     • pH (daily in hydro)                       │
    │     • EC (daily in hydro)                       │
    │     • Visual inspection                         │
    │                                                 │
    │  3. RESPOND EARLY                               │
    │     • Catch problems when subtle                │
    │     • Don't wait for severe symptoms            │
    │                                                 │
    │  4. DIAGNOSE BEFORE TREATING                    │
    │     • Rule out other causes                     │
    │     • Use mobility to guide diagnosis           │
    │                                                 │
    │  5. CORRECT HOLISTICALLY                        │
    │     • Check pH first                            │
    │     • Consider interactions                     │
    │     • Avoid over-correction                     │
    └─────────────────────────────────────────────────┘
```

### Common Mistakes

| Mistake | Result | Prevention |
|---------|--------|------------|
| Ignoring pH | Lockout despite adequate nutrients | Monitor and adjust |
| Over-fertilizing | Salt stress, toxicity | Follow recommendations |
| Single-nutrient focus | Imbalance, induced deficiency | Use complete formulas |
| Mixing incompatibles | Precipitation, lockout | Use compatible products |
| Diagnosing too fast | Wrong treatment | Confirm before acting |

## Summary

### Key Takeaways

1. **17 essential elements** are required for plant life
2. **NPK** are primary macros; **Ca, Mg, S** are secondary
3. **Micronutrients** are needed in traces but equally essential
4. **Mobility** determines where symptoms appear (old vs. new leaves)
5. **Nutrient interactions** can cause deficiencies even when nutrients are present
6. **Balance and pH** are more important than quantity

### The Nutrition Troubleshooting Priority

```
    WHEN YOU SEE A PROBLEM:

    1. Check pH ──────────► Most common cause of "deficiency"
           │
    2. Check EC/strength ─► Too high or too low?
           │
    3. Location of symptoms► Old leaves = mobile nutrient
           │                 New leaves = immobile nutrient
    4. Pattern of symptoms ► Guide specific diagnosis
           │
    5. Correct cause ─────► Don't just add more nutrients
```
