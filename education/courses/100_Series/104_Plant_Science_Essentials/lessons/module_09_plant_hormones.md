# Module 9: Plant Hormones & Growth Regulators
## Course 104: Plant Science Essentials

---

## Introduction

Plants don't have nervous systems, but they do have sophisticated chemical communication. Plant hormones (phytohormones) coordinate growth, development, and responses to the environment. Understanding these chemical messengers helps you manipulate plant shape, flowering, rooting, and ripening.

---

## Learning Objectives

By the end of this module, you will be able to:
- Identify the major classes of plant hormones and their functions
- Explain hormone interactions and ratios
- Understand practical applications of plant growth regulators
- Apply hormonal principles to propagation and growth manipulation
- Recognize hormone-related plant responses

## 1. Overview of Plant Hormones

### The Five Classical Hormones

```
    THE FIVE CLASSICAL PLANT HORMONES

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │  AUXINS ─────────► Cell elongation, apical dominance       │
    │                    Root initiation, tropisms               │
    │                                                             │
    │  CYTOKININS ─────► Cell division, shoot growth             │
    │                    Delay senescence                        │
    │                                                             │
    │  GIBBERELLINS ───► Stem elongation, seed germination       │
    │                    Flowering, fruit development            │
    │                                                             │
    │  ABSCISIC ACID ──► Stress responses, dormancy              │
    │                    Stomatal closure, seed maturation       │
    │                                                             │
    │  ETHYLENE ───────► Fruit ripening, senescence              │
    │                    Abscission, stress responses            │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

### Additional Hormone Classes

| Hormone Class | Primary Functions |
|---------------|-------------------|
| **Brassinosteroids** | Cell division/elongation, stress tolerance |
| **Jasmonates** | Defense responses, wound response |
| **Salicylic acid** | Disease resistance, systemic acquired resistance |
| **Strigolactones** | Branching inhibition, mycorrhizal signaling |

## 2. Auxins

### The Master Growth Hormone

Auxins (primarily IAA - indole-3-acetic acid) were the first plant hormones discovered.

```
    AUXIN FUNCTIONS

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │  CELL ELONGATION                                           │
    │  ════════════════                                          │
    │  Auxin "loosens" cell walls, allowing expansion            │
    │                                                             │
    │       Low auxin          High auxin                        │
    │       ┌──────┐           ┌──────────────┐                  │
    │       │      │    →      │              │                  │
    │       │      │           │              │                  │
    │       └──────┘           └──────────────┘                  │
    │       No growth          Cell elongates                    │
    │                                                             │
    │  APICAL DOMINANCE                                          │
    │  ════════════════                                          │
    │  Auxin from shoot tip suppresses lateral bud growth        │
    │                                                             │
    │         Apical meristem                                    │
    │              │                                             │
    │              │ Auxin flows down                            │
    │              │                                             │
    │         ─────●─────  Suppressed lateral bud               │
    │              │                                             │
    │         ─────●─────  Suppressed lateral bud               │
    │              │                                             │
    │                                                             │
    │  ROOT INITIATION                                           │
    │  ═══════════════                                           │
    │  Auxin promotes root formation on cuttings                 │
    │  (Rooting hormone = synthetic auxin)                       │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

### Phototropism: Auxin in Action

```
    HOW PLANTS BEND TOWARD LIGHT

    Light from one side:

    1. LIGHT        2. AUXIN         3. RESULT
       │               REDISTRIBUTION
       │               ↓
       ▼           ┌───┐             ┌───┐
    ┌───┐          │ ░ │             │  ╱│
    │   │  →       │░░░│  →          │ ╱ │
    │   │          │░░░│             │╱  │
    │   │          │░░░│             │   │
    └─┬─┘          └─┬─┘             └─┬─┘

    Light causes auxin     More auxin on      Shaded side
    to move to             shaded side        elongates more

```

### Practical Applications of Auxins

| Application | Product/Method | Effect |
|-------------|---------------|--------|
| Rooting cuttings | IBA, NAA | Promotes root initiation |
| Prevent fruit drop | NAA, 2,4-D | Delays abscission |
| Herbicide | 2,4-D (high conc.) | Uncontrolled growth kills dicots |
| Tissue culture | IAA | Root formation in vitro |

## 3. Cytokinins

### The Cell Division Hormone

Cytokinins promote cell division and interact with auxin to control plant form.

```
    CYTOKININ FUNCTIONS

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │  CELL DIVISION (Cytokinesis)                               │
    │  ═══════════════════════════                               │
    │  Essential for mitosis completion                          │
    │                                                             │
    │  SHOOT PROMOTION                                           │
    │  ═══════════════                                           │
    │  Counteracts apical dominance                              │
    │  Promotes lateral bud growth                               │
    │                                                             │
    │  DELAY SENESCENCE                                          │
    │  ════════════════                                          │
    │  Keeps leaves green longer                                 │
    │  "Anti-aging" hormone                                      │
    │                                                             │
    │  CHLOROPLAST DEVELOPMENT                                   │
    │  ═══════════════════════                                   │
    │  Promotes chlorophyll synthesis                            │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

### The Auxin:Cytokinin Ratio

```
    AUXIN:CYTOKININ RATIO CONTROLS DEVELOPMENT

    In tissue culture, this ratio determines what grows:

                HIGH AUXIN              BALANCED           HIGH CYTOKININ
                LOW CYTOKININ                              LOW AUXIN

                    │                      │                    │
                    ▼                      ▼                    ▼

               ROOT FORMATION         CALLUS GROWTH        SHOOT FORMATION
                  ┌───┐                 ┌───┐                 ┌▲─┐
                  │   │                 │░░░│                 ││││
                  │   │                 │░░░│                 ││││
                 ╲│   │╱                │░░░│                 │   │
                  ╲   ╱                 └───┘                 └───┘
                   ╲ ╱
                    V

    Practical use:
    • Rooting: High auxin, low cytokinin
    • Multiplication: Balanced or high cytokinin
    • Shoot regeneration: High cytokinin
```

### Cytokinin Applications

| Application | Method | Result |
|-------------|--------|--------|
| Tissue culture | BA, kinetin | Shoot multiplication |
| Extend flower life | Cytokinin spray | Delayed senescence |
| Break dormancy | Cytokinin application | Lateral bud release |
| Prevent yellowing | Postharvest treatment | Longer shelf life |

## 4. Gibberellins

### The Elongation Hormone

Gibberellins (GAs) promote stem elongation, seed germination, and flowering.

```
    GIBBERELLIN EFFECTS

    WITHOUT GA                          WITH GA
    ══════════                          ═══════

    DWARF PLANT                         TALL PLANT
        ┌─┐                                ┌─┐
       ┌┘ └┐                              ┌┘ └┐
      ┌┘   └┐                            ┌┘   └┐
      │     │                             │     │
      │     │                             │     │
      │─────│                             │     │
      │     │                             │─────│
      │─────│                             │     │
      └──┬──┘                             │     │
         │                                │─────│
     ════╧════                            │     │
                                          │─────│
    Short internodes                      │     │
                                          │     │
                                          │─────│
                                          │     │
                                          └──┬──┘
                                             │
                                         ════╧════

                                      Long internodes
```

### Key Gibberellin Functions

```
    GIBBERELLIN ROLES

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │  STEM ELONGATION                                           │
    │  ═══════════════                                           │
    │  Internode extension                                       │
    │  Overcomes genetic dwarfism                                │
    │                                                             │
    │  SEED GERMINATION                                          │
    │  ════════════════                                          │
    │  Triggers amylase production in seeds                      │
    │  Breaks seed dormancy                                      │
    │                                                             │
    │  FLOWERING                                                 │
    │  ════════                                                  │
    │  Bolting in rosette plants                                 │
    │  Replaces cold requirement in some plants                  │
    │                                                             │
    │  FRUIT DEVELOPMENT                                         │
    │  ═════════════════                                         │
    │  Seedless fruit production                                 │
    │  Increases berry size (grapes)                             │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

### Gibberellin Applications

| Application | Crop | Effect |
|-------------|------|--------|
| Grape berry sizing | Grapes | Larger, elongated berries |
| Seedless fruit | Citrus, grapes | Parthenocarpy |
| Malt production | Barley | Faster germination |
| Break dormancy | Seeds, bulbs | Uniform sprouting |
| Height increase | Celery | Longer petioles |

### Gibberellin Inhibitors (Growth Retardants)

Anti-gibberellin compounds create compact plants:

| Compound | Trade Name | Use |
|----------|------------|-----|
| Paclobutrazol | Bonzi, Piccolo | Potted plants |
| Chlormequat | Cycocel | Wheat lodging prevention |
| Daminozide | B-Nine | Ornamentals |
| Ancymidol | A-Rest | Greenhouse crops |

### The Stress Hormone

ABA accumulates during stress and triggers protective responses.

    │  STOMATAL CLOSURE                                          │

    │                                                             │
    │    Water stress → ABA increases → Stomata close            │
    │                                                             │
    │    ┌─────────┐         ┌───────┐                           │
    │   ╱    ○     ╲   →    │  ─○─  │                           │
    │  │     ○     │        │       │                           │
    │   ╲    ○     ╱        │       │                           │
    │    └─────────┘         └───────┘                           │
    │     Open stomata       Closed stomata                      │
    │                                                             │
    │  DORMANCY MAINTENANCE                                      │
    │  ════════════════════                                      │

## 6. Ethylene

### The Ripening Hormone

Ethylene is unique—it's a gas! Small amounts have powerful effects.

```
    ETHYLENE FUNCTIONS

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │  FRUIT RIPENING                                            │
    │  ══════════════                                            │
    │                                                             │
    │  Climacteric fruits:                                       │
    │  Green → Yellow/Red (color change)                         │
    │  Hard → Soft (texture change)                              │
    │  Starchy → Sweet (sugar increase)                          │
    │  Little aroma → Fragrant (volatile production)             │
    │                                                             │
    │  ABSCISSION (Leaf/Fruit Drop)                              │
    │  ════════════════════════════                              │
    │  Triggers separation layer formation                       │
    │  Allows clean break from plant                             │
    │                                                             │
    │  SENESCENCE                                                │
    │  ══════════                                                │
    │  Accelerates aging                                         │
    │  Triggers programmed cell death                            │
    │                                                             │
    │  "TRIPLE RESPONSE" (in darkness)                           │
    │  ═══════════════════════════════                           │
    │  • Shortened, thickened stem                               │
    │  • Exaggerated hook                                        │
    │  • Horizontal growth                                       │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

### Climacteric vs. Non-Climacteric Fruits

```
    FRUIT RIPENING PATTERNS

    Respiration
    Rate
        │              CLIMACTERIC
        │                 ╱╲
        │                ╱  ╲
        │               ╱    ╲
        │              ╱      ╲ Ethylene spike
        │             ╱        ╲
        │            ╱          ╲____
        │___________╱
        │
        │─────────────────────── NON-CLIMACTERIC
        │                        (No ethylene spike)
        │
        └─────────────────────────────────────────
               Mature            Ripe


    CLIMACTERIC:                NON-CLIMACTERIC:
    • Tomatoes                  • Strawberries
    • Bananas                   • Grapes
    • Apples                    • Citrus
    • Avocados                  • Peppers
    • Mangoes                   • Cucumbers
```

### Ethylene: Friend and Foe

```
    PRACTICAL ETHYLENE MANAGEMENT

    BENEFICIAL USES:
    ────────────────
    • Ripen bananas commercially
    • Degreen citrus (orange color)
    • Synchronize pineapple flowering
    • Induce flower in bromeliads

    PROBLEMS TO AVOID:
    ──────────────────
    • One ripe apple can ripen whole basket
    • Ethylene from exhaust damages plants
    • Stored produce deteriorates faster
    • Cut flowers senesce quickly

    PREVENTION STRATEGIES:
    ──────────────────────
    • Ventilation
    • Potassium permanganate sachets (absorbs ethylene)
    • 1-MCP (ethylene action inhibitor)
    • Separate ethylene-producing from sensitive items
```

### Hormone Balance Summary

| Process | Promoting Hormones | Inhibiting Hormones |
|---------|-------------------|---------------------|
| Stem elongation | GA, Auxin | ABA, Ethylene |

### Natural Methods to Manipulate Hormones

| Goal | Natural Method | Hormone Effect |
|------|---------------|----------------|
| More branching | Pinch/top growing tip | Removes auxin source |
| Promote rooting | Wound stem base | Auxin accumulates at wound |
| Delay ripening | Cold storage | Reduces ethylene sensitivity |
| Break dormancy | Cold stratification | Shifts ABA:GA ratio |
| Compact growth | Cool nights, high light | Multiple hormone effects |

## Summary

### Key Takeaways

1. **Five classical hormones** control plant growth and development
2. **Auxins** promote elongation and root formation; responsible for apical dominance
3. **Cytokinins** promote cell division and shoot growth
4. **Gibberellins** drive stem elongation and seed germination
5. **ABA** is the stress hormone, controlling stomata and dormancy
6. **Ethylene** triggers ripening and senescence
7. **Hormone ratios** are often more important than absolute amounts

### Hormone Quick Reference

```
    HORMONE SUMMARY TABLE

    Hormone      Primary Effect           Production Site
    ─────────────────────────────────────────────────────
    Auxin        Elongation, roots        Shoot tips
    Cytokinin    Cell division, shoots    Root tips
    Gibberellin  Stem elongation          Young leaves, roots
    ABA          Stress response          Leaves, roots
    Ethylene     Ripening, senescence     All tissues (stress)
```
