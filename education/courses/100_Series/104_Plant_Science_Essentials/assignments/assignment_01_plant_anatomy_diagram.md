# Assignment 1: Plant Anatomy Diagram

## Course 104: Plant Science Essentials

| **Attribute** | **Details** |
|--------------|-------------|
| **Type** | In-Class Activity |
| **Points** | 10 points |
| **Time** | 15-20 minutes |
| **LO** | LO1: Identify plant structures and explain functions |

## Objective

Create a detailed, labeled diagram of plant anatomy showing roots, stems, leaves, and their internal structures.

## Requirements

### Part 1: Root System (3 points)
- [ ] Root tip with zones (meristematic, elongation, maturation)
- [ ] Root hairs
- [ ] Vascular tissue (xylem and phloem)
- [ ] Labels for all structures

### Part 2: Stem Structure (3 points)
- [ ] Cross-section showing xylem, phloem, cambium
- [ ] Direction of water and nutrient flow (arrows)
- [ ] Labels for all tissues

### Part 3: Leaf Anatomy (3 points)
- [ ] Cross-section showing epidermis, mesophyll, stomata
- [ ] Chloroplasts in mesophyll cells
- [ ] Guard cells and stomatal opening
- [ ] Labels for all structures

### Part 4: Function Annotations (1 point)
Add brief notes explaining:
- Role of xylem vs. phloem
- Function of stomata
- Where photosynthesis occurs

## Grading

| Component | Points |
|-----------|--------|
| Root system accuracy | 3 |
| Stem structure accuracy | 3 |
| Leaf anatomy accuracy | 3 |
| Functional annotations | 1 |

## Tips

- Use Module 1 materials as reference
- Include arrows showing direction of transport
- Make labels clear and legible
- Add color to distinguish different tissues
