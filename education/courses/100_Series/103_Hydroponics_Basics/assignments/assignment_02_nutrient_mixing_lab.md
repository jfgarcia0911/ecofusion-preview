## Lab Procedure

### Part 1: Nutrient Solution Mixing (10 minutes)

**Scenario:** Mix a complete nutrient solution at 1.6 EC for lettuce production

**Given:**
- 5 gallons of water (dechlorinated tap water)
- 2-part nutrient system (A and B concentrates)
- Target EC: 1.6 mS/cm
- Target pH: 5.8-6.0

**Instructions:**

1. Fill container with 5 gallons of water
2. Measure and record starting EC and pH
3. Add Part A nutrients (slowly, while stirring)
4. Wait 1 minute, add Part B nutrients
5. Mix thoroughly for 2 minutes
6. Measure and record EC
7. Adjust pH to target range
8. Record final EC and pH

**Data Table:**

| Parameter | Starting | After Nutrients | After pH Adjustment | Target |
|-----------|----------|----------------|-------------------|--------|
| EC (mS/cm) | | | | 1.6 |
| pH | | | | 5.8-6.0 |
| Part A added (ml) | - | | - | |
| Part B added (ml) | - | | - | |
| pH adjuster (ml) | - | - | | |

---

### Part 2: Calculations (5 minutes)

**Question 1:** If the nutrient label says "Use 5ml per gallon to achieve EC 2.0," how much do you need for:
- 1 gallon at EC 1.6? _______ml
- 10 gallons at EC 1.0? _______ml

**Question 2:** Your solution is at pH 7.2 and you need pH 6.0. You add 2ml of pH Down per gallon. How much pH Down for 5 gallons? _______ml

---

### Part 3: Analysis Questions (5 minutes)

1. **Why must you add Part A before Part B?**

2. **What happens if EC is too high? Too low?**

3. **Why is pH adjustment done after adding nutrients?**

4. **What safety precautions are important when handling concentrated nutrients?**
