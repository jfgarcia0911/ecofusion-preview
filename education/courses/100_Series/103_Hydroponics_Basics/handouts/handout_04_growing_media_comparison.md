## Clay Pebbles (LECA / Hydroton)

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                    CLAY PEBBLES (LECA / HYDROTON)                          │
    │                                                                             │
    │   ┌───────────────────────────────────────────────────────────────────┐   │
    │   │                                                                   │   │
    │   │           ○ ○ ○ ○ ○ ○                                            │   │
    │   │          ○ ○ ○ ○ ○ ○ ○                                           │   │
    │   │           ○ ○ ○ ○ ○ ○        Expanded clay pellets               │   │
    │   │          ○ ○ ○ ○ ○ ○ ○       (8-16mm diameter)                   │   │
    │   │           ○ ○ ○ ○ ○ ○                                            │   │
    │   │                                                                   │   │
    │   └───────────────────────────────────────────────────────────────────┘   │
    │                                                                             │
    │   WHAT IS IT?                                                              │
    │   Lightweight clay balls heated to 1200°C, causing them to expand         │
    │   and become porous. LECA = Lightweight Expanded Clay Aggregate           │
    │                                                                             │
    │   ╔═══════════════════════════════════════════════════════════════════╗   │
    │   ║  PROS                          CONS                               ║   │
    │   ╠═══════════════════════════════════════════════════════════════════╣   │
    │   ║  ✓ Excellent drainage          ✗ Expensive initial cost          ║   │
    │   ║  ✓ Reusable many times         ✗ Heavy when wet                  ║   │
    │   ║  ✓ pH neutral (after rinse)    ✗ Can raise pH initially         ║   │
    │   ║  ✓ Won't compact               ✗ Low water retention             ║   │
    │   ║  ✓ Great aeration              ✗ Needs frequent watering         ║   │
    │   ║  ✓ Pest/disease resistant      ✗ Dust requires rinsing          ║   │
    │   ║  ✓ Environmentally friendly                                      ║   │
    │   ╚═══════════════════════════════════════════════════════════════════╝   │
    │                                                                             │
    │   BEST SYSTEMS: Flood & Drain, Dutch Buckets, Drip Systems               │
    │                                                                             │
    │   PREPARATION:                                                             │
    │   1. Rinse thoroughly to remove dust                                      │
    │   2. Soak in pH-adjusted water (5.5) for 24 hours                         │
    │   3. Rinse again before use                                               │
    │                                                                             │
    │   WATER HOLDING:  █░░░░░░░░░  LOW (10-15%)                                │

## Perlite

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                           PERLITE                                          │
    │                                                                             │
    │   ┌───────────────────────────────────────────────────────────────────┐   │
    │   │                                                                   │   │
    │   │          • • • • • • •                                           │   │
    │   │         • • • • • • • •      White volcanic glass               │   │
    │   │          • • • • • • •       Expanded by heating                │   │
    │   │         • • • • • • • •      Lightweight, porous                │   │
    │   │          • • • • • • •                                           │   │
    │   │                                                                   │   │
    │   └───────────────────────────────────────────────────────────────────┘   │
    │                                                                             │
    │   WHAT IS IT?                                                              │
    │   Volcanic glass heated to 1600°F, causing it to expand like popcorn.     │
    │   The white granules are lightweight and highly porous.                   │
    │                                                                             │
    │   ╔═══════════════════════════════════════════════════════════════════╗   │
    │   ║  PROS                          CONS                               ║   │
    │   ╠═══════════════════════════════════════════════════════════════════╣   │
    │   ║  ✓ Excellent aeration          ✗ FLOATS (problematic in flood)   ║   │
    │   ║  ✓ pH neutral (7.0-7.5)        ✗ Dusty (wet before handling)     ║   │
    │   ║  ✓ Sterile                     ✗ Low water retention alone       ║   │
    │   ║  ✓ Lightweight                 ✗ Can blow away outdoors          ║   │
    │   ║  ✓ Cheap                       ✗ Not reusable (breaks down)      ║   │
    │   ║  ✓ Great as an additive        ✗ Non-renewable resource          ║   │
    │   ╚═══════════════════════════════════════════════════════════════════╝   │
    │                                                                             │
    │   BEST SYSTEMS: Dutch Buckets, Mixed with Coco or Vermiculite            │
    │                                                                             │
    │   COMMON MIXES:                                                            │
    │   • 70% Coco / 30% Perlite (excellent all-purpose)                        │
    │   • 50% Perlite / 50% Vermiculite (good water/air balance)                │
    │   • 100% Perlite (Dutch bucket systems with frequent irrigation)          │
    │                                                                             │
    │   ⚠️  Always wet perlite before handling to avoid inhaling dust!          │
    │                                                                             │
    │   WATER HOLDING:  ███░░░░░░░  LOW-MEDIUM (surface only)                   │
    │   AIR SPACE:      ██████████  EXCELLENT                                   │
    │   DRAINAGE:       ██████████  EXCELLENT                                   │

    ║                                                                           ║
    ║   PREPARATION REMINDERS:                                                 ║
    ║   • Rockwool: MUST soak in pH 5.0-5.5 water for 24 hours                ║

    ║   • Coco Coir: Rinse if not pre-buffered, use coco-specific nutrients   ║
    ║   • Perlite: Wet before handling to avoid dust inhalation               ║
    ║                                                                           ║
    ║   GOLDEN RULE: Match your media to your watering frequency!              ║
    ║   Frequent watering → Use media with MORE drainage                       ║
    ║   Less frequent → Use media with MORE water retention                    ║
