## Understanding EC (Electrical Conductivity)

```
    ╔═══════════════════════════════════════════════════════════════════════════╗
    ║                                                                           ║
    ║                      WHAT IS EC?                                          ║
    ║                                                                           ║
    ║   EC (Electrical Conductivity) measures the total dissolved salts        ║
    ║   in your nutrient solution - essentially "nutrient strength"            ║
    ║                                                                           ║
    ║   ┌─────────────────────────────────────────────────────────────────┐    ║
    ║   │                                                                 │    ║
    ║   │   PURE WATER          NUTRIENT SOLUTION                        │    ║
    ║   │                                                                 │    ║
    ║   │   ┌─────────┐         ┌─────────┐                              │    ║
    ║   │   │         │         │ ⁺ ⁻ ⁺  │                              │    ║
    ║   │   │   💧    │         │  ⁻ ⁺ ⁻ │   Ions conduct electricity   │    ║
    ║   │   │         │         │ ⁺ ⁻ ⁺  │   More ions = higher EC      │    ║
    ║   │   └─────────┘         └─────────┘                              │    ║
    ║   │                                                                 │    ║
    ║   │   EC ≈ 0               EC = 1.0-3.0                            │    ║
    ║   │   No conductivity      Good conductivity                       │    ║
    ║   │                                                                 │    ║
    ║   └─────────────────────────────────────────────────────────────────┘    ║
    ║                                                                           ║
    ║   MEASUREMENT UNITS:                                                      ║
    ║   ══════════════════                                                      ║
    ║                                                                           ║
    ║   EC (mS/cm)  │  PPM (500 scale)  │  PPM (700 scale)  │  TDS            ║
    ║   ════════════════════════════════════════════════════════════════════   ║
    ║   0.5         │  250              │  350              │  Low            ║
    ║   1.0         │  500              │  700              │  Seedling       ║
    ║   1.5         │  750              │  1050             │  Light feed     ║
    ║   2.0         │  1000             │  1400             │  Medium         ║
    ║   2.5         │  1250             │  1750             │  Heavy feed     ║
    ║   3.0         │  1500             │  2100             │  Maximum        ║
    ║                                                                           ║
    ║   NOTE: PPM scales vary! Know your meter's conversion factor            ║
    ║   EC × 500 = PPM (US)    |    EC × 700 = PPM (EU/AU)                    ║
    ║                                                                           ║
    ╚═══════════════════════════════════════════════════════════════════════════╝
```

## Meter Care & Calibration

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                    METER MAINTENANCE                                       │
    │                                                                             │
    │   pH METER CARE:                                                           │
    │   ══════════════                                                           │
    │                                                                             │
    │   □ Calibrate weekly (or when readings seem off)                          │
    │   □ Use fresh calibration solutions (pH 4.0 and 7.0)                      │
    │   □ Store electrode in storage solution (NOT distilled water!)            │
    │   □ Rinse probe with distilled water between tests                        │
    │   □ Replace electrode annually or when slow to respond                    │
    │                                                                             │
    │   EC METER CARE:                                                           │
    │   ══════════════                                                           │
    │                                                                             │
    │   □ Calibrate monthly (use 1.413 or 2.76 mS/cm standard)                  │
    │   □ Rinse probe with distilled water after each use                       │
    │   □ Keep probes clean - mineral buildup affects readings                  │
    │   □ Store dry (unlike pH meters)                                          │
    │                                                                             │
    │   ─────────────────────────────────────────────────────────────────────   │
    │                                                                             │
    │   SIGNS YOUR METER NEEDS ATTENTION:                                       │
```
