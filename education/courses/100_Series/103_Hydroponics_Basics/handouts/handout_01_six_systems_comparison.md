## 1. Wick System

```
    ┌─────────────────────────────────────────────────────────────────────────┐
    │                                                                         │
    │                        WICK SYSTEM                                     │
    │                        ═══════════                                      │
    │                                                                         │
    │                           🌱                                            │
    │                          ┌─┴─┐                                          │
    │                          │   │ ◄── Growing container                   │
    │          ░░░░░░░░░░░░░░░░│░░░│░░░░░░░░░░░░░░░░ ◄── Growing media       │
    │                          │ │ │                                          │
    │                          │ │ │                                          │
    │                          │ │ │ ◄── Wick (cotton, nylon rope)           │
    │      ════════════════════│═│═│════════════════════                     │
    │      ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│▓│▓│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ ◄── Nutrient          │
    │      ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓     solution          │
    │      ════════════════════════════════════════════                      │
    │                                                                         │
    │   HOW IT WORKS:                                                        │
    │   Wicks passively draw nutrient solution up to roots via capillary     │
    │   action. No pumps, no electricity needed.                             │
    │                                                                         │
    │   BEST FOR:              NOT IDEAL FOR:                                │
    │   • Herbs                • Large/fruiting plants                       │
    │   • Lettuce              • Heavy feeders                               │
    │   • Beginners            • High production                             │
    │   • Low maintenance      • Hot environments                            │
    │                                                                         │
    │   PROS:                  CONS:                                         │
    │   ✓ Simplest system      ✗ Limited to small plants                    │
    │   ✓ No moving parts      ✗ Slow nutrient delivery                     │
    │   ✓ Very affordable      ✗ Not scalable                               │
    │   ✓ Silent operation     ✗ Prone to salt buildup                      │
    │                                                                         │
    └─────────────────────────────────────────────────────────────────────────┘
```

## 2. Deep Water Culture (DWC)

```
    ┌─────────────────────────────────────────────────────────────────────────┐
    │                                                                         │
    │                    DEEP WATER CULTURE (DWC)                            │
    │                    ═════════════════════════                            │
    │                                                                         │
    │         🌱          🌱          🌱          🌱                          │
    │        ┌┴┐         ┌┴┐         ┌┴┐         ┌┴┐                         │
    │   ═════╪═══════════╪═══════════╪═══════════╪═════ ◄── Lid with net pots│
    │        │           │           │           │                            │
    │   ▓▓▓▓▓│▓▓▓▓▓▓▓▓▓▓▓│▓▓▓▓▓▓▓▓▓▓▓│▓▓▓▓▓▓▓▓▓▓▓│▓▓▓▓▓                     │
    │   ▓▓▓▓▓│▓▓▓▓▓▓▓▓▓▓▓│▓▓▓▓▓▓▓▓▓▓▓│▓▓▓▓▓▓▓▓▓▓▓│▓▓▓▓▓ ◄── Nutrient        │
    │   ▓▓▓▓▓│▓▓▓▓▓▓▓▓▓▓▓│▓▓▓▓▓▓▓▓▓▓▓│▓▓▓▓▓▓▓▓▓▓▓│▓▓▓▓▓     solution        │
    │   ▓▓▓▓▓│▓▓▓▓▓▓▓▓▓▓▓│▓▓▓▓▓▓▓▓▓▓▓│▓▓▓▓▓▓▓▓▓▓▓│▓▓▓▓▓                     │
    │   ════════════○═══════════════════════════════════                     │
    │              ○○○ ◄── Air stone (CRITICAL!)                             │
    │   ════════════════════════════════════════════════                     │
    │                                                                         │
    │   HOW IT WORKS:                                                        │
    │   Roots hang directly in aerated nutrient solution. Air stones         │
    │   provide critical oxygen to prevent root drowning.                    │
    │                                                                         │
    │   BEST FOR:              NOT IDEAL FOR:                                │
    │   • Lettuce              • Very large plants                           │
    │   • Leafy greens         • Long-term crops                             │
    │   • Herbs                • Without power backup                        │
    │   • Fast growth          • Root vegetables                             │
    │                                                                         │
    │   PROS:                  CONS:                                         │
    │   ✓ Very fast growth     ✗ Requires constant aeration                 │
    │   ✓ Simple construction  ✗ Temperature fluctuations                   │
    │   ✓ Inexpensive          ✗ Root rot risk if pump fails               │
    │   ✓ Easy to monitor      ✗ Large plants can be unstable              │
    │                                                                         │
    └─────────────────────────────────────────────────────────────────────────┘
```

## 3. Ebb and Flow (Flood and Drain)

```
    ┌─────────────────────────────────────────────────────────────────────────┐
    │                                                                         │
    │                    EBB AND FLOW (FLOOD & DRAIN)                        │
    │                    ════════════════════════════                         │
    │                                                                         │
    │             🌱    🌱    🌱    🌱    🌱    🌱                            │
    │       ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ ◄── Growing media   │
    │       ░░░▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░ ◄── FLOOD level     │
    │       ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░                      │
    │       ═══════════════════════╤═══════════════════                      │
    │                              │                                          │
    │                         Overflow                                        │
    │                              │                                          │
    │       ┌──────────────────────┴──────────────────────┐                  │
    │       │                                             │                  │
    │       │           RESERVOIR                         │                  │
    │       │     ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓                │                  │
    │       │     ▓▓▓▓▓ (pump) ▓▓▓▓▓▓▓▓▓▓                │                  │
    │       └─────────────────────────────────────────────┘                  │
    │                                                                         │
    │   HOW IT WORKS:                                                        │
    │   Pump floods grow bed on timer, then solution drains back.            │
    │   Roots get nutrients during flood, oxygen during drain.               │
    │                                                                         │
    │   BEST FOR:              NOT IDEAL FOR:                                │
    │   • Almost any crop      • Very frequent harvests                      │
    │   • Larger plants        • Extremely fine-rooted crops                 │
    │   • Diverse gardens      • Beginners wanting simplicity                │
    │                                                                         │
    │   PROS:                  CONS:                                         │
    │   ✓ Very versatile       ✗ Timer/pump dependent                       │
    │   ✓ Good oxygenation     ✗ Media can be heavy                         │
    │   ✓ Supports large plants✗ More components                            │
    │   ✓ Forgiving system     ✗ Potential for clogging                     │
    │                                                                         │
    └─────────────────────────────────────────────────────────────────────────┘
```

## 4. Drip System

```
    ┌─────────────────────────────────────────────────────────────────────────┐
    │                                                                         │
    │                          DRIP SYSTEM                                   │
    │                          ═══════════                                    │
    │                                                                         │
    │                🌱         🌱         🌱         🌱                      │
    │                 │          │          │          │                      │
    │       ══════════│══════════│══════════│══════════│════════             │
    │             ◄───│──────────│──────────│──────────│───► Drip line       │
    │                 ↓          ↓          ↓          ↓                      │
    │       ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ ◄── Media      │
    │       ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░                 │
    │       ════════════════════════════════════════════════                 │
    │                            │                                            │
    │                        Drain back                                       │
    │                            │                                            │
    │       ┌────────────────────┴────────────────────┐                      │
    │       │              RESERVOIR                  │                      │
    │       │    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓           │                      │
    │       │    ▓▓▓▓ (pump) ▓▓▓▓▓▓▓▓▓▓▓▓           │                      │
    │       └─────────────────────────────────────────┘                      │
    │                                                                         │
    │   HOW IT WORKS:                                                        │
    │   Nutrient solution slowly drips onto growing media at each plant.     │
    │   Can be recovery (drains back) or non-recovery (waste to drain).     │
    │                                                                         │
    │   BEST FOR:              NOT IDEAL FOR:                                │
    │   • Commercial grows     • Very small operations                       │
    │   • Large plants         • Without maintenance schedule                │
    │   • Long-term crops      • Extremely hard water areas                  │
    │                                                                         │
    │   PROS:                  CONS:                                         │
    │   ✓ Highly scalable      ✗ Emitters can clog                          │
    │   ✓ Water efficient      ✗ Regular maintenance needed                 │
    │   ✓ Good for large plants✗ More complex than DWC                      │
    │   ✓ Flexible design      ✗ Uneven flow if not maintained              │
    │                                                                         │
    └─────────────────────────────────────────────────────────────────────────┘
```

## 5. Nutrient Film Technique (NFT)

```
    ┌─────────────────────────────────────────────────────────────────────────┐
    │                                                                         │
    │                    NUTRIENT FILM TECHNIQUE (NFT)                       │
    │                    ════════════════════════════                         │
    │                                                                         │
    │         🌱       🌱       🌱       🌱       🌱                          │
    │        ┌─┴─┐    ┌─┴─┐    ┌─┴─┐    ┌─┴─┐    ┌─┴─┐                       │
    │   ═════╪═══════╪═══════╪═══════╪═══════╪════════ ◄── Channel/gutter   │
    │   ────►│  ▓▓▓▓▓│▓▓▓▓▓▓▓│▓▓▓▓▓▓▓│▓▓▓▓▓▓▓│────────►                     │
    │        └───────┴───────┴───────┴───────┴────────┘    Thin film        │
    │         (Slight slope for flow)                      of solution      │
    │                            │                                            │
    │                            ▼                                            │
    │       ┌────────────────────────────────────────┐                       │
    │       │              RESERVOIR                 │                       │
    │       │    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓            │                       │
    │       │    ▓▓▓▓ (pump) ▓▓▓▓▓▓▓▓▓▓            │                       │
    │       └────────────────────────────────────────┘                       │
    │                                                                         │
    │   HOW IT WORKS:                                                        │
    │   A thin film of nutrient solution flows continuously over roots       │
    │   in sloped channels. Roots get both nutrients and oxygen.            │
    │                                                                         │
    │   BEST FOR:              NOT IDEAL FOR:                                │
    │   • Leafy greens         • Large plants (stability issues)            │
    │   • Herbs                • Root vegetables                             │
    │   • Commercial production• Areas without power backup                  │
    │   • Vertical farming                                                   │
    │                                                                         │
    │   PROS:                  CONS:                                         │
    │   ✓ Very water efficient ✗ Pump failure = rapid crop loss             │
    │   ✓ No media needed      ✗ Roots can block channels                   │
    │   ✓ Easy to clean        ✗ Larger plants unstable                     │
    │   ✓ High plant density   ✗ More technical to set up                   │
    │                                                                         │
    └─────────────────────────────────────────────────────────────────────────┘
```

## 6. Aeroponics

```
    ┌─────────────────────────────────────────────────────────────────────────┐
    │                                                                         │
    │                          AEROPONICS                                    │
    │                          ══════════                                     │
    │                                                                         │
    │         🌱       🌱       🌱       🌱       🌱                          │
    │        ┌─┴─┐    ┌─┴─┐    ┌─┴─┐    ┌─┴─┐    ┌─┴─┐                       │
    │   ═════╪═══════╪═══════╪═══════╪═══════╪════════                       │
    │   │    │       │       │       │       │       │                       │
    │   │    │  ~~~  │  ~~~  │  ~~~  │  ~~~  │       │ ◄── Mist zone        │
    │   │    └──┬────┴──┬────┴──┬────┴──┬────┘       │     (roots in air)   │
    │   │       │ ^^^^^ │ ^^^^^ │ ^^^^^ │           │                       │
    │   │       │       │       │       │           │                       │
    │   │       │ (mist nozzles spray roots)        │                       │
    │   │       │       │       │       │           │                       │
    │   └───────┴───────┴───────┴───────┴───────────┘                       │
    │                        │                                                │
    │       ┌────────────────┴────────────────────┐                          │
    │       │         HIGH-PRESSURE PUMP          │                          │
    │       │              RESERVOIR              │                          │
    │       └─────────────────────────────────────┘                          │
    │                                                                         │
    │   HOW IT WORKS:                                                        │
    │   Roots hang in air and are periodically misted with nutrient          │
    │   solution. Maximum oxygen exposure to roots.                          │
    │                                                                         │
    │   BEST FOR:              NOT IDEAL FOR:                                │
    │   • Maximum growth speed • Beginners                                   │
    │   • Research/commercial  • Budget-conscious                            │
    │   • Cloning/propagation  • Without technical skills                    │
    │                                                                         │
    │   PROS:                  CONS:                                         │
    │   ✓ Fastest growth rates ✗ Most complex system                        │
    │   ✓ Minimal water use    ✗ Nozzles clog easily                        │
    │   ✓ Maximum oxygen       ✗ Pump failure = rapid death                 │
    │   ✓ Easy root inspection ✗ Higher equipment cost                      │
    │                                                                         │
    └─────────────────────────────────────────────────────────────────────────┘
```

## System Selection Guide

```
    CHOOSING YOUR SYSTEM

    ┌─────────────────────────────────────────────────────────────────────────┐
    │                                                                         │
    │   "I'm a complete beginner"                                            │
    │   ─────────────────────────                                            │
    │   START WITH: Wick or DWC (Kratky method = no pump!)                  │
    │                                                                         │
    │   "I want to grow lots of lettuce/greens"                              │
    │   ─────────────────────────────────────────                            │
    │   BEST CHOICE: NFT or DWC Raft                                         │
    │                                                                         │
    │   "I want to grow tomatoes/peppers/large plants"                       │
    │   ─────────────────────────────────────────────                        │
    │   BEST CHOICE: Drip or Ebb & Flow                                      │
    │                                                                         │
    │   "I want variety - herbs, greens, AND vegetables"                     │
    │   ─────────────────────────────────────────────                        │
    │   BEST CHOICE: Ebb & Flow (most versatile)                             │
    │                                                                         │
    │   "I want maximum growth and don't mind complexity"                    │
    │   ─────────────────────────────────────────────────                    │
    │   BEST CHOICE: Aeroponics                                              │
    │                                                                         │
    │   "I'm going commercial/scalable"                                      │
    │   ───────────────────────────────                                      │
    │   BEST CHOICE: NFT (greens) or Drip (fruiting)                        │
    │                                                                         │
    └─────────────────────────────────────────────────────────────────────────┘
```
