## 1. Deep Water Culture (DWC)

### How It Works

Plants are suspended with roots hanging directly into a continuously oxygenated nutrient solution. Air pumps and air stones provide oxygen to prevent root drowning.

```
DEEP WATER CULTURE (DWC)
━━━━━━━━━━━━━━━━━━━━━━━

           🌱 Plant
            │
    ┌───────┴───────┐ ← Net pot with clay pebbles
════╪═══════════════╪════ ← Lid/Raft
    │               │
    │   ~~~~~~~~    │ ← Nutrient solution
    │   ~~~~~~~~    │
    │   ▒▒▒▒▒▒▒▒    │ ← Roots suspended in water
    │   ~~~~~~~~    │
    │      ○○○      │ ← Air stones (bubbling)
    └───────────────┘
           ↑
        Air pump
```

### Characteristics

| Aspect | Details |
|--------|---------|
| **Complexity** | Simple |
| **Cost** | Low |
| **Maintenance** | Low-Medium |
| **Best For** | Leafy greens, herbs, beginners |
| **Growth Rate** | Fast |
| **Power Dependency** | High (air pump critical) |

### Pros and Cons

| Pros | Cons |
|------|------|
| Simple to build and operate | Root rot if oxygen fails |
| Low cost entry | Large plants difficult |
| Fast growth rates | Temperature control needed |
| Great for beginners | Requires constant power |
| Easy to scale | pH/EC can fluctuate |

### Variations

- **Kratky Method**: Passive DWC with no air pump (air gap provides oxygen)
- **Recirculating DWC (RDWC)**: Multiple buckets connected with shared solution
- **Bubbleponics**: DWC with top-feed drip for seedlings

## 2. Nutrient Film Technique (NFT)

### How It Works

A thin film of nutrient solution flows continuously over the roots in shallow channels. Roots are partially exposed to air, partially in the nutrient film.

```
NUTRIENT FILM TECHNIQUE (NFT)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  🌱      🌱      🌱      🌱    ← Plants in net pots
   │       │       │       │
═══╪═══════╪═══════╪═══════╪═══ ← Channel lid
   │       │       │       │
   └───────┴───────┴───────┘    ← Roots in channel
        ~~~~~~~~~~~~→           ← Thin nutrient film (1-3mm)
                    │
               (slight slope)
                    ↓
              ┌─────────┐
              │Reservoir│ ←──── Pump returns solution
              └─────────┘
```

### Characteristics

| Aspect | Details |
|--------|---------|
| **Complexity** | Medium |
| **Cost** | Medium |
| **Maintenance** | Medium |
| **Best For** | Leafy greens, herbs, commercial operations |
| **Growth Rate** | Very Fast |
| **Power Dependency** | High (pump failure = rapid death) |

### Pros and Cons

| Pros | Cons |
|------|------|
| Excellent oxygenation | Pump failure is critical |
| Very efficient water use | Clogs from root growth |
| Easy plant access | Not for large/heavy plants |
| Scalable for commercial | Channels need cleaning |
| Consistent nutrient delivery | Precise slope required |

### Design Considerations

- **Slope**: 1:30 to 1:40 ratio (1" drop per 30-40" length)
- **Flow Rate**: 1-2 liters per minute per channel
- **Channel Length**: 10-15 feet maximum recommended
- **Film Depth**: 1-3mm ideal

## 3. Ebb and Flow (Flood and Drain)

### How It Works

A grow bed filled with media is periodically flooded with nutrient solution, then drained back to a reservoir. This cycle oxygenates roots and delivers nutrients.

```
EBB AND FLOW (FLOOD & DRAIN)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FLOOD CYCLE:                    DRAIN CYCLE:

🌱  🌱  🌱  🌱                   🌱  🌱  🌱  🌱
│   │   │   │                   │   │   │   │
▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ ← Media        ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
~~~~~~~~▓▓▓▓▓▓▓ ← Flooded      ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ ← Drained
~~~~~~~~▓▓▓▓▓▓▓                ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
═══════════════                ═══════════════
       ↑                              │
    PUMP ON                        PUMP OFF
       │                              ↓
  ┌─────────┐                   ┌─────────┐
  │Reservoir│                   │Reservoir│
  │  (low)  │                   │ (full)  │
  └─────────┘                   └─────────┘
```

### Characteristics

| Aspect | Details |
|--------|---------|
| **Complexity** | Medium |
| **Cost** | Medium |
| **Maintenance** | Medium |
| **Best For** | Variety of plants, aquaponics |
| **Growth Rate** | Good |
| **Power Dependency** | Medium (cycles on/off) |

### Pros and Cons

| Pros | Cons |
|------|------|
| Excellent root oxygenation | Timer/pump failure risks |
| Versatile plant selection | Media can be heavy |
| Good for larger plants | Requires more space |
| Familiar to soil growers | Cleaning media difficult |
| Works well with aquaponics | Root bound potential |

### Timing Guidelines

| Growth Stage | Flood Frequency | Duration |
|--------------|-----------------|----------|
| Seedlings | Every 4-6 hours | 10-15 min |
| Vegetative | Every 2-4 hours | 15 min |
| Flowering/Fruiting | Every 1-2 hours | 15 min |
| Hot conditions | More frequent | Same |

## 4. Drip Systems

### How It Works

Nutrient solution is pumped through tubing and dripped onto the base of each plant via emitters. Can be recovery (recirculating) or non-recovery (run-to-waste).

```
DRIP SYSTEM
━━━━━━━━━━━

        Main supply line
    ═══════════════════════
        │   │   │   │
        ↓   ↓   ↓   ↓    ← Drip emitters
        💧  💧  💧  💧
        🌱  🌱  🌱  🌱    ← Plants in containers
        ▓▓  ▓▓  ▓▓  ▓▓   ← Growing media
        │   │   │   │
        └───┴───┴───┘
              │
              ↓           ← Drainage collection
        ┌─────────┐
        │Reservoir│       ← Recovery system returns here
        └─────────┘
              │
           Pump
```

### Types of Drip Systems

| Type | Description | Use Case |
|------|-------------|----------|
| **Recovery** | Runoff returns to reservoir | Efficient, more monitoring |
| **Non-Recovery** | Runoff discarded | Less pH drift, more waste |
| **Top Drip** | Solution drips onto media surface | Most common |
| **Sub-Irrigation** | Solution enters from below | Less evaporation |

### Characteristics

| Aspect | Details |
|--------|---------|
| **Complexity** | Low-Medium |
| **Cost** | Low-Medium |
| **Maintenance** | Medium (clog prevention) |
| **Best For** | Large plants, commercial, tomatoes |
| **Growth Rate** | Good |
| **Power Dependency** | Medium |

### Pros and Cons

| Pros | Cons |
|------|------|
| Great for large plants | Emitters can clog |
| Scalable | pH drift in recovery systems |
| Individual plant control | More components to fail |
| Familiar technology | Uneven watering possible |
| Works with various media | Algae growth in lines |

## 5. Wick Systems

### How It Works

The simplest hydroponic system. Wicks (rope, felt) draw nutrient solution from a reservoir up to the growing media through capillary action. No pumps or electricity required.

```
WICK SYSTEM
━━━━━━━━━━━

           🌱 Plant
            │
    ┌───────┴───────┐
    │   ▓▓▓▓▓▓▓▓    │ ← Growing media
    │   ▓▓▓▓▓▓▓▓    │
    │      │││      │ ← Wicks
════╪══════│││══════╪════
    │      │││      │
    │   ~~~~~~~~    │ ← Nutrient solution
    │   ~~~~~~~~    │
    │   ~~~~~~~~    │
    └───────────────┘

    (No pump needed!)
```

### Characteristics

| Aspect | Details |
|--------|---------|
| **Complexity** | Very Simple |
| **Cost** | Very Low |
| **Maintenance** | Low |
| **Best For** | Small herbs, lettuce, beginners |
| **Growth Rate** | Slow |
| **Power Dependency** | None |

### Pros and Cons

| Pros | Cons |
|------|------|
| No electricity needed | Slow nutrient delivery |
| Very inexpensive | Not for large plants |
| Nearly fail-proof | Wicks can clog/fail |
| Great for beginners | Limited plant selection |
| Low maintenance | Slow growth rates |
| Perfect for small spaces | Oversaturation possible |

### Suitable Wick Materials

- Cotton rope
- Nylon rope
- Felt strips
- Polyester yarn
- Lantern wicks

## 6. Aeroponics

### How It Works

Plant roots are suspended in air inside a chamber and misted with nutrient solution at regular intervals. Provides maximum oxygenation and nutrient absorption.

```
AEROPONICS
━━━━━━━━━━

          🌱  🌱  🌱  🌱
           │   │   │   │
═══════════╪═══╪═══╪═══╪═════════ ← Lid with net pots
           │   │   │   │
    ┌──────┴───┴───┴───┴──────┐
    │                         │
    │    💨 mist  💨 mist     │ ← Mist/spray nozzles
    │       ╱╲      ╱╲        │
    │      ╱  ╲    ╱  ╲       │ ← Roots hanging in air
    │     ╱    ╲  ╱    ╲      │
    │         [nozzles]       │
    └─────────────────────────┘
              │
              ↓ Drainage
         ┌─────────┐
         │Reservoir│
         └─────────┘
              │
          High-pressure pump
```

### Types of Aeroponics

| Type | Pressure | Droplet Size | Use |
|------|----------|--------------|-----|
| **Low Pressure (LPA)** | <30 PSI | Large droplets | Hobby, simpler |
| **High Pressure (HPA)** | 60-90 PSI | Fine mist (50μm) | Commercial, NASA |

### Characteristics

| Aspect | Details |
|--------|---------|
| **Complexity** | High |
| **Cost** | High |
| **Maintenance** | High |
| **Best For** | Leafy greens, cloning, research |
| **Growth Rate** | Very Fast |
| **Power Dependency** | Very High (critical) |

### Pros and Cons

| Pros | Cons |
|------|------|
| Fastest growth possible | Pump failure is catastrophic |
| Maximum oxygenation | Complex equipment |
| Very water efficient | Expensive to build |
| Excellent for cloning | Nozzles clog easily |
| NASA-approved technology | Not for beginners |
| Clean, no media needed | Requires backup systems |

## System Comparison Chart

### Quick Reference

| System | Complexity | Cost | Growth Speed | Best For |
|--------|-----------|------|--------------|----------|
| **DWC** | Simple | Low | Fast | Beginners, leafy greens |
| **NFT** | Medium | Medium | Very Fast | Commercial, herbs |
| **Ebb & Flow** | Medium | Medium | Good | Variety, aquaponics |
| **Drip** | Medium | Low-Med | Good | Large plants, tomatoes |
| **Wick** | Simple | Very Low | Slow | Herbs, education |
| **Aeroponics** | Complex | High | Very Fast | Research, cloning |

### By Application

| Application | Recommended System |
|-------------|-------------------|
| First-time hydroponic grower | DWC or Wick |
| Commercial leafy greens | NFT or DWC |
| Tomatoes/peppers (home) | Drip or Ebb & Flow |
| Tomatoes/peppers (commercial) | Drip |
| Aquaponics integration | Ebb & Flow |
| Cloning/propagation | Aeroponics or DWC |
| Limited budget | Wick or simple DWC |
| No electricity | Wick or Kratky |
| Maximum yield | NFT or Aeroponics |

## Module Summary

### Key Takeaways

1. **Six main systems**: DWC, NFT, Ebb & Flow, Drip, Wick, Aeroponics
2. **DWC** is ideal for beginners - simple, low cost, effective
3. **NFT** offers fast growth but requires reliable power
4. **Ebb & Flow** provides versatility and good oxygenation
5. **Drip systems** work well for larger plants and commercial operations
6. **Wick systems** require no power but limit plant selection
7. **Aeroponics** delivers fastest growth but requires expertise
