## Lesson Content

### 3.1 Purpose of Growing Media

#### Why Use Growing Media in Hydroponics?

While hydroponics is soilless growing, most systems still use a **growing medium** (also called substrate) to provide:

```
FUNCTIONS OF GROWING MEDIA

┌─────────────────────────────────────────────────────────┐
│                                                         │
│  1. PHYSICAL SUPPORT                                    │
│     • Anchors plant roots                               │
│     • Keeps plants upright                              │
│                                                         │
│  2. MOISTURE RETENTION                                  │
│     • Holds water near roots                            │
│     • Prevents rapid drying                             │
│                                                         │
│  3. AERATION                                            │
│     • Provides oxygen to root zone                      │
│     • Prevents waterlogging                             │
│                                                         │
│  4. DRAINAGE                                            │
│     • Allows excess water to drain                      │
│     • Prevents root rot                                 │
│                                                         │
│  5. pH BUFFERING (some media)                           │
│     • Stabilizes pH fluctuations                        │
│     • Maintains root zone chemistry                     │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

#### Media vs. No Media Systems

| System Type | Media Required? | Function |
|-------------|-----------------|----------|
| **DWC/Kratky** | Optional/minimal | Small amount in net pot for support |
| **NFT** | Optional/minimal | None or minimal in net pot |
| **Ebb & Flow** | Yes | Full bed of media |
| **Drip Systems** | Yes | Containers filled with media |
| **Aeroponics** | No | Roots suspended in air |
| **Wick Systems** | Yes | Media wicks up nutrient solution |

### 3.2 Key Media Properties

#### Critical Characteristics

| Property | Description | Why It Matters |
|----------|-------------|----------------|
| **Water Retention** | Ability to hold moisture | Prevents plants from drying out |
| **Drainage** | How quickly water flows through | Prevents waterlogging and root rot |
| **Aeration** | Air space when saturated | Provides oxygen to roots |
| **pH Stability** | Doesn't alter solution pH | Maintains proper nutrient availability |
| **Inert** | Chemically inactive | Won't react with nutrients |
| **Sterile** | Free from pathogens | Reduces disease risk |
| **Reusability** | Can be cleaned and reused | Reduces long-term costs |
| **Weight** | Dry and wet weight | Affects structural requirements |

```
IDEAL GROWING MEDIA BALANCE

     Water Holding    ◄────►    Drainage/Aeration
     (30-40%)                   (60-70% air space)

     ▓▓▓▓▓▓▓▓                   ░░░░░░░░░░░░░░░░
     ▓ Water ▓                  ░   Air Pores  ░
     ▓▓▓▓▓▓▓▓                   ░░░░░░░░░░░░░░░░

     TOO MUCH WATER = Root Rot
     TOO MUCH AIR = Drought Stress
```

#### Media Performance Metrics

| Metric | Measurement | Ideal Range |
|--------|-------------|-------------|
| **Air-filled Porosity** | % air space when saturated | 20-30% |
| **Water-holding Capacity** | % water retained | 30-50% |
| **Bulk Density** | Weight per volume (g/cm³) | 0.1-0.6 |
| **pH** | Acidity/alkalinity | 5.5-7.0 (inert preferred) |
| **EC** | Electrical conductivity | Low (minimal dissolved solids) |

### 3.3 Inert Media Options

#### Expanded Clay Pebbles (LECA - Lightweight Expanded Clay Aggregate)

```
CLAY PEBBLES STRUCTURE

     ○○○○○○○○○○○○○○
    ○○○        ○○○
   ○  Porous   ○○
  ○   Interior  ○     Individual pebbles
   ○  (air pockets)   8-16mm diameter
    ○○        ○○      Round, uniform
     ○○○○○○○○○○

BENEFITS:
• Excellent drainage
• Good aeration
• Reusable indefinitely
• pH neutral
• Structurally stable
```

| Aspect | Details |
|--------|---------|
| **Water Retention** | Low-Medium |
| **Drainage** | Excellent |
| **Aeration** | Excellent |
| **pH** | Neutral (7.0) |
| **Reusable** | Yes (sterilize between crops) |
| **Cost** | Medium ($25-35 per 50L bag) |
| **Weight** | Medium-Light |
| **Best For** | DWC, Ebb & Flow, Drip systems |

**Pros:**
- Reusable for years with proper cleaning
- Excellent for larger plants
- Good oxygen availability
- No dust or breakdown

**Cons:**
- Higher initial cost
- Can be heavy when wet
- Requires pre-washing before use
- Can float in some systems

---

#### Perlite

Volcanic glass expanded by heat into white, lightweight particles.

```
PERLITE CHARACTERISTICS

    ░░  ░░░   ░░
   ░░░  ░░   ░░░   White, puffy particles
    ░░░░  ░░░░     2-5mm diameter
      ░░░░         Very lightweight
```

| Aspect | Details |
|--------|---------|
| **Water Retention** | Low |
| **Drainage** | Excellent |
| **Aeration** | Excellent |
| **pH** | Neutral (6.5-7.5) |
| **Reusable** | Limited (breaks down) |
| **Cost** | Low ($15-20 per 100L bag) |
| **Weight** | Very Light |
| **Best For** | Seed starting, mixes, propagation |

**Pros:**
- Inexpensive
- Extremely lightweight
- Excellent aeration
- Sterile when new

**Cons:**
- Dusty (use mask when handling)
- Not very reusable
- Can float
- Breaks down over time
- Requires washing

---

#### Vermiculite

Expanded mica mineral with excellent water-holding capacity.

| Aspect | Details |
|--------|---------|
| **Water Retention** | Very High |
| **Drainage** | Low-Medium |
| **Aeration** | Medium |
| **pH** | Neutral (6.0-7.5) |
| **Reusable** | No (compacts easily) |
| **Cost** | Low ($18-25 per 100L bag) |
| **Weight** | Light |
| **Best For** | Seed starting, mixes with perlite |

**Pros:**
- Excellent water retention
- Good for seed starting
- Lightweight
- pH neutral

**Cons:**
- Compacts over time
- Poor drainage alone
- Not reusable
- Must be mixed with other media

---

#### Growstone / Recycled Glass

Recycled glass processed into a lightweight, porous growing media.

| Aspect | Details |
|--------|---------|
| **Water Retention** | Medium |
| **Drainage** | Excellent |
| **Aeration** | Excellent |
| **pH** | Neutral |
| **Reusable** | Yes |
| **Cost** | Medium-High ($30-40 per 50L) |
| **Weight** | Light |
| **Best For** | Ebb & Flow, Drip, aquaponics |

**Pros:**
- Eco-friendly (recycled)
- Similar performance to clay pebbles
- Lighter than clay
- Reusable

**Cons:**
- More expensive
- Can have sharp edges
- Less widely available
- May break down over time

```

    Natural coconut husk fibers

    ≈  Fibrous  ≈

    Available as:
    • Bricks (compressed)
```

| Aspect | Details |
|--------|---------|
| **Water Retention** | High |
| **Drainage** | Good |
| **Aeration** | Good |
| **pH** | Slightly acidic (5.5-6.5) |
| **Reusable** | Limited (1-2 crops) |
| **Cost** | Low-Medium ($10-20 per 5kg brick) |
| **Weight** | Light (dry), Heavy (wet) |

- Buffering capacity

- Can be acidic
- Quality varies by source
- Requires Cal-Mag supplementation

### 3.5 Engineered Media

#### Rockwool (Stone Wool)

```
ROCKWOOL STRUCTURE

    ═══════════════════
    Spun mineral fibers
    ───────────────────
    Like insulation
    ═══════════════════

    Forms:
    • Cubes (1", 2", 3", 4")
    • Slabs (various sizes)
    • Blocks (6"x6" common)
    • Plugs (for seedlings)
```

| Aspect | Details |
|--------|---------|
| **Water Retention** | Very High |
| **Drainage** | Good (when not oversaturated) |
| **Aeration** | Good |
| **pH** | Alkaline initially (7.5-8.0) |
| **Reusable** | No |
| **Cost** | Medium ($20-40 for 50 cubes) |
| **Weight** | Medium |
| **Best For** | NFT, commercial operations, propagation |

**Pros:**
- Excellent for commercial production
- Uniform, consistent structure
- Good water/air balance
- Works well with drip/NFT
- Excellent for cloning

**Cons:**
- Not sustainable (manufacturing intensive)
- Must be pH-adjusted before use
- Not reusable
- Disposal issues
- Can cause skin irritation (use gloves)
- Not biodegradable

**Important:** Always pre-soak rockwool in pH 5.5 water for 24 hours before use!

### 3.6 Media-Free Systems

#### Systems That Use No Media

```
MEDIA-FREE HYDROPONIC SYSTEMS

1. KRATKY METHOD
   Plants in net pots
   Roots grow into air gap
   Minimal media for support only

2. DEEP WATER CULTURE (DWC)
   Net pots with small amount of media
   Roots suspend in solution
   Media only holds plant upright

3. NUTRIENT FILM TECHNIQUE (NFT)
   Bare roots in channels
   No media needed
   Roots form thick mat

4. AEROPONICS
   Roots suspended in air
   Zero media
   Misted with nutrients
```

#### Advantages of Media-Free

| Benefit | Impact |
|---------|--------|
| **Lower Cost** | No ongoing media purchases |
| **Reduced Weight** | Lighter system infrastructure |
| **Better Oxygenation** | Roots directly exposed to air/solution |
| **Faster Growth** | Maximum nutrient/oxygen availability |
| **No Media Disposal** | Environmentally friendly |
| **Cleaner System** | No media breakdown or clogging |

#### Challenges of Media-Free

| Challenge | Mitigation |
|-----------|------------|
| **Less Stability** | Secure plant support systems |
| **Rapid Drying** | Backup systems critical |
| **Limited to Certain Plants** | Best for smaller crops |
| **System Failure Impact** | Higher risk if pumps fail |

### 3.7 Media Selection Guide

#### By System Type

| System | Recommended Media | Alternative Options |
|--------|-------------------|---------------------|
| **DWC** | None or clay pebbles in net pot | Grodan cubes, net pot only |
| **NFT** | None or minimal in net pot | Rockwool cubes, Oasis cubes |
| **Ebb & Flow** | Clay pebbles, growstone | Coco coir, lava rock |
| **Drip (Recovery)** | Clay pebbles, growstone | Coco coir with perlite |
| **Drip (Non-Recovery)** | Coco coir, coco/perlite mix | Rockwool slabs |
| **Wick** | Vermiculite, perlite mix | Coco coir |
| **Aeroponics** | None | Neoprene collar only |

#### By Crop Type

```
MEDIA SELECTION BY CROP

LEAFY GREENS (lettuce, spinach, herbs)
├── NFT/DWC: None or rockwool cubes
├── Ebb & Flow: Clay pebbles
└── Drip: Coco coir

FRUITING PLANTS (tomatoes, peppers, cucumbers)
├── Drip: Coco coir, perlite/coco mix
├── Ebb & Flow: Clay pebbles, growstone
└── Dutch Buckets: Clay pebbles or coco

MICROGREENS
└── Coconut coir mats, capillary matting

SEEDLINGS/TRANSPLANTS
└── Rockwool cubes, Oasis cubes, coco pellets

ROOT VEGETABLES (if attempted)
└── Deep media beds: coco coir, clay pebbles
```

#### By Budget

| Budget Level | Recommendations |
|--------------|-----------------|
| **Low Budget** | Perlite/vermiculite mix, rice hulls |
| **Medium Budget** | Coco coir, basic clay pebbles |
| **Higher Budget** | Premium clay pebbles, growstone, rockwool |
| **Commercial** | Rockwool slabs, coco grow bags, premium clay |

### 3.9 Media Mixing Strategies

#### Creating Custom Blends

```
POPULAR MEDIA MIXES

1. PERLITE/VERMICULITE MIX
   50% Perlite (drainage)
   50% Vermiculite (water retention)
   = Balanced for most crops

2. COCO/PERLITE MIX
   70% Coco coir
   30% Perlite
   = Excellent for drip systems

3. SOILLESS MIX (Advanced)
   40% Coco coir
   30% Perlite
   20% Vermiculite
   10% Worm castings
   = Rich, well-draining mix

4. SEED STARTING MIX
   60% Vermiculite
   40% Perlite
   = Light, fluffy, excellent for germination
```

#### Why Mix Media?

| Benefit | Explanation |
|---------|-------------|
| **Balanced Properties** | Combine strengths of different media |
| **Custom Water Retention** | Adjust for climate/watering frequency |
| **Improved Drainage** | Prevent compaction and waterlogging |
| **Cost Optimization** | Use expensive media sparingly |
| **Better Root Development** | Varied pore sizes benefit roots |

### 3.10 Media Preparation and Maintenance

#### Pre-Use Preparation

```
MEDIA PREP CHECKLIST

ROCKWOOL
□ Soak in pH 5.5 water for 24 hours
□ Rinse until water runs clear
□ Drain before use

CLAY PEBBLES
□ Rinse thoroughly (dust removal)
□ Soak in clean water 6-12 hours
□ Rinse again until water is clear
□ Optional: pH stabilize in 5.5 solution

COCO COIR
□ Hydrate compressed blocks
□ Buffer with Cal-Mag solution
□ Rinse to remove excess salts
□ Check EC (should be <0.5)

PERLITE/VERMICULITE
□ Rinse to remove dust
□ Pre-moisten before use
□ Use mask during handling (dust!)
```

#### Between-Crop Sterilization

| Media | Sterilization Method |
|-------|---------------------|
| **Clay Pebbles** | 1) Rinse debris, 2) Soak in hydrogen peroxide solution (3-6%), 3) Rinse, dry |
| **Growstone** | Same as clay pebbles |
| **Coco Coir** | 1) Remove, 2) Can reuse once if sterilized with peroxide, 3) Compost after 2nd use |
| **Rockwool** | Not reusable - dispose |
| **Perlite** | Limited reuse - replace if broken down |

#### Signs Media Needs Replacement

- Algae growth throughout media
- Breakdown into fine particles
- Salt buildup (white crust)
- Persistent odors
- Poor drainage (compaction)
- Root disease history

#### Disposal Best Practices

```
END-OF-LIFE MEDIA DISPOSAL

REUSABLE MEDIA
├── Clean and sterilize
├── Store dry for next season
└── Replace after 3-5 years

ORGANIC MEDIA
├── Compost (coco, rice hulls)
├── Mix into garden soil
└── Municipal green waste

INORGANIC MEDIA
├── Perlite: can be added to garden
├── Rockwool: check local recycling
└── Avoid landfill when possible
```

### 3.12 Troubleshooting Media Issues

#### Common Problems and Solutions

| Problem | Cause | Solution |
|---------|-------|----------|
| **Algae Growth** | Light exposure + moisture | Cover media, reduce light |
| **Salt Buildup** | Hard water, overfertilization | Flush with clean water, adjust EC |
| **Fungus Gnats** | Organic media staying wet | Allow drying between watering, BTi |
| **Poor Drainage** | Compaction, wrong media | Mix in perlite, replace media |
| **Media Floating** | Lightweight media, water flow | Use heavier media, net covers |
| **pH Drift** | Media buffering | Pre-treat media, monitor closely |
| **Root Rot** | Waterlogged media | Improve drainage, add air stones |

## Vocabulary

| Term | Definition |
|------|------------|
| **Growing Medium** | Material used to support plant roots in place of soil |
