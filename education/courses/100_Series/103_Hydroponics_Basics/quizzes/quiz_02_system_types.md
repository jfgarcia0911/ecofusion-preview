## Answer Key

*(For instructor use only - remove before distributing to students)*

| Question | Answer | Explanation |
|----------|--------|-------------|
| 1 | C | In DWC, roots hang directly in oxygenated nutrient solution |
| 2 | B | Air pump/stones are critical for oxygenation to prevent root rot |
| 3 | B | NFT uses a thin film of 1-3mm flowing over roots |
| 4 | C | Wick systems use passive capillary action, no electricity needed |
| 5 | B | "Ebb" = drain/recede; the bed drains back to reservoir |
| 6 | C | Drip and Ebb & Flow support larger plants with media structure |
| 7 | False | Recovery systems RECIRCULATE solution back to reservoir |
| 8 | C | Aeroponics mists roots that hang in air |
| 9 | C | DWC and Wick systems are simplest for beginners |
| 10 | B | NFT roots can dry out/die within minutes of pump failure |
| 11 | C | Kratky is passive DWC with an air gap instead of air pump |
| 12 | C | Aeroponics provides fastest growth with roots suspended in air |

## System Quick Reference (Study Aid)

| System | Key Feature | Power Needed |
|--------|-------------|--------------|
| DWC | Roots in oxygenated water | Yes (air pump) |
| NFT | Thin film flowing over roots | Yes (water pump) |
| Ebb & Flow | Periodic flooding | Yes (pump + timer) |
| Drip | Dripped onto media | Yes (pump) |
| Wick | Capillary action | No |
| Aeroponics | Roots misted in air | Yes (high pressure pump) |
