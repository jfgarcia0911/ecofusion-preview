## The Golden Rules of Nutrient Mixing

```
┌────────────────────────────────────────────────────────────────┐
│                    5 GOLDEN MIXING RULES                        │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  1. ALWAYS add nutrients to water, never water to nutrients    │
│                                                                │
│  2. NEVER mix concentrates directly - always dilute first      │
│                                                                │
│  3. ADD Part A and Part B separately, mix between              │
│                                                                │
│  4. ADJUST pH LAST, after all nutrients are added              │
│                                                                │
│  5. MIX THOROUGHLY before testing EC/pH                        │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

## Mixing Order (CRITICAL!)

```
PROPER MIXING SEQUENCE
═══════════════════════

Step 1: WATER
         │
         ▼
    Fill reservoir with
    clean water
         │
Step 2: CALCIUM (if separate)
         │
         ▼
    Add CalMag or calcium
    products first
    MIX WELL
         │
Step 3: PART A
         │
         ▼
    Add Part A nutrients
    MIX WELL (2-3 minutes)
         │
Step 4: PART B
         │
         ▼
    Add Part B nutrients
    MIX WELL (2-3 minutes)
         │
Step 5: ADDITIVES
         │
         ▼
    Add any supplements
    (silica, beneficials)
    MIX WELL
         │
Step 6: pH ADJUSTMENT
         │
         ▼
    Test pH
    Adjust if needed
    MIX & RETEST
         │
         ▼
    ✓ DONE - Ready to use
```

## EC/TDS Target Ranges

### By Growth Stage

| Stage | EC (mS/cm) | TDS (ppm) | Notes |
|-------|------------|-----------|-------|
| **Seedlings** | 0.4-0.8 | 200-400 | Start weak |
| **Cuttings/Clones** | 0.5-1.0 | 250-500 | Gentle nutrients |
| **Vegetative (early)** | 0.8-1.2 | 400-600 | Ramp up slowly |
| **Vegetative (late)** | 1.2-2.0 | 600-1000 | Full strength |
| **Transition** | 1.4-2.0 | 700-1000 | Adjust N:P:K |
| **Flowering/Fruiting** | 1.8-2.4 | 900-1200 | Higher demand |
| **Late Bloom** | 1.6-2.2 | 800-1100 | Reduce slightly |
| **Flush** | 0.0-0.4 | 0-200 | Plain water |

## EC vs TDS Conversion

```
CONVERSION FORMULAS
═══════════════════

EC (mS/cm) × 500 = TDS (ppm) [Hanna Scale]
EC (mS/cm) × 640 = TDS (ppm) [Truncheon Scale]
EC (mS/cm) × 700 = TDS (ppm) [Eutech Scale]

EXAMPLE:
EC of 2.0 mS/cm =
  • 1000 ppm (×500)
  • 1280 ppm (×640)
  • 1400 ppm (×700)

⚠️ Know which scale your meter uses!
```

## pH Adjustment Guide

### Target pH by System

| System/Crop | Target pH |
|-------------|-----------|
| Most hydroponics | 5.5-6.5 |
| Leafy greens | 5.5-6.0 |
| Tomatoes | 5.8-6.3 |
| Peppers | 5.8-6.3 |
| Strawberries | 5.5-6.2 |
| Herbs | 5.5-6.5 |

### pH Adjustment Products

```
pH TOO HIGH (Alkaline)           pH TOO LOW (Acidic)
────────────────────            ───────────────────
Use pH DOWN products:           Use pH UP products:

• Phosphoric acid               • Potassium hydroxide
• Nitric acid                   • Potassium bicarbonate
• Sulfuric acid                 • Calcium carbonate
• Citric acid (organic)         • Potassium silicate

Start with small amounts!       Start with small amounts!
(1 mL per gallon, retest)       (1 mL per gallon, retest)
```

### pH Drift Troubleshooting

| Drift Direction | Possible Cause | Solution |
|-----------------|----------------|----------|
| Rising (up) | Calcium buildup | Clean system, check source water |
| Rising (up) | Algae growth | Block light from reservoir |
| Rising (up) | Low buffering | Add pH stabilizer |
| Falling (down) | Bacterial activity | Clean system, add beneficials |
| Falling (down) | Root decay | Check roots, increase oxygen |
| Falling (down) | Nutrient depletion | Top up with fresh solution |

## Common Nutrient Products

### Two-Part Systems

```
TWO-PART NUTRIENTS
══════════════════

┌─────────────────┐     ┌─────────────────┐
│     PART A      │     │     PART B      │
├─────────────────┤     ├─────────────────┤
│ • Calcium       │     │ • Phosphorus    │
│ • Nitrogen      │     │ • Potassium     │
│ • Some Micros   │     │ • Magnesium     │
│                 │     │ • Sulfur        │
│                 │     │ • Most Micros   │
└─────────────────┘     └─────────────────┘

⚠️ NEVER mix A & B concentrates together!
   Calcium + Phosphorus = Precipitate (lockout)
```

### Three-Part Systems

```
THREE-PART NUTRIENTS
════════════════════

┌──────────┐  ┌──────────┐  ┌──────────┐
│   GROW   │  │  MICRO   │  │  BLOOM   │
├──────────┤  ├──────────┤  ├──────────┤
│ High N   │  │ Calcium  │  │ High P   │
│ For veg  │  │ Iron     │  │ High K   │
│ growth   │  │ Micros   │  │ Flower   │
```

## Mixing Calculations

### Basic Dilution Formula

```
CALCULATING NUTRIENT AMOUNTS
════════════════════════════

Manufacturer Rate × Gallons = mL to add

EXAMPLE:
Label says: 5 mL per gallon
Reservoir: 20 gallons
Calculation: 5 mL × 20 = 100 mL of nutrient

For Part A/B (equal amounts):
100 mL Part A + 100 mL Part B = 20 gallons
```

## Reservoir Management

### Water Change Schedule

| System Type | Full Change | Top-Up |
|-------------|-------------|--------|
| Small DWC (<20 gal) | Weekly | As needed |
| Large DWC (>20 gal) | Every 2 weeks | 2-3× per week |
| NFT | Weekly | Daily |
| Recirculating Drip | Every 2 weeks | As needed |
| Ebb & Flow | Every 2 weeks | As needed |

### Top-Up Guidelines

```
TOPPING UP YOUR RESERVOIR
═════════════════════════

When water level drops due to plant uptake:

If EC is HIGH:  → Add plain water only
If EC is STABLE: → Add half-strength nutrients
If EC is LOW:   → Add full-strength nutrients

Always check EC before and after topping up!
```

## Troubleshooting Checklist

### Mixing Problems

| Problem | Likely Cause | Solution |
|---------|--------------|----------|
| Cloudy solution | Nutrients precipitated | Remix in correct order |
| White precipitate | Calcium + phosphorus mixed | Never mix A&B directly |
| pH won't stabilize | Poor water quality | Use RO water |
| EC keeps dropping | Plants feeding heavily | Top up with nutrients |
| EC keeps rising | Too much evaporation | Increase water changes |
| Slime in reservoir | Bacteria/algae | Clean, add H2O2, block light |
