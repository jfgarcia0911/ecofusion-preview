## DEEP WATER CULTURE (DWC)

```
┌─────────────────────────────────────────────────────────────────────┐
│                    DEEP WATER CULTURE (DWC)                         │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│    ┌─────────────────────────────────────────────────────┐         │
│    │  ◯ ◯ ◯ ◯ ◯ ◯ ◯ ◯ ◯   ← Net pots with plants        │         │
│    ├─────────────────────────────────────────────────────┤         │
│    │  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ ← Floating raft (styrofoam)  │         │
│    │  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ ← Nutrient solution   │         │
│    │  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~    (6-12" deep)       │         │
│    │  ○○○○○○○○○○○○○○○○○○○○○ ← Air stones                  │         │
│    └─────────────────────────────────────────────────────┘         │
│                     ↑                                               │
│              Air pump provides                                      │
│              dissolved oxygen                                       │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘

SPECIFICATIONS:
• Water depth: 6-12 inches
• pH: 5.5-6.5
• EC: 1.2-2.4 mS/cm
• DO minimum: 5 ppm

PROS                          CONS
──────────────────           ──────────────────
✓ Simple design              ✗ Heavy when filled
✓ Low cost                   ✗ Root disease risk
✓ Forgiving for beginners    ✗ Temperature sensitive
✓ Great for leafy greens     ✗ Not ideal for large plants
✓ Continuous nutrient access ✗ Requires aeration

BEST CROPS: Lettuce, basil, kale, bok choy, spinach
```

```
┌─────────────────────────────────────────────────────────────────────┐
│                   NUTRIENT FILM TECHNIQUE (NFT)                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│    Inlet ─────►  ┌═════════════════════════════════┐               │
│                  │ ◯   ◯   ◯   ◯   ◯   ◯   ◯   ◯ │ ← Plants       │
│                  │═══════════════════════════════│ ← Channel       │
│                  │ ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬│ ← Thin film     │
│                  └═══════════════════════════════════┘               │
│                                     │                               │
│                                     ▼                               │
│                            Return to reservoir                      │
│                                                                     │
│         Slope: 1-4%     Film depth: 1-3mm                          │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘

SPECIFICATIONS:
• Channel slope: 1:30 to 1:40 (1-3%)
• Film depth: 1-3mm
• Flow rate: 1-2 liters/minute per channel
• Channel width: 3-6 inches

PROS                          CONS
──────────────────           ──────────────────
✓ Efficient water use        ✗ Power dependent
✓ Lightweight channels       ✗ Root mat issues
✓ Excellent oxygenation      ✗ Pump failure = disaster
✓ Scalable                   ✗ Not for large plants
✓ Easy root inspection       ✗ Temperature fluctuations

BEST CROPS: Lettuce, herbs, strawberries, baby greens
```

## EBB AND FLOW (FLOOD AND DRAIN)

```
┌─────────────────────────────────────────────────────────────────────┐
│                    EBB AND FLOW SYSTEM                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│     FLOOD CYCLE                    DRAIN CYCLE                      │
│    ──────────────                 ─────────────                     │
│    ┌──────────────┐              ┌──────────────┐                  │
│    │ ◯ ◯ ◯ ◯ ◯ ◯ │              │ ◯ ◯ ◯ ◯ ◯ ◯ │                  │
│    │░░░░░░░░░░░░░░│ Media        │░░░░░░░░░░░░░░│                  │
│    │▓▓▓▓▓▓▓▓▓▓▓▓▓▓│ Flooded     │░░░░░░░░░░░░░░│ Drained         │
│    │▓▓▓▓▓▓▓▓▓▓▓▓▓▓│              │░░░░░░░░░░░░░░│                  │
│    └──────┬───────┘              └──────┬───────┘                  │
│           │                             │                           │
│           │ Pump ON                     │ Pump OFF                  │
│           ▼                             ▼                           │
│    ┌──────────────┐              ┌──────────────┐                  │
│    │   Reservoir  │              │   Reservoir  │                  │
│    │      ↓↓↓     │              │      ↑↑↑     │                  │
│    └──────────────┘              └──────────────┘                  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘

SPECIFICATIONS:
• Flood duration: 15-30 minutes
• Cycle frequency: 2-4x per day (light dependent)
• Flood depth: 2" below media surface
• Timer required: 15-minute intervals

PROS                          CONS
──────────────────           ──────────────────
✓ Versatile crops            ✗ Timer/pump dependent
✓ Good root oxygenation      ✗ Potential overflow issues
✓ Use various media          ✗ More components
✓ Can grow larger plants     ✗ Root bound possible
✓ Moderate cost              ✗ Media disposal

BEST CROPS: Peppers, tomatoes, cucumbers, herbs, lettuce
```

## DRIP SYSTEM

```
┌─────────────────────────────────────────────────────────────────────┐
│                        DRIP SYSTEM                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│    ┌─────────────────────────────────────────────────────┐         │
│    │      Drip emitters or stakes                        │         │
│    │         ↓     ↓     ↓     ↓     ↓     ↓            │         │
│    │       ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐         │         │
│    │       │ ◯ │ │ ◯ │ │ ◯ │ │ ◯ │ │ ◯ │ │ ◯ │         │         │
│    │       │░░░│ │░░░│ │░░░│ │░░░│ │░░░│ │░░░│         │         │
│    │       │░░░│ │░░░│ │░░░│ │░░░│ │░░░│ │░░░│         │         │
│    │       └─┬─┘ └─┬─┘ └─┬─┘ └─┬─┘ └─┬─┘ └─┬─┘         │         │
│    │         └─────┴─────┴─────┴─────┴─────┘            │         │
│    │                     │                               │         │
│    │              Drain to reservoir                     │         │
│    │              (Recovery) or waste                    │         │
│    │              (Non-recovery)                         │         │
│    └─────────────────────────────────────────────────────┘         │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘

TYPES:
• Recovery: Runoff returns to reservoir (recirculating)
• Non-Recovery: Runoff discarded (run-to-waste)

SPECIFICATIONS:
• Drip rate: 0.5-2 gallons/hour per emitter
• Run time: 5-15 minutes per cycle
• Cycles: 4-12 per day (media dependent)
• Runoff target: 10-20%

PROS                          CONS
──────────────────           ──────────────────
✓ Excellent for large plants ✗ Clogging issues
✓ Water efficient            ✗ More maintenance
✓ Precise delivery           ✗ Emitter variation
✓ Commercial standard        ✗ Cost of components
✓ Flexible design            ✗ Non-recovery wastes nutrients

BEST CROPS: Tomatoes, peppers, cucumbers, eggplant, cannabis
```

## AEROPONICS

```
┌─────────────────────────────────────────────────────────────────────┐
│                        AEROPONICS                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│    ┌───────────────────────────────────────────────────┐           │
│    │   ◯       ◯       ◯       ◯       ◯              │ ← Plants  │
│    │   │       │       │       │       │              │           │
│    │   ▼       ▼       ▼       ▼       ▼              │           │
│    │   ┆       ┆       ┆       ┆       ┆              │ ← Roots   │
│    │   ┆       ┆       ┆       ┆       ┆              │   in air  │
│    │   ┆       ┆       ┆       ┆       ┆              │           │
│    │   ·  ·  · · · · · · · · · · ·  ·  ·              │ ← Mist    │
│    │         ↑     ↑     ↑     ↑                      │           │
│    │        Misting nozzles (50-80 micron)            │           │
│    └───────────────────────────────────────────────────┘           │
│              │                                                      │
│    High-pressure pump (60-100 PSI)                                 │
│    or ultrasonic fogger                                            │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘

TYPES:
• High-Pressure Aeroponics (HPA): 60-100 PSI, 20-50 micron droplets
• Low-Pressure Aeroponics (LPA): Standard pump, larger droplets
• Fogponics: Ultrasonic fogger creates very fine mist

SPECIFICATIONS:
• Misting cycles: 3-5 seconds on, 3-5 minutes off
• Droplet size: 20-50 microns (HPA)
• Root zone humidity: 100%

PROS                          CONS
──────────────────           ──────────────────
✓ Fastest growth rates       ✗ Complex & expensive
✓ Lowest water usage         ✗ High failure risk
✓ Maximum oxygenation        ✗ Nozzle clogging
✓ No growing media           ✗ Requires expertise
✓ Easy root inspection       ✗ Timer precision critical

BEST CROPS: Lettuce, herbs, any crop (if managed well)
```

## QUICK DECISION GUIDE

### Choose DWC If:
- You're a beginner
- Growing leafy greens primarily
- Want low maintenance
- Budget is limited
- Space is not an issue

### Choose NFT If:
- Growing leafy greens commercially
- Want efficient water use
- Have reliable power
- Need lightweight system
- Can monitor regularly

### Choose Ebb & Flow If:
- Want crop variety
- Growing medium to large plants
- Have moderate budget
- Want flexibility
- Using various media types

### Choose Drip If:
- Growing fruiting crops commercially
- Need precise nutrient delivery
- Have higher budget
- Growing large plants
- Want industry-standard system

### Choose Wick If:
- Complete beginner
- Growing only herbs
- No power available
- Minimal budget
- Low commitment level

### Choose Aeroponics If:
- Advanced grower
- Maximum growth rate priority
- Have technical skills
- Budget is not limited
- Can monitor frequently

## SYSTEM SIZING FORMULAS

### DWC/Raft
```
Reservoir size = Plants × 1-2 gallons per plant
Example: 20 lettuce heads × 1.5 gal = 30 gallon reservoir
```

### NFT
```
Channel length = Plants per channel × spacing
Flow rate = 1-2 L/min per channel
Example: 10 plants × 8" = 80" channel, 1.5 L/min flow
```

### Ebb & Flow
```
Flood volume = Grow bed area × flood depth
Reservoir = Flood volume × 2 (safety margin)
Example: 4'×4' bed × 0.25' flood = 4 cu ft flood = 30 gal reservoir needed
```

### Drip
```
Emitters needed = Number of plants × 1-2 per plant
Flow rate = Emitters × 0.5-2 GPH per emitter
Example: 50 plants × 2 = 100 emitters × 1 GPH = 100 GPH capacity
```

## TROUBLESHOOTING BY SYSTEM

| Issue | DWC | NFT | Ebb&Flow | Drip |
|-------|-----|-----|----------|------|
| **Root rot** | Increase air, lower temp | Check flow rate | Reduce flood freq | Check drainage |
| **Wilting** | Check DO, temp | Check pump | Check timer | Clear emitters |
| **Slow growth** | Check pH, EC | Check nutrient | Check flood depth | Check drip rate |
| **Algae** | Light-proof reservoir | Cover channels | Cover media | Cover reservoir |
| **pH drift** | More frequent changes | Larger reservoir | Buffer addition | Larger reservoir |
