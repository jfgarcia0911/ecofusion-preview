### 5.2 Site Preparation (All Systems)

#### Step 1: Mark Your Location

```
SITE MARKING

Tools Needed:
├─ Tape measure
├─ Stakes or marking flags
├─ String or spray paint
└─ Carpenter's square

Process:
1. Measure and mark corners with stakes
2. Connect with string at ground level
3. Measure diagonals (should be equal if square)
4. Adjust until square
5. Mark final outline with spray paint or deeper stakes
```

**Checking Square:**
- Measure both diagonals
- If equal = square
- If not equal = adjust corners
- Use 3-4-5 triangle method for right angles

```
3-4-5 TRIANGLE METHOD

     5' (diagonal)
   ╱
  ╱
3'│    4'
  └────────

If diagonal measures 5', corner is 90°
Scale up: 6-8-10, 9-12-15, etc.
```

#### Step 2: Clear and Level

**Clearing:**
- Remove vegetation (grass, weeds)
- Clear rocks and debris
- Cut roots that interfere
- Create clean workspace

**Leveling:**

| Slope | Action |
|-------|--------|
| **Flat** | Ready to build |
| **Slight (< 2")** | Add soil to low spots or slight dig |
| **Moderate (2-6")** | Build up low side or terrace |
| **Steep (> 6")** | Terrace with retaining wall |

```
LEVELING CHECK

Place 4' level on ground
    ├─────────────┐
    │   LEVEL     │  If bubble centered = level
    └─────────────┤  If not, shim or dig to level
         ◐

Check multiple directions (N-S and E-W)
```

#### Step 3: Weed Barrier (Optional but Recommended)

**When to Use:**
- Raised beds (prevent weeds from below)
- Greenhouse floors
- Pathway areas

**Materials:**
- Cardboard (free, biodegradable)
- Landscape fabric ($15-30)
- Newspaper (several layers)

**How:**
1. Lay flat after clearing
2. Overlap seams 6-12"
3. Pin or weight down
4. Cut drainage slits if needed

### 5.3 Raised Bed Assembly

#### Step-by-Step Build Process

**Step 1: Cut Lumber (if needed)**

```
CUTTING LIST (4'x6'x12" bed)

├─ 2 pieces: 2"×12"×6' (long sides)
├─ 2 pieces: 2"×12"×4' (short sides - actually 45")
└─ 4 pieces: 2"×2"×18" or 4"×4"×18" (corner stakes)

Note: Short sides are 3" shorter (thickness of long sides)
```

**Measuring Twice:**
- Mark with pencil
- Use square to ensure straight line
- Measure again before cutting
- Cut conservatively (easier to trim than add)

**Step 2: Assemble First Corner**

```
CORNER ASSEMBLY

Side View:           Top View:

┌─────────┐         Long side
│ Long    │              │
│ side    │              │
├─────────┤         ─────┼───── Short side
│ Short   │              │
│ side    │         Corner stake
└─────────┘         (interior)

1. Place long side board on edge
2. Place short side at 90° angle
3. Insert corner stake inside corner
4. Pre-drill holes (prevent splitting)
5. Drive 3 screws through long into short end
6. Drive 2-3 screws through each board into stake
```

**Pro Tips:**
- Work on flat surface if possible
- Use clamps to hold while screwing
- Countersink screws slightly below surface
- Keep checking for square

**Step 3: Complete the Frame**

1. Add opposite corner (repeat corner assembly)
2. Attach remaining long side
3. Attach final short side and corners
4. Check diagonal measurements (should be equal)
5. Adjust if needed before final tightening

**Step 4: Position and Level**

```
POSITIONING FRAME

1. Place frame in prepared location
2. Check level in both directions
   ├─ Long axis
   └─ Short axis

3. Adjust level by:
   ├─ Digging down high spots
   └─ Adding soil under low spots

4. Re-check frequently

Frame should rest flat on ground
All four corners touching
No rocking or gaps
```

**Step 5: Secure in Place**

- Drive remaining corner stakes into ground (8-10" deep)
- Backfill around exterior slightly
- Walk around and check stability
- Make final adjustments

### 5.4 Hydroponic System Preparation

#### Kratky System Assembly

**Step 1: Prepare Containers**

```
CONTAINER PREPARATION

1. Clean containers thoroughly
   ├─ Wash with soap and water
   ├─ Rinse completely
   └─ Sanitize with dilute bleach (optional)

2. Mark cutting guide for lid
   ├─ Space net pots 6-8" apart
   ├─ Keep 2-3" from edges
   └─ Mark centers with marker

3. Drill or cut holes
   ├─ Use hole saw matching net pot size
   ├─ Go slow to prevent cracking
   ├─ Smooth edges with sandpaper
   └─ Clean away plastic shavings
```

**Net Pot Spacing:**

```
5-GALLON BUCKET (Top View)

       ┌────────┐
       │  ( )   │  ← 2" net pot (lettuce)
       │        │
       │  ( )   │  ← 2 plants per bucket
       │        │
       └────────┘

10-GALLON TOTE (Top View)

  ┌─────────────────┐
  │ ( ) ( ) ( ) ( ) │  ← 4-6 plants
  │                 │     depending on size
  │ ( ) ( ) ( ) ( ) │
  └─────────────────┘
```

**Step 2: Prepare Growing Medium**

**For Clay Pebbles:**
1. Rinse thoroughly (remove dust)
2. Soak in water 1-2 hours
3. Drain before use

**For Rockwool Cubes:**
1. Soak in pH 5.5 water overnight
2. Drain excess water

**Step 3: Start Seeds or Acquire Seedlings**

**Option A: Buy seedlings**
- Garden center transplants
- Remove from soil carefully
- Rinse roots gently
- Place in net pot with medium

**Option B: Start in rockwool**
- Soak cube, plant seed
- Germinate under humidity dome
- Transplant when roots show
- Place cube in net pot, surround with pebbles

### 5.5 Greenhouse Foundation

#### Foundation Options

| Type | Cost | Difficulty | Permanence |
|------|------|------------|------------|
| **Ground stakes** | $ | Easy | Temporary |
| **Gravel pad** | $$ | Medium | Semi-permanent |
| **Concrete blocks** | $$ | Medium | Permanent |
| **Poured concrete** | $$$ | Hard | Permanent |

**Recommended for First Build:** Gravel pad or concrete blocks

#### Gravel Pad Foundation (Most Popular)

```
GRAVEL PAD CROSS-SECTION

Greenhouse frame
       │
   ┌───▼────┐
   │ ░░░░░ │  ← 2-4" of gravel
   └────────┘
   ┌────────┐
   │▓▓▓▓▓▓▓│  ← Compacted soil
   └────────┘

Benefits:
├─ Good drainage
├─ Level surface
├─ Affordable
├─ Easy to adjust
└─ Doesn't require permit (usually)
```

**Step-by-Step:**

1. **Excavate:**
   - Dig 3-4" deep
   - 6" wider than greenhouse footprint
   - Remove roots and rocks
   - Compact soil base

2. **Edge (optional):**
   - Landscape timbers or stones
   - Keeps gravel contained
   - Neater appearance

3. **Fill with gravel:**
   - Pour 2-4" of pea gravel or crushed stone
   - Spread evenly with rake
   - Compact with tamper or plate compactor
   - Check level frequently

4. **Final leveling:**
   - Use long straight board and level
   - Add or remove gravel as needed
   - Critical: Foundation must be level for square structure

### 5.6 Common First-Day Challenges

#### Problem-Solving Guide

| Problem | Likely Cause | Solution |
|---------|--------------|----------|
| **Not square** | Incorrect measurements | Re-measure diagonals, adjust corners |
| **Not level** | Uneven ground | Dig high spots or shim low spots |
| **Gaps in joints** | Warped lumber | Clamp during assembly, add shims |
| **Splitting wood** | No pre-drilling | Always pre-drill near edges |
| **Screws stripping** | Wrong bit or over-torque | Use correct bit, reduce drill clutch setting |
| **Running out of time** | Underestimated | Secure what's done, resume next day |
| **Wrong measurements** | Cutting error | Measure twice, cut once; keep extra material |

#### When Things Go Wrong

**Mindset:**
- Mistakes are normal, especially on first build
- Most errors are fixable
- Don't be too hard on yourself
- Learn and adjust

**Decision Points:**
- Can I fix this now? → Try simple solution
- Do I need help? → Call knowledgeable friend
- Should I start over? → Rarely needed, usually can salvage
- Can I continue safely? → If no, stop and reassess

## Vocabulary

| Term | Definition |
|------|------------|
| **Square** | All corners at 90-degree angles |
| **Level** | Perfectly horizontal, not sloped |
| **Diagonal** | Corner-to-corner measurement |
| **Pre-drill** | Drilling pilot hole before screw |
| **Countersink** | Recessing screw head below surface |
| **Shim** | Thin material used to level or fill gaps |
| **Weed Barrier** | Material blocking weed growth from below |
