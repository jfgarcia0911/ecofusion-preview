## Lesson Content

### 4.1 Safety Fundamentals

#### Why Safety Matters

**Statistics:**
- 400,000+ DIY injuries annually in US
- Most common: Cuts, falls, eye injuries
- Most preventable with basic precautions

**Safety Mindset:**
- Slow is smooth, smooth is fast
- If you're tired, stop
- When in doubt, ask or research
- No project is worth an injury

```
SAFETY HIERARCHY

      ┌────────────────────┐
      │   ELIMINATE        │ ← Best: Design out hazards
      │   HAZARD           │
      └────────┬───────────┘
               │
      ┌────────▼───────────┐
      │   SUBSTITUTE       │ ← Use safer alternatives
      │   SAFER METHOD     │
      └────────┬───────────┘
               │
      ┌────────▼───────────┐
      │   ENGINEERING      │ ← Guards, safety features
      │   CONTROLS         │
      └────────┬───────────┘
               │
      ┌────────▼───────────┐
      │   PERSONAL         │ ← PPE: Last line of defense
      │   PROTECTIVE       │
      │   EQUIPMENT        │
      └────────────────────┘
```

#### Personal Protective Equipment (PPE)

**Essential PPE:**

| Item | When Needed | Why |
|------|-------------|-----|
| **Safety Glasses** | Always when cutting, drilling, grinding | Eye protection (most important!) |
| **Work Gloves** | Handling lumber, sharp edges | Cut/splinter protection |
| **Dust Mask** | Sawing, sanding, dusty work | Lung protection |
| **Hearing Protection** | Power tools, loud work | Prevent hearing damage |
| **Close-toed Shoes** | All building activities | Foot protection from drops |
| **Long Pants** | Always | Leg protection from cuts, sun |

**Cost:** Complete PPE kit = $30-50 (cheap insurance!)

```
PPE CHECKLIST

Before Starting Work:

□ Safety glasses on
□ Gloves (if handling rough materials)
□ Dust mask (if creating dust)
□ Ear protection (if using loud tools)
□ Proper footwear (no sandals!)
□ Long pants, secured long hair
□ No loose clothing/jewelry
□ Well-rested and alert
```

### 4.3 Power Tools

#### Cordless Drill/Driver

**The Single Most Useful Tool:**

```
DRILL/DRIVER FEATURES

Essential:
├─ 18-20V lithium battery
├─ Variable speed trigger
├─ Forward/reverse
├─ Adjustable clutch (torque)
├─ 1/2" chuck
└─ LED work light

Recommended Brands:
├─ DeWalt, Milwaukee (pro)
├─ Ryobi (best value)
└─ Makita, Bosch (quality)

Expect to pay: $80-150 for kit with battery & charger
```

**Drill Bits to Have:**
- Standard twist bit set (1/16" - 1/2")
- Countersink bit
- Screwdriver bits (Phillips, square drive)
- Hole saw set (if doing hydroponics)

**Safety:**
- Secure material being drilled
- Start slow, increase speed
- Never force - let tool do work
- Watch for bit binding
- Remove chuck key before starting

#### Circular Saw (Optional but Useful)

**When You Need It:**
- Cutting lumber to length
- Faster than hand saw
- Straighter cuts

**Safety Critical:**
- Use guide/straight edge
- Support material on both sides of cut
- Keep hands clear of blade path
- Unplug when changing blade
- Wear safety glasses and hearing protection

**Alternative:** Have lumber yard cut to length (often free for purchases)

### 4.4 Tool Safety Practices

#### General Safety Rules

```
UNIVERSAL TOOL SAFETY

1. READ THE MANUAL
   └─ Every tool is different

2. INSPECT BEFORE USE
   ├─ Check for damage
   ├─ Secure all adjustments
   └─ Verify power cord condition

3. USE RIGHT TOOL FOR JOB
   └─ Don't improvise/force

4. SECURE YOUR WORK
   ├─ Clamp or brace
   └─ Never hand-hold when cutting

5. MAINTAIN CLEAR WORKSPACE
   ├─ Remove tripping hazards
   ├─ Good lighting
   └─ Adequate space

6. UNPLUG TO ADJUST
   └─ Never adjust powered tool while connected

7. FOCUS
   ├─ No distractions
   ├─ No alcohol/drugs
   └─ Stop if tired
```

#### Common Hazards and Prevention

| Hazard | Risk | Prevention |
|--------|------|------------|
| **Kickback** | Tool jerks back violently | Secure work, proper grip, sharp blades |
| **Flying Debris** | Eye injury | Safety glasses, clear area |
| **Cuts** | Hand/finger injury | Keep hands clear, proper technique |
| **Falls** | Injury from height | Stable ladder, work at comfortable height |
| **Electrical Shock** | Electrocution | GFCI outlets, inspect cords, keep dry |
| **Repetitive Strain** | Long-term injury | Take breaks, vary tasks, proper form |

### 4.5 Site Safety

#### Worksite Setup

```
SAFE WORK AREA

Clear Zone (6-10 ft around work)
├─ No tripping hazards
├─ Remove obstacles
├─ Keep pets/children away
└─ Good footing (level, dry)

Tool Station
├─ Sturdy workbench or saw horses
├─ Power source nearby
├─ Tool organization
└─ First aid kit accessible

Material Storage
├─ Stack lumber flat
├─ Secure from tipping
├─ Off ground (keeps dry)
└─ Out of walkways
```

#### Weather Considerations

**Don't Work In:**
- Rain (electrical hazard, slippery)
- High winds (materials blow, debris flies)
- Extreme heat (heat exhaustion risk)
- Poor visibility (dusk, insufficient light)

**Ideal Conditions:**
- Dry, calm weather
- Moderate temperature
- Full daylight or excellent artificial light
- Comfortable working conditions

### 4.6 Tool Acquisition Strategy

#### Buy, Borrow, or Rent?

**BUY:**
- Use frequently (drill, tape measure, level)
- Basic hand tools (affordable)
- Long-term investment (will use again)
- Hard to borrow locally

**BORROW:**
- Use once or rarely (specialty tools)
- Friends/family have available
- Tool libraries in some communities
- Short-term need

**RENT:**
- Expensive specialty tools
- One-time or annual use
- Professional-grade for big job
- Want to try before buying

#### Tool Maintenance

**Basic Care:**

| Tool Type | Maintenance | Frequency |
|-----------|-------------|-----------|
| **Hand Tools** | Clean, oil moving parts | After each use |
| **Power Tools** | Clean dust, check cords | After each use |
| **Cutting Tools** | Sharpen as needed | When dull |
| **Batteries** | Charge, store properly | As needed |
| **All Tools** | Inspect for damage | Before each use |

**Storage:**
- Dry location (prevent rust)
- Organized (easy to find)
- Secure (especially power tools)
- Out of weather (prolong life)

### 4.7 Emergency Preparedness

#### First Aid Essentials

**On-Site First Aid Kit:**
- Adhesive bandages (various sizes)
- Gauze pads and tape
- Antiseptic wipes
- Antibiotic ointment
- Tweezers (splinters)
- Ice pack
- Pain reliever
- Emergency numbers

**For Serious Injury:**
1. Stop work immediately
2. Call 911 if needed
3. Apply first aid if trained
4. Get medical attention
5. Don't minimize injury

**Common Injuries:**
- **Minor Cuts**: Clean, apply pressure, bandage
- **Splinters**: Clean area, remove with tweezers, clean again
- **Eye Debris**: Flush with water, don't rub, seek help if doesn't clear
- **Back Strain**: Stop work, ice, rest, proper lifting technique next time
