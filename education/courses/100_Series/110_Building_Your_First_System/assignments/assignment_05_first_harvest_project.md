# Assignment 5: First Harvest Documentation Project

## Course 110: Building Your First System

**Type:** Final Project | **Points:** 15 | **Time:** 2-4 hours (over growing season)

## Project Overview
Document complete growing cycle from system startup to harvest, capturing lessons learned.

## Project Components

### 1. Build Documentation (4 pts)
- Complete photo documentation of build
- Step-by-step assembly notes
- Challenges encountered and solutions
- Final system specifications
- Total cost breakdown

### 2. Growing Log (4 pts)
Weekly entries documenting:
- Water quality parameters
- Plant growth observations
- Problems encountered
- Adjustments made
- Photos showing progress

### 3. Harvest Results (4 pts)
- Days to harvest
- Yield (weight/count)
- Quality assessment
- Cost per pound analysis
- Comparison to goals

### 4. Lessons Learned (3 pts)
- What worked well
- What would you change
- Recommendations for beginners
- Next steps/scaling plans

## Deliverable
Complete grow journal and harvest report (5-7 pages) with photos documenting entire journey from build to harvest

## Success Criteria
- System produces harvestable crop
- Complete documentation throughout process
- Thoughtful analysis of experience
- Clear lessons learned for future growers
