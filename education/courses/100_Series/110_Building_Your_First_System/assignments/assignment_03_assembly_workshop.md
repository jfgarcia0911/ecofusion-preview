# Assignment 3: Hands-On Assembly Workshop

## Course 110: Building Your First System

**Type:** In-Class | **Points:** 15 | **Time:** 30-45 min

## Objective
Assemble functional growing system following proper procedures.

## Assembly Steps

**Phase 1: Container Preparation (4 pts)**
- Clean and prepare reservoir
- Install drainage/overflow
- Test for leaks
- Set up support structure

**Phase 2: Plumbing Installation (4 pts)**
- Install pump
- Connect tubing/pipes
- Install aeration
- Test water flow

**Phase 3: Growing Area Setup (4 pts)**
- Install net pots or growing containers
- Add growing media
- Position correctly
- Plant seedlings

**Phase 4: System Check (3 pts)**
- Fill with water
- Test all components
- Check for leaks
- Verify proper operation

## Safety & Quality
- Follow safety procedures
- Clean workspace
- Proper tool use
- Professional assembly
