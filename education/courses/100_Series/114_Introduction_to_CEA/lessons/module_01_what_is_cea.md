### 1.1 Defining Controlled Environment Agriculture

#### What is CEA?

**Controlled Environment Agriculture (CEA)** is the practice of growing plants in an environment where key growing conditions are controlled or modified to optimize plant production.

```
CEA DEFINITION

┌──────────────────────────────────────────┐
│                                          │
│  CONTROLLED ───► Temperature             │
│                  Light                   │
│                  Humidity                │
│                  CO₂                     │
│                  Nutrients               │
│                  Water                   │
│                                          │
│  ENVIRONMENT ──► Protected structure     │
│                  (greenhouse, indoor)    │
│                                          │
│  AGRICULTURE ──► Commercial food         │
│                  production              │
│                                          │
└──────────────────────────────────────────┘
```

#### Key Characteristics

**All CEA systems share these features:**

1. **Environmental Control** - Active management of growing conditions
2. **Protected Structure** - Physical barrier from outdoor environment
3. **Resource Efficiency** - Optimized use of water, nutrients, space
4. **Year-Round Production** - Not limited by seasons
5. **Intensive Production** - Higher yields per square foot
6. **Technology Integration** - Sensors, automation, data management

```
CEA vs TRADITIONAL AGRICULTURE

TRADITIONAL FIELD                CEA FACILITY

│   ☀️ Weather   │              │ 🌡️ Climate     │

```

### 1.3 Major Types of CEA Systems

#### A. Greenhouses

**Definition:** Structures with transparent covering that allows sunlight penetration while providing environmental protection.

```
GREENHOUSE STRUCTURE

        Transparent covering
    ┌────────────────────────┐
   ╱                          ╲
  ╱   ☀️ Natural sunlight      ╲
 ╱                              ╲
├────────────────────────────────┤
│  🌱 🌱 🌱 🌱 🌱 🌱 🌱 🌱      │
│  Plants growing in beds/pots   │
│                                │
│  💧 Irrigation 🌡️ Climate     │
│     controls                   │
└────────────────────────────────┘

Types:
• Polyethylene (hoop houses)
• Glass (traditional)
• Polycarbonate
• High-tech climate controlled
```

**Key Features:**
- Primarily natural light + supplemental
- Range from simple to highly automated
- Most common CEA type globally
- $10-200+ per sq ft construction cost

#### B. Indoor Vertical Farms

**Definition:** Multi-level growing systems in warehouse-like buildings using artificial lighting.

```
VERTICAL FARM LAYOUT

Floor 1: Control room, packing
         ┌──────────────┐
Floor 2: │ 💡💡💡💡💡  │ LED lights
         │ 🌱🌱🌱🌱🌱  │ Growing level 4
         ├──────────────┤
Floor 3: │ 💡💡💡💡💡  │
         │ 🌱🌱🌱🌱🌱  │ Growing level 3
         ├──────────────┤
Floor 4: │ 💡💡💡💡💡  │
         │ 🌱🌱🌱🌱🌱  │ Growing level 2
         ├──────────────┤
Floor 5: │ 💡💡💡💡💡  │
         │ 🌱🌱🌱🌱🌱  │ Growing level 1
         └──────────────┘

100% artificial light
Complete climate control
Maximum space efficiency
```

**Key Features:**
- No natural light (100% LED)
- Stacked growing levels (4-12+ tiers)
- Complete environmental control
- Urban locations possible
- $100-300+ per sq ft construction cost

#### C. Container Farms

**Definition:** Repurposed shipping containers converted into self-contained growing environments.

```
SHIPPING CONTAINER FARM

┌────────────────────────────────────┐
│ 20' or 40' shipping container      │
│ ┌────────────────────────────────┐ │
│ │ 💡 LED    🌱🌱🌱  Racks       │ │
│ │ 💡 LED    🌱🌱🌱              │ │
│ │ 💡 LED    🌱🌱🌱              │ │
│ │ Climate   Hydro   Control     │ │
│ │ control   system  panel       │ │
│ └────────────────────────────────┘ │
└────────────────────────────────────┘

Portable, modular, scalable
```

**Key Features:**
- Portable and modular
- Pre-fabricated turnkey systems
- Suitable for remote locations
- Lower capital cost ($50K-150K per unit)

#### D. Plant Factories

**Definition:** Large-scale, fully automated indoor facilities with robotic systems.

```
PLANT FACTORY CONCEPT

        Automated systems
    ┌──────────────────────────┐
    │  Robots  🤖  Conveyors   │
    │  ▼       ▼       ▼       │
    │ 💡💡💡💡💡💡💡💡💡💡     │
    │ 🌱🌱🌱🌱🌱🌱🌱🌱🌱🌱     │
    │ Multi-tier cultivation    │
    │                          │
    │ Central AI control       │
    └──────────────────────────┘

Highest automation and efficiency
```

**Key Features:**
- Robotic planting, harvesting, monitoring
- AI-driven management
- Extreme precision
- Highest capital cost ($10M+)

#### E. Hybrid Systems

**Definition:** Combining multiple CEA approaches for optimal performance.

**Examples:**
- Greenhouse with vertical growing racks
- Natural + supplemental LED lighting
- Outdoor + greenhouse production (seasonal)
- Research + commercial production

## Vocabulary

| Term | Definition |
|------|------------|
| **CEA** | Controlled Environment Agriculture - growing plants with environmental control |
| **Greenhouse** | Transparent structure using primarily natural light |
| **Vertical Farm** | Multi-tier indoor facility with artificial lighting |
| **Plant Factory** | Fully automated indoor growing facility |
| **Container Farm** | Shipping container converted to growing space |
| **Hydroponics** | Growing plants without soil, using nutrient solutions |
| **HVAC** | Heating, Ventilation, and Air Conditioning systems |
| **Supplemental Lighting** | Artificial lights used to boost natural sunlight |
| **Climate Control** | Management of temperature, humidity, and airflow |
| **Food Miles** | Distance food travels from production to consumption |
