### 2.1 Growing Methods in CEA

#### Hydroponic Systems

```
HYDROPONIC SYSTEM TYPES

NUTRIENT FILM TECHNIQUE (NFT)
┌────────────────────────────┐
│ Thin film of nutrient      │
│ solution flows past roots  │
│ ▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼  │
│ 🌱  🌱  🌱  🌱  🌱        │
│ ════════════════════        │ Gutter
│ ~~~~~nutrient flow~~~~►     │
└────────────────────────────┘

DEEP WATER CULTURE (DWC)
┌────────────────────────────┐
│ 🌱  🌱  🌱  🌱  🌱        │
│ ┊┊┊┊┊┊┊┊┊┊┊┊┊┊┊┊┊┊┊┊┊  │ Net pots
│ ░░░░Nutrient solution░░░░░░│
│ 💨 💨 💨 Bubbles 💨 💨   │ Aeration
└────────────────────────────┘

DRIP SYSTEM
┌────────────────────────────┐
│    💧  💧  💧  💧         │ Drip emitters
│     ↓   ↓   ↓   ↓         │
│ 🌱  🌱  🌱  🌱  🌱        │
│ ▒▒▒Growing media▒▒▒▒▒▒▒   │
│         ↓ Drainage         │
└────────────────────────────┘

EBB & FLOW (Flood & Drain)
┌────────────────────────────┐
│ 🌱  🌱  🌱  🌱  🌱        │
│ ▒▒▒Growing media▒▒▒▒▒▒▒   │
│ ░░░Flood░with░solution░░░░ │ Periodic flooding
│ Drain ← ← ← ← back to tank│
└────────────────────────────┘
```

**Comparison:**

| System | Complexity | Cost | Water Use | Best For |
|--------|-----------|------|-----------|----------|
| **NFT** | Medium | $$ | Very low | Leafy greens, herbs |
| **DWC** | Low | $ | Low | Lettuce, leafy greens |
| **Drip** | Low | $ | Low | Tomatoes, cucumbers, wide variety |
| **Ebb & Flow** | Medium | $$ | Low | Potted plants, seedlings |
| **Aeroponics** | High | $$$ | Lowest | Research, high-value crops |

#### Aeroponics

```
AEROPONIC SYSTEM

┌────────────────────────────────┐
│  🌱    🌱    🌱    🌱    🌱    │ Plants suspended
│  ┊     ┊     ┊     ┊     ┊    │
│  ┊Roots hang in air chamber┊  │

Advantages:
• Maximum oxygen to roots
• Fastest growth rates
• Lowest water use

Challenges:
• System failures catastrophic
• Nozzle clogging
• High maintenance
```

#### Temperature Management

```
TEMPERATURE TARGETS BY CROP

Crop              Day Temp    Night Temp   DIF
─────────────────────────────────────────────────
Lettuce           65-70°F     60-65°F      5°F
Tomatoes          70-75°F     65-68°F      5-7°F
Cucumbers         75-80°F     68-72°F      5-8°F
Herbs (basil)     70-75°F     65-70°F      5°F
Strawberries      65-75°F     60-65°F      5-10°F
Microgreens       65-72°F     65-72°F      0°F

DIF = Day temperature minus Night temperature
(Affects stem elongation)
```

#### Humidity and VPD

```
VAPOR PRESSURE DEFICIT (VPD)

VPD = Saturation vapor pressure - Actual vapor pressure

┌─────────────────────────────────────┐
│  VPD ZONES                          │
│                                     │
│  TOO DRY (>1.2 kPa)                │
│  • Stress, slow growth              │
│  • Tip burn                         │
│  • Reduced transpiration            │
│                                     │
│  OPTIMAL (0.8-1.2 kPa)             │
│  • Active growth ✓                  │
│  • Good transpiration               │
│  • Nutrient uptake                  │
│                                     │
│  TOO WET (<0.4 kPa)                │
│  • Disease risk                     │
│  • Poor transpiration               │
│  • Slow drying                      │
└─────────────────────────────────────┘

Target RH by growth stage:
├─ Seedlings: 70-80%
├─ Vegetative: 60-70%
├─ Flowering: 50-60%
└─ Harvest: 45-55%
```

### 2.3 Lighting Technologies

#### Natural vs. Artificial Light

```
LIGHT SOURCE COMPARISON

NATURAL SUNLIGHT (Greenhouse)
Pros:
• Free energy
• Full spectrum
• High intensity (outdoors)
Cons:
• Variable (clouds, seasons)
• Day length changes
• Geographic limitations

SUPPLEMENTAL LED (Greenhouse)
Pros:
• Extends day length
• Boosts low-light periods
• Cost-effective hybrid
Cons:
• Additional energy cost
• Equipment investment

SOLE-SOURCE LED (Indoor/Vertical)
Pros:
• Complete control
• Optimized spectrum
• Location flexibility
Cons:
• High energy cost
• 100% artificial
• Significant investment
```

#### Automation Levels

```
AUTOMATION PROGRESSION

MANUAL (Level 0)
├─ Grower checks everything
├─ Manual adjustments
└─ Labor intensive

MONITORING (Level 1)
├─ Sensors collect data
├─ Alerts for out-of-range
├─ Manual response
└─ Basic data logging

AUTOMATED CONTROL (Level 2)
├─ Setpoint-based control
├─ Automatic adjustments
├─ Scheduled operations
└─ Grower oversight

OPTIMIZED CONTROL (Level 3)
├─ Dynamic setpoints
├─ Multi-variable optimization
├─ Predictive control
└─ Some autonomous decisions

AUTONOMOUS (Level 4)
├─ AI-driven management
├─ Self-optimizing
├─ Minimal human input
└─ Continuous learning

Most commercial CEA: Level 2-3
Cutting-edge: Level 3-4
```

### 2.5 Irrigation and Fertigation

#### Irrigation Systems

```
IRRIGATION METHODS

DRIP IRRIGATION
┌─────────────────────────────┐
│ Pump → Filter → Injector    │
│   ↓      ↓        ↓         │
│ Main line → Zone valves     │
│              ↓              │
│          Drip emitters      │
│          💧 💧 💧          │
│          🌱 🌱 🌱          │
└─────────────────────────────┘

Pros: Precise, efficient, scalable
Cons: Clogging risk, maintenance

OVERHEAD MISTING/FOGGING
Pros: Humidity control, cooling
Cons: Disease risk, leaf wetting

FLOOD/SUBIRRIGATION
Pros: Even watering, low labor
Cons: Disease spread risk

HAND WATERING
Pros: Flexible, low tech
Cons: Labor, inconsistent
```

#### Fertigation Components

```
FERTIGATION SYSTEM

Stock Tanks (Concentrated nutrients)
├─ Tank A: Ca-containing nutrients
├─ Tank B: Phosphate/sulfate nutrients
└─ Tank C: Acid (pH control)

        ↓ Injection pumps

Mixing Chamber
├─ Proportional mixing
├─ Target EC (1.5-2.5 dS/m)
└─ Target pH (5.5-6.5)

        ↓ Delivery

To Plants via irrigation system
└─ Constant feed or periodic
```

## Vocabulary

| Term | Definition |
|------|------------|
| **Hydroponics** | Growing plants in nutrient solution without soil |
| **Aeroponics** | Growing plants with roots suspended in air, misted with nutrients |
| **NFT** | Nutrient Film Technique - thin film of solution flows past roots |
| **DWC** | Deep Water Culture - roots submerged in oxygenated nutrient solution |
| **PPFD** | Photosynthetic Photon Flux Density - light intensity for photosynthesis |
| **DLI** | Daily Light Integral - total light received per day |
| **VPD** | Vapor Pressure Deficit - humidity measure affecting plant transpiration |
| **Fertigation** | Application of fertilizers through irrigation system |
| **EC** | Electrical Conductivity - measure of nutrient concentration |
| **HVAC** | Heating, Ventilation, Air Conditioning |
| **PLC** | Programmable Logic Controller - industrial automation computer |
| **PAR** | Photosynthetically Active Radiation (400-700 nm wavelengths) |
