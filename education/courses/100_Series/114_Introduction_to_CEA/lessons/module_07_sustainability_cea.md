## Lesson Content

### 7.1 Environmental Impact Comparison

```
CEA vs FIELD AGRICULTURE ENVIRONMENTAL METRICS

WATER USE
Field Agriculture:  100 gallons/lb produce
Greenhouse:         10-20 gallons/lb (80-90% reduction)
Vertical Farm:      1-5 gallons/lb (95-99% reduction)
└─ Recirculation and precision irrigation

LAND USE
Field: 1 acre → 20,000 lbs lettuce/year
Greenhouse: 1 acre → 100,000-200,000 lbs/year (5-10×)
Vertical (10 tiers): 1 acre → 400,000+ lbs/year (20×)
└─ Preserves natural habitats, reduces deforestation

PESTICIDE/HERBICIDE USE
Field: 5-20 lbs active ingredient/acre/year
CEA: <1 lb/acre/year (90-99% reduction)
└─ Controlled environment, IPM strategies

FERTILIZER RUNOFF
Field: 20-40% nutrient loss to environment
CEA: <5% nutrient loss (95%+ captured)
└─ Closed-loop systems, precision application

FOOD MILES
Field (average): 1,500 miles farm to consumer
CEA (urban): <50 miles (97% reduction)
└─ Local production, reduced transportation emissions
```

### 7.2 Energy and Carbon Footprint

```
ENERGY ANALYSIS

GREENHOUSE (Heated, Supplemental Light)
Energy use: 30-80 kWh/sq ft/year
├─ Heating: 60-70%
├─ Supplemental lighting: 15-25%
├─ Cooling/ventilation: 10-20%
└─ Other: 5-10%

VERTICAL FARM (Indoor, Full LED)
Energy use: 100-300 kWh/sq ft/year
├─ LED lighting: 65-75%
├─ HVAC: 20-30%
└─ Other: 5-10%

CARBON FOOTPRINT (kg CO₂e per kg produce)

Source             Field    Greenhouse  Vertical
─────────────────────────────────────────────────
Lettuce (local)    2.0      1.5-3.0     3.0-8.0*
Lettuce (shipped)  5.0      1.5-3.0     3.0-8.0
Tomatoes          2.5       1.5-2.5     N/A
Herbs             3.0       2.0-4.0     4.0-10.0

*Highly dependent on electricity grid carbon intensity

KEY INSIGHT: CEA carbon footprint varies dramatically by:
├─ Energy source (renewable vs fossil)
├─ Climate (heating needs)
├─ System efficiency
└─ Crop type
```

### 7.3 Renewable Energy Integration

```
RENEWABLE ENERGY OPTIONS FOR CEA

SOLAR PHOTOVOLTAIC (PV)
┌────────────────────────────────────┐
│ Potential: 20-100% of energy needs │
│ Cost: $2-4/Watt installed          │
│ Payback: 6-12 years                │
│                                    │
│ Applications:                      │
│ • Rooftop solar on greenhouse      │
│ • Ground-mount solar array         │
│ • Building-integrated PV           │
│                                    │
│ Considerations:                    │
│ • Shading of greenhouse            │
│ • Battery storage for night use    │
│ • Net metering availability        │
└────────────────────────────────────┘

SOLAR THERMAL
┌────────────────────────────────────┐
│ Potential: 40-80% of heating needs │
│ Cost: $50-150/sq ft collector      │
│ Payback: 8-15 years                │
│                                    │
│ Applications:                      │
│ • Water heating for radiant floors │
│ • Pre-heating irrigation water     │
│ • Seasonal thermal storage         │
└────────────────────────────────────┘

WIND ENERGY
┌────────────────────────────────────┐
│ Potential: Variable by location    │
│ Cost: $3-6/Watt (small turbines)   │
│ Payback: 10-20 years               │
│                                    │
│ Best for:                          │
│ • Rural locations with wind        │
│ • Large facilities                 │
│ • Grid-tie systems                 │
└────────────────────────────────────┘

GEOTHERMAL
┌────────────────────────────────────┐
│ Potential: 50-90% of HVAC needs    │
│ Cost: $15-40/sq ft                 │
│ Payback: 5-10 years                │
│                                    │
│ Types:                             │
│ • Ground-source heat pumps         │
│ • Deep geothermal (where available)│
│                                    │
│ Benefits:                          │
│ • Heating AND cooling              │
│ • Very reliable                    │
│ • Long lifespan (50+ years)        │
└────────────────────────────────────┘

BIOMASS/BIOGAS
┌────────────────────────────────────┐
│ Potential: 100% of heating needs   │
│ Cost: Variable                     │
│                                    │
│ Sources:                           │
│ • Wood pellets (boilers)           │
│ • Anaerobic digestion (biogas)     │
│ • Waste heat from other processes  │
└────────────────────────────────────┘

RECOMMENDED STRATEGY:
├─ Start with energy efficiency
├─ Add solar PV (rooftop or ground)
├─ Consider geothermal for heating/cooling
├─ Battery storage for time-shifting
└─ Aim for 50-100% renewable by Year 5
```

### 7.4 Circular Economy Principles

```
CIRCULAR CEA OPERATIONS

WATER CYCLE
┌────────────────────────────────────┐
│ Rainwater collection               │
│        ↓                           │
│ Use in irrigation                  │
│        ↓                           │
│ Plant uptake/transpiration         │
│        ↓                           │
│ Condensation capture               │
│        ↓                           │
│ Drainage/runoff collection         │
│        ↓                           │
│ Treatment/filtration               │
│        ↓                           │
│ Reuse (loop back)                  │
│                                    │
│ Water recycling: 90-98%            │
└────────────────────────────────────┘

NUTRIENT CYCLE
┌────────────────────────────────────┐
│ Apply fertilizer to plants         │
│        ↓                           │
│ Plant uptake                       │
│        ↓                           │
│ Harvest (nutrients in crop)        │
│        ↓                           │
│ Plant waste → compost              │
│        ↓                           │
│ Compost back to growing media      │
│        OR                          │
│ Runoff → capture → reuse           │
│                                    │
│ Nutrient efficiency: 80-95%        │
└────────────────────────────────────┘

CO₂ CYCLE
┌────────────────────────────────────┐
│ Plants absorb CO₂                  │
│        ↓                           │
│ Photosynthesis (plant growth)      │
│        ↓                           │
│ Decomposition/composting           │
│        ↓                           │
│ CO₂ released                       │
│        ↓                           │
│ Capture and enrich greenhouse      │
│                                    │
│ OR: Use waste CO₂ from brewery,    │
│     biogas plant, etc.             │
└────────────────────────────────────┘

ENERGY CYCLE
┌────────────────────────────────────┐
│ Solar/renewable generation         │
│        ↓                           │
│ Power LEDs, HVAC, equipment        │
│        ↓                           │
│ Waste heat from LEDs               │
│        ↓                           │
│ Heat recovery for heating/water    │
│        ↓                           │
│ Reduce purchased energy            │
└────────────────────────────────────┘

WASTE STREAMS
└─ Plant waste → Animal feed/compost
└─ Packaging → Recyclable/compostable materials
└─ Growing media → Recondition/compost
└─ Organic waste → Biogas digester
```

### 7.5 Waste Reduction and Recycling

```
ZERO-WASTE CEA STRATEGIES

PLANT WASTE MANAGEMENT
├─ Composting on-site (small-medium scale)
├─ Partner with composters (large scale)
├─ Animal feed (certain crops)
├─ Biogas production (anaerobic digestion)
└─ Target: >90% diversion from landfill

GROWING MEDIA
├─ Sterilize and reuse (see Module 8, Course 113)
├─ Compost aged media
├─ Land application (soil amendment)
└─ Target: 2-3 crop cycles per media batch

PACKAGING
├─ Reusable containers (clamshells, bins)
├─ Compostable packaging materials
├─ Recyclable materials only
├─ Minimal packaging design
└─ Customer take-back programs

WATER
├─ Capture condensation
├─ Treat and recycle drainage
├─ Rainwater harvesting
├─ Greywater recycling (where allowed)
└─ Target: <5% water loss

ENERGY
├─ LED waste heat recovery
├─ Thermal mass for heat storage
├─ Efficient equipment (VFD fans, LED)
└─ Monitoring and optimization
```

### 7.7 Life Cycle Assessment (LCA)

```
SIMPLIFIED LCA FOR CEA

SYSTEM BOUNDARIES
┌────────────────────────────────────┐
│ Infrastructure                     │
│ ├─ Materials (steel, glass, etc.)  │
│ ├─ Manufacturing                   │
│ ├─ Transportation                  │
│ └─ Construction                    │
│                                    │
│ Operations (per year)              │
│ ├─ Energy use                      │
│ ├─ Water use                       │
│ ├─ Nutrient/supply inputs          │
│ ├─ Waste disposal                  │
│ └─ Transportation (distribution)   │
│                                    │
│ End of Life                        │
│ ├─ Decommissioning                 │
│ ├─ Recycling                       │
│ └─ Disposal                        │
└────────────────────────────────────┘

IMPACT CATEGORIES
├─ Global warming potential (kg CO₂e)
├─ Water depletion (L)
├─ Land use (m²)
├─ Eutrophication potential (kg PO₄e)
├─ Acidification (kg SO₂e)
└─ Human toxicity

TYPICAL FINDINGS:
├─ Operations dominate LCA (70-90%)
├─ Energy is largest single impact
├─ Infrastructure amortized over 20-30 years
├─ Grid carbon intensity critical variable
└─ Local sourcing reduces transport impacts

Conduct LCA to:
• Identify improvement opportunities
• Compare to alternatives
• Communicate sustainability
• Inform design decisions
```

### 7.8 Sustainability Metrics and Reporting

```
CEA SUSTAINABILITY KPIs

ENVIRONMENTAL
├─ Water use per kg produce (liters/kg): <5L target
├─ Energy use per kg (kWh/kg): <3 kWh target
├─ Carbon footprint (kg CO₂e/kg): <2 kg target
├─ Waste to landfill (%): <5% target
├─ Renewable energy (%): 50-100% target
└─ Pesticide use (kg/acre): <0.5 kg target

SOCIAL
├─ Jobs created (FTE per 10,000 sq ft): 5-10
├─ Living wage employees (%): 100% target
├─ Diversity in workforce (%): Local demographics
├─ Community engagement (hours/year): 100+
├─ Produce donated (kg/year): 1-5% of production
└─ Educational participants (people/year): 100+

ECONOMIC
├─ Local economic impact ($): Wages + local purchases
├─ Value-added products (%): Diversification
├─ Profit margin (%): 15-30% sustainable
└─ Reinvestment in sustainability (%): 5-10% of profit

REPORTING FRAMEWORKS
├─ GRI (Global Reporting Initiative)
├─ SASB (Sustainability Accounting Standards)
├─ B Impact Assessment
├─ UN Sustainable Development Goals (SDGs)
└─ Custom dashboards for transparency
```

## Vocabulary

| Term | Definition |
|------|------------|
| **LCA** | Life Cycle Assessment - environmental impact over product lifespan |
| **Carbon Footprint** | Total greenhouse gas emissions caused by activity/product |
| **Circular Economy** | Economic system minimizing waste through reuse/recycling |
| **Food Desert** | Area with limited access to affordable, nutritious food |
| **Renewable Energy** | Energy from sources that naturally replenish (solar, wind) |
| **Eutrophication** | Excess nutrients causing algal blooms in waterways |
| **Living Wage** | Income sufficient to afford basic living costs |
| **B Corporation** | For-profit company certified for social/environmental performance |
| **Closed-Loop System** | System that recycles/reuses all or most inputs |
| **Embodied Energy** | Total energy required to produce material/product |
