## SECTION 6: Break-Even Analysis

```
╔═══════════════════════════════════════════════════════════════════════════════════════════╗
║                                                                                           ║
║                              BREAK-EVEN CALCULATION                                       ║
║                                                                                           ║
║   ┌─────────────────────────────────────────────────────────────────────────────────────┐ ║
║   │                                                                                     │ ║
║   │   BREAK-EVEN FORMULA:                                                              │ ║
║   │                                                                                     │ ║
║   │   Break-Even (lbs) = Fixed Costs ÷ (Price per lb - Variable Cost per lb)          │ ║
║   │                                                                                     │ ║
║   │   ─────────────────────────────────────────────────────────────────────────────   │ ║
║   │                                                                                     │ ║
║   │   YOUR CALCULATION:                                                                │ ║
║   │                                                                                     │ ║
║   │   Monthly fixed costs:                   $ ____________                            │ ║
║   │                                                                                     │ ║
║   │   Selling price per lb:                  $ ____________                            │ ║
║   │                                                                                     │ ║
║   │   Variable cost per lb:                  $ ____________                            │ ║
║   │   (variable cost per cycle ÷ yield per cycle)                                     │ ║
║   │                                                                                     │ ║
║   │   Contribution margin per lb:            $ ____________                            │ ║
║   │   (price - variable cost)                                                          │ ║
║   │                                                                                     │ ║
║   │   ═══════════════════════════════════════════════════════════════════════════════ │ ║
║   │                                                                                     │ ║
║   │   BREAK-EVEN VOLUME:                     ____________ lbs/month                    │ ║
║   │   (fixed costs ÷ contribution margin)                                             │ ║
║   │                                                                                     │ ║
║   │   ─────────────────────────────────────────────────────────────────────────────   │ ║
║   │                                                                                     │ ║
║   │   Your monthly production capacity:      ____________ lbs                          │ ║
║   │                                                                                     │ ║
║   │   MARGIN OF SAFETY:                      ____________ lbs                          │ ║
║   │   (capacity - break-even)                                                          │ ║
║   │                                                                                     │ ║
║   │   □ Above break-even  ✓                  □ Below break-even  ⚠️                    │ ║
```
