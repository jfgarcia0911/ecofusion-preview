## Learning Objectives

By the end of this module, you will be able to:
1. Establish quality standards for your products
2. Implement consistent grading procedures
3. Create quality control checkpoints throughout production
4. Document and track quality metrics
5. Meet buyer specifications and market requirements

### Quality vs Grade

```
┌───────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│   QUALITY VS GRADE - UNDERSTANDING THE DIFFERENCE                                 │
│                                                                                   │
│   QUALITY = Overall excellence (intrinsic characteristics)                       │
│   GRADE = Classification within a quality standard (sorting criteria)            │
│                                                                                   │
│   EXAMPLE: Premium Tomatoes                                                       │
│   ═══════════════════════════════════════════════════════════════════════════    │
│                                                                                   │
│   Quality standards (what makes a "good" tomato):                                │
│   • Vine-ripened                                                                 │
│   • Firm texture                                                                 │
│   • Full color development                                                       │
│   • No disease                                                                   │
│                                                                                   │
│   Grade distinctions (sorting "good" tomatoes):                                  │
│                                                                                   │
│   GRADE         SIZE          APPEARANCE         PRICE                           │
│   ─────────────────────────────────────────────────────────────────────────────  │
│   Extra Large   >3.5"         Perfect            $$$                             │
│   Large         3.0-3.5"      Minor spots OK     $$                              │
│   Medium        2.5-3.0"      Slight scarring    $                               │
│                                                                                   │
│   All grades are "quality" tomatoes - grade separates by size/cosmetics         │
│                                                                                   │
└───────────────────────────────────────────────────────────────────────────────────┘
```

║           ▼                                                                       ║

║           ▼                                                                       ║

### Inspection Procedures

```
┌───────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│   SAMPLE INSPECTION PROTOCOL                                                      │
│                                                                                   │
│   SAMPLING:                                                                       │
│   ═══════════════════════════════════════════════════════════════════════════    │
│                                                                                   │

│   ─────────────────────────────────────────────────────────────────────────────  │

│   ═══════════════════════════════════════════════════════════════════════════    │
│                                                                                   │

│   ┌─────────────────────────────────────────────────────────────────────────────┐ │

│   │ □ Shape typical for variety                                                │ │
│   │ □ No visible defects (spots, scars, decay)                                │ │
│   │ □ No pest or disease damage                                                │ │

│                                                                                   │
│   2. Physical Assessment                                                          │
│   ┌─────────────────────────────────────────────────────────────────────────────┐ │

│                                                                                   │
│   3. Record Results                                                               │
│   ┌─────────────────────────────────────────────────────────────────────────────┐ │
│   │ □ Document findings                                                        │ │

│   └─────────────────────────────────────────────────────────────────────────────┘ │
│                                                                                   │
└───────────────────────────────────────────────────────────────────────────────────┘
```

## Defect Identification

### Common Defects by Category

```
╔═══════════════════════════════════════════════════════════════════════════════════╗
║                                                                                   ║
║                         DEFECT CLASSIFICATION                                     ║
║                                                                                   ║
║   CRITICAL DEFECTS (Reject - Food Safety Risk)                                   ║
║   ════════════════════════════════════════════════════════════════════════════   ║
║   • Decay/rot (any amount)                                                       ║
║   • Mold growth                                                                  ║
║   • Foreign material contamination                                               ║
║   • Evidence of pest infestation                                                 ║
║   • Off-odors indicating spoilage                                                ║
║                                                                                   ║
║   ACTION: Remove from lot immediately, do not sell                               ║
║                                                                                   ║
║   ─────────────────────────────────────────────────────────────────────────────  ║
║                                                                                   ║
║   MAJOR DEFECTS (Downgrade - Affects Salability)                                 ║
║   ════════════════════════════════════════════════════════════════════════════   ║
║   • Significant scarring (>10% surface)                                         ║
║   • Mechanical damage (cuts, bruises)                                            ║
║   • Growth cracks                                                                ║
║   • Sunscald/heat damage                                                         ║
║   • Insect feeding damage                                                        ║
║   • Significant misshape                                                         ║
║   • Wrong maturity stage                                                         ║
║                                                                                   ║
║   ACTION: Downgrade to lower grade or processing                                 ║
║                                                                                   ║
║   ─────────────────────────────────────────────────────────────────────────────  ║
║                                                                                   ║
║   MINOR DEFECTS (Accept with Tolerance - Cosmetic)                               ║
║   ════════════════════════════════════════════════════════════════════════════   ║
║   • Light scarring (<10% surface)                                               ║
║   • Minor shape variation                                                        ║
║   • Slight color variation                                                       ║
║   • Minor surface blemishes                                                      ║
║   • Slight size variation within grade                                           ║
║                                                                                   ║
║   ACTION: Accept within tolerance limits (usually <10% of lot)                   ║
║                                                                                   ║
╚═══════════════════════════════════════════════════════════════════════════════════╝
```

## Summary

### Key Takeaways

1. **Define standards** - Establish clear quality criteria before production
2. **Check consistently** - Quality control at every production stage
3. **Document everything** - Records enable improvement and traceability
4. **Know your market** - Different buyers have different requirements
5. **Improve continuously** - Use data to identify and fix problems

### Quality Quick Reference

| Grade | Defect Tolerance | Typical Use |
|-------|-----------------|-------------|
| Premium/Fancy | <2% minor, 0% major | High-end retail, restaurants |
| #1/Choice | <5% minor, <2% major | General retail |
| #2/Standard | <10% minor, <5% major | Food service, value |
| Processing | Higher tolerance | Processing, juicing |
