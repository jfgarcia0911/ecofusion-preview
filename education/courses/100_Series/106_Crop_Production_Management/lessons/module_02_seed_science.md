## Germination Requirements

### The Five Essentials

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                    GERMINATION REQUIREMENTS                                │
    │                                                                             │
    │   All seeds need these five factors to germinate:                          │
    │                                                                             │
    │   1. MOISTURE (Water)                                                      │
    │      ════════════════                                                      │
    │      • Activates enzymes                                                   │
    │      • Softens seed coat                                                   │
    │      • Media should be moist, not saturated                               │
    │      • Consistent moisture critical until emergence                        │
    │                                                                             │
    │   2. TEMPERATURE                                                           │
    │      ════════════                                                          │
    │      • Each species has optimal range                                      │
    │      • Too cold = slow/no germination                                      │
    │      • Too hot = damaged embryo                                            │
    │      • Heat mats useful for tropical crops                                │
    │                                                                             │
    │   3. OXYGEN                                                                │
    │      ════════                                                              │
    │      • Required for cellular respiration                                   │
    │      • Waterlogged media = oxygen depleted                                │
    │      • Good drainage essential                                            │
    │                                                                             │
    │   4. LIGHT (or DARKNESS)                                                   │
    │      ══════════════════                                                    │
    │      • Some seeds require light (lettuce, celery)                         │
    │      • Some require darkness (onions, pansies)                            │
    │      • Most are indifferent                                               │
    │                                                                             │
    │   5. DORMANCY BREAK (if applicable)                                        │
    │      ═══════════════════════════════                                       │
    │      • Some seeds need stratification (cold period)                       │
    │      • Some need scarification (physical treatment)                       │
    │      • Most vegetable seeds: no special treatment needed                  │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘
```

## Seed Storage

```
╔═══════════════════════════════════════════════════════════════════════════╗
║                                                                           ║
║                    SEED STORAGE GUIDELINES                                ║
║                                                                           ║
║   OPTIMAL CONDITIONS:                                                    ║
║   ═══════════════════                                                    ║
║   Temperature: 35-40°F (2-4°C)                                          ║
║   Humidity: 30-40% RH                                                    ║
║   Container: Airtight (with desiccant packet)                           ║
║   Light: Dark                                                            ║
║                                                                           ║
║   RULE OF THUMB:                                                         ║
║   Temperature (°F) + Relative Humidity (%) should be ≤ 100              ║

║            70°F + 60% RH = 130 ✗ (too high)                             ║
```

## Seeding Calculations

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                    SEEDING CALCULATION FORMULA                             │
    │                                                                             │
    │   Seeds Needed = Plants Needed ÷ (Germ Rate × Transplant Success)         │
    │                                                                             │
    │   EXAMPLE:                                                                 │
    │   ═════════                                                                │
    │   Need: 1,000 lettuce transplants                                         │
    │   Germination rate: 90%                                                   │
    │   Transplant success: 95%                                                 │
    │                                                                             │
    │   Seeds = 1,000 ÷ (0.90 × 0.95)                                           │
    │   Seeds = 1,000 ÷ 0.855                                                   │
    │   Seeds = 1,170 seeds minimum                                             │
    │                                                                             │
    │   Add 10% buffer: 1,170 × 1.10 = 1,287 seeds                             │
    │                                                                             │
    │   ─────────────────────────────────────────────────────────────────────   │
    │                                                                             │
    │   SEEDS PER OUNCE (approximate):                                          │
    │                                                                             │
    │   Lettuce: 25,000          Tomato: 10,000                                 │
    │   Basil: 18,000            Pepper: 4,500                                  │
    │   Spinach: 2,800           Cucumber: 1,100                                │
    │   Kale: 9,000              Squash: 300                                    │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘
```

## Module Summary

### Key Takeaways

1. **Germination requires** moisture, temperature, oxygen, and (sometimes) light
2. **Temperature is critical** - each crop has an optimal range
3. **Proper storage** extends seed viability significantly
4. **Always calculate** seed needs with germination rate factored in
5. **Test germination** on older seed lots before committing to production
