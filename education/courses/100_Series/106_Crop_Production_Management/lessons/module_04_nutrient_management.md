## Understanding EC (Electrical Conductivity)

### EC Fundamentals

```
╔═══════════════════════════════════════════════════════════════════════════════════╗
║                                                                                   ║
║                         EC - ELECTRICAL CONDUCTIVITY                              ║
║                                                                                   ║
║   EC measures the total dissolved salts (nutrients) in solution                  ║
║                                                                                   ║
║   UNITS:                                                                          ║
║   • mS/cm (millisiemens per centimeter) - Most common                            ║
║   • EC units (1 EC = 1 mS/cm)                                                    ║
║   • PPM (parts per million) - Conversion varies by meter                         ║
║                                                                                   ║
║   CONVERSION:                                                                     ║
║   ┌─────────────────────────────────────────────────────────────────────────────┐ ║
║   │   EC (mS/cm) × 500 = PPM (500 scale - Hanna)                               │ ║
║   │   EC (mS/cm) × 640 = PPM (640 scale - Truncheon)                           │ ║
║   │   EC (mS/cm) × 700 = PPM (700 scale - Eutech)                              │ ║
║   └─────────────────────────────────────────────────────────────────────────────┘ ║
║                                                                                   ║
║   EC RANGES BY CROP TYPE:                                                         ║
║   ════════════════════════════════════════════════════════════════════════════   ║
║                                                                                   ║

║                                                                                   ║
║   Lettuce       │══════════│                                                     ║
║                 0.8-1.2                                                           ║

║   Herbs                │═══════════│                                             ║
║                        1.0-1.6                                                    ║

║   Tomatoes                        │═══════════════════│                          ║
║   (fruiting)                      2.0-3.5                                        ║
║                                                                                   ║
║   Peppers                    │═══════════════════│                               ║
║                              1.8-2.8                                              ║
║                                                                                   ║
╚═══════════════════════════════════════════════════════════════════════════════════╝
```

### EC Management Strategy

```
┌───────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│   EC CHANGES AND PLANT RESPONSE                                                   │
│                                                                                   │
│   SCENARIO              EC TREND        CAUSE                ACTION              │
│   ════════════════════════════════════════════════════════════════════════════   │
│                                                                                   │
│   EC Rising             ↗️              Plants taking more    Add fresh water    │
│   (concentrate)                        water than nutrients   Reduce feed EC     │
│                                                                                   │
│   EC Falling            ↘️              Plants taking more    Increase feed EC   │
│   (diluting)                           nutrients than water   Check root health  │
│                                                                                   │
│   EC Stable             →              Balanced uptake        Maintain current   │
│   (ideal)                              Good management        settings           │
│                                                                                   │
│   ─────────────────────────────────────────────────────────────────────────────  │
│                                                                                   │
│   MONITORING SCHEDULE:                                                            │
│                                                                                   │
│   • Recirculating systems: Check 2× daily minimum                                │
│   • Run-to-waste: Check input and runoff                                         │
│   • Target: Runoff EC within 0.3-0.5 of input                                   │
│                                                                                   │
│   HIGH EC SYMPTOMS:           LOW EC SYMPTOMS:                                   │
│   • Leaf tip burn             • Pale green color                                 │
│   • Wilting despite water     • Slow growth                                      │
│   • Brown root tips           • Thin stems                                       │
│   • Stunted growth            • Poor flower/fruit set                            │
│                                                                                   │
└───────────────────────────────────────────────────────────────────────────────────┘
```

### pH Adjustment

```
┌───────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│   pH ADJUSTMENT GUIDELINES                                                        │
│                                                                                   │
│   TO LOWER pH (Acidify):                                                          │
│   ═══════════════════════════════════════════════════════════════════════════    │
│   • Phosphoric acid (H₃PO₄) - Adds P, good for veg                              │
│   • Nitric acid (HNO₃) - Adds N, good for veg                                   │
│   • Sulfuric acid (H₂SO₄) - Neutral addition                                    │
│   • Citric acid - Organic option, less stable                                    │
│                                                                                   │
│   TO RAISE pH (Alkalize):                                                         │
│   ═══════════════════════════════════════════════════════════════════════════    │
│   • Potassium hydroxide (KOH) - Adds K                                          │
│   • Potassium bicarbonate - Gentle, adds K                                      │
│   • Sodium hydroxide - Avoid (adds sodium)                                       │
│                                                                                   │
│   ─────────────────────────────────────────────────────────────────────────────  │
│                                                                                   │
│   ADJUSTMENT TIPS:                                                                │
│                                                                                   │
│   1. Add pH adjusters SLOWLY - a little goes a long way                         │
│   2. Mix thoroughly before retesting                                             │
│   3. Wait 30+ minutes for reading to stabilize                                   │
│   4. Adjust in small increments (0.2-0.3 at a time)                             │
│   5. Add nutrients BEFORE adjusting pH                                           │
│                                                                                   │
│   ⚠️ SAFETY: pH adjusters are corrosive - use PPE!                              │
│                                                                                   │
└───────────────────────────────────────────────────────────────────────────────────┘
```

### Mixing Nutrients Properly

```
┌───────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│   NUTRIENT MIXING PROCEDURE                                                       │
│                                                                                   │
│   ⚠️ CRITICAL: Never mix concentrated nutrients directly together!               │
│                Calcium + Phosphates/Sulfates = Precipitation                     │
│                                                                                   │
│   CORRECT PROCEDURE:                                                              │
│   ════════════════════════════════════════════════════════════════════════════   │

│   ┌─────────┐         ┌─────────┐         ┌─────────┐         ┌─────────┐        │
│   │         │         │    A    │         │    B    │         │  TEST   │        │
│   │  FILL   │   ───►  │  ────►  │   ───►  │  ────►  │   ───►  │ EC, pH  │        │
│   │  WATER  │         │   MIX   │         │   MIX   │         │ ADJUST  │        │
│   │         │         │         │         │         │         │         │        │
│   └─────────┘         └─────────┘         └─────────┘         └─────────┘        │
│   Fill tank 75%       Add Part A          Add Part B          Test & adjust      │
│   with water          Stir thoroughly     Stir thoroughly     pH last            │
│                                                                                   │
│   ─────────────────────────────────────────────────────────────────────────────  │
│                                                                                   │
│   DOSING EXAMPLE (1000L tank, target EC 1.5):                                    │
│                                                                                   │
│   1. Fill tank with 750L RO water (starting EC ~0.0)                            │
│   2. Add Part A: Start with manufacturer's recommended rate                      │
│   3. Mix for 5 minutes, let settle                                               │
│   4. Add Part B: Same rate as Part A                                             │
│   5. Mix for 5 minutes, top up to 1000L                                         │
│   6. Test EC - adjust if needed                                                  │
│   7. Test pH - adjust to 5.8-6.0                                                │
```

### Understanding Nutrient Interactions

```
┌───────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│   NUTRIENT ANTAGONISMS AND SYNERGISMS                                             │
│                                                                                   │
│   ANTAGONISMS (Too much of A blocks B):                                          │
│   ════════════════════════════════════════════════════════════════════════════   │
│                                                                                   │
│   HIGH NUTRIENT          BLOCKS UPTAKE OF                                        │
│   ─────────────────────────────────────────                                      │
│   Nitrogen (NH₄)    →    Calcium, Magnesium, Potassium                          │
│   Potassium         →    Calcium, Magnesium                                      │
│   Calcium           →    Magnesium, Potassium, Boron                            │
│   Phosphorus        →    Zinc, Iron, Copper                                      │
│   Iron              →    Manganese                                               │
│                                                                                   │
│   SYNERGISMS (A helps B):                                                        │
│   ════════════════════════════════════════════════════════════════════════════   │
│                                                                                   │
│   Nitrogen + Phosphorus    Better P uptake when N adequate                       │
│   Calcium + Boron          Work together for cell wall strength                  │
│   Iron + Manganese         Both needed for chlorophyll (in balance)              │
│                                                                                   │
│   KEY TAKEAWAY: Balance is critical - more isn't always better!                  │
│                                                                                   │
```

## Summary

### Key Takeaways

1. **Monitor consistently** - EC and pH are your primary management tools
2. **Match feed to stage** - Different growth stages have different needs
3. **Diagnose accurately** - Mobile vs immobile nutrients show different symptoms
4. **Maintain balance** - Excess of one nutrient can cause deficiency of another
5. **Calibrate regularly** - Accurate measurements require calibrated tools
