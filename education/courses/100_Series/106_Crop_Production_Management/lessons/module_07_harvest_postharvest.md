## Harvesting Techniques

### Cut-and-Come-Again Method

```
╔═══════════════════════════════════════════════════════════════════════════════════╗
║                                                                                   ║
║                         CUT-AND-COME-AGAIN HARVESTING                             ║
║                                                                                   ║
║   Best for: Lettuce, spinach, chard, kale, herbs                                 ║
║                                                                                   ║
║   TECHNIQUE:                                                                      ║
║   ┌─────────────────────────────────────────────────────────────────────────────┐ ║
║   │                                                                             │ ║
║   │   Before Cut           After Cut             Regrowth                       │ ║
║   │                                                                             │ ║
║   │     🌿🌿🌿                🌿                  🌿🌿                           │ ║
║   │    🌿🌿🌿🌿            ╲│╱│╲                🌿│🌿🌿                          │ ║
║   │   🌿🌿🌿🌿🌿    ──►     │ │       ──►       │🌿│                            │ ║
║   │      │                  │                    │                              │ ║
║   │    ──┴──              ──┴──                ──┴──                            │ ║
║   │                                                                             │ ║
║   │   Cut 1-2" above        Leave growing        New leaves                     │ ║
║   │   growing point         point intact         in 1-2 weeks                   │ ║
║   │                                                                             │ ║
║   └─────────────────────────────────────────────────────────────────────────────┘ ║
║                                                                                   ║
║   GUIDELINES:                                                                     ║
║   • Leave at least 1-2 inches (growing point) above base                        ║
║   • Remove no more than 1/3 of plant at once                                    ║
║   • Allow 7-14 days between harvests                                            ║
║   • Expect 2-4 harvests per planting (decreasing quality)                       ║
║   • Increase nutrients after each cut                                            ║
║                                                                                   ║
╚═══════════════════════════════════════════════════════════════════════════════════╝
```

### Fruiting Crop Harvest

```

║   │                                                                             │ ║

║   │   • Cut stem 1/2" from fruit                                               │ ║

║   │   • Harvest frequently to maintain production                              │ ║
```

## Quality Maintenance

### Washing and Sanitizing

```
┌───────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│   WASH AND SANITIZE PROTOCOL                                                      │
│                                                                                   │
│   STEP 1: PRE-RINSE                                                               │
│   ═══════════════════════════════════════════════════════════════════════════    │
│   • Remove loose debris                                                          │
│   • Use clean potable water                                                      │
│   • Water temperature close to product temp (prevent thermal shock)              │
│                                                                                   │
│   STEP 2: WASH                                                                    │
│   ═══════════════════════════════════════════════════════════════════════════    │
│   • Clean water with approved sanitizer                                          │
│   • Agitate gently to remove soil                                                │
│   • Monitor and maintain sanitizer levels                                        │
│                                                                                   │
│   STEP 3: SANITIZE                                                                │
│   ═══════════════════════════════════════════════════════════════════════════    │
│                                                                                   │
│   SANITIZER OPTIONS:                                                              │
│   ┌─────────────────────────────────────────────────────────────────────────────┐ │
│   │                                                                             │ │
│   │   Chlorine (Sodium hypochlorite)                                           │ │
│   │   • Concentration: 50-200 ppm free chlorine                                │ │
│   │   • pH: 6.5-7.5 for effectiveness                                          │ │
│   │   • Contact time: 1-2 minutes                                              │ │
│   │   • Pros: Inexpensive, effective                                           │ │
│   │   • Cons: pH sensitive, dissipates quickly                                 │ │
│   │                                                                             │ │
│   │   Peroxyacetic Acid (PAA)                                                  │ │
│   │   • Concentration: 40-80 ppm                                               │ │
│   │   • pH: 3.5-7.5 (broader range)                                           │ │
│   │   • Contact time: 1-2 minutes                                              │ │
│   │   • Pros: Works in organic matter, stable                                  │ │
│   │   • Cons: More expensive, vinegar odor                                     │ │
│   │                                                                             │ │
│   │   Ozone                                                                     │ │
│   │   • Concentration: 1-3 ppm in water                                        │ │
│   │   • Contact time: <1 minute                                                │ │
│   │   • Pros: Very effective, no residue                                       │ │
│   │   • Cons: Equipment cost, safety concerns                                  │ │
│   │                                                                             │ │
│   └─────────────────────────────────────────────────────────────────────────────┘ │
│                                                                                   │
│   STEP 4: RINSE (if required)                                                     │
│   ═══════════════════════════════════════════════════════════════════════════    │
│   • Most sanitizers are no-rinse at proper concentrations                       │
│   • If rinsing, use sanitized water                                              │
│                                                                                   │
│   STEP 5: DRY                                                                     │
│   ═══════════════════════════════════════════════════════════════════════════    │
│   • Air dry or use salad spinner                                                 │
│   • Excess moisture promotes decay                                               │
│   • Cool storage after drying                                                    │
│                                                                                   │
└───────────────────────────────────────────────────────────────────────────────────┘
```

## Summary

### Key Takeaways

1. **Timing matters** - Harvest at optimal maturity for quality
2. **Cool quickly** - Remove field heat as fast as possible
3. **Maintain cold chain** - Every break reduces shelf life
4. **Handle gently** - Physical damage leads to decay
5. **Document everything** - Traceability is essential for food safety

### Shelf Life Quick Reference

| Crop | Optimal Temp | Optimal RH | Expected Shelf Life |
|------|-------------|------------|---------------------|
| Lettuce | 32-35°F | 95-100% | 2-3 weeks |
| Basil | 50-55°F | 90% | 5-7 days |
| Tomatoes (ripe) | 55-60°F | 85-90% | 1-2 weeks |
| Cucumbers | 50-55°F | 95% | 10-14 days |
| Peppers | 45-50°F | 90-95% | 2-3 weeks |
| Herbs (most) | 32-35°F | 95-100% | 1-2 weeks |
