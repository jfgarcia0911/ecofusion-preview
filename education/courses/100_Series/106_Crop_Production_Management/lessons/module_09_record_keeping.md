### Data Collection Best Practices

```
┌───────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│   DATA COLLECTION PRINCIPLES                                                      │
│                                                                                   │
│   1. COLLECT AT THE SOURCE                                                        │
│   ═══════════════════════════════════════════════════════════════════════════    │
│   • Enter data immediately when action occurs                                    │
│   • Use mobile devices in growing areas                                          │
│   • Avoid "I'll record it later" - leads to errors                              │
│                                                                                   │
│   2. STANDARDIZE FORMATS                                                          │
│   ═══════════════════════════════════════════════════════════════════════════    │
│   • Consistent date formats (YYYY-MM-DD recommended)                            │
│   • Standard units (always lbs, always mS/cm, etc.)                             │
│   • Consistent naming conventions (crop codes, location IDs)                     │
│                                                                                   │
│   3. MINIMIZE MANUAL ENTRY                                                        │
│   ═══════════════════════════════════════════════════════════════════════════    │
│   • Use dropdowns/selections where possible                                      │
│   • Auto-populate dates and user IDs                                             │
│   • Integrate sensors for automatic readings                                     │
│                                                                                   │
│   4. BACKUP REGULARLY                                                             │
│   ═══════════════════════════════════════════════════════════════════════════    │
│   • Cloud storage (Google Drive, Dropbox)                                        │
│   • Regular exports to local storage                                             │
│   • 3-2-1 rule: 3 copies, 2 different media, 1 offsite                          │
│                                                                                   │
│   5. REVIEW AND VALIDATE                                                          │
```
