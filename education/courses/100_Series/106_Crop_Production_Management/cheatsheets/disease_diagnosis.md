## Disease Identification by Symptom

### Leaf Symptoms

```
┌─────────────────────────────────────────────────────────────────┐
│  LEAF SYMPTOM DIAGNOSIS                                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  WHITE/GRAY POWDERY COATING                                     │
│  └── Powdery Mildew (fungal)                                   │
│      • Conditions: 60-80°F, RH 40-70%, poor airflow            │
│      • Often starts on upper leaf surfaces                     │
│                                                                 │
│  GRAY FUZZY GROWTH                                              │
│  └── Botrytis / Gray Mold (fungal)                             │
│      • Conditions: Cool temps, high humidity, still air        │
│      • Often on damaged tissue, dense canopies                 │
│                                                                 │
│  YELLOW/BROWN SPOTS WITH HALOS                                  │
│  └── Bacterial Leaf Spot                                       │
│      • Conditions: Warm, wet, water splash                     │
│      • Often angular spots limited by leaf veins               │
│                                                                 │
│  DOWNY PATCHES ON LEAF UNDERSIDES                               │
│  └── Downy Mildew (oomycete)                                   │
│      • Conditions: Cool, wet, high humidity                    │
│      • Yellow spots on top, fuzzy growth underneath            │
│                                                                 │
│  WATER-SOAKED LESIONS                                           │
│  └── Bacterial Disease                                          │
│      • Dark, greasy-looking spots                              │
│      • May have bacterial ooze                                 │
│                                                                 │
│  MOSAIC/MOTTLED PATTERN                                         │
│  └── Viral Infection                                            │
│      • Irregular light/dark patterns                           │
│      • Often distorted growth                                  │
│      • NO CURE - remove infected plants                        │
│                                                                 │
│  LEAF EDGE BROWNING (TIPBURN)                                   │
│  └── Calcium Deficiency (not disease)                          │
│      • Environmental/nutritional issue                         │
│      • Check humidity, airflow, calcium availability           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Root/Crown Symptoms

```
┌─────────────────────────────────────────────────────────────────┐
│  ROOT & CROWN DISEASE DIAGNOSIS                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  BROWN, MUSHY ROOTS                                             │
│  └── Pythium Root Rot (oomycete)                               │
│      • Conditions: Waterlogged, warm (77-86°F)                 │
│      • Outer root tissue slips off easily                      │
│      • "Wet feet" conditions                                   │
│                                                                 │
│  BROWN ROOTS, PLANT WILT                                        │
│  └── Fusarium (fungal)                                          │
│      • Conditions: Warm soil temps, stress                     │
│      • Internal stem discoloration (cut stem to check)         │
│      • Often one-sided wilting                                 │
│                                                                 │
│  SUDDEN COLLAPSE AT SOIL LINE                                   │
│  └── Damping Off (multiple pathogens)                          │
│      • Affects seedlings                                       │
│      • Stem constricted at media surface                       │
│      • Conditions: Overwatering, cold, overcrowding            │
│                                                                 │
│  CROWN ROT / SOFT BASE                                          │
│  └── Rhizoctonia or Sclerotinia                                │
│      • Brown, sunken lesions at crown                          │
│      • May see white fungal strands                            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## Common Diseases Reference

### Powdery Mildew
| Factor | Details |
|--------|---------|
| **Type** | Fungal (multiple species) |
| **Crops** | Cucurbits, tomatoes, peppers, herbs |
| **Conditions** | Moderate temps (60-80°F), moderate humidity, poor airflow |
| **Spread** | Airborne spores |
| **Prevention** | Good airflow, resistant varieties, avoid overcrowding |
| **Treatment** | Potassium bicarbonate, sulfur (some crops), biological fungicides |

### Botrytis (Gray Mold)
| Factor | Details |
|--------|---------|
| **Type** | Fungal (Botrytis cinerea) |
| **Crops** | All, especially dense crops and flowers |
| **Conditions** | Cool temps (65-75°F), high humidity (>85%), still air |
| **Spread** | Airborne spores, enters through wounds |
| **Prevention** | Lower humidity, increase airflow, remove debris |
| **Treatment** | Remove infected material, improve environment, biological fungicides |

### Pythium Root Rot
| Factor | Details |
|--------|---------|
| **Type** | Oomycete (water mold) |
| **Crops** | All, especially seedlings |
| **Conditions** | Waterlogged media, warm temps (77-86°F) |
| **Spread** | Water, contaminated media |
| **Prevention** | Good drainage, sterile media, avoid overwatering |
| **Treatment** | Remove affected plants, improve drainage, biological controls |

### Downy Mildew
| Factor | Details |
|--------|---------|
| **Type** | Oomycete (species-specific) |
| **Crops** | Lettuce, basil, cucurbits |
| **Conditions** | Cool temps (50-70°F), high humidity, wet leaves |
| **Spread** | Airborne spores, water splash |
| **Prevention** | Resistant varieties, avoid leaf wetness, good airflow |
| **Treatment** | Remove infected plants, copper fungicides, biological controls |

### Fusarium Wilt
| Factor | Details |
|--------|---------|
| **Type** | Fungal (Fusarium oxysporum) |
| **Crops** | Tomatoes, lettuce, basil (race-specific) |
| **Conditions** | Warm temps, plant stress |
| **Spread** | Contaminated soil/water, tools |
| **Prevention** | Resistant varieties, sanitation, clean water |
| **Treatment** | No cure - remove plants, sanitize system, resistant varieties |

## Disease Triangle

```
                    DISEASE
                       △
                      /|\
                     / | \
                    /  |  \
                   /   |   \
                  /    |    \
                 /     |     \
                /      |      \
               /       |       \
              /________|________\
         HOST     ENVIRONMENT    PATHOGEN


ALL THREE MUST BE PRESENT FOR DISEASE TO OCCUR

CONTROL STRATEGIES:
├── HOST: Use resistant varieties, healthy transplants
├── ENVIRONMENT: Manage temp, humidity, airflow
└── PATHOGEN: Sanitation, exclusion, biological controls
```

## Environmental Conditions Favoring Disease

| Condition | Diseases Favored | Prevention |
|-----------|------------------|------------|
| High humidity (>85%) | Botrytis, downy mildew | Ventilation, dehumidification |
| Wet leaves | Bacterial diseases, downy mildew | Overhead watering avoidance, morning watering |
| Poor airflow | Most fungal diseases | HAF fans, plant spacing |
| Waterlogged media | Pythium, damping off | Proper drainage, avoid overwatering |
| Temperature swings | Powdery mildew | Climate control |
| Plant stress | All diseases | Proper nutrition, watering |

## Sanitation Protocol

### Daily
- [ ] Remove dead/dying plant material
- [ ] Clean up fallen leaves and debris
- [ ] Sanitize harvest tools between plants if disease present

### Weekly
- [ ] Inspect all plants for symptoms
- [ ] Clean growing surfaces
- [ ] Replace dirty solution/water
- [ ] Check and clean filters

### Between Crops
- [ ] Remove all plant material
- [ ] Clean and sanitize all surfaces
- [ ] Sanitize irrigation system
- [ ] Replace or sterilize growing media
- [ ] Clean tools and equipment

### Sanitizer Options
| Product | Concentration | Contact Time | Notes |
|---------|---------------|--------------|-------|
| Hydrogen peroxide | 3% | 10 minutes | Safe, breaks down |
| Quaternary ammonium | Per label | 10 minutes | Residual activity |
| Chlorine bleach | 1:10 dilution | 10 minutes | Make fresh daily |
| Alcohol | 70% | 1 minute | Quick tool sanitizing |
