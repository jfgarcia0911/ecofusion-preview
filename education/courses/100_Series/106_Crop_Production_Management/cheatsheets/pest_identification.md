## Common Greenhouse Pests

### Aphids
```
┌─────────────────────────────────────────────────────────────────┐
│  APHIDS                                                         │
├─────────────────────────────────────────────────────────────────┤
│  Size: 1-3 mm        Color: Green, black, pink, yellow         │
│                                                                 │
│  IDENTIFICATION:                                                │
│  • Soft-bodied, pear-shaped insects                            │
│  • Often clustered on new growth, undersides of leaves         │
│  • Two "tail pipes" (cornicles) visible on rear                │
│  • May be winged or wingless                                   │
│                                                                 │
│  DAMAGE SIGNS:                                                  │
│  • Sticky "honeydew" residue on leaves                         │
│  • Curled, distorted new growth                                │
│  • Sooty mold (black fungus growing on honeydew)               │
│  • Stunted plant growth                                        │
│                                                                 │
│  BIOLOGICAL CONTROLS:                                           │
│  • Ladybugs (Hippodamia convergens)                            │
│  • Green lacewings (Chrysoperla carnea)                        │
│  • Parasitic wasps (Aphidius colemani)                         │
│  • Aphid midges (Aphidoletes aphidimyza)                       │
│                                                                 │
│  PREVENTION:                                                    │
│  • Inspect incoming plants                                      │
│  • Screen vents and openings                                   │
│  • Remove heavily infested plants                              │
│  • Avoid over-fertilization with nitrogen                      │
└─────────────────────────────────────────────────────────────────┘
```

### Fungus Gnats
```
┌─────────────────────────────────────────────────────────────────┐
│  FUNGUS GNATS                                                   │
├─────────────────────────────────────────────────────────────────┤
│  Adult: 2-3 mm        Larvae: 4-6 mm (white with black head)   │
│                                                                 │
│  IDENTIFICATION:                                                │
│  • Small, dark flies hovering near soil/media surface          │
│  • Long legs and antennae                                      │
│  • Weak, erratic flight pattern                                │
│  • Larvae are translucent white with shiny black head          │
│                                                                 │
│  DAMAGE SIGNS:                                                  │
│  • Weak seedlings, poor establishment                          │
│  • Root damage (larvae feed on roots and organic matter)       │
│  • Adult gnats flying when media is disturbed                  │
│  • Visible larvae in growing media                             │
│                                                                 │
│  BIOLOGICAL CONTROLS:                                           │
│  • Hypoaspis miles (soil predatory mite)                       │
│  • Steinernema feltiae (beneficial nematodes)                  │
│  • Bt (Bacillus thuringiensis var. israelensis)                │
│  • Rove beetles (Dalotia coriaria)                             │
│                                                                 │
│  PREVENTION:                                                    │
│  • Allow media surface to dry between waterings                │
│  • Use yellow sticky cards for monitoring                      │
│  • Avoid overwatering                                          │
│  • Use sterile growing media                                   │
└─────────────────────────────────────────────────────────────────┘
```

### Spider Mites
```
┌─────────────────────────────────────────────────────────────────┐
│  TWO-SPOTTED SPIDER MITES                                       │
├─────────────────────────────────────────────────────────────────┤
│  Size: <0.5 mm        Color: Pale green/yellow with 2 spots    │
│                                                                 │
│  IDENTIFICATION:                                                │
│  • Nearly microscopic - use hand lens                          │
│  • Eight legs (not insects - arachnids)                        │
│  • Two dark spots visible on body                              │
│  • Found on leaf undersides                                    │
│                                                                 │
│  DAMAGE SIGNS:                                                  │
│  • Fine webbing on leaves and between stems                    │
│  • Stippled, bronzed, or yellowed leaves                       │
│  • Tiny white/yellow dots (feeding damage)                     │
│  • Severe: complete leaf bronzing and drop                     │
│                                                                 │
│  BIOLOGICAL CONTROLS:                                           │
│  • Phytoseiulus persimilis (predatory mite)                    │
│  • Neoseiulus californicus (predatory mite)                    │
│  • Feltiella acarisuga (predatory midge)                       │
│                                                                 │
│  PREVENTION:                                                    │
│  • Maintain humidity above 60%                                 │
│  • Inspect new plants thoroughly                               │
│  • Avoid plant stress (drought, heat)                          │
│  • Regular monitoring with hand lens                           │
│                                                                 │
│  ⚠️  Spider mites reproduce rapidly in hot, dry conditions!    │
└─────────────────────────────────────────────────────────────────┘
```

### Thrips
```
┌─────────────────────────────────────────────────────────────────┐
│  THRIPS                                                         │
├─────────────────────────────────────────────────────────────────┤
│  Size: 1-2 mm        Color: Yellow, brown, or black            │
│                                                                 │
│  IDENTIFICATION:                                                │
│  • Tiny, slender insects with fringed wings                    │
│  • Very fast moving when disturbed                             │
│  • Difficult to see without magnification                      │
│  • Often found in flowers and new growth                       │
│                                                                 │
│  DAMAGE SIGNS:                                                  │
│  • Silver/gray streaks or patches on leaves                    │
│  • Distorted or scarred new growth                             │
│  • Black fecal spots on leaves                                 │
│  • Flower damage, poor fruit set                               │
│                                                                 │
│  BIOLOGICAL CONTROLS:                                           │
│  • Amblyseius cucumeris (predatory mite)                       │
│  • Orius insidiosus (minute pirate bug)                        │
│  • Steinernema feltiae (nematodes for pupae in soil)           │
│                                                                 │
│  PREVENTION:                                                    │
│  • Blue sticky cards for monitoring                            │
│  • Screen vents (thrips can enter through tiny gaps)           │
│  • Remove weeds and plant debris                               │
│  • Inspect flowers carefully on incoming plants                │
│                                                                 │
│  ⚠️  Thrips vector several serious plant viruses!              │
└─────────────────────────────────────────────────────────────────┘
```

### Whiteflies
```
┌─────────────────────────────────────────────────────────────────┐
│  WHITEFLIES                                                     │
├─────────────────────────────────────────────────────────────────┤
│  Size: 1-2 mm        Color: White (adults), pale green (nymph) │
│                                                                 │
│  IDENTIFICATION:                                                │
│  • Small white moths that fly up when plant disturbed          │
│  • Found on leaf undersides                                    │
│  • Nymphs are flat, oval, scale-like                           │
│  • "Snowstorm" effect when plant shaken                        │
│                                                                 │
│  DAMAGE SIGNS:                                                  │
│  • Sticky honeydew on leaves                                   │
│  • Sooty mold development                                      │
│  • Yellowing, weakened plants                                  │
│  • White "scale" nymphs on leaf undersides                     │
│                                                                 │
│  BIOLOGICAL CONTROLS:                                           │
│  • Encarsia formosa (parasitic wasp)                           │
│  • Eretmocerus eremicus (parasitic wasp)                       │
│  • Delphastus catalinae (beetle)                               │
│                                                                 │
│  PREVENTION:                                                    │
│  • Yellow sticky traps for monitoring                          │
│  • Screen all vents and openings                               │
│  • Inspect incoming plants thoroughly                          │
│  • Remove heavily infested material                            │
└─────────────────────────────────────────────────────────────────┘
```

## Monitoring Tools

| Tool | Target Pests | Placement |
|------|--------------|-----------|
| Yellow sticky cards | Fungus gnats, whiteflies, aphids (winged) | 1-2 per 1,000 sq ft, just above canopy |
| Blue sticky cards | Thrips | Near flowers and new growth |
| Potato slices | Fungus gnat larvae | On media surface |
| Hand lens (10x-20x) | Spider mites, thrips | Inspect leaf undersides |
| White paper | Thrips, mites | Tap foliage over paper to see pests |

---

## Action Thresholds

| Pest | Low | Moderate | High |
|------|-----|----------|------|
| Aphids | <5/plant | 5-20/plant | >20/plant |
| Fungus gnats | <5 adults/trap/week | 5-25/trap/week | >25/trap/week |
| Spider mites | <5% leaves affected | 5-25% leaves | >25% leaves |
| Thrips | <5/trap/week | 5-25/trap/week | >25/trap/week |
| Whiteflies | <3/trap/week | 3-10/trap/week | >10/trap/week |

## Beneficial Release Rates

| Beneficial | Target Pest | Rate | Notes |
|------------|-------------|------|-------|
| Ladybugs | Aphids | 1/sq ft | Evening release, mist plants |
| Lacewings | Aphids, mites | 1/10 sq ft | Larvae are predators |
| Aphidius colemani | Aphids | 0.5-2/sq ft | Preventive release best |
| Phytoseiulus | Spider mites | 2-5/sq ft | High humidity needed |
| Hypoaspis miles | Fungus gnats | 10-50/sq ft | Apply to media |
| Encarsia formosa | Whiteflies | 2-5/sq ft | Best at 70-80°F |
