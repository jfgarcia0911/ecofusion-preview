## Lesson Content

### 1.1 Core Design Principles

#### The Foundation of Good Design

Every successful growing system begins with solid design principles. These principles ensure your system is:

- **Functional** - Meets production goals
- **Sustainable** - Minimizes resource use
- **Scalable** - Can grow with your needs
- **Maintainable** - Easy to service and repair
- **Economic** - Cost-effective to build and operate


#### Key Design Considerations

| Consideration | Questions to Ask | Impact |
|---------------|------------------|--------|
| **Purpose** | What will you grow? How much? | Determines system size & type |
| **Location** | Indoor or outdoor? Climate? | Affects environmental control needs |
| **Resources** | Water availability? Power access? | Influences system selection |
| **Budget** | Initial investment? Operating costs? | Sets realistic scope |
| **Experience** | Skill level? Time commitment? | Guides complexity level |
| **Market** | Who will buy? Distribution? | Shapes production strategy |

### 1.2 The Design Cycle

#### A Systematic Approach

Good design is iterative. Follow this proven cycle:

```
THE DESIGN CYCLE

    ┌─────────────────────────────────────────────┐
    │                                             │
    │  1. DEFINE                                  │
    │     • Goals & objectives                    │
    │     • Requirements & constraints            │
    │     └──────┬──────────────────────────────┐ │
    │            ▼                               │ │
    │  2. RESEARCH                               │ │
    │     • Existing solutions                   │ │
    │     • Best practices                       │ │
    │     • Technologies available               │ │
    │     └──────┬──────────────────────────────┘ │
    │            ▼                                 │
    │  3. DESIGN                                   │
    │     • Sketch concepts                        │
    │     • Create detailed plans                  │
    │     • Calculate dimensions                   │
    │     └──────┬─────────────────────────────┐   │
    │            ▼                              │   │
    │  4. EVALUATE                              │   │
    │     • Check against requirements          │   │
    │     • Cost analysis                       │   │
    │     • Risk assessment                     │   │
    │     └──────┬──────────────────────────────┘  │
    │            ▼                                  │
    │  5. REFINE                                    │
    │     • Improve design                          │
    │     • Optimize performance                    │
    │     • Reduce costs                            │
    │     └──────┬──────────────────────────────┐   │
    │            ▼                               │   │
    │  6. BUILD ────► Test ──► Iterate ─────────┘   │
    │                                                │
    └────────────────────────────────────────────────┘
```

#### Design Phase Breakdown

| Phase | Duration | Key Deliverables |
|-------|----------|------------------|
| Define | 5-10% | Goals, requirements document |
| Research | 15-20% | Technology review, site assessment |
| Design | 30-40% | Detailed plans, parts list, budget |
| Evaluate | 15-20% | Analysis report, risk assessment |
| Refine | 15-20% | Optimized design, final plans |
| Build | Variable | Constructed system |

### 1.3 System Types and Selection

#### Hydroponic System Types

| System Type | Description | Best For | Complexity |
|-------------|-------------|----------|------------|
| **Deep Water Culture (DWC)** | Plants float in oxygenated nutrient solution | Leafy greens, herbs | Low |
| **Nutrient Film Technique (NFT)** | Thin film of nutrients flows past roots | Leafy greens, strawberries | Medium |
| **Drip System** | Nutrients dripped onto growing media | Tomatoes, peppers, cucumbers | Medium |
| **Ebb & Flow** | Periodic flooding and draining | Variety of crops | Medium |
| **Aeroponics** | Roots misted with nutrient solution | High-value crops | High |
| **Kratky Method** | Passive, no pumps required | Lettuce, herbs (small scale) | Very Low |

#### Aquaponic System Types

| System Type | Description | Best For | Complexity |
|-------------|-------------|----------|------------|
| **Media Bed** | Gravel/clay pebbles filter and grow | Root vegetables, diverse crops | Low-Medium |
| **DWC (Raft)** | Plants float, separate biofilter | Leafy greens, high volume | Medium |
| **NFT** | Nutrient film with biofilter | Leafy greens, herbs | Medium-High |
| **Hybrid** | Combines multiple techniques | Maximum production diversity | High |

```
SYSTEM SELECTION FLOWCHART

START: What do you want to grow?
    │
    ├─► Leafy Greens (lettuce, herbs)
    │   │
    │   ├─► Small scale, simple ──► Kratky or DWC
    │   │
    │   └─► Commercial scale ──► NFT or Raft Aquaponics
    │
    ├─► Fruiting Plants (tomatoes, peppers)
    │   │
    │   ├─► Hydroponic ──► Drip System or Dutch Bucket
    │   │
    │   └─► Aquaponic ──► Media Bed or Hybrid
    │
    └─► Root Vegetables (carrots, radishes)
        │
        └─► Media Bed Aquaponics (best option)

Experience Level Check:
    • Beginner ──► DWC, Kratky, Simple Media Bed
    • Intermediate ──► NFT, Drip, Ebb & Flow
    • Advanced ──► Aeroponics, Hybrid Systems
```

### 1.4 Site Assessment and Planning

#### Critical Site Factors

**A. Space Requirements**

| System Component | Space Allocation | Notes |
|------------------|------------------|-------|
| Growing area | 70-80% | Primary production |
| Walkways/access | 10-15% | Maintenance, harvest |
| Equipment | 5-10% | Pumps, filters, storage |
| Work area | 5% | Transplanting, packaging |

**C. Resource Availability**

| Resource | Minimum Requirement | Optimal |
|----------|---------------------|---------|
| **Water** | Municipal or well, tested | Low TDS, pH 6.5-7.5 |
| **Power** | 120V, 20A | 240V, dedicated circuits |
| **Internet** | Optional | Recommended for monitoring |
| **Climate Control** | Varies by location | 65-75°F, 50-70% humidity |

### 1.5 Design Considerations by System Type

#### Hydroponic Design Priorities

| Priority | Consideration | Design Impact |
|----------|---------------|---------------|
| 1 | Nutrient delivery | Pump sizing, pipe diameter |
| 2 | Oxygenation | Air pump capacity, water movement |
| 3 | Light | Natural vs. supplemental LED |
| 4 | Temperature | Heaters, chillers, insulation |
| 5 | pH/EC stability | Monitoring, dosing systems |

#### Aquaponic Design Priorities

| Priority | Consideration | Design Impact |
|----------|---------------|---------------|
| 1 | Fish tank size | Determines system capacity |
| 2 | Filtration | Mechanical & biological requirements |
| 3 | Grow bed ratio | 1:1 or 1:2 fish tank to grow bed |
| 4 | Water circulation | Pump sizing critical |
| 5 | Aeration | For fish and bacteria |

```
AQUAPONIC SYSTEM RATIOS

Fish Tank Volume : Grow Bed Volume

        1 : 1  (Balanced, beginner-friendly)
          │
          ├── 100 gal fish tank
          └── 100 gal grow bed volume

        1 : 2  (More plant production)
          │
          ├── 100 gal fish tank
          └── 200 gal grow bed volume

Stocking Density:
    • 1 lb of fish per 5-10 gallons (conservative)
    • 1 lb of fish per 3-5 gallons (intensive)

Plant Density:
    • Leafy greens: 1 plant per sq ft
    • Fruiting plants: 2-4 sq ft per plant
```

### 1.6 Scale and Production Planning

#### Sizing Your System

**Home Scale (Personal Use)**
- Growing area: 20-100 sq ft
- Production: 5-15 lbs/week
- Investment: $500-$3,000
- Time commitment: 5-10 hrs/week

**Market Garden (Local Sales)**
- Growing area: 500-2,000 sq ft
- Production: 50-200 lbs/week
- Investment: $10,000-$50,000
- Time commitment: 20-40 hrs/week

**Commercial (Full-time Business)**
- Growing area: 5,000+ sq ft
- Production: 500+ lbs/week
- Investment: $100,000+
- Time commitment: Full-time staff

#### Production Capacity Estimation

| Crop Type | Plants per sq ft | Harvest Cycle | Annual Production per sq ft |
|-----------|------------------|---------------|----------------------------|
| **Lettuce** | 4 | 35 days | 40 heads |
| **Basil** | 4 | 28 days | 8 lbs |
| **Tomatoes** | 0.25 | 120 days | 25 lbs |
| **Peppers** | 0.5 | 90 days | 15 lbs |
| **Strawberries** | 1 | Year-round | 20 lbs |

### 1.7 Safety and Regulatory Considerations

#### Design for Safety

```
SAFETY DESIGN PRINCIPLES

ELECTRICAL
┌─────────────────────────────────────┐
│ • GFCI outlets required near water  │
│ • Proper wire gauge for load        │
│ • Water-resistant enclosures        │
│ • Emergency shutoff accessible      │
└─────────────────────────────────────┘

STRUCTURAL
┌─────────────────────────────────────┐
│ • Calculate load capacity           │
│ • Secure tanks and structures       │
│ • Safe walkways and platforms       │
│ • Fall protection if elevated       │
└─────────────────────────────────────┘

WATER
┌─────────────────────────────────────┐
│ • Prevent overflow                  │
│ • Backflow prevention               │
│ • Drainage for spills               │
│ • Water quality monitoring          │
└─────────────────────────────────────┘

CHEMICAL
┌─────────────────────────────────────┐
│ • Proper storage for nutrients      │
│ • Ventilation for CO2/fertilizers   │
│ • Spill containment                 │
│ • Personal protective equipment     │
└─────────────────────────────────────┘
```

#### Regulatory Checklist

| Area | Considerations | Action Required |
|------|----------------|-----------------|

## Vocabulary

| Term | Definition |
|------|------------|
| **Design Cycle** | Iterative process of planning, evaluating, and refining before building |
| **Stocking Density** | Amount of fish per volume of water in aquaponics |
| **Growing Ratio** | Relationship between fish tank and grow bed volume |
| **Load Capacity** | Maximum weight a structure can safely support |
| **GFCI** | Ground Fault Circuit Interrupter - safety device for electrical near water |
| **TDS** | Total Dissolved Solids - measurement of water purity |
| **Biofilter** | Biological filtration system for converting fish waste |
| **Redundancy** | Backup systems to prevent single point of failure |
