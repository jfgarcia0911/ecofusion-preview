### 8.1 Preventive Maintenance Schedule

#### Daily Tasks (5-10 minutes)

```
DAILY MAINTENANCE CHECKLIST

VISUAL INSPECTION
□ Water levels normal
□ All pumps running
□ Fish behavior normal (active, eating)
□ Plants healthy (no wilting, pests)
□ No unusual odors
□ Temperature in range

FEEDING
□ Feed fish appropriate amount
□ Remove any uneaten food after 5 min
□ Observe feeding behavior

QUICK TESTS (Optional but recommended)
□ pH check
□ Temperature reading
□ Note any changes in log
```

#### Weekly Tasks (30-60 minutes)

```
WEEKLY MAINTENANCE

WATER TESTING
□ pH
□ Ammonia
□ Nitrite
□ Nitrate
□ Temperature
□ EC/TDS (hydroponics)
□ Record all results

EQUIPMENT CHECK
□ Clean pump pre-filters
□ Check air stone output
□ Inspect plumbing for leaks
□ Test GFCI outlets
□ Verify timer settings

PLANT CARE
□ Inspect for pests/disease
□ Remove dead leaves
□ Harvest mature crops
□ Note growth rates

FISH HEALTH
□ Observe for disease signs
□ Check for injuries
□ Verify all fish present
□ Assess body condition
```

#### Monthly Tasks (2-3 hours)

```
MONTHLY MAINTENANCE

DEEP CLEANING
□ Clean biofilter (gently!)
□ Remove solid waste buildup
□ Wipe down tanks (outside)
□ Clean light reflectors
□ Organize work area

SYSTEM CHECKS
□ Calibrate pH and EC meters
□ Test backup systems
□ Inspect all seals and gaskets
□ Check structural stability
□ Lubricate moving parts (if needed)

WATER MANAGEMENT
□ Partial water change (10-20% if needed)
□ Top off evaporation
□ Test source water quality
□ Clean water filters

PLANT MANAGEMENT
□ Deep plant inspection
□ Prune as needed
□ Replant gaps
□ Adjust spacing for growth

RECORD KEEPING
□ Review monthly data trends
□ Update inventory
□ Check supply levels
□ Plan next month's tasks
```

#### Seasonal Tasks

| Season | Special Tasks |
|--------|---------------|
| **Spring** | Deep clean after winter, increase feeding, add new plants |
| **Summer** | Monitor temperature closely, shade if needed, increase aeration |
| **Fall** | Reduce feeding gradually, harvest before frost, prepare for winter |
| **Winter** | Reduce feeding (outdoor), maintain temperature, ensure heaters work |

### 8.2 Systematic Troubleshooting

#### The Troubleshooting Process

```
STEP-BY-STEP PROBLEM SOLVING

1. OBSERVE
   What exactly is wrong?
   When did it start?
   What changed recently?

2. GATHER DATA
   Test water parameters
   Check equipment operation
   Review recent logs

3. HYPOTHESIZE
   What are possible causes?
   List from most to least likely

4. TEST
   Start with simplest/cheapest fix
   Change ONE thing at a time
   Document results

5. VERIFY
   Did the problem resolve?
   Monitor for 24-48 hours
   Confirm stability

6. PREVENT
   What caused it?
   How to prevent recurrence?
   Update maintenance plan
```

### 8.3 Common Problems: Fish Health

#### Fish Health Troubleshooting Matrix

| Symptom | Possible Cause | Check | Solution |
|---------|---------------|-------|----------|
| **Gasping at surface** | Low oxygen | DO level, pump | Increase aeration |
| | High ammonia | Ammonia test | Reduce feeding, water change |
| **Clamped fins** | Stress, disease | All parameters | Improve water quality |
| | Low temperature | Thermometer | Add heater |
| **Red/bloody streaks** | Ammonia burn | Ammonia test | Emergency water change |
| | Bacterial infection | Isolation | Treat infection |
| **White spots** | Ich parasite | Visual exam | Salt treatment, raise temp |
| **Not eating** | Stress | Recent changes | Give time, improve conditions |
| | Disease | Full health check | Isolate, diagnose |
| **Flashing/rubbing** | Parasites | Close inspection | Salt bath, treatment |
| | Poor water quality | Test all parameters | Water change, adjust |
| **Fuzzy growth** | Fungal infection | Visual exam | Improve circulation, treat |
| **Rapid breathing** | Low oxygen | DO test | Increase aeration |
| | High nitrite | Nitrite test | Water change, add salt |

```
EMERGENCY FISH TREATMENT

AMMONIA SPIKE (>1 ppm)
    1. Stop feeding immediately
    2. 50% water change
    3. Double aeration
    4. Test after 2 hours
    5. Repeat water change if needed

NITRITE SPIKE (>5 ppm)
    1. Stop feeding
    2. 30% water change
    3. Add salt (1 ppm salt per 1 ppm nitrite)
    4. Increase aeration
    5. Monitor daily

ICH OUTBREAK
    1. Raise temperature to 82°F gradually
    2. Add salt (1-3 tablespoons per gallon)
    3. Remove plants if salt sensitive
    4. Maintain 2 weeks minimum
    5. Quarantine new fish in future
```

### 8.4 Common Problems: Water Quality

#### Water Quality Troubleshooting

```
pH PROBLEMS

pH Too Low (<6.5)
    Causes:
        • Nitrification (produces acid)
        • Lack of buffering capacity
        • Overstocking/overfeeding

    Solutions:
        1. Add buffer (crushed coral, oyster shell)
        2. Small water change with higher pH water
        3. Reduce feeding rate
        4. Add potassium hydroxide (carefully)

    Prevention:
        • Monitor pH trends
        • Maintain adequate buffering
        • Don't overstock

pH Too High (>8.0)
    Causes:
        • Hard water source
        • Too much base added
        • Algae bloom (photosynthesis)

    Solutions:
        1. Dilute with lower pH water
        2. Add pH down (carefully)
        3. Control algae
        4. Reduce lighting period

    Prevention:
        • Test source water
        • Add adjustments slowly
        • Control algae growth
```

```
AMMONIA/NITRITE PROBLEMS

Ammonia Won't Drop to Zero
    Causes:
        • Overfeeding
        • Dead fish/organic matter
        • Insufficient biofilter
        • Biofilter damaged

    Solutions:
        □ Reduce feeding by 50%
        □ Remove dead material
        □ Increase aeration
        □ Add more biofilter media
        □ Water changes (temporary)

Nitrite Spike in Established System
    Causes:
        • Biofilter disruption (cleaned too aggressively)
        • Medication killed bacteria
        • Sudden increase in feeding
        • Temperature drop

    Solutions:
        □ Stop feeding 1-2 days
        □ Water change 25%
        □ Add salt temporarily
        □ Wait for re-establishment
        □ Don't deep clean biofilter
```

### 8.5 Common Problems: Plant Health

#### Plant Problem Diagnosis

```
NUTRIENT DEFICIENCIES

Nitrogen (N) - Most Common
    Symptoms:
        • Overall yellowing
        • Starts with older leaves
        • Slow growth

    Aquaponics: Increase feeding
    Hydroponics: Check/increase EC

Phosphorus (P)
    Symptoms:
        • Purple/dark leaves
        • Stunted growth

    Solution: Add supplement

Potassium (K)
    Symptoms:
        • Brown leaf edges
        • Weak stems

    Solution: Add potassium supplement

Iron (Fe)
    Symptoms:
        • Yellow between veins (new leaves)
        • Chlorosis

    Solution: Add chelated iron

Calcium (Ca)
    Symptoms:
        • Tip burn
        • Blossom end rot

    Solution: Add calcium supplement
```

#### Pest and Disease Management

| Problem | Identification | Treatment |
|---------|---------------|-----------|
| **Aphids** | Small green/black insects on new growth | Spray with water, neem oil |
| **Whiteflies** | Tiny white flies under leaves | Yellow sticky traps, neem oil |
| **Spider Mites** | Fine webbing, stippled leaves | Increase humidity, neem oil |
| **Fungus Gnats** | Small flies in media, larvae in roots | Reduce moisture, BTI treatment |
| **Powdery Mildew** | White powder on leaves | Improve airflow, sulfur spray |
| **Root Rot** | Brown mushy roots | Increase oxygen, remove affected plants |

### 8.6 Equipment Failures

#### Pump Problems

```
PUMP TROUBLESHOOTING

Pump Not Running
    □ Check power (outlet, breaker, GFCI)
    □ Test with different outlet
    □ Inspect cord for damage
    □ Listen for humming (clogged?)
    □ Clean impeller
    □ Replace if burned out

Pump Running But Low Flow
    □ Clean pre-filter/intake
    □ Remove debris from impeller
    □ Check for kinked hoses
    □ Look for air locks
    □ Verify valves are open

Pump Noisy
    □ Check for cavitation (inlet restriction)
    □ Ensure adequate water level
    □ Clean impeller
    □ Check for worn bearings
    □ May need replacement

Pump Short Cycling
    □ Electrical issue (check GFCI)
    □ Thermal overload (running hot)
    □ Failing motor
    □ Replace pump
```

#### Other Equipment Issues

| Equipment | Problem | Solution |
|-----------|---------|----------|
| **Air Pump** | Weak output | Clean air stones, check diaphragm |
| | Noisy | Place on foam pad, replace if worn |
| **Lights** | Not turning on | Check timer, bulb, ballast |
| | Flickering | Tighten connections, replace bulb |
| **Heater** | Won't maintain temp | Check thermostat, replace if needed |
| | Overheating | Unplug immediately, replace |
| **Timer** | Not switching | Replace battery (if digital), replace unit |
| | Lost program | Re-program, consider backup |

### 8.7 Seasonal Adjustments

#### Temperature Management

```
SUMMER COOLING STRATEGIES

□ Shade tanks and reservoirs
□ Increase aeration (cools through evaporation)
□ Run pumps at night (cooler)
□ Add fans for air circulation
□ Float frozen water bottles in tanks
□ Install chiller (if budget allows)
□ Reduce stocking density
□ Feed less (fish need less at high temps)

WINTER HEATING STRATEGIES

□ Insulate tanks and pipes
□ Use aquarium heaters
□ Create greenhouse enclosure
□ Reduce air exchange
□ Install backup heater
□ Monitor closely
□ Reduce feeding (fish metabolism slows)
□ Protect pipes from freezing
```

### 8.8 System Optimization

#### Improving Efficiency

```
OPTIMIZATION CHECKLIST

ENERGY EFFICIENCY
□ LED lighting instead of fluorescent
□ Efficient pumps (check GPH per watt)
□ Timer for non-critical equipment
□ Insulation to reduce heating/cooling
□ Solar panels for supplemental power

WATER EFFICIENCY
□ Reduce evaporation (cover tanks)
□ Fix all leaks promptly
□ Collect rainwater for top-offs
□ Optimize flow rates (not excessive)

PRODUCTIVITY
□ Maximize planting density
□ Succession planting (continuous harvest)
□ Vertical growing (more plants per sq ft)
□ Optimal fish stocking
□ Fast-growing varieties
□ Proper spacing

LABOR EFFICIENCY
□ Organize tools and supplies
□ Batch tasks
□ Automate where cost-effective
□ Good record keeping
□ Efficient workflow layout
```

### 8.9 Long-term System Management

#### Annual Deep Maintenance

```
YEARLY TASKS

COMPLETE SYSTEM DRAIN (Optional, every 1-2 years)
    1. Plan during slow season
    2. Relocate fish to holding tank
    3. Harvest all plants
    4. Drain system completely
    5. Deep clean all components
    6. Inspect for wear/damage
    7. Replace worn parts
    8. Re-plumb if needed
    9. Refill and re-cycle
    10. Re-stock gradually

EQUIPMENT REPLACEMENT SCHEDULE
    • Water pumps: 2-3 years (or as needed)
    • Air pumps: 3-5 years
    • Grow lights: Per manufacturer (LEDs 5-10 years)
    • Plumbing: Inspect, replace if degraded
    • Test kits: Replace reagents yearly
    • Meters: Calibrate quarterly, replace sensors as needed
```

#### Record Keeping for Optimization

```
LONG-TERM DATA TRACKING

PRODUCTION RECORDS
    • Harvest quantities and dates
    • Growth rates by variety
    • Success/failure rates
    • Seasonal patterns

MAINTENANCE RECORDS
    • Tasks performed and when
    • Parts replaced
    • Problems encountered

FINANCIAL RECORDS
    • Input costs (feed, power, supplies)
    • Harvest value
    • ROI calculations
    • Cost per pound produced

USE DATA TO:
    ✓ Identify best-performing varieties
    ✓ Optimize feeding rates
    ✓ Predict harvest times
    ✓ Prevent recurring problems
    ✓ Improve profitability
```

### 8.10 Emergency Preparedness

#### System Failure Response

```
EMERGENCY ACTION PLAN

POWER OUTAGE
    1. Manual aeration (battery air pump or hand agitate)
    2. Don't feed (conserves oxygen)
    3. Minimize stress to fish
    4. Start generator if available
    5. After power returns: Test water, resume gradually

MAJOR LEAK
    1. Turn off pumps immediately
    2. Contain water (towels, pumps)
    3. Move fish if needed
    4. Identify leak source
    5. Emergency repair or replace
    6. Document for insurance

PUMP FAILURE
    1. Install backup pump immediately
    2. Increase aeration
    3. Order replacement pump
    4. Monitor water quality closely

DISEASE OUTBREAK
    1. Isolate affected fish
    2. Improve water quality
    3. Research treatment options
    4. Treat in quarantine tank if possible
    5. Prevent spread to healthy fish

FREEZE WARNING
    1. Add heaters
    2. Insulate exposed pipes
    3. Run water continuously (prevents freeze)
    4. Monitor temperature hourly
```

#### Backup Systems

| Critical Function | Primary | Backup Option | Cost |
|------------------|---------|---------------|------|
| **Aeration** | Electric air pump | Battery air pump | $30-60 |
| | | Manual agitation | Free |
| **Circulation** | Main pump | Spare pump on hand | $50-200 |
| **Power** | Grid electricity | UPS battery backup | $200-500 |
| | | Generator | $500-2000 |
| **Temperature** | Heater | Backup heater | $20-50 |

### 8.11 Troubleshooting Decision Tree

```
SYSTEMATIC PROBLEM SOLVING

START: Is there a problem?
    │
    ├─► FISH showing symptoms?
    │   ├─► Test water quality immediately
    │   ├─► Check temperature and oxygen
    │   └─► See fish health troubleshooting
    │
    ├─► PLANTS showing symptoms?
    │   ├─► Check pH range
    │   ├─► Look for pests
    │   └─► See nutrient deficiency chart
    │
    ├─► WATER quality issues?
    │   ├─► High ammonia/nitrite → See cycling issues
    │   ├─► pH problems → See pH troubleshooting
    │   └─► Other parameters → Adjust as needed
    │
    └─► EQUIPMENT not working?
        ├─► Electrical → Check power, GFCI, connections
        ├─► Mechanical → Clean, service, replace
        └─► Plumbing → Check for clogs, leaks, airlocks

GENERAL RULE:
    When in doubt:
    1. Test water
    2. Check equipment
    3. Review recent changes
    4. Consult resources
    5. Ask for help (forums, experts)
```
