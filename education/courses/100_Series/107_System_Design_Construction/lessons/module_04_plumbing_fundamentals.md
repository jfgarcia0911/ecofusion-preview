### 4.1 Plumbing Materials Overview

#### Pipe Material Comparison

| Material | Pros | Cons | Best Use | Cost |
|----------|------|------|----------|------|
| **PVC (Schedule 40)** | Inexpensive, easy to work with, durable | Can crack if frozen, UV degrades | Most aqua/hydro systems | $ |
| **CPVC** | Higher temp tolerance | More expensive than PVC | Hot water applications | $$ |
| **Flexible PVC** | Bendable, fewer fittings | Can kink, less durable | Temporary setups | $$ |
| **Black Poly Pipe** | UV resistant, flexible | Lower pressure rating | Outdoor, low-pressure | $ |
| **Vinyl Tubing** | Very flexible, clear options | Limited sizes, algae growth | Drip lines, air lines | $ |

```
PVC SCHEDULE COMPARISON

Schedule 40 (Standard)
├── Wall Thickness: Standard
├── Pressure Rating: 600+ PSI (1" pipe)
├── Cost: Least expensive
└── Use: Most aqua/hydro systems ✓

Schedule 80 (Heavy Duty)
├── Wall Thickness: Thicker walls
├── Pressure Rating: 850+ PSI (1" pipe)
├── Cost: 30-50% more
└── Use: High pressure, buried lines
```

#### Pipe Sizing Guide

| Pipe Size | Flow Capacity | Typical Use | Velocity |
|-----------|---------------|-------------|----------|
| **1/2"** | 5-8 GPM | Small drip lines, air | Low |
| **3/4"** | 8-15 GPM | Medium systems, branches | Medium |
| **1"** | 15-25 GPM | Main lines small-medium systems | Optimal |
| **1.5"** | 30-50 GPM | Large system mains | Optimal |
| **2"** | 50-80 GPM | Commercial mains, drains | High capacity |
| **3"** | 100+ GPM | Large commercial drains | Very high |

```
PIPE SIZE SELECTION RULE

Water Velocity Guidelines:
    • Too slow (<2 fps): Settling, poor mixing
    • Optimal (2-5 fps): Efficient flow
    • Too fast (>7 fps): Noise, wear, pressure drop

Formula:
    Velocity (fps) = (GPM × 0.408) ÷ (pipe diameter in inches)²

Example - 1" pipe with 600 GPH (10 GPM):
    (10 × 0.408) ÷ (1)² = 4.08 fps ✓ Optimal
```

#### Common PVC Fittings

```
FITTING TYPES AND USES

STRAIGHT CONNECTIONS
    ├─ Coupling: Joins two straight pipes
    ├─ Union: Removable connection
    └─ Adapter: Changes thread types

DIRECTION CHANGES
    ├─ 90° Elbow: Right angle turn
    ├─ 45° Elbow: Gradual turn (better flow)
    ├─ Street Elbow: One socket, one slip
    └─ Sweep Elbow: Large radius turn

BRANCHING
    ├─ Tee: Three-way connection
    ├─ Wye: Angled three-way (45°)
    └─ Cross: Four-way connection

SIZE CHANGES
    ├─ Reducer: Decrease pipe size
    ├─ Bushing: Threaded size change
    └─ Increaser: Increase pipe size

TERMINATIONS
    ├─ Cap: Close end of pipe
    ├─ Plug: Threaded closure
    └─ Cleanout: Removable access point
```

### 4.3 Bulkheads and Tank Penetrations

#### Bulkhead Installation

```
BULKHEAD INSTALLATION STEPS

STEP 1: Select Size
    ├─ Match pipe size
    ├─ Consider flow requirements
    └─ Check wall thickness compatibility

STEP 2: Mark and Drill
    ├─ Center punch location
    ├─ Drill pilot hole
    ├─ Use hole saw (bulkhead size + 1/8")
    └─ Deburr edges

STEP 3: Prepare Bulkhead
    ├─ Apply thread sealant to threads
    ├─ Place rubber gasket on threaded side
    └─ Do NOT over-tighten

STEP 4: Install
    ├─ Insert from outside tank
    ├─ Add internal gasket
    ├─ Hand-tighten nut inside
    ├─ Final tighten 1/4 turn with wrench
    └─ Test for leaks

Common Sizes:
    • 3/4" bulkhead: 1-3/8" hole
    • 1" bulkhead: 1-13/16" hole
    • 1.5" bulkhead: 2-3/8" hole
    • 2" bulkhead: 3" hole
```

#### Uniseal Alternative

```
UNISEAL ADVANTAGES

✓ Easier installation (no threading)
✓ Adjustable height after installation
✓ More forgiving with tank flex
✓ Lower cost
✓ Tool-free installation

Installation:
    1. Drill hole (specific size for each uniseal)
    2. Lubricate pipe and uniseal with dish soap
    3. Push pipe through uniseal
    4. Push assembly into tank hole
    5. Seats and seals automatically

Size Chart:
    • 1/2" pipe: 7/8" hole
    • 3/4" pipe: 1-1/8" hole
    • 1" pipe: 1-1/2" hole
    • 1.5" pipe: 2" hole
```

#### Cutting and Joining PVC

```
PROPER PVC JOINING TECHNIQUE

STEP 1: Measure and Cut
    ├─ Measure twice, cut once
    ├─ Mark cut line completely around pipe
    ├─ Use PVC cutter or saw (straight cut)
    └─ Deburr inside and outside edges

STEP 2: Test Fit
    ├─ Dry fit all pieces first
    ├─ Mark depth of fitting on pipe
    ├─ Check alignment
    └─ Plan cement sequence (no going back!)

STEP 3: Prepare Surfaces
    ├─ Clean with degreaser if dirty
    ├─ Ensure surfaces are dry
    ├─ Apply purple primer to both surfaces
    └─ Let primer dry (5-10 seconds)

STEP 4: Apply Cement
    ├─ Apply even coat to pipe (outside)
    ├─ Apply even coat to fitting (inside)
    ├─ Work quickly (15-30 sec working time)
    └─ Don't over-apply (drips waste cement)

STEP 5: Join and Hold
    ├─ Push together firmly with slight twist
    ├─ Align to mark
    ├─ Hold 30 seconds without moving
    └─ Wipe excess cement

STEP 6: Cure Time
    ├─ Handle carefully: 15 minutes
    ├─ Pressure test: 2 hours
    └─ Full cure: 24 hours

CRITICAL TIPS:
    • Work in ventilated area
    • Don't cement in rain or wet conditions
    • Temperature affects cure time
    • Once joined, cannot be separated
```

### 4.5 Plumbing System Design

#### Layout Principles

```
GOOD PLUMBING DESIGN PRINCIPLES

1. MINIMIZE RESTRICTIONS
   ✓ Use larger pipes than minimum required
   ✓ Gradual turns (45°) better than sharp (90°)
   ✓ Reduce fittings where possible
   ✗ Avoid multiple elevation changes

2. PLAN FOR MAINTENANCE
   ✓ Include unions at service points
   ✓ Valves to isolate components
   ✓ Access to pumps and filters
   ✗ Don't cement everything permanently

3. PREVENT AIRLOCKS
   ✓ High points have air release
   ✓ Maintain proper slope
   ✓ Avoid trapped air pockets
   ✗ Don't create inverted U-shapes

4. ENSURE DRAINAGE
   ✓ Slope drain lines 1/4" per foot
   ✓ Drain valves at low points
   ✓ Plan for system draining
   ✗ Don't create low-point traps

5. REDUNDANCY FOR CRITICAL PATHS
   ✓ Backup pumps or bypass options
   ✓ Emergency drains
   ✓ Overflow protection
   ✗ Don't rely on single points of failure
```

### 4.6 Specialized Plumbing Techniques

#### Bell Siphon Construction

```
BELL SIPHON FOR FLOOD & DRAIN

Purpose: Automatic drain once bed fills

Components:
    1. Standpipe (determines water level)
    2. Bell (creates siphon)
    3. Media guard (keeps media out)

┌─────────────────────────────────────┐
│     GROW BED                        │
│  ════════════════ ← Media          │
│                                     │
│    ┌──────────┐                    │
│    │  MEDIA   │                    │
│    │  GUARD   │                    │
│    │  ┌────┐  │                    │
│    │  │BELL│  │                    │
│    │  │    │  │                    │
│    │  │ ┌──┼──┼──┐ ← Standpipe    │
│    └──┼─┼──┼──┼──┘                 │
│       │ │  │  │                    │
└───────┼─┼──┼──┼────────────────────┘
        │ │  │  └─ Air snorkel
        │ │  └──── Inner standpipe
        │ └─────── Bell chamber
        └──────── To drain

How It Works:
    1. Water fills bed
    2. Water rises above standpipe
    3. Siphon initiates
    4. Bed drains completely
    5. Air enters, breaks siphon
    6. Cycle repeats

Sizing:
    • Standpipe: Match bed drain
    • Bell: 2-3× standpipe diameter
    • Media guard: 4-6× standpipe diameter
```

#### Drain and Overflow Safety

```
OVERFLOW PROTECTION

Primary Drain: Regular operating drain
    └─ Bulkhead at desired water level

Secondary (Emergency) Overflow:
    └─ 1-2" above primary drain
    └─ Same or larger diameter
    └─ Direct to safe drain location

Sizing Rule:
    Overflow capacity > Pump capacity

    Example:
        Pump: 600 GPH
        Overflow: 1.5" drain = 800+ GPH capacity ✓

Standpipe Calculation:
    GPH ÷ 60 = GPM
    Use drain sizing chart for diameter

    600 GPH ÷ 60 = 10 GPM
    Requires: 1" minimum drain
    Recommended: 1.5" for safety margin
```

### 4.7 Valves and Flow Control

#### Valve Types and Applications

| Valve Type | Function | Best For | Cost |
|------------|----------|----------|------|
| **Ball Valve** | On/off (full flow) | Isolation, shut-offs | $ |
| **Gate Valve** | On/off (full flow) | Main shut-offs | $$ |
| **Globe Valve** | Flow restriction/control | Flow adjustment | $$ |
| **Check Valve** | One-way flow | Prevent backflow | $ |
| **Float Valve** | Automatic fill | Water level control | $$ |
| **Pressure Relief** | Safety release | Prevent overpressure | $$ |

#### Strategic Valve Placement

```
RECOMMENDED VALVE LOCATIONS

✓ After every pump (isolation for service)
✓ Before each grow bed/zone (individual control)
✓ Drain lines (controlled emptying)
✓ Bypass lines (maintenance mode)
✓ Fill lines (automatic or manual)

System with Valves:

Pump ──[V]── Manifold ──[V]── Bed 1
                      ├─[V]── Bed 2
                      ├─[V]── Bed 3
                      └─[V]── Bypass to tank

[V] = Ball valve for isolation/control

Benefits:
    • Service one bed without affecting others
    • Balance flow between zones
    • Emergency shutoff capability
    • System draining for maintenance
```

### 4.8 Air Line Plumbing

#### Air Distribution

```
AIR PUMP DISTRIBUTION SYSTEM

Air Pump (5 CFM)
      │
      ├──[Valve]── Fish Tank (Diffuser)
      │
      ├──[Valve]── Biofilter (Air stone)
      │
      ├──[Valve]── Sump (Air stone)
      │
      └──[Valve]── Spare capacity

Tubing Size:
    • Main line: 1/2" or 3/4"
    • Branches: 1/4" or 3/8"
    • Use check valves to prevent backflow

Components:
    • Airline tubing (vinyl)
    • T-fittings for branches
    • Check valves
    • Gang valves for adjustment
    • Air stones or diffusers
```

#### Preventing Backflow

```
AIR LINE CHECK VALVE PLACEMENT

         Air Pump
              │
              ▼
         [CHECK VALVE] ← Prevents water siphon
              │
              ├─────► Tank 1
              ├─────► Tank 2
              └─────► Tank 3

CRITICAL:
    • Place check valve ABOVE water level
    • If pump stops, water won't siphon back
    • Protects pump from water damage
    • One-way valve at each pump output
```

### 4.9 Common Plumbing Problems

#### Troubleshooting Guide

| Problem | Possible Causes | Solutions |
|---------|----------------|-----------|
| **Leaks at joints** | Poor cement application | Re-do with union, proper technique |
| | Threaded connection loose | Tighten, add teflon tape |
| | Cracked fitting | Replace fitting |
| **Low flow** | Undersized pipes | Increase pipe diameter |
| | Too many restrictions | Reduce fittings, smooth elbows |
| | Clogged filter | Clean or replace |
| **Pump cavitation** | Inlet restriction | Larger inlet pipe |
| | Air in line | Prime pump, check for leaks |
| **Bell siphon won't start** | Standpipe too tall | Shorten standpipe |
| | Bell too small | Increase bell diameter |
| | Air leak | Seal gaps |
| **Won't stop siphoning** | No air break | Add snorkel tube |
| | Too much flow | Reduce pump speed |
| **Overflow** | Drain clogged | Clear obstruction |
| | Pump too strong | Add valve to reduce flow |

### 4.10 Plumbing Checklist

```
PRE-CONSTRUCTION PLUMBING CHECKLIST

DESIGN PHASE
□ System flow diagram complete
□ Pipe sizes calculated for all runs
□ Fittings list created
□ Valve locations identified
□ Drain and overflow planned
□ Access for maintenance considered

MATERIALS LIST
□ Pipe (by size and length)
□ Fittings (by type and size)
□ Bulkheads/Uniseals
□ Valves
□ PVC cement and primer
□ Teflon tape
□ Tools available

INSTALLATION
□ Dry fit entire system first
□ Test fit all connections
□ Plan cement sequence
□ Proper ventilation
□ Appropriate temperature
□ Cure time allocated

POST-INSTALLATION
□ Pressure test (fill with water)
□ Check for leaks (24-48 hours)
□ Flow test (verify rates)
□ Valve operation test
□ Emergency drain test
□ Document "as-built" changes
```
