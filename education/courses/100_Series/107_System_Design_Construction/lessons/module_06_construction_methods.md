### 6.1 Pre-Construction Planning

#### Build Sequence Overview

```
CONSTRUCTION PHASES

PHASE 1: SITE PREPARATION (Days 1-2)
    ├─ Clear and level area
    ├─ Build foundations/platforms
    ├─ Install electrical rough-in
    └─ Verify measurements

PHASE 2: STRUCTURAL (Days 3-5)
    ├─ Build support frames
    ├─ Install tank stands
    ├─ Position tanks
    └─ Verify level and stability

PHASE 3: PLUMBING (Days 6-8)
    ├─ Install bulkheads/drains
    ├─ Run main lines
    ├─ Install pumps and filters
    └─ Complete connections

PHASE 4: ELECTRICAL (Days 9-10)
    ├─ Wire outlets and equipment
    ├─ Install timers/controllers
    ├─ Test all circuits
    └─ Label everything

PHASE 5: TESTING (Days 11-12)
    ├─ Leak test (water only)
    ├─ Flow test and adjustments
    ├─ Final quality inspection
    └─ Document as-built

PHASE 6: COMMISSIONING (Days 13-14)
    └─ See Module 7
```

### 6.2 Site Preparation

#### Foundation Requirements

| System Type | Foundation Needs | Load Capacity | Notes |
|-------------|------------------|---------------|-------|
| **Outdoor Ground** | Gravel pad or concrete | 100+ lbs/sq ft | Ensure drainage |
| **Indoor Concrete** | Existing slab OK | Check rating | Protect from spills |
| **Wood Floor** | Reinforcement needed | 40 lbs/sq ft typical | May need additional support |
| **Greenhouse** | Level, stable base | Varies | Consider expansion |
| **Rooftop** | Engineer required | Critical | Professional assessment |

#### Weight Calculations

```
SYSTEM WEIGHT CALCULATION

Example 500-gallon Aquaponic System:

Fish Tank (500 gal):
    Water: 500 × 8.34 lbs = 4,170 lbs
    Tank weight: 50 lbs
    Stand: 100 lbs
    Subtotal: 4,320 lbs

Grow Beds (4 × 120 gal):
    Water: 480 × 8.34 = 4,003 lbs
    Media (if used): 480 × 3 = 1,440 lbs
    Containers: 200 lbs
    Stands: 400 lbs
    Subtotal: 6,043 lbs

Equipment & Misc: 200 lbs

TOTAL SYSTEM WEIGHT: 10,563 lbs (5.3 tons!)

Footprint: 200 sq ft
Load: 10,563 ÷ 200 = 53 lbs/sq ft average

Note: Concentrated loads much higher
Fish tank: 4,320 lbs on ~12 sq ft = 360 lbs/sq ft!
```

#### Site Preparation Steps

```
LEVELING AND PREPARING SITE

STEP 1: Mark Layout
    • Use stakes and string
    • Mark all component locations
    • Include access walkways
    • Verify dimensions

STEP 2: Level Ground
    • Remove vegetation
    • Excavate high spots
    • Fill low spots with gravel
    • Compact thoroughly

STEP 3: Install Drainage
    • Slope away from structures (1/4" per foot)
    • Install French drain if needed
    • Ensure water cannot pool

STEP 4: Create Foundation
    Option A - Gravel Pad:
        • 4-6" compacted gravel
        • Landscape fabric underneath
        • Level within 1/4" per 10'

    Option B - Concrete Pad:
        • 4" concrete minimum
        • Wire mesh reinforcement
        • Allow 7 days curing
        • Seal surface

    Option C - Pavers/Blocks:
        • Level sand base
        • Interlocking pavers
        • Fill joints
```

### 6.3 Structural Support Systems

#### Tank Stand Construction

```
BASIC TANK STAND DESIGN

Materials: Pressure-treated 4×4 posts, 2×6 framing

For 500-gallon tank (4,500 lbs):

    Top View (6' × 6'):
    ┌─────────────────────┐
    │  [2×6 joists]       │
    │  ══════════════     │
    │  P1    P2    P3     │
    │                     │
    │  P4    P5    P6     │
    │                     │
    │  P7    P8    P9     │
    └─────────────────────┘
    P = 4×4 Post

Side View:
         [Tank platform - 3/4" plywood]
    ══════════════════════════════
    ║      ║      ║      ║
    ║ 4×4  ║ 4×4  ║ 4×4  ║  ← Posts
    ║      ║      ║      ║
    ════════════════════════════  ← Concrete blocks

Construction:
    1. Place concrete blocks (level)
    2. Cut 4×4 posts to height
    3. Assemble base frame
    4. Install floor joists
    5. Add plywood platform
    6. Seal wood, add liner protection
```

#### Grow Bed Support

| Method | Load Capacity | Cost | Difficulty | Best For |
|--------|---------------|------|------------|----------|
| **2×4 Frame** | Light | $ | Easy | Small beds |
| **4×4 Posts** | Medium-Heavy | $$ | Medium | Medium systems |
| **Steel Rack** | Very Heavy | $$$ | Medium | Commercial |
| **Concrete Blocks** | Very Heavy | $ | Easy | Ground level |
| **Bench System** | Medium | $$ | Medium | Multiple beds |

#### Leveling Critical

```
WHY LEVEL MATTERS

NOT Level:
    ┌──────────────┐
   ╱                ╲  ← Water surface stays level
  ╱  Uneven depth   ╲    (physics!)
 ╱____________________╲
╱                      ╲ ← Unlevel bed
────────────────────────

Result:
    • Uneven plant growth
    • Poor water distribution
    • Bell siphons won't work
    • Structural stress

LEVEL:
    ┌──────────────┐
    │   Even depth │  ← Water level
    │              │
    └──────────────┘  ← Level bed
    ──────────────────

Tolerance: Level within 1/4" over entire bed
```

### 6.4 Assembly Sequence

#### Component Installation Order

```
BUILD SEQUENCE (Must Follow Order!)

1. FOUNDATION
   ↓
2. STRUCTURAL SUPPORTS
   ↓
3. ELECTRICAL ROUGH-IN
   (Before tanks block access)
   ↓
4. POSITION TANKS
   (Verify level!)
   ↓
5. INSTALL BULKHEADS/DRAINS
   (Easier before filling)
   ↓
6. DRY FIT PLUMBING
   (Test before cementing)
   ↓
7. CEMENT PLUMBING
   (Work from low to high)
   ↓
8. INSTALL PUMPS
   (Connect but don't power yet)
   ↓
9. COMPLETE ELECTRICAL
   (Wire everything)
   ↓
10. LEAK TEST
    (Water only, no fish/plants)
    ↓
11. ADJUST AND VERIFY
    (Fix issues now)
    ↓
12. FINAL CLEANING
    (Prepare for commissioning)
```

#### Critical Installation Points

```
TANK INSTALLATION

Before Filling:
    □ Verify completely level
    □ Check all supports are stable
    □ Inspect tank for damage
    □ Install bulkheads with gaskets
    □ Have emergency shut-off accessible

After Positioning:
    □ Fill 1/3 full
    □ Re-check level
    □ Check for bulkhead leaks
    □ Fill to operating level
    □ Mark water lines for reference
    □ Wait 24 hours and re-check
```

### 6.5 Plumbing Installation

#### Installation Best Practices

```
PLUMBING ASSEMBLY TIPS

PLANNING
    1. Lay out all pipes and fittings
    2. Label each connection
    3. Plan cement sequence
    4. Have all tools ready

DRY FITTING
    • Assemble entire system without cement
    • Verify all connections fit
    • Check clearances
    • Mark alignment with sharpie
    • Test for interference

CEMENTING
    • Work in well-ventilated area
    • Do NOT skip primer
    • Apply even coat of cement
    • Quick but controlled insertion
    • Hold 30 seconds
    • Allow proper cure time

ORDER
    Start at: Farthest point from pump
    End at: Pump connection
    Why: Can't adjust already-cemented sections
```

#### Common Mistakes to Avoid

| Mistake | Consequence | Prevention |
|---------|-------------|------------|
| **Skip dry fit** | Misaligned, won't work | Always test first |
| **Cement wet pipes** | Won't bond, will leak | Dry completely |
| **Wrong slope on drains** | Poor drainage | Use level, verify |
| **Over-tighten bulkheads** | Crack tank | Hand-tight + 1/4 turn |
| **No unions** | Can't service | Add unions strategically |
| **Forget valve** | No isolation | Plan valve locations |

### 6.6 Electrical Installation

#### Safe Installation Process

```
ELECTRICAL INSTALLATION SEQUENCE

BEFORE STARTING:
    ⚠️  Turn off power at breaker
    ⚠️  Verify with tester
    ⚠️  Lock out/tag out breaker

1. INSTALL BOXES AND CONDUIT
   • Mount outlet boxes
   • Run conduit
   • Secure every 3-4 feet

2. PULL WIRE
   • Use correct gauge
   • Leave extra length
   • Label both ends

3. MAKE CONNECTIONS
   • Follow wiring diagram
   • Proper wire nuts
   • Secure ground wires
   • Neat and organized

4. INSTALL DEVICES
   • GFCI outlets
   • Switches
   • Cover plates

5. LABEL EVERYTHING
   • Circuit numbers
   • Equipment tags
   • Emergency shut-off

6. TEST BEFORE ENERGIZING
   • Continuity test
   • Ground test
   • Polarity check

7. POWER ON AND VERIFY
   • Test GFCI
   • Check voltage
   • Test all equipment
```

### 6.7 Leak Testing

#### Water Test Procedure

```
COMPREHENSIVE LEAK TEST

DAY 1: Initial Fill
    1. Fill system with water only
    2. Bring to operating level
    3. Run pumps for 15 minutes
    4. Mark water levels on all tanks
    5. Inspect all connections
    6. Take photos for reference

DAY 2: 24-Hour Check
    □ Check water levels (expect minor drop from evaporation)
    □ Inspect all joints and bulkheads
    □ Look for dampness on supports
    □ Check floor for water
    □ Document any issues

ACCEPTABLE:
    • 1-2% water loss (evaporation)
    • Completely dry connections
    • Stable structure

UNACCEPTABLE:
    • Visible drips
    • Wet areas around connections
    • Water on floor
    • Unstable supports
    → DRAIN AND FIX IMMEDIATELY
```

#### Finding and Fixing Leaks

```
LEAK TROUBLESHOOTING

Small Drip from Bulkhead:
    1. Drain tank below bulkhead
    2. Tighten 1/4 turn
    3. Refill and test
    4. If still leaks: Remove, reseat, replace gasket

PVC Joint Leak:
    1. Cannot repair cemented joint
    2. Must cut out and replace
    3. Use union to make repairable
    4. Cure 24 hours before testing

Crack in Tank:
    1. Small crack: Plastic welding or epoxy
    2. Large crack: Replace tank
    3. Prevention: Proper support

Slow Leak (no visible source):
    1. Dry entire system
    2. Add food coloring to water
    3. Look for colored water
    4. Inspect underneath
```

### 6.8 Quality Control

#### Pre-Commissioning Inspection

```
FINAL INSPECTION CHECKLIST

STRUCTURAL
□ All supports stable and level
□ No wobbling or movement
□ Weight distributed properly
□ Access for maintenance
□ Safe walkways

PLUMBING
□ No leaks anywhere
□ Proper slope on drains
□ Valves operate smoothly
□ Flow rates adequate
□ Overflows functional

ELECTRICAL
□ All GFCI outlets tested
□ Proper wire routing
□ Drip loops on all cords
□ Equipment properly grounded
□ Timers programmed correctly
□ Labels in place

TANKS
□ Completely level
□ Clean and rinsed
□ No sharp edges
□ Lids/covers if needed
□ Water at proper level

SAFETY
□ Emergency shut-off accessible
□ Fire extinguisher nearby
□ First aid kit stocked
□ Emergency procedures posted
□ Phone numbers visible

DOCUMENTATION
□ As-built drawings
□ Parts list and sources
□ Warranty information
□ Maintenance schedule
□ Startup procedures
```

### 6.9 Common Construction Challenges

#### Problem Solving Guide

| Challenge | Solution Approach |
|-----------|-------------------|
| **Uneven floor** | Build individual leveling platforms |
| **Limited space** | Vertical design, careful planning |
| **Low ceiling** | Lower profile tanks, grow beds |
| **Poor drainage** | Install collection system, sump pump |
| **Weak floor** | Add support beams, distribute load |
| **Temperature extremes** | Insulation, climate control |
| **Limited power** | Prioritize efficiency, add circuits |
| **Difficult access** | Plan for disassembly, use unions |

#### Adaptation and Modification

```
FIELD MODIFICATIONS

Original Plan vs. Reality:
    • Expect 10-20% design changes
    • Keep extra materials on hand
    • Document all changes
    • Photograph as-built condition

Common Adjustments:
    ✓ Pipe routes different than planned
    ✓ Valve locations moved
    ✓ Additional supports added
    ✓ Electrical outlet repositioned
    ✓ Access improvements

When to Stop and Redesign:
    ⚠️  Structural integrity compromised
    ⚠️  Safety hazard identified
    ⚠️  Major component doesn't fit
    ⚠️  Code violation discovered
```

### 6.10 Timeline and Project Management

#### Sample Build Schedule

```
2-WEEK BUILD TIMELINE
(Small-Medium System, 1-2 People)

WEEK 1
Monday:     Site prep, foundation
Tuesday:    Build supports, position tanks
Wednesday:  Install bulkheads, dry fit plumbing
Thursday:   Cement plumbing, install pumps
Friday:     Electrical installation

WEEK 2
Monday:     Testing and leak detection
Tuesday:    Fix any issues, adjustments
Wednesday:  Quality inspection, cleaning
Thursday:   Final testing, documentation
Friday:     Begin commissioning (Module 7)

LARGER SYSTEMS
    • Add 1 week per 1000 gallons
    • Account for weather delays
    • Include permit time
    • Schedule inspections
```

## Vocabulary

| Term | Definition |
|------|------------|
| **Foundation** | Base support structure distributing weight |
| **Load Capacity** | Maximum weight a structure can safely support |
| **Level** | Perfectly horizontal, equal height at all points |
| **Dry Fit** | Assembling without permanent joining to test fit |
| **Bulkhead** | Fitting that penetrates tank wall for plumbing |
| **Commissioning** | Process of starting up and testing new system |
| **As-Built** | Documentation showing final construction (vs. original plans) |
| **Union** | Removable plumbing connection for maintenance |
