### 7.2 Initial Fill and Startup

#### Water Source Preparation

| Water Source | Treatment Needed | Process |
|--------------|------------------|---------|
| **Municipal (Chlorinated)** | Dechlorination | Let stand 24-48 hours OR add dechlorinator |
| **Well Water** | Testing | Test for hardness, iron, pH before use |
| **Rainwater** | Filtration | Filter debris, may need pH adjustment |
| **RO Water** | Remineralization | Add minerals back for buffering |

#### Initial Fill Procedure

```
FILLING NEW SYSTEM

STEP 1: Clean System
    • Rinse all tanks
    • Remove construction debris
    • Wipe down surfaces
    • Flush plumbing lines

STEP 2: Fill Fish Tank
    • Add dechlorinator (if needed)
    • Fill to operating level
    • Start aeration immediately
    • Test temperature

STEP 3: Fill Grow Beds/Reservoir
    • Fill to operating level
    • Check for leaks (again)
    • Verify drains working
    • Test flow rates

STEP 4: Start Circulation
    • Turn on water pump
    • Verify flow to all zones
    • Check for airlocks
    • Adjust valves for balance

STEP 5: Initial Testing
    • pH
    • Temperature
    • Ammonia (should be 0)
    • Nitrite (should be 0)
    • Nitrate (should be 0)
```

### 7.3 Aquaponic System Cycling

#### Understanding the Nitrogen Cycle

```
THE NITROGEN CYCLE (Aquaponics)

Fish eat food
    ↓
Fish produce ammonia (NH₃)
    ↓ (Toxic to fish!)
Nitrosomonas bacteria convert
    ↓
Nitrite (NO₂)
    ↓ (Toxic to fish!)
Nitrobacter bacteria convert
    ↓
Nitrate (NO₃)
    ↓ (Plant food!)
Plants absorb nitrate
    ↓
Clean water returns to fish

CYCLING = Establishing beneficial bacteria
          that perform these conversions
```

#### Cycling Timeline

```
FISHLESS CYCLING METHOD (Recommended)

WEEK 1: Setup
    Day 1: Fill system, start circulation
    Day 2-3: Add ammonia source (see below)
    Day 4-7: Test daily
        • Ammonia should rise to 2-4 ppm

WEEK 2-3: Nitrite Spike
    Day 8-14: Ammonia starts dropping
              Nitrite appears and rises
        • Test daily
        • Don't add more ammonia yet

WEEK 3-4: Nitrite Drop
    Day 15-21: Nitrite begins dropping
               Nitrate appears
        • Test daily
        • Add small ammonia doses

WEEK 4-6: Stabilization
    Day 22-42: System processes ammonia
               within 24 hours
        • Ammonia added → processed in 24hr
        • Ready for fish! ✓

CYCLING COMPLETE WHEN:
    ✓ 2 ppm ammonia → 0 ppm in 24 hours
    ✓ Nitrite stays at 0 ppm
    ✓ Nitrate present (10-40 ppm)
```

#### Ammonia Sources for Cycling

| Method | Amount | Pros | Cons |
|--------|--------|------|------|
| **Pure Ammonia** | To reach 2-4 ppm | Precise control | Must be pure (no surfactants) |
| **Fish Food** | Handful per 50 gal | Readily available | Harder to control, messy |
| **Urine** | Small amount | Free | Inconsistent, not professional |
| **Compost Tea** | 1 cup per 100 gal | Adds bacteria | Variable results |

```
AMMONIA DOSING CALCULATOR

Target: 2-4 ppm ammonia

Pure Ammonia (clear, no additives):
    Drops needed = (Tank Volume in Gallons × Target ppm) ÷ 7

    Example: 500 gallon system, want 3 ppm
    (500 × 3) ÷ 7 = 214 drops
    Or about 1.5 tablespoons

Fish Food Method:
    1 tablespoon per 50 gallons
    Example: 500 gallons = 10 tablespoons
```

### 7.4 Monitoring During Cycling

#### Testing Schedule

```
CYCLING MONITORING PROTOCOL

DAILY TESTS (During Cycling)
    • Ammonia (NH₃)
    • Nitrite (NO₂)
    • pH
    • Temperature

WEEKLY TESTS
    • Nitrate (NO₃)
    • Water level

RECORD ALL DATA
    Use log sheet or app
    Track trends over time
```

#### Parameter Targets

| Parameter | Cycling Range | Stable System | Action if Out of Range |
|-----------|---------------|---------------|------------------------|
| **pH** | 6.8-8.0 | 6.8-7.2 | Adjust with pH up/down |
| **Ammonia** | 0-4 ppm | 0 ppm | Reduce feeding OR cycle longer |
| **Nitrite** | 0-5 ppm | 0 ppm | Continue cycling |
| **Nitrate** | Rising | 10-40 ppm | Water change if >100 ppm |
| **Temperature** | 70-80°F | 72-78°F | Add heater/chiller |

#### Troubleshooting Cycling Problems

```
COMMON CYCLING ISSUES

Problem: pH keeps dropping
    Cause: Nitrification produces acid
    Solution: Add buffer (calcium carbonate)
              Small water changes

Problem: Ammonia won't drop
    Cause: Bacteria not established yet
    Solution: Be patient, may take 4-6 weeks
              Check temperature (too cold?)
              Verify aeration (need O₂)

Problem: Nitrite stuck at high level
    Cause: Second bacteria slower to establish
    Solution: Wait it out (can take 2-3 weeks)
              Small water changes if >5 ppm
              Add salt (1 ppm per 1 ppm nitrite)

Problem: Nothing happening
    Cause: No ammonia source, or too cold
    Solution: Verify ammonia present
              Increase temperature to 75-80°F
              Add bacteria starter (optional)
```

### 7.5 Introducing Fish

#### Fish Selection for Startup

```
BEGINNER-FRIENDLY FISH

Goldfish (coldwater):
    • Very hardy
    • Tolerate mistakes
    • Good for cycling
    • Not for eating
    • Best: First aquaponics system

Tilapia (warmwater):
    • Fast growing
    • Edible
    • Need warmer water (75-85°F)
    • Best: Established systems

Koi (coldwater):
    • Hardy
    • Long-lived
    • Ornamental
    • Best: Display systems
```

#### Stocking Procedure

```
SAFE FISH INTRODUCTION

STEP 1: Verify Cycle Complete
    □ Ammonia: 0 ppm
    □ Nitrite: 0 ppm
    □ Nitrate: 10-40 ppm
    □ pH: 6.8-7.5
    □ Temperature stable

STEP 2: Prepare Fish
    • Order from reputable source
    • Quarantine if possible (separate tank)
    • Inspect for disease/damage

STEP 3: Acclimation
    • Float bag in tank for 15 minutes (temperature)
    • Add 1 cup tank water to bag
    • Wait 10 minutes
    • Repeat 2-3 times over 30-45 minutes
    • Gently net fish into tank (don't add bag water)

STEP 4: Initial Stocking
    • Start with 25-50% of final capacity
    • Example: 500 gal tank = 100 lbs max
              Start with 25-50 lbs
    • Allows system to adjust

STEP 5: Monitor Closely
    • Test daily for 1 week
    • Watch fish behavior
    • Feed lightly at first
    • Add more fish gradually
```

### 7.6 Feeding and Fish Care

#### Initial Feeding Protocol

```
FIRST FEEDING SCHEDULE

DAY 1-2: Do not feed
    • Fish are stressed
    • Need to acclimate

DAY 3: First feeding
    • Small amount (1% body weight)
    • Observe eating
    • Remove uneaten food after 5 min

DAY 4-7: Light feeding
    • Once per day
    • Gradually increase
    • Watch water quality

WEEK 2+: Normal feeding
    • 1-2 times per day
    • Amount they consume in 5 minutes
    • Adjust based on temperature

RULE: Better to underfeed than overfeed!
```

#### Feeding Rate Guidelines

| Water Temp | % Body Weight | Frequency | Notes |
|------------|---------------|-----------|-------|
| **50-60°F** | 0.5% | Every 2-3 days | Very slow metabolism |
| **60-70°F** | 1.0% | Once daily | Cool season |
| **70-80°F** | 1.5-2.0% | 1-2× daily | Optimal growth |
| **80-85°F** | 2.0-3.0% | 2-3× daily | Warm season |
| **>85°F** | Reduce | 1× daily | Stress zone |

### 7.7 Hydroponic System Startup

#### Nutrient Solution Preparation

```
HYDROPONIC COMMISSIONING

STEP 1: Clean Fill
    • Fill reservoir with clean water
    • Dechlorinate if needed
    • Adjust temperature (65-75°F)

STEP 2: Add Nutrients
    • Follow manufacturer instructions
    • Typical: 2-3 grams per gallon
    • Mix thoroughly
    • Let circulate 30 minutes

STEP 3: Adjust pH
    • Test pH
    • Target: 5.5-6.5
    • Add pH up/down as needed
    • Retest after 1 hour

STEP 4: Check EC
    • Test electrical conductivity
    • Target depends on crop:
        - Seedlings: 0.8-1.0 EC
        - Leafy greens: 1.5-2.0 EC
        - Fruiting: 2.0-3.0 EC

STEP 5: Start Circulation
    • Turn on pumps
    • Verify flow to all plants
    • Check for leaks (again!)
    • Adjust timers
```

### 7.8 Adding Plants

#### Transplant Timing

```
WHEN TO ADD PLANTS

AQUAPONICS
    Option 1: After Fishless Cycle
        • System fully cycled (4-6 weeks)
        • Ammonia/Nitrite at 0
        • Add fish, then plants immediately

    Option 2: With Fish (Preferred)
        • Fish added first
        • Wait 2 weeks for waste production
        • Add plants gradually
        • Plants help stabilize system

HYDROPONICS
    • System filled and balanced
    • pH and EC stable for 24 hours
    • Temperature in range
    • Add plants anytime

PLANT SIZE
    • Seedlings: 2-3 true leaves
    • Transplants: Well-established roots
    • Cuttings: Rooted in 1-2 weeks
```

#### Transplanting Procedure

```
TRANSPLANTING TO SYSTEM

STEP 1: Prepare Plants
    • Water seedlings 1 hour before
    • Remove from pots carefully
    • Gently rinse soil from roots
    • Inspect for pests

STEP 2: Media Bed Planting
    • Make hole in media
    • Position plant
    • Backfill with media
    • Firm gently
    • Support if needed

STEP 3: Net Pot/NFT Planting
    • Rinse roots well
    • Place in net pot
    • Add clay pebbles around roots
    • Insert into system
    • Ensure roots touch water/nutrients

STEP 4: Initial Care
    • Shade for 2-3 days if needed
    • Monitor closely
    • Some leaf drop is normal
    • New growth within 1 week
```

### 7.9 Stabilization Period

#### First Month Monitoring

```
WEEK-BY-WEEK EXPECTATIONS

WEEK 1: Adjustment
    • Plants may wilt slightly
    • Fish hide frequently
    • System finding balance
    Action: Monitor closely, minimal intervention

WEEK 2: Recovery
    • Plants perk up
    • Fish more active
    • First algae appears (normal)
    Action: Regular testing, light feeding

WEEK 3: Growth Begins
    • Visible plant growth
    • Fish eating well
    • System stabilizing
    Action: Increase feeding slightly

WEEK 4: Established
    • Strong growth
    • Normal fish behavior
    • Parameters stable
    Action: Begin regular maintenance routine

MONTH 2-3: Optimization
    • Adjust feeding rates
    • Fine-tune pH and nutrients
    • Increase stocking if desired
    • System reaches full productivity
```

#### Stability Indicators

```
SIGNS OF A STABLE SYSTEM

WATER QUALITY
    ✓ pH stable within 0.2 units
    ✓ Ammonia/Nitrite consistently 0
    ✓ Nitrate 10-40 ppm (aquaponics)
    ✓ EC stable (hydroponics)

FISH BEHAVIOR
    ✓ Active and alert
    ✓ Eating eagerly
    ✓ Even swimming
    ✓ No gasping at surface

PLANT HEALTH
    ✓ New growth visible
    ✓ Good green color
    ✓ No yellowing or spots
    ✓ Strong stems

SYSTEM OPERATION
    ✓ Pumps running smoothly
    ✓ No leaks
    ✓ Proper water levels
    ✓ No unusual odors
```

### 7.10 Common Startup Problems

#### Troubleshooting Guide

| Problem | Likely Cause | Solution |
|---------|-------------|----------|
| **Cloudy water** | Bacterial bloom (normal) | Wait 3-5 days, will clear |
| **Green water** | Algae from light | Shade tank, reduce light exposure |
| **Fish gasping** | Low oxygen | Increase aeration, check pump |
| **pH crash** | Insufficient buffering | Add crushed coral, oyster shell |
| **Ammonia spike** | Overfeeding, too many fish | Reduce feeding, water change |
| **Plants yellow** | Nutrient deficiency | Wait (aqua), check EC (hydro) |
| **No plant growth** | Too early, wrong pH | Be patient, check pH range |

## Vocabulary

| Term | Definition |
|------|------------|
| **Cycling** | Process of establishing beneficial bacteria in new systems |
| **Nitrification** | Bacterial conversion of ammonia to nitrite to nitrate |
| **Fishless Cycling** | Cycling method using ammonia source without live fish |
| **Acclimation** | Gradual adjustment of fish to new water conditions |
| **Stabilization** | Period when system reaches balanced operation |
| **EC (Electrical Conductivity)** | Measurement of dissolved nutrients in solution |
| **Buffer** | Substance that resists pH changes |
| **Biofilter** | Component housing beneficial bacteria |
