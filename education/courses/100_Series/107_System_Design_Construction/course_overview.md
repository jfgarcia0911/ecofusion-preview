## Course Description

Learn to design, build, and commission professional-grade growing systems from the ground up. This comprehensive course covers site assessment, system sizing, component selection, plumbing and electrical basics, construction techniques, and system commissioning. Whether you're building a backyard hobby system or planning a commercial installation, this course provides the engineering fundamentals you need.

---

## Learning Outcomes

Upon successful completion of this course, learners will be able to:

1. **Assess** sites for growing system installations
2. **Calculate** system sizing for production goals
3. **Select** appropriate components and materials
4. **Design** plumbing and water distribution systems
5. **Plan** electrical requirements and safety systems
6. **Construct** growing systems using proper techniques
7. **Commission** and troubleshoot new installations
8. **Document** system specifications and maintenance procedures

## Key Topics

### Site Assessment
- Space requirements and layout planning
- Utility access (water, electricity, drainage)
- Structural considerations (floor load, ceiling height)
- Environmental factors (temperature, sunlight, access)
- Permitting and code requirements

### System Sizing
- Production goal calculations
- Tank and reservoir sizing
- Pump flow rate calculations
- Grow bed and channel sizing
- Fish stocking calculations (aquaponics)

### Plumbing Systems
- Pipe sizing and flow calculations
- Pressure and head loss
- Fitting types and applications
- Valve selection and placement
- Drain and overflow design
- Water treatment integration

### Electrical Systems
- Load calculations
- Circuit planning
- GFCI requirements for wet environments
- Timer and controller wiring
- Backup power considerations
- Safety and code compliance

### Construction Techniques
- Frame construction methods
- Tank and container selection
- Grow bed construction
- NFT and vertical system assembly
- Waterproofing and sealing
- Support and leveling

## Component Reference

### Pumps

| Application | Flow Rate | Head | Type |
|-------------|-----------|------|------|
| Small system (<100 gal) | 100-300 GPH | 3-6 ft | Submersible |
| Medium system (100-500 gal) | 300-800 GPH | 6-10 ft | Submersible/External |
| Large system (>500 gal) | 800-2000+ GPH | 10-20 ft | External |
| High head applications | Variable | 15+ ft | External, multistage |

### Pipe Sizing Guide

| Flow Rate (GPH) | Minimum Pipe Diameter |
|-----------------|----------------------|
| Up to 100 | 1/2" |
| 100-300 | 3/4" |
| 300-600 | 1" |
| 600-1200 | 1-1/4" |
| 1200-2000 | 1-1/2" |
| 2000+ | 2" |
