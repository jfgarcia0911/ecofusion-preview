# Assignment 5: Complete System Design Project

## Course 107: System Design & Construction

**Type:** Final Project | **Points:** 15 | **Time:** 2-4 hours

## Project Overview
Create comprehensive, buildable system design package.

## System Requirements
- 300-600 gallon capacity
- Your choice of system type
- Suitable for specified crop(s)
- Budget: $2,000-$4,000

## Deliverables

### 1. Design Drawings (5 pts)
- Plan view (overhead layout)
- Elevation view (side profile)
- Plumbing schematic
- Electrical diagram
- All properly dimensioned and labeled

### 2. Engineering Calculations (4 pts)
- System sizing ratios
- Pump specifications
- Electrical loads
- Structural requirements
- Flow rates and head loss

### 3. Complete Documentation (4 pts)
- Bill of materials
- Construction instructions
- Commissioning checklist
- Operating procedures
- Maintenance schedule

### 4. Professional Presentation (2 pts)
- Clear, organized
- Buildable specifications
- Realistic budget
- Construction-ready

## Grading
Technical accuracy, completeness, feasibility, and professional quality
