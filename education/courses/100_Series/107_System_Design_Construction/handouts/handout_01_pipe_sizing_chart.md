## Quick Reference Formulas

**Pump Flow Required:**
```
GPH = System Volume (gal) × Turnover Rate (/hr)
```

**Head Pressure (Static):**
```
Head (ft) = Vertical lift from water surface to discharge point
```

**Pipe Cross-Section Area:**
```
Area (sq in) = π × (diameter/2)²
```
