# Assignment 3: Lighting Layout Design

## Course 105: Environmental Control Systems

**Type:** In-Class | **Points:** 15 | **Time:** 30-45 min

## Objective
Design optimal lighting layout for a growing space achieving uniform PPFD coverage.

## Scenario
- Growing area: 16ft × 24ft (384 sq ft)
- Target crop: Lettuce (requires 300-400 μmol/m²/s PPFD)
- Budget: $5,000 for fixtures
- Height available: 8ft ceiling

## Requirements

**Part 1: Fixture Selection (5 pts)**
- Choose fixture model with specs
- Determine PPFD at plant canopy height
- Calculate number of fixtures needed

**Part 2: Layout Design (6 pts)**
- Create overhead layout diagram
- Show fixture spacing and coverage
- Ensure no dark spots <250 μmol/m²/s

**Part 3: Performance Calculations (4 pts)**
- Total watts: _______
- Average PPFD: _______ μmol/m²/s
- Uniformity ratio: _______
- Annual energy cost (at $0.12/kWh, 16hr/day): $_______

## Deliverable
- Scale drawing with dimensions
- Fixture specifications
- Calculations worksheet
