## Efficiency Strategies

### Lighting Efficiency

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                    LIGHTING EFFICIENCY UPGRADES                            │
    │                                                                             │
    │   HPS TO LED CONVERSION:                                                   │
    │   ═══════════════════════                                                  │
    │                                                                             │
    │   Before: 10 × 1000W HPS = 10,000W                                        │
    │   After:  10 × 600W LED = 6,000W (same PPFD)                              │
    │   Savings: 4,000W = 40% reduction                                         │
    │                                                                             │
    │   ANNUAL SAVINGS CALCULATION:                                              │
    │   ══════════════════════════                                               │
    │   4,000W × 12 hrs/day × 365 days = 17,520 kWh                             │
    │   At $0.12/kWh = $2,102/year electricity savings                          │
    │   PLUS: ~30% reduction in cooling costs                                   │
    │                                                                             │
    │   LED UPGRADE COST: $6,000-10,000                                         │
    │   PAYBACK: 2-4 years                                                      │
    │                                                                             │
    │   OTHER LIGHTING STRATEGIES:                                               │
    │   ══════════════════════════                                               │
    │   • Keep fixtures clean (10-20% loss when dirty)                          │
    │   • Replace reflectors when degraded                                      │
    │   • Use light movers for better coverage                                  │
    │   • Match photoperiod to DLI needs (don't over-light)                     │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘
```

### HVAC Efficiency

```
╔═══════════════════════════════════════════════════════════════════════════╗
║                                                                           ║
║                    HVAC EFFICIENCY IMPROVEMENTS                           ║
║                                                                           ║
║   1. RIGHT-SIZE EQUIPMENT                                                 ║
║      • Oversized equipment cycles inefficiently                          ║
║      • Undersized runs constantly                                        ║
║      • Calculate actual loads, add modest margin                         ║
║                                                                           ║
║   2. UPGRADE TO HIGHER EFFICIENCY                                        ║
║      • SEER 21+ vs SEER 14 = 30-50% reduction                           ║
║      • Inverter-driven compressors                                       ║
║      • Variable speed fans                                               ║
║                                                                           ║
║   3. IMPROVE INSULATION                                                  ║
║      • Seal air leaks                                                    ║
║      • Add insulation to walls/ceiling                                   ║
║      • Use thermal screens in greenhouses                                ║
║                                                                           ║
║   4. HEAT RECOVERY                                                       ║
║      • Capture waste heat from equipment                                 ║
║      • Pre-heat/pre-cool incoming air                                    ║
║      • Use heat pumps for efficiency                                     ║
║                                                                           ║
║   5. STRATEGIC SCHEDULING                                                 ║
║      • Run during off-peak electricity hours                             ║
║      • Use thermal mass for temperature stability                        ║
║      • Pre-condition before high-demand periods                          ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

## Renewable Energy Options

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                    RENEWABLE ENERGY FOR CEA                                │
    │                                                                             │
    │   SOLAR PV:                                                                │
    │   ═════════                                                                │
    │   • 1 kW of solar ≈ 4-6 kWh/day production (varies by location)           │
    │   • 10kW system can offset ~30-50% of small indoor farm                   │
    │   • ROI: 5-10 years depending on incentives                               │
    │   • Net metering can credit excess production                             │
    │                                                                             │
    │   CONSIDERATIONS:                                                          │
    │   • Peak production (midday) may not match peak demand (lights on)        │
    │   • Battery storage adds cost but improves self-consumption               │
    │   • Roof space often limited for greenhouses (use ground mount)           │
    │                                                                             │
    │   OTHER OPTIONS:                                                           │
    │   ═══════════════                                                          │
    │   • Wind (site dependent)                                                 │
    │   • Geothermal heat pumps (excellent efficiency, high install cost)       │
    │   • Biogas from waste (especially with fish or livestock)                 │
    │   • Purchasing renewable energy credits (RECs)                            │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘
```

## Module Summary

### Key Takeaways

1. **Lighting is the largest energy cost** in indoor farms
2. **LED upgrades** typically pay back in 2-4 years
3. **HVAC efficiency** compounds - insulation helps everything
4. **Solar PV** can offset significant energy costs
5. **Measure to manage** - you can't improve what you don't track
