# Equipment Sizing Quick Reference
## Course 105: Environmental Control Systems

```
╔═══════════════════════════════════════════════════════════════════════════════════╗
║                                                                                   ║
║                      EQUIPMENT SIZING MASTER GUIDE                                ║
║                   Quick Calculations for CEA Systems                              ║
║                                                                                   ║
╚═══════════════════════════════════════════════════════════════════════════════════╝

┌───────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│                         LIGHTING CALCULATIONS                                     │
│                                                                                   │
│   ═══════════════════════════════════════════════════════════════════════════    │
│                                                                                   │
│   PPF NEEDED = PPFD × Area (m²) ÷ Efficiency Factor                              │
│                                                                                   │
│   Efficiency Factor: 0.85 (typical reflective room)                              │
│                                                                                   │
│   ┌─────────────────────────────────────────────────────────────────────────┐    │
│   │ QUICK REFERENCE: WATTS PER SQ FT                                       │    │
│   ├─────────────────────────────────────────────────────────────────────────┤    │
│   │                                                                         │    │
│   │   APPLICATION           HPS              LED                           │    │
│   │   ─────────────────────────────────────────────────────────            │    │
│   │   Seedlings/Clones      10-20 W/sq ft    5-15 W/sq ft                 │    │
│   │   Vegetative            30-40 W/sq ft    20-30 W/sq ft                │    │
│   │   Flowering             50-65 W/sq ft    30-40 W/sq ft                │    │
│   │   High-intensity        65-80 W/sq ft    40-50 W/sq ft                │    │
│   │                                                                         │    │
│   └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                   │
│   EXAMPLE:                                                                        │
│   100 sq ft flowering room with LED                                              │
│   100 × 35 W/sq ft = 3,500W total lighting                                       │
│                                                                                   │
│   ─────────────────────────────────────────────────────────────────────────────  │
│                                                                                   │
│   DLI FORMULA: DLI = PPFD × Hours × 0.0036                                       │
│                                                                                   │
│   Target DLI:                                                                     │
│   • Leafy greens: 12-17 mol/m²/day                                              │
│   • Herbs: 15-22 mol/m²/day                                                     │
│   • Tomatoes: 25-35 mol/m²/day                                                  │
│   • Cannabis: 40-60 mol/m²/day                                                  │
│                                                                                   │
└───────────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│                          HVAC CALCULATIONS                                        │
│                                                                                   │
│   ═══════════════════════════════════════════════════════════════════════════    │
│                                                                                   │
│   COOLING (AC) SIZING:                                                            │
│   ════════════════════                                                            │
│                                                                                   │
│   BTU/hr = Lighting Watts × Multiplier                                           │
│                                                                                   │
│   ┌─────────────────────────────────────────────────────────────────────────┐    │
│   │ LIGHT TYPE         MULTIPLIER     BTU/1000W      TONS/1000W            │    │
│   ├─────────────────────────────────────────────────────────────────────────┤    │
│   │ HPS/MH             × 4.0          4,000 BTU      0.33 tons             │    │
│   │ LED (typical)      × 2.5          2,500 BTU      0.21 tons             │    │
│   │ LED (efficient)    × 2.0          2,000 BTU      0.17 tons             │    │
│   └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                   │
│   1 Ton = 12,000 BTU/hr                                                          │
│   Add 20% margin for other heat sources!                                         │
│                                                                                   │
│   ─────────────────────────────────────────────────────────────────────────────  │
│                                                                                   │
│   HEATING SIZING:                                                                 │
│   ═══════════════                                                                 │
│                                                                                   │
│   BTU/hr = Floor Area × BTU per sq ft × (Temp Rise ÷ 50)                         │
│                                                                                   │
│   ┌─────────────────────────────────────────────────────────────────────────┐    │
│   │ STRUCTURE TYPE              BTU/SQ FT (for 50°F rise)                  │    │
│   ├─────────────────────────────────────────────────────────────────────────┤    │
│   │ Single poly greenhouse      40-50                                      │    │
│   │ Double poly greenhouse      25-35                                      │    │
│   │ Glass greenhouse            35-45                                      │    │
│   │ Insulated building          15-25                                      │    │
│   │ Well-insulated grow room    10-15                                      │    │
│   └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                   │
└───────────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│                       VENTILATION CALCULATIONS                                    │
│                                                                                   │
│   ═══════════════════════════════════════════════════════════════════════════    │
│                                                                                   │
│   EXHAUST FAN CFM:                                                                │
│   ════════════════                                                                │
│                                                                                   │
│   CFM = Room Volume × Air Changes per Minute                                     │
│   Room Volume = Length × Width × Height (feet)                                   │
│                                                                                   │
│   ┌─────────────────────────────────────────────────────────────────────────┐    │
│   │ APPLICATION                    AIR CHANGES/MINUTE                      │    │
│   ├─────────────────────────────────────────────────────────────────────────┤    │
│   │ Basic ventilation              1.0                                     │    │
│   │ Standard grow room             1.0 - 1.5                               │    │
│   │ High heat load (HPS)           2.0 - 3.0                               │    │
│   │ Sealed room (minimal)          0.5                                     │    │
│   └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                   │
│   ADD FOR RESTRICTIONS:                                                           │
│   • Carbon filter: +25%                                                          │
│   • Long duct run: +10% per 10 ft                                               │
│   • Each 90° elbow: +10%                                                        │
│                                                                                   │
│   ─────────────────────────────────────────────────────────────────────────────  │
│                                                                                   │
│   HAF (CIRCULATION) FANS:                                                         │
│   ═══════════════════════                                                         │
│                                                                                   │
│   Total CFM = 1 CFM per sq ft of floor area                                      │
│                                                                                   │
│   Example: 1,000 sq ft = 1,000 CFM total                                         │
│            = 4 × 250 CFM fans                                                    │
│                                                                                   │
│   ─────────────────────────────────────────────────────────────────────────────  │
│                                                                                   │
│   INTAKE SIZING:                                                                  │
│   ══════════════                                                                  │
│                                                                                   │
│   Passive intake: 2-4× exhaust duct area                                         │
│   Powered intake: 80-90% of exhaust CFM                                          │
│                                                                                   │
└───────────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│                       DEHUMIDIFIER SIZING                                         │
│                                                                                   │
│   ═══════════════════════════════════════════════════════════════════════════    │
│                                                                                   │
│   Pints/Day = Canopy Sq Ft × 2-4 pints/100 sq ft                                │
│                                                                                   │
│   ┌─────────────────────────────────────────────────────────────────────────┐    │
│   │ CANOPY SIZE          LOW NEED (2 pt)    HIGH NEED (4 pt)               │    │
│   ├─────────────────────────────────────────────────────────────────────────┤    │
│   │ 100 sq ft            20 pint/day        40 pint/day                    │    │
│   │ 500 sq ft            100 pint/day       200 pint/day                   │    │
│   │ 1,000 sq ft          200 pint/day       400 pint/day                   │    │
│   └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                   │
│   ⚠️  HEAT OUTPUT: Dehumidifiers add ~1,000-1,500 BTU/hr per 70 pints/day      │
│       Factor this into cooling calculations!                                     │
│                                                                                   │
└───────────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│                         QUICK SIZING EXAMPLES                                     │
│                                                                                   │
│   ═══════════════════════════════════════════════════════════════════════════    │
│                                                                                   │
│   EXAMPLE: 10' × 10' × 8' room with 4,000W LED                                   │
│   ─────────────────────────────────────────────────                               │
│                                                                                   │
│   LIGHTING: Already specified (4,000W = 40W/sq ft) ✓                             │
│                                                                                   │
│   COOLING:                                                                        │
│   4,000W × 2.5 = 10,000 BTU/hr                                                   │
│   + 20% margin = 12,000 BTU = 1 ton AC                                           │
│                                                                                   │
│   EXHAUST:                                                                        │
│   Volume: 10 × 10 × 8 = 800 cu ft                                                │
│   CFM: 800 × 1.5 = 1,200 CFM                                                     │
│   With filter: 1,200 × 1.25 = 1,500 CFM fan                                      │
│                                                                                   │
│   DEHUMIDIFIER:                                                                   │
│   100 sq ft × 3 pt/100 = 30 pints/day                                            │
│   Select: 35-50 pint unit                                                        │
│                                                                                   │
│   CIRCULATION:                                                                    │
│   100 sq ft = 100 CFM total                                                      │
│   = 2 small oscillating fans                                                     │
│                                                                                   │
└───────────────────────────────────────────────────────────────────────────────────┘
```
