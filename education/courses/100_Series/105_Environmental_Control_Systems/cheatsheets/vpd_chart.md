┌───────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│                         VPD FORMULA & CALCULATION                                 │
│                                                                                   │
│   VPD = SVP × (1 - RH/100)                                                       │
│                                                                                   │
│   WHERE:                                                                          │
│   SVP = Saturation Vapor Pressure at leaf temperature                            │
│   RH = Relative Humidity (%)                                                      │
│                                                                                   │
│   SVP can be approximated: SVP = 0.6108 × e^(17.27×T/(T+237.3))                 │
│   Where T = Temperature in °C                                                     │
│                                                                                   │

│                                                                                   │

│   ═════════════════════════════════                                               │
│   → Increase temperature (raises SVP)                                            │
│   → Run dehumidifier                                                             │
│   → Increase air circulation                                                     │
│   → Reduce irrigation frequency                                                  │
│                                                                                   │
│   VPD TOO HIGH (dry conditions)?                                                 │
│   ═══════════════════════════════                                                 │
│   → Lower temperature (if possible)                                              │
│   → Add humidifier                                                               │
│   → Mist plants (temporary)                                                      │
│   → Reduce ventilation                                                           │
│                                                                                   │
│   ─────────────────────────────────────────────────────────────────────────────  │
│                                                                                   │
│   REMEMBER: Temperature and humidity are linked!                                  │
