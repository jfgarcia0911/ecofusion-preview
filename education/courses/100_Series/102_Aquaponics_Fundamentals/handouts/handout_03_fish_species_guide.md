## Fish Feeding Guide

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │                         FEEDING YOUR FISH                                  │
    │                                                                             │
    │   ╔═══════════════════════════════════════════════════════════════════╗   │
    │   ║                                                                   ║   │
    │   ║   GENERAL FEEDING RULES:                                         ║   │
    │   ║   ══════════════════════                                          ║   │
    │   ║                                                                   ║   │
    │   ║   1. Feed 1-3% of total fish body weight per day                 ║   │
    │   ║   2. Feed only what fish eat in 5-10 minutes                     ║   │
    │   ║   3. Remove uneaten food to prevent water quality issues         ║   │
    │   ║   4. Reduce feeding in cold water (metabolism slows)             ║   │
    │   ║   5. Split daily ration into 2-3 feedings                        ║   │
    │   ║                                                                   ║   │
    │   ╚═══════════════════════════════════════════════════════════════════╝   │
    │                                                                             │
    │   FEED TYPE BY SPECIES:                                                    │
    │   ═════════════════════                                                    │
    │                                                                             │
    │   ┌────────────────┬──────────────┬────────────────────────────────────┐  │
    │   │ SPECIES        │ PROTEIN %    │ FEED TYPE                          │  │
    │   ├────────────────┼──────────────┼────────────────────────────────────┤  │
    │   │ Tilapia        │ 28-32%       │ Floating pellet (omnivore)         │  │
    │   │ Catfish        │ 28-32%       │ Sinking pellet (omnivore)          │  │
    │   │ Trout          │ 40-45%       │ Floating/sinking (carnivore)       │  │
    │   │ Bass           │ 40-45%       │ Floating pellet (carnivore)        │  │
    │   │ Barramundi     │ 40-45%       │ Floating pellet (carnivore)        │  │
    │   │ Koi/Goldfish   │ 25-30%       │ Floating pellet (omnivore)         │  │
    │   └────────────────┴──────────────┴────────────────────────────────────┘  │
    │                                                                             │
    │   FEEDING RATE BY TEMPERATURE:                                             │
    │   ════════════════════════════                                             │
    │                                                                             │
    │   ┌────────────────────────────────────────────────────────────────────┐  │
    │   │ WATER TEMP        │ FEEDING RATE (% body weight/day)               │  │
    │   ├────────────────────────────────────────────────────────────────────┤  │
    │   │ < 55°F (13°C)     │ 0.5% or stop (metabolism too slow)             │  │
    │   │ 55-65°F (13-18°C) │ 1.0%                                           │  │
    │   │ 65-75°F (18-24°C) │ 1.5-2.0%                                       │  │
    │   │ 75-85°F (24-29°C) │ 2.0-3.0% (optimal for most species)           │  │
    │   │ > 85°F (29°C)     │ 1.5-2.0% (stress reduces appetite)             │  │
    │   └────────────────────────────────────────────────────────────────────┘  │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘
```
