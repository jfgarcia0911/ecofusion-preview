## The Three Forms of Nitrogen

```
    NITROGEN TRANSFORMATION IN AQUAPONICS

    ┌───────────────────────────────────────────────────────────────────────┐
    │                                                                       │
    │   AMMONIA (NH₃/NH₄⁺)                                                 │
    │   ══════════════════                                                 │
    │   Source: Fish waste, decomposing matter, uneaten food               │
    │   Toxicity: HIGH (especially at high pH)                             │
    │   Safe Level: < 0.5 ppm (ideally 0)                                  │
    │   pH Impact: More toxic at higher pH                                 │
    │                                                                       │
    │         │                                                             │
    │         │ Nitrosomonas bacteria                                       │
    │         ▼                                                             │
    │                                                                       │
    │   NITRITE (NO₂⁻)                                                     │
    │   ═════════════                                                       │
    │   Source: Bacterial conversion of ammonia                            │
    │   Toxicity: HIGH (interferes with fish blood oxygen)                 │
    │   Safe Level: < 0.5 ppm (ideally 0)                                  │
    │   Danger: "Brown blood disease" in fish                              │
    │                                                                       │
    │         │                                                             │
    │         │ Nitrobacter bacteria                                        │
    │         ▼                                                             │
    │                                                                       │
    │   NITRATE (NO₃⁻)                                                     │
    │   ═════════════                                                       │
    │   Source: Bacterial conversion of nitrite                            │
    │   Toxicity: LOW (safe up to 150+ ppm for most fish)                 │
    │   Target Level: 20-80 ppm                                            │
    │   Value: PRIMARY PLANT NUTRIENT!                                     │
    │                                                                       │
    └───────────────────────────────────────────────────────────────────────┘
```

## Cycling Your System

```
    SYSTEM CYCLING: ESTABLISHING THE NITROGEN CYCLE

    Week 1-2: AMMONIA PHASE
    ════════════════════════
    • Add ammonia source (fish or pure ammonia)
    • Ammonia rises, nitrite = 0, nitrate = 0
    • Nitrosomonas bacteria establishing

         Ammonia: ████████████████████ HIGH
         Nitrite: ░░░░░░░░░░░░░░░░░░░░ ZERO
         Nitrate: ░░░░░░░░░░░░░░░░░░░░ ZERO


    Week 2-4: NITRITE SPIKE
    ═══════════════════════
    • Ammonia starts dropping
    • Nitrite spikes HIGH
    • Nitrobacter bacteria establishing
    • DANGER ZONE for fish!

         Ammonia: ████████░░░░░░░░░░░░ DROPPING
         Nitrite: ██████████████████░░ SPIKING!
         Nitrate: ████░░░░░░░░░░░░░░░░ APPEARING


    Week 4-6: NITRATE RISE
    ══════════════════════
    • Ammonia approaches zero
    • Nitrite drops to zero
    • Nitrate steadily rises
    • System is "CYCLING"

         Ammonia: █░░░░░░░░░░░░░░░░░░░ NEAR ZERO
         Nitrite: █░░░░░░░░░░░░░░░░░░░ DROPPING
         Nitrate: ████████████████░░░░ RISING


    Week 6+: CYCLED SYSTEM
    ══════════════════════
    • Ammonia converts within hours
    • Nitrite stays at zero
    • Nitrate stable (controlled by plants)
    • READY FOR FULL PRODUCTION!

         Ammonia: ░░░░░░░░░░░░░░░░░░░░ ZERO
         Nitrite: ░░░░░░░░░░░░░░░░░░░░ ZERO
         Nitrate: ████████████████████ STABLE
```

### Target Ranges

| Parameter | Ideal Range | Action if Outside |
|-----------|-------------|-------------------|
| **Ammonia** | 0-0.25 ppm | Stop feeding, check pH, add aeration |
| **Nitrite** | 0 ppm | Stop feeding, water change, add salt |
| **Nitrate** | 20-80 ppm | Add plants (high) or fish (low) |
| **pH** | 6.8-7.2 | Adjust with buffers |
| **Temperature** | 65-80°F | Heater/chiller |
| **Dissolved O₂** | >6 mg/L | Add aeration |

## Troubleshooting the Nitrogen Cycle

```
    COMMON PROBLEMS & SOLUTIONS

    ┌─────────────────────────────────────────────────────────────────────────┐
    │                                                                         │
    │   PROBLEM: Ammonia spike in established system                         │
    │   ═══════════════════════════════════════════                          │
    │   Possible causes:                                                      │
    │   • Overfeeding                                                        │
    │   • Dead fish                                                          │
    │   • pH crash (bacteria die)                                            │
    │   • New fish added too fast                                            │
    │   • Power outage (lost bacteria)                                       │
    │                                                                         │
    │   Solutions:                                                           │
    │   • Stop feeding                                                       │
    │   • Remove dead matter                                                 │
    │   • Partial water change                                               │
    │   • Increase aeration                                                  │
    │   • Add established media                                              │
    │                                                                         │
    │   ─────────────────────────────────────────────────────────────────── │
    │                                                                         │
    │   PROBLEM: Persistent nitrite                                          │
    │   ═══════════════════════════                                          │
    │   Possible causes:                                                      │
    │   • Nitrobacter colony immature                                        │
    │   • pH too low (<6.0)                                                  │
    │   • Temperature too extreme                                            │
    │   • Chlorine/chloramine in water                                       │
    │                                                                         │
    │   Solutions:                                                           │
    │   • Be patient (wait for bacteria)                                     │
    │   • Check/adjust pH                                                    │
    │   • Add salt (0.1-0.3%) to protect fish                               │
    │   • Ensure dechlorination                                              │
    │                                                                         │
    │   ─────────────────────────────────────────────────────────────────── │
    │                                                                         │
    │   PROBLEM: Nitrate too high                                            │
    │   ═════════════════════════                                            │
    │   Possible causes:                                                      │
    │   • Not enough plants                                                  │
    │   • Overstocked with fish                                              │
    │   • Overfeeding                                                        │
    │                                                                         │
    │   Solutions:                                                           │
    │   • Add more plants                                                    │
    │   • Partial water change                                               │
    │   • Reduce feeding                                                     │
    │   • Check fish:plant ratio                                             │
    │                                                                         │
    └─────────────────────────────────────────────────────────────────────────┘
```

## Key Takeaways

1. **Ammonia → Nitrite → Nitrate** is the essential conversion
2. **Two types of bacteria** do the work (Nitrosomonas & Nitrobacter)
3. **Cycling takes 4-6 weeks** - patience is essential
4. **Test regularly** - especially during cycling
5. **Balance is key** - fish, bacteria, and plants must be in proportion
6. **The bacteria are doing the heavy lifting** - protect them!
