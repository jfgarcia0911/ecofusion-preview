#### Rule #2: Feeding Rate Ratio

```
FEEDING RATE CALCULATION

System capacity based on daily feeding:

┌──────────────────────────────────────────┐
│  Daily Feed (oz) ÷ Grow Bed Area (sq ft)│
│                                          │
│  Target: 1-2 oz feed per sq ft per day   │
│                                          │
│  Example:                                │
│  50 sq ft grow bed                       │
│  × 1.5 oz/sq ft                          │
│  ─────────────                           │
│  = 75 oz feed per day (4.7 lbs)          │
│                                          │
│  Fish biomass needed (at 2% body weight):│
│  4.7 lbs feed ÷ 0.02 = 235 lbs fish     │
│  (Very intensive - more typical: 100 lbs)│
└──────────────────────────────────────────┘

Conservative approach:
0.5-1 oz feed per sq ft per day
```

#### Rule #3: Water Flow Rate

**Turnover Rate Guidelines:**

| System Type | Turnovers per Hour | Calculation Example (100 gal) |
|-------------|-------------------|-------------------------------|
| **Media Bed** | 1-2× | 100-200 GPH |
| **NFT** | 2-4× | 200-400 GPH |
| **DWC** | 1-2× | 100-200 GPH |

```
PUMP SIZING CALCULATION

Step 1: Determine system volume
Fish tank: 100 gal
Grow bed: 100 gal
Plumbing: ~10 gal
Total: 210 gallons

Step 2: Select turnover rate
Media bed system = 1.5× per hour
210 gal × 1.5 = 315 GPH

Step 3: Account for head height
Height from pump to grow bed: 4 feet
Add 25% per foot over 3 feet
315 GPH × 1.25 = 394 GPH

Step 4: Add safety margin (20%)
394 GPH × 1.2 = 473 GPH

Final pump selection: 500 GPH rated at 4 ft head
```

#### Rule #4: Aeration Requirements

```
OXYGEN CALCULATION

Minimum Aeration:
┌────────────────────────────────┐
│  Fish Tank Volume (gallons)    │
│  ÷ 4 gallons per watt          │
│  = Air pump wattage needed     │
│                                │
│  Example:                      │
│  100 gal ÷ 4 = 25 watts        │
│                                │
│  Recommended: 30-40 watts      │
│  (provides safety margin)      │
└────────────────────────────────┘

High-Density Systems:
• 1 watt per 2-3 gallons
• Multiple air stones
• Backup pump recommended
```

### 6.3 Sizing Calculations

#### Media Bed System Example

```
COMPLETE MEDIA BED DESIGN

GOAL: 20 heads lettuce per week, home system

Step 1: Calculate plant needs
├─ 20 heads/week × 0.44 sq ft per head = 8.8 sq ft
├─ Add succession planting (3 stages)
└─ Total: 8.8 × 3 = 26.4 sq ft (round to 30 sq ft)

Step 2: Grow bed dimensions
├─ 30 sq ft × 12" deep = 225 gallons
├─ Practical layout: Two beds of 3' × 5' × 1'
└─ Actual volume: 2 × (3 × 5 × 1) × 7.5 gal/cu ft = 225 gal

Step 3: Fish tank sizing (1:1 ratio)
├─ 225 gal grow bed = 225 gal fish tank
├─ Practical: Use 275-gal IBC tote
└─ Provides some buffer

Step 4: Fish stocking
├─ 275 gal ÷ 5 gal per lb = 55 lbs fish max
├─ Conservative: Stock 40 lbs at maturity
└─ Start with 80 fingerlings (assuming 50% to market)

Step 5: Pump selection
├─ System volume: 275 + 225 = 500 gal
├─ Turnover: 500 × 1.5 = 750 GPH
├─ Head height: 3 feet (minimal adjustment)
└─ Select: 800 GPH pump

Step 6: Aeration
├─ 275 gal fish tank ÷ 4 = 69 watts
└─ Select: 70-watt air pump with 4 outlets
```

#### NFT System Example

```
COMMERCIAL NFT DESIGN

GOAL: 500 heads lettuce per week

Step 1: Production calculation
├─ 500 heads/week × 5 weeks growth = 2,500 plants
├─ At 8" spacing: 2,500 × 0.44 sq ft = 1,100 sq ft
└─ Add 20% for aisles/access = 1,320 sq ft

Step 2: NFT channel layout
├─ 4" channels, 10 feet long
├─ 8 plants per channel (8" spacing)
├─ Channels needed: 2,500 ÷ 8 = 313 channels
├─ Layout: 16 rows × 20 channels = 320 channels
└─ Growing area: Approximately 1,350 sq ft

Step 3: Biofilter sizing
├─ Target fish: 200 lbs at maturity
├─ Surface area: 200 lbs × 100 sq ft/lb = 20,000 sq ft
├─ Moving bed biofilter: 20,000 ÷ 600 sq ft/cu ft = 33 cu ft
└─ Biofilter tank: 4' × 4' × 2' deep = 32 cu ft ✓

Step 4: Fish tank sizing
├─ 1,350 sq ft growing ÷ 3 (ratio) = 450 gal minimum
├─ At 1 lb per 3 gal: 450 ÷ 3 = 150 lbs fish max
├─ Target stocking: 200 lbs (intensive)
└─ Fish tank: 600 gallons (provides buffer)

Step 5: Pump sizing
├─ NFT requires: 1 liter/minute per channel
├─ 320 channels × 0.26 gal/min = 83 GPH... NO!
├─ CORRECT: System turnover method
├─ 600 gal fish + 200 gal biofilter + 400 gal NFT = 1,200 gal
├─ Turnover 2×/hour: 2,400 GPH
├─ With head: 2,400 × 1.3 = 3,120 GPH
└─ Select: 3,500 GPH pump

Step 6: Multiple pump strategy
├─ Primary: 2,000 GPH (main circulation)
├─ Secondary: 1,500 GPH (backup/boost)
└─ Both on separate circuits
```

#### Environmental Control Planning

**Temperature Management:**

| Climate | Challenge | Solution | Estimated Cost |
|---------|-----------|----------|----------------|
| **Cold (<40°F)** | Heat fish tank, prevent freezing | Water heater, insulation, greenhouse | $200-$2,000 |
| **Hot (>85°F)** | Cool water, reduce fish stress | Shade, evaporative cooling, chiller | $100-$3,000 |
| **Variable** | Temperature swings | Thermal mass, insulation | $50-$500 |

**Lighting Requirements:**

```
LIGHTING DESIGN

Natural Light (Greenhouse/Outdoor)
├─ Pros: Free, full spectrum
├─ Cons: Seasonal variation, limited control
└─ Best for: Warm climates, leafy greens

Supplemental LED
├─ Pros: Efficient, customizable spectrum
├─ Cons: Upfront cost, electricity
├─ Requirements: 20-40 watts per sq ft
└─ Best for: Year-round production, fruiting crops

Full LED (Indoor)
├─ Pros: Complete control, any location
├─ Cons: Highest electricity cost
├─ Requirements: 30-50 watts per sq ft
└─ Best for: Urban, basement, climate extremes
```

### 6.5 Layout and Space Planning

#### Component Placement Principles

```
LAYOUT BEST PRACTICES

1. MINIMIZE PLUMBING DISTANCE
   Fish Tank ──[short pipe]──► Grow Bed

2. MAXIMIZE GRAVITY
   Grow Bed (high) ──[gravity]──► Fish Tank (low)

3. ENSURE ACCESS
   ┌─────────────┐
   │  Grow Bed   │ ← 3 ft minimum on one side
   └─────────────┘

4. PLAN FOR GROWTH
   Leave 25% expansion room

5. SEPARATE WET/DRY
   Work area away from growing area
```

#### Pipe Sizing Reference

```
PLUMBING SPECIFICATIONS

Main Supply Lines (from pump):
┌────────────────────────────────┐
│ 200 GPH or less:    3/4" pipe  │
│ 200-500 GPH:        1" pipe    │
│ 500-1000 GPH:       1.5" pipe  │
│ 1000+ GPH:          2" pipe    │
└────────────────────────────────┘

Drain Lines (gravity flow):
┌────────────────────────────────┐
│ Always larger than supply!     │
│ Small system:       1.5" min   │
│ Medium system:      2" min     │
│ Large system:       3" min     │
│                                │
│ Bell siphon:        1-2" drain │
└────────────────────────────────┘

Fittings and Valves:
• Use swept elbows (less restriction)
• Ball valves for flow control
• Union fittings for maintenance
• Check valves on air lines
```

### 6.9 Common Design Mistakes

#### Pitfalls to Avoid

```
TOP 10 DESIGN ERRORS

1. ❌ UNDERSIZED PUMP
   └─ ✓ Calculate properly, add safety margin

2. ❌ INSUFFICIENT AERATION
   └─ ✓ More is better - plan for maximum stocking

3. ❌ POOR DRAINAGE
   └─ ✓ Drain pipes larger than supply pipes

4. ❌ NO ACCESS FOR MAINTENANCE
   └─ ✓ 3-foot clearance on at least one side

5. ❌ INADEQUATE BIOFILTER
   └─ ✓ Calculate surface area based on fish load

6. ❌ IGNORING STRUCTURAL LOAD
   └─ ✓ Water weighs 8.34 lbs/gallon - check floor

7. ❌ NO BACKUP PLAN
   └─ ✓ Backup air pump, power considerations

8. ❌ WRONG SYSTEM TYPE FOR GOALS
   └─ ✓ Match system to crops and experience

9. ❌ OVERLY COMPLEX FIRST SYSTEM
   └─ ✓ Start simple, expand later

10. ❌ NO BUDGET FOR OPERATIONS
    └─ ✓ Plan for electricity, feed, supplies
```

## Vocabulary

| Term | Definition |
|------|------------|
| **System Ratio** | Proportional relationship between system components |
| **Turnover Rate** | Number of times total volume is circulated per hour |
| **Head Height** | Vertical distance pump must lift water |
| **Load Capacity** | Maximum weight a structure can safely support |
| **Thermal Mass** | Material's ability to store heat energy |
| **Manifold** | Pipe fitting distributing flow to multiple outlets |
| **Bioload** | Amount of waste produced by fish in system |
| **Contingency** | Extra budget allocation for unexpected costs |
