## Lesson Content

### 2.1 The Nitrogen Cycle Foundation

#### Why the Nitrogen Cycle Matters

**The nitrogen cycle is the heart of aquaponics.** Without it working properly:
- Fish die from ammonia poisoning
- Plants starve from nutrient deficiency
- The system fails

```
THE AQUAPONIC NITROGEN CYCLE

    FISH
     │
     │ Excrete waste (ammonia NH₃/NH₄⁺)
     │ TOXIC to fish at 0.5+ ppm
     ▼
┌─────────────────────────────────────┐
│  BENEFICIAL BACTERIA (Biofilter)   │
│                                     │
│  Step 1: Nitrosomonas bacteria     │
│  NH₃ + O₂ → NO₂⁻ (Nitrite)        │
│  (Still VERY TOXIC)                │
│                                     │
│  Step 2: Nitrobacter bacteria      │
│  NO₂⁻ + O₂ → NO₃⁻ (Nitrate)       │
│  (SAFE and usable by plants)       │
└──────────────┬──────────────────────┘
               │
               ▼
          PLANTS
     Absorb nitrate (NO₃⁻)
     Use it for growth
     Return clean water to fish
               │
               └──→ Back to fish tank
```

#### The Three Nitrogen Forms

| Form | Chemical | Toxicity | Source | Safe Level |
|------|----------|----------|--------|------------|
| **Ammonia** | NH₃/NH₄⁺ | Very High | Fish waste, uneaten feed | <0.5 ppm |
| **Nitrite** | NO₂⁻ | Very High | Bacterial conversion | <0.5 ppm |
| **Nitrate** | NO₃⁻ | Low | Bacterial conversion | 5-150 ppm |

### 2.2 The Bacterial Heroes

#### Nitrifying Bacteria

**Two Key Players:**

```
BACTERIAL SUCCESSION

Week 1-2:
┌──────────────────────────────┐
│  NITROSOMONAS BACTERIA       │
│  • Consume ammonia (NH₃)     │
│  • Produce nitrite (NO₂⁻)    │
│  • Double every 8-15 hours   │
│  • Need oxygen & surface area│
└──────────────┬───────────────┘
               │
Week 2-4:      ▼
┌──────────────────────────────┐
│  NITROBACTER BACTERIA        │
│  • Consume nitrite (NO₂⁻)    │
│  • Produce nitrate (NO₃⁻)    │
│  • Double every 12-20 hours  │
│  • Need oxygen & surface area│
└──────────────────────────────┘

Both work together in mature system
```

#### What Bacteria Need

**The 5 Essential Requirements:**

| Requirement | Why | How to Provide |
|-------------|-----|----------------|
| **Surface Area** | Place to colonize | Biofilter media, grow beds |
| **Oxygen** | Aerobic metabolism | Air stones, water movement |
| **Ammonia Source** | Food for bacteria | Fish waste |
| **pH 6-8** | Optimal range | Monitor and adjust |
| **Temperature 65-85°F** | Active growth | Heaters if needed |

### 2.3 System Cycling Process

#### What is Cycling?

**Cycling:** The 4-6 week process of establishing beneficial bacterial colonies in a new system before adding fish at full density.

#### The Cycling Timeline

```
TYPICAL CYCLING PROGRESSION

Week 0: START
│ Add ammonia source (fish food, pure ammonia, or few fish)
│ Test daily
▼

Week 1-2: AMMONIA PHASE
│ Ammonia: RISING (2-4 ppm)
│ Nitrite: 0 ppm
│ Nitrate: 0 ppm
│ Nitrosomonas bacteria starting to grow
▼

Week 2-3: NITRITE SPIKE
│ Ammonia: FALLING (1-2 ppm)
│ Nitrite: RISING (2-8 ppm) ⚠️ Peak
│ Nitrate: Starting to appear (5-20 ppm)
│ Nitrobacter bacteria starting to grow
▼

Week 3-4: NITRATE RISE
│ Ammonia: <0.5 ppm ✓
│ Nitrite: FALLING (1-2 ppm)
│ Nitrate: RISING (20-50 ppm)
│ Both bacteria established
▼

Week 4-6: CYCLED!
│ Ammonia: <0.5 ppm ✓
│ Nitrite: <0.5 ppm ✓
│ Nitrate: 20-100 ppm ✓
│ System ready for full fish load
▼

System is CYCLED when:
• Ammonia converts to 0 within 24 hours
• Nitrite converts to 0 within 24 hours
• Nitrate is accumulating
```

#### Cycling Methods

**1. Fishless Cycling (Recommended)**

| Method | Process | Timeline | Pros/Cons |
|--------|---------|----------|-----------|
| **Pure Ammonia** | Add liquid ammonia daily to reach 2-4 ppm | 4-6 weeks | Precise, humane, fast |
| **Fish Food** | Add pinch of food, let it decompose | 4-6 weeks | Simple, no chemicals, slower |

**2. Fish-In Cycling**

```
FISH-IN CYCLING (Use with caution)

Week 0:
│ Add VERY FEW hardy fish (10-25% of final load)
│ Feed sparingly (1/4 normal amount)
│ Test water daily
│ Be ready for 50% water changes
▼

Week 1-4:
│ Monitor fish stress (gasping, lethargy)
│ Change 50% water if ammonia >1 ppm OR nitrite >1 ppm
│ Continue testing daily
│ Feed lightly
▼

Week 4-6:
│ Parameters stable
│ Gradually increase feeding
│ Slowly add more fish over several weeks
▼

RISKS:
• Fish may die from ammonia/nitrite
• Stressful for fish
• Slower than fishless
• Requires intensive monitoring

Only use with: Hardy species (goldfish, tilapia)
Never use with: Expensive or sensitive fish
```

**3. Seeded Cycling (Fastest)**

| Source | How to Use | Benefit |
|--------|-----------|---------|
| **Established filter media** | Transfer media from mature system | Cuts time by 50-70% |
| **Commercial bacteria** | Bottled nitrifying bacteria | Jumpstarts process |
| **Garden soil** | Small amount in media | Natural bacteria source |

### 2.4 Water Testing

#### Essential Test Kit

**Must-Have Tests:**

| Parameter | Test Frequency | Critical Levels |
|-----------|----------------|-----------------|
| **Ammonia (NH₃/NH₄⁺)** | Daily (cycling), Weekly (mature) | >0.5 ppm = Dangerous |
| **Nitrite (NO₂⁻)** | Daily (cycling), Weekly (mature) | >0.5 ppm = Dangerous |
| **Nitrate (NO₃⁻)** | Weekly | 5-150 ppm ideal |
| **pH** | 2-3x per week | 6.8-7.2 optimal |
| **Temperature** | Daily | Species-dependent |

#### Testing Procedure

```
WATER TESTING PROTOCOL

1. COLLECT SAMPLE
   └─ Take from system (not surface)
   └─ Use clean container
   └─ Test immediately or refrigerate

2. TEST AMMONIA
   └─ Follow kit instructions exactly
   └─ Record result and color
   └─ If >0.5 ppm, take action

3. TEST NITRITE
   └─ Follow kit instructions
   └─ Record result
   └─ If >0.5 ppm, take action

4. TEST NITRATE
   └─ Follow kit instructions
   └─ Record result
   └─ If >150 ppm, consider water change

5. TEST pH
   └─ Use digital meter or drops
   └─ Record result
   └─ Adjust if outside 6.8-7.2 range

6. RECORD DATA
   └─ Keep testing log
   └─ Look for trends
   └─ Make informed decisions
```

#### Understanding Test Results

**Ideal Mature System Readings:**

```
TARGET WATER PARAMETERS

Ammonia:    0  ━━━━━━━━━━━━━━━━━━━━━━
Nitrite:    0  ━━━━━━━━━━━━━━━━━━━━━━
Nitrate:    40 ████████━━━━━━━━━━━━━━
pH:         7.0 █████████░░░░░░░░░░░░░░

Key:  ━ = Safe zone
      █ = Actual reading
      ░ = Acceptable range
```

### 2.5 Managing the Nitrogen Cycle

#### Maintaining Balance

**The Balancing Act:**

```
SYSTEM BALANCE

Too Much Ammonia          Balanced System         Too Little Nitrate
     ↓                           ↓                       ↓
Reduce feeding           Everything working       Add more fish
Add biofilter            Monitor regularly        OR reduce plants
Dilute with water        Enjoy harvest            OR supplement

The goal: Continuous cycling with levels in safe range
```

#### Common Issues and Solutions

**Problem 1: High Ammonia**

| Cause | Solution |
|-------|----------|
| Overfeeding | Reduce feed to 1-2% body weight |
| Dead fish | Remove immediately |
| Insufficient biofilter | Add media or expand filter |
| New system (cycling) | Be patient, partial water change if >2 ppm |
| Low oxygen | Increase aeration |

**Problem 2: High Nitrite**

| Cause | Solution |
|-------|----------|
| System still cycling | Wait, test daily, be patient |
| Biofilter disruption | Avoid cleaning entire filter at once |
| Temperature shock | Maintain stable temp |
| pH too low/high | Adjust pH to 6.8-7.2 |
| Overfeeding | Reduce feeding |

**Problem 3: Low Nitrate**

| Cause | Solution |
|-------|----------|
| Too many plants for fish | Reduce plants OR add fish |
| System not cycled | Complete cycling process |
| Insufficient feeding | Increase feed gradually |

**Problem 4: Very High Nitrate (>150 ppm)**

| Cause | Solution |
|-------|----------|
| Insufficient plant uptake | Add more plants |
| Too much fish/feeding | Reduce density or feeding |
| No water changes | 10-20% water change monthly |

### 2.6 Optimizing Bacterial Health

#### Creating Ideal Conditions

**Temperature Effects:**

| Temperature | Bacterial Activity | Impact |
|-------------|-------------------|---------|
| <55°F | Slow/dormant | Cycling stops, ammonia builds |
| 55-65°F | Active but slow | Longer cycling time |
| 65-85°F | Optimal | Fast cycling, good performance |
| 85-95°F | Active | Can work but stressful |
| >95°F | Declining | Bacteria die off |

**pH Effects:**

```
pH IMPACT ON NITRIFICATION

pH 4-6:   Severely impaired ░░░░░░░░░░
pH 6-6.5: Reduced efficiency ░░░░░█████
pH 6.5-8: Optimal range     ██████████
pH 8-8.5: Reduced efficiency █████░░░░░
pH >8.5:  Severely impaired ░░░░░░░░░░

Sweet spot: pH 7.0
```

**Oxygen Requirements:**

| Dissolved O₂ | Nitrification Rate | Action Needed |
|--------------|-------------------|---------------|
| <3 ppm | Severely limited | Emergency aeration |
| 3-5 ppm | Reduced | Increase aeration |
| 5-8 ppm | Optimal | Maintain current level |
| >8 ppm | Excellent | No action needed |

### 2.7 The Complete Cycle

#### Beyond Nitrogen

```
COMPLETE NUTRIENT CYCLING

FISH FEED (Input)
    │
    ▼
FISH consume feed
    │
    ├─► Ammonia (NH₃) ──────► Bacteria ──► NO₂⁻ ──► NO₃⁻ ──► PLANTS
    │
    ├─► Solid waste ────────► Mechanical filtration ──► Compost
    │
    ├─► Phosphorus ─────────► Dissolved ──────────────► PLANTS
    │
    ├─► Potassium ──────────► Dissolved ──────────────► PLANTS
    │
    └─► Micronutrients ─────► Dissolved ──────────────► PLANTS

PLANTS clean water and return it to fish
```

#### Mineralization

**Solid waste breakdown:**

| Process | Location | Organisms | Products |
|---------|----------|-----------|----------|
| **Heterotrophic bacteria** | Biofilter, media | Various bacteria | Break down organics |
| **Mineralization** | Throughout system | Bacteria, worms | Release nutrients |
| **Anaerobic zones** | Deep in media | Anaerobic bacteria | Denitrification |
