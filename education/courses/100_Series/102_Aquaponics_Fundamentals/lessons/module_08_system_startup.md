### 8.2 Pre-Start System Checklist

#### Complete Pre-Start Inspection

```
SYSTEM STARTUP CHECKLIST

□ STRUCTURAL INTEGRITY
  ├─ All tanks level and stable
  ├─ Grow beds properly supported
  ├─ Floor load capacity verified
  └─ No structural concerns

□ PLUMBING COMPLETE
  ├─ All connections tight (no leaks)
  ├─ Ball valves operational
  ├─ Drain pipes clear
  ├─ Overflow protection installed
  └─ Bell siphons tuned (if applicable)

□ ELECTRICAL SAFETY
  ├─ GFCI outlets installed
  ├─ All cords in good condition
  ├─ No electrical near water
  ├─ Pumps connected properly
  └─ Heater installed safely

□ EQUIPMENT FUNCTIONAL
  ├─ Water pump tested
  ├─ Air pump operational
  ├─ Air stones bubbling vigorously
  ├─ Heater working (if needed)
  └─ All equipment accessible for service

□ MEDIA PREPARED
  ├─ Growing media rinsed thoroughly
  ├─ Media in grow beds
  ├─ Biofilter media in place (if separate)
  └─ No dust or debris

□ TESTING SUPPLIES
  ├─ Water test kit (ammonia, nitrite, nitrate, pH)
  ├─ Thermometer
  ├─ Notebook/log ready
  └─ Calculator available

□ CYCLING SUPPLIES
  ├─ Ammonia source selected
  ├─ pH adjustment materials on hand
  ├─ Dechlorinator (if needed)
  └─ Backup plan for problems
```

#### Leak Testing Protocol

```
LEAK TEST PROCEDURE

Step 1: INITIAL FILL
├─ Fill fish tank slowly
├─ Watch all connections
├─ Mark any leaks
└─ Fix before continuing

Step 2: PLUMBING TEST
├─ Run pump for 10 minutes
├─ Check every connection
├─ Test all valves
├─ Verify overflow works
└─ Fix any issues

Step 3: CYCLING TEST
├─ Run system for 24 hours
├─ Monitor water levels
├─ Check for slow leaks
├─ Verify stable operation
└─ Make final adjustments

Step 4: READY FOR CYCLING
├─ All leaks fixed
├─ System running smoothly
├─ Water levels stable
└─ Begin adding ammonia
```

### 8.3 Fishless Cycling (Recommended Method)

#### Why Fishless Cycling is Best

**Advantages:**
- No animal welfare concerns
- Faster and more predictable
- Can reach higher ammonia concentrations safely
- Build larger bacterial colonies before adding fish
- No risk of losing expensive fish

#### Method 1: Pure Ammonia

```
PURE AMMONIA CYCLING PROTOCOL

Required Material:
• Pure ammonia (NO surfactants, soaps, or scents)
• Test: Shake bottle - no suds = good
• Concentration: Usually 9-10% ammonium hydroxide

Dosing Schedule:

DAY 1: INITIAL DOSE
┌────────────────────────────────────────┐
│ Calculate system volume in gallons     │
│ Example: 200 gallons total             │
│                                        │
│ Target: 2-4 ppm ammonia                │
│                                        │
│ Formula:                               │
│ (Target ppm × Gallons × 0.0038) ÷ 0.10│
│ = ml of 10% ammonia needed             │
│                                        │
│ Example:                               │
│ (3 ppm × 200 gal × 0.0038) ÷ 0.10    │
│ = 22.8 ml ammonia                      │
│                                        │
│ Add ammonia, mix well, test after 1hr │
└────────────────────────────────────────┘

DAYS 2-14: DAILY TESTING
┌────────────────────────────────────────┐
│ Test ammonia daily                     │
│ If <1 ppm: Add dose to bring to 3 ppm  │
│ If >1 ppm: Do not add more             │
│                                        │
│ Watch for nitrite to appear            │
│ (Usually days 7-10)                    │
└────────────────────────────────────────┘

DAYS 14-28: NITRITE PHASE
┌────────────────────────────────────────┐
│ Continue daily ammonia dosing          │
│ Ammonia drops quickly now              │
│ Nitrite rises (may reach 5-10 ppm)    │
│ This is normal! Be patient.            │
│                                        │
│ Watch for nitrate to appear            │
│ (Usually days 14-21)                   │
└────────────────────────────────────────┘

DAYS 28-42: COMPLETION
┌────────────────────────────────────────┐
│ Ammonia → 0 within 24 hours ✓         │
│ Nitrite → 0 within 24 hours ✓         │
│ Nitrate accumulating ✓                 │
│                                        │
│ CYCLED! Ready for fish.                │
└────────────────────────────────────────┘
```

#### Method 2: Fish Food Cycling

```
FISH FOOD CYCLING METHOD

Advantages:
✓ No chemicals needed
✓ Simple, natural process
✓ Good for organic operations

Disadvantages:
✗ Slower (5-8 weeks)
✗ Less precise ammonia control
✗ Can cloud water
✗ May attract pests

Procedure:
┌────────────────────────────────────────┐
│ DAY 1:                                 │
│ Add 1 cup fish food per 100 gallons   │
│ Let decompose                          │
│                                        │
│ DAYS 2-7:                              │
│ Add small pinch food daily             │
│ Food will decay and release ammonia    │
│                                        │
│ WEEKS 2-6:                             │
│ Continue adding food as needed         │
│ Monitor ammonia, nitrite, nitrate      │
│ Same progression as ammonia cycling    │
│                                        │
│ COMPLETION:                            │
│ When parameters stable, system cycled  │
└────────────────────────────────────────┘

Tips:
• Use sinking pellets (less messy)
• Remove excess uneaten food weekly
• May need to add more food mid-cycle
```

### 8.4 Fish-In Cycling (Use with Caution)

#### When Fish-In Cycling Might Be Necessary

**Only Use If:**
- Educational demonstration required immediately
- Cannot obtain pure ammonia
- Very small system with hardy fish only
- Willing to do intensive monitoring and water changes

```
FISH-IN CYCLING PROTOCOL

⚠️ WARNING: Stressful for fish, high mortality risk

Step 1: MINIMAL STOCKING
├─ Use ONLY hardy species (goldfish, fathead minnows)
├─ Stock 10% of final capacity
├─ Example: 200 gal system → 4 lbs fish max
└─ NEVER use tilapia, trout, or expensive fish

Step 2: MINIMAL FEEDING
├─ Feed once daily
├─ Only 0.5% body weight
├─ Skip feeding if ammonia >0.5 ppm
└─ Remove uneaten food after 5 minutes

Step 3: INTENSIVE MONITORING
├─ Test ammonia AND nitrite DAILY
├─ Test pH every 2 days
├─ Watch fish behavior constantly
└─ Be ready for emergency intervention

Step 4: EMERGENCY RESPONSES
┌────────────────────────────────────────┐
│ IF AMMONIA >1.0 ppm:                   │
│ • Stop feeding immediately             │
│ • Water change 50%                     │
│ • Add bacterial supplement if available│
│                                        │
│ IF NITRITE >1.0 ppm:                   │
│ • Add salt (1 lb per 100 gal)          │
│ • Water change 50%                     │
│ • Stop feeding 24 hours                │
│                                        │
│ IF FISH GASPING:                       │
│ • Emergency aeration                   │
│ • Water change 75%                     │
│ • Add pure oxygen if available         │
└────────────────────────────────────────┘

Timeline: 6-10 weeks (slower than fishless)
```

**Fish-In Cycling Reality Check:**

```
EXPECTED OUTCOMES

Best Case (with intensive care):
• 70-80% fish survival
• 8-10 week cycling time
• High stress and time commitment
• Fish may have stunted growth

Worst Case (inadequate management):
• 100% fish mortality
• System still not cycled
• Wasted time and money
• Emotional toll

Recommendation: Use fishless cycling whenever possible
```

#### What to Test and When

```
CYCLING TESTING SCHEDULE

WEEK 1-2 (Ammonia Phase):
Daily:
□ Ammonia (expect: rising then plateauing)
□ pH (expect: slowly dropping)
□ Temperature

Every 3 days:
□ Nitrite (expect: 0 until week 2)

WEEK 2-4 (Nitrite Phase):
Daily:
□ Ammonia (expect: drops to 0 quickly)
□ Nitrite (expect: RISING to 5-10 ppm)
□ pH

Every 3 days:
□ Nitrate (expect: starting to appear)

WEEK 4-6 (Completion):
Daily:
□ Ammonia (should → 0 in <24 hrs)
□ Nitrite (should → 0 in <24 hrs)

□ Nitrate (expect: accumulating)
```

### 8.7 Cycling Problems and Solutions

#### Common Issues

**Problem 1: Stalled Cycle - Ammonia Not Dropping**

```
DIAGNOSIS:

Ammonia stays high (>2 ppm) for 3+ weeks

Possible Causes:
├─ pH too low (<6.0) → Bacteria inactive
├─ Temperature too cold (<60°F) → Slow growth
├─ Insufficient oxygen → Bacteria dying
├─ Chlorine in water → Bacteria killed
└─ Not enough surface area → Limited colonization

Solutions:
├─ Test and raise pH to 7.0-7.5
├─ Add heater if water <65°F
├─ Increase aeration significantly
├─ Dechlorinate all water
└─ Add more biofilter media
```

**Problem 2: pH Crash**

```
DIAGNOSIS:

pH drops below 6.0 and continues falling

Why it happens:
Nitrification produces acid (H⁺ ions)
Without buffering, pH can crash
Low pH stops bacterial activity

Solution:
┌────────────────────────────────────────┐
│ 1. IMMEDIATE:                          │
│    • Add 1 tsp baking soda per 100 gal │
│    • Raises pH ~0.3 temporarily        │
│                                        │
│ 2. LONG-TERM:                          │
│    • Add potassium bicarbonate         │
│    • Add calcium carbonate (shells)    │
│    • Maintain KH at 60-100 ppm         │
│                                        │
│ 3. PREVENTION:                         │
│    • Test pH every 2-3 days            │
│    • Adjust before it drops <6.5       │
│    • Use buffered water source         │
└────────────────────────────────────────┘
```

**Problem 3: Nitrite Won't Drop**

```
DIAGNOSIS:

Ammonia → 0 quickly, but nitrite stays >2 ppm for 4+ weeks

Why it happens:
• Nitrobacter grows slower than Nitrosomonas
• High pH can inhibit Nitrobacter
• Low temperature slows growth

Solutions:
┌────────────────────────────────────────┐
│ BE PATIENT! This phase can take time.  │
│                                        │
│ If >6 weeks:                           │
│ • Verify pH is 6.5-7.5                 │
│ • Ensure temperature >65°F             │
│ • Add nitrifying bacteria product      │
│ • Reduce ammonia dosing temporarily    │
│ • Wait - eventually it will drop       │
└────────────────────────────────────────┘
```

**Problem 4: Cycling Too Fast (Suspicious)**

```
DIAGNOSIS:

Ammonia and nitrite both at 0 within 2 weeks

Likely Causes:
├─ Over-planted system consuming all nitrogen
├─ Very well-seeded system (good!)
├─ Testing error
└─ Not adding enough ammonia

Verification:
┌────────────────────────────────────────┐
│ Add challenge dose:                    │
│ • Dose ammonia to 3 ppm                │
│ • Test after 24 hours                  │
│                                        │
│ Result:                                │
│ • Ammonia + Nitrite = 0 → CYCLED ✓    │
│ • Ammonia or Nitrite >0 → NOT READY ✗ │
└────────────────────────────────────────┘
```

### 8.8 Confirming a Cycled System

#### The Final Test

```
CYCLING COMPLETION CHECKLIST

□ Ammonia challenge test passed:
  ├─ Dose to 3-4 ppm
  ├─ After 24 hours: <0.5 ppm ✓
  └─ After 48 hours: 0 ppm ✓

□ Nitrite verification:
  ├─ After ammonia challenge

  └─ Nitrate >20 ppm ✓

  ├─ pH between 6.5-7.5 ✓

  ├─ All equipment functioning ✓
  ├─ No leaks ✓
  ├─ Good aeration ✓
  └─ Temperature controlled ✓

IF ALL CHECKS PASS → READY FOR FISH!
```

### 8.9 Transitioning to Fish

#### Gradual Stocking Protocol

```
POST-CYCLING FISH INTRODUCTION

PREPARATION (Day before fish arrive):
□ Stop adding ammonia
□ 25% water change
□ Verify all parameters optimal
□ Prepare quarantine area (if applicable)
□ Have fish food ready

DAY 1: INITIAL STOCKING (25% of target)
┌────────────────────────────────────────┐
│ Example: Target = 40 lbs fish          │
│ Day 1: Add 10 lbs (25%)                │
│                                        │
│ Acclimation process:                   │
│ 1. Float bags 20-30 minutes (temp)     │
│ 2. Add system water to bags gradually  │
│ 3. After 1 hour, release fish          │
│ 4. Don't add bag water to system       │
└────────────────────────────────────────┘

DAYS 2-7: MONITORING
□ Test ammonia and nitrite daily
□ Watch fish behavior closely
□ Feed sparingly (0.5-1% body weight)
□ Parameters should stay: NH₃=0, NO₂⁻=0

DAY 8-10: SECOND STOCKING (to 50%)
□ If parameters stable, add another 25%
□ Repeat acclimation process
□ Continue daily testing

DAY 15-20: THIRD STOCKING (to 75%)
□ Parameters still stable?
□ Add another 25%
□ Testing can reduce to every other day

DAY 25-30: FINAL STOCKING (to 100%)
□ Add final fish to reach target
□ Begin normal feeding schedule
□ Reduce testing to weekly
```

#### First Feeding After Cycling

```
FEEDING SCHEDULE - WEEK 1

Day 1: Don't feed (let fish acclimate)

Day 2: Small feeding
├─ 0.25% body weight
├─ Watch fish for interest
└─ Remove uneaten food after 10 min

Days 3-4:
├─ 0.5% body weight
├─ Once per day
└─ Monitor water quality

Days 5-7:
├─ 0.75% body weight
├─ Once per day
└─ Ammonia should stay 0

Week 2+:
├─ Gradually increase to 1-2%
├─ Feed 2× daily
└─ Normal operations
```

## Vocabulary

| Term | Definition |
|------|------------|
| **Cycling** | Process of establishing beneficial bacterial colonies |
| **Challenge Test** | Adding ammonia to verify bacteria can process it quickly |
| **Fishless Cycling** | Cycling method using ammonia without fish present |
| **Fish-In Cycling** | Cycling with fish present (stressful for fish) |
| **Seeding** | Adding bacteria from established system to new system |
| **Nitrite Spike** | Peak nitrite concentration during cycling (weeks 2-4) |
| **Acclimation** | Gradual adjustment of fish to new water parameters |
| **Stocking Density** | Amount of fish biomass relative to water volume |
