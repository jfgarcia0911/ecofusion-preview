## Assessment Components

### 1. Module Quizzes (60 points total)
**20 quizzes × 3 points each**

#### Quiz Grading Rubric (per quiz)
| Criteria | Points | Description |
|----------|--------|-------------|
| Perfect Score | 3 pts | All questions correct, demonstrates mastery |
| Good Understanding | 2 pts | 70-90% correct, minor gaps in knowledge |
| Basic Understanding | 1 pt | 50-69% correct, significant gaps |
| Insufficient | 0 pts | Below 50% correct |

**Quiz Format:**
- 5-10 questions per quiz
- Mix of multiple choice, true/false, and short answer
- Open book, timed (15 minutes)
- 2 attempts allowed, highest score counts

## Academic Integrity

All work must be original. Collaboration is encouraged on in-class activities but all submitted work must be your own.

**Violations include:**
- Copying another student's work
- Using unauthorized resources during quizzes
- Submitting work done by others
- Plagiarizing from online sources without citation

**Consequences:** First violation results in zero on assignment; second violation results in course failure.
