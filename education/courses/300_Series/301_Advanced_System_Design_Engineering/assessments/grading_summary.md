## In-Class Activities (65 points, 29%)

### Assignment 01: Hydraulic Calculations Exercise (15 points)
**Duration:** 15-20 minutes
**Completed:** During Module 2

**Objectives:**
- Calculate Total Dynamic Head (TDH)
- Size pumps appropriately
- Select proper pipe diameters
- Apply friction loss calculations

**Deliverables:**
- Completed calculation worksheet
- Pump selection with justification
- Pipe sizing recommendations

---

### Assignment 02: Biofilter Sizing Analysis (20 points)
**Duration:** 20-30 minutes
**Completed:** During Module 4

**Objectives:**
- Calculate TAN load based on feed rate
- Determine required nitrification capacity
- Size biofilter with appropriate media
- Apply safety factors

**Deliverables:**
- TAN load calculations
- Biofilter sizing worksheet
- Media selection justification
- Final volume recommendation

---

### Assignment 03: P&ID Development Workshop (30 points)
**Duration:** 30-45 minutes
**Completed:** During Module 9

**Objectives:**
- Create Process & Instrumentation Diagram
- Use industry-standard symbols
- Show all flows and control points
- Integrate instrumentation

**Deliverables:**
- Complete P&ID for small system
- Component list
- Flow rate annotations
- Control strategy notes

## Comprehensive Capstone Project (70 points, 31%)

### Assignment 05: Complete System Design Project (70 points)
**Duration:** 2-4 hours
**Assigned:** Module 20
**Due:** End of course

**Project Scope:**
Design a complete commercial aquaponics system including all engineering drawings, calculations, specifications, and operational documents.

### Component Requirements:

#### 1. Design Drawings (20 points)
- Process & Instrumentation Diagram (P&ID)
- Floor plan with dimensions
- System elevations and sections
- Equipment layout

#### 2. Engineering Calculations (20 points)
- Hydraulic analysis (TDH, pump sizing)
- Biofilter sizing calculations
- Structural load analysis
- Electrical load analysis

#### 3. Specifications (15 points)
- Equipment specifications
- Material specifications
- Performance requirements
- Quality standards

#### 4. Bill of Materials & Operations Manual (15 points)
- Complete component list
- Vendor identification
- Cost estimates
- Startup procedures
- Normal operations
- Maintenance schedules

### Submission Requirements:
- Professional engineering package
- All drawings in CAD format (PDF export acceptable)
- Calculations clearly documented
- Organized in logical sequence
- Executive summary included

## Assessment Philosophy

This course emphasizes **professional-level engineering competency**. Assessments are designed to:

1. **Build Skills Progressively:** Each assignment builds on previous concepts
2. **Simulate Real Work:** Assignments mirror actual engineering deliverables
3. **Encourage Excellence:** Rubrics reward thoroughness and professional quality
4. **Support Learning:** Feedback is detailed and constructive
5. **Prepare for Industry:** Standards match commercial expectations
