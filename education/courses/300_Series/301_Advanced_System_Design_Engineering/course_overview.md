## Course Description

Master the engineering principles behind world-class aquaponic and hydroponic systems. This rigorous course covers hydraulic design, structural engineering, environmental systems integration, and advanced automation for commercial-scale facilities. Complete a comprehensive system design project as your capstone.

---

## Learning Outcomes

Upon successful completion, learners will be able to:
1. Apply engineering principles to system design
2. Perform hydraulic calculations and pump sizing
3. Design integrated environmental control systems
4. Develop detailed engineering specifications
5. Create professional engineering drawings (P&ID, floor plans)
6. Manage design review and approval processes

## Engineering Reference

### Hydraulic Calculations

**Total Dynamic Head (TDH):**
```
TDH = Static Head + Friction Head + Pressure Head

Where:
- Static Head = Vertical lift (ft)
- Friction Head = Pipe friction losses
- Pressure Head = Operating pressure requirements
```

**Pipe Sizing Guidelines:**

| Flow Rate (GPM) | Recommended Pipe Size | Max Velocity |
|-----------------|----------------------|--------------|
| 5-15 | 1" | 4-5 ft/s |
| 15-30 | 1.5" | 4-5 ft/s |
| 30-60 | 2" | 5-6 ft/s |
| 60-100 | 3" | 5-6 ft/s |
| 100-200 | 4" | 6-7 ft/s |

### Biofilter Sizing

```
Step 1: Calculate TAN Load
Daily Feed × Protein % × 0.092 = kg TAN/day

Step 2: Determine Nitrification Rate
Typical: 0.5-1.0 g TAN/m²/day

Step 3: Calculate Required Surface Area
TAN Load ÷ Nitrification Rate = m² required

Step 4: Select Media and Calculate Volume
Media surface area (m²/m³) → Volume required

Step 5: Apply Safety Factor (50%)
```

## Capstone Project Requirements

The capstone design project must include:

1. **Design Drawings**
   - Process & Instrumentation Diagram (P&ID)
   - Floor plan with dimensions
   - System elevations/sections
   - Equipment layout

2. **Engineering Calculations**
   - Hydraulic analysis (TDH, pump sizing)
   - Biofilter sizing
   - Structural loads
   - Electrical load analysis

3. **Specifications**
   - Equipment specifications
   - Material specifications
   - Performance requirements

4. **Bill of Materials**
   - Complete component list
   - Vendor identification
   - Cost estimates

5. **Operations Manual Outline**
   - Startup procedures
   - Normal operations
   - Maintenance schedules
