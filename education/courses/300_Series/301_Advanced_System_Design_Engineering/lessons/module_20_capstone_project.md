# Module 20: Capstone Design Project

## Introduction

The capstone project integrates all concepts from this course into a comprehensive system design. You will design a complete commercial aquaponic facility from concept through construction documentation, demonstrating mastery of engineering fundamentals, system integration, and professional documentation.

**Duration:** 1 hour (guidance) + 20-40 hours (project work)

---

## Learning Objectives

1. Integrate multiple engineering disciplines into cohesive design
2. Perform complete engineering calculations
3. Create professional construction documents
4. Write comprehensive technical specifications
5. Develop operations and maintenance documentation
6. Present design to technical audience

---

## Project Requirements

### Project Scope

**Design a commercial aquaponic facility with these parameters:**

```
Facility Type: Indoor vertical farm with integrated aquaponics
Location: Select any climate zone
Fish Production: 10,000 lb/year tilapia (or equivalent species)
Plant Production: Leafy greens, 500 sq ft growing area minimum
System Type: Recirculating aquaculture + deep water culture (DWC)
Budget Target: $150,000-250,000 capital cost
```

### Required Deliverables

**1. Design Narrative (10-15 pages)**
```
Contents:
- Executive summary

- Climate and environmental considerations
- Production targets and market analysis
- Risk assessment
- Sustainability features
```

**2. Engineering Calculations (Complete Package)**
```
Required Calculations:
a) Biological Loading
   - Fish stocking density and growth projections
   - Feed rate and protein content
   - TAN production calculations
   - Nutrient production for plants

b) Hydraulic Design
   - System flow rates and turnover
   - Total dynamic head (TDH) for all circuits
   - Pump selection and sizing
   - Pipe sizing with friction loss
   - Manifold design
   - Gravity drain sizing

c) Biofilter Design
   - TAN loading calculations
   - Nitrification rate assumptions
   - Media selection and volume sizing
   - Oxygen requirements
   - Aeration system design

d) Structural Analysis
   - Tank loads (dead + live)
   - Floor loading calculations
   - Support beam sizing
   - Foundation requirements

e) Electrical Design
   - Load calculations
   - Service sizing
   - Circuit design
   - Wire sizing and voltage drop
   - Backup power sizing

f) HVAC Design
   - Heat load calculations (heating + cooling)
   - Ventilation requirements
   - Dehumidification sizing
   - Equipment selection

g) Lighting Design
   - PPFD and DLI calculations
   - Fixture selection and layout
   - Power requirements
   - Heat load from lighting

h) Water Treatment
   - Mechanical filtration sizing
   - UV sizing (if used)
   - Dechlorination design
   - Effluent treatment (if required)

All calculations must show:
- Given values and assumptions
- Formulas used
- Step-by-step solution
- Units throughout
- Safety factors applied
- Final results summarized
```

## Design Process

### Phase 1: Concept Development (Week 1-2)

**Tasks:**
1. Review project requirements
2. Research similar facilities
3. Develop system concept
4. Create preliminary layout sketches
5. Size major equipment (rough)
6. Estimate feasibility and cost
7. Identify design challenges

**Deliverable:** Conceptual design narrative and sketches

### Phase 2: Design Development (Week 3-6)

**Tasks:**
1. Perform all engineering calculations
2. Size all equipment precisely
3. Develop floor plan and elevations
4. Design plumbing and electrical systems
5. Select materials
6. Create P&ID
7. Refine cost estimate

**Deliverable:** Complete calculations and preliminary drawings

### Phase 3: Construction Documents (Week 7-10)

**Tasks:**
1. Finalize all drawings in CAD
2. Write technical specifications
3. Develop detailed BOM
4. Create operations manual outline
5. Perform design review (self and peer)
6. Address review comments
7. Finalize all documentation

**Deliverable:** Complete construction document set

### Phase 4: Presentation Preparation (Week 11-12)

**Tasks:**
1. Create presentation slides
2. Prepare for Q&A
3. Practice presentation
4. Refine based on feedback
5. Finalize all deliverables

**Deliverable:** Final presentation and complete project package

## Tips for Success

### Organization

```
1. Start early - this is a major project
2. Create a project schedule with milestones
3. Organize files systematically:
   /Calculations
   /Drawings
   /Specifications
   /References
   /Presentation
4. Back up work regularly (cloud + local)
5. Track assumptions and decisions
```

### Calculations

```
1. Show all work (partial credit possible)
2. Use spreadsheets for repetitive calculations
3. Include references for formulas
4. State assumptions clearly
5. Apply safety factors consistently
6. Double-check critical calculations
7. Use peer review
```

### Drawings

```
1. Start with floor plan (everything builds from this)
2. Use layers effectively in CAD
3. Maintain consistent scale
4. Reference details clearly
5. Include all required information
6. Check for conflicts between drawings
7. Plot/print to verify appearance
```

### Specifications

```
1. Use specification templates (CSI format)
2. Be specific but not overly restrictive
3. Include performance requirements
4. Reference standards (ASTM, NSF, etc.)
5. Specify testing and acceptance
6. Proofread carefully
```

## Example Project Outline

**Project Title:** "Urban Indoor Tilapia & Lettuce Farm"

**System Overview:**
- Location: Portland, Oregon (Climate Zone 4C)
- Building: Existing warehouse, 2,500 ft² converted space
- Fish: 10,000 lb/year tilapia (3 growth cohorts)
- Plants: 500 ft² DWC lettuce (4,800 heads/month)
- System: Recirculating with MBBR biofilter
- Automation: PLC-based with remote monitoring

**Key Design Features:**
- Heat recovery from lighting to fish tanks
- Rainwater harvesting for makeup water
- Solar-ready electrical design
- Modular expansion capability
- Gravity drain backup for pumps
- Battery backup aeration (8 hour capacity)

**Innovation Highlights:**
- Waste heat from LED drivers used for tank heating
- Denitrification loop for effluent treatment
- Automated feeding with growth tracking
- Energy use intensity: 15 kWh/kg fish (excellent)
