# Module 17: Specifications Writing

## Introduction

Technical specifications communicate design requirements to contractors, suppliers, and operators. Well-written specs prevent errors, ensure quality, and provide legal protection. This module covers specification writing for equipment, materials, and performance requirements.

**Duration:** 1 hour

---

## Learning Objectives

1. Understand specification types and organization
2. Write performance specifications for equipment
3. Develop material specifications with standards
4. Create installation specifications
5. Specify testing and acceptance criteria
6. Organize specifications using CSI MasterFormat

---

## 1. Specification Types

### 1.1 Prescriptive vs Performance

**Prescriptive:** "The contractor shall install a Pentair Aquatic Eco-Systems MD-70 pump or approved equal."
- Specifies exact product
- Limits flexibility
- Reduces risk

**Performance:** "The contractor shall provide a centrifugal pump capable of 200 GPM at 35 ft TDH with minimum 65% efficiency at design point."
- Specifies requirements
- Allows alternatives
- Encourages competition

**Recommendation:** Use performance specs with approved manufacturers list

## 3. Equipment Specifications

### 3.1 Pump Specification Example

```
SECTION 22 14 13 - RECIRCULATION PUMPS

1.0 GENERAL
    1.1 Summary: This section specifies centrifugal pumps for recirculating aquaponic system water.
    1.2 Related Sections: See 26 24 00 for electrical work.

2.0 PRODUCTS
    2.1 Manufacturers:
        - Pentair Aquatic Eco-Systems
        - Little Giant
        - Or approved equal

    2.2 Main Recirculation Pump:
        - Type: Centrifugal, magnetic drive
        - Capacity: 200 GPM ±5% at 35 ft TDH
        - Efficiency: Minimum 65% at design point
        - Motor: 2 HP, 230V, 1-phase, TEFC
        - Materials: Noryl impeller, stainless shaft, Viton seals
        - NPSH Required: <8 ft at design point

3.0 EXECUTION
    3.1 Installation: Mount on vibration isolators per manufacturer.
    3.2 Testing: Demonstrate flow and pressure per submittal pump curve.
```

## 4. Material Specifications

### 4.1 Piping Specification

```
SECTION 22 05 23 - GENERAL-DUTY VALVES

1.0 GENERAL
    1.1 Summary: PVC ball valves for aquaponic system.

2.0 PRODUCTS
    2.1 Materials:
        - Body: PVC Schedule 40, ASTM D1785
        - Ball: PVC or CPVC
        - Seals: EPDM, NSF-61 rated
        - Pressure Rating: 150 PSI @ 73°F minimum

    2.2 Sizes: 1/2" through 4" as shown on drawings

    2.3 End Connections: Socket (solvent weld) both ends

3.0 EXECUTION
    3.1 Install with unions for serviceability
    3.2 Support piping per ASME B31.1
    3.3 Pressure test at 1.5× operating pressure for 2 hours
```

## 5. Performance Requirements

### 5.1 Biofilter Specification

```
SECTION 22 66 13 - BIOLOGICAL FILTRATION

1.0 GENERAL
    1.1 Summary: Moving bed biofilter for ammonia oxidation.

2.0 PERFORMANCE REQUIREMENTS
    2.1 Capacity:
        - TAN removal: 500 g/day minimum
        - Outlet TAN: <1.0 mg/L
        - Outlet NO₂⁻: <0.5 mg/L

    2.2 Operating Conditions:
        - Flow rate: 150 GPM ±10%
        - Temperature: 75-82°F
        - pH: 6.8-7.8
        - DO: >5.0 mg/L

3.0 PRODUCTS
    3.1 Vessel: 3,000 gallon HDPE, NSF-61
    3.2 Media: Kaldnes K1 or K3, 50-60% fill
    3.3 Aeration: Fine bubble diffusers, 200 CFM total
    3.4 Blower: Rotary vane, 5 HP, 250 CFM @ 6 PSI

4.0 EXECUTION
    4.1 Startup: Allow 4-6 weeks for bacterial establishment
    4.2 Testing: Demonstrate performance per 2.1 after maturation
```

## 6. Installation Requirements

### 6.1 Installation Tolerances

```
Levelness:
- Tank tops: ±1/4" in 10 ft
- Drain slopes: 1/4" per foot ±1/8"
- Equipment pads: ±1/8" in 3 ft

Alignment:
- Pipe: ±1/4" from centerline
- Supports: ±2" from specified location
- Electrical panels: ±1/2" plumb

Clearances:
- Equipment access: 3 ft minimum
- Electrical panels: 3.5 ft clear space
- Maintenance access: Per manufacturer
```

## 7. Testing and Acceptance

### 7.1 Testing Procedures

```
Pressure Testing:
1. Fill system with clean water
2. Pressurize to 1.5× operating pressure
3. Hold for 2 hours minimum
4. Inspect all connections
5. Document any leaks
6. Repair and retest

Flow Testing:
1. Commission all pumps per manufacturer
2. Measure flow at design points using calibrated meter
3. Verify flows within ±10% of specified
4. Adjust/balance as required
5. Document final flows

Water Quality Testing:
1. Operate biofilter for 6 weeks minimum
2. Daily monitoring of TAN, NO₂⁻, NO₃⁻, pH, DO
3. Achieve specified performance for 7 consecutive days
4. Submit test data for approval
```

---

## Summary

Specifications ensure design intent is executed correctly:

1. Use performance specifications with approved manufacturers
2. Organize using CSI MasterFormat
3. Include complete product requirements
4. Specify materials with ASTM/NSF standards
5. Detail installation tolerances
6. Define testing and acceptance criteria

Well-written specifications prevent disputes and ensure quality construction.
