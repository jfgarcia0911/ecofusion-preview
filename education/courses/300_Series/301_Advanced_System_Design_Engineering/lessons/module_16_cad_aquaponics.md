# Module 16: CAD for Aquaponics

## Introduction

Computer-Aided Design (CAD) is essential for professional system design. CAD enables precise layouts, 3D visualization, interference checking, and generation of construction documents. This module covers CAD fundamentals for aquaponic facility design.

**Duration:** 1 hour

---

## Learning Objectives

1. Select appropriate CAD software for aquaponics
2. Create 2D floor plans and elevations
3. Develop 3D models for visualization
4. Generate construction documents and details
5. Perform interference checking
6. Export drawings for contractors

---

## 1. CAD Software Options

### 1.1 Software Comparison

| Software | Type | Cost | Learning Curve | Best For |
|----------|------|------|----------------|----------|
| AutoCAD | 2D/3D | $$$$ | High | Professional, detailed drawings |
| SketchUp | 3D | $$-Free | Low | Conceptual design, visualization |
| Fusion 360 | 3D parametric | $-Free | Medium | Product design, fabrication |
| LibreCAD | 2D | Free | Medium | 2D drawings, open-source |
| SolidWorks | 3D parametric | $$$$ | High | Engineering analysis, manufacturing |

**Recommendation for Aquaponics:**
- Small systems: SketchUp (easy, visual)
- Commercial: AutoCAD or Fusion 360 (professional documentation)
- Structural analysis: SolidWorks (FEA capabilities)

## 2. Drawing Types

### 2.1 Floor Plans

**Required Elements:**
```
- Overall dimensions
- Equipment locations with clearances
- Pipe routing (mains and risers)
- Electrical panel locations
- Drainage and containment
- Access aisles (minimum 3 ft)
- Door swings and emergency exits
- North arrow and scale

Scale: 1/4" = 1'-0" or 1/8" = 1'-0" for large facilities
```

### 2.2 Elevations and Sections

**Purpose:** Show vertical relationships
```
- Equipment heights
- Pipe elevations
- Structural support
- Head room clearances
- Drainage slopes
- Overflow protection

Show at least two elevations: long axis and short axis
```

### 2.3 Details

**Common Details:**
```
- Bulkhead installation
- Pipe support brackets
- Tank support structure
- Electrical panel layout
- Plumbing manifold connections
- Bell siphon assembly

Scale: 1" = 1'-0" or larger for clarity
Include material callouts and dimensions
```

## 3. 3D Modeling

### 3.1 Component Libraries

**Build or Download:**
```
Common components:
- IBC totes (standard 275 gal)
- PVC pipes and fittings
- Pumps and valves
- Grow beds and rafts
- Lighting fixtures
- Structural steel shapes

Sources:
- Manufacturer websites (CAD downloads)
- 3D Warehouse (SketchUp)
- GrabCAD (community library)
- Model from scratch (learn dimensions)
```

### 3.2 Interference Checking

**Collision Detection:**
```
Common interferences:
- Pipes crossing at same elevation
- Equipment door swing blocked
- Insufficient clearance for maintenance
- Lighting fixtures hitting structural members
- Electrical conduit in plumbing path

Check in 3D before construction!
Moving a pipe in CAD: 5 minutes
Moving an installed pipe: 5 hours + $$
```

## 4. Layers and Organization

### 4.1 Layer Standards

**AIA Layer Naming:**
```
Format: A-XXXX-YYYY

Examples:
A-WALL - Walls
A-DOOR - Doors and frames
M-PIPE - Mechanical piping
P-TANK - Plumbing tanks
E-LITE - Electrical lighting
E-POWR - Electrical power

Color coding:
Walls: Black
Plumbing: Blue
Electrical: Red
HVAC: Green
Annotation: Magenta
```

---

## 5. Dimensioning Standards

### 5.1 Dimension Best Practices

```
- Dimension to centerlines
- Provide overall dimensions
- Chain dimensions for aligned objects
- Use architectural units (feet and inches)
- Dimension critical clearances
- Call out pipe sizes
- Show slopes for drainage (1/4" per foot)

Example annotation:
"3" PVC SCH 40 MAIN SUPPLY, SLOPE 1/4" PER FOOT TO DRAIN"
```
