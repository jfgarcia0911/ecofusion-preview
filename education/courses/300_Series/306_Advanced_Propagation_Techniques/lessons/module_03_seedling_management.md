# Module 3: Seedling Management

**Course:** 306 - Advanced Propagation Techniques
**Duration:** 1 hour
**Level:** Advanced

---

## Learning Objectives

By the end of this module, you will be able to:
1. Manage seedlings from emergence through transplant-ready stage
2. Implement proper fertilization programs for young plants
3. Control growth and timing using environmental manipulation
4. Prevent and manage common seedling problems
5. Produce high-quality, uniform transplants

### Stage-Specific Requirements

| Stage | Temperature | Light (fc) | Humidity | Fertilizer | Irrigation |
|-------|-------------|------------|----------|------------|------------|
| **Radicle emergence** | Optimal for species | 0-100 | 90-100% | None | High, constant |
| **Cotyledon emergence** | Optimal-2°F | 500-1000 | 70-90% | None | High |
| **True leaf** | Optimal-5°F | 1000-2000 | 60-80% | 50-100 ppm N | Moderate |
| **Rapid growth** | Optimal-5 to 10°F | 2000-5000 | 50-70% | 100-200 ppm N | Dry-down cycles |
| **Pre-transplant** | Cool 5-10°F | 2000-5000 | 40-60% | 75-150 ppm N | Reduced |

### Pour-Through Testing Protocol

```
POUR-THROUGH METHOD FOR EC AND pH TESTING
════════════════════════════════════════════════════════════════════════════

Purpose: Measure nutrient levels and pH in root zone without destroying plant

Equipment Needed:
├─ EC meter (calibrated)
├─ pH meter (calibrated)
├─ Collection saucers
├─ Distilled water
└─ Graduated cylinder

Procedure:
┌──────────────────────────────────────────────────────────────────────────┐
│ 1. Wait 1 hour after normal irrigation                                  │
│                                                                          │
│ 2. Place collection saucer under container                              │
│                                                                          │
│ 3. Pour distilled water slowly onto substrate surface                   │
│    Amount: 50-75 mL for 4" pot, 100-150 mL for 6" pot                  │
│                                                                          │
│ 4. Collect leachate that drains within 30-60 seconds                   │
│                                                                          │
│ 5. Measure EC and pH of leachate immediately                            │
│                                                                          │
│ 6. Record results and compare to targets                                │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

TARGET RANGES:
├─ EC: 0.5-1.5 mS/cm (seedlings)
│     1.0-2.5 mS/cm (established plants)
├─ pH: 5.8-6.2 (soilless media)
│      6.0-6.5 (soil-based media)

INTERPRETATION:
├─ EC too low (<0.5): Increase fertilizer concentration
├─ EC too high (>2.0): Leach with clear water, reduce fertilizer
├─ pH too low (<5.5): Add lime or use alkaline fertilizer
└─ pH too high (>6.5): Use acidic fertilizer, add sulfur
```

## 3. Environmental Control

### DIF and DROP for Height Control

```
╔══════════════════════════════════════════════════════════════════════════════╗
║                        TEMPERATURE-BASED HEIGHT CONTROL                      ║
╠══════════════════════════════════════════════════════════════════════════════╣
║                                                                              ║
║  DIF (Day-Night Temperature Difference)                                      ║
║  ┌────────────────────────────────────────────────────────────────────────┐ ║
║  │                                                                         │ ║
║  │  DIF = Day Temp - Night Temp                                           │ ║
║  │                                                                         │ ║
║  │  POSITIVE DIF (Day > Night)                                            │ ║
║  │  Example: Day 72°F, Night 62°F → +10°F DIF                            │ ║
║  │  Effect: Normal to increased stem elongation                           │ ║
║  │  Use: When height is desired                                           │ ║
║  │                                                                         │ ║
║  │  ZERO DIF (Day = Night)                                                │ ║
║  │  Example: Day 68°F, Night 68°F → 0°F DIF                              │ ║
║  │  Effect: Moderate growth, compact plants                               │ ║
║  │  Use: Standard production                                              │ ║
║  │                                                                         │ ║
║  │  NEGATIVE DIF (Day < Night)                                            │ ║
║  │  Example: Day 62°F, Night 68°F → -6°F DIF                             │ ║
║  │  Effect: Reduced stem elongation, compact growth                       │ ║
║  │  Use: Height control without chemicals                                 │ ║
║  │                                                                         │ ║
║  └────────────────────────────────────────────────────────────────────────┘ ║
║                                                                              ║
║  DROP (Morning Temperature Drop)                                             ║
║  ┌────────────────────────────────────────────────────────────────────────┐ ║
║  │                                                                         │ ║
║  │  Temperature °F                                                         │ ║
║  │   75─┐                                                                  │ ║
║  │      │     ┌──────────── Day temp                                      │ ║
║  │   70─┤─────┘                                                            │ ║
║  │      │                                                                  │ ║
║  │   65─┤                                                                  │ ║
║  │      │                                                                  │ ║
║  │   60─┤               ┌────────── Night temp                            │ ║
║  │      │               │                                                  │ ║
║  │   55─┼───────────────┘                                                  │ ║
║  │      └────┬────────────────────────────► Time                          │ ║
║  │        Sunrise  (2-3 hr drop)                                          │ ║
║  │                                                                         │ ║
║  │  Protocol:                                                              │ ║
║  │  ├─ At sunrise, drop temp 5-10°F for 2-3 hours                        │ ║
║  │  ├─ Then raise to normal day temperature                               │ ║
║  │  └─ Effect: Reduces stem elongation dramatically                       │ ║
║  │                                                                         │ ║
║  │  Practical application:                                                 │ ║
║  │  ├─ Open vents at sunrise                                              │ ║
║  │  ├─ Use evaporative cooling                                            │ ║
║  │  └─ Can reduce PGR use by 50-100%                                      │ ║
║  │                                                                         │ ║
```

## 4. Water Management and Hardening Off

### Irrigation Strategies by Growth Stage

| Stage | Frequency | Method | Goal |
|-------|-----------|--------|------|
| **Germination** | 2-4× daily | Mist or sub-irrigation | Constant moisture |
| **Emergence** | 1-2× daily | Light overhead or sub-irrigation | Moist but not saturated |
| **Early growth** | 1× daily | Sub-irrigation preferred | Allow slight drying |
| **Rapid growth** | 1× daily or alternate days | Dry-down between waterings | Encourage root growth |
| **Pre-transplant** | As needed, reduced | Stress irrigation | Hardening, toughen plants |

### Hardening Off Protocol

```
╔══════════════════════════════════════════════════════════════════════════════╗
║                        HARDENING OFF PROGRAM                                 ║
║                         (7-14 days before transplant)                        ║
╠══════════════════════════════════════════════════════════════════════════════╣
║                                                                              ║
║  WEEK 1: GRADUAL STRESS                                                      ║
║  ┌────────────────────────────────────────────────────────────────────────┐ ║
║  │ Day 1-2:                                                                │ ║
║  │  ├─ Reduce temperature 3-5°F day and night                             │ ║
║  │  ├─ Reduce humidity to 50-60%                                          │ ║
║  │  ├─ Reduce irrigation frequency (allow slight wilting)                 │ ║
║  │  └─ Maintain full light                                                │ ║
║  │                                                                         │ ║
║  │ Day 3-4:                                                                │ ║
║  │  ├─ Reduce temperature another 3-5°F                                   │ ║
║  │  ├─ Reduce fertilizer concentration by 50%                             │ ║
║  │  ├─ Increase air circulation                                           │ ║
║  │  └─ Short outdoor exposure (1-2 hrs) if applicable                     │ ║
║  │                                                                         │ ║
║  │ Day 5-7:                                                                │ ║
║  │  ├─ Temperature at final production level                              │ ║
║  │  ├─ Fertilizer reduced to 25% or clear water                           │ ║
║  │  ├─ Allow moderate wilting between waterings                           │ ║
║  │  └─ Increase outdoor exposure (3-4 hrs) if applicable                  │ ║
║  └────────────────────────────────────────────────────────────────────────┘ ║
║                                                                              ║
║  WEEK 2: FINAL CONDITIONING (if time allows)                                 ║
```

### Disease Management

```

│                    SEEDLING DISEASE PREVENTION & CONTROL                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  DAMPING-OFF (Pythium, Rhizoctonia, Fusarium)                               │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ Symptoms: Seedlings collapse at soil line, water-soaked lesions      │ │
│  │                                                                        │ │
│  │ Prevention:                                                            │ │
│  │  ├─ Use sterile medium and containers                                 │ │
│  │  ├─ Avoid overwatering and high humidity                              │ │
│  │  ├─ Ensure good air circulation                                       │ │
│  │  ├─ Don't over-seed (prevent crowding)                                │ │
│  │  └─ Maintain proper temperature                                       │ │
│  │                                                                        │ │
│  │ Treatment:                                                             │ │
│  │  ├─ Remove affected seedlings immediately                             │ │
│  │  ├─ Reduce watering, improve drainage                                 │ │
│  │  ├─ Apply biological fungicides (Trichoderma, Bacillus)              │ │
│  │  ├─ Chemical options: Subdue MAXX, RootShield                         │ │
│  │  └─ Increase air flow and reduce humidity                             │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│  BOTRYTIS (Gray Mold)                                                        │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ Symptoms: Gray fuzzy growth on dying tissue, brown lesions            │ │
│  │                                                                        │ │
│  │ Prevention:                                                            │ │
│  │  ├─ Avoid overhead irrigation late in day                             │ │
│  │  ├─ Ensure leaves dry before dark                                     │ │
│  │  ├─ Space plants for air circulation                                  │ │
│  │  ├─ Remove dead/dying tissue promptly                                 │ │
│  │  └─ Reduce humidity below 85%                                         │ │
│  │                                                                        │ │
│  │ Treatment:                                                             │ │
│  │  ├─ Improve environmental conditions                                  │ │
│  │  ├─ Fungicide rotation (Decree, Switch, Daconil)                     │ │
│  │  └─ Biological: Cease, BotryStop                                      │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│  POWDERY MILDEW                                                              │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ Symptoms: White powdery coating on leaves                             │ │
│  │                                                                        │ │
│  │ Prevention:                                                            │ │
│  │  ├─ Ensure adequate spacing                                           │ │
│  │  ├─ Avoid excess nitrogen                                             │ │
│  │  ├─ Maintain moderate humidity (40-60%)                               │ │
│  │  └─ Good air circulation                                              │ │
│  │                                                                        │ │
│  │ Treatment:                                                             │ │
│  │  ├─ Sulfur or potassium bicarbonate sprays                           │ │
│  │  ├─ Horticultural oils                                                │ │
│  │  ├─ Fungicides: Eagle, Compass, Terraguard                           │ │
│  │  └─ Biological: MilStop, Regalia                                      │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### Physiological Disorders

| Disorder | Symptoms | Cause | Solution |
|----------|----------|-------|----------|
| **Stretching** | Long, weak stems | Low light, high temp, high humidity | Increase light, lower temp, reduce humidity |
| **Purpling** | Purple stems/leaves | Cold stress, P deficiency | Increase temperature, add phosphorus |
| **Edema** | Warty bumps on leaves | Overwatering, high humidity | Reduce irrigation, improve air flow |
| **Tipburn** | Brown leaf edges | Calcium deficiency, rapid growth | Add calcium, reduce temps, increase air flow |
| **Chlorosis** | Yellow leaves | Nutrient deficiency, pH issues | Test and adjust fertility and pH |
| **Necrosis** | Dead tissue | Salt buildup, disease | Leach medium, reduce EC, manage pathogens |

## Key Takeaways

1. **Stage-specific management** is critical for seedling success
2. **Nutrition programs** must match plant development and growth rate
3. **Environmental control** (DIF, light) offers non-chemical height control
4. **Hardening off** dramatically improves transplant success
5. **Disease prevention** is far more effective than treatment
6. **Quality grading** ensures customer satisfaction and profitability
