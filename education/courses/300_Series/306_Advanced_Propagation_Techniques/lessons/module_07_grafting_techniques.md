## 1. Why Graft?

### Advantages of Grafting

- **Disease resistance**: Resistant rootstock protects susceptible scion
- **Vigor control**: Dwarfing or invigorating rootstocks
- **Soil adaptation**: Rootstocks tolerant to pH, salts, pathogens
- **Early fruiting**: Skip juvenile phase
- **Multi-variety trees**: Multiple scions on one rootstock
- **Repair**: Bridge grafting for damaged trees

### Common Grafted Crops

| Crop | Rootstock Purpose | Typical Method | Success Rate |
|------|-------------------|----------------|--------------|
| Tomato | Fusarium/Verticillium resistance | Splice, tube | 90-95% |
| Cucumber | Vigor, disease resistance | Hole insertion | 85-92% |
| Eggplant | Bacterial wilt resistance | Splice | 85-90% |
| Citrus | Cold hardiness, dwarfing | T-bud, chip bud | 80-90% |
| Apple | Dwarfing, soil adaptation | Whip & tongue | 85-95% |
| Grape | Phylloxera resistance | Whip & tongue | 70-85% |

## 2. Grafting Compatibility

### Botanical Relationships

**Rule**: Closer botanical relationship = higher compatibility

- **Same species**: Nearly 100% compatible
- **Same genus**: Usually compatible (80-95%)
- **Same family**: Sometimes compatible (30-70%)
- **Different families**: Rarely compatible (<10%)

### Compatibility Factors

1. **Vascular cambium alignment**: Critical for union formation
2. **Growth rates**: Similar vigor prevents overgrowth
3. **Phenology**: Matching dormancy/activity periods
4. **Biochemical compatibility**: No toxic interactions
5. **Virus indexing**: Clean stock prevents transmission

## 3. Grafting Methods - Illustrated

### Whip and Tongue Graft (for similar-diameter stems)

```
STEP 1: Make Matching Cuts
     Scion                Rootstock
       |                      |
       |   /                  |   /
       |  /                   |  /
       | /                    | /
       |/___                  |/___

STEP 2: Create "Tongue"
     ___                    ___
    /   |                  /   |
   /    | <-- Upward cut  /    |
       |                      |

STEP 3: Interlock
         ┌────────┐
    Scion│   /\   │
         │  /  \  │
         │ /    \ │
         ├┴──────┴┤ <-- Cambium contact
         │        │
Rootstock│        │
         └────────┘

STEP 4: Wrap Tightly
   ═══════════════
   ║   Grafted   ║ <-- Parafilm or grafting tape
   ║    Union    ║
   ═══════════════
```

Success rate: 85-95% | Best for: Grapes, apples, stone fruits

---

### Cleft Graft (for thick rootstock, thin scions)

```
STEP 1: Cut Rootstock Square
         ┌────┐
         │    │  Rootstock (1-4" diameter)
         └────┘

STEP 2: Split Down Center
         ┌──│──┐
         │  │  │  1-2" deep split
         └──┴──┘

STEP 3: Prepare Wedge Scions
           /\
          /  \   Scion (pencil-thick)
         /    \  Cut to wedge shape
        /      \

STEP 4: Insert Scions (1-2)
         ┌─/\──/\─┐
         │/  \/  \│  Cambium aligned
         │   ||   │  on one or both sides
         └───||───┘

STEP 5: Seal Completely
    ╔═══════════╗
    ║ Wax/sealant
    ╚═══════════╝
```

Success rate: 75-90% | Best for: Top-working fruit trees

---

### Splice Graft (for vegetable grafting)

```
  Scion          Rootstock
    |               |
    |               |
   /|              /|
  / |    ALIGN    / |
 /  | ========>> /  |  Matching diagonal cuts
|   |           |   |  (45-60° angle)
 \  |            \  |
  \_|             \_|

Secure with:
- Grafting clip (vegetables)
- Parafilm wrap (woody plants)
- Silicon tube (tomato grafting)
```

Success rate: 85-95% | Best for: Tomato, eggplant, cucumber

## 4. Grafting Procedure

### Pre-Graft Preparation

**Stock Plants:**
- Well-watered 24 hours before grafting
- Disease-free, vigorous
- Proper size/age for method

**Tools:**
- Razor-sharp grafting knife
- Sterilize between plants (70% alcohol)
- Grafting tape or clips
- Grafting wax (for woody plants)

**Environment:**
- Clean workspace
- 65-75°F ambient temperature
- High humidity chamber ready (90-100% RH)

### Healing Chamber Conditions

| Parameter | Target | Duration | Notes |
|-----------|--------|----------|-------|
| Temperature | 75-85°F | 7-14 days | Higher = faster callus |
| Humidity | 90-100% | 7-10 days | Prevents desiccation |
| Light | Low (500-1000 fc) | Until union | Reduce transpiration |
| Air circulation | Minimal | 7 days | Then gradually increase |

### Post-Graft Care Timeline

```
DAY 1-3: Critical Period
├─ Keep in humid chamber
├─ Monitor for wilting
├─ Maintain 80-85°F
└─ No direct sun

DAY 4-7: Callus Formation
├─ Callus tissue visible
├─ Reduce humidity slightly (85-95%)
├─ Increase light to 1000 fc
└─ Check for disease

DAY 7-14: Union Strengthening
├─ Vascular connection forming
├─ Reduce humidity to 70-80%
├─ Increase light to 2000 fc
├─ Begin air circulation
└─ Remove clips/tape (woody grafts leave longer)

DAY 14-21: Acclimation
├─ Move to normal growing conditions
├─ Full light and air
├─ Remove any temporary support
└─ Pinch rootstock shoots
```

## 7. Troubleshooting

| Problem | Cause | Solution |
|---------|-------|----------|
| **Graft failure/separation** | Poor cambium contact | Ensure smooth cuts, tight wrapping |
| | Desiccation | Increase humidity in healing chamber |
| | Movement during healing | Secure firmly, avoid disturbance |
| **Wilting after grafting** | Transpiration exceeds uptake | Increase humidity, reduce light |
| | Vascular blockage | May recover, give time |
| **Disease at union** | Contaminated tools/wounds | Sterilize tools, use clean technique |
| **Rootstock shoots dominating** | Not removed promptly | Pinch rootstock growth weekly |
| **Graft incompatibility** | Biochemical incompatibility | Use compatible combinations only |
| **Callus but no connection** | Low temperature | Increase to 80-85°F |
| | Poor alignment | Ensure cambium contact |

---

## Key Takeaways

1. **Cambium contact is critical** - even small misalignment reduces success
2. **Cleanliness prevents disease** - sterilize tools between each graft
3. **Healing environment matters** - high humidity and warmth are essential
4. **Grafting is a skill** - practice improves speed and success rates
5. **Rootstock selection** drives production goals (disease, vigor, adaptation)
6. **Economic benefit** justifies higher cost through disease resistance and yield
