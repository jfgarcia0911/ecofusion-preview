## Learning Objectives

By the end of this module, you will be able to:

## 1. Why Vegetative Propagation?

### Advantages vs. Seed Propagation

```
┌─────────────────────────────────────────────────────────────────────────────┐
│               VEGETATIVE VS. SEED PROPAGATION COMPARISON                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  VEGETATIVE PROPAGATION                                                     │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ Advantages:                                                            │ │
│  │  ✓ Genetic clone - maintains exact characteristics                    │ │
│  │  ✓ Faster to market (skips juvenile phase)                            │ │
│  │  ✓ Propagate plants that don't set seed                               │ │
│  │  ✓ Preserve hybrid vigor without segregation                          │ │
│  │  ✓ Can select for superior individuals                                │ │
│  │  ✓ Year-round production (not seasonal)                               │ │
│  │                                                                        │ │
│  │ Disadvantages:                                                         │ │
│  │  ✗ Higher labor and skill requirement                                 │ │
│  │  ✗ Can spread diseases from stock plants                              │ │
│  │  ✗ Requires maintaining stock plant collection                        │ │
│  │  ✗ No genetic diversity (vulnerability)                               │ │
│  │  ✗ Some species difficult to root                                     │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│  SEED PROPAGATION                                                            │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ Advantages:                                                            │ │
│  │  ✓ Lower cost and labor                                               │ │
│  │  ✓ Disease-free start (if certified seed)                             │ │
│  │  ✓ Easy storage and shipping                                          │ │
│  │  ✓ Genetic diversity (if open-pollinated)                             │ │
│  │  ✓ Strong taproot development                                         │ │
│  │                                                                        │ │
│  │ Disadvantages:                                                         │ │
│  │  ✗ Genetic variation (except F1 hybrids)                              │ │
│  │  ✗ Longer juvenile period                                             │ │
│  │  ✗ Not possible for sterile cultivars                                 │ │
│  │  ✗ Hybrids segregate in F2 generation                                 │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

|---------------|----------|----------------|--------------|

## 3. The Physiology of Root Formation

### Adventitious Root Development Stages

```
╔══════════════════════════════════════════════════════════════════════════════╗
║                  ADVENTITIOUS ROOT FORMATION PROCESS                         ║
╠══════════════════════════════════════════════════════════════════════════════╣
║                                                                              ║
║  PHASE 1: DEDIFFERENTIATION (Days 0-3)                                       ║
║  ├─ Mature cells revert to meristematic state                               ║
║  ├─ Cell division begins in cambium or pericycle                            ║
║  ├─ Influenced by auxin (IBA, NAA) from cut surface                         ║
║  └─ No visible change externally                                            ║
║                                                                              ║
║  PHASE 2: ROOT INITIATION (Days 3-7)                                         ║
║  ├─ Root primordia (initial root cells) form                                ║
║  ├─ Clusters of dividing cells organize                                     ║
║  ├─ Requires auxin + cytokinins + carbohydrates                             ║
║  ├─ Small bumps may be visible on stem                                      ║
║  └─ Critical period - maintain optimal conditions!                          ║
║                                                                              ║
║  PHASE 3: ROOT DEVELOPMENT (Days 7-14)                                       ║
║  ├─ Root primordia elongate and differentiate                               ║
║  ├─ Roots push through stem tissue                                          ║
║  ├─ White root tips visible (breakthrough)                                  ║
║  ├─ Begin absorbing water and nutrients                                     ║
║  └─ Most critical for humidity management                                   ║
║                                                                              ║
║  PHASE 4: ROOT GROWTH (Days 14-28)                                           ║
║  ├─ Extensive root system develops                                          ║
║  ├─ Lateral roots form                                                      ║
║  ├─ Plant becomes self-sufficient                                           ║
║  ├─ Ready for transplanting                                                 ║
║  └─ Can reduce humidity and increase light                                  ║
║                                                                              ║
║  KEY FACTORS AFFECTING ROOTING:                                              ║
║  ┌────────────────────────────────────────────────────────────────────────┐ ║
║  │                                                                         │ ║
║  │  INTERNAL (Stock Plant Factors)                                        │ ║
║  │  ├─ Age of tissue: Juvenile roots faster than mature                  │ ║
║  │  ├─ Carbohydrate status: Higher = better rooting                      │ ║
║  │  ├─ C:N ratio: Higher C:N favors rooting                              │ ║
║  │  ├─ Endogenous hormones: Natural auxin levels                         │ ║
║  │  └─ Genetic factors: Some varieties root easily, others difficult     │ ║
║  │                                                                         │ ║
║  │  EXTERNAL (Environmental Factors)                                      │ ║
║  │  ├─ Temperature: 70-75°F optimal for most species                     │ ║
║  │  ├─ Humidity: 85-100% prevents desiccation                            │ ║
║  │  ├─ Light: Moderate (500-1500 fc) - not too high                      │ ║
║  │  ├─ Oxygen: Essential at rooting zone                                 │ ║
║  │  └─ Medium: Well-drained, sterile, low fertility                      │ ║
║  │                                                                         │ ║
║  └────────────────────────────────────────────────────────────────────────┘ ║
║                                                                              ║
╚══════════════════════════════════════════════════════════════════════════════╝
```

## 4. Cutting Preparation Techniques

### Step-by-Step Cutting Protocol

```
╔══════════════════════════════════════════════════════════════════════════════╗
║                    STANDARD CUTTING PREPARATION                              ║
╠══════════════════════════════════════════════════════════════════════════════╣
║                                                                              ║
║  STEP 1: STOCK PLANT PREPARATION (1-2 weeks before)                          ║
║  ┌────────────────────────────────────────────────────────────────────────┐ ║
║  │ • Maintain stock plants in optimal health                              │ ║
║  │ • High light to build carbohydrate reserves                            │ ║
║  │ • Moderate nitrogen (avoid excess vegetative growth)                   │ ║
║  │ • Irrigate well 1 day before taking cuttings                           │ ║
║  │ • Take cuttings in early morning (high turgidity)                      │ ║
║  └────────────────────────────────────────────────────────────────────────┘ ║
║                                                                              ║
║  STEP 2: TAKING THE CUTTING                                                  ║
║  ┌────────────────────────────────────────────────────────────────────────┐ ║
║  │                                                                         │ ║
║  │  ┌──────────────────────────────────────────────────────────────────┐ │ ║
║  │  │                    Terminal cutting                               │ │ ║
║  │  │         ╱──── Growing tip (included)                              │ │ ║
║  │  │        │                                                          │ │ ║
║  │  │        │ ████ ← Node (leaf attachment)                           │ │ ║
║  │  │        │      ← Internode                                         │ │ ║
║  │  │        │ ████ ← Node                                              │ │ ║
║  │  │        │                                                          │ │ ║
║  │  │  ┌─────│ ████ ← Node                                              │ │ ║
║  │  │  │     │                                                          │ │ ║
║  │  │  │ CUT │ ████ ← Node (cut 1/4" below)                            │ │ ║
║  │  │  │     │                                                          │ │ ║
║  │  │  └─────┘ ╱ ←── 45° angle cut                                      │ │ ║
║  │  │                                                                    │ │ ║
║  │  └──────────────────────────────────────────────────────────────────┘ │ ║
║  │                                                                         │ ║
║  │ • Use sharp, sterilized blade or pruners                               │ ║
║  │ • Cut at 45° angle just below a node                                   │ ║
║  │ • Length: 3-6 inches (2-4 nodes)                                       │ ║
║  │ • Place immediately in water or damp towel                             │ ║
║  └────────────────────────────────────────────────────────────────────────┘ ║
║                                                                              ║
║  STEP 3: PREPARING THE CUTTING                                               ║
║  ┌────────────────────────────────────────────────────────────────────────┐ ║
║  │                                                                         │ ║
║  │         ╱‾‾╲    ╱‾‾╲  Keep terminal leaves                            │ ║
║  │        │    │  │    │ (reduce by 50% if large)                        │ ║
║  │         ╲__╱    ╲__╱                                                    │ ║
║  │            │  │                                                        │ ║
║  │            ║  ║                                                        │ ║
║  │            ║  ║                                                        │ ║
║  │         ═══╪══╪═══  ← Remove all lower leaves                         │ ║
║  │            ║  ║      (bottom 1-2 nodes)                               │ ║
║  │         ═══╪══╪═══                                                     │ ║
║  │            ║  ║                                                        │ ║
║  │            ▼  ▼                                                        │ ║
║  │          Optional: Wound stem by scraping                             │ ║
║  │          1/2-1" of bark on one or both sides                           │ ║
║  │                                                                         │ ║
║  │ • Remove flowers, flower buds (divert energy to roots)                 │ ║
║  │ • Keep 2-4 leaves at top for photosynthesis                            │ ║
║  │ • Large leaves: cut in half to reduce transpiration                    │ ║
║  │ • Woody stems: wound to expose cambium (optional)                      │ ║
║  └────────────────────────────────────────────────────────────────────────┘ ║
║                                                                              ║
║  STEP 4: HORMONE APPLICATION                                                 ║
║  ┌────────────────────────────────────────────────────────────────────────┐ ║
║  │ • Dip cut end in rooting hormone                                       │ ║
║  │ • Depth: 1/2-1 inch into hormone                                       │ ║
║  │ • Tap to remove excess powder/gel                                      │ ║
║  │ • Don't contaminate main hormone supply                                │ ║
║  │   (use small amount in separate container)                             │ ║
║  └────────────────────────────────────────────────────────────────────────┘ ║
║                                                                              ║
║  STEP 5: STICKING THE CUTTING                                                ║
║  ┌────────────────────────────────────────────────────────────────────────┐ ║
║  │ • Pre-make holes with dibble (don't push cutting in)                  │ ║
║  │ • Insert 1-2 nodes deep                                                │ ║
║  │ • Firm medium gently around stem                                       │ ║
║  │ • Space 1-2 inches apart                                               │ ║
║  │ • Water immediately after sticking                                     │ ║
║  │ • Label with variety, date, lot number                                 │ ║
║  └────────────────────────────────────────────────────────────────────────┘ ║
║                                                                              ║
╚══════════════════════════════════════════════════════════════════════════════╝
```

### Wounding Techniques for Difficult-to-Root Species

| Technique | Method | When to Use | Effect |
|-----------|--------|-------------|--------|
| **Vertical slice** | Remove 1/2-1" strip of bark on one side | Semi-hardwood, hardwood | Exposes cambium, increases hormone uptake |
| **Cross-hatch** | Light cuts in X pattern at base | Woody stems | Increases surface area for rooting |
| **Basal split** | 1/2" vertical cut at base | Very woody cuttings | Opens tissue, retains hormone |
| **Ring** | Remove 1/8" band of bark 1/2" from base | Thick stems | Concentrates auxin above wound |

## 7. Commercial Production Systems

### Direct Sticking vs. Pre-rooting

```
PRODUCTION SYSTEM COMPARISON
════════════════════════════════════════════════════════════════════════════

DIRECT STICK (Cut and stick directly in final container)
┌──────────────────────────────────────────────────────────────────────────┐
│ Process:                                                                 │
│ ├─ Take cutting                                                          │
│ ├─ Treat with hormone                                                    │
│ ├─ Stick in final growing container                                     │
│ └─ Root and grow in same pot                                             │
│                                                                          │
│ Advantages:                                                              │
│ ├─ ✓ Less labor (no transplanting)                                      │
│ ├─ ✓ No transplant shock                                                │
│ ├─ ✓ Better root system (no disturbance)                                │
│ └─ ✓ Faster to market                                                    │
│                                                                          │
│ Disadvantages:                                                           │
│ ├─ ✗ More space required during rooting                                 │
│ ├─ ✗ Higher medium cost                                                 │
│ ├─ ✗ Losses leave empty pots (space waste)                              │
│ └─ ✗ Harder to maintain uniform rooting environment                     │
│                                                                          │
│ Best for: High-value crops, fast-rooting species, limited labor         │
└──────────────────────────────────────────────────────────────────────────┘

PROPAGATION TRAYS → TRANSPLANT
┌──────────────────────────────────────────────────────────────────────────┐
│ Process:                                                                 │
│ ├─ Root cuttings in high-density trays (72-cell, etc.)                  │
│ ├─ Optimal rooting environment (mist, bottom heat)                      │
│ ├─ Transplant rooted cuttings to final containers                       │
│ └─ Grow on to finished size                                              │
│                                                                          │
│ Advantages:                                                              │
│ ├─ ✓ Efficient use of propagation space                                 │
│ ├─ ✓ Better environmental control                                       │
│ ├─ ✓ Cull failures before using containers                              │
│ ├─ ✓ Lower medium cost during rooting                                   │
│ └─ ✓ Can root many more cuttings in same space                          │
│                                                                          │
│ Disadvantages:                                                           │
│ ├─ ✗ Extra labor for transplanting                                      │
│ ├─ ✗ Transplant shock risk                                              │
│ ├─ ✗ Root damage during transplant                                      │
│ └─ ✗ Additional time to market                                          │
│                                                                          │
│ Best for: Large-scale production, moderate-rooting species, space-limited│
└──────────────────────────────────────────────────────────────────────────┘
```

### Production Metrics and Timing

```
EXAMPLE: Basil Cutting Production Timeline

WEEK 0: Stock Plant Harvest
├─ Harvest 1,000 cuttings from stock plants
├─ Prepare and treat cuttings
├─ Stick in 72-cell trays (14 trays)
└─ Place under mist system

WEEK 1: Active Rooting
├─ Mist 5-10 seconds every 15 minutes during day
├─ Bottom heat at 72-75°F
├─ Monitor for disease
└─ Root initiation beginning

WEEK 2: Root Emergence
├─ First roots visible
├─ Reduce misting frequency
├─ Begin light fertilization (50 ppm N)
└─ 80% of cuttings rooted

WEEK 3: Ready for Transplant
├─ Well-rooted (95% success)
├─ Transplant to 4" pots (950 plants)
├─ Move to growing area
└─ 50 culls discarded

WEEK 4-6: Growing On
├─ Standard production practices
├─ Full fertilization program
└─ Ready for sale at 6 weeks from cutting

PRODUCTION COSTS (per 1000 cuttings):
├─ Stock plant maintenance: $50
├─ Labor (cutting, sticking): $80
├─ Rooting supplies (cells, hormone): $30
├─ Utilities (mist, heat): $25
├─ Labor (transplant, growing): $60
├─ Containers and medium (4"): $200
├─ Total cost: $445
├─ Cost per successful plant: $0.47
└─ Selling price at $2.50 = $1,780 margin (80%)
```

## Key Takeaways

1. **Timing and tissue maturity** are critical for rooting success
2. **Stock plant management** determines cutting quality and quantity
3. **Proper preparation** (cutting, wounding, hormone) improves rooting
4. **Environmental control** (humidity, temperature) is essential during rooting
5. **Production system choice** (direct vs. transplant) affects efficiency and cost
6. **Understanding physiology** allows better problem-solving and optimization
