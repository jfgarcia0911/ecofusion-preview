### Seed Component Functions

| Component | Function | Commercial Significance |
|-----------|----------|------------------------|
| **Seed Coat (Testa)** | Protection from pathogens, moisture regulation, dormancy control | Affects germination speed, storage life |
| **Endosperm** | Food storage (proteins, carbs, oils) | Determines seedling vigor |
| **Embryo** | Future plant | Quality determines crop uniformity |
| **Cotyledons** | First leaves, food storage (in some species) | Affects transplant timing |
| **Radicle** | Primary root | First to emerge in germination |
| **Hypocotyl** | Stem between root and cotyledons | Affects seedling establishment |
| **Epicotyl** | Stem above cotyledons | Becomes main shoot |
| **Hilum** | Attachment scar | Water entry point in some species |
| **Micropyle** | Opening in seed coat | Primary water entry point |

## 2. Seed Dormancy Mechanisms

### Types of Dormancy

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        SEED DORMANCY CLASSIFICATION                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. PHYSICAL DORMANCY (PY)                                                  │
│     └─ Hard seed coat prevents water uptake                                │
│        Examples: Legumes, some brassicas                                   │
│        Break: Scarification (mechanical, chemical, hot water)              │
│                                                                             │
│  2. PHYSIOLOGICAL DORMANCY (PD)                                             │
│     └─ Embryo requires after-ripening                                      │
│        Examples: Lettuce, many vegetables                                  │
│        Break: Stratification (cold/warm), light, gibberellic acid          │
│                                                                             │
│  3. MORPHOLOGICAL DORMANCY (MD)                                             │
│     └─ Embryo underdeveloped at seed shed                                  │
│        Examples: Some herbs, native plants                                 │
│        Break: Time, warm stratification                                    │
│                                                                             │
│  4. MORPHO-PHYSIOLOGICAL DORMANCY (MPD)                                     │
│     └─ Combined underdeveloped embryo + physiological block                │
│        Examples: Many perennials                                           │
│        Break: Sequential warm then cold stratification                     │
│                                                                             │
│  5. COMBINATIONAL DORMANCY (PY + PD)                                        │
│     └─ Hard seed coat + physiological dormancy                             │
│        Examples: Some native species                                       │
│        Break: Scarification followed by stratification                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### Breaking Dormancy - Treatment Guide

| Dormancy Type | Treatment Method | Duration | Temperature | Success Rate |
|---------------|------------------|----------|-------------|--------------|
| **Hard Seed Coat** | Mechanical scarification | Minutes | Ambient | 90-95% |
| | Hot water treatment | 5-10 min | 170-212°F | 80-90% |
| | Sulfuric acid | 10-60 min | Ambient | 95%+ |
| **Cold Requirement** | Moist cold stratification | 1-16 weeks | 34-41°F | 85-95% |
| **Warm Requirement** | Warm stratification | 2-12 weeks | 68-86°F | 70-90% |
| **Light Sensitive** | Light exposure during germination | Continuous | 68-77°F | 80-95% |
| **Chemical Inhibitors** | Leaching (water soak) | 12-24 hours | Room temp | 70-85% |

## 3. Seed Quality Testing

### Standard Germination Test Protocol

```
GERMINATION TEST PROCEDURE
════════════════════════════════════════════════════════════════════════════

1. PREPARATION
   ├─ Sample size: 4 replicates of 50-100 seeds each
   ├─ Substrate: Paper towel, blotter, or sand
   ├─ Sterilize substrate and containers
   └─ Label clearly with date, species, lot number

2. SETUP
   ├─ Place seeds uniformly spaced on substrate
   ├─ Maintain optimal moisture (not saturated)
   ├─ Set temperature according to species requirements
   └─ Provide light if required

3. INCUBATION
   ├─ Duration: Species-specific (7-21 days typical)
   ├─ First count: Mid-point (assess vigor)
   ├─ Final count: End of test period
   └─ Monitor moisture and temperature daily

4. EVALUATION
   ├─ Normal seedlings: Complete, healthy structures
   ├─ Abnormal seedlings: Damaged or incomplete
   ├─ Dead seeds: Soft, moldy, no growth
   └─ Fresh ungerminated: Firm, dormant

5. CALCULATION

   Germination % = (Normal Seedlings ÷ Total Seeds) × 100

   Vigor Index = Germination % × Average Seedling Length
```

#### Electrical Conductivity Test

| Test Phase | Time | What It Measures | Interpretation |
|------------|------|------------------|----------------|
| **Seed Soaking** | 24 hours | Ion leakage from membranes | High conductivity = low vigor |
| **Conductivity Reading** | After soaking | μS/cm/g seed | <15 = excellent, 15-25 = good, >25 = poor |
| **Correlation** | - | Relates to field emergence | Strong correlation (r = 0.7-0.9) |

## 4. Seed Longevity and Storage

### Orthodox vs. Recalcitrant Seeds

| Characteristic | Orthodox Seeds | Recalcitrant Seeds |
|----------------|----------------|-------------------|
| **Definition** | Can be dried and frozen | Cannot withstand drying |
| **Moisture Content** | Can be reduced to 5-7% | Must stay >20% |
| **Storage Temp** | Cold (32-50°F) or frozen | Cool (50-60°F), never frozen |
| **Longevity** | Years to decades | Weeks to months |
| **Examples** | Most vegetables, herbs | Tropical fruits, aquatic plants |
| **Commercial Handling** | Standard seed storage | Immediate use or special handling |

### Seed Storage Life Prediction

```
HARRINGTON'S RULES OF SEED STORAGE
════════════════════════════════════════════════════════════════════════════

Rule 1: For every 1% decrease in seed moisture content (5-14% range),
        seed life DOUBLES

Rule 2: For every 10°F decrease in storage temperature (32-100°F range),
        seed life DOUBLES

PRACTICAL APPLICATION:

Example: Lettuce seed at 50°F and 10% moisture = 3 years viability

Improvement options:
├─ Reduce moisture to 8% → 6 years (doubled)
├─ Reduce temperature to 40°F → 6 years (doubled)
└─ Both improvements → 12 years (quadrupled)

FORMULA:
Storage Life = Base Life × 2^((MC₁-MC₂) + ((T₁-T₂)/10))

Where:
MC = Moisture Content (%)
T = Temperature (°F)
Subscript 1 = starting conditions
Subscript 2 = new conditions
```

### Commercial Storage Recommendations

| Seed Type | Moisture Content | Temperature | Relative Humidity | Expected Life |
|-----------|------------------|-------------|-------------------|---------------|
| **Short-term (<1 year)** | 8-10% | 50-60°F | 30-40% | Current season |
| **Medium-term (1-3 years)** | 6-8% | 40-50°F | 25-35% | 2-3 seasons |
| **Long-term (>3 years)** | 4-6% | 32-40°F or frozen | 20-30% | 5-10+ years |
| **Ultra-long (genetic preservation)** | 3-5% | -4°F to -20°F | <25% | 20-50+ years |

## 5. Seed Priming and Enhancement

### Priming Techniques

| Method | Process | Duration | Best For | Benefits |
|--------|---------|----------|----------|----------|
| **Hydropriming** | Soak in pure water | 12-24 hours | Large seeds | Simple, low cost |
| **Osmopriming** | Soak in PEG or salt solution | 1-14 days | Small seeds | Controlled hydration |
| **Solid Matrix Priming** | Mix with vermiculite + water | 3-7 days | All seed types | Easy handling |
| **Biopriming** | Combine with beneficial microbes | 12-24 hours | Disease-prone crops | Disease suppression |
| **Hormopriming** | Soak in hormone solution | 6-24 hours | Difficult germinators | Enhanced germination |

### Seed Purchase Calculations

```
SEED QUANTITY PLANNING FORMULA
════════════════════════════════════════════════════════════════════════════

Seeds to Purchase = (Plants Needed ÷ Germination %) ÷ Expected Success Rate

Where:
├─ Plants Needed: Final transplant requirement
├─ Germination %: From seed test or supplier spec
└─ Expected Success Rate: Accounts for handling losses (typically 0.90-0.95)

EXAMPLE:
Need: 10,000 lettuce transplants
Germination: 90%
Success rate: 92% (account for handling, culling)

Seeds = (10,000 ÷ 0.90) ÷ 0.92
Seeds = 11,111 ÷ 0.92
Seeds = 12,077 seeds needed

Order: 13,000 seeds (add 8% safety margin)

COST ANALYSIS:
├─ Seed cost: $0.08 per seed × 13,000 = $1,040
├─ Cost per successful plant: $1,040 ÷ 10,000 = $0.104
└─ Transplant value: $2.00 each → 95% margin after seed cost
```

## Key Takeaways

1. **Seed anatomy** determines germination behavior and seedling development
2. **Dormancy mechanisms** must be understood and overcome for reliable germination
3. **Quality testing** ensures consistent production and identifies problems early
4. **Proper storage** can extend seed life and reduce costs significantly
5. **Seed treatments** can enhance performance and reduce production risks
6. **Accurate calculations** prevent shortages and minimize waste
