## Maintenance & Reliability KPIs

| KPI | Formula | Target | Frequency |
|-----|---------|--------|-----------|
| **Equipment uptime** | Operating time / Planned time × 100 | >95% | Daily |
| **MTBF** (Mean Time Between Failures) | Operating time / Number of failures | Maximize | Monthly |
| **MTTR** (Mean Time To Repair) | Total repair time / Number of repairs | Minimize | Monthly |
| **PM compliance** | Completed PMs / Scheduled PMs × 100 | 100% | Monthly |
| **Emergency work %** | Emergency hours / Total maint hours × 100 | <10% | Monthly |
| **OEE** (Overall Equipment Effectiveness) | Availability × Performance × Quality | >85% | Daily |

**OEE Calculation:**
```
Availability = Operating time / Planned time
Performance = Actual output / Design capacity
Quality = Good units / Total units
OEE = Availability × Performance × Quality

Example:
Availability: 95% (good uptime)
Performance: 92% (slightly below capacity)
Quality: 96% (few defects)
OEE = 0.95 × 0.92 × 0.96 = 84%
```

## How to Use This Guide

### Setting Targets

1. **Baseline:** Measure current performance for 3-6 months
2. **Benchmark:** Compare to industry standards (this guide)
3. **Set goals:**
   - Short-term (3-6 mo): Close 50% of gap
   - Medium-term (1 yr): Reach "good" performance
   - Long-term (2-3 yr): Approach world-class

### Dashboard Design

**Daily Dashboard (5-7 metrics):**
- Production volume
- Quality (Grade A rate)
- Safety (days without incident)
- Equipment uptime
- On-time delivery

**Weekly Dashboard (10-12 metrics):**
- All daily metrics (trends)
- Labor productivity
- Customer complaints
- Costs vs. budget

**Monthly Dashboard (15-20 metrics):**
- All weekly metrics
- Financial performance
- Improvement projects
- Employee metrics

### Traffic Light System

```
🟢 GREEN: On target or better (maintain)
🟡 YELLOW: 5-10% off target (watch closely)
🔴 RED: >10% off target (immediate action)
```

### Trending

**Track over time:**
- Daily: Spot checks
- Weekly: Short-term trends
- Monthly: Performance patterns
- Quarterly: Strategic review
- Annually: Year-over-year growth

## Quick Reference: Metric Formulas

```
PRODUCTION
Yield = Harvest lbs / Growing sq ft / Time period
Cycles = 365 days / Average crop cycle days

QUALITY
FPY = (Total units - Defects - Rework) / Total units

EFFICIENCY
Productivity = Output / Input (lbs/hour, lbs/kWh, etc.)

MAINTENANCE
Uptime = (Planned time - Downtime) / Planned time
OEE = Availability × Performance × Quality

SAFETY
TRIR = (Total recordable injuries × 200,000) / Total hours

FINANCIAL
Margin % = (Revenue - Costs) / Revenue × 100
Cost/unit = Total costs / Units produced

CUSTOMER
On-time % = On-time deliveries / Total deliveries × 100
```
