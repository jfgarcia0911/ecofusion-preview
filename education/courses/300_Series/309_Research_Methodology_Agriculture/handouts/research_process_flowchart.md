## Decision Points & Common Branches

### After Pilot Study

```
Pilot Results
     │
     ├─► Protocols work well ────► Proceed to main study
     │
     ├─► Minor issues ───────────► Refine and repeat pilot
     │
     └─► Major problems ─────────► Redesign study
```

### After Assumption Checking

```
Assumptions Met?
     │
     ├─► Yes ─────────────► Use planned parametric test
     │
     └─► No
          │
          ├─► Transform data ────► Recheck assumptions
          │
          └─► Use non-parametric alternative
```

### After Statistical Analysis

```
Results
     │
     ├─► Significant ──────────► Interpret, calculate effect size
     │
     └─► Not significant
          │
          ├─► Adequate power? ──YES──► Real null effect
          │
          └─── NO ───────────► Consider larger study
```

### After Manuscript Submission

```
Editor Decision
     │
     ├─► Accept ─────────────────► Publication!
     │
     ├─► Minor revisions ────────► Revise & resubmit
     │
     ├─► Major revisions ────────► Substantial changes needed
     │
     └─► Reject
          │
          ├─► Revise for different journal
          │
          └─► Archive & move on
```

## Critical Success Factors

### Planning Phase
- [ ] Clear, specific research question
- [ ] Comprehensive literature review
- [ ] Testable hypothesis
- [ ] Adequate funding secured
- [ ] All approvals obtained

### Design Phase
- [ ] Appropriate experimental design
- [ ] Sufficient sample size (power analysis)
- [ ] Valid controls included
- [ ] Randomization planned
- [ ] Detailed protocols written

### Execution Phase
- [ ] Protocols followed consistently
- [ ] Quality control maintained
- [ ] Data recorded accurately
- [ ] Problems documented
- [ ] Backups performed regularly

### Analysis Phase
- [ ] Assumptions checked
- [ ] Appropriate tests used
- [ ] Effect sizes calculated
- [ ] Results not cherry-picked
- [ ] Code/scripts documented

### Communication Phase
- [ ] Complete, accurate reporting
- [ ] Limitations acknowledged
- [ ] Proper citations
- [ ] Data available
- [ ] Conflicts disclosed

## Common Pitfalls to Avoid

1. **Inadequate planning** → Flawed design discovered mid-study
2. **Insufficient power** → Missing real effects
3. **Pseudoreplication** → Invalid statistical inference
4. **Poor documentation** → Cannot reproduce methods
5. **P-hacking** → False positives
6. **Selective reporting** → Biased literature
7. **Rushed writing** → Manuscript rejection
8. **Ignoring reviewers** → Rejection on resubmission
