## Short Answer (2 points each)

**7. Explain the difference between systematic error and random error in data collection. Provide an example of each from agricultural research.**

**Example Answer:**

**Systematic Error (Bias):**
- Consistent error in one direction
- Affects accuracy
- Example: A pH meter not properly calibrated reads 0.3 units too high on all measurements

**Random Error:**
- Unpredictable variation in measurements
- Affects precision
- Example: Slight variations in how deeply a ruler is placed in soil when measuring plant height, causing readings to vary ±2mm around true value

**Key difference:** Systematic errors can be corrected through calibration; random errors are reduced through replication and careful technique.

**8. A researcher notices their dissolved oxygen (DO) readings have been gradually decreasing over 3 weeks even though system conditions haven't changed. What is the most likely cause and what should they do?**

**Example Answer:**

**Most likely cause:** Instrument drift - the DO probe membrane has degraded or the sensor has fouled, causing inaccurate (declining) readings despite stable actual DO levels.

**Actions:**
1. Immediately calibrate the DO meter using calibration standards or air-saturated water
2. Clean the DO probe membrane according to manufacturer instructions
3. If calibration doesn't resolve the issue, replace the membrane or probe
4. Compare recent readings to a second calibrated DO meter to verify accuracy
5. Document the issue and note when drift was detected
6. Review calibration schedule - may need more frequent calibration
7. Consider whether to exclude or flag data from the drift period

## Application (2 points each)

**9. Design a quality control procedure for measuring tomato fruit weight in a greenhouse experiment. Include at least 3 specific quality control checks.**

**Example Answer:**

**Quality Control Procedure for Tomato Fruit Weight:**

1. **Daily Scale Calibration:**
   - Calibrate balance each morning using certified calibration weights (100g, 500g)
   - Document calibration in logbook with date, time, and technician initials
   - If calibration fails (>1g deviation), service balance before use

2. **Duplicate Measurements:**
   - For 10% of samples (randomly selected), weigh fruit twice
   - Remove and replace fruit on scale between measurements
   - Calculate coefficient of variation; should be <1%
   - If CV >1%, retrain personnel or service scale

3. **Reference Standard:**
   - Keep a set of reference tomatoes (preserved or artificial)
   - Weigh reference standards weekly
   - Track reference weights on control chart
   - Investigate if reference weight drifts >2g from baseline

4. **Data Entry Verification:**
   - Double-entry for 10% of records by second person
   - Compare entries and calculate error rate
   - If error rate >1%, implement additional checks

5. **Range Checks:**
   - Flag any weights outside expected range (e.g., <10g or >500g for tomatoes)
   - Verify flagged values before accepting

**10. A researcher's data collection form has the following issues: (1) no space for recording time of measurement, (2) unclear abbreviations, (3) no data entry validation, (4) handwriting illegible. For each issue, explain why it's problematic and suggest a solution.**

**Example Answer:**

**Issue 1: No time of measurement**
- **Problem:** Many parameters (pH, DO, temperature) vary throughout the day. Without time stamps, cannot detect diurnal patterns or ensure measurements taken at consistent times, reducing data quality and comparability.
- **Solution:** Add a dedicated "Time" column (HH:MM format, 24-hour) to data sheet. Make it a required field.

**Issue 2: Unclear abbreviations**
- **Problem:** Abbreviations can be misinterpreted (e.g., "T" could mean temperature, time, or treatment), leading to data entry errors or confusion during analysis.
- **Solution:** Create a data dictionary defining all variables and abbreviations. Use standard, unambiguous codes. Include dictionary on data form or reference it clearly.

**Issue 3: No data entry validation**
- **Problem:** Typos or out-of-range values (e.g., pH of 17, negative weights) won't be caught immediately, contaminating dataset and requiring time-consuming cleaning later.
- **Solution:** If using digital forms, implement real-time validation rules (range checks, required fields, format checks). For paper forms, conduct same-day verification by second person and use range checks during entry.

**Issue 4: Illegible handwriting**
- **Problem:** Cannot accurately transcribe data into analysis software, leading to errors, missing data, or wasted time trying to decipher writing.
- **Solution:** (1) Use digital data entry (tablets, smartphones) with structured forms to eliminate handwriting, (2) train personnel on clear printing standards, (3) use pre-printed tick boxes where possible, (4) implement same-day transcription while memory is fresh.
