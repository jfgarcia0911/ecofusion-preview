## Types of Literature Sources

### Source Hierarchy for Agricultural Research

| Source Type | Credibility | Use Case | Example |
|-------------|-------------|----------|---------|
| **Peer-reviewed journal articles** | Highest | Primary research evidence | Journal of Aquaculture, HortScience |
| **Review articles** | High | Comprehensive overviews | Annual Review of Plant Biology |
| **Conference proceedings** | Moderate-High | Recent findings | ISOPONICS Conference papers |
| **Technical reports** | Moderate | Government/industry data | USDA technical bulletins |
| **Theses/Dissertations** | Moderate | Detailed methodologies | University repositories |
| **Books** | Moderate | Foundational knowledge | Aquaponic textbooks |
| **Trade publications** | Low-Moderate | Practical applications | Growing Magazine |
| **Websites/Blogs** | Low | General information | Industry blogs |

### Primary vs. Secondary Sources

**Primary Sources:**
- Original research articles
- First-hand experimental data
- Novel findings and methods

**Secondary Sources:**
- Review articles
- Meta-analyses
- Textbooks summarizing research

**Tertiary Sources:**
- Encyclopedias
- Handbooks
- Databases and indexes

```
┌─────────────────────────────────────────────────────────────────────┐
│                    EFFECTIVE SEARCH PROCESS                         │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  STEP 1: Define Your Topic                                         │
│  ├─ Main concepts                                                  │
│  ├─ Related terms                                                  │
│  └─ Synonyms and variants                                          │
│                                                                     │
│  STEP 2: Identify Keywords                                         │
│  ├─ Core terms: aquaponics, hydroponics, CEA                      │

│                                                                     │
│  STEP 3: Build Search String                                       │
│  └─ Use Boolean operators (AND, OR, NOT)                          │
│                                                                     │
│  STEP 4: Apply Filters                                             │
│  ├─ Date range                                                     │
│  ├─ Publication type                                               │
│  ├─ Language                                                       │
│  └─ Subject area                                                   │
│                                                                     │
│  STEP 5: Review Results                                            │
│  ├─ Scan titles and abstracts                                     │
│  ├─ Check relevance                                               │
│  └─ Save promising articles                                       │
│                                                                     │
│  STEP 6: Refine Search                                             │
│  └─ Broaden or narrow based on results                            │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Boolean Operators

**AND** - Narrows search (both terms must be present)
```
aquaponics AND lettuce
Returns: Articles containing both "aquaponics" and "lettuce"
```

**OR** - Broadens search (either term can be present)
```
aquaponics OR hydroponics
Returns: Articles with either term or both
```

**NOT** - Excludes terms
```
aquaponics NOT recirculating
Returns: Articles about aquaponics excluding "recirculating"
```

**Combining Operators:**
```
(aquaponics OR hydroponics) AND (lettuce OR basil) AND yield
```

### Wildcards and Phrase Searching

**Asterisk (*)** - Truncation
```
nutri*
Finds: nutrient, nutrition, nutritional, nutrients
```

**Question Mark (?)** - Single character
```
wom?n
Finds: woman, women
```

**Quotation Marks (" ")** - Exact phrase
```
"nutrient film technique"
Finds: Exact phrase only
```

### Example Search Strategy

**Research Question:**
"How does water temperature affect tilapia growth in aquaponic systems?"

**Search String:**
```
(aquapon* OR "recirculating aquaculture") AND
(tilapia OR Oreochromis) AND
(temperature OR thermal) AND
(growth OR "growth rate" OR "weight gain")
```

**Filters:**
- Date: 2015-2025
- Language: English
- Document type: Article, Review

## Evaluating Source Quality

### CRAAP Test for Source Evaluation

| Criterion | Questions to Ask | Red Flags |
|-----------|------------------|-----------|
| **Currency** | When was it published? Is it current? | Outdated information for rapidly evolving field |
| **Relevance** | Does it address your question? Appropriate level? | Tangential topic, wrong audience |
| **Authority** | Who is the author? What are their credentials? | Unknown author, no affiliations |
| **Accuracy** | Is it supported by evidence? Can you verify? | No citations, unsupported claims |
| **Purpose** | Why was it written? Is there bias? | Commercial agenda, conflicts of interest |

### Journal Quality Indicators

**Impact Factor (IF):**
- Measures citation frequency
- Higher IF generally indicates more influential journal
- Limitations: Varies by field, can be manipulated

**Journal Rankings:**
- Q1 = Top 25% in field
- Q2 = 25-50%
- Q3 = 50-75%
- Q4 = Bottom 25%

**Peer Review Process:**
- Single-blind (reviewers anonymous)
- Double-blind (both anonymous)
- Open review (all transparent)

### Red Flags in Published Research

| Warning Sign | Implication |
|--------------|-------------|
| No peer review | Not vetted by experts |
| Predatory journal | Pay-to-publish, low standards |
| No conflict of interest statement | Potential bias |
| Missing methodology details | Cannot replicate |
| Cherry-picked data | Selective reporting |
| Extraordinary claims without evidence | Likely unreliable |
| No statistical analysis | Questionable conclusions |

## Reading Scientific Papers Efficiently

### The 3-Pass Approach

**First Pass (5-10 minutes):**
- Read title, abstract, conclusions
- Scan figures and tables
- Check references for relevance
- Decide: Relevant or not?

**Second Pass (30-60 minutes):**
- Read introduction and conclusion carefully
- Look at figures/tables in detail
- Note key points and methods
- Identify main contributions

**Third Pass (1-3 hours):**
- Read entire paper thoroughly
- Understand methodology in depth
- Evaluate assumptions and evidence
- Consider implications and limitations

### Critical Reading Questions

**Introduction:**
- What is the research question?
- Why is this important?
- What is the hypothesis?

**Methods:**
- Is the design appropriate?
- Are controls adequate?
- Is sample size sufficient?
- Can this be replicated?

**Results:**
- Do data support conclusions?
- Are statistics appropriate?
- Are there alternative interpretations?
- What is missing?

**Discussion:**
- How do results compare to literature?
- What are limitations?
- Are conclusions justified?
- What are implications?

## Synthesizing Literature

### From Summary to Synthesis

**Summary (Not Synthesis):**
"Smith (2021) found that pH 6.5 was optimal. Jones (2022) reported best results at pH 6.0. Chen (2023) recommended pH 6.0-6.5."

**Synthesis:**
"Recent research converges on pH 6.0-6.5 as optimal for aquaponic lettuce production (Smith, 2021; Jones, 2022; Chen, 2023). However, optimal pH may vary with water hardness (Smith, 2021) and plant species (Jones, 2022), suggesting the need for system-specific optimization."

### Synthesis Strategies

**1. Chronological Organization**
- Shows development of ideas over time
- Useful for historical context

**2. Thematic Organization**
- Groups by topic or theme
- Most common in literature reviews

**3. Methodological Organization**
- Compares different approaches
- Useful for methods-focused reviews

**4. Theoretical Organization**
- Examines different theoretical frameworks
- Common in conceptual research

## Identifying Research Gaps

### Types of Gaps

```
┌─────────────────────────────────────────────────────────────────────┐
│                        RESEARCH GAPS                                │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  KNOWLEDGE GAP                                                      │
│  └─► Area where little/no research exists                          │
│      Example: Limited data on CBD hemp in aquaponics               │
│                                                                     │
│  METHODOLOGICAL GAP                                                 │
│  └─► Need for different research approach                          │
│      Example: Most studies lab-scale; need commercial data         │
│                                                                     │
│  EMPIRICAL GAP                                                      │
│  └─► Conflicting findings need resolution                          │
│      Example: Disagreement on optimal fish:plant ratios            │
│                                                                     │
│  THEORETICAL GAP                                                    │
│  └─► Existing theories don't explain phenomena                     │
│      Example: Nutrient uptake models don't fit aquaponics          │
│                                                                     │
│  POPULATION GAP                                                     │
│  └─► Under-studied groups or contexts                              │
│      Example: Tropical species in temperate aquaponics             │
│                                                                     │
│  PRACTICAL GAP                                                      │
│  └─► Research hasn't addressed real-world problems                 │
│      Example: Economic viability studies lacking                   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Gap Identification Process

1. **Read broadly** in your topic area
2. **Note limitations** sections in papers
3. **Look for phrases** like:
   - "Future research should..."
   - "More work is needed..."
   - "This remains unclear..."
   - "Little is known about..."
4. **Identify patterns** in what's missing
5. **Consider practical needs** of industry
6. **Check recent reviews** for identified gaps

## Writing the Literature Review

### Structure

**1. Introduction**
- Define scope and purpose
- Explain search strategy
- Outline organization

**2. Body (Thematic Sections)**
- Synthesize findings by theme
- Compare and contrast studies
- Identify patterns and trends
- Note contradictions

**3. Gaps and Conclusions**
- Summarize state of knowledge
- Identify clear gaps
- Justify proposed research

### Writing Tips

**DO:**
- Use your own words (paraphrase)
- Cite properly and consistently
- Compare and synthesize sources
- Maintain critical perspective
- Connect ideas logically
- Identify limitations of existing research

**DON'T:**
- String together quotes
- Simply summarize each paper separately
- Include irrelevant information
- Plagiarize (even accidentally)
- Use biased language
- Cherry-pick only supporting evidence

### Citation Styles

**APA (7th edition) - Most common in agriculture:**
```
In-text: (Smith & Jones, 2022)
Reference: Smith, J., & Jones, A. (2022). Aquaponic nutrient management.
           Journal of Aquaculture, 45(3), 123-145.
```

**Chicago:**
```
Note: Smith and Jones, "Aquaponic Nutrient Management," 125.
```

**Vancouver:**
```
In-text: (1)
Reference: 1. Smith J, Jones A. Aquaponic nutrient management.
              J Aquaculture. 2022;45(3):123-145.
```

## Avoiding Plagiarism

### What Counts as Plagiarism?

| Action | Is it Plagiarism? |
|--------|-------------------|
| Copying text without quotation marks or citation | YES |
| Paraphrasing without citation | YES |
| Using someone's idea without credit | YES |
| Citing incorrectly | Possibly |
| Too-close paraphrasing (even with citation) | YES |
| Reusing your own previous work without disclosure | YES (self-plagiarism) |

### Proper Paraphrasing

**Original:**
"Aquaponic systems demonstrate 90% water savings compared to conventional agriculture while producing both fish and vegetables in a symbiotic relationship."

**Poor Paraphrase (Too Similar):**
Aquaponic systems show 90% water savings versus conventional farming while growing both fish and plants in a symbiotic system.

**Good Paraphrase:**
Recirculating aquaponic systems use substantially less water than traditional farming—approximately one-tenth as much—while simultaneously cultivating aquatic animals and crops through nutrient cycling (Smith, 2022).

## Common Mistakes to Avoid

| Mistake | Impact | Solution |
|---------|--------|----------|
| Too broad search | Information overload | Narrow scope with specific terms |
| Too narrow search | Missing relevant work | Use OR with synonyms |
| Relying only on abstracts | Incomplete understanding | Read full texts of key papers |
| Ignoring older research | Missing foundational work | Include seminal papers |
| Only positive results | Biased perspective | Seek negative and null findings |
| Poor organization | Scattered review | Use themes or framework |
| Insufficient synthesis | List of summaries | Connect ideas across sources |
