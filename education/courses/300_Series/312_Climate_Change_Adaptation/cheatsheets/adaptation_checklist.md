# Climate Adaptation Implementation Checklist

**Course 312: Climate Change Adaptation**

Use this checklist to track your progress implementing climate adaptation measures at your CEA operation.

---

## Phase 1: Assessment & Planning (Months 1-3)

### Climate Risk Assessment
- [ ] Identify top 5 climate hazards for your location
- [ ] Complete vulnerability assessment (exposure, sensitivity, adaptive capacity)
- [ ] Calculate vulnerability scores for each hazard
- [ ] Prioritize risks (>15 priority score)

### Data Gathering
- [ ] Download regional climate projections (2050, 2080) from USDA Climate Hub
- [ ] Review FEMA flood maps for your site
- [ ] Check wildfire risk (if applicable)
- [ ] Access historical weather data (temperature, precipitation extremes)

### Baseline Measurements
- [ ] Measure current water use (gal/day, gal/lb produce)
- [ ] Measure current energy use (kWh/month, kWh/lb produce)
- [ ] Calculate current carbon footprint (kg CO2e/lb produce)
- [ ] Document current crop portfolio
- [ ] List current market channels and % revenue each

### Planning
- [ ] Set 3-5 SMART adaptation goals (specific, measurable, achievable, relevant, time-bound)
- [ ] Develop 5-year implementation timeline
- [ ] Create budget and identify funding sources
- [ ] Write climate adaptation plan (use Module 12 template)

---

## Phase 2: Quick Wins (Months 3-6)

### Monitoring & Alerts
- [ ] Install temperature sensors with alerts (text/email)
- [ ] Install power monitoring (detect outages immediately)
- [ ] Set up weather monitoring (NOAA alerts, apps)
- [ ] If aquaponics: Install DO (dissolved oxygen) monitoring with alerts

### Emergency Protocols
- [ ] Write power outage response protocol
- [ ] Write heat wave response protocol
- [ ] Write flood response protocol (if applicable)
- [ ] Write hurricane/severe storm protocol (if applicable)
- [ ] Conduct staff training on all protocols
- [ ] Run emergency drills (quarterly)

### Operational Improvements
- [ ] Increase crop diversity (add 2-3 new crops)
- [ ] Add one new market channel
- [ ] Cross-train staff (create skill matrix)
- [ ] Build emergency supply kit (flashlights, batteries, first aid, water)

### Financial
- [ ] Open separate account for financial reserves
- [ ] Begin contributing to reach 3-month operating expenses
- [ ] Review and update insurance policies (property, business interruption, flood if needed)

---

## Phase 3: Critical Infrastructure (Year 1)

### Backup Power
- [ ] Size backup generator (calculate critical loads)
- [ ] Purchase and install generator (25-50kW typical)
- [ ] Install automatic transfer switch
- [ ] Secure fuel storage (propane tank or diesel, 72+ hour supply)
- [ ] Test monthly, run under load quarterly
- [ ] Train staff on operation

### Water Security
- [ ] Assess rainwater harvest potential
- [ ] Install rainwater collection system (gutters, tanks, filtration)
- [ ] Size water storage tanks (30-90 days supply)
- [ ] Install condensate recovery system (HVAC)
- [ ] Identify backup water source (well, alternate connection)
- [ ] Install water quality testing protocol

### Structural
- [ ] Inspect structure for wind, snow, flood resistance
- [ ] Identify and address deficiencies (anchoring, glazing, vents)
- [ ] If flood-prone: Elevate critical equipment
- [ ] If hurricane zone: Reinforce connections, install impact-resistant glazing
- [ ] If wildfire risk: Create defensible space, ember-resistant vents

---

## Phase 4: Energy Efficiency & Renewables (Years 1-2)

### Lighting
- [ ] Upgrade to LED (if not already)
- [ ] Optimize light intensity (match crop needs)
- [ ] Install occupancy sensors in work areas
- [ ] Implement dimming or on/off scheduling

### HVAC
- [ ] Seal air leaks
- [ ] Install or upgrade insulation (thermal curtains, double-wall glazing)
- [ ] Upgrade to high-efficiency HVAC (heat pumps if applicable)
- [ ] Optimize ventilation (natural before mechanical)
- [ ] Install shade cloth (retractable for flexibility)

### Solar Energy
- [ ] Conduct energy audit
- [ ] Assess solar potential (roof space, shading, solar resource)
- [ ] Get 3+ quotes for solar PV system
- [ ] Apply for incentives (Federal ITC, USDA REAP, state programs)
- [ ] Install solar PV system
- [ ] Monitor performance (kWh generated, % of needs met)

### Energy Storage (Optional, if economics favorable)
- [ ] Evaluate battery storage (backup + peak shaving)
- [ ] Apply for incentives (SGIP in CA, others)
- [ ] Install battery system if ROI acceptable
- [ ] Program for time-of-use optimization

---

## Phase 5: Advanced Water Systems (Year 2)

### Recirculation Optimization
- [ ] Audit current recirculation rate
- [ ] Identify and fix leaks
- [ ] Optimize system (target 95%+ recirculation)
- [ ] Install flow meters to track precisely

### Rainwater/Alternative Sources
- [ ] Complete rainwater harvest system (if not done)
- [ ] Consider well drilling (if not done, as backup)
- [ ] Integrate greywater for non-food uses (if applicable)
- [ ] Test all water sources for quality

### Drought Preparedness
- [ ] Develop drought response plan (trigger points, actions)
- [ ] Secure water rights or agreements
- [ ] Document water efficiency for regulatory exemptions
- [ ] Build strategic water reserve (fill tanks before dry season)

---

## Phase 6: Operations Optimization (Years 2-3)

### Crop Management
- [ ] Implement seasonal crop rotation (match crops to climate)
- [ ] Test heat-tolerant varieties
- [ ] Increase crop diversity to 8-12 types
- [ ] Optimize planting schedules to avoid worst heat/cold

### Cooling Management
- [ ] Size cooling system for future climate (2050 projections)
- [ ] Install evaporative cooling (if in dry climate)
- [ ] Upgrade AC capacity if needed
- [ ] Implement passive cooling (thermal mass, reflective coatings)

### Heating Management
- [ ] Optimize heating system efficiency
- [ ] Consider heat pumps or geothermal (new builds, retrofits)
- [ ] Maximize passive solar gain
- [ ] Reduce heat loss (insulation, curtains)

### Market Diversification
- [ ] Add 2-3 new sales channels
- [ ] No single channel >30% of revenue
- [ ] Develop institutional customers (schools, hospitals) for stability
- [ ] Explore value-added products

---

## Phase 7: Community & Policy (Ongoing)

### Network Building
- [ ] Join regional grower association
- [ ] Establish mutual aid agreements (backup equipment, emergency support)
- [ ] Participate in knowledge sharing (field days, workshops)
- [ ] Mentor new growers

### Policy Engagement
- [ ] Sign up for USDA local office emails (programs, funding)
- [ ] Monitor state legislation affecting agriculture, climate
- [ ] Participate in public comment periods
- [ ] Meet with local officials (farm tours, education)

### Documentation & Communication
- [ ] Document climate adaptation measures (photos, data)
- [ ] Track and report metrics (water, energy, carbon savings)
- [ ] Share success stories (website, social media, press)
- [ ] Contribute to industry case studies

---

## Phase 8: Continuous Improvement (Annual)

### Monitoring
- [ ] Review monthly energy use (identify anomalies)
- [ ] Review monthly water use
- [ ] Track crop yields by variety and season
- [ ] Monitor market performance by channel

### Annual Review
- [ ] Calculate annual KPIs (water/energy per lb, carbon footprint)
- [ ] Update vulnerability assessment
- [ ] Evaluate adaptation investments (ROI, effectiveness)
- [ ] Adjust adaptation plan based on results

### Looking Forward
- [ ] Review updated climate projections
- [ ] Identify new technologies or practices
- [ ] Plan next year's adaptation priorities
- [ ] Update budget and funding strategy

---

## Completion Milestones

### Year 1 Complete
- [ ] Emergency protocols in place and tested
- [ ] Backup generator operational
- [ ] Basic water storage installed
- [ ] 3-month financial reserve achieved
- [ ] Energy efficiency improvements begun

### Year 2 Complete
- [ ] Solar PV operational (if planned)
- [ ] Water security systems complete
- [ ] Crop diversity 8+ types
- [ ] Market diversity 4+ channels
- [ ] 6-month financial reserve

### Year 3-5 Complete
- [ ] Renewable energy >50% of total
- [ ] 95%+ water recirculation
- [ ] Vulnerability score <25 (low)
- [ ] Climate adaptation plan fully implemented
- [ ] Positioned for resilience through 2050+

---

## Certifications & Recognition (Optional but Valuable)

- [ ] Energy audit completed (USDA REAP requirement)
- [ ] Carbon footprint verified (third-party for credits)
- [ ] Water use certified (document for recognition)
- [ ] USDA Climate-Smart certification (when available)
- [ ] B Corp or sustainability certification
- [ ] Awards or recognition (local, state, industry)
