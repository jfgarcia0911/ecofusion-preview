# Delivery Checklist - Daily Operations

**Course 308:** Supply Chain & Distribution

---

## PRE-DELIVERY (Night Before / Early Morning)

### Planning & Prep
- [ ] Review tomorrow's delivery schedule
- [ ] Verify all orders confirmed
- [ ] Check weather forecast (traffic impacts, temp control needs)
- [ ] Plan route (optimize for time windows, distance)
- [ ] Print delivery manifests and invoices
- [ ] Prepare cash box (if collecting payment)
- [ ] Charge devices (phone, GPS, payment terminal, temp logger)

### Vehicle Preparation
- [ ] Fuel tank filled (>3/4 full recommended)
- [ ] Tire pressure check
- [ ] Lights and signals working
- [ ] Windshield washer fluid filled
- [ ] Emergency supplies on board (jumper cables, flashlight, first aid)
- [ ] Vehicle cleaned and organized
- [ ] Refrigeration unit operational (if equipped)
  - [ ] Pre-cool to target temperature overnight
  - [ ] Verify thermostat setting
  - [ ] Check for unusual noises
- [ ] Ice packs frozen (if using insulated vehicle)

### Load Preparation Area
- [ ] Staging area clean and organized
- [ ] Orders organized by route sequence
- [ ] Temperature sensitive products in cooler until loading
- [ ] Packing materials available (boxes, tape, labels)
- [ ] Hand truck or dolly available (if needed)

---

## LOADING (Morning of Delivery)

### Pre-Load
- [ ] Start vehicle and refrigeration unit (30 min before load)
- [ ] Verify cargo area temperature at target
- [ ] Place temperature data logger in cargo area
- [ ] Open cooler and prep products for loading

### Loading Sequence
- [ ] Load in REVERSE order (last delivery loaded first)
- [ ] Heavy/sturdy items on bottom
- [ ] Delicate items on top or in separate section
- [ ] Products secured (won't shift during transport)
- [ ] Separation between incompatible products
- [ ] Air circulation maintained (don't block vents)
- [ ] Emergency access to first delivery (near door)

### Load Verification
- [ ] Cross-check each order against manifest
  - [ ] Customer name
  - [ ] Product types and quantities
  - [ ] Special instructions noted
- [ ] Invoice/receipt with each order
- [ ] All products labeled with customer name
- [ ] Total load weight within vehicle capacity
- [ ] Temperature logger activated and recording

### Final Pre-Departure
- [ ] Close and secure cargo door
- [ ] Verify refrigeration running
- [ ] All paperwork organized and accessible
- [ ] Phone fully charged
- [ ] Payment terminal ready
- [ ] GPS/navigation app open
- [ ] Cooler back at farm locked/closed
- [ ] Estimated return time communicated to team

## DURING DELIVERY ROUTE

### At Each Stop

#### Arrival (2-3 min)
- [ ] Park safely (not blocking traffic/access)
- [ ] Turn off engine if stop >5 min
- [ ] Grab products for THIS customer only
- [ ] Bring invoice and pen
- [ ] Close cargo door (maintain temperature)

#### Delivery (5-10 min)
- [ ] Greet customer professionally
- [ ] Unload products carefully
- [ ] Verify products with customer
  - [ ] Correct items
  - [ ] Acceptable quality
  - [ ] Quantities match invoice
- [ ] Address any questions or concerns
- [ ] Note any issues on invoice
- [ ] Obtain signature or confirmation
- [ ] Process payment (if applicable)
  - [ ] Cash: Provide receipt, secure cash
  - [ ] Card: Process and provide receipt
  - [ ] Account: Signature for receipt
- [ ] Leave invoice/receipt with customer
- [ ] Thank customer and confirm next delivery date
- [ ] Return to vehicle promptly

#### Departure
- [ ] Secure any returns or rejected items
- [ ] Update delivery status (app/log sheet)
- [ ] Check cargo temperature (visual on logger)
- [ ] Verify next delivery address in GPS
- [ ] Proceed to next stop

### Between Stops
- [ ] Follow planned route (don't deviate without reason)
- [ ] Drive safely (represents farm brand)
- [ ] Monitor cargo temperature if gauge visible
- [ ] Minimize door openings
- [ ] Update farm if delays occur (>15 min behind)
- [ ] Keep cargo door fully closed while driving

### Delivery Issues - Immediate Response
- [ ] **Customer not available:**
  - Call customer
  - Leave note and attempt safe drop (if authorized)
  - Return product to farm (don't leave in heat)
  - Note on manifest

- [ ] **Product quality concern:**
  - Acknowledge professionally
  - Offer replacement if available
  - Note issue for farm follow-up
  - Credit or refund as appropriate

- [ ] **Order discrepancy:**
  - Verify against order records
  - Adjust invoice if error
  - Provide what's available
  - Note shortage for follow-up

- [ ] **Vehicle breakdown:**
  - Safety first (pull over safely)
  - Call farm immediately
  - Arrange product transfer or rental vehicle
  - Notify affected customers

## POST-DELIVERY (Return to Farm)

### Immediate
- [ ] Unload any returns or unsold product
- [ ] Note condition of returns
- [ ] Place returns in cooler immediately
- [ ] Clean cargo area (sweep, remove debris)
- [ ] Remove any trash
- [ ] Turn off refrigeration unit
- [ ] Plug in vehicle (if electric) or note fuel level

### Documentation (Within 30 minutes)
- [ ] Download temperature data logger
- [ ] Verify temperature compliance (no excursions)
- [ ] Complete delivery log
  - [ ] Actual departure time
  - [ ] Arrival time each stop
  - [ ] Total route time
  - [ ] Total miles driven
  - [ ] Any issues or delays
- [ ] Process cash payments
  - [ ] Count and verify
  - [ ] Complete cash log
  - [ ] Deposit or secure
- [ ] File all signed invoices
- [ ] Update customer notes (issues, feedback, etc.)
- [ ] Report any vehicle issues for maintenance

### Reconciliation
- [ ] Compare actual vs. planned route time
- [ ] Calculate cost per delivery (miles, time, fuel)
- [ ] Note any route inefficiencies
- [ ] Customer feedback (positive or negative)
- [ ] Product quality issues reported
- [ ] Suggestions for improvement

### Vehicle Maintenance
- [ ] Inspect for damage
- [ ] Note fuel level (refill if <1/4 tank)
- [ ] Check tire condition
- [ ] Report any warning lights or issues
- [ ] Schedule maintenance if due

### Communication
- [ ] Report delivery completion to management
- [ ] Follow up on any customer issues same-day
- [ ] Coordinate with production on product feedback
- [ ] Schedule next delivery day prep

## WEEKLY TASKS

### Sunday or Monday
- [ ] Review upcoming week's delivery schedule
- [ ] Confirm all orders and delivery windows
- [ ] Optimize routes for the week
- [ ] Check vehicle maintenance schedule
- [ ] Order any needed supplies (ice packs, labels, etc.)

### End of Week
- [ ] Deep clean vehicle cargo area
  - [ ] Sweep and wash floor
  - [ ] Wipe down walls and shelves
  - [ ] Sanitize contact surfaces
  - [ ] Squeegee and air dry
- [ ] Refill emergency supplies
- [ ] Restock paperwork (invoices, receipts)
- [ ] Review week's delivery metrics
  - [ ] On-time delivery rate
  - [ ] Customer satisfaction
  - [ ] Cost per delivery
  - [ ] Miles per delivery
  - [ ] Temperature compliance
- [ ] Prepare report for management

- [ ] Review and update customer database
- [ ] Analyze route efficiency (opportunities to improve)
- [ ] Refresh emergency supplies
- [ ] Deep clean and organize vehicle

## TROUBLESHOOTING QUICK REFERENCE

| Issue | Immediate Action |
|-------|-----------------|
| **Temperature rising** | Check refrigeration unit running, minimize door openings, call farm if exceeds 45°F |
| **Flat tire** | Safety first, pull over, call roadside assistance, alert farm for backup |
| **Customer complaint** | Listen, apologize, offer solution, document, report to farm same-day |
| **Wrong product delivered** | Apologize, exchange if possible, credit if not, document for prevention |
| **Late arrival** | Call customer ASAP, provide realistic ETA, apologize for inconvenience |
| **Vehicle won't start** | Jump battery, call roadside if needed, arrange product transfer immediately |
| **Accident (any severity)** | Safety first, exchange info, document with photos, notify farm and insurance |
