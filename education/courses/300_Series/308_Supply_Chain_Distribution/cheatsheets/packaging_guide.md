## Packaging Decision Tree

```
START: What channel are you serving?

├─ FARMERS MARKET
│  ├─ Premium positioning? → Clear clamshells
│  ├─ Value positioning? → Perforated bags
│  └─ Eco-conscious? → Compostable or reusable
│
├─ RESTAURANT DIRECT
│  ├─ Volume accounts (>25 lbs)? → Reusable bins
│  ├─ Smaller accounts? → Cardboard boxes + bags
│  └─ White tablecloth? → Premium clamshells
│
├─ RETAIL STORES
│  ├─ Always: Consumer-ready packaging
│  ├─ Organic/natural stores? → Compostable preferred
│  └─ Standard grocery? → PET clamshells or bags
│
├─ ONLINE/SHIPPING
│  ├─ Local (<50 mi)? → Reusable totes
│  ├─ Regional (50-200 mi)? → Insulated boxes
│  └─ Long distance (200+ mi)? → Professional shippers
│
└─ WHOLESALE/DISTRIBUTOR
   └─ Bulk cases, industry standard (waxed boxes or RPC)
```

## Labeling Requirements Checklist

### Mandatory (FDA/USDA):
- [ ] Product name/identity
- [ ] Net weight (oz or lbs + grams)
- [ ] Producer name and address
- [ ] Country of origin (if required)

### Recommended:
- [ ] Harvest or pack date
- [ ] Best by date (shelf life)
- [ ] Lot code (traceability)
- [ ] Handling/storage instructions
- [ ] Organic certification logo (if applicable)
- [ ] UPC/PLU barcode (retail)

### Optional but Valuable:
- [ ] Farm story/brand message
- [ ] Recipe suggestions or QR code
- [ ] Social media handles
- [ ] Nutritional information (if space allows)
- [ ] Sustainability certifications

## Sustainable Packaging Options

| Material | Environmental Impact | Cost Premium | Availability | Notes |
|----------|---------------------|--------------|--------------|-------|
| **Recycled PET** | Medium (uses recycled content) | +10-20% | Good | Look similar to virgin PET |
| **PLA (corn-based)** | Low-Medium (bio-based) | +30-50% | Good | Requires commercial composting |
| **Cellulose film** | Low (compostable) | +40-60% | Limited | Home compostable, biodegradable |
| **Molded fiber** | Low (recycled paper) | +20-40% | Good | Egg carton style, less moisture resistant |
| **Reusable plastics** | Lowest (multiple uses) | High initial, -50% long-term | Good | Requires return/wash system |

**Certifications to Look For:**
- BPI Certified Compostable
- ASTM D6400 (composting standard)
- Cedar Grove approved
- FSC (Forest Stewardship Council) for paper
- How2Recycle labels

## Packaging by Budget

### BOOTSTRAP (<$500 initial investment)
- Perforated bags for all products
- Basic labels (laser printer + sticker paper)
- Cardboard boxes (stock sizes)
- **Total cost per unit:** $0.10-0.20
- **Best for:** Start-ups, markets only

### GROWING ($500-2,000 investment)
- Clamshells for premium items
- Bags for volume items
- Custom labels (professional printer)
- Mix of packaging types
- **Total cost per unit:** $0.20-0.40
- **Best for:** Diversifying channels, 1,000-3,000 lbs/week

### ESTABLISHED ($2,000-5,000 investment)
- Full range of packaging types
- Custom printed boxes/clamshells
- Reusable bin system for restaurants
- Professional branding
- **Total cost per unit:** $0.15-0.50 (blended average)
- **Best for:** Multiple channels, 3,000-10,000 lbs/week

### PREMIUM ($5,000+ investment)
- Compostable packaging line
- Custom design and branding
- Multiple packaging lines for differentchannels
- Technology integration (QR codes, NFC tags)
- **Total cost per unit:** $0.30-0.80
- **Best for:** Brand differentiation, 10,000+ lbs/week or high-margin retail

## Packaging Storage & Handling

### Storage Requirements:
- **Environment:** Dry, clean, pest-free
- **Stacking:** Original cartons, organized by type
- **Inventory:** First in, first out (rotate stock)
- **Protection:** Cover to prevent dust

### Order Quantities:
- **Clamshells:** Order 1,000-5,000 minimum (volume discounts)
- **Bags:** Order 5,000-10,000 (low cost per unit)
- **Boxes:** Order 100-500 (bulky, moderate cost)
- **Custom printed:** Higher minimums (2,500-10,000)

### Lead Times:
- **Stock packaging:** 1-7 days
- **Custom printed:** 2-6 weeks
- **Specialty/compostable:** 2-4 weeks

## Common Mistakes to Avoid

1. **Over-packaging:** Adds cost without value
2. **Under-packaging:** Product damage, customer dissatisfaction
3. **Wrong moisture barrier:** Condensation or drying out
4. **No breathing holes:** Ethylene buildup, decay
5. **Unlabeled product:** Non-compliant, confusing
6. **Cheap labels that peel:** Looks unprofessional
7. **Packaging before product is cool:** Condensation, spoilage
8. **Not testing:** Always test new packaging with real product
