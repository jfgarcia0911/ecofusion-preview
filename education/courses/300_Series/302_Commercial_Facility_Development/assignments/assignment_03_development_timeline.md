# Course 302: Commercial Facility Development
## Assignment 03: Development Timeline

**Type:** In-Class Activity | **Duration:** 30-45 min | **Points:** 20

## Objective
Create a realistic development timeline from site acquisition through grand opening.

## Required Phases
1. Planning (site selection, financing)
2. Design (architectural, engineering)
3. Permitting (submissions, approvals)
4. Construction (site prep, building, MEP)
5. Installation (growing systems, equipment)
6. Commissioning (testing, startup)
7. Ramp-up (production, hiring, launch)

## Tasks
1. Estimate duration for each phase (in months)
2. Identify dependencies and critical path
3. Mark key milestones
4. Flag potential delays/risks

## Deliverable
Visual timeline with phases, durations, and milestones clearly marked
