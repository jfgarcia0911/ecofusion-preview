**Learning Objectives:**
- Oversee growing system installation

## 2. Racking System Installation

```
RACKING/BENCH INSTALLATION CHECKLIST

Pre-Installation:
□ Floor clean, level, and cured (concrete)
□ Layout marked on floor
□ All components delivered and inventoried
□ Tools and equipment ready
□ Installation crew trained

Layout:
□ Measure and mark centerlines
□ Verify aisle widths (36" minimum for access)
□ Check for obstructions (columns, utilities)
□ Confirm door swings and equipment clearances
□ Mark anchor locations

Assembly:
□ Follow manufacturer's instructions
□ Assemble in sequence
□ Verify all connections tight
□ Check for square and plumb (±1/4" over 10')
□ Level critical for proper irrigation (±1/8" over 10')

Anchoring:
□ Use specified anchors for floor type
□ Proper embedment depth
□ Torque to specification
□ Lateral bracing where required
□ Seismic restraint (if required by code)

Verification:
□ Measure aisle widths (verify clear)
□ Check level along entire run
□ Verify no wobble or instability
□ Load test if possible
□ Photo documentation

Common Issues:
✗ Not level (irrigation problems, water pooling)
✗ Inadequate anchoring (tip hazard, code violation)
✗ Aisle widths too narrow (access problems)
✗ Racks not square (difficult to integrate lighting, irrigation)
```

## 3. Irrigation System Installation

```
IRRIGATION INSTALLATION CHECKLIST

Main Distribution:
□ Supply lines sized per design
□ Proper support (every 4-6')
□ Unions for service access
□ Valves for zone control
□ Pressure gauges at key points
□ Flow meters (if specified)

Zone Distribution:
□ Zone valves located accessibly
□ Solenoids wired correctly
□ Manifolds level
□ Emitters/drippers at each plant site
□ Drains at low points
□ Air vents at high points

Fertigation System:
□ Injector pumps mounted securely
□ Stock tanks accessible for filling
□ Check valves preventing backflow
□ Proportioning verified (calibration)
□ Mixing chamber adequate
□ Sample ports accessible

Filtration:
□ Filters before sensitive equipment
□ Adequate micron rating (120-200 mesh typical)
□ Easy access for cleaning
□ Pressure gauges before and after (differential = clogging indicator)

Pressure Testing:
□ Test at 1.5× operating pressure
□ Hold for 2 hours minimum
□ No pressure drop indicates no leaks
□ Fix any leaks, retest

Functional Testing:
□ Manual activation of each zone
□ Verify uniform flow
□ Check for leaks during operation
□ Test dosing system accuracy (pH, EC)
□ Verify controller functions

Uniformity Testing:
□ Measure flow at 10+ sample points per zone
□ Calculate uniformity coefficient: UC = (1 - (avg deviation / avg flow)) × 100%
□ Target: UC > 90%
□ If low, check for clogs, pressure issues, poor design

Common Issues:
✗ Leaks (water damage, waste)
✗ Poor uniformity (inconsistent growth)
✗ Clogged emitters (clean filters regularly)
✗ Dosing inaccurate (calibrate injectors)
✗ No drainage (standing water, root problems)
```

## 4. Lighting System Installation

```
GROW LIGHTING INSTALLATION CHECKLIST

Support Structure:
□ Independent of racking (allows flexibility)
□ Adequate strength for light weight + safety factor
□ Anchored to structure or ceiling
□ Allows height adjustment
□ Won't interfere with maintenance

Fixture Installation:
□ Uniform spacing per design
□ Proper height above canopy (12-36" typical)
□ Securely mounted
□ Level orientation (for uniform distribution)
□ Heat sink orientation correct (vertical fins for convection)
□ No obstructions to light distribution

Electrical Connections:
□ Proper circuit assignment (balanced loads)
□ Connections tight and weatherproof
□ Grounding continuous
□ Wire management neat
□ No stress on connections
□ Drivers accessible for service

Control Wiring:
□ Control signal wiring separate from power
□ Shielded cable if needed (reduce interference)
□ Connections labeled
□ Dimming signal verified (0-10V typically)

Testing:
□ Each fixture powers on
□ No flickering or faults
□ Dimming function smooth (0-100%)
□ Timers/controllers function correctly
□ Zoning independent
□ Emergency off accessible

Light Measurement:
□ PAR meter used for verification
□ Measure at canopy height
□ Multiple points per fixture (center, corners, edges)
□ Verify:
  - Average PAR meets spec (±10%)
  - Uniformity acceptable (<15% variation)
  - No dark spots
  - Coverage complete

Common Issues:
✗ Fixtures not level (uneven distribution)
✗ Wrong height (too high = low intensity, too low = hot spots)
✗ Poor uniformity (spacing off, obstructions)
✗ Flickering (loose connections, driver issues)
✗ Circuits overloaded (trips breakers)
```

## 5. Water Treatment Installation

```
WATER TREATMENT SYSTEM SETUP

System Sequence:
Water Source → Sediment Filter → Carbon Filter →
RO System → Storage Tank → Booster Pump →
Irrigation System

Installation:
Sediment Filter:
□ First in sequence (protects downstream)
□ Proper size for flow rate
□ Pressure gauges before/after
□ Drain valve for servicing

Carbon Filter:
□ After sediment, before RO
□ Adequate contact time (flow rate)
□ Pressure gauges
□ Vent valve (release air when filling)

RO System:
□ Pre-filter pressure adequate (40-60 PSI typical)
□ Permeate and waste lines plumbed correctly
□ Waste ratio per spec (check TDS to verify performance)
□ Pressure gauges on all ports
□ Flush valve accessible

Storage Tank:
□ Food-grade material
□ Adequate size (2-4 hours of peak use)
□ Float valve or level control
□ Overflow to drain
□ Clean and sanitized before use
□ Insulated if freeze risk

Booster Pump:
□ Sized for system flow and pressure
□ Variable frequency drive (smooth, efficient)
□ Pressure switch or controller
□ Check valves preventing backflow

Testing:
□ Measure input water TDS, pH
□ Operate system
□ Measure output water TDS (should be <50 ppm), pH
□ Verify flow rate meets design
□ Check waste ratio (3:1 to 5:1 typical)
□ Confirm no leaks
□ Test under continuous operation

Performance Verification:
□ TDS reduction >95% (quality RO)
□ Flow rate adequate for peak irrigation
□ Pressure stable
□ No unusual noises (cavitation, etc.)
□ Waste discharge properly

Common Issues:
✗ Low output flow (fouled membranes, low pressure)
✗ Poor TDS reduction (membranes bad, incorrect plumbing)
✗ Excessive waste (ratio off, fouling)
✗ Tank overflow (float valve stuck)
✗ Low pressure (undersized pump, leaks)
```

## 6. Environmental Sensor Installation

```
SENSOR PLACEMENT & SETUP

Temperature Sensors:
□ Representative locations (not near heat sources)
□ Canopy level (where plants experience temp)
□ Shaded (not in direct light)
□ 3-5 sensors minimum (average readings)
□ Aspirated if possible (active air draw for accuracy)

Humidity Sensors:
□ Co-located with temperature sensors
□ Away from direct air flow (ducts, fans)
□ Calibrated before installation
□ Multiple sensors (verify, average)

CO2 Sensors:
□ Canopy level (where plants uptake CO2)
□ Multiple locations if large space
□ Away from CO2 injection points (avoid local high readings)
□ Calibrated to ambient (400 ppm)

Light Sensors:
□ Plant level
□ Representative location (not shadowed)
□ Shaded from direct sunlight (if greenhouse)
□ Quantum sensor for PAR measurement

Wiring:
□ Neat and protected
□ Labeled at both ends
□ Shielded cable for analog signals (reduce noise)
□ Home-run to controller (star topology preferred)
□ Strain relief at connections

Calibration:
□ Temperature: Ice bath (32°F), boiling water (212°F)
□ Humidity: Calibration salts (33%, 75%)
□ CO2: Outdoor air (400 ppm), known calibration gas
□ pH: Buffer solutions (pH 4, 7, 10)
□ EC: Calibration standards (1413 µS, etc.)

Verification:
□ All sensors reporting
□ Values reasonable
□ Sensors agree (within spec)
□ Response to changes (heat, steam, etc.)
□ Data logging functioning

Common Issues:
✗ Poor placement (not representative)
✗ Not calibrated (inaccurate readings)
✗ Electrical noise (poor shielding, routing near power)
✗ Drift over time (recalibrate regularly)
```

## 8. System Flushing & Cleaning

```
PRE-OPERATIONAL CLEANING

Irrigation System Flush:
Purpose: Remove construction debris, prevent emitter clogging

Process:
1. Flush main lines (remove end caps, high flow)
2. Flush zone lines
3. Install filters
4. Flush to emitters
5. Check for clogs
6. Clean filters
7. Final flush

Duration: Until water runs clear (1-4 hours per zone)

Cleaning Agents (if needed):
□ Chlorine (1-2 ppm) for disinfection
□ Acid (citric or phosphoric) for mineral deposits
□ Rinse thoroughly after treatment

Water Treatment System:
□ Flush sediment and carbon filters (30 min)
□ Flush RO system per manufacturer (may need special procedure)
□ Sanitize storage tank (chlorine solution, rinse)
□ Fill tank with treated water
□ Flush to irrigation system

Growing Surfaces:
□ Wipe down all racking/benches
□ Remove labels, protective films
□ Clean with approved sanitizer
□ Rinse
□ Dry before use

HVAC System:
□ Replace filter media (construction dust)
□ Ductwork blow-out (if accessible)
□ Clean diffusers and grilles

Processing Areas:
□ Clean all surfaces (walls, floors, equipment)
□ Sanitize food contact surfaces
□ Rinse
□ Health department pre-opening inspection
```

## 9. Trial Runs

```
SYSTEM VALIDATION BEFORE CROPS

Environmental Control Trial:
Duration: 72 hours minimum
Monitor:
□ Temperature stability (±2°F of setpoint)
□ Humidity stability (±5% of setpoint)
□ CO2 stability (if enriching)
□ No unexpected shutdowns
□ Alarm functionality

Irrigation Trial:
Duration: 1 week (full irrigation schedule)
Monitor:
□ Pressure stability
□ Uniformity maintained
□ pH and EC control (±0.2 pH, ±10% EC)
□ No leaks develop
□ Timer accuracy

Lighting Trial:
Duration: Full photoperiod cycle (2-3 weeks)
Monitor:
□ Timers accurate
□ No unexpected outages
□ Dimming functions (if used)
□ No failures (fixtures or drivers)
□ Heat load manageable

Integration Trial:
Test: Run all systems simultaneously
Monitor:
□ Electrical load (doesn't exceed capacity)
□ HVAC keeps up with heat load
□ Humidity control adequate
□ No system conflicts
□ Controls responsive

Data Collection:
□ Log all parameters hourly
□ Note any anomalies
□ Analyze trends
□ Identify issues
□ Make adjustments

Issue Resolution:
□ Document all problems
□ Diagnose root causes
□ Implement corrections
□ Retest
□ Verify resolved

Sign-Off:
□ All systems performed acceptably
□ No major issues unresolved
□ Ready for crop production
□ Training complete
□ Documentation provided
```

## Summary

Successful growing system installation requires:

1. **Proper sequencing** - racks, irrigation, lights, controls
2. **Quality installation** - level, square, tight connections
3. **Thorough testing** - pressure, uniformity, controls
4. **System integration** - all systems work together
5. **Cleaning and flushing** - remove debris, prevent clogs
6. **Trial runs** - validate before introducing crops
7. **Staff training** - operators understand systems
8. **Documentation** - as-builts, manuals, SOPs
9. **Supplies ready** - seeds, nutrients, media
10. **Market prepared** - customers ready for harvest

The growing systems are the heart of your operation. Install correctly, test thoroughly, and prepare completely for successful crop production.
