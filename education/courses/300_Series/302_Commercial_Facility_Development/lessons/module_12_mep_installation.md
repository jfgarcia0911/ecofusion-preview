# Module 12: MEP Installation

**Duration:** 1 hour
**Learning Objectives:**
- Oversee mechanical, electrical, and plumbing installation
- Verify proper MEP system integration
- Identify and resolve installation issues
- Ensure code compliance and quality
- Coordinate MEP trades effectively

---

## 1. MEP Installation Sequence

```
INSTALLATION TIMELINE & COORDINATION

Week 1-4: Underground & Rough-In
├─ Underground electrical conduits
├─ Underground plumbing (water, sewer, drains)
├─ Site utilities connections
└─ Foundation penetrations/sleeves

Week 5-10: Overhead Rough-In (Before Ceiling)
├─ HVAC ductwork installation
├─ Electrical conduit and wire pulls
├─ Plumbing supply and drain pipes
├─ Fire sprinkler piping
└─ Low-voltage wiring (controls, data)

Week 11-14: Equipment Setting
├─ HVAC units installed
├─ Electrical panels installed
├─ Plumbing equipment (pumps, tanks)
├─ Fire sprinkler heads and devices
└─ Controls panels and devices

Week 15-18: Finish Work
├─ HVAC grilles, diffusers, thermostats
├─ Electrical devices, fixtures, panels labeled
├─ Plumbing fixtures and trim
├─ Fire alarm devices
└─ Testing and commissioning preparation
```

## 2. Mechanical Installation

### HVAC Installation Checklist

```
MECHANICAL SYSTEM OVERSIGHT

Equipment Placement:
□ Units level and properly supported
□ Vibration isolation installed
□ Clearances for service access (24" minimum)
□ Condensate drain sloped to termination
□ Refrigerant lines insulated (prevent condensation)
□ Electrical disconnect within sight
□ Gas connections leak-tested (if applicable)

Ductwork:
□ Sealed at all seams (mastic or tape, not just screws)
□ Insulated per code (external ductwork in unconditioned spaces)
□ Properly hung and supported (max 10' spacing)
□ No sagging or misalignment
□ Fire dampers installed where required
□ Turning vanes in elbows (for efficiency)
□ Access doors for cleaning

Distribution:
□ Supply diffusers located for good coverage
□ Return grilles adequately sized
□ Balancing dampers accessible
□ No supply/return short-circuiting
□ Uniform air distribution across growing areas

Dehumidification:
□ Adequately sized for latent load
□ Condensate removal functional
□ Controls integrated properly
□ Set points programmable

Common Issues:
✗ Ductwork not sealed (energy waste, humidity problems)
✗ Inadequate return air (system can't work properly)
✗ Poor diffuser placement (hot/cold spots)
✗ Vibration isolation missing (noise, wear)
✗ Condensate drain improper (water damage risk)
```

## 3. Electrical Installation

### Electrical System Verification

```
ELECTRICAL INSTALLATION CHECKLIST

Service & Panels:
□ Service size matches plans and load calculations
□ Main panel labeled and located per plans
□ Sub-panels properly sized and located
□ Panel schedules accurate and posted
□ Proper grounding and bonding
□ Torque connections per spec
□ Arc-fault and GFCI protection where required

Conduit & Wire:
□ Conduit properly supported
□ Wire size matches circuit breaker and load
□ Color coding correct (black/red=hot, white=neutral, green/bare=ground)
□ Proper fill (not overstuffed)
□ No damaged insulation
□ Connections tight
□ Junction boxes accessible

Lighting:
□ Fixtures level and properly mounted
□ Uniform spacing and coverage
□ Proper circuits (not overloaded)
□ Switches/controls in logical locations
□ Emergency lighting functional
□ Exit signs illuminated

Receptacles:
□ Adequate quantity (per code + functional needs)
□ GFCI in wet areas (within 6' of water)
□ Proper height (18" typical, higher near water)
□ Hospital grade in critical areas
□ Labeled circuits (helpful for troubleshooting)

Grow Lighting:
□ Circuits balanced across phases
□ Properly supported (independent of racking)
□ Connections weatherproof (if applicable)
□ Grounding continuous
□ Control wiring correct
□ Timers/contactors properly sized

Testing:
□ Continuity testing
□ Ground fault testing
□ Load testing
□ Panel phasing correct
□ Voltage drop acceptable (<3%)

Common Issues:
✗ Undersized wiring (voltage drop, heat, fire risk)
✗ Poor connections (arcing, failure)
✗ Missing GFCI (code violation, safety)
✗ Overloaded circuits (breaker trips)
✗ Improper grounding (shock hazard)
```

## 4. Plumbing Installation

### Plumbing System Verification

```
PLUMBING INSTALLATION CHECKLIST

Water Supply:
□ Pipe sized per calculations
□ Properly supported (every 6-8' for horizontal)
□ Insulated where freeze risk
□ Pressure tested (100 PSI for 2 hours, no drop)
□ Backflow preventer installed (irrigation, processing)
□ Shutoff valves at equipment
□ Expansion tanks where needed
□ Water hammer arrestors if needed

Drainage:
□ Proper slope (1/4" per foot minimum)
□ Vents properly sized and located
□ Cleanouts accessible
□ Floor drains where needed (processing, mechanical rooms)
□ Trap primers on floor drains
□ No 180-degree bends
□ Properly supported

Irrigation System:
□ Zone valves located per plan
□ Pressure gauges at key points
□ Flow meters (if specified)
□ Filtration before sensitive equipment
□ Drain valves at low points
□ Tested for leaks and pressure

Processing Areas:
□ 3-compartment sink properly connected
□ Handwash sinks (within 25' of food prep)
□ Mop sink with vacuum breaker
□ Floor drains sloped properly
□ Grease trap (if required)

Fixtures:
□ Proper height and alignment
□ Secure mounting
□ No leaks
□ Proper trap installation
□ Hot and cold water to correct sides

Testing:
□ Pressure test (water supply)
□ Drain test (fill all fixtures, drain simultaneously)
□ Backflow preventer test
□ Water quality test (initial flush)

Common Issues:
✗ Inadequate slope (standing water, clogs)
✗ Missing backflow prevention (contamination risk, code violation)
✗ No trap primers (sewer gas enters building)
✗ Undersized pipes (low pressure, slow flow)
✗ Leaks at connections (water damage)
```

## 5. Fire Protection Installation

### Sprinkler System Oversight

```
FIRE SPRINKLER INSTALLATION

System Components:
□ Mains properly sized
□ Branch lines correct spacing
□ Heads correct type and spacing (per NFPA 13)
□ Escutcheons installed (finish rings)
□ Inspector test connection installed
□ Flow alarm installed and connected
□ Tamper switches on control valves
□ Backflow preventer on water supply

Growing Areas:
□ Head spacing adequate for rack height
□ Proper clearance above racks (18" typical)
□ Correct temperature rating (typically 155°F or 165°F)
□ Upright vs. pendant correct
□ Coverage not obstructed by equipment

Hydraulic Testing:
□ Hydrostatic test (200 PSI for 2 hours)
□ No leaks
□ Pressure maintained

Flow Testing:
□ Flow test performed
□ Alarm functions
□ Pressure adequate at most remote head
□ Test report provided

Inspection:
□ Fire marshal inspection passed
□ Test certificates posted
□ Maintenance instructions provided

Common Issues:
✗ Insufficient coverage (heads too far apart)
✗ Obstructed heads (racks too close)
✗ Wrong head types (upright vs. pendant)
✗ Leaking connections (water damage)
✗ System not tested (may not work when needed)
```

## 7. MEP Coordination Issues

### Resolving Conflicts

```
COMMON MEP COORDINATION PROBLEMS

Spatial Conflicts:
Problem: Ductwork interferes with structure
Solution:
- Review plans before installation
- Coordinate routing
- May need to reroute or resize
- Document resolution

Problem: Pipe runs conflict with electrical
Solution:
- Maintain clearances (especially for hot water)
- Cross perpendicularly when possible
- Install sleeves at penetrations

Problem: Equipment doesn't fit in allocated space
Solution:
- Verify dimensions before delivery
- Coordinate access paths
- May need to disassemble for installation

Performance Conflicts:
Problem: HVAC supply diffuser too close to sensor
Solution:
- Relocate sensor to representative location
- Adjust diffuser direction
- Average multiple sensors

Problem: Lighting circuits overloaded
Solution:
- Redistribute fixtures across circuits
- Add circuits if needed
- Verify calculations

Problem: Inadequate water pressure
Solution:
- Check for restrictions (clogged filters, crimped lines)
- Verify sizing adequate
- Add booster pump if needed

Code Conflicts:
Problem: Sprinkler head coverage inadequate
Solution:
- Add heads
- Relocate existing heads
- May need hydraulic recalculation

Problem: Insufficient ventilation
Solution:
- Add exhaust capacity
- Add make-up air
- Rebalance system

Documentation:
□ Document all conflicts discovered
□ Propose solutions
□ Get approval before proceeding
□ Update as-built drawings
□ Communicate to all parties
```

## 8. Testing & Balancing (TAB)

### Commissioning MEP Systems

```
TEST & BALANCE REQUIREMENTS

Air Balance:
Purpose: Ensure proper airflow to all spaces

Process:
1. Measure airflow at all diffusers
2. Compare to design
3. Adjust dampers to balance
4. Verify total system flow
5. Test under all operating modes

Report Should Include:
□ Design airflow vs. actual
□ Static pressures
□ Equipment performance
□ Damper positions
□ Recommendations

Water Balance:
Purpose: Ensure proper water flow in hydronic systems (if applicable)

Process:
1. Measure flow rates
2. Adjust balancing valves
3. Verify pump performance
4. Check pressures

Electrical Testing:
□ Voltage at all panels
□ Current draw on all circuits
□ Power factor
□ Ground resistance
□ Load balance across phases
□ Harmonics (if concern)

Irrigation Testing:
□ Pressure at each zone
□ Flow at sample emitters
□ Uniformity coefficient (>90% target)
□ pH and EC dosing accuracy (±5%)

Functional Performance Testing:
Purpose: Verify systems respond correctly

Tests:
□ Setpoint response (does system maintain setpoint?)
□ Dead band (how much variation before response?)
□ Recovery time (how fast does it correct?)
□ Stability (does it oscillate or settle?)

Acceptance Criteria:
□ Airflow within 10% of design
□ Water flow within 5% of design
□ Electrical voltage within 5% of nominal
□ Irrigation uniformity >90%
□ Environmental control within setpoints

If Failed:
- Identify deficiencies
- Require corrections
- Retest after corrections
- Do not accept until passing
```

## 9. As-Built Documentation

### Documenting Installed Conditions

```
AS-BUILT DRAWING REQUIREMENTS

Red-Lining Process:
During construction:
□ GC marks changes on drawings (red pencil/pen)
□ Notes relocations, size changes, additions, deletions
□ Superintendent maintains set

After construction:
□ GC provides red-lined drawings to architect
□ Architect prepares formal as-built CAD drawings
□ Owner receives final as-builts

Critical As-Built Information:
Electrical:
□ Panel locations and schedules
□ Circuit routing (especially concealed)
□ Splice locations
□ Device locations (especially if concealed)

Mechanical:
□ Ductwork routing
□ Equipment locations
□ Damper locations
□ Sensor locations

Plumbing:
□ Pipe routing (especially underground)
□ Valve locations
□ Cleanout locations
□ Drain locations

Controls:
□ Sensor locations and wiring
□ Controller locations
□ Network topology
□ IP addresses

As-Built Deliverables:
□ Full set of CAD drawings (PDF and native format)
□ O&M manuals for all equipment
□ Warranties
□ Test reports (TAB, commissioning, etc.)
□ Submittals (approved product data)
□ Attic stock (spare parts, extra materials)
□ Training documentation
□ Control sequences and set points

Use of As-Builts:
- Troubleshooting (find components)
- Maintenance (access points)
- Modifications (avoid existing systems)
- Emergency response (shutoffs, isolations)
- Future expansions (capacity available)
```

## Summary

Successful MEP installation requires:

1. **Proper sequencing** - coordinate trades effectively
2. **Quality installation** - follow manufacturer instructions
3. **Code compliance** - verify all requirements met
4. **System integration** - ensure interoperability
5. **Thorough testing** - functional performance verification
6. **Balancing** - optimize system performance
7. **As-built documentation** - capture installed conditions
8. **Commissioning** - prove systems work as intended
9. **Training** - operators understand systems
10. **Acceptance** - formal sign-off when complete

MEP systems are the backbone of your facility. Invest in quality installation and thorough commissioning for reliable, efficient operations.
