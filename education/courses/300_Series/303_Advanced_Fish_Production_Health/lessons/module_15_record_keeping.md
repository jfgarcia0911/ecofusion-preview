## 4. Key Performance Indicators

### Production KPIs

```
KPI DASHBOARD (Monthly)

GROWTH PERFORMANCE:
  □ Specific Growth Rate (SGR): _______ %/day
    Target: _______  Status: □ ✓  □ ✗

  □ Feed Conversion Ratio (FCR): _______
    Target: _______  Status: □ ✓  □ ✗

  □ Average Daily Gain (ADG): _______ g/day
    Target: _______  Status: □ ✓  □ ✗

SURVIVAL:
  □ Monthly Survival: _______ %
    Target: >98%  Status: □ ✓  □ ✗

  □ Cumulative Survival: _______ %
    Target: >90%  Status: □ ✓  □ ✗

PRODUCTION EFFICIENCY:
  □ Biomass Gain: _______ kg
  □ Feed Used: _______ kg
  □ Production per m³: _______ kg/m³
  □ Production per m³/year: _______ kg/m³/yr

ECONOMIC:
  □ Feed Cost per kg Gain: $______
    Target: $_______  Status: □ ✓  □ ✗

  □ Revenue: $_______
  □ Operating Costs: $_______
  □ Gross Margin: $_______  (______ %)


KPI CALCULATION FORMULAS:

SGR (%/day) = ((ln(Wf) - ln(Wi)) / days) × 100

FCR = Total Feed (kg) / Weight Gain (kg)

Survival (%) = (Final Count / Initial Count) × 100

Cost/kg = (Feed Cost × FCR) + Other Variable Costs

Production/m³/yr = Annual Harvest (kg) / Volume (m³)
```

## 6. Data Analysis

### Trend Analysis

```
PERFORMANCE TRENDING

Track over time to identify patterns:

EXAMPLE: FCR Trend Analysis

Batch │ FCR  │ Temp(avg) │ DO(avg) │ Mortality│ Notes
──────┼──────┼───────────┼─────────┼──────────┼──────
  1   │ 1.8  │   24°C    │ 6.2mg/L │   15%    │ Hot
  2   │ 1.6  │   27°C    │ 7.1mg/L │   8%     │ Improved DO
  3   │ 1.5  │   27°C    │ 7.5mg/L │   5%     │ Better
  4   │ 1.4  │   28°C    │ 7.8mg/L │   4%     │ Optimal
  5   │ 1.7  │   29°C    │ 7.2mg/L │   12%    │ Too hot

INSIGHTS:
  • Optimal temperature: 27-28°C
  • DO >7.5 mg/L correlates with better FCR
  • High mortality impacts FCR
  • Target: Maintain 27-28°C, DO >7.5


GRAPHICAL ANALYSIS:

  Plot over time:
    - FCR trend
    - Survival rate
    - Growth rate
    - Water quality parameters

  Look for:
    - Seasonal patterns
    - Correlation between variables
    - Improvement over time
    - Problem identification
```

## 7. Regulatory Compliance

### Required Documentation

```
REGULATORY RECORD REQUIREMENTS

FOOD SAFETY:
  □ Water quality test results
  □ Treatment/chemical use logs (with withdrawal)
  □ Feed lot numbers and usage
  □ Harvest records (traceability)
  □ Processing/handling records
  □ Temperature logs (cold chain)

ENVIRONMENTAL:
  □ Water discharge permits
  □ Effluent quality testing
  □ Water usage records
  □ Waste disposal logs

HEALTH/DISEASE:
  □ Mortality records
  □ Disease investigation reports
  □ Laboratory test results
  □ Veterinary prescriptions
  □ Reportable disease notifications

BUSINESS:
  □ Sales records
  □ Purchase receipts
  □ Production reports
  □ Employee records
  □ Insurance documents


RETENTION PERIODS:

  Food Safety: 2-3 years minimum
  Financial: 7 years (IRS requirement)
  Health: 2 years
  Environmental: Per permit (often 3-5 years)

  Best Practice: Keep all records 5-7 years
```

```

  Pros:

    ✓ Complete control

  Cons:
    ✗ Development cost

  • Cloud storage → Backup and access
```

## 9. Continuous Improvement

### Data-Driven Decision Making

```
IMPROVEMENT CYCLE

1. COLLECT DATA
   ↓
2. ANALYZE TRENDS
   ↓
3. IDENTIFY PROBLEMS/OPPORTUNITIES
   ↓
4. DEVELOP SOLUTIONS
   ↓
5. IMPLEMENT CHANGES
   ↓
6. MONITOR RESULTS
   ↓
(Return to step 1)


EXAMPLE CASE:

Problem Identified: FCR increasing (1.4 → 1.7)

Data Review:
  - Feed consumption normal
  - Growth rate declining
  - DO levels variable (5.5-7.5 mg/L)
  - Temperature stable

Hypothesis: Low DO limiting growth

Action:
  - Increase aeration capacity
  - Maintain DO >7 mg/L

Results (next batch):
  - FCR improved to 1.5
  - Growth rate increased
  - Problem resolved

Learning: DO management critical to FCR
```

## 10. Record-Keeping Best Practices

### Standard Practices

```
RECORD-KEEPING EXCELLENCE

ACCURACY:
  ✓ Record immediately (don't rely on memory)
  ✓ Use calibrated equipment
  ✓ Double-check calculations
  ✓ Cross-reference data

COMPLETENESS:
  ✓ Fill all fields
  ✓ Note absences (write "NA" not leave blank)
  ✓ Include context/notes
  ✓ Document deviations

CONSISTENCY:
  ✓ Use standard forms
  ✓ Same units throughout
  ✓ Standardized abbreviations
  ✓ Consistent timing

ACCESSIBILITY:
  ✓ Organized filing system
  ✓ Easy to retrieve
  ✓ Backed up (digital and/or physical)
  ✓ Secure but available

AUDIT TRAIL:
  ✓ Date and time stamps
  ✓ Observer/recorder name
  ✓ Changes documented (not erased)
  ✓ Version control


COMMON MISTAKES TO AVOID:

  ✗ Incomplete entries
  ✗ Illegible handwriting
  ✗ Delayed recording (memory errors)
  ✗ No backup copies
  ✗ Inconsistent units
  ✗ Missing dates
  ✗ Overwriting errors (should strikethrough)
  ✗ No verification/review
```
