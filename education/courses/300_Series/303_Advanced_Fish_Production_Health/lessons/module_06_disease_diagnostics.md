## 1. Fish Health Examination Protocol

### Visual Observation (Tank-side Assessment)

```
BEHAVIOR ASSESSMENT CHECKLIST

Normal Behavior:
  ✓ Active swimming
  ✓ Schooling (if species appropriate)
  ✓ Responsive to feed
  ✓ Even distribution in tank
  ✓ Regular gill movement
  ✓ Horizontal body position

Abnormal Behavior (Red Flags):
  ✗ Lethargy, hanging at surface
  ✗ Erratic swimming, spinning
  ✗ Isolation from group
  ✗ Gasping at surface (piping)
  ✗ Rapid gill movement
  ✗ Rubbing against surfaces (flashing)
  ✗ Loss of equilibrium
  ✗ Bottom sitting
```

### External Examination

```
HEAD-TO-TAIL EXAMINATION

    HEAD REGION
    ├─ Eyes: Clarity, position, hemorrhage
    ├─ Mouth: Lesions, deformities, color
    ├─ Gills: Color, mucus, parasites
    └─ Opercula: Flaring, erosion

    BODY
    ├─ Skin: Color, scales, lesions, ulcers
    ├─ Mucus: Amount, color, consistency
    ├─ Fins: Erosion, hemorrhage, rot
    └─ Anus: Inflammation, prolapse

    ABDOMEN
    ├─ Distension: Bloating, swelling
    ├─ Palpation: Firmness, abnormalities
    └─ Scales: Lifting, roughness


BODY CONDITION SCORING

Score │ Description │ Visual Cues
──────┼─────────────┼──────────────────────────────
  5   │ Obese       │ Rounded, thick back
  4   │ Good        │ Slightly rounded, healthy
  3   │ Normal      │ Streamlined, proportionate
  2   │ Thin        │ Slight head prominence
  1   │ Emaciated   │ Sunken belly, head very large

Target: Score 3-4 for market fish
```

## 2. Necropsy (Post-Mortem Examination)

### Necropsy Setup

**Required Equipment:**
```
NECROPSY KIT

Instruments:
  □ Dissection scissors (2 pairs)
  □ Forceps (fine and coarse)
  □ Scalpel with blades
  □ Ruler (metric)
  □ Probes
  □ Petri dishes
  □ Microscope slides & coverslips

Solutions:
  □ 10% buffered formalin
  □ 70% ethanol
  □ Saline (0.9% NaCl)
  □ Sterile water

Documentation:
  □ Camera
  □ Data sheets
  □ Labels
  □ Permanent markers
  □ Notebook
```

### Internal Examination Protocol

```
NECROPSY PROCEDURE

1. EXTERNAL PHOTOS
   - Dorsal, ventral, lateral views
   - Close-ups of lesions

2. WEIGHT & MEASURE
   - Total length
   - Body weight
   - Record condition

3. GILL EXAMINATION
   - Clip gill arch
   - Mount in saline
   - Observe under microscope
   - Look for parasites, bacteria

4. BODY CAVITY
   - Lateral incision from anus to gills
   - Reflect body wall
   - Note: fluid, gas, adhesions

5. ORGAN EXAMINATION

   Liver:
   ├─ Color (normal: dark red-brown)
   ├─ Texture (firm, not friable)
   ├─ Size (normal or enlarged)
   └─ Lesions (spots, nodules)

   Spleen:
   ├─ Size (normal: small, dark)
   ├─ Color (dark red)
   └─ Enlargement indicates infection

   Kidney:
   ├─ Color (dark red)
   ├─ Swelling
   └─ Bacterial swab if indicated

   Intestine:
   ├─ Contents (feed, mucus, parasites)
   ├─ Inflammation
   └─ Color changes

   Swim Bladder:
   ├─ Inflation
   ├─ Lesions
   └─ Parasites

6. SAMPLE COLLECTION
   - Fresh for bacteriology
   - Formalin-fixed for histology
   - Frozen for virology (if suspected)
```

## 3. Microscopic Examination

### Wet Mount Preparations

**Gill Examination:**
```
GILL WET MOUNT PROCEDURE

1. Remove gill arch with scissors
2. Place in Petri dish with saline
3. Separate filaments gently
4. Transfer to microscope slide
5. Add drop of saline
6. Apply coverslip
7. Examine at 40-400× magnification

Look For:
  • Ectoparasites:
    - Ichthyophthirius (Ich) - large, ciliated
    - Trichodina - disc-shaped, ciliated
    - Ichthyobodo (Costia) - small, flagellated
    - Dactylogyrus - monogenean flukes

  • Bacterial colonies
  • Fungal hyphae
  • Tissue damage
  • Mucus hyperplasia
```

**Skin Scraping:**
```
SKIN SCRAPE TECHNIQUE

1. Scrape lateral line area with scalpel
2. Mix scrapings with saline on slide
3. Add coverslip
4. Examine at 100-400× magnification

Organisms to Identify:
  - Trichodina (disc with denticles)
  - Epistylis (colonial, stalked)
  - Ichthyobodo (small, kidney-shaped)
  - Chilodonella (oval, ciliated)
```

## 4. Bacterial Diagnostics

### Sample Collection for Bacteriology

```
STERILE SAMPLING TECHNIQUE

Kidney Sample (Primary site):
1. Surface sterilize fish with 70% alcohol
2. Flame sterilize instruments
3. Make aseptic incision
4. Use sterile loop/swab
5. Swab anterior kidney
6. Streak on TSA (Tryptic Soy Agar)
7. Incubate 25-28°C for 48 hours

Brain Sample (for some diseases):
1. Remove head
2. Split skull aseptically
3. Swab brain tissue
4. Plate on appropriate media

Lesion Sample:
1. Sterilize surface
2. Excise tissue aseptically
3. Homogenize if needed
4. Plate on selective media
```

### Culture Media Selection

| Medium | Target Organisms | Incubation |
|--------|-----------------|------------|
| **TSA (Tryptic Soy Agar)** | General bacteria | 25-28°C, 48h |
| **BHIA (Brain Heart Infusion)** | Fastidious bacteria | 28-30°C, 48-72h |
| **Cytophaga Medium** | Flexibacter/Flavobacterium | 20-25°C, 72h |
| **TCBS** | Vibrio spp. | 30°C, 24h |
| **Anacker-Ordal** | Coldwater disease | 15°C, 7-10d |

### Gram Staining Protocol

```
GRAM STAIN PROCEDURE

1. Heat-fix bacterial smear
2. Flood with Crystal Violet (1 min)
3. Rinse with water
4. Flood with Gram's Iodine (1 min)
5. Rinse with water
6. Decolorize with 95% alcohol (10-20 sec)
7. Rinse immediately
8. Counterstain with Safranin (30 sec)
9. Rinse and air dry
10. Examine under oil immersion (1000×)

Results:
  Gram-positive: Purple/blue
  Gram-negative: Pink/red


Common Fish Pathogens:
  Gram-negative:
    • Aeromonas (rods)
    • Flavobacterium (rods)
    • Vibrio (curved rods)
    • Edwardsiella (rods)

  Gram-positive:
    • Streptococcus (cocci in chains)
    • Mycobacterium (acid-fast rods)
```

## 5. Molecular Diagnostics

### PCR (Polymerase Chain Reaction)

```
PCR TESTING WORKFLOW

Sample Collection
       ↓
DNA/RNA Extraction
       ↓
PCR Amplification
       ↓
Gel Electrophoresis
       ↓
Result Interpretation


Applications:
  ✓ Viral detection (ISAV, KHV, SVCV)
  ✓ Bacterial identification
  ✓ Parasite species confirmation
  ✓ Genetic screening

Advantages:
  • High sensitivity
  • Fast results (4-6 hours)
  • Species-specific
  • Detects subclinical infections

Disadvantages:
  • Expensive equipment
  • Requires expertise
  • Can't distinguish live/dead pathogens
```

### ELISA (Enzyme-Linked Immunosorbent Assay)

```
ELISA APPLICATIONS

Test Types:
  1. Antibody Detection (serology)
     - Determines exposure history
     - Monitors vaccination response

  2. Antigen Detection
     - Identifies active infection
     - Pathogen-specific

Common Fish ELISA Kits:
  • Aeromonas salmonicida
  • Yersinia ruckeri
  • Renibacterium salmoninarum (BKD)
  • IHN virus
  • VHS virus


Procedure:
  Sample → Extraction → ELISA Plate → Incubation →
  Wash → Add Substrate → Read Color → Result

Time: 2-4 hours
Sensitivity: High (pg/mL range)
```

## 6. Water Quality Diagnostics

### Chemical Parameters

```
WATER QUALITY TESTING PRIORITY

CRITICAL DAILY:
  □ Dissolved Oxygen (DO)
  □ Temperature
  □ pH

IMPORTANT (2-3×/week):
  □ Ammonia (NH₃/NH₄⁺)
  □ Nitrite (NO₂⁻)
  □ Nitrate (NO₃⁻)

WEEKLY:
  □ Alkalinity
  □ Hardness
  □ Carbon dioxide (CO₂)

MONTHLY:
  □ Phosphate
  □ Calcium
  □ Magnesium
  □ Iron
```

### Disease-Water Quality Correlations

| Disease Risk | Water Quality Trigger | Mechanism |
|--------------|----------------------|-----------|
| **Columnaris** | High temperature (>25°C) + low DO | Stress + pathogen growth |
| **Ich** | Temperature fluctuation | Stress weakens immunity |
| **Bacterial Gill Disease** | High ammonia + organics | Gill damage + bacteria |
| **Aeromonas** | Poor quality + stress | Opportunistic infection |
| **Saprolegnia** | Injury + organics | Fungal growth on wounds |

## 7. Histopathology

### Tissue Fixation and Processing

```
HISTOLOGY SAMPLE COLLECTION

Fixation Protocol:
1. Collect tissue samples <5mm thick
2. Place immediately in 10% buffered formalin
3. Use 10× volume of formalin to tissue
4. Fix for 24-48 hours minimum

Tissues to Collect:
  □ Gill (complete arch)
  □ Liver (2-3 sections)
  □ Kidney (anterior and posterior)
  □ Spleen
  □ Heart
  □ Intestine (2-3 sections)
  □ Brain (if neurological signs)
  □ Lesions (with normal tissue margin)


Processing Steps:
  Formalin → Dehydration (alcohols) →
  Clearing (xylene) → Embedding (paraffin) →
  Sectioning (5μm) → Staining (H&E) →
  Mounting → Microscopy
```

### Common Histological Findings

```
TISSUE CHANGES

INFLAMMATORY:
  • Lymphocyte infiltration
  • Macrophage aggregation
  • Necrosis
  • Granuloma formation

DEGENERATIVE:
  • Hepatic steatosis (fatty liver)
  • Cellular swelling
  • Necrosis
  • Atrophy

PROLIFERATIVE:
  • Hyperplasia (increased cells)
  • Hypertrophy (enlarged cells)
  • Neoplasia (tumors)

PARASITIC:
  • Cyst formation
  • Parasite identification
  • Surrounding inflammation
```

## 8. Differential Diagnosis

### Diagnostic Decision Trees

```
LESION-BASED DIAGNOSIS

WHITE SPOTS ON SKIN/FINS
    │
    ├─ Large (0.5-1mm), raised → ICH
    │   └─ Confirm: Wet mount, see trophont
    │
    ├─ Small, flat, white patches → COLUMNARIS
    │   └─ Confirm: Gram stain, long thin rods
    │
    └─ Cottony growth → SAPROLEGNIA (fungus)
        └─ Confirm: Wet mount, see hyphae


HEMORRHAGIC LESIONS
    │
    ├─ Widespread petechiae → SEPTICEMIA
    │   ├─ Motile aeromonas (MAS)
    │   ├─ Streptococcus
    │   └─ Vibrio
    │   └─ Confirm: Bacterial culture
    │
    ├─ Localized ulcers → AEROMONAS/INJURY
    │   └─ Confirm: Culture, rule out EUS
    │
    └─ Internal hemorrhage → VIRAL (possibly)
        └─ Confirm: PCR, histology


RESPIRATORY DISTRESS
    │
    ├─ Gills pale → ANEMIA
    │   ├─ Blood parasites
    │   └─ Nutritional deficiency
    │
    ├─ Gills dark/swollen → BACTERIAL GILL DISEASE
    │   └─ Confirm: Wet mount, Gram stain
    │
    └─ Gill parasites visible → PARASITIC
        └─ Confirm: Wet mount identification
```

### Clinical Sign Matrix

```
DIAGNOSTIC MATRIX

Sign/Symptom         │ Likely Causes
─────────────────────┼──────────────────────────────────
Exophthalmia         │ Streptococcus, gas bubble disease,
(pop-eye)            │ poor water quality
─────────────────────┼──────────────────────────────────
Ascites              │ Bacterial infection, kidney failure,
(swollen abdomen)    │ viral disease
─────────────────────┼──────────────────────────────────
Erratic swimming     │ Viral (neurological), parasites,
                     │ water quality (ammonia, TGP)
─────────────────────┼──────────────────────────────────
Loss of appetite     │ ANY disease, stress, poor water
                     │ quality - non-specific sign
─────────────────────┼──────────────────────────────────
Fin/tail rot         │ Columnaris, Aeromonas, poor water
                     │ quality, stress
─────────────────────┼──────────────────────────────────
Skin darkening       │ Stress, chronic disease, poor
                     │ water quality
─────────────────────┼──────────────────────────────────
Flashing/rubbing     │ External parasites (Ich, Trichodina,
                     │ Ichthyobodo), water quality
```

## 10. Diagnostic Algorithm

### Systematic Approach

```
STEP-BY-STEP DIAGNOSTIC PROTOCOL

STEP 1: COLLECT INFORMATION
  ✓ Mortality pattern (acute vs chronic)
  ✓ Affected age/size class
  ✓ Recent changes (feed, temperature, etc.)
  ✓ Water quality trends
  ✓ Previous health issues

STEP 2: OBSERVE POPULATION
  ✓ Behavior abnormalities
  ✓ Distribution in tank
  ✓ Feeding response
  ✓ Prevalence of signs

STEP 3: EXAMINE INDIVIDUALS
  ✓ External examination (5-10 fish)
  ✓ Fresh dead fish (<2 hours)
  ✓ Moribund fish (best for diagnosis)

STEP 4: PERFORM DIAGNOSTICS
  Priority 1 (Quick, cheap):
    □ Water quality tests
    □ Wet mounts (gills, skin)
    □ External exam

  Priority 2 (If indicated):
    □ Necropsy
    □ Bacterial culture
    □ Gram stains

  Priority 3 (Advanced):
    □ Histopathology
    □ PCR
    □ ELISA

STEP 5: INTERPRET RESULTS
  ✓ Correlate all findings
  ✓ Rule out non-infectious causes
  ✓ Consider mixed infections
  ✓ Assess significance of findings

STEP 6: FORMULATE DIAGNOSIS
  Confirmed: Lab test positive
  Presumptive: Clinical signs + compatible findings
  Differential: Multiple possibilities

STEP 7: TREATMENT/MANAGEMENT
  ✓ Address water quality
  ✓ Specific treatment if available
  ✓ Supportive care
  ✓ Biosecurity measures

STEP 8: MONITOR AND ADJUST
  ✓ Track mortality
  ✓ Reassess in 24-48 hours
  ✓ Modify treatment if needed
  ✓ Document outcomes
```

## Summary

Effective disease diagnostics require:

1. **Systematic examination** - Follow protocols consistently
2. **Multiple methods** - Combine clinical, microscopic, and lab tests
3. **Proper sampling** - Collect and preserve correctly
4. **Record keeping** - Document all findings
5. **Differential diagnosis** - Consider multiple possibilities
6. **Laboratory support** - Know when to submit samples

Diagnostic Tools:
- Visual observation and behavior monitoring
- Necropsy and organ examination
- Microscopy for parasites
- Bacterial culture and Gram staining
- Molecular methods (PCR, ELISA)
- Histopathology for confirmation

---

## Key Takeaways

1. **Early detection** improves treatment success
2. **Moribund fish** are best for diagnosis (not dead)
3. **Water quality** should always be checked first
4. **Multiple samples** increase diagnostic accuracy
5. **Proper preservation** is critical for lab tests
6. **Document everything** for pattern recognition
