## 2. Koi Herpesvirus Disease (KHVD)

### Disease Characteristics

```
KOI HERPESVIRUS (CyHV-3)

Affected Species:
  - Common carp (Cyprinus carpio)
  - Koi (ornamental carp)
  - ALL carp varieties susceptible

Temperature Range:
  Active: 16-28°C
  Optimal: 22-27°C
  Inactive: <16°C or >30°C

Transmission:
  • Direct contact (fish-to-fish)
  • Water-borne
  • Equipment, nets
  • Vertical (egg transmission suspected)

Incubation: 7-21 days

Mortality: 70-100% in naive populations
```

### Clinical Signs and Diagnosis

```
CLINICAL SIGNS:

Behavioral:
  • Lethargy
  • Disoriented swimming
  • Gasping at surface
  • Anorexia

External:
  • Gill necrosis (primary lesion)
  • Pale, mottled gills
  • Excess mucus
  • Skin lesions
  • Sunken eyes

Internal:
  • Enlarged kidney
  • Pale organs
  • Gill hemorrhage/necrosis


DIAGNOSIS:

Presumptive:
  • Clinical signs + mortality pattern
  • Gill necrosis in carp
  • Water temperature 18-27°C
  • Rapid spread

Confirmatory:
  • PCR (gill, kidney tissue)
  • ELISA
  • Virus isolation (cell culture)
  • Histopathology

Sample Collection:
  • Fresh (PCR): Refrigerate 4°C
  • Frozen (PCR): -80°C
  • Fixed (Histology): 10% formalin
  • Submit 5-10 moribund fish
```

### Control Measures

```
KHV CONTROL PROTOCOL

NO TREATMENT EXISTS

Outbreak Response:
  1. QUARANTINE immediately
  2. Stop all fish movements
  3. Notify authorities (reportable)
  4. Sample and confirm diagnosis
  5. Depopulation likely required

Temperature Manipulation (Controversial):
  • Raise temperature >30°C
  • May reduce mortality
  • Does not eliminate virus
  • Survivors are carriers
  • NOT recommended for eradication

Prevention:
  ✓ Source certified KHV-free stock
  ✓ Strict quarantine (45+ days at 20-25°C)
  ✓ PCR test before introduction
  ✓ Biosecurity protocols
  ✓ Avoid carp/koi mixing
  ✓ Disinfection between crops

Vaccination:
  • Available in some countries
  • Live attenuated vaccine
  • Regulatory restrictions
  • Check local regulations
```

## 3. Spring Viremia of Carp (SVC)

### Disease Overview

```
SPRING VIREMIA OF CARP

Virus: Rhabdovirus (SVCV)

Characteristics:
  • OIE-notifiable disease
  • Cool water (10-17°C)
  • Spring outbreaks common
  • Cyprinids affected

Clinical Signs:
  • Hemorrhagic septicemia
  • Ascites (swollen abdomen)
  • Exophthalmia
  • Pale gills
  • Petechial hemorrhages
  • Hemorrhagic intestine

Mortality: 30-70%

Diagnosis: PCR, virus isolation

Control:
  ✗ No treatment
  ✓ Depopulation
  ✓ Disinfection
  ✓ Restocking restrictions
  ✓ Vaccination (where available)
```

## 4. Tilapia Lake Virus (TiLV)

### Emerging Disease

```
TILAPIA LAKE VIRUS

Discovery: 2014 (Israel)
Spread: Now on multiple continents

Affected Species:
  • Nile tilapia (primary)
  • Other tilapia species
  • All life stages

Clinical Signs:
  • Lethargy
  • Anorexia
  • Exophthalmia
  • Gill pallor
  • Mortality 10-90%
  • Brain/eye lesions

Diagnosis:
  • PCR (brain, liver)
  • Histopathology
  • RT-qPCR

Management:
  ✗ No treatment
  ✗ No vaccine yet
  ✓ Biosecurity essential
  ✓ Selective breeding (resistance)
  ✓ Early detection and culling
  ✓ Avoid stress triggers
```

## 5. Viral Hemorrhagic Septicemia (VHS)

### Disease Profile

```
VHS (VHSV - Rhabdovirus)

Species: Salmonids, pike, other freshwater/marine fish

Temperature: 4-18°C (cold water)

Clinical Signs:
  • Hemorrhagic septicemia
  • Darkening
  • Exophthalmia
  • Anemia (pale gills)
  • Ascites
  • Hemorrhages (skin, organs, eyes)

Mortality: Up to 100%

Diagnosis:
  • Virus isolation
  • PCR
  • Immunofluorescence

Control:
  • OIE-notifiable
  • Depopulation required
  • Strict biosecurity
  • Movement restrictions
  • Zoning/compartmentalization
```

        │  • PPE donning    │
        └─────────┬─────────┘
                  │
    ┌─────────────▼─────────────┐
    │    PRODUCTION ZONE (RED)  │
    │  • Hatchery               │
    │  • Grow-out systems       │
    │  • Feed storage           │
    │  • Equipment storage      │
    └───────────────────────────┘


TRAFFIC FLOW:

  UNIDIRECTIONAL MOVEMENT:
    Clean → Dirty
    Young fish → Older fish
    Never reverse direction


EQUIPMENT PROTOCOLS:

  Dedicated per zone:
    • Nets
    • Boots
    • Buckets
    • Tools

  Between uses:
    1. Clean (remove organic matter)
    2. Disinfect (bleach, Virkon)
    3. Rinse
    4. Dry
    5. UV exposure (if available)

## 8. Disinfection Protocols

### Effective Disinfectants

```
DISINFECTANT SELECTION

CHLORINE (Sodium Hypochlorite):
  Use: General disinfection, virus inactivation
  Concentration: 50-200 ppm active chlorine
  Contact time: 10-30 minutes

  Advantages:
    ✓ Broad spectrum
    ✓ Inexpensive
    ✓ Readily available

  Disadvantages:
    ✗ Inactivated by organics
    ✗ Corrosive
    ✗ Must neutralize before discharge


IODOPHORS:
  Use: Equipment, footbaths
  Concentration: 50-200 ppm
  Contact time: 10 minutes

  Advantages:
    ✓ Less affected by organics
    ✓ Less corrosive
    ✓ Visible color indicator


QUATERNARY AMMONIUM COMPOUNDS:
  Use: Hard surfaces, equipment
  Concentration: Per manufacturer
  Contact time: 10 minutes

  Advantages:
    ✓ Good penetration
    ✓ Residual activity

  Disadvantages:
    ✗ Inactivated by soaps
    ✗ Expensive


VIRKON S (Potassium peroxymonosulfate):
  Use: All-purpose, virus effective
  Concentration: 1% (10 g/L)
  Contact time: 10 minutes

  Advantages:
    ✓ Broad spectrum including viruses
    ✓ Works in organic matter
    ✓ Non-corrosive

  Disadvantages:
    ✗ Expensive


FORMALIN (37% Formaldehyde):
  Use: Tank/pond disinfection
  Concentration: 100-200 ppm
  Contact time: 24 hours

  WARNING:
    ⚠ Carcinogenic
    ⚠ Use PPE
    ⚠ Proper disposal
    ⚠ Restricted in many areas


LIME (Calcium Oxide):
  Use: Pond bottom treatment
  Application: 1,000-2,000 kg/ha

  Advantages:
    ✓ Inexpensive
    ✓ pH adjustment
    ✓ Nutrient management


DRYING:
  Duration: 14+ days
  Effectiveness: High (most pathogens)
  Cost: Free (time only)
```

### Disinfection Procedures

```
STANDARD DISINFECTION PROTOCOL

1. CLEANING (Critical first step):
   □ Remove all fish and water
   □ Scrub all surfaces
   □ Remove organic matter
   □ Rinse thoroughly
   □ Inspect for missed areas

2. DISINFECTION:
   □ Select appropriate disinfectant
   □ Calculate correct dose
   □ Apply evenly to all surfaces
   □ Ensure contact time
   □ Cover all equipment

3. RINSING:
   □ Thorough rinse with clean water
   □ Remove all disinfectant residue
   □ Test for residuals if needed

4. DRYING:
   □ Allow complete drying
   □ UV exposure if possible
   □ Minimum 24-48 hours

5. VERIFICATION:
   □ Visual inspection
   □ ATP bioluminescence (if available)
   □ Environmental swabs (high-security)

6. RESTOCKING:
   □ Fill with clean water
   □ Test water quality
   □ Acclimate before stocking
```

## 9. Quarantine Protocols

### Effective Quarantine

```
QUARANTINE SYSTEM DESIGN

Physical Requirements:
  ✓ Separate building/room
  ✓ Independent water supply
  ✓ Separate drainage (no shared water)
  ✓ Dedicated equipment
  ✓ Biosecurity barriers

Duration:
  Minimum: 30 days
  Viral diseases: 45-60 days
  High-value: 90 days

Protocol:
  Day 0: Receive fish
    - External exam
    - Behavioral observation
    - Water quality baseline
    - Initial sampling

  Day 7: First health check
    - Wet mounts (parasites)
    - Behavioral assessment
    - Mortality review

  Day 14: Mid-quarantine
    - Detailed examination
    - Sample for bacteria
    - PCR if indicated

  Day 21: Pre-release check
    - Comprehensive health exam
    - Laboratory tests complete

  Day 30: Release or extend
    - Final approval
    - Transfer to production
    - OR extend if issues detected


TESTING DURING QUARANTINE:

  Mandatory:
    □ Parasite examination (wet mounts)
    □ Bacterial culture (if mortality)
    □ Behavioral observation daily

  Recommended:
    □ PCR for known regional viruses
    □ Histopathology sample
    □ Water quality monitoring

  High-Security:
    □ Full viral panel
    □ Molecular diagnostics
    □ Quarantine duration: 90 days


REJECT CRITERIA:

  Immediate rejection:
    • Reportable disease detected
    • High mortality (>5% in 30 days)
    • Clinical viral disease signs
    • Severe parasitism

  Conditional (treat and extend):
    • Treatable bacterial infection
    • Moderate parasites
    • Poor condition (if recoverable)
```

## 10. Outbreak Response Plan

### Viral Disease Response Protocol

```
EMERGENCY RESPONSE PLAN

PHASE 1: DETECTION (Day 0)
  □ Recognize unusual mortality/signs
  □ Isolate affected unit immediately
  □ Stop all fish movements
  □ Notify management/authorities
  □ Begin documentation

PHASE 2: INVESTIGATION (Days 1-3)
  □ Clinical examination (multiple fish)
  □ Sample collection for lab
  □ Review recent changes
  □ Water quality assessment
  □ Interview staff

PHASE 3: DIAGNOSIS (Days 3-7)
  □ Laboratory results
  □ Confirm etiology
  □ Determine extent
  □ Risk assessment

PHASE 4: CONTAINMENT (Days 7-14)
  □ Enhanced biosecurity
  □ Movement control
  □ Additional testing
  □ Stakeholder communication
  □ Regulatory compliance

PHASE 5: ERADICATION (Weeks 2-8)

  If REPORTABLE VIRAL DISEASE:
    1. Depopulation required
    2. Humane euthanasia
    3. Proper disposal (burial, incineration)
    4. Complete disinfection
    5. Fallow period (30-90 days)
    6. Testing before restocking

  If MANAGEABLE DISEASE:
    1. Cull affected fish
    2. Increase biosecurity
    3. Monitor remaining stock
    4. Supportive care
    5. Prevent spread

PHASE 6: RECOVERY (Months 2-6)
  □ System validation
  □ Gradual restocking
  □ Enhanced monitoring
  □ Review and improve protocols
  □ Staff training
  □ Documentation review


COMMUNICATION PLAN:

  Internal:
    • Hourly updates during crisis
    • Daily briefings
    • Document all actions

  Regulatory:
    • Immediate notification (reportable diseases)
    • Daily updates during investigation
    • Final report

  Industry:
    • Inform neighboring farms (disease risk)
    • Industry associations
    • Trade partners (if needed)

  Public:
    • Media relations (if needed)
    • Customer communication
    • Transparency
```

## Summary

Viral diseases represent the greatest disease threat in aquaculture because:

1. **No Treatment** - Prevention is the only option
2. **High Mortality** - Can cause total losses
3. **Rapid Spread** - Highly contagious
4. **Economic Impact** - Trade restrictions, depopulation costs
5. **Long-term Effects** - Survivors may be carriers

Biosecurity is the ONLY defense:
- Physical isolation and barriers
- Traffic control and sanitation
- Quarantine protocols
- Health monitoring and testing
- Rapid outbreak response
- Staff training and compliance

---

## Key Takeaways

1. **Prevention is everything** - No viral disease treatment exists
2. **Biosecurity is non-negotiable** - Must be consistent
3. **Quarantine is essential** - 30-60 days minimum
4. **Early detection saves money** - Daily monitoring critical
5. **Depopulation may be required** - Reportable diseases
6. **Staff training is key** - Humans are vectors
