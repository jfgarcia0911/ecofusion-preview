# Module 14: Biological Systems Project

## Overview
This capstone module integrates all concepts from the course into a comprehensive biological system optimization project. Students will apply their knowledge to design, implement, and evaluate biological enhancement strategies for real or hypothetical aquaponic systems.

**Duration:** 1 hour
**Learning Objectives:**
- Integrate course concepts into system design
- Develop comprehensive biological management plans
- Create monitoring and intervention protocols
- Evaluate biological system performance
- Present biological optimization strategies

---

## Project Overview

### Project Goal

**Develop a comprehensive Biological Enhancement Plan for an aquaponic system that optimizes:**
1. Nitrification efficiency
2. Plant health and productivity (via root zone microbiome)
3. Fish health and growth (via gut microbiome and water quality)
4. Pest and disease management (biological control)
5. System sustainability and stability

**C. Fish Gut Health Program**

Design probiotic and prebiotic program for fish:

```
PROBIOTIC STRATEGY:
├─ Selected probiotic species:
│  ├─ Bacillus subtilis (primary - spore-former)
│  ├─ Lactobacillus plantarum (LAB)
│  └─ Saccharomyces cerevisiae (yeast) - optional
├─ Delivery method:
│  ├─ Feed incorporation (top-coating protocol)
│  ├─ Commercial probiotic feed (if available)
│  └─ Dosage: 10^8 CFU/g feed
├─ Feeding schedule:
│  ├─ Daily during establishment (weeks 1-4)
│  ├─ Maintenance: 5x per week ongoing
│  └─ Intensive: Daily during stress/post-treatment
└─ Storage and handling procedures

PREBIOTIC SUPPLEMENTATION:
├─ Selected prebiotics:
│  ├─ MOS (mannan-oligosaccharides) 0.2% feed
│  ├─ FOS (fructooligosaccharides) 1% feed
│  └─ Beta-glucans 0.5% feed - optional
└─ Synbiotic approach (probiotic + prebiotic combined)

EXPECTED OUTCOMES:
├─ FCR improvement (target: 10-20% better)
├─ Growth rate improvement (target %)
├─ Disease resistance (reduced mortality during outbreaks)
├─ Fecal quality improvement (visual assessment)
└─ Reduced ammonia excretion (target: 5-15% reduction)
```

**D. Biological Pest and Disease Control**

Develop integrated biological pest/disease management program:

```
PEST CONTROL STRATEGY:
├─ Identify primary pests (current or expected)
├─ For each pest, specify:
│  ├─ Beneficial insect/organism
│  ├─ Release rate and frequency
│  ├─ Banker plant system (if applicable)
│  ├─ Environmental requirements (temp, humidity)
│  └─ Monitoring method and action thresholds
├─ Example for Aphids:
│  ├─ Primary: Aphidius colemani (parasitoid wasp)
│  ├─ Rate: 1-2 wasps/m² weekly
│  ├─ Banker plants: Barley with grain aphids
│  ├─ Monitor: Yellow sticky traps, count mummies
│  └─ Threshold: Release when >5 aphids/trap/week
└─ Integration with cultural controls (sanitation, exclusion)

DISEASE CONTROL STRATEGY:
├─ Identify primary plant diseases
├─ Biocontrol applications:
│  ├─ Preventive foliar sprays (Bacillus, schedule)
│  ├─ Root zone applications (Trichoderma, frequency)
│  └─ Environmental controls (humidity, air flow, DO)
├─ Resistant varieties selection
└─ Monitoring and response protocols

IPM PYRAMID APPLICATION:
1. Foundation: Monitoring (sticky traps, scouting schedule)
2. Level 2: Cultural controls (sanitation, environment)
3. Level 3: Biological controls (release schedule)
4. Level 4: Bio-pesticides (if needed, which ones)
5. Level 5: Synthetic pesticides (AVOID in aquaponics)

EXPECTED OUTCOMES:
├─ Pest population suppression (<action thresholds)
├─ Disease incidence reduction (target %)
├─ Reduced need for chemical interventions (target: zero)
└─ Beneficial insect establishment (self-sustaining populations)
```

**Deliverable:** Biological IPM plan with release schedules and cost estimates

### Part 3: Monitoring and Evaluation Plan (20%)

**A. Monitoring Protocol**

Design comprehensive monitoring to track biological performance:

```
DAILY MONITORING:
├─ Visual inspection (fish, plants, water)
├─ pH and temperature (automated if possible)
├─ Feeding log (amount, fish appetite)
└─ Observations (any abnormalities)

WEEKLY MONITORING:
├─ Water chemistry (ammonia, nitrite, nitrate, alkalinity)
├─ Dissolved oxygen (fish tank, biofilter, root zones)
├─ Root inspections (sample 10% of plants, rotating)
├─ Pest monitoring (sticky trap counts, visual scouting)
├─ Disease scouting (10-20% of plants)
└─ Fish health assessment (behavior, appearance)

MONTHLY MONITORING:
├─ Microscopy (protozoa count in biofilter samples)
├─ Growth measurements:
│  ├─ Fish weights (sample, calculate biomass)
│  ├─ Plant measurements (height, leaf count, yield)
│  └─ Compare to targets (growth curves)
├─ System performance calculations:
│  ├─ Nitrification rate (calculate from TAN input/output)
│  ├─ FCR (feed / fish weight gain)
│  ├─ Plant yield per m²
│  └─ Disease/pest incidence (%)
└─ Deep system inspection (biofilter flow, sediment accumulation)

DATA MANAGEMENT:
├─ Recording method (spreadsheet, database, app)
├─ Data visualization (charts, graphs for trends)
├─ Threshold alarms (high ammonia, low DO, pH out of range)
└─ Regular review and analysis (weekly summaries)
```

**Deliverable:** Monitoring plan with templates/forms

**B. Key Performance Indicators (KPIs)**

Define measurable biological success metrics:

```
BIOFILTER KPIs:
├─ Ammonia conversion time (<24 hours to <0.5 mg/L)
├─ Nitrite conversion time (<24 hours to <0.5 mg/L)
├─ pH stability (drift <0.3 units per day)
├─ Nitrification rate (g NH3-N/m²/day, compare to baseline)
└─ Alkalinity consumption rate (stable with buffering schedule)

PLANT KPIs:
├─ Root health index (1-5 scale, target 4-5)
├─ Disease incidence (<5% plants affected)
├─ Growth rate (% increase per week, compare to baseline/standards)
├─ Yield per m² per month (quantify harvest)
└─ Marketable quality (% premium grade)

FISH KPIs:
├─ FCR (target species-specific optimal: 1.0-1.5 for tilapia)
├─ Specific growth rate (% body weight/day)
├─ Survival rate (target >95%)
├─ Disease incidence (events per year, target <2)
└─ Fish health index (composite score, target 7-8/8)

PEST/DISEASE KPIs:
├─ Pest populations (sticky trap counts, target <action thresholds)
├─ Beneficial insect establishment (presence/absence, population trends)
├─ Disease incidence (% plants, target <5%)
├─ Control efficacy (% reduction after intervention, target >80%)
└─ Chemical intervention frequency (target: zero)

SUSTAINABILITY KPIs:
├─ Water exchange rate (L/kg fish produced, target minimize)
├─ Feed efficiency (kg feed / kg fish + plant biomass, optimize)
├─ Energy use per kg production (if tracked)
└─ System stability (fewer interventions, longer without crashes)
```

**Deliverable:** KPI dashboard with baseline and target values

### Part 4: Implementation Timeline (10%)

**A. Phased Implementation Plan**

Realistic timeline for biological enhancements:

```
PHASE 1: FOUNDATION (Weeks 1-4)
├─ Optimize environmental parameters:
│  ├─ pH buffering system implemented
│  ├─ Aeration upgrades installed
│  ├─ DO monitoring established
│  └─ Temperature control (if needed)
├─ Baseline monitoring initiated:
│  ├─ Daily/weekly parameters logged
│  ├─ Fish and plant measurements taken
│  └─ Microscopy samples collected
└─ Initial inoculations:
   ├─ Nitrifying bacteria to biofilter
   ├─ PGPR to plant root zones
   ├─ Probiotics in fish feed started
   └─ Expected: Minimal visible results yet, foundation setting

PHASE 2: ESTABLISHMENT (Weeks 5-12)
├─ Continue biological applications:
│  ├─ Nitrifying bacteria: Weekly for 4 weeks, then PRN

├─ Monitor and adjust:

   ├─ Biofilter: Improved ammonia/nitrite processing
   ├─ Plants: Healthier roots, increased vigor

   └─ Pests: Population reduction (if releases effective)

PHASE 3: OPTIMIZATION (Weeks 13-24)
├─ Fine-tune protocols:
│  ├─ Reduce intervention frequency (move to maintenance)

│  └─ Establish self-sustaining populations where possible
├─ Expand successes:
│  ├─ Apply effective strategies system-wide
│  ├─ Consider additional enhancements
│  └─ Optimize for cost-effectiveness
└─ Expected results:
   ├─ Stable biological systems
   ├─ Reduced intervention needs (self-regulating)
   ├─ Measurable KPI improvements
   └─ Lower long-term management effort

PHASE 4: MAINTENANCE (Months 6+)
├─ Ongoing protocols:
│  ├─ Probiotic feeding 3-5x/week (fish)

├─ Continuous improvement:
│  ├─ Quarterly system reviews
```

### Part 5: Risk Assessment and Contingency Planning (10%)

**Identify Potential Failures and Backup Plans:**

```
RISK 1: Biological interventions don't work as expected
├─ Likelihood: Moderate
├─ Impact: Moderate (wasted money, delayed improvements)
├─ Mitigation:
│  ├─ Use high-quality products from reputable sources
│  ├─ Follow application protocols precisely
│  ├─ Optimize environment first (bacteria need good conditions)
│  └─ Start with proven interventions (Trichoderma, Bacillus subtilis)
└─ Contingency:
   ├─ Try alternative products/strains
   ├─ Increase application frequency/concentration
   ├─ Seek expert consultation
   └─ Fall back to chemical controls if emergency (avoid if possible)

RISK 2: Biofilter crash during transition
├─ Likelihood: Low (if done carefully)
├─ Impact: High (fish losses, system reset)
├─ Mitigation:
│  ├─ Gradual changes only (don't shock biofilter)
│  ├─ Monitor ammonia/nitrite daily during transitions
│  ├─ Maintain backup biofilter media (spare colonized media)
│  └─ Have emergency ammonia detoxifiers on hand
└─ Contingency:
   ├─ Reduce feeding immediately
   ├─ Massive aeration increase
   ├─ Partial water changes
   ├─ Commercial nitrifying bacteria additions
   └─ Fish transfer to backup system (if available)

RISK 3: Disease outbreak during implementation
├─ Likelihood: Low to moderate
├─ Impact: High (crop/fish losses)
├─ Mitigation:
│  ├─ Preventive biocontrol applications
│  ├─ Strict sanitation protocols
│  ├─ Quarantine new plants/fish
│  └─ Maintain optimal environmental conditions (reduce stress)
└─ Contingency:
   ├─ Isolate affected organisms
   ├─ Intensive biocontrol applications
   ├─ Environmental optimization (DO, temp)
   ├─ Remove severely affected (prevent spread)
   └─ Chemical treatment if necessary (hospital tank for fish)

RISK 4: Budget overruns
├─ Likelihood: Moderate
├─ Impact: Moderate (project delays or scaling back)
├─ Mitigation:
│  ├─ Prioritize interventions (high-impact first)
│  ├─ Phase implementation (spread costs over time)
│  ├─ Compare product prices (shop around)
│  └─ DIY where possible (homemade inoculants - with caution)
└─ Contingency:
   ├─ Focus on free/low-cost strategies (environmental optimization)
   ├─ Delay lower-priority interventions
   ├─ Seek grants or partnerships
   └─ Scale back to pilot test (smaller area, prove concept)

RISK 5: Lack of time for intensive monitoring
├─ Likelihood: Moderate (common constraint)
├─ Impact: Moderate (may miss early problems)
├─ Mitigation:
│  ├─ Automate monitoring (pH, DO, temp continuous)
│  ├─ Simplify protocols (combine tasks)
│  ├─ Schedule dedicated time blocks
│  └─ Train additional personnel/family members
└─ Contingency:
   ├─ Reduce monitoring frequency (focus on critical parameters)
   ├─ Use alarms/alerts (automated systems notify of problems)
   ├─ Hire part-time assistant
   └─ Accept higher risk (informed decision)
```

**Deliverable:** Risk matrix with likelihood, impact, and mitigation strategies

## Project Examples and Inspiration

### Example 1: Backyard Aquaponic System Enhancement

**System:**
- 500-gallon media bed system
- Tilapia, lettuce and herbs
- 1 year old, experiencing recurring Pythium in summer

**Biological Enhancement Focus:**
- Root zone DO optimization (added air stones to beds)
- Trichoderma harzianum preventive applications (monthly)
- Bacillus subtilis fish probiotic (improved FCR 15%)
- Ladybug and lacewing releases (controlled aphids on basil)

**Results:**
- Pythium incidence: 40% → 5%
- Plant yield increase: 25%
- Fish FCR: 1.8 → 1.5
- Zero pesticide use

---

### Example 2: Commercial Greenhouse Aquaponics

**System:**
- 10,000-gallon DWC system
- Hybrid striped bass, lettuce and herbs
- High nitrate accumulation (fish-heavy)

**Biological Enhancement Focus:**
- Denitrification reactor added (woodchip bioreactor)
- Comprehensive beneficial insect program (10 species)
- PGPR cocktail applications to all transplants
- Automated monitoring and alerts

**Results:**
- Nitrate stabilized at 80 mg/L (was climbing to 200+)
- Pest control costs reduced 80%
- Plant disease incidents: 12/year → 2/year
- Labor savings: 10 hrs/week (automated monitoring)

---

### Example 3: Research/Educational System
