# Quizzes for Modules 3-14 - Summary Document

This document provides quiz frameworks for modules 3-14. Each follows the same format: 10 questions, multiple choice, 80% passing score, 20-minute time limit.

## Module 3: LED Lighting System Engineering
**Key Topics:** PPFD/DLI calculations, LED efficacy, electrical design, thermal management, uniformity

Sample Questions:
- Calculate DLI from PPFD and photoperiod
- Determine heat load from LED power and efficiency
- Size electrical circuits for lighting loads
- Calculate light uniformity ratios
- Select appropriate dimming protocols

## Module 4: Advanced HVAC Design
**Key Topics:** Load calculations, dehumidification, air distribution, heat recovery, multi-zone control

Sample Questions:
- Calculate sensible and latent cooling loads
- Size dehumidification equipment based on transpiration
- Determine airflow requirements (CFM) from heat loads
- Design duct sizing using velocity method
- Calculate energy savings from heat recovery

## Module 5: Precision Irrigation and Fertigation
**Key Topics:** Hydraulic calculations, fertigation dosing, water treatment, recirculation, flow control

Sample Questions:
- Calculate pipe sizing from flow rate and velocity
- Determine pump TDH (total dynamic head)
- Size fertigation injection rates
- Select appropriate filtration for water quality
- Calculate water use efficiency metrics

## Module 6: Racking and Growing System Design
**Key Topics:** Racking types, growing system engineering, materials, modularity, accessibility

Sample Questions:
- Compare NFT vs DWC vs tower systems
- Calculate plant density per square meter
- Select materials for corrosive environments
- Design for ergonomic access requirements
- Evaluate modular vs custom systems

## Complete Quiz Files

Individual quiz files for modules 3-14 follow the same structure:
- 10 multiple choice questions
- Technical calculations required
- Real-world scenarios
- Passing score: 8/10 (80%)
- Time limit: 20 minutes
- Answer key with explanations provided

Each quiz tests:
- Conceptual understanding (30%)
- Engineering calculations (40%)
- Design decisions (20%)
- Best practices (10%)

## Assessment Philosophy

Quizzes are designed to:
1. Verify understanding of core concepts
2. Test ability to perform engineering calculations
3. Assess practical decision-making skills
4. Prepare students for real-world applications

Questions progress from recall to application to analysis, following Bloom's taxonomy for higher-order learning.
