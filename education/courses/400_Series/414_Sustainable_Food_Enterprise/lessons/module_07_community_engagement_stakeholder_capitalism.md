## 6.7 From Shareholder to Stakeholder Capitalism

### The Evolution of Corporate Purpose

```
CORPORATE GOVERNANCE EVOLUTION
===============================

SHAREHOLDER PRIMACY (1970-2010s)
┌─────────────────────────────────────┐
│ Milton Friedman: "The business of  │
│ business is business"               │
│                                     │
│ • Maximize shareholder value        │
│ • Fiduciary duty to owners only     │
│ • Externalities ignored             │
│ • Short-term profit focus           │
└─────────────────────────────────────┘
                ↓
CORPORATE SOCIAL RESPONSIBILITY (1990s-2010s)
┌─────────────────────────────────────┐
│ Profit + Philanthropy               │
│                                     │
│ • Primary: Shareholder value        │
│ • Secondary: Social programs        │
│ • CSR as separate function          │
│ • Often marketing-driven            │
└─────────────────────────────────────┘
                ↓
STAKEHOLDER CAPITALISM (2010s-Present)
┌─────────────────────────────────────┐
│ All stakeholders create value       │
│                                     │
│ • Shareholders AND stakeholders     │
│ • Integrated into strategy          │
│ • Long-term value creation          │
│ • Purpose beyond profit             │
└─────────────────────────────────────┘
```

### Business Roundtable 2019 Statement

181 CEOs signed commitment to lead companies for benefit of all stakeholders:

1. **Delivering value to customers**
2. **Investing in employees** (compensation, benefits, training)
3. **Dealing fairly and ethically with suppliers**
4. **Supporting communities**
5. **Generating long-term value for shareholders**

Significance: Mainstream acceptance of stakeholder model, though implementation varies widely.

EXAMPLE MAPPING:

### Salience Model (Mitchell, Agle, Wood)

Stakeholders characterized by three attributes:

**1. Power:** Ability to influence the organization
**2. Legitimacy:** Appropriate relationship to organization
**3. Urgency:** Time-sensitive or critical claims

```
STAKEHOLDER SALIENCE
====================

         ┌─────────────────────────────────┐
         │         POWER                   │
    ┌────┼─────────────────────────────────┼────┐
    │    │    LEGITIMACY                   │    │
    │    │                                 │    │
    │    │       ┌──────────┐             │    │
    │    │       │ DEFINITIVE│             │    │
    │    └───────│STAKEHOLDER│─────────────┘    │
    │            └──────────┘                   │
    │         (All 3 attributes)                │
    │           HIGHEST PRIORITY                │
    │                                           │
    │    POWER + LEGITIMACY = DOMINANT         │
    │    POWER + URGENCY = DANGEROUS            │
    │    LEGITIMACY + URGENCY = DEPENDENT       │
    │                                           │
    │    Single attribute = LATENT              │
    │    (dormant, discretionary, demanding)    │
    └───────────────────────────────────────────┘

Application: Prioritize stakeholders with multiple attributes,
especially definitive stakeholders with all three.
```

## 7.3 Multi-Stakeholder Governance Models

### Governance Structure Options

**1. Advisory Councils**

Non-binding input from stakeholder representatives

```
BOARD OF DIRECTORS
(Fiduciary duty, decision authority)
         │
         ↓
┌────────────────────────────────────┐
│   STAKEHOLDER ADVISORY COUNCILS    │
├────────────────────────────────────┤
│ • Farmer Advisory Council          │
│ • Employee Council                 │
│ • Community Advisory Board         │
│ • Customer Panel                   │
└────────────────────────────────────┘
         │
         ↓ (Recommendations)
    MANAGEMENT
(Considers input in decision-making)
```

**Advantages:**
- Structured stakeholder input
- Lower risk than binding governance
- Flexible implementation

**Challenges:**
- Advisory only, can be ignored
- Risk of tokenism if not genuine
- Stakeholder frustration if not influential

**2. Multi-Stakeholder Cooperatives**

Ownership and governance by multiple stakeholder classes

**Example Structure:**
```
MULTI-STAKEHOLDER FOOD COOP
===========================

MEMBER-OWNERS:
• Producer members (farmers)         - 40% ownership
• Worker members (employees)         - 30% ownership
• Consumer members (shoppers)        - 20% ownership
• Community members (local orgs)     - 10% ownership

BOARD OF DIRECTORS:
Elected proportionally by stakeholder class
• 4 producer representatives
• 3 worker representatives
• 2 consumer representatives
• 1 community representative

VOTING:
One member, one vote within each class
Major decisions require approval from multiple classes
```

**Examples:**
- La Montanita Co-op (New Mexico): Producer, consumer, worker members
- Mondragon Corporation (Spain): Worker and consumer cooperatives
- Farmers Diner (Vermont): Multi-stakeholder LLC

**3. Benefit Corporation with Stakeholder Directors**

Benefit corporation legal status + board seats for stakeholders

**Example:**
```
BENEFIT CORPORATION BOARD
=========================

SHAREHOLDER REPRESENTATIVES:    5 seats
STAKEHOLDER REPRESENTATIVES:    4 seats
  • Employee-elected:           1 seat
  • Supplier representative:    1 seat
  • Community representative:   1 seat
  • Environmental expert:       1 seat
─────────────────────────────────────────
TOTAL:                          9 seats

Requirements:
• Stakeholder directors have full fiduciary duty
• Not simply representing constituency interests
• Must act in best interest of benefit corporation
  (which includes all stakeholders)
```

**4. B Corp with Stakeholder Engagement**

B Corp certification + formalized engagement processes

**Mechanisms:**
- Annual stakeholder surveys (employees, suppliers, customers)
- Regular town halls and feedback sessions
- Participatory decision-making on material issues
- Transparent communication of decisions and rationale
- Accountability to stakeholder commitments in benefit report

## 7.4 Community Benefit Agreements

### What is a Community Benefit Agreement (CBA)?

A CBA is a legally binding contract between community organizations and a developer/business outlining the project benefits to be provided to the community.

**Typical Components:**

```
COMMUNITY BENEFIT AGREEMENT ELEMENTS
=====================================

ECONOMIC BENEFITS
┌─────────────────────────────────────┐
│ • Local hiring commitments          │
│ • Living wage guarantees            │
│ • Local business purchasing         │
│ • Job training programs             │
│ • Community ownership opportunities │
└─────────────────────────────────────┘

SOCIAL BENEFITS
┌─────────────────────────────────────┐
│ • Affordable food access programs   │
│ • Community space provision         │
│ • Educational programming           │
│ • Health and wellness initiatives   │
│ • Cultural preservation/celebration │
└─────────────────────────────────────┘

ENVIRONMENTAL BENEFITS
┌─────────────────────────────────────┐
│ • Sustainable building practices    │
│ • Waste reduction commitments       │
│ • Green space preservation          │
│ • Transportation/access planning    │
│ • Pollution mitigation              │
└─────────────────────────────────────┘

GOVERNANCE & ACCOUNTABILITY
┌─────────────────────────────────────┐
│ • Community oversight committee     │
│ • Regular reporting requirements    │
│ • Enforcement mechanisms            │
│ • Renewal/expansion provisions      │
│ • Dispute resolution process        │
└─────────────────────────────────────┘
```

### CBA Development Process

**1. Community Organizing (6-12 months)**
- Coalition building among community groups
- Articulate community vision and priorities
- Research and document community needs
- Build negotiating power

**2. Negotiation (3-6 months)**
- Engage developer/business
- Present community demands
- Negotiate terms and commitments
- Legal review and drafting

**3. Agreement Finalization (1-3 months)**
- Sign binding agreement
- Public announcement and celebration
- Establish oversight mechanism

**4. Implementation and Monitoring (Ongoing)**
- Regular compliance reporting
- Community oversight committee review
- Public accountability
- Enforcement if necessary

### Case Study: Mandela Foods Cooperative (Oakland, CA)

**Context:**
- Food desert in West Oakland
- Community organizing for food justice
- Development of cooperative grocery store

**Community Benefits Achieved:**
- 100% local ownership (community members)
- Living wage jobs with benefits
- Healthy food access in underserved neighborhood
- Community gathering space
- Youth employment and training
- Support for local food producers
- SNAP/EBT acceptance and incentives

**Governance:**
- Member-owned cooperative
- Community advisory board
- Regular town halls
- Transparent financial reporting

**Impact:**
- $3M+ in local economic impact
- 25+ jobs created
- Improved diet and health outcomes
- Model replicated in other communities

## 7.5 Building Social Capital

### Forms of Social Capital

**Bonding Social Capital:**
- Connections within homogeneous groups
- Strong ties, high trust
- Example: Farmer cooperative, employee community

**Bridging Social Capital:**
- Connections across diverse groups
- Weaker ties but broader reach
- Example: Food hub connecting farmers, restaurants, consumers

**Linking Social Capital:**
- Connections across power differences
- Access to institutions and resources
- Example: Community organization relationship with government

### Strategies for Building Social Capital

**1. Authentic Relationships**

Beyond transactional interactions:
```
TRANSACTIONAL ────────────────→ RELATIONAL

What?           How?                       Impact
─────────────────────────────────────────────────────────
Single          Regular communication      Trust
interaction     Multi-channel engagement   Loyalty

Anonymous       Personal connection        Shared identity
                Know names and stories     Pride

Extractive      Mutual benefit             Co-creation
                Shared success             Partnership

Closed          Transparent                Accountability
                Open communication         Learning
```

**2. Participatory Processes**

Involve stakeholders in decisions:
- Co-design of products/services with beneficiaries
- Employee participation in strategy
- Supplier input on procurement terms
- Community input on facility development

**3. Knowledge Sharing**

Build capacity of stakeholders:
- Training and education programs
- Open-source tools and methodologies
- Peer learning networks
- Transparent communication of challenges and learnings

**4. Collective Action**

Organize for shared goals:
- Industry coalitions for policy change
- Supplier networks for mutual support
- Community organizing for food justice
- Cross-sector partnerships for systems change

**5. Trust Building**

Foundational for all relationships:
- Consistent follow-through on commitments
- Transparency in communication
- Admitting mistakes and learning publicly
- Long-term orientation over short-term gains
- Authentic listening and responsiveness

## 7.6 Balancing Stakeholder Interests

### When Stakeholder Interests Conflict

Common tension points in food enterprises:

```
STAKEHOLDER CONFLICTS
=====================

SHAREHOLDERS vs. WORKERS
Profit maximization ←→ Higher wages/benefits

CUSTOMERS vs. PRODUCERS
Low prices ←→ Fair compensation

SHORT-TERM vs. LONG-TERM
Quarterly results ←→ Patient investment

GROWTH vs. MISSION
Scale and efficiency ←→ Relationship and quality

ECONOMIC vs. ENVIRONMENTAL
Cost minimization ←→ Sustainability investment

LOCAL vs. GLOBAL
Regional focus ←→ Broad impact
```

### Decision Framework for Trade-Offs

**Step 1: Understand the True Conflict**
- Are interests actually opposed, or can both be served?
- Is this a zero-sum trade-off or false dichotomy?
- What creative solutions might reconcile interests?

**Step 2: Assess Stakeholder Salience**
- Which stakeholders have highest power, legitimacy, urgency?
- Who is most materially affected by this decision?
- What are long-term vs. short-term considerations?

**Step 3: Evaluate Against Mission**
- Which choice better advances core purpose?
- What would founders/values mandate?
- How does benefit corporation purpose guide decision?

**Step 4: Seek Stakeholder Input**
- Consult with affected parties
- Consider perspectives and priorities
- Build understanding even if decision disappoints

**Step 5: Make Transparent Decision**
- Document rationale considering all stakeholders
- Communicate decision and reasoning
- Commit to review and learning

**Step 6: Monitor and Adjust**
- Track outcomes for all stakeholders
- Be willing to revise if negative impacts emerge
- Demonstrate responsiveness and learning

### Case Example: Wage vs. Price Trade-Off

**Scenario:** Community food business faces decision:
- Option A: Raise worker wages to living wage (+20%), increase customer prices
- Option B: Maintain current wages and prices to preserve affordability for low-income customers

**Analysis:**
```
STAKEHOLDER IMPACT ASSESSMENT
==============================

Stakeholder    Option A              Option B
──────────────────────────────────────────────────────────
Workers        Living wage (+++)     Below living wage (-)
              Dignity, security      Financial stress

Customers      Higher prices (-)     Affordable prices (++)
              Some may leave         Access maintained

Mission        Worker justice (+)    Food access (+)
              Partially fulfilled    Partially fulfilled

Financials     Margin decrease (-)   Status quo (0)
              Risk to sustainability Stable

Community      Mixed (0)             Mixed (0)
              Values alignment      Economic impact
```

**Resolution Strategies:**

**Hybrid Approach:**
- Phase in wage increases over 2 years
- Implement modest price increase (<5%)
- Launch fundraising for "fair wage fund" to subsidize gap
- Efficiency improvements offset some costs
- Tiered pricing (sliding scale for low-income)

**Result:**
- Workers progress toward living wage
- Customer affordability preserved for most vulnerable
- Community rallies support through donations
- Both stakeholder groups benefit, neither fully optimized

## Key Takeaways

1. Stakeholder capitalism recognizes that businesses create value for and depend on multiple groups beyond shareholders
2. Stakeholder mapping using power-interest matrix and salience model enables strategic prioritization and engagement
3. Multi-stakeholder governance models range from advisory councils to cooperative ownership structures
4. Community benefit agreements create legally binding commitments to local economic, social, and environmental benefits
5. Building social capital through authentic relationships, participation, knowledge sharing, and collective action strengthens stakeholder connections
6. Balancing competing stakeholder interests requires transparent decision-making frameworks that assess trade-offs against mission
7. Stakeholder engagement is not philanthropy but strategic imperative for sustainable, resilient food enterprises

## Practical Exercise

**Stakeholder Engagement Strategy Development**

Choose a sustainable food enterprise (real or hypothetical).

**Part 1: Stakeholder Mapping**
- Identify all primary, secondary, and tertiary stakeholders
- Plot on power-interest matrix
- Apply salience model (power, legitimacy, urgency)
- Prioritize top 5-7 stakeholders for active engagement

**Part 2: Governance Design**
- Select governance model (advisory, multi-stakeholder coop, benefit corp, etc.)
- Justify choice based on mission, stage, resources
- Design specific structure (board composition, councils, etc.)
- Define decision rights and processes

**Part 3: Community Benefit Agreement**
- Identify host community and key community groups
- Research community priorities and needs
- Draft CBA outline with specific commitments
- Create oversight and enforcement mechanism

**Part 4: Social Capital Building**
- Design engagement strategy for each priority stakeholder
- Specify frequency, format, and goals of engagement
- Create feedback and accountability loops
- Develop metrics to assess relationship quality

**Part 5: Conflict Resolution**
- Identify likely stakeholder conflicts in your enterprise
- Apply decision framework to one example conflict
- Demonstrate transparent analysis and resolution
- Describe communication approach to stakeholders
