# Activity: CEA Facility Design Project

## Objective
Apply course concepts to design a complete CEA facility from concept through preliminary design documentation.

## Project Overview

### Scenario
You have been hired to design a vertical farm facility for a client in Denver, Colorado. The client has secured a site and requires a comprehensive design.

### Client Requirements
- **Production Goal**: 500,000 lbs/year of leafy greens (lettuce, herbs)
- **Site**: 2.5 acre parcel in industrial zone, flat terrain
- **Budget**: $12 million total project (land, construction, equipment)
- **Timeline**: 18 months from design to operation
- **Special Requirements**:
  - Retail farm stand (500 sq ft)
  - Educational tour capability
  - LEED Silver certification desired
  - Renewable energy integration

---

## Deliverables

### Part 1: Programming and Feasibility (Week 1-2)

**Tasks:**
1. Calculate required facility size
   - Target productivity: 10 lbs/sq ft/year (vertical farm, 6 levels)
   - Determine footprint needed
   - Space programming (growing, support, circulation)

2. Site analysis
   - Review provided site information
   - Utility assessment
   - Climate data analysis (Denver: 5,283 HDD, 689 CDD)
   - Regulatory review (zoning, codes)

3. Preliminary budget
   - Construction cost estimate ($/sq ft)
   - Equipment costs
   - Professional fees
   - Contingency

**Deliverable**: 5-page feasibility report with diagrams

---

### Part 2: Conceptual Design (Week 3-4)

**Tasks:**
1. Building configuration
   - Floor plan layout (AutoCAD, SketchUp, or hand-drawn)
   - Growing area arrangement (6-tier racks)
   - Support spaces (post-harvest, mechanical, office)
   - Circulation and workflow

2. Building systems selection
   - HVAC approach (chilled water, DX, etc.)
   - Electrical service size
   - Water treatment system
   - LED lighting specification

3. Energy modeling
   - Baseline energy consumption estimate
   - EUI calculation
   - Preliminary renewable energy sizing

**Deliverable**: Conceptual design package
- Site plan (1:100 scale)
- Floor plan (1:50 scale)
- Building sections (1:50 scale)
- System diagrams
- Cost estimate update

---

### Part 3: Load Calculations (Week 5)

**Tasks:**
1. Electrical load calculation
   - Lighting loads (specify LED W/sq ft)
   - HVAC equipment
   - Other systems
   - Total demand load with diversity factors

2. HVAC load calculation
   - Cooling load (envelope, internal gains, ventilation)
   - Heating load (Denver winter design: -4°F)
   - Dehumidification requirement
   - Equipment sizing

3. Water demand calculation
   - Irrigation water (gal/sq ft/day)
   - Process water
   - Domestic water
   - Total supply sizing

**Deliverable**: Technical calculations document (show all work)

---

### Part 4: Building Systems Design (Week 6-7)

**Tasks:**
1. HVAC system design
   - Equipment selection (chillers, air handlers, dehumidifiers)
   - Distribution design (ductwork layout)
   - Control strategy
   - Energy recovery integration

2. Electrical system design
   - Single-line diagram showing distribution
   - Lighting circuit layout
   - Emergency power sizing (if provided)
   - Solar PV system design (size, layout, economics)

3. Plumbing system design
   - Water treatment train
   - Irrigation distribution
   - Drainage system
   - Backflow prevention

**Deliverable**: System design drawings and specifications

---

### Part 5: Code Compliance and Documentation (Week 8)

**Tasks:**
1. Code compliance review
   - Occupancy classification
   - Construction type selection
   - Means of egress design (occupant load, exits, travel distance)
   - Fire protection requirements
   - Accessibility compliance

2. Energy code compliance
   - Envelope performance
   - Lighting power density
   - HVAC efficiency
   - Overall building performance

3. Permit documentation
   - Drawing list
   - Specification outline (CSI format)
   - Code compliance summary

**Deliverable**: Code compliance report and permit document outline

---

### Part 6: Economic Analysis and Final Presentation (Week 9-10)

**Tasks:**
1. Detailed cost estimate
   - Construction costs by system
   - Equipment costs
   - Professional fees, permits
   - Total project cost vs. budget

2. Operating cost projection
   - Annual energy cost
   - Water cost
   - Maintenance cost
   - Staffing requirements

3. Financial analysis
   - Capital investment summary
   - Operating expense projection
   - Revenue projection (at 500,000 lbs/year)
   - Simple payback
   - Return on investment

4. Final presentation
   - Prepare 20-minute presentation
   - Visual aids (renderings, diagrams)
   - Present to class/instructor

**Deliverable**:
- Final project report (25-30 pages)
- Presentation slides
- Drawing set (10-15 sheets)

## Tips for Success

- Start early - programming and feasibility set the foundation
- Use spreadsheets for calculations (easier to revise)
- Sketch multiple layout options before finalizing
- Check your work - have calculations reviewed by peers
- Be realistic about costs and performance
- Document all assumptions clearly
- Seek feedback during interim reviews

**This project synthesizes all course content - treat it as a professional design assignment!**
