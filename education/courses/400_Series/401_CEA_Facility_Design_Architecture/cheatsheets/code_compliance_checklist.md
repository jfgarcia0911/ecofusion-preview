# Building Code Compliance Checklist

## Pre-Design Phase

### Occupancy Classification
- [ ] Determine primary occupancy (F, S, U, H, etc.)
- [ ] Identify mixed occupancy conditions
- [ ] Verify agricultural building eligibility
- [ ] Document occupancy determination rationale

### Construction Type
- [ ] Select construction type (IA, IB, IIA, IIB, etc.)
- [ ] Verify height and area limitations
- [ ] Calculate allowable area (frontage, sprinklers)
- [ ] Confirm fire-resistance ratings

### Zoning Compliance
- [ ] Verify permitted use in zone
- [ ] Check setback requirements
- [ ] Confirm height restrictions
- [ ] Review parking requirements
- [ ] Identify buffer/screening needs

## Life Safety Systems

### Means of Egress
- [ ] Calculate occupant load
- [ ] Determine number of exits required
- [ ] Verify exit capacity (doors, stairs)
- [ ] Check travel distance limits
- [ ] Confirm exit signage locations
- [ ] Design emergency lighting

### Fire Protection
- [ ] Determine sprinkler requirements
- [ ] Specify sprinkler system type (wet/dry)
- [ ] Design fire alarm system (if required)
- [ ] Locate manual pull stations
- [ ] Specify notification devices (horns/strobes)

### Accessibility (ADA)
- [ ] Design accessible routes (36" min width)
- [ ] Specify accessible parking spaces
- [ ] Design accessible restrooms
- [ ] Verify door clear widths (32" min)
- [ ] Check hardware operability
- [ ] Confirm maneuvering clearances

## Building Systems

### Electrical (NEC)
- [ ] Size service per load calculations
- [ ] Specify proper conductor sizes
- [ ] Design grounding electrode system
- [ ] Specify GFCI protection locations
- [ ] Select wet/damp location equipment
- [ ] Verify emergency power requirements

### Plumbing (IPC)
- [ ] Size water supply system
- [ ] Design drainage system with proper slope
- [ ] Specify backflow prevention devices
- [ ] Design vent system
- [ ] Verify fixture counts (restrooms)
- [ ] Check trap requirements

### Mechanical (IMC)
- [ ] Size ventilation per IMC requirements
- [ ] Design combustion air (if required)
- [ ] Specify duct materials and sizing
- [ ] Verify equipment clearances
- [ ] Check refrigerant compliance

## Energy Code (IECC/ASHRAE 90.1)
- [ ] Meet envelope requirements (R-values, U-factors)
- [ ] Specify efficient HVAC equipment
- [ ] Design lighting per power density limits
- [ ] Include lighting controls (occupancy, daylight)
- [ ] Address service water heating efficiency

## Permitting Documentation
- [ ] Prepare site plan
- [ ] Complete architectural drawings
- [ ] Provide structural calculations and drawings
- [ ] Submit MEP drawings
- [ ] Include equipment specifications
- [ ] Provide energy compliance forms
- [ ] Submit sealed drawings (by licensed PE/Architect)

## Inspection Checkpoints
- [ ] Footing inspection (before pour)
- [ ] Foundation inspection
- [ ] Framing inspection
- [ ] Rough-in inspections (MEP)
- [ ] Fire protection inspection
- [ ] Final inspection
- [ ] Certificate of Occupancy

---

**Use this checklist for all CEA facility projects to ensure comprehensive code compliance**
