## Broodstock Selection and Management

### Selection Criteria

**Genetic Traits:**
- Growth rate (top 10-20%)
- Disease resistance
- Body conformation (commercial quality)
- Reproductive performance
- Temperament (handling ease)

**Physical Requirements:**

| Parameter | Requirement |
|-----------|-------------|
| Age | Species-specific sexual maturity + 1 year |
| Size | 2-5× harvest size typically |
| Health | Disease-free, good body condition |
| Sex ratio | Species-specific (often 1:1 to 1:3 F:M) |
| Genetic diversity | Minimum 50 unrelated individuals |

## Reproductive Conditioning

### Environmental Manipulation

**Temperature:**
```
Simulate natural spawning cues:

Temperate Species (e.g., trout):
Fall/Winter → Spring warming triggers spawning
- Reduce temp to 4-6°C for 6-8 weeks
- Gradually increase to 10-12°C
- Spawning occurs during warming phase

Tropical Species (e.g., tilapia):
Year-round breeders with optimal temperature
- Maintain 26-30°C constantly
- Stable temperature = continuous reproduction
```

**Photoperiod:**
```
Day length manipulation:

Spring Spawners:
- Winter: Short days (8L:16D)
- Spring simulation: Increase to 16L:8D
- Rate: +15-30 minutes per week

Fall Spawners:
- Summer: Long days (16L:8D)
- Fall simulation: Decrease to 8L:16D
```

### Nutrition for Reproduction

**Enhanced Broodstock Diet:**

| Nutrient | Standard Diet | Broodstock Diet | Importance |
|----------|---------------|-----------------|------------|
| Protein | 35-45% | 45-55% | Vitellogenesis |
| Lipid | 8-12% | 12-18% | Energy, hormones |
| EPA/DHA | 0.5-1% | 1-2% | Egg quality |
| Vitamin E | 100 mg/kg | 200-400 mg/kg | Antioxidant |
| Vitamin C | 100 mg/kg | 400-1000 mg/kg | Stress, immunity |
| Astaxanthin | 0-50 mg/kg | 50-100 mg/kg | Egg pigmentation |

**Feeding Rate:**
- 1.0-1.5% body weight per day
- Fed to satiation during conditioning
- Quality over quantity

## Spawning Protocols

### Natural Spawning

**Substrate Spawners (e.g., bass, cichlids):**
```
Tank Setup:
- Provide spawning substrate (rocks, tiles, mesh)
- Reduce density
- Introduce pairs or trios
- Monitor for spawning behavior
- Collect eggs/fry after hatching
```

**Broadcast Spawners (e.g., carp, marine species):**
```
Process:
- Condition broodstock separately
- Introduce to spawning tank
- Water flow/circulation triggers release
- Eggs float or sink depending on species
- Collect eggs in downstream net
```

### Hormone-Induced Spawning

**Common Hormones:**

| Hormone | Dose | Species | Method |
|---------|------|---------|--------|
| HCG (Human Chorionic Gonadotropin) | 500-2000 IU/kg | Many species | IM injection |
| GnRHa (Gonadotropin-Releasing Hormone analog) | 10-100 μg/kg | Most species | IM injection |
| LHRHa (Luteinizing Hormone-Releasing Hormone) | 20-50 μg/kg | Salmonids, others | IM or implant |
| CPE (Carp Pituitary Extract) | 2-4 mg/kg | Carp, catfish | IM injection |

**Injection Protocol:**

```
24-48 Hours Before Spawning:

Females:
1. Prime (optional): 10% of total dose
2. Resolving dose: 90% of total dose after 12-24 hrs
3. Expected ovulation: 24-48 hours later @ 25°C

Males:
1. Single injection: 50% of female dose
2. Inject same time as female resolving dose
3. Sperm ready when females ovulate

Temperature affects timing:
- Warmer = faster (12-18 hrs @ 28°C)
- Cooler = slower (48-72 hrs @ 15°C)
```

### Strip Spawning

**Procedure:**
```
1. Anesthetize fish (MS-222, clove oil)
2. Check ripeness:
   Female: Gently press abdomen - eggs flow freely
   Male: Milt flows with light pressure

3. Dry method (best fertilization):
   - Strip eggs into dry bowl
   - Strip milt directly onto eggs
   - Mix gently with feather
   - Add small amount of water (activates sperm)
   - Mix for 30-60 seconds
   - Rinse eggs with clean water

4. Transfer to incubation system
```

## Egg Incubation Systems

### Incubator Types

**1. Vertical Flow Incubators (Salmonids)**

```
┌────────────────────────────────────────────────────┐
│       VERTICAL FLOW INCUBATOR                      │
├────────────────────────────────────────────────────┤
│                                                     │
│        Water In (bottom)                           │
│             ↑↑↑                                    │
│      ┌──────────────┐                             │
│      │ ▓▓▓▓▓▓▓▓▓▓▓ │  ← Eggs on mesh/screen      │
│      │  Egg layer   │                             │
│      ├──────────────┤                             │
│      │  ↑↑↑↑↑↑↑↑↑↑  │  ← Water flows up           │
│      └──────────────┘                             │
│             ↓                                       │
│        Overflow out                                │
│                                                     │
│  Gentle upward flow prevents eggs settling         │
│  Removes metabolic waste                           │
│  Maintains DO                                      │
└────────────────────────────────────────────────────┘

Flow rate: 4-10 L/min per 10,000 eggs
```

```
│                                                     │
│              ┌───┐                                 │
│              │   │  ← Overflow                     │
│          ┌───┴───┴───┐                            │
│          │   ○ ○ ○   │  ← Eggs suspended          │
│          │  ○ ○ ○ ○  │     in water column        │
│          │ ○ ○ ○ ○ ○ │                            │
│          │  ○ ○ ○ ○  │                            │
│          │   ↑↑↑↑↑   │                            │
│          └─────┬─────┘                            │
│                │                                    │
│           Water in (bottom)                        │
│                                                     │
│  Upward flow keeps adhesive eggs suspended         │
│  Constant gentle tumbling                          │
│  Dead eggs (white) can be removed                  │
└────────────────────────────────────────────────────┘

Flow: Adjust to keep eggs suspended but not violent
```

**3. Trough/Raceway Incubators**

```
Simple shallow troughs:
- Eggs in single layer
- Gentle flow over eggs
- Easy to observe and clean
- For hardy, non-adhesive eggs
```

### Incubation Water Quality

| Parameter | Requirement | Notes |
|-----------|-------------|-------|
| Temperature | Species-specific | Controls development rate |
| DO | >6 mg/L | >8 mg/L preferred |
| pH | 6.5-8.0 | 7.0-7.5 optimal |
| TAN | <0.2 mg/L | Eggs very sensitive |
| NO₂⁻ | <0.1 mg/L | Toxic to embryos |
| Chlorine | 0 mg/L | Will kill eggs |
| Flow rate | Species-specific | Prevents fungus, provides O₂ |

### Egg Disinfection

**Iodine Treatment:**
```
25-100 ppm iodine (Betadine, Argentyne)
Duration: 10-15 minutes
Timing: Immediately post-fertilization
Purpose: Kill surface bacteria and fungus
```

**Hydrogen Peroxide:**
```
100-500 ppm H₂O₂
Duration: 15 minutes
Alternative to iodine
```

## Larval Rearing

### First Feeding

**Critical Period:**
```
Yolk-sac absorption → Exogenous feeding

Point of No Return (PNR):
- Larvae must start feeding before yolk depleted
- Typically 3-7 days post-hatch (species-dependent)
- High mortality if feeding not initiated
```

**Live Feeds:**

| Feed Type | Size | Use | Production |
|-----------|------|-----|------------|
| Rotifers (Brachionus) | 100-200 μm | First feed marine larvae | Cultured on-site |
| Artemia nauplii | 400-500 μm | Second feed, freshwater/marine | Hatch from cysts |
| Copepods | 50-500 μm | Natural feed, marine | Culture complex |
| Moina | 500-1000 μm | Freshwater larvae | Simple culture |
| Daphnia | 0.5-2 mm | Larger freshwater fry | Pond culture |

**Artemia Hatching:**
```
Simple, most common live feed:

1. Seawater or 35 ppt salt solution
2. Add Artemia cysts: 1-2 g/L
3. Strong aeration (keeps cysts suspended)
4. Light continuous
5. Temperature: 26-28°C
6. Hatch time: 18-24 hours
7. Harvest nauplii, rinse, feed to larvae
```

### Larval Rearing Systems

**1. Green Water Technique:**
```
Add phytoplankton (Nannochloropsis, Chlorella) to larval tank:
- Provides food for rotifers/Artemia
- Improves water quality (O₂, nutrients)
- Reduces stress (color)
- Density: 200,000-500,000 cells/mL
```

**2. Clear Water Technique:**
```
No algae, controlled environment:
- Precise feeding control
- Better observation
- Requires excellent water quality
- More management intensive
```

### Weaning to Formulated Feeds

**Transition Protocol:**

```
Week 1: 100% live feed
Week 2: 75% live, 25% micro-pellets (100-300 μm)
Week 3: 50% live, 50% micro-pellets
Week 4: 25% live, 75% micro-pellets
Week 5: 100% formulated feed (500 μm)

Gradual size increase as larvae grow
Co-feeding period critical for transition
```

## Species-Specific Examples

### Tilapia Hatchery

**Reproduction:**
- Mouthbrooders (female holds eggs)
- Natural spawning common
- 200-2000 eggs per spawn depending on size
- 10-14 day incubation in mouth
- Swim-up fry ready to feed

**Hatchery Protocol:**
```
1. Breeding tanks: 1 male : 3 females
2. Check for holding females (distended throat)
3. Strip eggs/fry from mouth at 5-7 days
4. Transfer to nursery tanks
5. First feed: Artemia or fine powder (50-60 μm)
6. Grow to 1g in nursery (4-6 weeks)
7. Stock to grow-out
```

### Salmonid Hatchery

**Reproduction:**
- Fall/winter spawning
- Strip spawning standard
- 1,000-5,000 eggs per female
- Long incubation: 30-90 days depending on temperature

**Degree-Days:**
```
Hatching = Temperature (°C) × Days

Rainbow trout: ~300 degree-days
- 10°C = 30 days
- 5°C = 60 days

Cold water = slower development but better survival
```

## Nursery Management

### Fry to Fingerling

**Sizing and Grading:**
```
Regular grading (every 2-4 weeks):
- Size uniformity improves growth
- Reduces cannibalism
- Allows efficient feeding
- Three size groups minimum (large, medium, small)
```

**Density Management:**

| Life Stage | Density | Tank Volume |
|------------|---------|-------------|
| Larvae (0.01-0.1g) | 10,000-50,000/m³ | High density OK |
| Fry (0.1-1g) | 5,000-20,000/m³ | Start reducing |
| Fingerlings (1-10g) | 1,000-5,000/m³ | Lower density |
| Juveniles (10-50g) | 200-1,000/m³ | Approaching grow-out |

## Key Takeaways

1. **Broodstock quality determines offspring** - invest in selection
2. **Environmental cues trigger spawning** - manipulate temperature and photoperiod
3. **Hormones enable controlled spawning** - timing and planning
4. **Egg incubation requires pristine water** - maintain excellent quality
5. **Larval rearing is most challenging** - high management intensity
6. **Live feeds often necessary** - plan production systems
7. **Weaning is critical period** - gradual transition to formulated feeds
