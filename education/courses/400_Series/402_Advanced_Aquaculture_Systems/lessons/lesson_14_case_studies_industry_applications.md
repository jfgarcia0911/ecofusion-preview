## Case Study 1: Atlantic Salmon RAS - Norway

### Superior Fresh - Hixton, Wisconsin (Largest RAS in North America)

**Facility Overview:**

```
┌────────────────────────────────────────────────────┐
│         SUPERIOR FRESH SPECIFICATIONS              │
├────────────────────────────────────────────────────┤
│                                                     │
│  Location: Hixton, Wisconsin, USA                  │
│  Species: Atlantic salmon + Aquaponics vegetables  │
│  Annual capacity: 1,900 tonnes salmon              │
│  Facility size: 12 acres (indoor)                  │
│  Investment: $170 million                          │
│  Completion: 2018 (Phase 1)                        │
│                                                     │
│  KEY FEATURES:                                     │
│  • Fully recirculating system (99% reuse)          │
│  • Integrated aquaponics (10 acres vegetables)     │
│  • Pure oxygen injection                           │
│  • Advanced SCADA automation                       │
│  • Zero-discharge objective                        │
│  • Geothermal cooling                              │
│                                                     │
│  PRODUCTION PARAMETERS:                            │
│  • Stocking density: 60-80 kg/m³                   │
│  • Harvest weight: 4-5 kg                          │
│  • Growth period: 14-16 months                     │
│  • FCR: 1.1-1.2                                    │
│  • Survival: >95%                                  │
│                                                     │
│  MARKET STRATEGY:                                  │
│  • Premium fresh (never frozen)                    │
│  • Distributed within 24-48 hours                  │
│  • Direct to retailers and restaurants             │
│  • Price point: $10-12/lb ($22-26/kg)              │
│  • Brand: "Superior Fresh"                         │
│                                                     │
│  INNOVATIONS:                                      │
│  • Aquaponics integration for nutrient recovery    │
│  • Comprehensive traceability                      │
│  • Sustainable image leveraged for premium price   │
│  • Eliminated antibiotics                          │
│                                                     │
└────────────────────────────────────────────────────┘
```

**Lessons Learned:**

1. **Scale is essential** - 1,900 tonnes needed for economic viability
2. **Premium positioning** - sustainable story commands higher price
3. **Vertical integration** - aquaponics adds value, reduces waste
4. **Location matters** - near major markets (Chicago, Minneapolis)
5. **Automation critical** - manages complexity at scale

**Challenges:**

- High capital cost ($89,000 per tonne capacity)
- Long grow-out period (14-16 months)
- Complex biology (cold-water species)
- Market education needed
- Initial production delays (common for new facilities)

## Case Study 2: Tilapia RAS - Multiple Sites

### Riverence (formerly Blue Ridge Aquaculture)

**Facility: Martinsville, Virginia**

```
┌────────────────────────────────────────────────────┐
│         RIVERENCE RAS - SPECIFICATIONS             │
├────────────────────────────────────────────────────┤
│                                                     │
│  Established: 1995 (one of the oldest US RAS)      │
│  Species: Hybrid tilapia                           │
│  Annual production: 1,800 tonnes                   │
│  System volume: ~7,000 m³                          │
│                                                     │
│  TECHNOLOGY:                                       │
│  • Bead filters for solids removal                 │
│  • Trickling biofilters                            │
│  • Diffused aeration (air)                         │
│  • Automated feeding                               │
│  • Batch production (all-in, all-out)              │
│                                                     │
│  PRODUCTION SPECS:                                 │
│  • Harvest size: 800g-1.2kg                        │
│  • Growth period: 7-8 months                       │
│  • Density: 50-60 kg/m³                            │
│  • FCR: 1.4-1.6                                    │
│  • Temperature: 28-30°C                            │
│                                                     │
│  BUSINESS MODEL:                                   │
│  • Wholesale to distributors                       │
│  • Live haul for Chinese markets                   │
│  • Fresh fillets to restaurants                    │
│  • Price: $4-5/kg wholesale                        │
│                                                     │
│  SUCCESS FACTORS:                                  │
│  1. Long operational history (>25 years)           │
│  2. Continuous improvement/optimization            │
│  3. Established market channels                    │
│  4. Relatively simple species (tilapia)            │
│  5. Lower capex per tonne vs salmon                │
│                                                     │
└────────────────────────────────────────────────────┘
```

**Key Insights:**

- **Tilapia advantages:**
  - Fast growth (6-8 months vs 14-16 for salmon)
  - Warm water (easier to heat than cool)
  - Hardy species (tolerates variable conditions)
  - Omnivorous (less expensive feed)

- **Economic model:**
  - Lower selling price than salmon ($4-5 vs $20-26/kg)
  - Lower production costs offset price
  - Faster turnover improves cash flow
  - Simpler technology possible

### 2. Biofloc Technology (BFT) Integration

**Hybrid RAS-BFT Systems:**

- Biofloc = suspended bacterial aggregates
- Consume waste in water column
- Fish consume biofloc (protein source)
- Reduces external feed requirement
- Improves water quality
- Currently used for shrimp, tilapia
- Emerging for marine finfish

**Advantages:**
- Lower water exchange (<1% daily)
- In-situ waste treatment
- Supplemental nutrition
- Lower operating costs

**Disadvantages:**
- Requires careful C:N ratio management
- High aeration energy
- Risk of crashes
- Water clarity poor (monitoring challenging)

### 4. Microbial Management Technologies

**Probiotics and Beneficial Bacteria:**

- Specific bacterial strains added to system
- Outcompete pathogens
- Improve water quality
- Enhance fish immunity
- Reduce disease incidence

**Quorum Quenching:**

- Interfere with bacterial communication
- Prevent biofilm formation
- Reduce pathogenic bacteria
- Experimental stage

## Future Trends

### 1. Artificial Intelligence and Machine Learning

**Applications:**

- Predictive feeding (computer vision monitors appetite)
- Disease early detection (behavioral analysis)
- Growth forecasting
- Equipment failure prediction
- Optimal stocking and harvest scheduling
- Automated grading via imaging

**Examples:**

- XpertSea (shrimp counting and sizing AI)
- Aquabyte (computer vision for salmon farms)
- iXperion (fish behavior monitoring)

### 2. Cell-Based Seafood

**Lab-Grown Fish:**

- Cultivate fish cells in bioreactors
- No fish needed (biopsy only)
- Ultra-controlled environment
- Ethical considerations
- Regulatory pathway unclear

**Status:** Pilot products emerging, 5-10 years to market scale

**Impact on RAS:** Potential long-term competition, but RAS likely remains dominant medium-term

### 3. Modular/Containerized RAS

**Concept:**

- Complete RAS in shipping containers
- Plug-and-play systems
- Scalable (add containers)
- Transportable

**Companies:**

- Terramor (containerized systems)
- Local Coho (containerized salmon)
- Pure Salmon (modular approach)

**Advantages:**

- Lower capital entry point
- Rapid deployment
- Flexibility
- Urban location possible

**Limitations:**

- Small scale per unit
- Economics marginal
- Maintenance complexity

### Final Project: Complete RAS Facility Design

**Requirements:**

   - Target production (minimum 100 tonnes/year)

   - Monitoring protocols

   - Identify key risks
   - Mitigation strategies

   - Waste management
   - Energy efficiency

- Executive summary

## Key Takeaways from Course

### The 10 Commandments of RAS Success

1. **Scale Appropriately** - Minimum 500 tonnes for economic viability
2. **Water Quality First** - All else depends on this foundation
3. **Redundancy Everything** - Backup systems save lives and livelihoods
4. **Monitor Continuously** - Data-driven decisions beat intuition
5. **Biosecurity Always** - Prevention cheaper than cure
6. **Feed Quality Matters** - Don't compromise on nutrition
7. **Know Your Market** - Secure buyers before building
8. **Plan for Challenges** - Things will go wrong, be prepared
9. **Keep Learning** - Technology and best practices evolve
10. **Sustainable Practices** - Long-term success requires environmental stewardship
