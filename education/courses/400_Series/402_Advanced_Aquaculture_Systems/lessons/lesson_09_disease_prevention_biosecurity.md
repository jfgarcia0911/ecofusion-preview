## Biosecurity Fundamentals

### The Biosecurity Triangle

```
┌────────────────────────────────────────────────────┐
│              DISEASE OCCURRENCE                     │
│                                                     │
│              HOST (Fish)                            │
│                   /\                                │
│                  /  \                               │
│                 /    \                              │
│                /      \                             │
│               /        \                            │
│              /          \                           │
│             /   DISEASE  \                          │
│            /   TRIANGLE   \                         │
│           /                \                        │
│          /                  \                       │
│    PATHOGEN ────────────── ENVIRONMENT              │
│   (Bacteria,               (Water quality,          │
│    Virus,                   Stress,                 │
│    Parasite)                Temperature)            │
│                                                     │
│  Disease occurs when all three factors align        │
│  Biosecurity breaks any one connection              │
└────────────────────────────────────────────────────┘
```

### Biosecurity Levels

**Level 1: External Biosecurity**
- Prevent pathogen entry to facility
- Control access (people, equipment, animals)
- Water source protection
- Wild fish exclusion

**Level 2: Internal Biosecurity**
- Prevent pathogen spread between units
- Equipment sanitation
- Personnel hygiene
- System isolation

**Level 3: Individual Animal Protection**
- Vaccination
- Prophylactic treatments
- Optimal husbandry
- Stress reduction

**Personnel Protocols:**

```
┌────────────────────────────────────────────────────┐
│         FACILITY ENTRY PROCEDURE                   │
├────────────────────────────────────────────────────┤
│                                                     │
│  1. ENTRY LOG                                      │
│     Sign in, declare recent fish contact           │
│                                                     │
│  2. FOOTBATH                                       │
│     200 ppm chlorine or iodophor                   │
│     30-second minimum contact                      │
│                                                     │
│  3. HAND WASHING                                   │
│     Soap and water, 20+ seconds                    │
│                                                     │
│  4. COVERALLS/BOOTS                                │
│     Facility-specific clothing                     │
│     Clean boots for each visit                     │
│                                                     │
│  5. RESTRICTED ACCESS                              │
│     High-value areas: limited personnel            │
│     Hatchery: strictest protocols                  │
│                                                     │
└────────────────────────────────────────────────────┘
```

**Visitor Policy:**
- 48-hour fish-free period before visit
- Or use disposable coveralls/boots
- Supervised access only
- Log all visits

### Water Source Biosecurity

**Source Water Risks:**

| Source | Disease Risk | Biosecurity Measures |
|--------|--------------|----------------------|
| Municipal | Very Low | None typically needed |
| Well water | Low | Test periodically |
| Surface water (river/lake) | High | Multi-barrier treatment |
| Seawater | High | Filtration + UV + ozone |

**Treatment Barriers:**

```
Surface Water Treatment Train:

Intake screen (>100μm)
    ↓
Sand filtration (10-50μm)
    ↓
UV sterilization (40-60 mJ/cm²)
    ↓
Optional: Ozone treatment
    ↓
Storage reservoir (24hr minimum)
    ↓
To facility
```

### Quarantine Protocols

**Duration:**
- Minimum: 30 days
- Preferred: 45-60 days
- Temperature-dependent (longer for cold water)

**Monitoring:**

```
Week 1:
- Daily observation
- Baseline health assessment
- Parasite screening (skin scrape, gill biopsy)
- Behavioral assessment

Week 2-4:
- Every 2-3 days observation
- Water quality checks
- Watch for disease signs

Week 4+:
- Weekly checks
- Pre-release health certification
- Only release if 100% healthy
```

**Health Certification:**

Required tests before release:
- Bacterial culture (kidney, spleen)
- Viral screening (PCR for known pathogens)
- Parasite examination
- Physical examination (no lesions, deformities)
- Growth and feeding normal

## Common Aquaculture Diseases

### Bacterial Diseases

**1. Columnaris (Flavobacterium columnare)**

| Aspect | Details |
|--------|---------|
| **Signs** | White/gray patches on skin, fins, gills; lethargy |
| **Cause** | Gram-negative bacterium |
| **Transmission** | Water, contact, stress-induced |
| **Treatment** | Oxytetracycline (50-75 mg/kg feed for 10 days) |
| **Prevention** | Good water quality, low stress, <28°C |

**2. Motile Aeromonas Septicemia (MAS)**

| Aspect | Details |
|--------|---------|
| **Signs** | Hemorrhages on skin, fins; ulcers; exophthalmia (pop-eye) |
| **Cause** | Aeromonas hydrophila, A. sobria |
| **Transmission** | Ubiquitous in water, opportunistic |
| **Treatment** | Antibiotics (oxytetracycline, florfenicol) |
| **Prevention** | Reduce stress, optimal nutrition, avoid injuries |

**3. Streptococcosis**

| Aspect | Details |
|--------|---------|
| **Signs** | Erratic swimming, exophthalmia, hemorrhages; high mortality |
| **Cause** | Streptococcus iniae, S. agalactiae |
| **Transmission** | Horizontal (water), vertical (egg) |
| **Treatment** | Difficult; antibiotics partially effective |
| **Prevention** | Vaccination available; biosecurity critical |

### Viral Diseases

**1. Infectious Hematopoietic Necrosis (IHN) - Salmonids**

```
Characteristics:
- Highly contagious
- High mortality (up to 90% in fry)
- No treatment
- OIE-listed disease

Signs:
- Lethargy, dark coloration
- Exophthalmia
- Hemorrhages in eyes, fins
- Abdominal distension

Management:
- Depopulation of infected stock
- Facility disinfection
- Source certified IHN-free eggs
```

**2. Spring Viremia of Carp (SVC)**

```
Characteristics:
- OIE-listed
- Temperature-dependent (11-17°C)
- Reportable disease

Prevention:
- Stock from certified disease-free sources
- Quarantine rigorously
- Avoid temperature stress in spring
```

### Parasitic Diseases

**1. Ichthyophthirius multifiliis ("Ich" - White Spot)**

```
Life Cycle Understanding is Key:

Trophont (feeding stage):
- On fish, visible white spots
- Embedded in skin/gills
- Feeds 3-7 days
- Immune to treatment

        ↓ Drops off fish

Tomont (cyst on substrate):
- Divides into 100-1000 tomites
- 12-18 hours @ 25°C
- Can't be treated

        ↓ Hatches

Theront (free-swimming, infective):
- Must find host in 48 hours or dies
- VULNERABLE TO TREATMENT
- Small, invisible

        ↓ Infects fish

Back to Trophont stage
```

**Treatment Strategy:**

```
Formalin Treatment:
- 25 ppm for 1 hour (bath treatment)
- Repeat every 2-3 days
- Minimum 4 treatments
- Targets free-swimming theronts

Or

Salt Treatment:
- 3-5 ppt (parts per thousand)
- Prolonged exposure (7-14 days)
- Effective, low cost
- Not for all species (scaleless fish sensitive)

Temperature manipulation:
- Raise to 30°C (accelerates life cycle)
- Shortens treatment period
- Combined with chemical treatment
```

**2. Trichodina spp. (Ciliated Protozoan)**

```
Signs:
- Excessive mucus production
- Flashing (rubbing on surfaces)
- Respiratory distress

Treatment:
- Formalin: 25 ppm for 1 hour
- Salt: 1-3 ppt indefinitely
- Usually secondary to stress

Prevention:
- Maintain good water quality
- Avoid overcrowding
```

**3. Monogenean Flukes (Gyrodactylus, Dactylogyrus)**

```
Gyrodactylus (livebearing):
- Skin fluke
- Direct life cycle
- Rapid reproduction

Dactylogyrus (egg-laying):
- Gill fluke
- Eggs in environment

Treatment:
- Praziquantel: 10 mg/L for 3-24 hours
- Formalin: 25 ppm for 1 hour (repeat)
- Hydrogen peroxide: 100-500 ppm (15-30 min)
```

## Therapeutic Treatments

### Approved Therapeutants (USA - FDA)

| Drug | Species | Use | Withdrawal |
|------|---------|-----|------------|
| Oxytetracycline | All finfish | Bacterial infections | 21 days |
| Florfenicol | Catfish, salmonids, others | Bacterial infections | 15 days |
| Sulfadimethoxine/Ormetoprim | Salmonids, catfish | Bacterial infections | 42 days |
| Formalin | All fish | External parasites | 0 days |
| Hydrogen peroxide | Salmonids, catfish, etc. | External parasites | 0 days |
| 35% PEROX-AID | Various | Low DO emergency | 0 days |

**Critical Notes:**
- Use only approved drugs for food fish
- Follow withdrawal periods strictly
- Extra-label use illegal without VEFD
- Keep detailed treatment records

### Treatment Delivery Methods

**1. Bath Treatment**

```
Procedure:
1. Calculate treatment volume accurately
2. Mix therapeutic in small volume first
3. Distribute evenly in treatment tank
4. Monitor fish closely during treatment
5. Aerate well (many drugs reduce DO)
6. Time treatment precisely
7. Flush or neutralize after treatment

Advantages: Effective, treats external
Disadvantages: Stress, handling, water waste
```

**2. Medicated Feed**

```
Incorporation:
1. Calculate dose based on biomass and feeding rate
2. Mix drug into feed uniformly
3. Top-coat preferred (better stability)
4. Feed immediately after mixing
5. Continue for full treatment period (10-14 days typical)

Advantages: Less stress, treats internal
Disadvantages: Sick fish may not feed, water contamination
```

**3. Injection**

```
Used for:
- High-value broodstock
- Vaccination
- Individual treatment

Technique:
- Anesthetize fish first
- Intraperitoneal (IP) or intramuscular (IM)
- Aseptic technique
- Minimal volume
```

## Vaccination Programs

### Available Vaccines

**Commercial Vaccines:**

| Disease | Species | Type | Efficacy |
|---------|---------|------|----------|
| Vibriosis | Salmon, sea bass | Killed | High (75-90%) |
| Furunculosis | Salmonids | Killed | Moderate-High |
| Yersiniosis | Salmonids | Killed | Moderate |
| Streptococcosis | Tilapia, various | Killed/Live | Moderate |
| IPN (Infectious Pancreatic Necrosis) | Salmonids | Killed | Moderate |

### Vaccination Methods

**Immersion (Bath):**
```
Best for: Small fish (<10g), large numbers
Procedure:
- Dilute vaccine in water
- Immerse fish for 30-60 seconds
- Booster may be needed
Advantages: Fast, low stress
Disadvantages: Lower immune response
```

**Injection:**
```
Best for: Large fish (>50g), high-value stock
Procedure:
- Intraperitoneal injection
- 0.05-0.1 mL per fish
- Automated injectors for commercial scale
Advantages: Strong immunity, long duration
Disadvantages: Labor, stress, cost
```

**Oral:**
```
Best for: Any size, mass delivery
Procedure:
- Incorporate vaccine into feed
- Feed for 7-14 days
Advantages: No handling stress
Disadvantages: Variable uptake, efficacy uncertain
```

## Health Monitoring Program

### Daily Observations

**Critical Signs:**

```
BEHAVIOR:
- Lethargy or hyperactivity
- Abnormal swimming (spiraling, surface gasping)
- Isolation from school
- Loss of equilibrium
- Reduced feeding response

EXTERNAL:
- Color changes (darkening, lightening)
- Hemorrhages (red spots)
- Lesions or ulcers
- Fin erosion
- Mucus excess or absence
- Exophthalmia (pop-eye)

ENVIRONMENTAL:
- Dead/moribund fish
- Foam on surface
- Off-odor
- Water discoloration
```

### Necropsy Protocol

**When to Perform:**
- Unexplained mortality
- Disease investigation
- Routine monitoring (monthly sampling)

**Procedure:**

```
External Examination:
- Body condition, weight/length
- Skin: lesions, hemorrhages, parasites
- Fins: condition, erosion
- Gills: color, mucus, parasites
- Eyes: exophthalmia, opacity

Internal Examination:
- Liver: color, size, texture
- Spleen: size, color
- Kidney: swelling, granulomas
- Intestine: contents, inflammation
- Swim bladder: gas, inflammation
- Heart: hemorrhages

Sample Collection:
- Kidney/spleen: bacterial culture
- Tissues: histopathology (10% formalin)
- Tissues: viral PCR (frozen or RNAlater)
- Parasites: wet mount microscopy
```

## Emergency Response Protocols

### Disease Outbreak Response

```
PHASE 1: IMMEDIATE (0-24 hours)
- Stop feeding
- Increase monitoring to 2-4× daily
- Sample sick/dead fish (necropsy)
- Increase water exchange if possible
- Check water quality thoroughly
- Isolate affected tanks if possible

PHASE 2: DIAGNOSIS (24-72 hours)
- Submit samples to diagnostic lab
- Begin presumptive treatment if indicated
- Increase biosecurity (prevent spread)
- Notify regulatory authorities if required
- Document all findings and actions

PHASE 3: TREATMENT (Ongoing)
- Follow diagnostic lab recommendations
- Implement treatment protocol
- Monitor efficacy
- Adjust as needed

PHASE 4: RECOVERY
- Gradual return to normal feeding
- Continue monitoring
- Investigate root cause
- Implement preventive measures
```

## Biosecurity Best Practices Summary

**Top 10 Rules:**

1. **All-in, all-out stocking** - don't mix cohorts
2. **Quarantine all new stock** - no exceptions
3. **Disinfect equipment between tanks** - dedicated or sanitized
4. **Control human traffic** - footbaths, clothing changes
5. **Source water treatment** - appropriate for risk level
6. **Maintain optimal water quality** - stressed fish = disease
7. **Avoid overstocking** - density within limits
8. **Proper nutrition** - immune system support
9. **Vaccination when available** - prevention cheaper than treatment
10. **Rapid response** - early detection, quick action

---

## Key Takeaways

1. **Prevention is cheaper than cure** - invest in biosecurity
2. **Disease triangle concept** - break any leg to prevent disease
3. **Quarantine is non-negotiable** - 30-60 days minimum
4. **Know your enemy** - understand disease signs and cycles
5. **Treatment options limited** - few approved drugs for food fish
6. **Vaccination works** - use when available
7. **Water quality underpins health** - stress enables disease
8. **Early detection critical** - daily observations save lives
