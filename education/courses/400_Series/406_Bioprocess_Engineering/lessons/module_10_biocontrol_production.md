## 10.2 Bacterial Biocontrol Production

### Bacillus thuringiensis (Bt)

**Production Process:**

```
Organism: B. thuringiensis (various subspecies/strains)

Fermentation:
- Fermenter: 10,000-100,000 L
- Medium: Soybean meal, yeast extract, salts
- Temperature: 28-30°C
- pH: 7.0-7.2
- DO: >30% saturation
- Agitation: 200-400 RPM
- Duration: 36-72 hours

Growth phases:
1. Vegetative growth (24-36 h)
2. Sporulation + crystal protein formation (12-36 h)

Endpoint: >90% sporulation, maximum crystal protein

Harvest density: 10¹⁰-10¹¹ spores/mL
Crystal protein: 1-3 g/L (Cry toxins)
```

**Downstream Processing:**

```
1. Fermentation broth concentration (optional)
2. Additives:
   - UV protectants (lignin, molasses)
   - Stickers (xanthan gum, clay)
   - Stabilizers

3. Spray drying:
   - Inlet temp: 180-200°C
   - Outlet temp: 90-110°C
   - Product moisture: <5%

4. Milling and packaging

Final product:
- Spore count: 10¹⁰-10¹² spores/g
- Potency: 10,000-50,000 IU/mg
- Shelf life: 2-3 years (refrigerated)
```

### Bacillus subtilis (Biofungicide)

```
Advantages over Bt:
- Broader mode of action (antibiosis, competition, ISR)
- Longer shelf life
- Easier formulation

Production conditions:
- Similar to Bt but no sporulation requirement
- Harvest during late exponential phase
- Cell concentration: 10⁹-10¹⁰ CFU/mL

Key metabolites:
- Lipopeptides (surfactin, iturin, fengycin)
- Antibiotics (bacillomycin, mycosubtilin)

Formulation:
- Wettable powder: 10¹⁰ CFU/g
- Liquid suspension: 10⁹ CFU/mL
- Granules: 10⁸-10⁹ CFU/g
```

## 10.3 Fungal Biocontrol Production

### Trichoderma Species

**Solid-State Fermentation (Preferred):**

```
Substrate: Rice, wheat bran, or composted materials
Inoculum: 10⁶-10⁷ spores/g substrate
Moisture: 50-60%
Temperature: 25-28°C
pH: 5.0-6.0
Duration: 7-14 days

Spore yield: 10⁹-10¹⁰ spores/g dry substrate

Harvest:
- Dry at 30-35°C (maintain viability)
- Mill to <250 μm
- Sieve to remove large particles

Product specifications:
- Spore concentration: 10⁸-10⁹ spores/g
- Viability: >80%
- Moisture: <8%
- Shelf life: 12-18 months (room temperature)
```

**Submerged Fermentation (Alternative):**

```
Medium: Glucose, peptone, mineral salts
Conditions:
- Temperature: 25-28°C
- pH: 5.5-6.5
- Agitation: 150-250 RPM
- Aeration: 0.5-1.0 VVM
- Duration: 5-7 days

Biomass concentration: 10-20 g/L
Spore concentration: 10⁷-10⁸ spores/mL

Recovery:
- Centrifugation or filtration
- Wash biomass
- Resuspend in formulation buffer or dry
```

### Beauveria bassiana (Entomopathogenic Fungus)

```
Challenges:
- Sensitive to environmental stress
- Requires high humidity for infection
- UV sensitive

Production (SSF):
- Substrate: Barley, rice
- Temperature: 24-26°C
- Humidity: 80-90%
- Duration: 10-15 days

Yield: 10⁹-10¹⁰ conidia/g substrate

Formulation requirements:
- Oil-based (better UV protection)
- Emulsifiable concentrate
- Adjuvants for spreading and adhesion

Application:
- Spray to foliage
- Best in evening (high humidity)
- Repeated applications (7-14 day intervals)
```

## 10.4 Quality Control

### Viability and Potency

```
Spore/Cell Viability:
Method: Plate count (serial dilution)
Acceptable: >80% of label claim
Test frequency: Every batch

Germination Test:
- Incubate on agar medium (specific conditions)
- Count germinated spores after 24-48 hours
- Target: >80% germination

Bioassay (Potency):
- In vivo test with target pest/pathogen
- Measure mortality or disease suppression
- Express as LC₅₀ or ED₅₀
- Compare to reference standard
```

### Contaminants

```
Microbial contamination:
- Total aerobic count: <10⁵ CFU/g (other microbes)
- E. coli: Absent in 1 g
- Salmonella: Absent in 25 g

Quality control release criteria:
✓ Potency: ≥90% of label
✓ Viability: ≥80%
✓ Moisture: ≤10% (dry products)
✓ pH: Within specification (±0.5)
✓ Contaminants: Below limits
✓ Appearance: No off-color, odor, caking
```

## 10.5 Formulation and Stability

### Formulation Types

```
Wettable Powder (WP):
Components:
- Active ingredient: 10-50%
- Dispersing agents: 3-10% (lignosulfonate, surfactants)
- Fillers: 40-87% (kaolin, talc)
- Wetting agents: 0.5-2%

Advantages: Long shelf life, easy storage/transport
Disadvantages: Dust generation, mixing required

Liquid Concentrate (SC):
Components:
- Active ingredient: 10-40%
- Suspending agents: 2-8% (xanthan gum, CMC)
- Antifreeze: 5-10% (glycerol, propylene glycol)
- Preservatives: 0.1-0.5%
- Water: Balance

Advantages: Easy application, no dust
Disadvantages: Shorter shelf life, requires preservatives

Oil Dispersion (OD):
Components:
- Active ingredient: 10-30%
- Vegetable oil: 60-80%
- Emulsifiers: 5-10%

Advantages: UV protection, better rain-fastness
Disadvantages: Cost, application equipment considerations
```

### Shelf Life Extension

```
Strategies:

1. Reduced moisture (<5% for dry products)
   - Spray drying
   - Desiccant packaging

2. Low temperature storage (4-10°C)
   - Extends shelf life 2-3×
   - Not always practical for distribution

3. Protective additives
   - UV protectants (lignin, melanin)
   - Antioxidants (ascorbic acid, BHT)
   - Osmoprotectants (trehalose, glycerol)

4. Microencapsulation
   - Alginate beads
   - Spray-dried microspheres
   - Protects from environmental stress

Expected shelf life:
- Bacterial spores (Bacillus): 2-3 years
- Fungal spores (Trichoderma): 12-18 months
- Vegetative bacteria: 6-12 months
- Sensitive fungi (Beauveria): 6-12 months

Testing: Accelerated aging at 35-40°C (3 months = 1 year at 20°C)
```

## 10.6 Regulatory Requirements

### Registration Process

```
United States (EPA regulation):

Biopesticides exempt from registration (25(b) list):
- Some Bacillus species
- Specific essential oils
- Minimal data requirements

Non-exempt biopesticides (requires full registration):
- Extensive testing required
- Cost: $500,000-3,000,000
- Timeline: 3-7 years

Required studies:
✓ Product characterization
✓ Toxicology (acute, subchronic)
✓ Allergenicity testing
✓ Non-target organism effects
✓ Environmental fate
✓ Efficacy data
✓ Residue analysis (if applicable)
```

### Good Manufacturing Practices (GMP)

```
Requirements for biocontrol production:

Facility:
- Dedicated production areas (no cross-contamination)
- Environmental monitoring (air quality, surfaces)
- Pest control program
- Water quality testing

Process:
- Validated fermentation process
- In-process testing (pH, temperature, DO)
- Batch records (complete documentation)
- Deviation tracking

Quality:
- Quarantine of raw materials and finished products
- Testing before release
- Stability program
- Complaint investigation

Personnel:
- Training programs
- Health monitoring
- Hygiene protocols
```
