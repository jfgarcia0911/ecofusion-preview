# Lesson 9: Tissue Culture and Micropropagation

## Learning Objectives

- Understand principles of plant tissue culture and totipotency
- Implement micropropagation techniques for rapid plant multiplication
- Apply somatic embryogenesis for clonal propagation
- Use doubled haploid production for breeding acceleration
- Perform virus elimination through meristem culture
- Recognize applications of genetic transformation basics

## Introduction

Tissue culture techniques enable rapid multiplication of elite genotypes, virus elimination, doubled haploid production, and genetic transformation. These tools accelerate breeding programs and ensure delivery of disease-free, uniform planting material critical for CEA operations.

## 1. Principles of Plant Tissue Culture

### 1.1 Totipotency

**Concept:**
```
Every living plant cell contains complete genetic information to regenerate whole plant

Totipotency: Ability of single cell to develop into complete organism

Enables:
- Cloning from small tissue pieces
- Regeneration from callus
- Somatic embryogenesis
- Protoplast culture
```

### 1.2 Dedifferentiation and Redifferentiation

**Process:**
```
Differentiated cell (leaf, root)
         ↓
    Dedifferentiation (callus formation)
         ↓
    Undifferentiated callus cells
         ↓
    Redifferentiation (organ formation)
         ↓
    Organized structures (shoots, roots, embryos)
         ↓
    Complete plant
```

### 1.3 Plant Growth Regulators

**Auxins:**
```
Examples: NAA, IAA, 2,4-D, IBA
Functions:
- Cell division and elongation
- Callus induction
- Root formation
- Somatic embryogenesis (2,4-D)

Typical concentrations: 0.1-10 mg/L
```

**Cytokinins:**
```
Examples: BAP, Kinetin, Zeatin, TDZ
Functions:
- Shoot formation
- Axillary bud proliferation
- Delays senescence
- Cell division

Typical concentrations: 0.1-5 mg/L
```

**Auxin:Cytokinin Ratio:**
```
High Auxin:Cytokinin → Root formation
Balanced → Callus formation
High Cytokinin:Auxin → Shoot formation

Skoog and Miller model:
- 10:1 (A:C) = Roots
- 1:1 = Callus
- 1:10 = Shoots
```

**Other Growth Regulators:**
- Gibberellins (GA₃): Stem elongation
- Abscisic acid (ABA): Embryo maturation
- Ethylene inhibitors (AgNO₃, AVG): Reduce stress

### 1.4 Culture Media

**Components:**
```
Macronutrients (high concentration):
- N, P, K, Ca, Mg, S

Micronutrients (trace elements):
- Fe, Mn, Zn, Cu, B, Mo, Co

Carbon source:
- Sucrose (20-30 g/L typical)
- Glucose (alternative)

Vitamins:
- Thiamine (B1): Essential
- Myo-inositol
- Nicotinic acid, Pyridoxine

pH: 5.6-5.8
Solidifying agent: Agar or gellan gum (for solid media)
```

**Common Formulations:**
```
MS (Murashige and Skoog): Most widely used
  - High salts
  - Suitable for many species

B5 (Gamborg's): Lower salts
  - Good for dicots, callus

WPM (Woody Plant Medium): Lower salts
  - Designed for woody species

SH (Schenk and Hildebrandt): Moderate salts
  - Callus and suspension cultures
```

## 2. Micropropagation Techniques

### 2.1 Stages of Micropropagation

**Stage 0: Mother Plant Preparation**
```
- Select healthy, disease-free plant
- Pre-treat if needed (low light, pesticides)
- Prepare for explant harvest
```

**Stage I: Establishment**
```
- Surface sterilization
- Explant excision
- Initial culture
- Contamination check

Protocol example (lettuce):
1. Rinse explants with tap water
2. 70% ethanol for 30 seconds
3. 10% bleach (0.5% NaOCl) for 10 minutes
4. Rinse 3× with sterile water
5. Transfer to culture medium
```

**Stage II: Multiplication**
```
- Rapid shoot proliferation
- Subculture every 3-4 weeks
- Exponential multiplication

Typical multiplication rates:
Lettuce: 5-8× per cycle
Strawberry: 4-6× per cycle
Basil: 6-10× per cycle

After 6 cycles: 15,625 to 1,000,000 plants from single explant
```

**Stage III: Rooting**
```
- Transfer shoots to rooting medium
- Lower cytokinin, add auxin (IBA common)
- 2-4 weeks for root development
```

**Stage IV: Acclimatization**
```
- Transfer to greenhouse
- Gradual reduction of humidity
- Hardening off period
- 1-2 weeks to full acclimatization

Survival rates: 80-95% typical for well-established protocols
```

### 2.2 Shoot Tip Culture

**Procedure:**
```
Explant: Apical meristem + 2-3 leaf primordia (1-2 mm)

Medium: MS + BAP (1-3 mg/L) + low auxin

Development:
- Axillary buds activated
- Multiple shoots form
- Subcultureperiodically
- Transfer to rooting medium

Advantages:
- Maintains genetic fidelity
- Virus elimination (if meristem small enough)
- Rapid multiplication
```

### 2.3 Node Culture

**Procedure:**
```
Explant: Single node with axillary bud

Medium: Similar to shoot tip protocol

Development:
- Axillary bud grows
- Cut into nodes again
- Repeat

Advantages:
- Simple
- Reliable
- Good for woody plants
```

### 2.4 Callus Culture

**Induction:**
```
Explant: Leaf, stem, root segment

Medium: MS + 2,4-D (1-2 mg/L) + BAP (0.5 mg/L)

Result:
- Undifferentiated cell mass (callus)
- Transfer to regeneration medium

Organogenesis:
- Shoots from callus
- Roots from callus
- Eventually complete plants

Disadvantages:
- Somaclonal variation risk
- Slower than shoot culture
- Genetic instability possible
```

## 3. Somatic Embryogenesis

### 3.1 Concept and Process

**Somatic Embryo:**
```
Embryo-like structure from somatic cell
Bipolar (shoot and root pole)
Develops through similar stages as zygotic embryo
```

**Stages:**
```
Globular → Heart → Torpedo → Cotyledonary → Mature

Advantages over organogenesis:
- Bipolar (has root)
- No need for separate rooting
- Can be encapsulated (synthetic seeds)
- High multiplication rates
```

### 3.2 Protocol Example: Lettuce

**Induction:**
```
Medium: MS + 2,4-D (2 mg/L) + BAP (0.5 mg/L)
Explant: Young leaf tissue
Duration: 3-4 weeks
Result: Embryogenic callus
```

**Maturation:**
```
Transfer embryogenic callus to:
MS + ABA (1-2 mg/L) + reduced sucrose
Duration: 4-6 weeks
Result: Mature somatic embryos
```

**Germination:**
```
Transfer to hormone-free medium
Light exposure
Embryos germinate and develop into plantlets
```

### 3.3 Applications in Breeding

**Mass Propagation:**
- 1 gram callus → thousands of embryos
- Bioreactor scale-up possible
- Automated systems (embryo production lines)

**Artificial Seeds:**
- Encapsulate embryos in gel (alginate)
- Direct sowing
- Storage potential
- Delivery system for elite genotypes

**Cryopreservation:**
- Freeze embryogenic cultures in liquid N₂
- Long-term storage
- Germplasm preservation

## 4. Doubled Haploid Production

### 4.1 Principle and Advantages

**Haploid → Doubled Haploid:**
```
F1 hybrid
    ↓
Haploid induction (anther/microspore culture)
    ↓
Haploid plant (n)
    ↓
Chromosome doubling (colchicine)
    ↓
Doubled Haploid (2n, 100% homozygous)

Advantages:
- Immediate homozygosity (vs. 7-8 gen of selfing)
- Time savings: 2-3 years vs. 7-8 years
- All genetic variation from F1 preserved
- No selection during inbreeding phase
```

### 4.2 Anther Culture

**Procedure:**
```
1. Collect flower buds at correct stage
   - Microspores at uninucleate stage
   - Visualize by acetocarmine staining

2. Surface sterilize buds

3. Excise anthers aseptically

4. Place anthers on induction medium
   - MS modified + 2,4-D + kinetin
   - Cold pre-treatment (4°C, 3-7 days)

5. Incubate in dark (28°C)

6. Embryos/callus develop from microspores

7. Transfer to regeneration medium

8. Regenerate haploid plants

9. Chromosome doubling
   - Colchicine treatment (0.1-0.5%, 24-48h)
   - Spontaneous doubling in some cases

10. DH plants
```

### 4.3 Microspore Culture

**Isolated Microspore Culture:**
```
More efficient than anther culture
1. Collect anthers
2. Crush and filter to isolate microspores
3. Culture microspores in liquid medium
4. Embryos develop from microspores
5. Transfer to solid medium for regeneration

Advantages:
- Higher efficiency
- Better control
- Scaling possible

Disadvantages:
- More technical skill required
- Species/genotype dependent
```

### 4.4 Application to CEA Breeding

**Example: Lettuce DH Production**

```
Year 1:
Cross: Elite A × Elite B → F1 hybrid

Year 2:
Flower induction of F1
Anther culture → Haploids
Chromosome doubling → 200 DH lines

Year 3:
Field/CEA trials of 200 DH lines
Selection of 10 best
Advanced testing

Year 4:
Final selection (2-3 lines)
Seed increase, release

Total: 4 years vs. 10+ years traditional
```

**Success Rates:**
```
Highly genotype-dependent

Lettuce: Moderate (10-20 embryos per 100 anthers)
Tomato: Difficult (low efficiency)
Brassicas: Excellent (>50%)
Barley/wheat: Good protocols available

Recalcitrant species:
- Use gynogenesis
- Hybridization with haploid inducer
- Molecular approaches to enhance embryogenesis
```

## 5. Meristem Culture and Virus Elimination

### 5.1 Virus Distribution in Plant

**Concentration Gradient:**
```
High virus load:
- Mature leaves
- Roots
- Stems

Low or no virus:
- Apical meristem (0.1-0.3 mm)
- Rapidly dividing cells
- Virus replication can't keep pace

Principle: Excise virus-free meristem, regenerate clean plant
```

### 5.2 Meristem Culture Protocol

**Procedure:**
```
1. Select infected but vigorous plant

2. Surface sterilize shoot tip

3. Dissect under microscope
   - Remove leaf primordia
   - Excise meristem dome (0.2-0.5 mm)

4. Culture on MS medium
   - Often + GA₃ for elongation
   - Low growth regulators

5. Slow growth (small explant)

6. After 4-8 weeks, shoots emerge

7. Test for virus (ELISA, PCR)

8. Multiply virus-free clones
```

### 5.3 Thermotherapy Enhancement

**Combined Approach:**
```
Heat treatment + meristem culture
= Higher success rate

Protocol:
1. Grow infected plant at 37-40°C for 2-4 weeks
   - Inhibits virus replication
   - Plant grows slowly but survives

2. Excise meristem immediately after heat

3. Culture as above

4. Test for virus

Success rates increase from 40-60% to 70-90%
```

### 5.4 Importance for CEA

**Certification Programs:**
```
CEA requires:
- Certified, virus-free planting material
- Consistent performance
- High health status

Strawberry example:
- Multiple viruses common (SVBV, SMoV, etc.)
- Reduce yield 20-70%
- Meristem culture produces clean stock
- Certified plants for CEA production
```

## 6. Protoplast Culture and Somatic Hybridization

### 6.1 Protoplast Isolation

**Process:**
```
1. Enzyme treatment of leaf tissue
   - Cellulase (cell wall digestion)
   - Pectinase (middle lamella)
   - 4-16 hours, 28°C

2. Release of protoplasts (naked cells)

3. Purification
   - Filtration
   - Density gradient centrifugation

4. Culture in specialized medium
   - High osmoticum (mannitol, sorbitol)
   - Protects naked cells

5. Cell wall regeneration (48-72 hours)

6. Cell division

7. Callus formation

8. Regeneration to plants
```

### 6.2 Somatic Hybridization

**Protoplast Fusion:**
```
Combine protoplasts from two species
Induce fusion:
- PEG (polyethylene glycol)
- Electrofusion

Result: Hybrid cell with chromosomes from both parents

Applications:
- Overcome sexual incompatibility
- Transfer traits between species
- Create novel combinations

Example: Brassica cybrids (cybrid = cytoplasmic hybrid)
- CMS transfer
```

### 6.3 Applications in CEA

**Limited Current Use:**
- Technically demanding
- Low efficiency in many species
- Regulation issues (some consider GMO)

**Future Potential:**
- Trait transfer from wild relatives
- Disease resistance
- Stress tolerance
- When conventional breeding fails

## 7. Genetic Transformation Basics

### 7.1 Overview

**Definition:**
Introduction of foreign DNA into plant genome

**Methods:**
- Agrobacterium-mediated
- Biolistics (gene gun)
- Electroporation
- PEG-mediated

**Note:** Detailed regulation and methods beyond scope; overview only

### 7.2 Agrobacterium-mediated Transformation

**Process:**
```
1. Clone gene of interest into binary vector

2. Transform Agrobacterium with vector

3. Co-culture plant tissue with Agrobacterium
   - T-DNA transfer into plant cells

4. Select transformed cells (antibiotic resistance)

5. Regenerate plants

6. Verify gene integration (PCR, Southern blot)

7. Test for trait expression

Widely used for dicots (tomato, lettuce)
```

### 7.3 Trait Examples

**Potential CEA Applications:**
- Herbicide resistance (unlikely needed in CEA)
- Disease resistance genes
- Nutritional enhancement
- Flowering time modification
- Enhanced photosynthetic efficiency

**Regulatory Landscape:**
- GMOs heavily regulated
- Consumer acceptance issues
- Gene-edited crops (separate category)

## 8. Somaclonal Variation

### 8.1 Phenomenon

**Definition:**
Genetic/epigenetic variation arising in tissue culture

**Causes:**
- Chromosome number changes (polyploidy, aneuploidy)
- Chromosome structural changes
- Point mutations
- DNA methylation changes
- Transposon activation

**Frequency:**
Higher with:
- Callus phase (vs. direct regeneration)
- Long culture duration
- High growth regulator levels
- 2,4-D especially problematic

### 8.2 Detection

**Cytological:**
- Karyotyping
- Flow cytometry (ploidy)

**Molecular:**
- Microsatellite markers
- RAPD, AFLP
- Sequencing

**Phenotypic:**
- Off-types in field
- Trait variation

### 8.3 Managing Somaclonal Variation

**Minimize Unwanted Variation:**
```
- Use direct regeneration (avoid callus)
- Short culture duration
- Low growth regulator concentrations
- Shoot tip culture preferred
- Minimize subcultures
```

**Exploit for Breeding:**
```
- Induce variation deliberately
- Screen large populations
- Select novel variants
- Example: Banana somaclones with disease resistance
```

## 9. Practical Applications in CEA

### 9.1 Strawberry Micropropagation

**Commercial Protocol:**
```
Stage I: Runner tip explants, MS + BAP (1 mg/L)
Stage II: Multiplication, MS + BAP (0.5 mg/L), 4-week cycle
         6-8 shoots per explant per cycle
Stage III: Rooting, MS + IBA (0.5 mg/L), 3 weeks
Stage IV: Acclimatization, greenhouse, 2 weeks

Output: 10,000 plants from 1 mother plant in 6 months

Cost: $0.30-0.50 per plant
vs. Field runners: $0.20 but disease risk

Benefit: Virus-free, uniform, year-round production
```

### 9.2 Basil Breeding Support

**Applications:**
```
1. Rapid multiplication of elite selections
2. International distribution (tissue culture shippable)
3. Hybrid seed parent maintenance
4. Germplasm preservation (slow growth storage)
5. Potential DH production (under development)
```

## Summary

Tissue culture techniques provide powerful tools for CEA breeding:

1. **Micropropagation**: Rapid clonal multiplication
2. **Somatic Embryogenesis**: High-throughput regeneration
3. **Doubled Haploids**: Accelerate inbred line development
4. **Meristem Culture**: Virus elimination
5. **Protoplast Culture**: Somatic hybridization potential
6. **Transformation**: Gene introduction (regulated)

These technologies complement conventional breeding and accelerate variety development for CEA systems.

## Key Takeaways

- Totipotency enables regeneration from single cells
- Auxin:cytokinin ratio controls organogenesis
- Micropropagation enables exponential multiplication
- DHs provide immediate homozygosity for breeding
- Meristem culture produces virus-free plants critical for CEA
- Somaclonal variation is concern but also opportunity
- Protocols are species and genotype-specific
- Tissue culture requires sterile technique and specialized facilities
