# Module 11: Construction Management & Site Coordination

## Learning Objectives

- Plan and execute construction activities safely and efficiently
- Coordinate multi-trade activities and resolve conflicts
- Manage site logistics, safety, and quality control
- Handle RFIs and field changes effectively
- Monitor construction progress and manage punch lists

---

## 1. Construction Execution Planning

### Construction Sequencing

```
TYPICAL CEA FACILITY CONSTRUCTION SEQUENCE
+===================================================================+
| PHASE 1: SITE PREPARATION (4-6 weeks)                             |
| - Mobilization and site setup                                     |

| - Rough grading and erosion control                               |

| - Site concrete (paving, walks, loading areas)                    |

| - Roof structure and decking                                      |

| - Exterior wall systems                                           |
| - Doors and loading docks                                         |
| - Windows (if applicable)                                         |
|                                                                   |
| PHASE 4: MEP ROUGH-IN (14-18 weeks)                               |
| - Electrical service and distribution                             |
| - Plumbing rough-in                                               |
| - HVAC ductwork and piping                                        |

| - Low-voltage infrastructure (data, controls)                     |

|                                                                   |
| PHASE 5: INTERIOR CONSTRUCTION (8-12 weeks)                       |
| - Interior framing and partitions                                 |
| - Drywall and finishing                                           |
| - Flooring systems                                                |
| - Interior doors and hardware                                     |

|                                                                   |
| PHASE 6: EQUIPMENT INSTALLATION (12-16 weeks)                     |

| - LED lighting fixtures and controls                              |
| - Irrigation/fertigation systems                                  |
| - Processing/packaging equipment                                  |
| *Critical path - long lead equipment*                             |
|                                                                   |

| - BMS/SCADA installation and programming                          |
| - Sensor installation and calibration                             |
| - Electrical terminations and testing                             |
| - Final finishes and trim                                         |
| - Site landscaping                                                |
|                                                                   |
| PHASE 8: COMMISSIONING & STARTUP (6-10 weeks)                     |
| - Pre-functional testing                                          |
| - Factory/site acceptance testing                                 |
| - Integrated systems testing                                      |
| - Performance validation                                          |
| - Training                                                        |
| - Punch list completion                                           |
|                                                                   |
| TOTAL DURATION: 18-24 months (with overlaps)                      |
+===================================================================+
```

## 2. Site Logistics & Safety

### Site Safety Management

```
CONSTRUCTION SAFETY PROGRAM
+===================================================================+
| 1. PRE-CONSTRUCTION SAFETY PLANNING                               |
| - Site-specific safety plan                                       |
| - Hazard identification and mitigation                            |
| - Emergency response procedures                                   |
| - Safety equipment and PPE requirements                           |
|                                                                   |
| 2. DAILY SAFETY PRACTICES                                         |
| - Daily safety huddle (all trades, 15 min)                        |
| - Job hazard analysis (JHA) for high-risk tasks                   |
| - Toolbox talks (weekly safety topics)                            |
| - Safety inspections (daily walk-throughs)                        |
|                                                                   |
| 3. HIGH-RISK ACTIVITIES IN CEA CONSTRUCTION                       |
| - Elevated work (racking installation, lighting)                  |
| - Confined spaces (tanks, underground utilities)                  |
| - Heavy rigging (chillers, air handlers)                          |
| - Electrical work (high voltage connections)                      |
| - Hot work (welding, cutting)                                     |
|                                                                   |
| 4. INCIDENT MANAGEMENT                                            |
| - First aid and emergency response                                |
| - Incident reporting (within 24 hours)                            |
| - Root cause investigation                                        |
| - Corrective action implementation                                |
| - Lessons learned documentation                                   |
|                                                                   |
| 5. SAFETY METRICS (Track Weekly)                                  |
| - Total man-hours worked                                          |
| - Recordable incidents (OSHA)                                     |
| - Lost-time incidents                                             |
| - Near-miss reports (leading indicator)                           |
| - Safety observations/interventions                               |
| - Target: Zero recordable incidents                               |
+===================================================================+
```

## 3. Progress Monitoring & Control

### Weekly Progress Meetings

```
WEEKLY CONSTRUCTION PROGRESS MEETING AGENDA
+===================================================================+
| TIME: Wednesdays, 9:00 AM (90 minutes)                            |
| LOCATION: On-site job trailer                                     |
| ATTENDEES: PM, GC Super, Trade Foremen, Owner's Rep, Inspectors   |
+===================================================================+

9:00-9:15   SAFETY REPORT
            - Incidents/near-misses from past week
            - Safety concerns for upcoming week
            - High-risk activities planned

9:15-9:30   SCHEDULE UPDATE
            - Progress vs. baseline (2-week lookahead)
            - Milestones achieved
            - Delays and recovery plans
            - Critical path status

9:30-9:45   QUALITY & INSPECTIONS
            - Inspections completed/pending
            - Test results
            - Non-conformances and resolutions
            - Upcoming quality hold points

9:45-10:00  COORDINATION & CONFLICTS
            - Trade stacking and sequencing
            - Access/laydown area conflicts
            - Utility shutdowns required
            - Delivery schedules

10:00-10:15 RFIs & SUBMITTALS
            - Outstanding RFIs (status, priority)
            - Submittal approvals needed
            - Design clarifications required

10:15-10:25 CHANGE ORDERS & COST
            - Pending change orders
            - Budget status
            - Payment applications

10:25-10:30 LOOKAHEAD & ACTION ITEMS
            - Next 2 weeks critical activities
            - Owner decisions needed
            - Long-lead procurement status
            - Assign action items with due dates
+===================================================================+
```

## 4. RFI Management

### RFI Process

```
REQUEST FOR INFORMATION (RFI) WORKFLOW
+===================================================================+
|                                                                   |
| CONTRACTOR identifies issue/conflict/unclear detail               |
|        ↓                                                           |
| Submit RFI (numbered, with drawings/photos/description)           |
|        ↓                                                           |
| PROJECT MANAGER logs and assigns to appropriate party             |
| - Design: To Architect/Engineer                                   |
| - Specification: To spec writer                                   |
| - Owner decision: To Owner's Rep                                  |
| - Schedule/coordination: PM resolves                              |
|        ↓                                                           |
| RESPONSIBLE PARTY investigates and drafts response                |
| - Review contract documents                                       |
| - Consult with team if needed                                     |
| - Determine cost/schedule impact                                  |
| - Prepare response (clear, complete, documented)                  |
|        ↓                                                           |
| PM reviews response for completeness                              |
|        ↓                                                           |
| DISTRIBUTE response to contractor and team                        |
|        ↓                                                           |
| CONTRACTOR implements and acknowledges                            |
|        ↓                                                           |
| CLOSE RFI in tracking log                                         |
|                                                                   |
+===================================================================+

RFI RESPONSE TIME TARGETS:
- Critical path impact: 2 business days
- Standard: 5 business days
- Complex/non-critical: 10 business days
```

## 5. Punch List Management

### Punch List Process

```
PUNCH LIST MANAGEMENT
+===================================================================+
| DEFINITION: List of incomplete or deficient work items identified |
| near project completion that must be corrected before final       |
| acceptance and payment.                                           |
+===================================================================+

PUNCH LIST DEVELOPMENT:
+-------------------------------------------------------------------+
| PHASE 1: PRE-PUNCH (90% Complete)                                 |
| - Contractor self-inspection                                      |
| - Trade-by-trade walkthrough                                      |
| - Identify and correct obvious deficiencies                       |
| - Reduces formal punch list length                                |
|                                                                   |
| PHASE 2: FORMAL PUNCH WALK (95% Complete)                         |
| - Owner, PM, Architect, Contractor                                |
| - Systematic room-by-room inspection                              |
| - Document all deficiencies (photos, descriptions)                |
| - Categorize items (critical vs. minor)                           |
|                                                                   |
| PHASE 3: PUNCH LIST EXECUTION                                     |
| - Contractor addresses items by priority                          |
| - Weekly status updates                                           |
| - PM verifies completion                                          |
| - Re-inspect corrected work                                       |
|                                                                   |
| PHASE 4: FINAL INSPECTION                                         |
| - Verify 100% completion                                          |
| - Issue Certificate of Substantial Completion                     |
| - Release final payment (less retainage for any open items)       |
+-------------------------------------------------------------------+

PUNCH LIST ITEM CATEGORIES:
+-------------------------------------------------------------------+
| CATEGORY A - CRITICAL (Prevents occupancy or system operation)    |
| - Safety hazards                                                  |
| - Code violations                                                 |
| - Systems not functional                                          |
| - Missing/inoperable equipment                                    |
| TIMELINE: Correct before Substantial Completion                   |
|                                                                   |
| CATEGORY B - MAJOR (Significant deficiency)                       |
| - Visible damage or defects                                       |
| - Performance below specification                                 |
| - Incomplete work affecting usability                             |
| TIMELINE: Correct within 30 days of Substantial Completion        |
|                                                                   |
| CATEGORY C - MINOR (Cosmetic or minor deficiency)                 |
| - Paint touch-up                                                  |
| - Minor scratches/dents                                           |
| - Trim gaps or alignment                                          |
| - Missing labels                                                  |
| TIMELINE: Correct within 60 days or before warranty expires       |
+-------------------------------------------------------------------+

SAMPLE PUNCH LIST ITEMS (CEA Facility):
+-------------------------------------------------------------------+
| Item | Location      | Description          | Category | Status   |
+======+===============+======================+==========+==========+
| 001  | Growing Zone 2| LED fixture #47      | A        | Open     |

+------+---------------+----------------------+----------+----------+
| 018  | Chiller Room  | Pipe insulation      | B        | Corrected|
|      |               | incomplete at valve  |          |          |
+------+---------------+----------------------+----------+----------+
| 042  | Office        | Door closer          | C        | Open     |

+------+---------------+----------------------+----------+----------+
| 067  | Growing Zone 1| Temp sensor #12      | A        | Corrected|

+===================================================================+
```

## Key Takeaways

1. **Construction is about coordination** - Multiple trades, tight spaces, competing schedules require constant communication.

2. **Safety is non-negotiable** - Daily focus, leading indicators, zero-tolerance for violations.

3. **Progress tracking drives accountability** - Weekly meetings, 2-week lookaheads, clear action items.

4. **RFIs reveal design gaps** - Fast response prevents delays; track trends to improve future projects.

5. **Punch lists are inevitable** - Systematic approach and categorization ensure timely completion.

6. **Documentation protects all parties** - Photos, daily reports, meeting minutes, test results.
