# Module 13: Post-Project Evaluation & Lessons Learned

## Learning Objectives

- Conduct comprehensive post-project performance assessments
- Measure project success against original objectives
- Gather and analyze stakeholder feedback
- Conduct effective lessons learned sessions
- Document knowledge for organizational learning
- Apply continuous improvement to future projects

## 3. Lessons Learned Process

### Lessons Learned Workshop

```
LESSONS LEARNED WORKSHOP AGENDA
+===================================================================+
| SESSION: GreenLeaf Vertical Farm Post-Project Review              |
| DATE: February 15, 2027                                           |
| TIME: 9:00 AM - 3:00 PM                                           |
| LOCATION: Conference Room / Virtual Option                        |
+===================================================================+

PARTICIPANTS (20-25 people):
- Project sponsor and steering committee
- Project manager and core team
- Design team leads (architect, engineers)
- General contractor and key subcontractors
- Equipment vendors (major systems)
- Commissioning agent
- Operations team (facility manager, head grower)

PREPARATION (2 weeks before):
- Distribute project performance data
- Request participants to prepare:
  • Top 3 things that went well
  • Top 3 things to improve
  • Specific recommendations for future projects

AGENDA:

9:00-9:15   OPENING & OBJECTIVES
            - Purpose: Capture knowledge, improve future projects
            - Ground rules: Constructive, no blame, specific
            - Confidentiality: Candid feedback, sanitized final report

9:15-9:45   PROJECT PERFORMANCE REVIEW (PM Presentation)
            - Schedule, cost, technical performance summary
            - Stakeholder satisfaction results
            - Major milestones and key events timeline

9:45-10:45  WHAT WENT WELL (Facilitated Discussion)
            - Round-robin sharing (each person 2-3 minutes)
            - Group similar themes
            - Identify root causes of success
            - Document specific practices to replicate

10:45-11:00 BREAK

11:00-12:00 WHAT TO IMPROVE (Facilitated Discussion)
            - Round-robin sharing of challenges
            - Group similar themes
            - Avoid blame, focus on process/system improvements
            - Root cause analysis of major issues

12:00-1:00  LUNCH (Working Lunch - Informal Discussion)

1:00-2:00   RECOMMENDATIONS & ACTION ITEMS
            - Brainstorm specific improvements for future projects
            - Prioritize recommendations (impact vs. effort)
            - Assign owners for implementing changes
            - Identify process/template updates needed

2:00-2:30   KNOWLEDGE CAPTURE
            - Critical information for future projects
            - Vendor performance feedback
            - Cost/schedule benchmarks
            - Technical lessons

2:30-2:50   CLOSEOUT & NEXT STEPS
            - Action item review
            - Lessons learned report timeline
            - Appreciation and recognition
            - Final comments

2:50-3:00   PROJECT CELEBRATION
            - Acknowledge team effort and successes
            - Photos and memories
            - Close on positive note

+===================================================================+

FACILITATOR TECHNIQUES:
✓ Create safe environment for honest feedback
✓ Keep discussion focused and productive
✓ Capture detailed notes (scribe assigned)
✓ Draw out quiet participants
✓ Prevent domination by vocal individuals
✓ Stay on schedule
✓ Synthesize and summarize key points
```

### Lessons Learned Documentation

```
LESSONS LEARNED REPORT - GREENLEAF VERTICAL FARM
+===================================================================+

EXECUTIVE SUMMARY
-----------------
The GreenLeaf Vertical Farm project was completed successfully,
delivering a 50,000 sf facility producing 2.4M lbs annually within
1.3% of budget and 15 days past target completion date. Stakeholder
satisfaction was high (8.5/10 average). This report captures key
lessons to improve future CEA project delivery.

QUANTITATIVE BENCHMARKS
-----------------------
| Metric                    | Value           | Use for Future  |
+===========================+=================+=================+
| Total Project Cost        | $30.4M          | $608/sf         |
| Schedule (design-complete)| 26 months       | Baseline        |
| Cost breakdown            |                 |                 |
| - Building shell          | 25% of total    | Estimating      |
| - HVAC systems            | 20% of total    | Estimating      |
| - Lighting systems        | 18% of total    | Estimating      |
| - Growing systems         | 15% of total    | Estimating      |
| Change orders             | 4.2% of budget  | Contingency     |
| Equipment lead times      |                 |                 |
| - Chillers                | 24 weeks        | Procurement     |
| - LED fixtures            | 18 weeks        | Procurement     |
| - Growing systems         | 20 weeks        | Procurement     |
| Permitting duration       | 22 weeks        | Schedule        |
| Commissioning duration    | 10 weeks        | Schedule        |

WHAT WORKED WELL (Sustain)
---------------------------
1. EARLY EQUIPMENT PROCUREMENT
   - Ordered long-lead equipment during design phase
   - Avoided schedule delays from equipment delivery
   - RECOMMENDATION: Formalize early procurement protocol

2. SYSTEMATIC COMMISSIONING APPROACH
   - Comprehensive testing revealed integration issues early
   - Performance validation gave operations team confidence
   - RECOMMENDATION: Use same commissioning agent model

3. GROWER INVOLVEMENT IN DESIGN
   - Head grower participated in design reviews
   - Operational input improved system usability
   - RECOMMENDATION: Engage operations earlier (concept phase)

4. WEEKLY PROGRESS MEETINGS WITH STRUCTURED AGENDA
   - Consistent communication prevented surprises
   - Clear action items and accountability
   - RECOMMENDATION: Continue this practice

5. VENDOR SELECTION USING SCORECARD APPROACH
   - Objective evaluation led to best vendors
   - Avoided low-bid issues
   - RECOMMENDATION: Standardize vendor evaluation template

WHAT TO IMPROVE (Change)
-------------------------
1. PERMITTING STRATEGY AND TIMELINE
   ISSUE: Permitting took 22 weeks vs. 16-week estimate
   ROOT CAUSE: Underestimated city's unfamiliarity with CEA,
               insufficient pre-application engagement
   RECOMMENDATION:
   - Add 50% buffer to permitting estimates for CEA projects
   - Conduct pre-application meetings earlier (concept phase)
   - Prepare educational materials for planning departments
   - Budget for expediting services if available

2. CHANGE ORDER PROCESSING SPEED
   ISSUE: Average 12-day turnaround for change order approvals
   ROOT CAUSE: Multiple review/approval steps, stakeholder delays
   RECOMMENDATION:
   - Establish clear change order authority thresholds
   - Implement 3-day review turnaround commitment
   - Empower PM for changes <$25K/no schedule impact

3. EQUIPMENT INSTALLATION SEQUENCING
   ISSUE: Lighting installation delayed by HVAC ductwork conflicts
   ROOT CAUSE: Insufficient 3D coordination in design
   RECOMMENDATION:
   - Require BIM clash detection for all MEP systems
   - Hold coordination meeting before releasing for fabrication
   - Include installation sequencing in design documents

4. OPERATIONS TRAINING TIMING
   ISSUE: Operations team trained weeks before commissioning complete
           (knowledge fade before actual use)
   ROOT CAUSE: Training scheduled for contractor convenience
   RECOMMENDATION:
   - Schedule training closer to system handover (within 2 weeks)
   - Provide refresher training at 30 and 90 days
   - Include vendor on-call support for first 6 months

5. CONTINGENCY MANAGEMENT CLARITY
   ISSUE: Confusion about contingency allocation for changes
   ROOT CAUSE: No formal contingency drawdown procedure
   RECOMMENDATION:
   - Create contingency utilization policy upfront
   - Track contingency usage in monthly reports
   - Establish approval thresholds for accessing contingency

CRITICAL SUCCESS FACTORS (For Future CEA Projects)
---------------------------------------------------
1. Early and continuous grower/operator involvement
2. Adequate permitting time buffer (1.5x estimate minimum)
3. Equipment procurement overlapping design (long-lead items)
4. Comprehensive 3D coordination before construction
5. Experienced commissioning agent engaged early
6. Strong safety culture and daily reinforcement
7. Transparent communication with all stakeholders
8. Realistic schedule and budget (avoid optimism bias)
```

## Key Takeaways

1. **Post-project evaluation is not optional** - It's how organizations learn and improve.

2. **Measure what matters** - Track performance across schedule, cost, technical, and stakeholder dimensions.

3. **Stakeholder feedback is invaluable** - Structured surveys reveal perspectives PM may miss.

4. **Lessons learned require facilitation** - Structured workshop prevents blame and captures actionable insights.

5. **Document for future use** - Lessons not documented are lessons not learned by organization.

6. **Action items must have owners** - Lessons learned without implementation yield no improvement.

7. **Celebrate successes** - Recognition motivates team and reinforces positive practices.

5. Create action plan for implementing improvements
6. Present findings to stakeholders
