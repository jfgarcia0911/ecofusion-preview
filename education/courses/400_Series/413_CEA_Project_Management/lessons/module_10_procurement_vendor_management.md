## 1. Procurement Planning

### Make-or-Buy Analysis

```
MAKE-OR-BUY DECISION FRAMEWORK
+================================================================+
| MAKE (Self-perform or design-build)                            |
| Consider when:                                                 |
| + Cost savings significant (>20%)                              |
| + Control and flexibility critical                             |
| + Have internal expertise                                      |
| + Long-term capability building desired                        |
| - Increases project risk                                       |
| - Requires management bandwidth                                |
|                                                                |
| BUY (Subcontract or purchase)                                  |
| Consider when:                                                 |
| + Specialized expertise required                               |
| + Risk transfer important                                      |
| + Speed to market critical                                     |
| + Lack internal capability                                     |
| + Technology/equipment proprietary                             |
| - Premium cost                                                 |
| - Less control                                                 |
+================================================================+
```

## 2. Vendor Selection

### RFP/RFQ Development

```
REQUEST FOR PROPOSAL STRUCTURE
+===================================================================+
| 1. PROJECT OVERVIEW                                               |
|    - Project description and objectives                           |
|    - Facility size, capacity, crops                               |
|    - Location and site conditions                                 |
|    - Project timeline                                             |
|                                                                   |
| 2. SCOPE OF WORK                                                  |
|    - Detailed technical requirements                              |
|    - Performance specifications                                   |
|    - Interfaces with other systems/contractors                    |
|    - Delivery and installation requirements                       |
|    - Warranty and service requirements                            |
|                                                                   |
| 3. SUBMITTAL REQUIREMENTS                                         |
|    - Technical proposal (design approach, equipment, specs)       |
|    - Project schedule                                             |
|    - Pricing (itemized breakdown)                                 |
|    - References from similar projects                             |
|    - Company qualifications and experience                        |
|    - Quality and safety plans                                     |
|                                                                   |
| 4. EVALUATION CRITERIA (Weighted)                                 |
|    - Technical approach and compliance (40%)                      |
|    - Price (30%)                                                  |
|    - Experience and qualifications (15%)                          |
|    - Schedule (10%)                                               |
|    - Warranty and support (5%)                                    |
|                                                                   |
| 5. TERMS AND CONDITIONS                                           |
|    - Contract type (lump sum, unit price, etc.)                   |
|    - Payment terms                                                |
|    - Liquidated damages for late delivery                         |
|    - Warranty requirements (minimum 1 year)                       |
|    - Insurance requirements                                       |
|    - Safety requirements                                          |
|                                                                   |
| 6. INSTRUCTIONS TO BIDDERS                                        |
|    - Submission deadline and format                               |
|    - Pre-bid meeting details (if applicable)                      |
|    - Questions/clarifications process                             |
|    - Selection timeline                                           |
+===================================================================+
```

## 3. Contract Types

### Contract Type Selection

```
CONSTRUCTION CONTRACT TYPES
+====================================================================================+
| Type          | Description       | Risk Allocation | Best Use Case                  |
+===============+===================+=================+================================+
| LUMP SUM      | Fixed price for   | Contractor      | - Well-defined scope           |
| (Fixed Price) | defined scope     | (cost risk)     | - Complete design              |
|               |                   | Owner (scope)   | - Competitive market           |
|               |                   |                 | - Simple/standard work         |
|               | Pros: Cost certainty, simple admin                                    |
|               | Cons: Change orders costly, less flexibility                          |
+---------------+-------------------+-----------------+--------------------------------+
| UNIT PRICE    | Fixed rates for   | Shared          | - Quantities uncertain         |
|               | units of work     | (Contractor:    | - Site work, earthwork         |
|               | ($/cy, $/lf)      | productivity,   | - Repetitive tasks             |
|               |                   | Owner: quantity)|                                |
|               | Pros: Fair for uncertain quantities                                   |
|               | Cons: Total cost unknown until complete                               |
+---------------+-------------------+-----------------+--------------------------------+
| COST-PLUS     | Reimburse costs   | Owner           | - Scope uncertain              |
| FIXED FEE     | plus fixed fee    | (cost risk)     | - Fast-track/early start       |
| (CPFF)        |                   | Contractor      | - Complex/unique work          |
|               |                   | (minimal risk)  | - Trust-based relationship     |
|               | Pros: Flexibility, contractor cooperation                             |
|               | Cons: Cost overruns, requires close oversight                         |
+---------------+-------------------+-----------------+--------------------------------+
| GUARANTEED    | Max price with    | Shared          | - Design-build                 |
| MAXIMUM PRICE | potential savings | (Contractor:    | - Fast-track projects          |
| (GMP)         | sharing           | over GMP,       | - Some uncertainty             |
|               |                   | Owner: savings) | - Risk mitigation              |
|               | Pros: Cost ceiling, incentive for efficiency                          |
|               | Cons: GMP may include padding                                         |
+===============+==================+=================+================================+

CEA PROJECT RECOMMENDATIONS:
- Building Shell: Lump sum (standard construction)
- Site Work: Unit price (quantities vary)
- MEP Systems: GMP (complexity, coordination)
- Specialized Equipment: Lump sum with performance guarantees
- Commissioning: Cost-plus or time & materials
```

## 5. International Procurement

### International Procurement Considerations

```
INTERNATIONAL EQUIPMENT PROCUREMENT CHALLENGES
+===================================================================+
| ISSUE              | IMPACT              | MITIGATION            |
+====================+=====================+=======================+
| Long Lead Times    | 12-28 weeks typical | - Order early         |
|                    | shipping + customs  | - Air freight option  |
|                    |                     | - Track shipment      |
+--------------------+---------------------+-----------------------+
| Import Duties &    | 0-25% of value      | - Classify correctly  |
| Taxes              |                     | - Use customs broker  |
|                    |                     | - Budget for fees     |
+--------------------+---------------------+-----------------------+
| Currency Risk      | Exchange rate       | - Fix pricing in USD  |
|                    | fluctuation         | - Currency hedging    |
|                    |                     | - Contingency         |
+--------------------+---------------------+-----------------------+
| Quality Control    | Limited oversight   | - Factory inspection  |
|                    | of manufacturing    | - Third-party QC      |
|                    |                     | - Detailed specs      |
+--------------------+---------------------+-----------------------+
| Warranty/Service   | Limited local       | - Require local rep   |
|                    | support             | - Spare parts stock   |
|                    |                     | - Training for staff  |
+--------------------+---------------------+-----------------------+
| Documentation      | Language barriers,  | - Translation         |
|                    | metric units        | - Unit conversion     |
|                    |                     | - Clear drawings      |
+--------------------+---------------------+-----------------------+
| Payment Terms      | Wire transfer,      | - Letter of credit    |
|                    | advance payment     | - Payment milestones  |
|                    | required            | - Escrow              |
+===================================================================+

INCOTERMS (International Commercial Terms):
- EXW (Ex Works): Buyer handles all shipping/import
- FOB (Free on Board): Seller delivers to ship
- CIF (Cost, Insurance, Freight): Seller pays to destination port
- DDP (Delivered Duty Paid): Seller handles all costs to site

RECOMMENDATION FOR CEA EQUIPMENT: CIF or DDP
- Shifts shipping/customs complexity to vendor
- Clear total landed cost
- Reduced owner risk
```

## Key Takeaways

1. **Procurement strategy impacts project success** - Right packaging and contract types reduce risk.

2. **Vendor selection requires objective criteria** - Use weighted scorecards, not gut feel.

3. **Contract type must match risk allocation** - Align incentives and risk appropriately.

4. **Performance management is ongoing** - Monthly scorecards keep vendors accountable.

5. **International procurement requires planning** - Lead times, customs, and quality control are critical.

6. **Relationships matter** - Fair treatment and clear communication yield better results.
