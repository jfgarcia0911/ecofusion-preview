# Grading Rubric
## Course 409: Global Food Security Systems

---

## Overview

This rubric provides detailed grading criteria for all assignments and assessments in Course 409. The total possible points across all assessments is 110 points, with a passing threshold of 80% (88 points).

---

## Assignment Breakdown

| Assignment | Points | Weight | Description |
|------------|--------|--------|-------------|
| Assignment 1: Food Security Assessment | 15 | 13.6% | In-class global nutrition analysis |
| Assignment 2: Resilient Food System Design | 20 | 18.2% | In-class supply chain planning |
| Assignment 3: Community Food Program Development | 25 | 22.7% | In-class local food access strategy |
| Assignment 4: Policy and Advocacy Strategy | 20 | 18.2% | Take-home food systems change plan |
| Assignment 5: Complete Food Security Initiative | 30 | 27.3% | Full regional food system transformation |
| **Total** | **110** | **100%** | |

**Passing Threshold:** 88 points (80%)

---

## Grading Scale

| Percentage | Letter Grade | Point Range | Performance Level |
|------------|--------------|-------------|-------------------|
| 90-100% | A | 99-110 | Excellent - Exceeds expectations |
| 80-89% | B | 88-98 | Good - Meets all requirements |
| 70-79% | C | 77-87 | Fair - Meets most requirements |
| 60-69% | D | 66-76 | Poor - Below expectations |
| Below 60% | F | 0-65 | Failing - Does not meet requirements |

**Note:** A minimum of 80% (88 points) is required to pass this course and receive a Certificate of Completion.
