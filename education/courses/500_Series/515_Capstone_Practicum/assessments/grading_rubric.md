# Grading Rubric
## Course 515: Capstone Practicum

---

## Overview

This rubric provides detailed grading criteria for all assignments and assessments in Course 515. The total possible points across all assessments is 110 points, with a passing threshold of 80% (88 points).

---

## Assignment Breakdown

| Assignment | Points | Weight | Description |
|------------|--------|--------|-------------|
| Assignment 1: Capstone Project Proposal | 15 | 13.6% | In-class project planning and scoping |
| Assignment 2: Literature Review and Research | 20 | 18.2% | In-class comprehensive background analysis |
| Assignment 3: Implementation and Execution | 25 | 22.7% | In-class hands-on project delivery |
| Assignment 4: Data Analysis and Results | 20 | 18.2% | Take-home findings documentation |
| Assignment 5: Final Capstone Presentation | 30 | 27.3% | Complete professional project demonstration |
| **Total** | **110** | **100%** | |

**Passing Threshold:** 88 points (80%)

---

## Grading Scale

| Percentage | Letter Grade | Point Range | Performance Level |
|------------|--------------|-------------|-------------------|
| 90-100% | A | 99-110 | Excellent - Exceeds expectations |
| 80-89% | B | 88-98 | Good - Meets all requirements |
| 70-79% | C | 77-87 | Fair - Meets most requirements |
| 60-69% | D | 66-76 | Poor - Below expectations |
| Below 60% | F | 0-65 | Failing - Does not meet requirements |

**Note:** A minimum of 80% (88 points) is required to pass this course and receive a Certificate of Completion.
