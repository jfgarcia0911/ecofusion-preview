# Content Creation Quick Reference Guide

## Quick Content Formulas

### The Perfect LinkedIn Post
```
HOOK (2 lines - grab attention)
↓
CONTEXT (2-3 lines - why it matters)
↓
VALUE (3-5 bullet points or short paragraphs)
↓
CALL TO ACTION (question or invitation to engage)
```

**Length**: 1300 characters max to avoid "see more"

### The Compelling Article Outline
```
TITLE: Clear + Specific + Benefit
INTRODUCTION (10-15%)
   - Hook: Compelling opening
   - Problem/Opportunity
   - What you'll cover
   - Why it matters

BODY (70-80%)
   - 3-5 main sections with clear headers
   - Each section: Point → Evidence → Example
   - Scannable formatting

CONCLUSION (10-15%)
   - Summarize key points
   - Reinforce main message
   - Call to action
```

**Length**: 1000-2000 words (articles), 800-1200 (blog posts)

### The Twitter/X Thread Formula
```
TWEET 1: Hook that stands alone + thread indicator
TWEET 2-7: One idea per tweet, numbered
TWEET 8: Summary + CTA
```

**Best Practices**:
- First tweet must work standalone
- 280 characters max per tweet
- Line breaks for readability
- 1-2 hashtags maximum

## Content Quality Checklist

**Before Publishing, Ask:**

□ **Clear Value**: Does this help my audience solve a problem or achieve a goal?
□ **Specific**: Have I used concrete examples and data, not just generalities?
□ **Accurate**: Have I fact-checked all claims and cited sources?
□ **Original**: Am I adding unique insight, not just repeating what others say?
□ **Scannable**: Can someone skim headers and bullets to get key points?
□ **Actionable**: Can readers apply this immediately?
□ **Authentic**: Does this sound like me? Am I being genuine?
□ **Proofread**: No typos, grammatical errors, or formatting issues?
□ **Optimized**: Appropriate length, good title, includes visuals?
□ **Aligned**: Does this support my positioning and goals?

## Writing Efficiency Hacks

### The Pomodoro Content Sprint
- **25 min**: Write (no editing)
- **5 min**: Break
- **25 min**: Edit and refine
- **5 min**: Break
- **25 min**: Proofread and format

**Result**: Publishable content in ~90 minutes

### The Content Batching Block
**Every 2 weeks, dedicate 3 hours:**
- Hour 1: Write 4-6 social posts
- Hour 2: Write 1 article
- Hour 3: Create 3-4 graphics + schedule everything

**Result**: 2 weeks of content in one session

### The Swipe File System
**Maintain folder with:**
- Headlines that grabbed you
- Openings that hooked you
- Structures that worked well
- Your own best-performing content
- Industry examples to reference

**Use for**: Inspiration when stuck, pattern recognition, quality benchmarks

- **Image**: 1200 x 627 pixels
- **Best times**: Tue-Thu, 8-10 AM

- **Tweet**: 280 characters
- **Thread**: 5-10 tweets
- **Video**: Up to 2:20 (most watch < 1 min)
- **Image**: 1200 x 675 pixels
- **Best times**: Multiple daily

### YouTube
- **Length**: 8-15 minutes ideal
- **Thumbnail**: 1280 x 720 pixels
- **Title**: Under 60 characters
- **Description**: First 150 chars critical
- **Best days**: Thu-Sat

### Email Newsletter
- **Subject**: 30-50 characters
- **Preview**: First 75 characters
- **Body**: 500-800 words
- **Images**: 600 pixels wide
- **Best days**: Tue-Thu mornings

## Headline Formulas That Work

1. **How to [Desired Outcome] Without [Common Obstacle]**
   _How to Reduce Energy Costs Without Sacrificing Yields_

2. **[Number] Ways to [Achieve Goal] Even If [Constraint]**
   _5 Ways to Improve Crop Quality Even with Limited Budget_

3. **The [Adjective] Guide to [Topic] for [Audience]**
   _The Practical Guide to LED Selection for Vertical Farmers_

4. **What [Successful Example] Can Teach You About [Topic]**
   _What Tesla Can Teach You About CEA Innovation_

5. **Why [Common Belief] is Wrong (And What to Do Instead)**
   _Why Chasing Automation is Wrong (And What to Prioritize Instead)_

6. **[Do Something] Like [Admired Person/Company]**
   _Scale Your Operation Like AppHarvest_

7. **[Number] [Things] I Learned From [Experience]**
   _7 Lessons I Learned From My First Failed Vertical Farm_

## The One-Hour Article Process

**:00-:15** - Outline
- Choose topic
- List 3-5 main points
- Note examples for each
- Write headline

**:15-:40** - Draft
- Write introduction
- Write body (follow outline)
- Write conclusion
- Don't edit while drafting

**:40-:55** - Edit
- Improve clarity
- Strengthen examples
- Tighten language
- Add subheaders

**:55-:60** - Finalize
- Proofread
- Format
- Add visual
- Write social teaser

## SEO Basics for Thought Leaders

**Key Optimization Points:**

1. **Title Tag** (50-60 characters)
   - Include primary keyword
   - Make compelling
   - Accurate to content

2. **Meta Description** (150-160 characters)
   - Summarize content
   - Include keyword naturally
   - Call to action

3. **Headers** (H1, H2, H3)
   - Logical hierarchy
   - Include keywords naturally
   - Descriptive and scannable

4. **Internal Links**
   - Link to related content
   - Descriptive anchor text
   - Build content ecosystem

5. **External Links**
   - Link to authoritative sources
   - Adds context and value
   - Shows thoroughness

**Keywords for CEA:**
- "vertical farming [specific topic]"
- "CEA [problem] solutions"
- "controlled environment agriculture [topic]"
- "indoor farming [application]"
- Long-tail: "how to reduce tip burn in hydroponic lettuce"
