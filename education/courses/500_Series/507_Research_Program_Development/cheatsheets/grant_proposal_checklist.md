# Grant Proposal Checklist

**Course 507: Research Program Development**

## Pre-Submission Checklist

### 1. Strategic Assessment
- [ ] Opportunity aligns with research program strategy
- [ ] Sufficient time for quality proposal (minimum 4-6 weeks)
- [ ] Team expertise matches requirements
- [ ] Success probability reasonable (>15%)
- [ ] Funding amount justifies effort

### 2. Proposal Narrative Components

**Abstract/Summary** ✓
- [ ] 250-500 words (or as specified)
- [ ] Problem statement
- [ ] Research approach
- [ ] Expected outcomes and impact
- [ ] Compelling and clear

**Introduction/Background** ✓
- [ ] Establishes significance
- [ ] Reviews relevant literature
- [ ] Identifies knowledge gap
- [ ] States objectives clearly
- [ ] 2-3 pages typical

**Goals and Objectives** ✓
- [ ] Specific and measurable (SMART)
- [ ] Aligned with funder priorities
- [ ] Achievable within timeline
- [ ] Clear deliverables defined

**Methods/Approach** ✓
- [ ] Sufficient detail for replication
- [ ] Demonstrates feasibility
- [ ] Includes preliminary data
- [ ] Statistical analysis described
- [ ] Alternative approaches if needed
- [ ] 5-8 pages typical

**Expected Outcomes** ✓
- [ ] Clear anticipated results
- [ ] Significance explained
- [ ] Broader impacts described
- [ ] Dissemination plan included
- [ ] 1-2 pages

**Timeline** ✓
- [ ] Realistic schedule
- [ ] Major milestones identified
- [ ] Gantt chart or table
- [ ] Accounts for delays

### 3. Budget Components

**Personnel** ✓
- [ ] PI and co-Is with % effort
- [ ] Postdocs, students, technicians
- [ ] Fringe benefits calculated
- [ ] Salary escalation included (3% annually)

**Equipment** ✓
- [ ] Items >$5,000 listed separately
- [ ] Quotes obtained
- [ ] Justification provided

**Materials & Supplies** ✓
- [ ] Itemized or categorized
- [ ] Quantities and unit costs
- [ ] Realistic estimates

**Travel** ✓
- [ ] Conference presentations
- [ ] Collaborator visits
- [ ] Field work
- [ ] Per diem rates followed

**Other Direct Costs** ✓
- [ ] Publication fees
- [ ] Subawards calculated correctly
- [ ] Consultant fees if applicable

**Indirect Costs** ✓
- [ ] Correct institutional rate
- [ ] Applied to proper base (MTDC)
- [ ] Calculated accurately

### 4. Budget Justification
- [ ] Every line item explained
- [ ] Necessity demonstrated
- [ ] Calculations shown
- [ ] Connected to project activities
- [ ] 2-4 pages typical

### 5. Supporting Documents

**Biographical Sketches** ✓
- [ ] All key personnel included
- [ ] Format requirements followed (NSF, NIH, etc.)
- [ ] Relevant publications highlighted
- [ ] Expertise demonstrated
- [ ] 2-3 pages per person

**Current and Pending Support** ✓
- [ ] All active grants listed
- [ ] Pending proposals noted
- [ ] Effort percentages accurate
- [ ] Overlap addressed
- [ ] Format requirements followed

**Facilities and Equipment** ✓
- [ ] Available resources described
- [ ] Access confirmed
- [ ] Capabilities demonstrated
- [ ] 1-2 pages

**Letters of Support/Collaboration** ✓
- [ ] From all collaborators
- [ ] Specific commitments stated
- [ ] On letterhead with signature
- [ ] Recent dates
- [ ] Genuine (not generic)

**Data Management Plan** ✓
- [ ] Data types described
- [ ] Storage and backup plan
- [ ] Sharing plan included
- [ ] Retention timeline
- [ ] 1-2 pages

**References Cited** ✓
- [ ] All citations included
- [ ] Proper format
- [ ] Complete information
- [ ] Consistent style

### 6. Review Criteria Alignment

**Intellectual Merit / Scientific Quality** ✓
- [ ] Explicitly addressed
- [ ] Innovation clearly stated
- [ ] Approach soundness demonstrated
- [ ] Qualifications evident

**Broader Impacts / Significance** ✓
- [ ] Societal benefits described
- [ ] Training components included
- [ ] Dissemination plan clear
- [ ] Explicit statement of broader impacts

### 7. Writing Quality

**Clarity** ✓
- [ ] Written for non-specialist reviewers
- [ ] Jargon minimized and defined
- [ ] Short sentences and paragraphs
- [ ] Logical flow

**Visual Hierarchy** ✓
- [ ] Clear headings and subheadings
- [ ] White space adequate
- [ ] Figures and tables effective
- [ ] Key points emphasized

**Grammar and Style** ✓
- [ ] Proofread thoroughly
- [ ] Active voice used
- [ ] Consistent terminology
- [ ] Professional tone

### 8. Formatting Requirements

**Page Limits** ✓
- [ ] All sections within limits
- [ ] No cheating with tiny fonts or margins
- [ ] Figures count toward limits (check rules)

**Font and Margins** ✓
- [ ] Font size (typically 11-12 pt)
- [ ] Font type (typically Arial, Times, Helvetica)
- [ ] Margin requirements (typically 1")
- [ ] Line spacing (typically single)

**File Format** ✓
- [ ] PDF (usually required)
- [ ] File naming convention followed
- [ ] Files not corrupted
- [ ] Size limits respected

### 9. Internal Reviews

**Technical Review** ✓
- [ ] Colleague in field reviewed
- [ ] Feedback incorporated
- [ ] Science is sound

**Writing Review** ✓
- [ ] Clear and compelling
- [ ] Non-specialist can understand
- [ ] Free of errors

**Compliance Review** ✓
- [ ] Institutional requirements met
- [ ] Approvals obtained
- [ ] Signatures collected

### 10. Submission Process

**Final Checks** ✓
- [ ] All required documents included
- [ ] Correct versions uploaded
- [ ] No placeholder text remaining
- [ ] Page numbers correct

**System Requirements** ✓
- [ ] Grants.gov, FastLane, or other system account active
- [ ] Institutional authorization obtained
- [ ] Required registrations complete (DUNS, SAM, etc.)

**Timing** ✓
- [ ] Submitting 24-48 hours before deadline
- [ ] Not waiting until last minute
- [ ] Time for system issues
- [ ] Confirmation received

## Common Mistakes to Avoid

1. ❌ Submitting at deadline (system failures common)
2. ❌ Ignoring page limits or formatting requirements
3. ❌ Weak or missing preliminary data
4. ❌ Vague objectives and methods
5. ❌ Budget doesn't match narrative
6. ❌ Poor justification for budget items
7. ❌ Typos and grammatical errors
8. ❌ Generic letters of support
9. ❌ Not addressing review criteria explicitly
10. ❌ Overly ambitious scope

---

## Success Tips

✓ Start early (6-8 weeks before deadline)
✓ Contact program officer if appropriate
✓ Include compelling preliminary data
✓ Use figures and tables effectively
✓ Get multiple internal reviews
✓ Address all review criteria explicitly
✓ Make reviewer's job easy (clear, organized)
✓ Show, don't just tell (evidence for claims)
✓ Connect to broader significance
✓ Submit early with time for issues

---

## After Submission

- [ ] Save confirmation email/number
- [ ] Note expected decision timeline
- [ ] Continue research (don't wait)
- [ ] Prepare for resubmission if declined
- [ ] Plan for success (what if funded?)

---

**Remember**: Grant writing is a learnable skill that improves with practice. Learn from each proposal, whether funded or not!
