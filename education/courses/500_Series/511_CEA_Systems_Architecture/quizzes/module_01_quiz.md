## Questions

### Question 1
What is the primary purpose of enterprise architecture in a CEA organization?

A) To document all software code
B) To align technology with business objectives and provide integration standards
C) To replace the need for project managers
D) To eliminate all legacy systems immediately

**Correct Answer**: B

**Explanation**: Enterprise architecture provides the organizing logic for business processes and IT infrastructure, reflecting integration and standardization requirements to support business objectives.

---

### Question 2
In TOGAF ADM (Architecture Development Method), which phase focuses on defining the target architecture vision?

A) Preliminary Phase
B) Architecture Vision
C) Business Architecture
D) Implementation Governance

**Correct Answer**: B

**Explanation**: The Architecture Vision phase (Phase A) defines the scope, stakeholders, and target state vision for the architecture initiative.

---

### Question 3
Which of the following is NOT one of the four primary architecture domains?

A) Business Architecture
B) Data Architecture
C) Financial Architecture
D) Technology Architecture

**Correct Answer**: C

**Explanation**: The four primary architecture domains are: Business, Data, Application, and Technology. Financial is part of Business Architecture but not a separate domain.

---

### Question 4
In a CEA context, why is Operational Technology (OT) / Information Technology (IT) convergence important?

A) To reduce the number of employees needed
B) To integrate real-time control systems with business systems for unified operations
C) To eliminate the need for SCADA systems
D) OT/IT convergence is not important for CEA

**Correct Answer**: B

**Explanation**: CEA organizations need to bridge OT systems (SCADA, PLCs, real-time control) with IT systems (ERP, analytics) to create unified, data-driven operations.

---

### Question 5
Which architecture principle states that systems must support continuous operations with graceful degradation?

A) Data as a Strategic Asset
B) Business Continuity First
C) Security in Depth
D) Standards-Based Integration

**Correct Answer**: B

**Explanation**: The "Business Continuity First" principle emphasizes that CEA systems must maintain operations since crops cannot be paused, requiring redundancy and failover capabilities.

---

### Question 6
What is the Lambda Architecture pattern primarily used for?

A) Cloud deployment models
B) Combining batch and real-time data processing
C) Security frameworks
D) User interface design

**Correct Answer**: B

**Explanation**: Lambda Architecture combines batch processing (historical data) with stream processing (real-time data) to provide both comprehensive analytics and immediate insights.

---

### Question 7
In the Zachman Framework, which perspective represents the "Builder" view?

A) Contextual (Planner)
B) Conceptual (Owner)
C) Logical (Designer)
D) Physical (Builder)

**Correct Answer**: D

**Explanation**: The Physical row in the Zachman Framework represents the Builder perspective, showing detailed specifications for implementation.

---

### Question 8
For CEA operations, which system typically requires the LOWEST latency (fastest response time)?

A) Business analytics and reporting
B) Climate control systems
C) Historical data warehouse queries
D) Monthly financial reporting

**Correct Answer**: B

**Correct Answer**: B

**Explanation**: Climate control systems require <100ms latency as they directly affect plant health and must respond in real-time to environmental changes.

---

### Question 9
What is the primary benefit of using the C4 model for architecture documentation?

A) It replaces the need for all other documentation
B) It provides multiple levels of abstraction from high-level context to detailed code
C) It only works for cloud-based systems
D) It eliminates the need for architecture governance

**Correct Answer**: B

**Explanation**: The C4 model (Context, Containers, Components, Code) provides a hierarchical approach to architecture visualization, allowing different stakeholders to view appropriate levels of detail.

---

### Question 10
Which stakeholder group typically has HIGH influence but requires engagement focused on operational efficiency and improvements?

A) Executive Leadership
B) Operations Management
C) IT Team
D) External Vendors

**Correct Answer**: B

**Explanation**: Operations Management has high influence and is focused on operational efficiency, requiring engagement around process improvements, workflow optimizations, and operational metrics.
