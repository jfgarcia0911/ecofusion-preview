# Course 511: CEA Systems Architecture

## Master/Executive Level (500-Series)

### Course Overview
This comprehensive master-level course provides enterprise systems architecture training specifically designed for Controlled Environment Agriculture (CEA) organizations. Students learn to design, implement, and govern complex technology ecosystems that support large-scale CEA operations.

**Duration**: 60 hours
**Format**: 14 modules + assessments + hands-on activities
**Prerequisites**: Courses 203, 406, 411 or equivalent experience

## Assessment and Grading

### Formative Assessment (40%)
- **Module Quizzes** (35%): 14 quizzes × 2.5% each
  - 10 questions per quiz
  - Passing score: 70% per quiz
- **Hands-on Activity** (5%): Architecture design exercise
  - Evaluated on technical design, business alignment, feasibility

### Summative Assessment (60%)
- **Final Examination** (40%): 50-question comprehensive exam
  - Passing score: 75%
- **Capstone Project** (20%): Complete enterprise architecture design
  - Real-world application of all concepts

### Overall Passing Requirement
- Minimum 75% overall course score
- Minimum 70% on each module quiz
- Minimum 75% on final examination
- Completed capstone project meeting rubric requirements
