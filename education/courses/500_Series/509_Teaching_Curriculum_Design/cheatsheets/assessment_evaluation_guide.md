## Formative vs. Summative Assessment

| Aspect | Formative | Summative |
|--------|-----------|-----------|
| **Purpose** | Monitor & improve learning | Evaluate achievement |
| **Timing** | During instruction | End of instruction |
| **Stakes** | Low or no grades | High; graded |
| **Feedback** | Immediate, detailed | Final score/grade |
| **Frequency** | Frequent, ongoing | Once or few times |
| **Examples** | Quizzes, exit tickets, drafts | Final exam, capstone project |
| **Use** | Guide instruction | Certify mastery |

## Kirkpatrick's Four Levels of Evaluation

### Level 1: REACTION
**Question:** Did they like it?

**Methods:**
- End-of-training survey
- Satisfaction ratings
- Open-ended feedback

**Measures:**
- Content relevance
- Instructor effectiveness
- Materials quality
- Overall satisfaction

**Timing:** Immediately after training

---

### Level 2: LEARNING
**Question:** Did they learn?

**Methods:**
- Pre/post tests
- Skills demonstrations
- Performance assessments
- Self-assessments

**Measures:**
- Knowledge gained
- Skills acquired
- Attitude changes

**Timing:** End of training

---

### Level 3: BEHAVIOR
**Question:** Are they using it?

**Methods:**
- Observation
- Supervisor surveys
- Self-report
- Performance data

**Measures:**
- Application on the job
- Behavior changes
- Use of new skills

**Timing:** 1-6 months post-training

---

### Level 4: RESULTS
**Question:** Did it matter?

**Methods:**
- Business metrics
- Performance data
- ROI calculation
- Impact analysis

**Measures:**
- Productivity
- Quality
- Cost savings
- Safety improvements

**Timing:** 3-12 months post-training

---

## ROI Calculation

**Formula:**
```
ROI = (Benefits - Costs) / Costs × 100%
```

**Example:**
- Training Costs: $10,000
- Benefits (crop loss reduction): $18,000
- ROI = ($18,000 - $10,000) / $10,000 = 80%
- **For every $1 invested, gained $0.80 in benefits**

## Assessment Types

### TRADITIONAL ASSESSMENTS

**Multiple Choice:**
- ✓ Efficient scoring
- ✓ Broad content coverage
- ✗ Hard to test higher-order thinking
- Use for: Knowledge, comprehension

**Essay:**
- ✓ Higher-order thinking
- ✓ Communication skills
- ✗ Time to grade
- Use for: Analysis, evaluation, synthesis

**Short Answer:**
- ✓ Reduces guessing
- ✓ Tests understanding
- ✗ More time than MC
- Use for: Recall, comprehension, application

---

### PERFORMANCE-BASED ASSESSMENTS

**Skills Demonstration:**
- Student performs specific task
- Scored with rubric or checklist
- Example: Calibrate pH meter

**Practical Exam:**
- Series of hands-on tasks
- Often timed
- Example: Set up hydroponic system

**Project:**
- Extended work
- Authentic product
- Example: Design facility system

**Portfolio:**
- Collection of work
- Shows growth over time
- Includes reflection

---

### ALTERNATIVE ASSESSMENTS

**Concept Maps:**
- Visual representation of understanding
- Shows relationships

**Journals/Reflections:**
- Metacognitive thinking
- Learning process

**Peer Assessment:**
- Students evaluate each other
- Learn from others

**Self-Assessment:**
- Student evaluates own work
- Develops self-awareness

## Rubric Design

### ANALYTIC RUBRIC
Separate scores for each criterion

**Example:**

| Criterion | Exemplary (4) | Proficient (3) | Developing (2) | Beginning (1) |
|-----------|---------------|----------------|----------------|---------------|
| Technical Accuracy | All correct | Minor errors | Multiple errors | Major errors |
| Completeness | All components | Most complete | Missing some | Incomplete |
| Justification | Thorough | Adequate | Limited | Minimal |

**Use when:** Need detailed feedback, diagnostic information

---

### HOLISTIC RUBRIC
Single overall score

**Example:**
- **4:** Exceptional work; all criteria exceeded
- **3:** Proficient; all criteria met
- **2:** Developing; some criteria met
- **1:** Beginning; few criteria met

**Use when:** Need quick scoring, overall judgment

## Writing Effective Test Questions

### DO:
- ✓ Test important concepts
- ✓ Use clear language
- ✓ One correct answer
- ✓ Align with objectives
- ✓ Plausible distractors
- ✓ Appropriate difficulty

### DON'T:
- ✗ Trick questions
- ✗ Trivial facts
- ✗ Ambiguous wording
- ✗ "All of the above"
- ✗ Double negatives
- ✗ Textbook verbatim

## Effective Feedback Guidelines

### CHARACTERISTICS:
- **Specific:** "Good job" → "Your VPD calculations are accurate"
- **Actionable:** Tell what to do next
- **Timely:** Soon after performance
- **Balanced:** Strengths + areas to improve
- **Focused on work:** Not personal

### FEEDBACK FORMULA:
1. **Strength:** What they did well
2. **Suggestion:** Specific improvement
3. **Next Steps:** How to improve

**Example:**
"Your system design correctly sized all components (strength). To improve, add more detail on maintenance procedures (suggestion). Review example protocols on page 45 and revise your section (next step)."

## Common Assessment Mistakes

### MISALIGNMENT
- **Problem:** Testing different content/level than taught
- **Fix:** Use alignment matrix; check objectives

### NO CLEAR CRITERIA
- **Problem:** Subjective, inconsistent grading
- **Fix:** Develop and share rubrics

### ONLY ONE METHOD
- **Problem:** Incomplete picture of learning
- **Fix:** Use multiple assessment types

### NO FORMATIVE ASSESSMENT
- **Problem:** No feedback until too late
- **Fix:** Build in frequent low-stakes checks

### ASSESSMENT AS AFTERTHOUGHT
- **Problem:** Poorly aligned, invalid
- **Fix:** Design assessment before instruction (backward design)

## Quick Decision Guide

**Need to measure knowledge?**
→ Multiple choice, short answer

**Need to measure understanding?**
→ Essays, concept maps, explanations

**Need to measure skills?**
→ Performance assessment, demonstrations

**Need to measure application?**
→ Projects, case studies, simulations

**Need to monitor progress?**
→ Formative assessments (quizzes, checks)

**Need to certify mastery?**
→ Summative assessments (exams, capstones)

---

## Data-Driven Improvement

### ANALYZE RESULTS:
1. Which objectives did students meet?
2. Which were challenging?
3. Patterns in errors?
4. Unexpected results?

### TAKE ACTION:
- Re-teach challenging concepts
- Adjust pacing
- Modify assessments
- Improve instruction
- Update materials

### DOCUMENT:
- What changed
- Why
- Results

---

**Remember:** Assessment should improve learning, not just measure it!
