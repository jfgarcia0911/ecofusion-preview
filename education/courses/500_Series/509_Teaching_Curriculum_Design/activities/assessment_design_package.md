# Activity 3: Assessment Design Package

## CEA-509 Practical Application

**Type:** Assessment Development Exercise
**Duration:** 4 weeks
**Points:** 15% of course grade
**Format:** Individual work
**Due:** Week 10

---

## Overview

Create a comprehensive assessment package for a specific CEA topic that includes multiple assessment types, scoring tools, and validity/reliability documentation. This demonstrates your mastery of assessment design principles.

---

## Project Requirements

Choose ONE CEA topic and develop a complete assessment suite:

**Topic Examples:**
- Hydroponic system design and operation
- Integrated pest management
- Climate control and environmental management
- Nutrient management and plant nutrition
- Crop production planning
- Food safety and sanitation

---

## Required Components

### 1. Formative Assessments (3 different types)

**Purpose:** Monitor learning and provide feedback DURING instruction

**Examples:**
- Exit tickets
- Quick quizzes (5 questions)
- Think-pair-share prompts
- Concept checks
- Practice problems
- Self-assessment checklists

**For Each Formative Assessment:**
- Clear purpose statement
- When used in instruction sequence
- Complete instrument (questions, prompts, etc.)
- How results inform teaching
- Answer key or expected responses

---

### 2. Summative Written Assessment (1)

**Purpose:** Evaluate learning at END of unit/module

**Options:**
- Comprehensive exam (25-30 questions)
- Short answer test (10-15 questions)
- Essay exam (3-5 prompts)
- Case study analysis

**Requirements:**
- Test blueprint showing content coverage and Bloom's levels
- Complete test instrument
- Answer key with scoring guidelines
- Point values clearly indicated
- Instructions for students
- Estimated time to complete

**Example Blueprint:**

| Topic | Remember | Understand | Apply | Analyze | Total | % |
|-------|----------|------------|-------|---------|-------|---|
| Topic 1 | 3 | 2 | 1 | - | 6 | 25% |
| Topic 2 | 2 | 3 | 2 | 1 | 8 | 33% |
| Topic 3 | 2 | 2 | 3 | 1 | 8 | 33% |
| Topic 4 | 1 | 1 | 1 | - | 3 | 13% |
| **Total** | **8** | **8** | **7** | **2** | **25** | **100%** |

---

### 3. Performance-Based Assessment (1)

**Purpose:** Measure actual skill demonstration

**Options:**
- Skills demonstration (hands-on task)
- Practical exam (multiple tasks/stations)
- Project with deliverable
- Presentation
- Portfolio

**Requirements:**
- Clear task description
- Materials/resources needed
- Time allocation
- Performance criteria/rubric
- Scoring procedures
- Example of proficient work

---

### 4. Scoring Guides/Rubrics (For all assessments)

**For Written Assessments:**
- Answer keys
- Point allocation
- Partial credit guidelines

**For Performance Assessments:**
- Detailed analytic or holistic rubric
- Clear performance level descriptors
- Criteria aligned with objectives
- Point values

**Example Rubric Structure:**

| Criterion | Weight | Exemplary (4) | Proficient (3) | Developing (2) | Beginning (1) |
|-----------|--------|---------------|----------------|----------------|---------------|
| Technical Accuracy | 40% | Description | Description | Description | Description |
| Completeness | 25% | Description | Description | Description | Description |
| Justification | 25% | Description | Description | Description | Description |
| Professional Quality | 10% | Description | Description | Description | Description |

---

### 5. Validity and Reliability Documentation

**Content Validity:**
- How does assessment cover important content?
- Alignment matrix showing objectives mapped to assessment items
- Expert review process

**Example Alignment Matrix:**

| Learning Objective | Assessment Item(s) | Assessment Type |
|--------------------|-------------------|-----------------|
| 1. Calculate DLI | Q15, Q22, Performance Task | Written + Practical |
| 2. Design lighting system | Performance Task | Project |
| 3. Evaluate light efficiency | Q18, Q24, Essay prompt | Written |

**Reliability Considerations:**
- Clear, unambiguous questions
- Consistent scoring criteria
- Inter-rater reliability plan (if multiple graders)

---

### 6. Administration Guidelines

**For Each Assessment:**
- When to administer in course sequence
- Time required
- Materials needed
- Setup/logistics
- Instructions to students
- Accommodations available
- Academic integrity measures

## Example: Nutrient Management Assessment Package

### Learning Objectives:
1. Identify common nutrient deficiencies from visual symptoms (Understand)
2. Calculate nutrient requirements for specific crops (Apply)
3. Mix nutrient solutions to target EC and pH (Apply)
4. Diagnose and correct nutritional problems (Analyze)

### Formative Assessment 1: Exit Ticket
"List three symptoms of nitrogen deficiency and where they appear on the plant"
- Used after Day 1 lesson on macronutrients
- Checks basic understanding before moving forward

### Formative Assessment 2: Practice Problems
5 calculation problems: "Calculate grams of fertilizer needed..."
- Homework after Day 2 calculation lesson
- Identifies students needing extra help before practical

### Formative Assessment 3: Peer Review
Students bring photos of plants; partners diagnose deficiencies
- Day 4 activity
- Checks application skills; reveals misconceptions

### Summative Written: 25-Question Exam
- 8 Remember (identify nutrients, functions)
- 7 Understand (explain deficiency progression, nutrient interactions)
- 7 Apply (calculations, interpret data)
- 3 Analyze (diagnose complex scenarios)
- Blueprint ensures balanced coverage

### Performance Assessment: Mix and Adjust Task
**Task:** Mix nutrient solution for lettuce; test and adjust to targets
**Rubric criteria:**
- Accurate calculations (40%)
- Proper mixing procedure and safety (25%)
- EC and pH within ±5% of target (25%)
- Efficient workflow and documentation (10%)

### Validity Evidence:
- All objectives assessed by multiple items
- Alignment matrix shows 100% coverage
- Items reviewed by 3 CEA professionals for relevance

## Tips for Success

**1. Start with objectives**
- What do you need to assess?
- Choose methods that actually measure those objectives

**2. Use multiple methods**
- No single assessment tells whole story
- Variety gives comprehensive picture

**3. Authentic when possible**
- Real-world tasks
- Industry-relevant scenarios
- Actual professional work

**4. Clear criteria**
- Students should know what success looks like
- Rubrics clarify expectations
- Enable consistent scoring

**5. Pilot test**
- If possible, try with real students or colleagues
- Refine based on experience
- Time actual completion

**6. Practical feasibility**
- Can you actually administer this?
- Do you have needed resources?
- Is grading load manageable?

**7. Professional polish**
- Proofread carefully
- Consistent formatting
- Complete documentation
- Ready to implement
