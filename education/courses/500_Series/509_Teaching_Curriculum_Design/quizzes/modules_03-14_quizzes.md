# Modules 3-14 Quizzes: Teaching & Curriculum Design for CEA

## Module 3 Quiz: Learning Objectives and Outcomes Development

**1. A well-written learning objective using the ABCD format includes:**
A) Audience, Behavior, Condition, Degree
B) Assessment, Books, Content, Discussion
C) Analysis, Backward design, Curriculum, Delivery
D) Andragogy, Bloom's, Competency, Design

**Answer: A**

**2. Which action verb is appropriate for a "Create" level objective in Bloom's Taxonomy?**
A) Define
B) Explain
C) Design
D) Identify

**Answer: C**

**3. "Students will understand hydroponics" is a poor objective because:**
A) It's too specific
B) "Understand" is not measurable/observable
C) It includes the audience
D) It mentions a specific topic

**Answer: B**

**4. In Dave's Psychomotor Taxonomy, "performing a skill accurately without assistance" represents which level?**
A) Imitation
B) Manipulation
C) Precision
D) Naturalization

**Answer: C**

**5. An objective stating "Demonstrate commitment to food safety" is an example of:**
A) Cognitive objective
B) Psychomotor objective
C) Affective objective
D) Invalid objective

**Answer: C**

**6. The "R" in SMART objectives stands for:**
A) Realistic
B) Relevant
C) Rigorous
D) Redundant

**Answer: B**

**7. Which objective is written at the highest Bloom's level?**
A) List the components of a hydroponic system
B) Explain how NFT systems work
C) Calculate flow rates for a system
D) Evaluate three system designs and recommend the best

**Answer: D (Evaluate level)**

**8. Objectives should be aligned with:**
A) Only assessments
B) Only instruction
C) Both assessments and instruction
D) Neither assessments nor instruction

**Answer: C**

**9. "By Week 4, calibrate pH meters to within ±0.1 accuracy" includes which SMART criteria?**
A) Time-bound and Measurable
B) Only Specific
C) Only Achievable
D) Only Relevant

**Answer: A**

**10. For an introductory CEA course, objectives should primarily focus on which Bloom's levels?**
A) Create and Evaluate only
B) Remember, Understand, and Apply
C) All levels equally
D) Only Remember

**Answer: B**
