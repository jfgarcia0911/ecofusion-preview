## Problem Identification & Solutions

### GERMINATION PROBLEMS

```
┌─────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Poor germination rate (<80%)                                   │
├─────────────────────────────────────────────────────────────────────────┤
│ SYMPTOMS: Empty spots, patchy emergence                                 │
│                                                                         │
│ CAUSES → SOLUTIONS:                                                     │
│ • Old/poor seeds → Test batch, change supplier                          │
│ • Wrong temperature → Check 68-75°F range                               │
│ • Dried out during blackout → Check moisture daily                      │
│ • Buried too deep → Surface sow or light cover only                     │
│ • Improper soak → Review pre-soak protocol                              │
│ • Contaminated seeds → Rinse before seeding                             │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Mold growth during germination (white fuzzy)                   │
├─────────────────────────────────────────────────────────────────────────┤
│ SYMPTOMS: White cottony growth on stems/media                           │
│                                                                         │
│ CAUSES → SOLUTIONS:                                                     │
│ • Over-watering → Reduce water, improve drainage                        │
│ • Poor air circulation → Unstack daily, add ventilation                 │
│ • Too warm/humid → Lower temp to 68-72°F, reduce RH                     │
│ • Over-seeding → Reduce seed density 25%                                │
│ • Contaminated seeds → Use quality, clean seeds                         │
│                                                                         │
│ ACTION: Remove affected trays immediately, adjust conditions            │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Uneven germination across tray                                 │
├─────────────────────────────────────────────────────────────────────────┤
│ CAUSES → SOLUTIONS:                                                     │
│ • Uneven moisture → Level trays, even watering technique                │
│ • Temperature variation → Eliminate drafts, check hot/cold spots        │
│ • Uneven seeding → Practice distribution, use shaker method             │
│ • Media not level → Press flat before seeding                           │
└─────────────────────────────────────────────────────────────────────────┘
```

### GROWING PHASE PROBLEMS

```
┌─────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Leggy, stretched, weak stems                                   │
├─────────────────────────────────────────────────────────────────────────┤
│ CAUSES → SOLUTIONS:                                                     │
│ • Insufficient light → Increase intensity or duration                   │
│ • Lights too far away → Position 12-18" from canopy                     │
│ • Too warm → Lower temp to 65-70°F                                      │
│ • Over-seeding → Reduce density 25-30%                                  │
│ • Blackout too long → Remove earlier (when cotyledons emerge)           │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Yellowing leaves (chlorosis)                                   │
├─────────────────────────────────────────────────────────────────────────┤
│ CAUSES → SOLUTIONS:                                                     │
│ • Insufficient light → Increase to 200-400 μmol PPFD                    │
│ • Over-watering → Improve drainage, reduce frequency                    │
│ • Nutrient deficiency → For crops >14 days, add dilute fertilizer       │
│ • Root problems → Check for rot, improve aeration                       │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Wilting or drooping plants                                     │
├─────────────────────────────────────────────────────────────────────────┤
│ CAUSES → SOLUTIONS:                                                     │
│ • Under-watering → Check soil moisture, water promptly                  │
│ • Heat stress → Lower temp, increase air circulation                    │
│ • Root damage → Review watering method, check drainage                  │
│ • Disease (damping off) → Improve sanitation, reduce moisture           │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Lodging (falling over)                                         │
├─────────────────────────────────────────────────────────────────────────┤
│ CAUSES → SOLUTIONS:                                                     │
│ • Over-watering → Bottom water only, reduce frequency                   │
│ • Insufficient air movement → Add circulation fans                      │
│ • Over-seeding → Reduce density                                         │
│ • Harvesting too late → Harvest earlier in window                       │
└─────────────────────────────────────────────────────────────────────────┘
```

### PEST AND DISEASE ISSUES

```
┌─────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Fungus gnats (small black flies)                               │
├─────────────────────────────────────────────────────────────────────────┤
│ IDENTIFICATION: Tiny black flies around trays, larvae in media          │
│                                                                         │
│ SOLUTIONS:                                                              │
│ 1. Allow media surface to dry between waterings                         │
│ 2. Switch to bottom watering exclusively                                │
│ 3. Place yellow sticky traps to capture adults                          │
│ 4. Remove any standing water                                            │
│ 5. For severe cases: Beneficial nematodes in media                      │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Powdery mildew (white powder on leaves)                        │
├─────────────────────────────────────────────────────────────────────────┤
│ MOST COMMON ON: Peas, sunflower (late in cycle)                         │
│                                                                         │
│ SOLUTIONS:                                                              │
│ 1. Harvest immediately if close to ready                                │
│ 2. Increase air circulation                                             │
│ 3. Reduce humidity to 40-50%                                            │
│ 4. Don't overhead water late in day                                     │
│ 5. Space trays further apart                                            │
│ 6. If severe: Discard tray, clean area                                  │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Damping off (seedlings collapse)                               │
├─────────────────────────────────────────────────────────────────────────┤
│ SYMPTOMS: Brown water-soaked stems, seedlings fall over                 │
│                                                                         │
│ PREVENTION (no cure once infected):                                     │
│ • Use sterile media only                                                │
│ • Don't over-water                                                      │
│ • Ensure good drainage and air circulation                              │
│ • Proper sanitation of tools and containers                             │
│ • Remove affected trays immediately                                     │
└─────────────────────────────────────────────────────────────────────────┘
```

### POST-HARVEST PROBLEMS

```
┌─────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Short shelf life (<5 days)                                     │
├─────────────────────────────────────────────────────────────────────────┤
│ CAUSES → SOLUTIONS:                                                     │
│ • Delayed cooling → Cool to 34-38°F within 1 hour                       │
│ • Rough handling → Handle gently during harvest/packaging               │
│ • Wet product packaged → Dry thoroughly if washed                       │
│ • Warm storage → Verify cooler at 34-38°F continuously                  │
│ • Over-mature at harvest → Harvest earlier in window                    │
│ • Poor air circulation in package → Use breathable containers           │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Slimy or rotting product                                       │
├─────────────────────────────────────────────────────────────────────────┤
│ CAUSES → SOLUTIONS:                                                     │
│ • Packaged wet → Ensure product dry before packaging                    │
│ • Temperature abuse → Maintain cold chain continuously                  │
│ • Airtight packaging → Use breathable/vented containers                 │
│ • Too old → Check dates, enforce FIFO rotation                          │
└─────────────────────────────────────────────────────────────────────────┘
```

## Environmental Parameter Quick Check

```
IDEAL CONDITIONS AT-A-GLANCE
═════════════════════════════

GERMINATION PHASE:
Temperature: 68-75°F
Humidity: 70-80%
Light: None (blackout)
Moisture: Moist, not wet

GROWING PHASE:
Temperature: 65-72°F
Humidity: 40-60%
Light: 200-400 μmol, 14-16 hours
Air Movement: Gentle, continuous

POST-HARVEST:
Temperature: 34-38°F
Humidity: 95-98%
Time to cool: <1 hour
Storage: Dark, organized
```

## Emergency Action Plan

```
CRITICAL ISSUES - IMMEDIATE ACTION REQUIRED
═══════════════════════════════════════════

POWER OUTAGE:
1. Note time outage began
2. Keep cooler closed (holds 4-6 hours)
3. If >2 hours: Move product to backup cooler or ice
4. Monitor temperature continuously
5. Document temperature log for food safety

COOLING FAILURE:
1. Move all product to backup cooling immediately
2. Check product temperatures
3. Discard anything >45°F for >2 hours
4. Call refrigeration repair service
5. Document incident and actions taken

MOLD OUTBREAK:
1. Remove all affected trays immediately
2. Isolate unaffected trays
3. Deep clean entire growing area
4. Review sanitation procedures
5. Increase air circulation
6. Adjust watering/humidity

WATER SUPPLY CONTAMINATION:
1. Stop using water immediately
2. Use bottled/treated water for irrigation
3. Test water source
4. Discard any product irrigated with contaminated water
5. Document and report as required
```
