# Activity 2: Germination Rate Comparison Trial
## Course 206: Microgreens Production Mastery

---

## Objective

Conduct a controlled germination trial to compare germination rates, timing, and vigor across different microgreens varieties or growing conditions, developing skills in scientific observation and data collection.

---

## Overview

- **Duration:** 5-7 days (germination phase only)
- **Varieties:** Minimum 3 different varieties
- **Replicates:** 3 trays per variety for statistical validity
- **Deliverables:** Data collection sheet and analysis report

---

## Learning Outcomes

Upon completion, you will be able to:
1. Design and execute a controlled germination experiment
2. Accurately measure and record germination data
3. Calculate germination percentages and rates
4. Identify factors affecting germination success
5. Make data-driven decisions about seed quality and variety selection

---

## Materials Needed

**Equipment:**
- Growing trays (10x20) or smaller test trays: 9-12 total
- Growing media (consistent type across all trays)
- Seeds: 3+ varieties for testing
- Marker and labels
- Thermometer and hygrometer
- Timer/stopwatch
- Camera for documentation

**Optional:**
- Hand counter (for counting seeds)
- Scale (for weighing seeds)
- Magnifying glass (for close observation)

---

## Experimental Design

### Option A: Multi-Variety Comparison

**Purpose:** Compare germination performance across different microgreens varieties

**Variables:**
- Independent: Variety type (3-5 different varieties)
- Dependent: Germination rate, time to emergence, vigor
- Controlled: Media, temperature, moisture, light conditions

**Setup:**
```
Test 3-5 varieties simultaneously:
├─ Variety 1: Sunflower (3 replicate trays)
├─ Variety 2: Radish (3 replicate trays)
├─ Variety 3: Broccoli (3 replicate trays)
└─ Optional: Add Pea, Arugula, or others
```

---

### Option B: Growing Condition Comparison

**Purpose:** Test how growing conditions affect germination of a single variety

**Variables:**
- Independent: Temperature, pre-soak time, or media type
- Dependent: Germination rate, time to emergence, vigor
- Controlled: Variety, seed lot, seeding density

**Example Treatments:**
```
Testing Sunflower Pre-Soak Duration:
├─ Treatment 1: No soak (3 trays)
├─ Treatment 2: 4-hour soak (3 trays)
├─ Treatment 3: 8-hour soak (3 trays)
└─ Treatment 4: 12-hour soak (3 trays)
```

---

### Option C: Seed Quality Comparison

**Purpose:** Compare germination between different seed sources or lot numbers

**Variables:**
- Independent: Seed supplier, lot number, or age
- Dependent: Germination rate, uniformity, vigor
- Controlled: Variety, growing conditions

**Setup:**
```
Same variety from different sources:
├─ Source A: Premium microgreens supplier (3 trays)
├─ Source B: Budget online supplier (3 trays)
└─ Source C: Bulk feed store (3 trays)
```

---

## Step-by-Step Protocol

### Day 0: Setup and Seeding

**1. Prepare Materials**
- Label all trays clearly: Variety, Treatment, Replicate #, Date
- Prepare growing media to consistent depth (1-1.5")
- Pre-soak seeds if required (follow standard protocols)

**2. Count and Seed**
- Count exact seed numbers for small-scale trial:
  - Small tray (5x5"): 100 seeds per tray
  - Quarter tray (10x10"): 200-400 seeds per tray
  - Full tray (10x20"): Use standard seeding density
- Record actual seed count per tray
- Distribute seeds evenly across media surface
- Lightly press seeds into contact with media

**3. Initial Moisture and Environment**
- Water thoroughly using bottom watering
- Ensure all trays receive equal moisture
- Record initial environmental conditions:
  - Temperature: _____°F
  - Humidity: _____%
  - Location: __________
- Stack and cover for blackout (if variety requires)
- Take photos of each setup

**4. Document Baseline**
- Record seeding time (day and hour)
- Note any variations or observations
- Create data collection sheet (template below)

---

### Days 1-5: Observation and Data Collection

**Daily Tasks (Same time each day):**

**1. Visual Inspection**
- Carefully lift trays to check undersides
- Look for root emergence (first sign of germination)
- Note any seeds beginning to swell or crack

**2. Count Germinated Seeds**
- Use consistent definition: "Germinated = radicle visible"
- Count all emerged seedlings in each tray
- Record cumulative count (not just new ones)

**3. Environmental Monitoring**
- Temperature: _____°F
- Humidity: _____%
- Moisture level: Dry / Moist / Wet

**4. Moisture Management**
- Water lightly if needed (maintain consistent moisture)
- Use same watering method for all trays
- Record any watering performed

**5. Photography**
- Daily photos of each treatment/variety
- Use same angle and lighting for consistency

**6. Observations**
- Note vigor, uniformity, color
- Document any problems (mold, poor emergence)
- Unusual patterns or concerns

## Commercial Applications

### Translating Results to Production

**Quality Control Protocols:**
```
Based on trial results, establish standards:

Minimum acceptable germination: ____%
Target germination: ____%
Rejection threshold: ____%

Testing frequency:
├─ New seed lot: Always test
├─ Stored seeds (3+ months): Test every batch
└─ Suspected problems: Test immediately
```

**Seeding Density Adjustments:**
```
If germination < 90%, adjust seeding:

Example: Radish normally 1.25 oz per tray
├─ If germination = 95%: Use 1.25 oz (standard)
├─ If germination = 85%: Use 1.47 oz (+18%)
└─ If germination = 75%: Use 1.67 oz (+33%)

Formula: Standard rate ÷ (Germination % ÷ 100)
```

## Extension Activities

**For Advanced Students:**

1. **Statistical Analysis**
   - Calculate standard deviation and confidence intervals
   - Perform t-test to determine if differences are significant
   - Create error bars on graphs

2. **Time-to-Event Analysis**
   - Track exact timing of each seed's germination
   - Calculate mean time to germination (MTG)
   - Analyze germination synchrony

3. **Vigor Testing**
   - Measure radicle length at Day 3
   - Assess cotyledon expansion rate
   - Compare fresh weight at Day 5

4. **Economic Analysis**
   - Calculate cost per successfully germinated seed
   - Compare ROI across varieties
   - Determine break-even germination rates

---

## Tips for Success

**Consistency is Key:**
- Use same technique for all trays
- Count at the same time each day
- Maintain identical environmental conditions

**Definition Matters:**
- Define "germinated" consistently (radicle visible)
- Use same counting method throughout
- Don't change criteria mid-trial

**Documentation:**
- Write legibly and completely
- Date and time all observations
- Note anything unusual immediately

**Replication:**
- Run full 3 replicates for statistical validity
- Don't skip replicates to save time/space
- Average results across replicates for final numbers
