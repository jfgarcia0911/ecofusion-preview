### Label Design and Production

**Design Considerations:**

```
LABEL DESIGN BEST PRACTICES

Visual Hierarchy:
1. Farm/Brand name (most prominent)
2. Product variety
3. Weight and date
4. Required information
5. Additional details

Color and Typography:
• Use colors that complement product (green = fresh)
• Avoid busy backgrounds (hard to read)
• Legible fonts, minimum 8-10pt for details
• High contrast (dark text on light background)
• Professional, clean design

Production Methods:

OPTION 1: Pre-printed labels
✓ Professional appearance
✓ Cost-effective at volume (>1,000)
✓ Consistent branding
✗ Must add variable info (date, weight) separately
Cost: $0.05-0.15 per label

OPTION 2: Print-on-demand
✓ Fully customizable
✓ Include all variable information
✓ Small batch flexibility
✗ Higher per-label cost
✗ Requires label printer
Cost: $0.10-0.25 per label + equipment

OPTION 3: Handwritten
✓ Very low cost
✓ Artisanal appeal
✓ No special equipment
✗ Time-consuming
✗ Less professional for retail
✗ Inconsistent appearance
Cost: $0.02-0.05 per label
```

### Step-by-Step Packaging Process

```
STANDARD PACKAGING PROCEDURE

1. PREPARE WORKSPACE (Before starting)
   □ Sanitize work surface
   □ Wash hands thoroughly
   □ Set out clean containers
   □ Stage labels and sealing materials
   □ Calibrate scale (if needed)

2. ORGANIZE PRODUCT
   □ Bring harvested microgreens from cooler
   □ Keep refrigerated until packaging
   □ Work in small batches (prevent warming)

3. WEIGH AND FILL
   □ Tare scale with empty container
   □ Fill to target weight (+/- 0.25 oz acceptable)
   □ Don't compress product (reduces shelf life)
   □ Leave headroom in container

4. INSPECT QUALITY
   □ Visual check for foreign material
   □ Remove any yellowed or damaged leaves
   □ Ensure product meets grade standards

5. SEAL CONTAINER
   □ Wipe rim clean if needed
   □ Secure lid firmly
   □ Apply tamper-evident seal (if required)

6. APPLY LABEL
   □ Include all required information
   □ Ensure accurate date and weight
   □ Label straight and professional

7. FINAL CHECK
   □ Verify weight and labeling correct
   □ Container sealed properly
   □ Visual appearance acceptable

8. IMMEDIATE COOLING
   □ Place in cooler within 5 minutes
   □ Organize by variety and date
   □ Prepare for distribution

TIMING TARGET: 2-3 minutes per package (experienced)
```

## Shelf Life Extension

### Maximizing Product Longevity

```
┌──────────────────────────────────────────────────────────────────────────┐
│                    SHELF LIFE OPTIMIZATION FACTORS                       │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  HARVEST TIMING                                                          │
│  • Harvest at peak maturity (not over-mature)                            │
│  • Morning harvest (higher moisture, crispness)                          │
│  • Handle gently (reduce damage)                                         │
│  Impact: +2-3 days shelf life                                            │
│                                                                          │
│  RAPID COOLING                                                           │
│  • Cool to 34-38°F within 30-60 minutes                                  │
│  • Maintain cold chain continuously                                      │
│  • Minimize temperature fluctuations                                     │
│  Impact: +3-5 days shelf life                                            │
│                                                                          │
│  MOISTURE MANAGEMENT                                                     │
│  • Dry product before packaging (if washed)                              │
│  • Avoid condensation in containers                                      │
│  • Breathable packaging for gas exchange                                 │
│  Impact: +2-4 days shelf life                                            │
│                                                                          │
│  MODIFIED ATMOSPHERE                                                     │
│  • Reduce O₂, increase CO₂ in package                                    │
│  • Specialized packaging materials                                       │
│  • Commercial MAP equipment                                              │
│  Impact: +5-7 days shelf life (expensive)                                │
│                                                                          │
│  VARIETY SELECTION                                                       │
│  • Broccoli, sunflower: 10-14 day shelf life                             │
│  • Radish, arugula: 7-9 day shelf life                                   │
│  • Basil, delicate herbs: 5-7 day shelf life                             │
│  • Communicate expectations to customers                                 │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

## Waste Reduction

### Minimizing Losses

```
WASTE REDUCTION STRATEGIES

PRODUCTION PLANNING:
• Grow to confirmed orders (reduce overproduction)
• Stagger seeding for steady supply (avoid gluts)
• Track customer patterns (seasonality, preferences)
• Build buffer for growth, not excess

QUALITY CONTROL:
• Maintain high standards (reduces customer returns)
• Proper environmental control (reduces crop loss)
• Pest and disease prevention (protects production)

SALES AND DISTRIBUTION:
• Pre-sell production when possible
• Offer discounts on older inventory (approaching use-by)
• Develop outlets for B-grade product
• Build relationships with multiple channels

CREATIVE USES FOR EXCESS:
• Juice bars (wheatgrass, sunflower shoots)
• Pet food stores (wheatgrass for cats)
• Food banks (donations, tax deduction)
• Composting (worst case, return nutrients)

TYPICAL WASTE TARGETS:
Excellent: <5% waste
Good: 5-10% waste
Concerning: >10% waste (review systems)
```

## Module Summary

### Key Takeaways

1. **Match packaging to market** - restaurants need bulk containers, retail needs clamshells

2. **Invest in professional labeling** - builds brand and meets regulatory requirements

3. **Cool immediately** - rapid cooling to 34-38°F is critical for shelf life

4. **Organize storage effectively** - FIFO system prevents waste and ensures freshness

5. **Plan production to demand** - reduces waste and improves profitability
