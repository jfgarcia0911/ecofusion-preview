# Garden Program Planning Checklist
## Course 214: Community & School Garden Programs

---

## Pre-Planning Phase

### Vision & Purpose
- [ ] Define primary purpose and goals
- [ ] Identify target audience and numbers
- [ ] Articulate 3-5 SMART goals
- [ ] Ensure alignment with organizational mission
- [ ] Develop compelling vision statement

### Needs Assessment
- [ ] Survey potential participants/stakeholders
- [ ] Conduct focus groups or interviews
- [ ] Review relevant data (academic, health, community)
- [ ] Assess organizational readiness (score pillars)
- [ ] Document assessment findings

### Stakeholder Engagement
- [ ] Identify key stakeholders across groups
- [ ] Complete power-interest mapping
- [ ] Develop engagement strategy for each group
- [ ] Schedule initial meetings with decision-makers
- [ ] Build core planning team

---

## Site Selection & Design Phase

### Site Assessment
- [ ] Evaluate potential locations
- [ ] Test sun exposure (6+ hours ideal)
- [ ] Check water access
- [ ] Test or assess soil quality
- [ ] Verify ownership/permission
- [ ] Consider visibility and accessibility
- [ ] Review security needs

### Garden Design
- [ ] Determine total space available
- [ ] Calculate growing area needed
- [ ] Design layout (beds, paths, zones)
- [ ] Plan for accessibility (ADA compliance)
- [ ] Include teaching/gathering space
- [ ] Design water system
- [ ] Plan tool storage
- [ ] Create scaled drawing

### Infrastructure Planning
- [ ] List required materials (beds, soil, paths)
- [ ] Identify water needs and system
- [ ] Plan fencing if needed
- [ ] Determine storage requirements
- [ ] Consider special features (compost, greenhouse)
- [ ] Obtain necessary permits
- [ ] Develop phased construction plan

---

## Curriculum & Programming Phase

### Educational Planning
- [ ] Identify academic standards to address
- [ ] Develop scope and sequence
- [ ] Create or adapt lesson plans
- [ ] Plan assessment strategies
- [ ] Develop teacher/educator training
- [ ] Create student materials
- [ ] Build resource library

### Scheduling
- [ ] Determine frequency (weekly, bi-weekly)
- [ ] Coordinate with school/organizational calendar
- [ ] Plan seasonal programming
- [ ] Schedule special events
- [ ] Create annual calendar
- [ ] Plan for vacation/summer care

---

## Operations & Staffing Phase

### Staffing
- [ ] Define roles and responsibilities
- [ ] Determine staffing model (paid/volunteer)
- [ ] Write position descriptions
- [ ] Recruit garden coordinator (if applicable)
- [ ] Identify teacher/educator involvement
- [ ] Establish reporting structure

### Volunteer Management
- [ ] Develop recruitment strategy
- [ ] Create volunteer position descriptions
- [ ] Plan orientation and training
- [ ] Set up scheduling system
- [ ] Establish communication protocols
- [ ] Design recognition program
- [ ] Arrange background checks (if needed)

### Policies & Procedures
- [ ] Write safety protocols
- [ ] Develop garden use policies
- [ ] Create emergency procedures
- [ ] Establish maintenance responsibilities
- [ ] Document decision-making processes
- [ ] Create operations manual

---

## Budget & Funding Phase

### Budget Development
- [ ] Calculate startup costs
  - [ ] Infrastructure
  - [ ] Materials and supplies
  - [ ] Tools and equipment
  - [ ] Initial plantings
- [ ] Estimate annual operating costs
  - [ ] Personnel
  - [ ] Supplies
  - [ ] Water/utilities
  - [ ] Maintenance
- [ ] Account for in-kind contributions
- [ ] Build 10% contingency

### Funding Strategy
- [ ] Research grant opportunities
- [ ] Identify potential sponsors/donors
- [ ] Explore earned income options
- [ ] Request institutional budget allocation
- [ ] Plan fundraising events/campaigns
- [ ] Develop 3-year sustainability plan
- [ ] Write grant proposals
- [ ] Cultivate donor relationships

---

## Partnership Development Phase

### Identifying Partners
- [ ] List potential partner organizations
- [ ] Research their missions and programs
- [ ] Identify mutual benefits
- [ ] Prioritize partnership prospects

### Building Partnerships
- [ ] Schedule initial conversations
- [ ] Develop partnership proposals
- [ ] Draft MOUs or agreements
- [ ] Clarify roles and contributions
- [ ] Establish communication protocols
- [ ] Plan collaboration activities

---

## Implementation Phase

### Construction & Setup (Months 1-3)
- [ ] Secure necessary approvals
- [ ] Purchase or obtain materials
- [ ] Organize volunteer workdays
- [ ] Build raised beds or prepare plots
- [ ] Install pathways
- [ ] Set up water system
- [ ] Install fencing (if applicable)
- [ ] Build/install storage
- [ ] Prepare soil
- [ ] Install signage

### Program Launch (Month 3-4)
- [ ] Conduct staff/teacher training
- [ ] Orient volunteers
- [ ] Order seeds and plants
- [ ] Create planting plan
- [ ] Begin programming with participants
- [ ] Host kickoff event
- [ ] Launch communication systems
- [ ] Start documentation

### Ongoing Operations (Months 4-12)
- [ ] Implement curriculum
- [ ] Maintain regular schedule
- [ ] Coordinate volunteers
- [ ] Monitor plant health and growth
- [ ] Address challenges as they arise
- [ ] Communicate with stakeholders
- [ ] Document activities and outcomes
- [ ] Adjust and adapt as needed

---

## Evaluation & Sustainability Phase

### Evaluation System
- [ ] Finalize evaluation plan
- [ ] Conduct baseline assessment
- [ ] Set up data collection systems
- [ ] Train staff on data collection
- [ ] Establish reporting schedule
- [ ] Create photo/story documentation
- [ ] Analyze data regularly
- [ ] Share results with stakeholders

### Sustainability Planning
- [ ] Build institutional integration
  - [ ] Curriculum integration
  - [ ] Budget allocation
  - [ ] Policy inclusion
  - [ ] Cultural embedding
- [ ] Develop leadership succession
  - [ ] Document all processes
  - [ ] Cross-train staff/volunteers
  - [ ] Identify future leaders
- [ ] Strengthen community ownership
  - [ ] Deepen engagement
  - [ ] Build advocacy
  - [ ] Create traditions
- [ ] Diversify funding
  - [ ] Multiple revenue streams
  - [ ] Reduce grant dependence
  - [ ] Build reserves
- [ ] Maintain infrastructure
  - [ ] Regular maintenance
  - [ ] Capital improvement plan
  - [ ] Long-term design

### Year-End Review
- [ ] Gather evaluation data
- [ ] Survey stakeholders
- [ ] Hold team reflection meetings
- [ ] Document successes and challenges
- [ ] Identify improvement priorities
- [ ] Celebrate achievements
- [ ] Recognize contributors
- [ ] Update plans for next year
- [ ] Submit required reports

---

## Communication & Marketing

### Ongoing Communication
- [ ] Create communication calendar
- [ ] Launch newsletter (monthly)
- [ ] Update website/social media (weekly)
- [ ] Send stakeholder updates (quarterly)
- [ ] Share photos and stories
- [ ] Respond to inquiries promptly
- [ ] Gather and share testimonials

### Special Events
- [ ] Plan seasonal celebrations
- [ ] Organize volunteer appreciation
- [ ] Host community workdays
- [ ] Conduct garden tours
- [ ] Participate in organizational events
- [ ] Create media opportunities
- [ ] Build community tradition

---

## Long-Term Planning (Years 2-5)

### Expansion & Refinement
- [ ] Evaluate year 1 and adjust
- [ ] Expand participation if appropriate
- [ ] Add programming elements
- [ ] Enhance infrastructure
- [ ] Deepen curriculum integration
- [ ] Strengthen partnerships
- [ ] Build earned income
- [ ] Achieve full sustainability

### Replication & Scaling
- [ ] Document successful model
- [ ] Share learnings with others
- [ ] Support new programs
- [ ] Build network of practitioners
- [ ] Advocate for garden programs
- [ ] Contribute to field knowledge

---

## Quick Reference: First 90 Days

### Days 1-30: Foundation
1. Secure site and permissions
2. Form core planning team
3. Conduct needs assessment
4. Develop initial design
5. Create budget
6. Begin fundraising

### Days 31-60: Development
1. Finalize design and budget
2. Order materials
3. Recruit volunteers
4. Develop curriculum outline
5. Submit grant applications
6. Build partnerships

### Days 61-90: Implementation
1. Construct infrastructure
2. Train staff and volunteers
3. Prepare soil and plant
4. Launch programming
5. Establish communication
6. Document and celebrate

---

**Remember:**
- Start small and build over time
- Engage stakeholders early and often
- Document everything
- Celebrate successes
- Learn from challenges
- Focus on sustainability from day one
- Maintain flexibility and adaptability
- Keep the mission central
