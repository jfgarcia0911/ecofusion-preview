# Production Planning Checklist
## Course 204: Crop Production Planning

---

## Purpose

This checklist provides a comprehensive timeline of tasks for planning and executing crop production in CEA operations. Use this as a roadmap for systematic production planning from initial concept through ongoing operations.

---

## Phase 1: Pre-Production Planning (Weeks 1-4)

### Week 1: Market Analysis & Crop Selection

**Market Research:**
- [ ] Identify target customers (restaurants, retail, direct consumers)
- [ ] Research pricing for top 10-15 potential crops in your market
- [ ] Validate demand through customer conversations
- [ ] Secure preliminary commitments or letters of intent
- [ ] Document seasonal demand patterns

**Crop Evaluation:**
- [ ] Complete Crop Evaluation Scorecard for top 10 crop candidates
- [ ] Calculate profitability metrics (GM%, revenue/sqft, contribution margin)
- [ ] Assess system compatibility with available infrastructure
- [ ] Evaluate labor requirements and skill availability
- [ ] Analyze space efficiency and annual turns

**Decision:**
- [ ] Select core crops (70-80% of space)
- [ ] Select rotation crops (15-25% of space)
- [ ] Allocate trial crop space (5-10%)
- [ ] Reserve buffer space (5-10%)

---

### Week 2: Production Calculations

**Seeding Requirements:**
- [ ] Determine weekly harvest targets by crop
- [ ] Calculate germination rates for each crop
- [ ] Factor in transplant success rates (90-95%)
- [ ] Account for crop loss percentages (5-10%)
- [ ] Add safety buffers (10-20% depending on experience)
- [ ] Calculate final seeds needed per week per crop

**Space Allocation:**
- [ ] Determine plant spacing for each crop
- [ ] Calculate plants per square foot
- [ ] Determine number of batches needed in system
- [ ] Allocate production zones by crop type
- [ ] Calculate propagation space needs (10-15% of production)

**Timeline Development:**
- [ ] Document days to maturity for each crop/variety
- [ ] Adjust for seasonal variations (add 20-30% for winter)
- [ ] Calculate crop cycle lengths
- [ ] Determine number of annual turns per crop

---

### Week 3: Calendar & Schedule Creation

**Production Calendar:**
- [ ] Create weekly seeding schedule
- [ ] Map transplanting schedule (offset by propagation period)
- [ ] Project harvest windows
- [ ] Identify peak labor periods
- [ ] Build in buffer time for delays

**Batch Tracking System:**
- [ ] Set up batch numbering system
- [ ] Create tracking spreadsheet or software
- [ ] Design data collection forms
- [ ] Establish performance metrics to track

**Resource Planning:**
- [ ] Calculate seed quantities needed (first 3 months)
- [ ] Order propagation supplies (trays, media, nutrients)
- [ ] Schedule equipment setup/testing
- [ ] Plan nutrient formulations by crop and stage

---

### Week 4: Infrastructure & Systems Setup

**Propagation Area:**
- [ ] Set up propagation benches/racks
- [ ] Install lighting (if needed)
- [ ] Configure environmental controls
- [ ] Test germination chamber or propagation zone
- [ ] Organize seed storage area

**Production Systems:**
- [ ] Configure growing systems by crop type
- [ ] Install irrigation/nutrient delivery
- [ ] Set up environmental monitoring
- [ ] Test all equipment and controls
- [ ] Calibrate sensors and meters

**Post-Harvest:**
- [ ] Set up harvest/packing area
- [ ] Install cooling/storage
- [ ] Organize packaging materials
- [ ] Establish quality control station
- [ ] Create harvest protocols

---

## Phase 2: Launch & Ramp-Up (Weeks 5-12)

### Week 5-6: Initial Seeding

**First Batches:**
- [ ] Seed first batch of all core crops
- [ ] Label clearly with batch ID and date
- [ ] Record quantities seeded
- [ ] Monitor germination daily
- [ ] Adjust environmental conditions as needed

**Week 2 Succession:**
- [ ] Seed second batch (week later)
- [ ] Continue monitoring batch 1
- [ ] Record germination percentages
- [ ] Make notes on any issues

---

### Week 7-8: First Transplants

**Transplanting:**
- [ ] Transplant first batches at appropriate stage
- [ ] Record transplant success rate
- [ ] Monitor for transplant shock
- [ ] Adjust environmental conditions for production
- [ ] Continue weekly seeding succession

**System Monitoring:**
- [ ] Check pH and EC daily
- [ ] Monitor temperature and humidity
- [ ] Inspect for pests or diseases
- [ ] Record growth observations
- [ ] Adjust nutrient strength by growth stage

---

### Week 9-12: System Fill & First Harvests

**Steady State Approach:**
- [ ] Continue weekly seeding without fail
- [ ] Maintain transplanting schedule
- [ ] Monitor crop development closely
- [ ] Prepare for first harvests

**First Harvests:**
- [ ] Harvest first mature batches
- [ ] Record actual vs. planned harvest date
- [ ] Measure yields and quality
- [ ] Document any issues or variations
- [ ] Deliver to customers and gather feedback

---

## Phase 3: Steady-State Operations (Ongoing)

### Daily Tasks

**Morning (7:00-9:00 AM):**
- [ ] Check environmental conditions (temp, humidity, EC, pH)
- [ ] Visual inspection of all crops
- [ ] Identify any issues requiring immediate attention
- [ ] Check irrigation systems functioning properly

**Mid-Day (10:00 AM-2:00 PM):**
- [ ] Execute scheduled tasks (seeding, transplanting, or harvesting)
- [ ] Perform crop maintenance (pruning, training, etc.)
- [ ] Adjust environmental controls as needed
- [ ] Process harvests (wash, pack, cool)

**Afternoon (2:00-5:00 PM):**
- [ ] Complete packing and quality control
- [ ] Record batch data and observations
- [ ] Clean work areas and equipment
- [ ] Prepare for next day's tasks
- [ ] Order supplies as needed

---

### Weekly Tasks

**Monday:**
- [ ] Seed scheduled batches
- [ ] Update production calendar
- [ ] Review week's schedule

**Tuesday/Wednesday:**
- [ ] Major harvest days
- [ ] Transplant scheduled batches
- [ ] Quality control checks

**Thursday:**
- [ ] System maintenance and cleaning
- [ ] Water quality testing
- [ ] Nutrient adjustments

**Friday:**
- [ ] Final harvests for week
- [ ] Update all tracking records
- [ ] Plan following week
- [ ] Order supplies for next 2 weeks

---

### Monthly Tasks

**First Week of Month:**
- [ ] Review previous month's performance
- [ ] Analyze actual vs. planned yields
- [ ] Calculate revenue and costs by crop
- [ ] Identify top performers and underperformers
- [ ] Adjust production plan if needed

**Mid-Month:**
- [ ] Deep cleaning of one production zone
- [ ] Equipment maintenance and inspection
- [ ] Inventory seed and supply stocks
- [ ] Plan next month's crop mix

**End of Month:**
- [ ] Financial review and reporting
- [ ] Customer feedback collection
- [ ] Team performance review
- [ ] Update annual production plan

---

### Quarterly Tasks

**Every 3 Months:**
- [ ] Comprehensive facility inspection
- [ ] Major equipment servicing
- [ ] Review and update standard operating procedures
- [ ] Evaluate crop portfolio performance
- [ ] Consider variety or crop changes
- [ ] Adjust for upcoming seasonal changes
- [ ] Plan variety trials for next quarter
- [ ] Staff training and development

---

### Seasonal Adjustments

**Spring (March-May):**
- [ ] Transition from winter to spring crop cycles
- [ ] Reduce supplemental lighting gradually
- [ ] Adjust seeding quantities for faster growth
- [ ] Plan for increased production capacity

**Summer (June-August):**
- [ ] Optimize for fastest crop cycles
- [ ] Maximize turns and production volume
- [ ] Monitor cooling systems closely
- [ ] Consider heat-sensitive crop adjustments

**Fall (September-November):**
- [ ] Prepare for slower winter cycles
- [ ] Increase seeding quantities gradually
- [ ] Test supplemental lighting systems
- [ ] Adjust customer expectations for winter

**Winter (December-February):**
- [ ] Operate with extended crop cycles (+25-33%)
- [ ] Use supplemental lighting as needed
- [ ] Maintain consistent temperatures
- [ ] Focus on high-value crops to offset increased costs

## Critical Success Factors

### Never Skip These:

**Succession Seeding:**
- [ ] Seed on schedule every single week without fail
- [ ] Missing even one week creates a gap in harvest flow
- [ ] Build seeding into routine, make it non-negotiable

**Record Keeping:**
- [ ] Document every batch (seed date, transplant, harvest)
- [ ] Record actual yields and quality
- [ ] Track issues and resolutions
- [ ] Use data to continuously improve

**Quality Control:**
- [ ] Inspect every harvest for quality standards
- [ ] Never compromise on quality to meet volume
- [ ] Maintain customer specifications consistently

**Customer Communication:**
- [ ] Provide harvest forecasts weekly
- [ ] Communicate any issues or shortages immediately
- [ ] Gather feedback regularly
- [ ] Adjust production to meet evolving needs

**System Maintenance:**
- [ ] Daily checks prevent major failures
- [ ] Clean and sanitize on schedule
- [ ] Replace worn components proactively
- [ ] Keep backup supplies on hand

## Emergency Protocols

### Crop Loss Event:

1. [ ] Assess extent of loss immediately
2. [ ] Identify cause and remediate
3. [ ] Calculate impact on harvest schedule
4. [ ] Notify affected customers ASAP
5. [ ] Activate replacement crop protocol
6. [ ] Seed additional batches if needed
7. [ ] Document incident and prevention measures

### Equipment Failure:

1. [ ] Switch to backup systems if available
2. [ ] Protect crops from environmental stress
3. [ ] Contact repair services immediately
4. [ ] Assess timeline for resolution
5. [ ] Communicate with customers if harvest affected
6. [ ] Document failure and add to preventive maintenance

### Unexpected Demand Surge:

1. [ ] Review available buffer inventory
2. [ ] Check upcoming harvest schedule
3. [ ] Identify fast-growing backup crops
4. [ ] Communicate realistic delivery timeline
5. [ ] Consider premium pricing for rush orders
6. [ ] Increase seeding for future demand

## Key Performance Indicators (KPIs) to Track

**Production Metrics:**
- [ ] Actual vs. planned harvest dates (±2 days target)
- [ ] Yield per batch vs. target (>95% of expected)
- [ ] Quality pass rate (>90%)
- [ ] Crop loss percentage (<7%)
- [ ] Space utilization (>85% productive space)

**Financial Metrics:**
- [ ] Revenue per square foot per year
- [ ] Gross margin by crop
- [ ] Labor cost per pound/unit
- [ ] Waste percentage (<5%)
- [ ] Customer retention rate (>90%)

**Operational Metrics:**
- [ ] On-time delivery rate (>95%)
- [ ] Germination rate by crop and seed lot
- [ ] Transplant success rate (>90%)
- [ ] Succession schedule adherence (100%)
- [ ] Equipment uptime (>98%)
