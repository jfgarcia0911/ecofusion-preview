## Yield Calculation Formulas

```
YIELD ESTIMATION FORMULAS

┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  BASIC YIELD CALCULATION                                                    │
│  ───────────────────────────────────────────────────────────────────────    │
│                                                                             │
│  Annual Yield = Growing Area × Yield/sq ft/cycle × Cycles/year              │
│                                                                             │
│  Example: 4,000 sq ft × 1.5 lbs × 10 cycles = 60,000 lbs/year               │
│                                                                             │
│                                                                             │
│  CYCLES PER YEAR                                                            │
│  ───────────────────────────────────────────────────────────────────────    │
│                                                                             │
│  Cycles/year = 365 ÷ Crop Cycle Days                                        │
│                                                                             │
│  Example: 365 ÷ 35 days = 10.4 cycles → use 10 cycles                       │
│                                                                             │
│  Note: Account for turnover time (cleaning, replanting) - typically 1-3    │
│  days between cycles                                                        │
│                                                                             │
│                                                                             │
│  WEEKLY PRODUCTION                                                          │
│  ───────────────────────────────────────────────────────────────────────    │
│                                                                             │
│  Weekly Harvest = Annual Yield ÷ 52 weeks                                   │
│                                                                             │
│  OR                                                                         │
│                                                                             │
│  Weekly Harvest = (Growing Area ÷ Batches) × Yield/sq ft                    │
│                                                                             │
│  Where: Batches = Crop Cycle ÷ Succession Interval                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## Yield Adjustment Factors

### Environmental Factors

| Factor | Impact on Yield | Adjustment |
|--------|----------------|------------|
| Suboptimal temperature | -10% to -30% | Adjust climate control |
| Low light (DLI < 12) | -15% to -40% | Add supplemental lighting |
| High light (DLI > 20 for lettuce) | -5% to -15% | Add shading |
| VPD out of range | -10% to -25% | Adjust humidity/temp |
| CO2 enrichment (1000+ ppm) | +15% to +30% | Add CO2 system |

### Operational Factors

| Factor | Impact on Yield | Adjustment |
|--------|----------------|------------|
| First-year operation | -20% to -40% | Budget conservatively |
| Experienced team | +10% to +20% | Improve training |
| Optimized variety | +10% to +25% | Conduct variety trials |
| Pest/disease pressure | -10% to -50% | Improve IPM |
| Nutrient optimization | +5% to +15% | Fine-tune formulas |

### Seasonal Factors (for greenhouses)

| Season | Light Adjustment | Temperature Adjustment | Net Yield Impact |
|--------|-----------------|----------------------|------------------|
| Winter (Dec-Feb) | -20% to -40% | More heating | -15% to -35% |
| Spring (Mar-May) | Baseline | Moderate | Baseline |
| Summer (Jun-Aug) | +10% to +20% | More cooling | +5% to +15% |
| Fall (Sep-Nov) | -10% to -20% | Moderate | -5% to -15% |

## Yield Loss Budget

```
REALISTIC YIELD CALCULATION

Theoretical Maximum Yield
├── Germination Loss (5-15%).............. -10%
├── Transplant Loss (2-5%)................ -3%
├── Crop Care Loss (3-8%)................. -5%
├── Pest/Disease Loss (2-10%)............. -5%
├── Quality Cull at Harvest (5-15%)....... -10%
└── Handling/Packing Loss (2-5%).......... -3%
                                          ─────
    Total Loss Factor..................... -36%

Realistic Yield = Theoretical × 0.64 (or 64%)

EXAMPLE:
Theoretical: 100 lbs/week
Realistic: 100 × 0.64 = 64 lbs/week

For planning, use:
- Conservative: 55-65% of theoretical
- Moderate: 65-75% of theoretical
- Optimistic: 75-85% of theoretical
```
