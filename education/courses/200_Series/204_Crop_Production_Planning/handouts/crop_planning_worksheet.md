## Quick Reference Formulas

```
PRODUCTION PLANNING FORMULAS

┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  YIELD CALCULATIONS                                                         │
│  ─────────────────────────────────────────────────────────────────────────  │
│  Plants per sq ft = 144 ÷ (spacing in inches)²                              │
│                                                                             │
│  Yield per cycle = (sq ft × plants/sq ft × yield/plant)                     │
│                                                                             │
│  Annual yield = yield per cycle × cycles per year                           │
│                                                                             │
│                                                                             │
│  SUCCESSION PLANTING                                                        │
│  ─────────────────────────────────────────────────────────────────────────  │
│  Batches needed = crop cycle days ÷ succession interval                     │
│                                                                             │
│  Weekly trays = (weekly target lbs ÷ yield per tray)                        │
│                                                                             │
│  Seeds per week = trays × cells per tray × (1 + overseed %)                 │
│                                                                             │
│                                                                             │
│  ECONOMICS                                                                  │
│  ─────────────────────────────────────────────────────────────────────────  │
│  Cost per lb = (input cost + labor cost) ÷ yield in lbs                     │
│                                                                             │
│  Gross margin = (revenue - cost) ÷ revenue × 100                            │
│                                                                             │
│  Break-even volume = fixed costs ÷ (price - variable cost per unit)         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
