## Color/Symbol Key

```
CALENDAR MARKING LEGEND

  🌱 or [S] = Seeding Day
  🌿 or [T] = Transplant Day
  🥬 or [H] = Harvest Day
  📦 or [D] = Delivery Day
  🔧 or [M] = Maintenance Day

CROP COLOR CODES (use highlighters or colored pens)
┌────────────────┬──────────┐
│ Lettuce        │ GREEN    │
│ Herbs          │ PURPLE   │
│ Spinach        │ BLUE     │
│ Microgreens    │ YELLOW   │
│ Tomatoes       │ RED      │
```
