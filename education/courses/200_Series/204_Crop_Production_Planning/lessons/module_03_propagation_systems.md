## Introduction

Effective propagation is the foundation of successful succession planting. Your ability to consistently produce healthy, vigorous seedlings on schedule directly impacts harvest timing, crop quality, and overall profitability. Poor propagation leads to gaps in production, missed deliveries, and lost revenue.

This module covers the systems, techniques, and calculations needed to run a reliable propagation program that supports continuous commercial production.

## Germination Optimization

### Critical Germination Factors

```
┌────────────────────────────────────────────────────────────────────────┐
│                    GERMINATION REQUIREMENTS                            │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│  FACTOR 1: MOISTURE                                                    │
│  ═════════════════                                                     │
│  Too Dry → Seeds won't germinate                                      │
│  Optimal → Moist but not waterlogged, visible moisture on surface     │
│  Too Wet → Damping off, poor oxygen, fungal issues                    │
│                                                                        │
│  Control method: Humidity dome + bottom watering or misting           │
│  Target: Media surface moist, not dripping                            │
│                                                                        │
│  ────────────────────────────────────────────────────────────────      │
│                                                                        │
│  FACTOR 2: TEMPERATURE                                                 │
│  ══════════════════════                                                │
│                                                                        │
│  Crop Type           Optimal Temp    Range        Germ Time           │
│  ───────────────────────────────────────────────────────────────      │
│  Lettuce             65-70°F         60-75°F      3-5 days            │
│  Basil               75-80°F         70-85°F      5-10 days           │
│  Tomato              70-80°F         65-85°F      5-8 days            │
│  Arugula             60-70°F         55-75°F      3-5 days            │
│                                                                        │
│  Control: Heat mats (for warmth-loving), cool room (lettuce)          │
│                                                                        │
│  ────────────────────────────────────────────────────────────────      │
│                                                                        │
│  FACTOR 3: LIGHT                                                       │
│  ════════════════                                                      │
│                                                                        │
│  During germination: Most seeds germinate in DARK                      │
│  • Cover trays with humidity dome (blocks light)                      │
│  • Some crops need light (lettuce can benefit from light)             │
│                                                                        │
│  After germination: IMMEDIATE light needed                             │
│  • Move to lights within 12-24 hours of emergence                     │
│  • 14-16 hours/day photoperiod                                         │
│  • 100-200 μmol/m²/s for seedlings                                     │
│                                                                        │
│  ────────────────────────────────────────────────────────────────      │
│                                                                        │
│  FACTOR 4: OXYGEN                                                      │
│  ═════════════════                                                     │
│  Seeds need oxygen to germinate                                        │
│  • Don't oversaturate media                                            │
│  • Use well-draining media                                             │
│  • Provide air circulation once sprouted                               │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘
```

### Germination Protocols

```
STANDARD GERMINATION PROTOCOL
═════════════════════════════

Day 0: SEEDING
□ Pre-moisten plugs (rockwool: soak 30 min, drain)
□ Dibble holes to appropriate depth (2-3× seed diameter)
□ Place 1 seed per cell
□ Cover with vermiculite or media (light cover for small seeds)
□ Label with crop, variety, date, batch number
□ Place in germination area

Day 0-3: GERMINATION PHASE
□ Maintain humidity dome coverage
□ Temperature: Optimal for crop (see chart above)
□ Light: Covered/dark for most crops
□ Check moisture 2×/day, mist if surface drying
□ No nutrients needed yet

Day 3-7: EMERGENCE
□ Check daily for emergence
□ IMMEDIATELY move sprouted trays to light
□ Remove humidity dome gradually (vent for 1 day, then remove)
□ Reduce temperature slightly (5°F cooler)
□ Begin air circulation (small fans)

Day 7-14: SEEDLING DEVELOPMENT
□ Full light exposure: 14-16 hrs/day
□ Temperature: Crop-specific optimal
□ Start light fertilization (¼ strength)
□ Monitor for damping off or stretching
□ Thin to one plant per cell if needed
```

## Propagation Space Design

### Space Requirements Calculation

```
╔════════════════════════════════════════════════════════════════════════╗
║             PROPAGATION SPACE REQUIREMENT FORMULA                      ║
╠════════════════════════════════════════════════════════════════════════╣
║                                                                        ║
║  Step 1: Calculate weekly tray requirements                            ║
║  ═══════════════════════════════════════                               ║
║  Trays/week = Seeds needed ÷ Cells per tray                           ║
║                                                                        ║
║  Step 2: Calculate total trays in propagation                          ║
║  ════════════════════════════════════════════                          ║
║  Total trays = Trays/week × Weeks in propagation                      ║
║                                                                        ║
║  Step 3: Calculate space needed                                        ║
║  ═══════════════════════════                                           ║
║  Space (sq ft) = Total trays × 1.4 sq ft per tray                     ║
║  (1.4 includes tray footprint + access space)                          ║
║                                                                        ║
╚════════════════════════════════════════════════════════════════════════╝


WORKED EXAMPLE: Butterhead Lettuce
══════════════════════════════════

Weekly seeds needed: 400
Tray size: 128-plug
Propagation time: 2 weeks

Step 1: 400 seeds ÷ 128 cells = 3.13 → 4 trays per week

Step 2: 4 trays/week × 2 weeks = 8 trays total in propagation

Step 3: 8 trays × 1.4 sq ft = 11.2 sq ft needed for this crop


MULTI-CROP EXAMPLE
══════════════════

Butterhead         4        2       8      11 sq ft

TOTAL PROPAGATION SPACE NEEDED             37 sq ft
```

## Transplanting Protocols

### Transplant Readiness

```
┌────────────────────────────────────────────────────────────────────────┐
│                 SEEDLING TRANSPLANT READINESS CRITERIA                 │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│  READY TO TRANSPLANT:                                                  │
│  ═══════════════════                                                   │
│  ✓ True leaves developed (2-4 true leaves)                             │
│  ✓ Roots visible at bottom of plug                                     │
│  ✓ Roots hold plug together when removed                               │
│  ✓ Stem sturdy, not stretched                                          │
│  ✓ Dark green color (adequate nutrition)                               │
│  ✓ No disease or pest issues                                           │
│                                                                        │
│  NOT READY - TOO YOUNG:                                                │
│  ═══════════════════════                                               │
│  ✗ Only cotyledons, no true leaves                                     │
│  ✗ Roots not visible                                                   │
│  ✗ Plug falls apart when handled                                       │
│  → WAIT 3-7 more days                                                  │
│                                                                        │
│  NOT READY - TOO OLD:                                                  │
│  ═══════════════════════                                               │
│  ✗ Roots circling excessively (root-bound)                             │
│  ✗ Yellowing lower leaves                                              │
│  ✗ Stunted growth                                                      │
│  → TRANSPLANT IMMEDIATELY or discard                                   │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘
```

### Transplanting Best Practices

```
TRANSPLANTING PROCEDURE
═══════════════════════

PREPARATION:
□ Clean and sanitize production system
□ Check water quality and temperature
□ Adjust nutrients to appropriate strength (½ full for new transplants)
□ Gather all needed materials
□ Schedule labor (200-400 plants/hour per person)

PROCESS:
□ Water seedling trays 1-2 hours before transplanting
□ Handle seedlings gently by leaves, not stems
□ Insert plug to appropriate depth:
  • Top of plug level with growing media/net pot rim
  • Not too deep (crown rot risk)
  • Not too shallow (drying out risk)
□ Ensure good contact between plug and system
□ Label rows/sections with variety and date

POST-TRANSPLANT CARE:
□ Reduce light by 25% for first 2-3 days (if possible)
□ Keep temperature slightly cooler (5°F)
□ Monitor closely for wilting or stress
□ Check that water is reaching plugs
□ Resume full light and temp by day 4
```

## Common Propagation Problems

### Troubleshooting Guide

| Problem | Cause | Solution |
|---------|-------|----------|
| **Poor germination (<85%)** | Old seeds, wrong temp, too dry | Test seed viability, check temperature, increase moisture |
| **Damping off (seedling collapse)** | Fungal disease, too wet, poor air flow | Reduce moisture, improve air circulation, sanitize |
| **Leggy/stretched seedlings** | Insufficient light, too warm | Increase light intensity, lower temperature |
| **Yellow seedlings** | Nutrient deficiency, pH issue | Start light fertilization, check pH |
| **Algae on media surface** | Too wet, stagnant | Reduce moisture, improve air flow, less overhead watering |
| **Uneven germination** | Uneven moisture/temp, old seeds | Improve uniformity, test seeds, replace old stock |

## Module Summary

### Key Takeaways

1. **Transplant production is standard** - More efficient than direct seeding for most commercial crops

2. **Select appropriate plug sizes** - 128-plug for most lettuce/herbs, 72-plug for basil, 50-plug for fruiting crops

3. **Optimize germination conditions** - Moisture, temperature, and light must be crop-specific and carefully controlled

4. **Calculate propagation space needs** - Based on weekly seeding volume and crop propagation time

5. **Develop transplanting protocols** - Timing, handling, and post-transplant care affect success rates

6. **Track batches systematically** - Maintain records for quality control and continuous improvement

7. **Quality control is essential** - Daily monitoring prevents small issues from becoming major losses

8. **Troubleshoot proactively** - Address propagation problems immediately to protect production schedules
