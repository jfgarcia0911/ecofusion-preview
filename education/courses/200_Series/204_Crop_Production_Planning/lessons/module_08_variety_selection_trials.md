## Introduction

Variety selection can make or break your production success. The right variety for your system, climate, and market can yield 30-50% more than a poor choice. Beyond yield, varieties differ in disease resistance, growth speed, flavor, appearance, and shelf life—all factors that impact profitability.

This module teaches you to evaluate, test, and select the best-performing varieties for your operation.

## Designing Variety Trials

### Trial Protocol

```
VARIETY TRIAL DESIGN
════════════════════

OBJECTIVE: Compare 3-5 varieties to identify best performer

TRIAL SETUP:
────────────
• Minimum 3 varieties (including current standard)
• 20-30 plants per variety (statistical significance)
• Identical growing conditions for all
• Same seeding date
• Same location/system
• Random or blocked arrangement
• Clear labeling

TIMELINE:
─────────
• Test through minimum 3 full cycles
• Span different seasons if possible
• 3-6 months total for most crops

DATA COLLECTION:
────────────────

Week 0: SEEDING
□ Number of seeds planted per variety
□ Seed lot numbers
□ Seeding date

Week 1-2: GERMINATION
□ Germination count and percentage
□ Days to emergence
□ Seedling vigor rating

Week 2-4: TRANSPLANT
□ Transplant date
□ Number transplanted
□ Seedling quality score

Weekly: GROWTH MONITORING
□ Growth rate observations
□ Disease/pest incidence
□ Environmental anomalies

Harvest: PERFORMANCE DATA
□ Harvest date (DTM calculation)
□ Total plants harvested
□ Marketable vs. culls
□ Weight per plant (sample 10+)
□ Quality scores (sample 10+)
□ Photos for documentation

Post-Harvest:
□ Shelf life testing (sample storage)
□ Customer feedback (if possible)

ANALYSIS:
─────────
Calculate for each variety:
• Average yield per plant
• Marketable percentage
• Actual DTM
• Disease incidence
• Quality scores
• Revenue per square foot

Compare to current standard variety
Identify statistically significant differences
```

## Variety Planning and Rotation

### Seasonal Variety Selection

```
SEASONAL VARIETY STRATEGY
══════════════════════════

Different varieties excel in different conditions
Plan rotation to optimize for season

LETTUCE EXAMPLE:
────────────────

Spring/Summer (High light, warmer)
• Heat-tolerant varieties
• Bolt-resistant types
• Faster-growing options
Varieties: 'Nevada', 'Skyphos', 'Muir'

Fall/Winter (Low light, cooler)
• Cold-tolerant varieties
• Slower bolting
• Better low-light performance
Varieties: 'Rex', 'Buttercrunch', 'Ostinata'

BASIL EXAMPLE:
──────────────

Summer (High heat, light)
• Standard Genovese types
• Maximum production
Varieties: 'Nufar', 'Eleonora'

Winter (Lower temps possible)
• More tolerant varieties
• Compact types for efficiency
Varieties: 'Prospera', 'Dolly'

BENEFITS:
• Optimized performance year-round
• Risk mitigation (variety failures)
• Market variety/interest
• Continuous learning
```

### Market-Driven Variety Mix

```
VARIETY PORTFOLIO STRATEGY
═══════════════════════════

CORE VARIETIES (70-80% of production)
──────────────────────────────────────
• Proven performers
• High demand
• Reliable
• Year-round production
• Established pricing

Example: Standard butterhead, Genovese basil, cherry tomatoes

ROTATION VARIETIES (15-25%)
────────────────────────────
• Seasonal specialties
• Color variations
• Size options
• Customer requests

Example: Red butterhead, red leaf, purple basil

TRIAL VARIETIES (5-10%)
────────────────────────
• New releases
• Potential improvements
• Market tests
• Innovation

Example: New varieties, unique items, trendy crops

STRATEGY:
• Maintain consistency (core)
• Offer variety (rotation)
• Stay innovative (trials)
• Don't over-complicate (limit SKUs)
```

## New Variety Introduction

### Implementation Process

```
┌────────────────────────────────────────────────────────────────────────┐
│              NEW VARIETY INTRODUCTION PROTOCOL                         │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│  PHASE 1: RESEARCH (2-4 weeks)                                         │
│  ══════════════════════════                                            │
│  □ Identify candidate varieties                                        │
│  □ Review breeder specifications                                       │
│  □ Read grower reviews/forums                                          │
│  □ Consult seed suppliers                                              │
│  □ Check disease resistance claims                                     │
│  □ Verify market acceptance                                            │
│                                                                        │
│  PHASE 2: SMALL-SCALE TRIAL (8-12 weeks)                               │
│  ════════════════════════════════════════                              │
│  □ Order trial quantity seeds                                          │
│  □ Conduct formal variety trial (see protocol above)                   │
│  □ Document all metrics                                                │
│  □ Compare to current variety                                          │
│  □ Get customer feedback on samples                                    │
│                                                                        │
│  PHASE 3: DECISION (1 week)                                            │
│  ═══════════════════════                                               │
│  □ Analyze trial data                                                  │
│  □ Calculate projected improvements                                    │
│  □ Consider risks/challenges                                           │
│  □ Make go/no-go decision                                              │
│                                                                        │
│  PHASE 4: PHASE-IN (4-12 weeks)                                        │
│  ═══════════════════════════════                                       │
│  □ Order production quantity seeds                                     │
│  □ Start with 25-50% of space                                          │
│  □ Maintain old variety as backup                                      │
│  □ Monitor performance closely                                         │
│  □ Gather customer feedback                                            │
│  □ Adjust production practices if needed                               │
│                                                                        │
│  PHASE 5: FULL ADOPTION (After success)                                │
│  ════════════════════════════════════════                              │
│  □ Scale to full production                                            │
│  □ Update all documentation                                            │
│  □ Train staff on any unique requirements                              │
│  □ Update marketing materials                                          │
│  □ Continue performance monitoring                                     │
│                                                                        │
│  DON'T:                                                                │
│  • Switch 100% of production immediately                               │
│  • Introduce multiple new varieties simultaneously                     │
│  • Skip trials ("it should work")                                      │
│  • Ignore early warning signs                                          │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘
```

## Module Summary

### Key Takeaways

1. **Variety selection significantly impacts profitability** - 30-50% performance differences are common between varieties

2. **Systematic trials are essential** - Don't rely on catalogs alone; test in your conditions

3. **Evaluate multiple factors** - Yield is important, but also consider quality, consistency, disease resistance, market fit

4. **Source quality seeds** - Don't compromise on seed quality; cost is minimal compared to value

5. **Plan variety rotation seasonally** - Different varieties perform better in different conditions

6. **Introduce new varieties gradually** - Phase in over time with trials and monitoring

7. **Maintain detailed records** - Document performance for continuous improvement and decision-making

8. **Balance core and trial varieties** - Stability from proven performers, innovation from trials
