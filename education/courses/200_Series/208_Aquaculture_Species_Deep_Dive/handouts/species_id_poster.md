```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│    CHANNEL CATFISH - The Hardy American Classic           │
│                                                            │
│           Dorsal Fin                                       │
│      Adipose Fin  │                                        │
│           │      ┌┴┐                                       │
│          ┌┴┐    ╱─ ─╲                                      │
│          └─┘ ╱ ●     ╲══════════╗                         │
│     ╱╲╱╲╱  ╱  8 Barbels  ║      ║ Forked Tail            │

│           ║                ║      ║                       │

│       Pectoral Fin (spine!)  Anal Fin                     │

│  • Deeply forked tail                                     │
│  • Scaleless, slimy skin                                  │

│  ✓ Count barbels - should be 8 total                     │
│  ✓ Look for deeply forked tail                           │
│  ✓ Bottom-dwelling behavior                              │
│  ✓ Handle with care - spines can puncture!               │
│                                                            │
│  MARKET SIZE: 1-2 lbs | TIME: 8-12 months | TEMP: 75-85°F│
│                                                            │
└────────────────────────────────────────────────────────────┘
```
