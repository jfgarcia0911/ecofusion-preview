## Learning Objectives

By the end of this module, you will be able to:

## Why Accurate Identification Matters

```
╔═══════════════════════════════════════════════════════════════════════════╗
║                                                                           ║
║               WRONG IDENTIFICATION = FAILED CONTROL                       ║
║                                                                           ║
║   Example 1: Whiteflies vs. Fungus Gnats                                ║
║   ─────────────────────────────────────────────                          ║
║   Both are small flying insects on sticky traps                          ║
║   • Whiteflies feed on plant sap (damage plants directly)               ║
║   • Fungus gnats feed on organic matter (mostly nuisance)               ║
║   → Different control strategies needed!                                 ║
║                                                                           ║
║   Example 2: Spider Mites vs. Russet Mites                              ║
║   ────────────────────────────────────────────                           ║
║   Both cause stippling on leaves                                         ║
║   • Spider mites visible with hand lens                                 ║
║   • Russet mites need microscope (much smaller)                         ║
║   → Russet mites need more aggressive treatment!                        ║
║                                                                           ║
║   COST OF MISIDENTIFICATION:                                             ║
║   • Wasted money on ineffective treatments                              ║
║   • Pest population continues growing                                   ║
║   • Crop damage worsens                                                 ║
║   • Lost time and opportunity                                           ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

## Major Pest Categories

### 1. Sucking Insects (Piercing-Sucking)

These pests have needle-like mouthparts that pierce plant tissue and suck sap.

```
    COMMON SUCKING PESTS
    ══════════════════

    APHIDS               WHITEFLIES          THRIPS
    ......               ..........          ......
    .    .               \      /            |  |
    .OOOO.                \    /             |==|

    ......                  \/               |  |
     ||||                   ||               ||||

    • Pear-shaped        • Tiny white        • Slender
    • Soft-bodied          moths             • Fast-moving
    • Often green        • Waxy coating      • Dark/yellow
    • In clusters        • Fly when          • Hide in flowers
    • Honeydew             disturbed         • Rasping damage

## Pest Identification Guide

### Aphids

```
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   APHID IDENTIFICATION CARD                                 │
    │   ═══════════════════════════                               │
    │                                                             │
    │   SIZE: 1-3mm (pinhead to match head)                      │
    │                                                             │
    │   COLOR: Green, black, yellow, pink, white, gray           │
    │                                                             │
    │   BODY: Pear-shaped, soft, may have waxy coating           │
    │                                                             │
    │   LOCATION: Undersides of young leaves, stems, shoots      │
    │                                                             │
    │   BEHAVIOR:                                                 │
    │   • Usually in colonies                                     │
    │   • Both winged and wingless forms                         │
    │   • Produce honeydew (sticky)                              │
    │   • Attended by ants (farming for honeydew)                │
    │                                                             │
    │   DAMAGE SIGNS:                                             │
    │   • Curled, distorted leaves                               │
    │   • Yellowing                                               │
    │   • Sticky honeydew on leaves below                        │
    │   • Black sooty mold on honeydew                           │
    │   • Stunted new growth                                      │
    │   • White cast skins                                        │
    │                                                             │
    │   CROPS MOST AFFECTED:                                      │
    │   Lettuce, herbs, tomatoes, peppers, cucurbits             │
    │                                                             │
    │   REPRODUCTION:                                             │
    │   Females give live birth (no eggs!) - 5-10 nymphs/day     │
    │   Can reach 100s in 1-2 weeks                              │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

### Whiteflies

```
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   WHITEFLY IDENTIFICATION CARD                              │
    │   ══════════════════════════                                │
    │                                                             │
    │   SIZE: 1-2mm (smaller than aphid)                         │
    │                                                             │
    │   APPEARANCE:                                               │
    │   • Tiny white moth-like insects                           │
    │   • Wedge-shaped with 4 white wings                        │
    │   • Covered in white waxy powder                           │
    │                                                             │
    │   LOCATION: Undersides of leaves                            │
    │                                                             │
    │   BEHAVIOR:                                                 │
    │   • Fly up in cloud when plant disturbed                   │
    │   • Poor fliers - short flights                            │
    │   • Settle quickly after disturbance                       │
    │                                                             │
    │   LIFE STAGES ON PLANT:                                     │
    │   • Eggs: Tiny, cone-shaped, on leaf underside             │
    │   • Crawlers: Mobile for few hours, then settle            │
    │   • Scales: Flat, oval, attached to leaf (4 instars)       │
    │   • Pupae: Thicker, with visible eye spots                 │
    │   • Adults: Flying white insects                           │
    │                                                             │
    │   DAMAGE SIGNS:                                             │
    │   • Yellowing, stippled leaves                             │
    │   • Honeydew and sooty mold                                │
    │   • Weakened plants                                         │
    │   • Virus transmission (TYLCV in tomatoes)                 │
    │                                                             │
    │   CROPS MOST AFFECTED:                                      │
    │   Tomatoes, peppers, cucumbers, poinsettias, herbs         │
    │                                                             │
    │   KEY DIFFERENCE FROM FUNGUS GNATS:                         │
    │   Whiteflies are WHITE, rest on leaves, fly when touched   │
    │   Fungus gnats are DARK, hover near media, don't rest      │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

### Thrips

```
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   THRIPS IDENTIFICATION CARD                                │
    │   ════════════════════════                                  │
    │                                                             │
    │   SIZE: 1-2mm (slender, cigar-shaped)                      │
    │                                                             │
    │   COLOR: Yellow, brown, or black                            │
    │                                                             │
    │   APPEARANCE:                                               │
    │   • Very slender body                                       │
    │   • Fringed wings (look like feathers)                     │
    │   • Fast-moving                                             │
    │                                                             │
    │   LOCATION:                                                 │
    │   • Inside flowers and buds                                 │
    │   • Between petals                                          │
    │   • On young leaves                                         │
    │   • Hide when disturbed                                     │
    │                                                             │
    │   FEEDING METHOD:                                           │
    │   • Rasp surface cells with mouthparts                     │
    │   • Suck released plant fluids                             │
    │   • Creates silvery scarring                               │
    │                                                             │
    │   DAMAGE SIGNS:                                             │
    │   • Silver/bronze streaks on leaves                        │
    │   • Black fecal spots (looks like pepper)                  │
    │   • Distorted flowers and buds                             │
    │   • Silvery scars on fruit                                 │
    │   • Leaf curling                                            │
    │                                                             │
    │   SERIOUS CONCERN:                                          │
    │   Vector for Tomato Spotted Wilt Virus (TSWV) and         │
    │   Impatiens Necrotic Spot Virus (INSV) - NO CURE!          │
    │                                                             │
    │   CROPS MOST AFFECTED:                                      │
    │   Peppers, cucumbers, ornamentals, onions, herbs           │
    │                                                             │
    │   DETECTION:                                                │
    │   • Shake flowers over white paper                         │
    │   • Look for tiny moving "slivers"                         │
    │   • Blue sticky traps attract thrips                       │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

### Spider Mites

```
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   SPIDER MITE IDENTIFICATION CARD                           │
    │   ═════════════════════════════                             │
    │                                                             │
    │   SIZE: 0.5mm (barely visible, size of period: . )        │
    │                                                             │
    │   COLOR: Yellow-green, orange, or red (seasonal)           │
    │                                                             │
    │   IDENTIFICATION:                                           │
    │   • 8 legs (arachnid, not insect)                          │
    │   • Two spots on back (two-spotted spider mite)            │

    │                                                             │
    │   LOCATION: Underside of leaves                             │
    │                                                             │
    │   WEBBING:                                                  │

    │   • Webbing protects from predators and sprays             │
    │                                                             │
    │   DAMAGE SIGNS:                                             │
    │   • Yellow stippling (tiny dots) on leaves                 │
    │   • Bronze or gray appearance                              │
    │   • Premature leaf drop                                     │
    │   • Fine webbing                                            │
    │   • Starts on lower, older leaves                          │
    │   • Moves upward as population grows                       │
    │                                                             │
    │   ENVIRONMENTAL PREFERENCES:                                │
    │   • Hot temperatures (>80°F)                               │
    │   • Low humidity (<50%)                                    │
    │   • Dusty conditions                                        │
    │   • Water-stressed plants                                   │
    │                                                             │
    │   REPRODUCTION RATE:                                        │
    │   Complete life cycle in 7-10 days at 80°F                 │
    │   Female lays 100-200 eggs in lifetime                     │
    │   Population can DOUBLE every 3 days!                      │
    │                                                             │
    │   CROPS MOST AFFECTED:                                      │
    │   Tomatoes, peppers, cucumbers, beans, strawberries        │
    │                                                             │
    │   QUICK TEST:                                               │
    │   Hold white paper under leaf, tap leaf sharply.           │
    │   Look for tiny moving specks on paper.                    │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

```

## Damage Pattern Recognition

```
    DAMAGE TYPE                    LIKELY PEST
    ═══════════                    ═══════════

    Stippling (tiny yellow dots)   Spider mites, thrips

    Honeydew + sooty mold          Aphids, whiteflies, scales

    Holes with frass               Caterpillars

    Chewed leaf edges              Beetles, caterpillars

    Leaf mines (trails)            Leafminer flies

    Distorted new growth           Aphids, broad mites, virus

    Bronzing of leaves             Spider mites (heavy)

    Silvery streaks                Thrips

    Wilting despite water          Root aphids, root rot, nematodes

    White fuzzy coating            Mealybugs, whitefly scales

    Webbing                        Spider mites, some caterpillars
```

## Module Summary

### Key Takeaways

1. **Accurate identification is critical** - wrong ID leads to failed control
2. **Know the major pest categories**: sucking insects, mites, chewing insects, root-zone pests
3. **Use proper tools**: hand lens, microscope, sticky traps, reference guides
4. **Look for multiple clues**: location, damage type, pest appearance, behavior
5. **Don't confuse beneficial insects with pests** - protect your allies
6. **When in doubt, send samples to a diagnostic lab** - worth the cost

| Aphids | 1-3mm | Pear-shaped, colonies | Curled leaves, honeydew |
| Whiteflies | 1-2mm | White wings, fly when touched | Yellowing, honeydew, virus |
| Spider Mites | 0.5mm | Webbing, stippling | Yellow dots, bronzing |
| Thrips | 1-2mm | Slender, in flowers | Silver streaks, black dots |
| Fungus Gnats | 3mm adult | Dark flies near media | Root damage (larvae) |
| Mealybugs | 2-5mm | White fuzzy coating | Honeydew, stunting |
| Scales | 1-3mm | Bumps on stems | Yellowing, honeydew |
