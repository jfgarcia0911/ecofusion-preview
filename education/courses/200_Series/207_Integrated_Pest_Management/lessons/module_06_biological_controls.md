## What is Biological Control?

```
╔═══════════════════════════════════════════════════════════════════════════╗
║                                                                           ║
║     BIOLOGICAL CONTROL = Using Living Organisms to Control Pests         ║
║                                                                           ║
║   THREE TYPES:                                                            ║
║                                                                           ║
║   1. CLASSICAL BIOCONTROL                                                 ║
║      Import natural enemy from pest's origin                             ║
║      (Rarely used in greenhouses)                                        ║
║                                                                           ║
║   2. AUGMENTATIVE BIOCONTROL (Most common in CEA)                        ║
║      Release beneficial organisms to supplement populations              ║
║      • Inoculative: Small releases, establish and reproduce             ║
║      • Inundative: Large releases, immediate control                    ║
║                                                                           ║
║   3. CONSERVATION BIOCONTROL                                              ║
║      Create conditions that favor natural enemies                        ║
║      • Provide habitat                                                   ║
║      • Reduce pesticide impacts                                          ║
║      • Supply food sources (pollen, nectar, prey)                       ║
║                                                                           ║
║   ═══════════════════════════════════════════════════════════════════    ║
║                                                                           ║
║   ADVANTAGES:                      LIMITATIONS:                           ║
║   ═══════════                      ════════════                           ║
║   ✓ Sustainable long-term          • Slower acting than pesticides      ║
║   ✓ No chemical resistance         • Require planning and knowledge     ║
║   ✓ Target-specific                • Environmental sensitive            ║
║   ✓ Safe for workers/consumers     • Cost (upfront investment)          ║
║   ✓ Compatible with IPM            • Need pest presence to survive      ║
║   ✓ Self-reproducing (some)        • Incompatible with some pesticides  ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

### Parasitic Wasps

```
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   APHID PARASITOIDS (Aphidius, Aphelinus)                  │
    │   ══════════════════════════════════════                    │
    │                                                             │
    │   Size: Tiny (1-3mm long)                                  │
    │   Appearance: Black, delicate, non-stinging                │
    │                                                             │
    │   HOW THEY WORK:                                            │
    │   1. Female wasp finds aphid                                │
    │   2. Inserts egg into aphid body                           │
    │   3. Larva develops inside aphid                           │
    │   4. Aphid becomes "mummy" (tan, bloated shell)            │
    │   5. Adult wasp emerges from mummy (exit hole)             │
    │                                                             │
    │   Healthy Aphid:     Parasitized "Mummy":                  │
    │      .....               .....                              │
    │     . oo .              . xx .  ← Tan/brown                │
    │     . ^^ .              . xx .     Bloated                 │
    │      .....              . ● .   ← Exit hole                │
    │                          .....                              │
    │                                                             │
    │   TARGET PESTS: Aphids (species-specific)                  │
    │   RELEASE RATE: 1-3 per aphid OR 250-500 per 1,000 sq ft  │
    │   TEMPERATURE: 60-80°F                                      │
    │   CYCLE TIME: 2-3 weeks egg to adult                       │
    │                                                             │
    │   PROS: Self-reproducing, very effective, find aphids well │
    │   CONS: Need aphids present, slow initial impact           │
    │   MONITORING: Count mummies to assess effectiveness        │
    │                                                             │
    │   ─────────────────────────────────────────────────────    │
    │                                                             │
    │   WHITEFLY PARASITOIDS (Encarsia formosa)                  │
    │   ═══════════════════════════════════════                   │
    │                                                             │
    │   Size: 0.6mm (smaller than whitefly)                      │
    │   Appearance: Yellowish body, red eyes                     │
    │                                                             │
    │   HOW THEY WORK:                                            │
    │   • Female lays egg in whitefly scale (nymph stage)        │
    │   • Parasitized scale turns black                          │
    │   • Adult wasp emerges in 2-4 weeks                        │
    │                                                             │
    │   TARGET PESTS: Greenhouse whitefly (Trialeurodes)         │
    │   RELEASE RATE: 3-5 per plant weekly; 5-10 in hot spots   │
    │   TEMPERATURE: 65-85°F (stops working <60°F)               │
    │   LIGHTING: Needs 12+ hours light                          │
    │                                                             │
    │   PROS: Excellent greenhouse establishment                  │
    │   CONS: Temperature/light sensitive, species-specific      │
    │   MONITORING: Look for black (parasitized) scales          │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

## Banker Plant Systems

```
╔═══════════════════════════════════════════════════════════════════════════╗
║                                                                           ║
║                    BANKER PLANT CONCEPT                                   ║
║                                                                           ║
║   Problem: Beneficial insects need pest prey to survive                  ║
║   Solution: Provide non-crop hosts with alternative prey                 ║
║                                                                           ║
║   HOW IT WORKS:                                                           ║
║                                                                           ║
║   [Barley] ← Planted in greenhouse                                       ║
║      │                                                                    ║
║      ├─→ [Bird cherry-oat aphid] ← Harmless to crops                    ║
║      │         │                                                          ║
║      │         └─→ [Aphid parasitoids] ← Reproduce on banker aphids     ║
║      │                   │                                                ║
║      │                   └─→ Fly to crops → Control crop aphids          ║
║                                                                           ║
║   ADVANTAGES:                                                             ║
║   ✓ Continuous beneficial insect production                              ║
║   ✓ Preventive control (beneficials present before crop pests)          ║
║   ✓ Self-sustaining system                                               ║
║   ✓ Reduces need for repeated releases                                   ║
║                                                                           ║
║   ═══════════════════════════════════════════════════════════════════    ║
║                                                                           ║
║   COMMON BANKER SYSTEMS:                                                  ║
║                                                                           ║
║   FOR APHID CONTROL:                                                      ║
║   Crop plant: Barley, wheat, or oats                                     ║
║   Banker pest: Bird cherry-oat aphid (Rhopalosiphum padi)               ║
║   Beneficials: Aphidius colemani (parasitoid)                            ║
║   Setup: 1 pot per 100-200 sq ft                                         ║
║                                                                           ║
║   FOR WHITEFLY CONTROL:                                                   ║
║   Crop plant: Tobacco or eggplant                                        ║
║   Banker pest: Greenhouse whitefly                                       ║
║   Beneficials: Encarsia formosa                                          ║
║   Setup: More complex, less common                                       ║
║                                                                           ║
║   MANAGEMENT:                                                             ║
║   • Replace banker plants every 4-8 weeks                                ║
║   • Monitor for contamination with crop pests                            ║
║   • Keep separate from production (edge placement)                       ║
║   • Ensure banker aphids don't spread to crops                           ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

## Microbial Pesticides

```
╔═══════════════════════════════════════════════════════════════════════════╗
║                                                                           ║
║                    BENEFICIAL MICROORGANISMS                              ║
║                                                                           ║
║   BACILLUS THURINGIENSIS (Bt)                                            ║
║   ═══════════════════════════                                             ║
║   Type: Bacterium producing insecticidal proteins                        ║
║   Target: Caterpillars (lepidoptera larvae)                              ║
║   How it works: Toxin disrupts insect gut                                ║
║   Products: Dipel, Thuricide, Javelin                                    ║
║   Application: Spray on foliage, larvae must eat it                      ║
║   Safety: Non-toxic to humans, bees, beneficials                         ║
║   Limitations: Must be eaten, breaks down in sunlight                    ║
║                                                                           ║
║   Different strains for different pests:                                 ║
║   • Bt kurstaki (Btk): Caterpillars                                     ║
║   • Bt israelensis (Bti): Fungus gnat larvae, mosquitoes                ║
║                                                                           ║
║   ─────────────────────────────────────────────────────────              ║
║                                                                           ║
║   BEAUVERIA BASSIANA                                                      ║
║   ══════════════════                                                      ║
║   Type: Entomopathogenic fungus                                          ║
║   Target: Whiteflies, aphids, thrips, fungus gnats                       ║
║   How it works: Spores attach, penetrate insect, grow inside            ║
║   Products: BotaniGard, Mycotrol                                         ║
║   Application: Spray on plants and pests                                 ║
║   Conditions: Needs humidity >80% for 12+ hours                          ║
║   Safety: Generally safe, may cause allergies in handlers                ║
║   Limitations: Slow (7-14 days), humidity dependent                      ║
║                                                                           ║
║   ─────────────────────────────────────────────────────────              ║
║                                                                           ║
║   STEINERNEMA & HETERORHABDITIS NEMATODES                                ║
║   ═══════════════════════════════════════════                            ║
║   Type: Beneficial (entomopathogenic) nematodes                          ║
║   Target: Fungus gnat larvae, thrips pupae, other soil pests            ║
║   How it works: Nematodes enter insect, release bacteria                 ║
║   Products: NemaShield, Nemasys                                          ║
║   Application: Drench growing media                                      ║
║   Conditions: Moist media, 55-85°F                                       ║
║   Safety: Non-toxic to plants, animals, people                           ║
║   Limitations: Short shelf life, must keep cool, reapply                 ║
║                                                                           ║
║   Species:                                                                ║
║   • S. feltiae: Fungus gnats, thrips                                    ║
║   • H. bacteriophora: Root weevils, grubs                               ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

## Implementing Biological Control Programs

### Release Strategies

```
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   INOCULATIVE RELEASES                                      │
    │   ══════════════════════                                    │
    │   Goal: Establish population that reproduces                │
    │   Timing: Early, before pests arrive or at first detection │
    │   Rate: Low numbers (establish, not overwhelm)             │
    │   Frequency: Once or few times per season                  │
    │   Best for: Enclosed environments, long seasons            │
    │   Examples: Predatory mites, aphid parasitoids             │
    │                                                             │
    │   ─────────────────────────────────────────────────────    │
    │                                                             │
    │   INUNDATIVE RELEASES                                       │
    │   ═══════════════════                                       │
    │   Goal: Immediate pest reduction (not establishment)        │
    │   Timing: When pests detected above threshold              │
    │   Rate: High numbers for quick knockdown                   │
    │   Frequency: Repeat as needed                               │
    │   Best for: Acute infestations, outdoor, short crops       │
    │   Examples: Ladybugs, large lacewing releases              │
    │                                                             │
    │   ─────────────────────────────────────────────────────    │
    │                                                             │
    │   PREVENTIVE PROGRAMS                                       │
    │   ═══════════════════════                                   │
    │   Schedule: Weekly or biweekly releases                    │
    │   Approach: Regular small releases                          │
    │   Goal: Maintain beneficial population constantly          │
    │   Cost: Higher ongoing, but prevents outbreaks             │
    │   Best for: High-value crops, persistent pest pressure    │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

### Release Procedures

```
    PROPER RELEASE TECHNIQUE:

    1. TIMING
       • Early morning or evening (cool, calm)
       • Avoid hot, sunny conditions
       • Humidity >50%

    2. PLACEMENT
       • Distribute evenly throughout crop
       • Focus on pest hot spots
       • Near air intakes and doors
       • On lower leaves (many beneficials climb up)

    3. HANDLING
       • Keep cool until release (not refrigerator!)
       • Release within 24 hours of receipt
       • Don't shake containers roughly
       • Open carefully (some fly immediately)

    4. DOCUMENTATION
       • Record species, quantity, date
       • Note pest levels at time of release
       • Map release locations
       • Track environmental conditions

    5. POST-RELEASE
       • Monitor pest AND beneficial populations
       • Avoid pesticides (see compatibility chart)
       • Maintain optimal environment
       • Assess effectiveness after 1-2 weeks
```

## Module Summary

### Key Takeaways

1. **Biological control uses living organisms** - predators, parasitoids, pathogens
2. **Many options available** for common greenhouse pests (aphids, mites, whiteflies, thrips)
3. **Two strategies**: Inoculative (establish populations) vs. Inundative (quick knockdown)
4. **Banker plants** provide continuous beneficial insect production
5. **Microbial pesticides** (Bt, Beauveria, nematodes) are biological tools
6. **Compatibility matters** - avoid broad-spectrum pesticides with biocontrol programs

### Beneficial Insect Quick Reference

| Pest | Beneficial | Type | Release Rate |
|------|------------|------|--------------|
| Aphids | Aphidius wasps | Parasitoid | 1-3 per aphid |
| Aphids | Lacewing larvae | Predator | 1-5 eggs per plant |
| Spider Mites | Phytoseiulus | Predator | 2-10 per plant |
| Whiteflies | Encarsia formosa | Parasitoid | 3-5 per plant |
| Thrips | Amblyseius cucumeris | Predator | 50-100 per plant |
| Fungus Gnats | Steinernema feltiae | Nematode | Drench media |
| Caterpillars | Bt (Bacillus thuringiensis) | Pathogen | Spray foliage |
