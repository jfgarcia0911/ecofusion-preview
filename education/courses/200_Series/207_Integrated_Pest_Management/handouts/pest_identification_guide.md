# Quick Pest Identification Guide
## Course 207: Integrated Pest Management - Handout

---

## Purpose

This visual guide provides rapid identification of common greenhouse and indoor farming pests using visual ASCII diagrams and key identification features. Print and post near scouting stations for quick reference.

## SAMPLING TECHNIQUES

```
┌────────────────────────────────────────────────────────────────────────────┐
│                                                                            │
│                    PROPER SAMPLING METHODS                                 │
│                                                                            │
│   FOR APHIDS:                                                              │
│   • Inspect new growth and shoot tips                                     │
│   • Flip young leaves and check undersides                                │
│   • Look for honeydew drips                                               │
│                                                                            │
│   FOR WHITEFLIES:                                                          │
│   • Gently shake plant, watch for white cloud                            │
│   • Flip leaves, examine undersides                                       │
│   • Check sticky traps                                                     │
│                                                                            │
│   FOR SPIDER MITES:                                                        │
│   • Start with lower, older leaves                                        │
│   • Use tap test with white paper                                         │
│   • Look for webbing                                                       │
│   • Use hand lens on leaf underside                                       │
│                                                                            │
│   FOR THRIPS:                                                              │
│   • Shake flowers over white paper                                        │
│   • Peel open buds carefully                                              │
│   • Check blue sticky traps                                               │
│   • Examine young leaves for streaks                                      │
│                                                                            │
│   FOR FUNGUS GNATS:                                                        │
│   • Check yellow sticky traps near media                                  │
│   • Probe top inch of media for larvae                                    │
│   • Look for adults hovering                                              │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
```
