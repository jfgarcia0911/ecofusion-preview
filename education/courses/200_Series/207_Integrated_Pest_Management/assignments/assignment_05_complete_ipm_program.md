# Assignment 5: Complete IPM Program
## Course 207: Integrated Pest Management

| **Type** | Project | **Duration** | 2-4 hrs | **Points** | 30 | **Due** | Module 10 |

## Purpose
Create comprehensive IPM program for greenhouse operation.

## Required Components

### 1. Facility Risk Assessment (6 pts)
- Common pests for crop types
- Risk factors (nearby agriculture, season, etc.)
- Priority pest list

### 2. Prevention Strategies (6 pts)
- Sanitation protocols
- Quarantine procedures
- Cultural practices
- Resistant varieties

### 3. Monitoring Program (8 pts)
- Scouting schedule and procedures
- Trap types and placement
- Record-keeping system
- Action thresholds

### 4. Treatment Protocols (6 pts)
- Biological control program
- Approved treatment list
- Application procedures
- Safety protocols

### 5. Documentation System (4 pts)
- Scouting logs
- Treatment records
- Efficacy evaluation
- Compliance documentation

**Deliverable:** 12-15 page IPM manual including:
- Risk assessment
- Prevention protocols
- Monitoring procedures
- Treatment guidelines
- Record templates
- Pest ID photo guide
