### 9.1 Facility Workflow Design

#### Production Flow Principles

```
OPTIMAL VERTICAL FARM WORKFLOW

┌─────────────────────────────────────────────┐
│ RECEIVING                                   │
│ ├─ Seeds, supplies, packaging              │
│ └─ Quality control, storage                │
└──────┬──────────────────────────────────────┘
       ↓ One-way flow (minimize backtracking)
┌──────▼──────────────────────────────────────┐
│ PROPAGATION AREA                            │
│ ├─ Seeding station (climate controlled)    │
│ ├─ Germination chambers                    │
│ └─ Seedling holding (7-14 days)            │
└──────┬──────────────────────────────────────┘
       ↓
┌──────▼──────────────────────────────────────┐
│ TRANSPLANTING                               │
│ ├─ Move to main growing racks              │
│ └─ Quality check, spacing                  │
└──────┬──────────────────────────────────────┘
       ↓
┌──────▼──────────────────────────────────────┐
│ MAIN PRODUCTION ZONE                        │
│ ├─ Vertical racks (14-21 days growth)      │
│ ├─ Daily monitoring, maintenance           │
│ └─ Environmental optimization              │
└──────┬──────────────────────────────────────┘
       ↓
┌──────▼──────────────────────────────────────┐
│ HARVESTING AREA                             │
│ ├─ Climate controlled (60-65°F)            │
│ ├─ Ergonomic harvest stations              │
│ └─ Quality sorting                         │
└──────┬──────────────────────────────────────┘
       ↓
┌──────▼──────────────────────────────────────┐
│ PROCESSING & PACKAGING                      │
│ ├─ Washing (if required)                   │
│ ├─ Packaging (clamshells, bags, bulk)      │
│ └─ Labeling, batch coding                  │
└──────┬──────────────────────────────────────┘
       ↓
┌──────▼──────────────────────────────────────┐
│ COLD STORAGE & SHIPPING                     │
│ ├─ Walk-in cooler (35-38°F)                │
│ ├─ Order staging                           │
│ └─ Loading dock                            │
└─────────────────────────────────────────────┘

KEY PRINCIPLES:
✓ Linear flow (no crossing paths)
✓ Dedicated zones (prevent cross-contamination)
✓ Climate-appropriate staging
✓ Minimize material handling distance
```

### 9.2 Labor Requirements Analysis

#### Task Time Standards

```
LABOR TIME PER 1,000 SQ FT PRODUCTION

LETTUCE (28-day cycle):

SEEDING (Day 0):
├─ Fill trays with media:        2 hours
├─ Seed trays (manual):          3 hours
│  (or robotic: 0.5 hours)
├─ Move to germination:          0.5 hours
└─ TOTAL:                        5.5 hours (3% of total cycle labor)

TRANSPLANTING (Day 10-14):
├─ Prepare growing positions:   1 hour
├─ Transfer seedlings:           6 hours
│  (or robotic: 1.5 hours)
├─ Quality check:                1 hour
└─ TOTAL:                        8 hours (4%)

DAILY MAINTENANCE (Days 1-28):
├─ System checks:                0.5 hr/day × 28 = 14 hours
├─ Nutrient management:          0.3 hr/day × 28 = 8.4 hours
├─ Scouting/monitoring:          0.4 hr/day × 28 = 11.2 hours
├─ Environmental adjustments:    0.2 hr/day × 28 = 5.6 hours
└─ TOTAL:                        39.2 hours (22%)

HARVESTING (Day 28):
├─ Harvest crop:                 12 hours
│  (400 heads/hour per person)
├─ Quality sorting:              3 hours
└─ TOTAL:                        15 hours (8%)

PROCESSING & PACKAGING:
├─ Washing (if needed):          2 hours
├─ Packaging:                    8 hours
├─ Labeling, boxing:             3 hours
└─ TOTAL:                        13 hours (7%)

FACILITY MANAGEMENT:
├─ Cleaning/sanitation:          8 hours/cycle
├─ Equipment maintenance:        4 hours/cycle
├─ Inventory, ordering:          3 hours/cycle
├─ Record keeping:               2 hours/cycle
└─ TOTAL:                        17 hours (9%)

CYCLE TOTAL:                     ~100 labor hours per 1,000 sq ft

Annual Labor (13 cycles):        1,300 hours per 1,000 sq ft
                                 = 0.65 FTE (Full-Time Equivalent)
```

### 9.3 Task Scheduling and Optimization

#### Weekly Schedule Example

```
WEEKLY TASK SCHEDULE (Continuous Production)

MONDAY:
├─ 6am-10am: Harvest mature crops (Batch 1)
├─ 10am-12pm: Package & prepare orders
├─ 1pm-3pm: Transplant new seedlings (Batch 5)
├─ 3pm-5pm: Seed new trays (Batch 6)
└─ Throughout: Daily monitoring, maintenance

TUESDAY:
├─ 6am-10am: Harvest (Batch 2)
├─ 10am-12pm: Package
├─ 1pm-3pm: Transplant (Batch 6)
├─ 3pm-4pm: Reservoir changes (Zone 1)
└─ 4pm-5pm: System checks

WEDNESDAY:
├─ 6am-10am: Harvest (Batch 3)
├─ 10am-12pm: Package
├─ 1pm-3pm: Deep cleaning (Zone A)
├─ 3pm-4pm: Seed new trays (Batch 7)
└─ 4pm-5pm: Quality control, data review

THURSDAY:
├─ 6am-10am: Harvest (Batch 4)
├─ 10am-12pm: Package
├─ 1pm-3pm: Transplant (Batch 7)
├─ 3pm-4pm: Reservoir changes (Zone 2)
└─ 4pm-5pm: Equipment maintenance

FRIDAY:
├─ 6am-10am: Harvest (any remaining)
├─ 10am-12pm: Package
├─ 1pm-3pm: Weekly deep cleaning
├─ 3pm-4pm: Inventory, ordering supplies
└─ 4pm-5pm: Staff meeting, next week planning

SATURDAY (Reduced Staff):
├─ 8am-10am: System checks, monitoring
├─ 10am-12pm: Any pending packaging
└─ Automated systems handle climate/irrigation

SUNDAY:
├─ Automated systems only
└─ Emergency on-call only
```

#### Peak Efficiency Strategies

**Batch Processing:**
- Group similar tasks together
- Example: All seeding on same day
- Reduces setup/cleanup time by 30%

**Cross-Training:**
- All staff trained on multiple tasks
- Flexibility during peak periods (harvest)
- Reduces downtime

**Time-Motion Studies:**
```
HARVEST EFFICIENCY ANALYSIS

Baseline (Unoptimized):
├─ Walk to rack:              30 seconds
├─ Harvest one head:          45 seconds
├─ Place in bin:              15 seconds
├─ Repeat 400×
└─ Rate: 40 heads/hour

Optimized (Streamlined):
├─ Pre-position harvest carts: -10 seconds
├─ Two-hand technique:        -15 seconds harvest
├─ Larger bin capacity:       -5 seconds placement
├─ Total time: 45 seconds per head
└─ Rate: 80 heads/hour (2× improvement!)

Results:
- Harvest labor reduced 50%
- Cost savings: $15,000-25,000/year
```

### 9.4 Standard Operating Procedures (SOPs)

#### SOP Framework

```
SOP TEMPLATE STRUCTURE

1. TITLE & PURPOSE
   - Task name
   - Why it's important

2. SCOPE
   - When performed
   - Who performs it

3. MATERIALS & EQUIPMENT
   - Tools needed
   - PPE requirements

4. SAFETY PRECAUTIONS
   - Hazards
   - Protective measures

5. STEP-BY-STEP INSTRUCTIONS
   - Numbered, detailed steps
   - Photos/diagrams

6. QUALITY CHECKS
   - Verification points
   - Acceptance criteria

7. DOCUMENTATION
   - What to record
   - Where to record

8. TROUBLESHOOTING
   - Common issues
   - Solutions
```

#### Example SOP: Daily Reservoir Check

```
SOP-004: DAILY NUTRIENT RESERVOIR CHECK

PURPOSE:
Maintain optimal nutrient levels for plant health and growth

FREQUENCY: Daily (morning, before 9am)

MATERIALS:
- pH meter (calibrated weekly)
- EC meter (calibrated weekly)
- Thermometer
- Data entry tablet
- Gloves

PROCEDURE:
1. Put on gloves
2. Locate Zone 1 reservoir
3. Measure and record pH
   ✓ Target: 5.8-6.2
   ✗ If <5.5 or >6.5, alert supervisor
4. Measure and record EC
   ✓ Target: 1.8-2.2 mS/cm (lettuce)
   ✗ If <1.6 or >2.4, alert supervisor
5. Measure and record temperature
   ✓ Target: 65-72°F
6. Visual inspection:
   - Color (should be slightly cloudy)
   - Smell (earthy, not foul)
   - Debris (skim if present)
7. Check reservoir level
   - Top off if below 80% full
8. Enter data into management system
9. Repeat for Zones 2, 3, 4
10. Report any anomalies immediately

DOCUMENTATION:
- Daily log sheet (paper backup)
- Digital entry in FarmOS

TIME REQUIRED: 20-30 minutes for 4 zones
```

### 9.5 Quality Control

#### Quality Standards

```
PRODUCT QUALITY CRITERIA

LETTUCE (Baby Leaf Mix):

GRADE A (Premium):
├─ Color: Vibrant, consistent
├─ Leaf Size: 2-4 inches
├─ Uniformity: >95% within spec
├─ Damage: <2% leaves affected
├─ Foreign Material: None
├─ Freshness: Crisp, turgid
└─ Price: 100% base price ($6/lb)

GRADE B (Standard):
├─ Color: Acceptable, minor variation
├─ Leaf Size: 1.5-5 inches
├─ Uniformity: 85-95%
├─ Damage: 2-5% leaves
├─ Foreign Material: Minimal
├─ Freshness: Acceptable
└─ Price: 70-85% base price ($4.50/lb)

REJECT/COMPOST:
├─ Yellowing, browning
├─ >5% damage
├─ Wilted, not crisp
└─ Foreign material/contamination

TARGET: >90% Grade A, <5% Reject
```

#### Quality Assurance Process

```
QA CHECKPOINTS

1. SEEDLING STAGE (Day 10):
   ├─ Germination rate >95%
   ├─ Uniform size
   └─ No disease/pests

2. MID-GROWTH (Day 18):
   ├─ Color, vigor assessment
   ├─ Growth rate on track
   └─ Environmental conditions optimal

3. PRE-HARVEST (Day 26):
   ├─ Size/maturity check
   ├─ Quality prediction
   └─ Market timing confirmation

4. HARVEST:
   ├─ Visual inspection during cut
   ├─ Segregate damaged plants
   └─ Grade A vs. B sorting

5. POST-HARVEST:
   ├─ Weight verification
   ├─ Packaging quality
   ├─ Temperature compliance
   └─ Final QC before shipping

6. CUSTOMER FEEDBACK:
   ├─ Track complaints/compliments
   ├─ Adjust processes
   └─ Continuous improvement
```

### 9.6 Safety and Sanitation

#### Food Safety Protocols

```
SANITATION SCHEDULE

DAILY:
├─ Hand washing (all staff, frequent)
├─ Harvest tool sanitation (between batches)
├─ Packaging area cleaning
└─ Floor sweeping (harvest/pack areas)

WEEKLY:
├─ Deep clean harvest area
├─ Sanitize all food contact surfaces
├─ Clean cold storage
└─ Mop all floors with sanitizer

MONTHLY:
├─ Reservoir deep clean
├─ Filter replacement/cleaning
├─ Equipment disassembly and cleaning
└─ Pest monitoring

QUARTERLY:
├─ Water quality testing
├─ Third-party sanitation audit
└─ Equipment calibration verification

SANITIZER OPTIONS:
├─ Quaternary ammonium (food safe)
├─ Hydrogen peroxide (leaves no residue)
├─ Chlorine bleach (diluted, rinse after)
└─ Follow label instructions for dilution
```

#### Worker Safety

**Key Hazards:**
- Slips/falls (wet floors)
- Lifting injuries (harvest bins)
- Electrical (lights, pumps)
- Chemical exposure (nutrients, cleaners)
- Ladder use (upper tiers)

**Safety Measures:**
```
SAFETY PROGRAM

TRAINING:
├─ New hire orientation
├─ Ladder safety certification
├─ Chemical handling (SDS review)
└─ Emergency procedures

PPE (Personal Protective Equipment):
├─ Non-slip shoes (required)
├─ Gloves (harvesting, chemicals)
├─ Safety glasses (cleaning, maintenance)
└─ Aprons (processing area)

EQUIPMENT:
├─ First aid kits (multiple locations)
├─ Eyewash station (chemical storage)
├─ Fire extinguishers
├─ Spill kits
└─ Ladder stabilizers

REPORTING:
├─ Incident log (all injuries, near-misses)
├─ Monthly safety meetings
└─ Continuous improvement focus
```

### 9.8 Continuous Improvement

#### Lean Principles

```
LEAN VERTICAL FARMING

1. IDENTIFY VALUE
   - What does customer pay for?
   - Focus: Quality, freshness, consistency

2. VALUE STREAM MAPPING
   - Map every step seed → customer
   - Identify waste (non-value-added)

3. ELIMINATE WASTE (7 Types):
   ├─ Overproduction (grow only what sells)
   ├─ Waiting (idle time between tasks)
   ├─ Transportation (minimize movement)
   ├─ Over-processing (unnecessary steps)
   ├─ Inventory (excess seeds, supplies)
   ├─ Motion (inefficient movements)
   └─ Defects (poor quality, rejects)

4. CONTINUOUS FLOW
   - Batch sizes optimized
   - Minimal work-in-progress
   - Predictable schedules

5. PULL SYSTEMS
   - Produce based on demand
   - Just-in-time harvesting
   - Avoid overstock

6. KAIZEN (Continuous Improvement)
   - Regular team brainstorming
   - Small, incremental changes
   - Measure results
   - Iterate
```
