## Project Overview

### Capstone Assignment

```
VERTICAL FARM DESIGN PROJECT

DELIVERABLES:

1. EXECUTIVE SUMMARY (2 pages)
   ├─ Concept overview
   ├─ Market opportunity
   ├─ Competitive advantage
   └─ Financial highlights

2. FACILITY DESIGN (5-8 pages)
   ├─ Location and site selection rationale
   ├─ Facility layout and floor plan
   ├─ Rack configuration and capacity
   ├─ Growing system selection (with justification)
   └─ Infrastructure (HVAC, lighting, irrigation)

3. OPERATIONAL PLAN (4-6 pages)
   ├─ Crop selection and rotation strategy
   ├─ Production schedule and cycles
   ├─ Labor plan and staffing model
   ├─ Standard operating procedures (key SOPs)
   └─ Quality control and food safety

4. FINANCIAL ANALYSIS (4-6 pages)
   ├─ Startup capital requirements
   ├─ 5-year pro forma financials
   ├─ Break-even analysis
   ├─ Sensitivity analysis
   └─ Funding strategy

5. MARKETING & SALES (3-4 pages)
   ├─ Target market and customer segments
   ├─ Go-to-market strategy
   ├─ Pricing strategy
   ├─ Distribution channels
   └─ Brand positioning

6. RISK MANAGEMENT (2-3 pages)
   ├─ Identified risks
   ├─ Mitigation strategies
   ├─ Contingency plans
   └─ Success metrics

7. PRESENTATION (15-20 minutes)
   ├─ Slide deck (12-15 slides)
   ├─ Visual aids (diagrams, renderings)
   ├─ Financial summary
   └─ Q&A preparedness

TOTAL DOCUMENT: 20-30 pages + appendices
```

### Presentation Tips

```
EFFECTIVE PRESENTATION STRATEGIES

PREPARATION:
✓ Practice 5-10 times before presenting
✓ Time yourself (15-20 minutes strict)
✓ Prepare for Q&A (anticipate 10 questions)
✓ Have backup slides ready
✓ Test technology/equipment beforehand

DELIVERY:
✓ Start strong (compelling opening)
✓ Tell a story (problem → solution → impact)
✓ Use visuals (diagrams, charts, not just text)
✓ Speak to audience, not slides
✓ Maintain energy and enthusiasm
✓ Pause for emphasis
✓ End with clear call to action

CONTENT:
✓ Focus on "why" not just "what"
✓ Use data to support claims
✓ Be realistic (avoid overpromising)
✓ Show you understand challenges
✓ Demonstrate you've done the work
✓ Make it memorable

Q&A STRATEGY:
✓ Listen fully before answering
✓ Repeat/clarify question if needed
✓ Be honest if you don't know
✓ Keep answers concise (1-2 minutes)
✓ Tie back to your key points
```

## Example Projects

### Sample Project 1: Urban Greens Co.

```
PROJECT SNAPSHOT

CONCEPT:
5,000 sq ft NFT-based vertical farm in downtown Seattle
Focus on gourmet salad mixes for high-end restaurants

HIGHLIGHTS:
├─ Location: 10 blocks from Pike Place Market
├─ System: 8-tier NFT racks
├─ Capacity: 130,000 lbs/year (mixed greens)
├─ Revenue: $780K/year (wholesale + DTC)
├─ Customers: 35 restaurants, 2 farmers markets
├─ Startup: $3.2M (mix of equity + SBA loan)
├─ Break-even: Month 22
└─ Differentiation: Same-day delivery, custom blends

STRENGTHS:
✓ Strong market research (interviews with 20 chefs)
✓ Detailed facility layout with 3D rendering
✓ Conservative financials with sensitivity analysis
✓ Clear competitive advantage (proximity + service)

AREAS FOR IMPROVEMENT:
- Could expand crop diversity
- Limited automation (budget constraint)
- Delivery logistics could be optimized
```

### Sample Project 2: MicroLeaf Systems

```
PROJECT SNAPSHOT

CONCEPT:
8,000 sq ft microgreens-focused operation in Austin, TX
High-volume production for regional distributors

HIGHLIGHTS:
├─ Location: East Austin industrial area
├─ System: Custom shallow-tray aeroponics
├─ Capacity: 250,000 lbs/year (microgreens)
├─ Revenue: $5.2M/year (high value crops)
├─ Customers: Whole Foods, Central Market, 100+ restaurants
├─ Startup: $4.8M (VC-backed)
├─ Break-even: Month 18

✓ Innovative automation (proprietary system)

✓ Clear scalability plan (franchise model)
✓ Strong team backgrounds

AREAS FOR IMPROVEMENT:
- High technology risk (custom equipment)
- Market saturation concerns addressed weakly
```
