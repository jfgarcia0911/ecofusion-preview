### 7.1 Crop Suitability Criteria

#### Evaluation Matrix

```
VERTICAL FARMING SUITABILITY ASSESSMENT

Criteria (Score 1-5, 5=best):

ECONOMIC FACTORS:
├─ Value per pound (5 = >$5/lb)
├─ Market demand (5 = year-round, growing)
├─ Shelf life (5 = >7 days)
├─ Price premium for local/fresh (5 = 40%+)
└─ Competition level (5 = low competition)

PRODUCTION FACTORS:
├─ Growth rate (5 = <30 days harvest)
├─ Yield per sq ft (5 = >2 lbs/sq ft/cycle)
├─ Light requirements (5 = low DLI needed)
├─ Space efficiency (5 = compact growth)
└─ Disease resistance (5 = very hardy)

TECHNICAL FACTORS:
├─ Temperature tolerance (5 = wide range)
├─ Humidity tolerance (5 = flexible)
├─ Nutrient requirements (5 = low, simple)
├─ Pollination needs (5 = none required)
└─ Harvest complexity (5 = simple cut)

SCORE RANGES:
60-75: EXCELLENT for vertical farming
45-59: GOOD - commercially viable
30-44: MARGINAL - niche opportunities
<30: POOR - not recommended
```

#### Lettuce Mix Strategy

**Gourmet Salad Mix (Highest Value):**
- 30% Red Oak Leaf
- 25% Green Oak Leaf
- 20% Baby Romaine
- 15% Red Butterhead
- 10% Arugula
- **Retail price:** $8-12/lb
- **Production cost:** $1.50-2.50/lb
- **Margin:** 70-80%

**Production Benefits:**
- Harvest all at once (baby leaf at 21-25 days)
- Varieties have similar growth rates
- Color diversity = premium pricing
- Continuous succession plantings

### 7.4 Microgreens

#### Top Microgreen Varieties

```
MICROGREEN PRODUCTION GUIDE

FAST GROWERS (7-10 days):
├─ Radish (colorful, spicy) - $30-40/lb
├─ Mustard (peppery) - $25-35/lb
├─ Arugula (nutty) - $28-38/lb

├─ Sunflower (crunchy, nutty) - $20-30/lb
├─ Pea shoots (sweet, tender) - $25-35/lb
├─ Broccoli (health benefits) - $30-40/lb
└─ Kohlrabi (mild cabbage flavor) - $25-35/lb

SPECIALTY/SLOW (14-21 days):
├─ Cilantro (challenging but high value) - $35-50/lb
├─ Basil (aromatic) - $40-60/lb
└─ Amaranth (colorful, nutritious) - $35-45/lb

PRODUCTION SYSTEM:
┌────────────────────────────────────┐
│ DAY 0: Seed dense trays (10-20g/tray)│
│ DAY 1-3: Blackout period (germination)│
│ DAY 3-7: Low light (100-150 PPFD)    │
│ DAY 7-10: Higher light (200-300 PPFD)│
│ DAY 10: HARVEST                       │
│                                       │
│ Yield: 8-16 oz per 10"×20" tray      │
│ Trays per sq ft: 2-4 (vertical stack)│
│ Production: 1-4 lbs/sq ft per 10 days │
│ Annual: 36-146 lbs/sq ft              │
└────────────────────────────────────────┘
```

#### Microgreen Economics

**10,000 sq ft dedicated to microgreens:**
- Production area: 7,000 sq ft (70% usable)
- Yield: 2 lbs/sq ft per 10-day cycle
- Cycles per year: 36
- Annual production: 504,000 lbs
- Average wholesale: $30/lb
- **Gross revenue: $15.1M/year**
- Production cost: $8-12/lb
- **Net revenue: $9-11M/year**

**Challenges:**
- Very labor intensive (seeding, harvest, packaging)
- Short shelf life (3-7 days)
- Requires consistent high-quality seed
- Sensitive to disease (damping off)

### 7.5 Emerging Crops

#### Strawberries

```
VERTICAL STRAWBERRY PRODUCTION

SYSTEM REQUIREMENTS:
├─ Tower or vertical column systems
├─ PPFD: 400-500 μmol/m²/s
├─ Temperature: 65-70°F
├─ Humidity: 60-70%
├─ Photoperiod: 12-16 hours (variety dependent)
└─ Pollination: Manual, bumblebees, or airflow

VARIETIES:
├─ Day-Neutral (best for VF): Albion, San Andreas, Monterey
├─ Ever-bearing: Seascape, Tribute
└─ June-bearing: Not recommended (photoperiod sensitive)

PRODUCTION TIMELINE:
├─ Transplant to first harvest: 8-12 weeks
├─ Production period: 6-12 months
├─ Yield: 1-3 lbs per plant over season
├─ Density: 10-15 plants per sq ft (vertical)
└─ Annual yield: 10-45 lbs/sq ft

ECONOMICS:
├─ Wholesale price: $4-8/lb
├─ Retail (direct): $6-12/lb
├─ Revenue potential: $40-540/sq ft/year
├─ Higher input costs (pollination, labor)
└─ Premium for local, no-pesticide
```

**Status:** Growing commercial interest, 20-30 farms in US producing at scale

#### Cherry Tomatoes

```
COMPACT TOMATO PRODUCTION

BEST CULTIVARS:
├─ Determinate/Compact: Better for VF
│  ├─ Micro-Tom (8-12" height, novelty)
│  ├─ Red Robin (container variety)
│  └─ Window Box Roma (determinate)
│
└─ Semi-Determinate Cherry:
   ├─ Fantastico (compact vine)

CHALLENGES:

YIELD:
├─ 5-15 lbs per plant
├─ 2-4 plants per sq ft (vertical training)
├─ 10-60 lbs/sq ft over 6 months
├─ Price: $3-6/lb (varies by season)
└─ Revenue: $30-360/sq ft over season

STATUS: Experimental to early commercial
```

### 7.6 Crops to Avoid

#### Poor Choices for Vertical Farming

```
NOT RECOMMENDED CROPS

LOW VALUE PER SQ FT:
├─ Grains (wheat, rice, corn)
│  └─ Value: $0.10-0.50/lb, too low for VF economics
├─ Commodity vegetables (cabbage, potatoes)
│  └─ Value: $0.50-1.50/lb, requires too much space
└─ Iceberg lettuce
   └─ 60-80 days, low value, high light needs

IMPRACTICAL PRODUCTION:
├─ Root vegetables (carrots, beets, potatoes)
│  └─ Require deep growing media, space inefficient
├─ Vining crops (melons, squash, cucumbers)
│  └─ Large space needs, heavy fruit = structural challenges
├─ Large fruiting crops (watermelon)
│  └─ Extremely space inefficient
└─ Tree crops (apples, citrus)
   └─ Long production timeline, vertical space wasted

TECHNICAL CHALLENGES:
├─ Crops requiring outdoor pollinators (some berries)
├─ Crops with very specific temperature vernalization (some onions)
├─ Crops requiring soil microbiome (some root veg)
└─ Extremely pest-prone crops (some Brassicas)
```

### 7.7 Crop Planning and Rotation

#### Succession Planting Schedule

```
CONTINUOUS PRODUCTION CALENDAR

LETTUCE EXAMPLE (28-day cycle):

Week 1:  Seed Batch 1 (Tray 1-10)
Week 2:  Transplant Batch 1 → Grow Area A
         Seed Batch 2 (Tray 11-20)
Week 3:  Transplant Batch 2 → Grow Area B
         Seed Batch 3 (Tray 21-30)
Week 4:  HARVEST Batch 1 (Area A)
         Transplant Batch 3 → Grow Area A (refilled)
         Seed Batch 4...
Week 5:  HARVEST Batch 2 (Area B)
         Transplant Batch 4 → Grow Area B
         Seed Batch 5...

Result: Weekly harvests, continuous cash flow

SPACE ALLOCATION:
├─ Propagation: 10% of growing area
├─ Weeks 1-2 growth: 25%
├─ Weeks 2-3 growth: 30%
├─ Weeks 3-4 growth: 35%
└─ Weekly turnover: ~25% of facility
```

#### Multi-Crop Rotation

**Strategy:** Alternate crops to optimize market demand and resource use

```
EXAMPLE: 10,000 SQ FT FACILITY

Spring/Summer (High Basil Demand):
├─ 40% Basil (4,000 sq ft)
├─ 30% Lettuce Mix (3,000 sq ft)
├─ 20% Microgreens (2,000 sq ft)
└─ 10% Specialty Herbs (1,000 sq ft)

Fall/Winter (Holiday Demand):
├─ 35% Lettuce Mix
├─ 25% Basil (reduced)
├─ 20% Microgreens
├─ 10% Arugula/Kale (hearty greens)
└─ 10% Herbs (parsley, cilantro, mint)

Benefits:
- Match market seasonality
- Reduce disease pressure (crop rotation)
- Diversify revenue
- Learn optimal crops over time
```

### 7.8 Cultivar Optimization

#### Variety Trials

```
SYSTEMATIC VARIETY TESTING

Trial Design:
├─ Select 4-6 cultivars per crop type
├─ Replicate 3× per cultivar (statistical validity)
├─ Randomize placement (avoid bias)
├─ Identical environmental conditions
└─ Track metrics (see below)

METRICS TO MEASURE:
├─ Days to harvest
├─ Yield (weight per plant, per sq ft)
├─ Quality scores (color, texture, flavor)
├─ Uniformity (CV of yield)
├─ Disease incidence
├─ Customer feedback
├─ Shelf life
└─ Economic return ($/sq ft)

Example Basil Trial Results:
┌──────────────────────────────────────────┐
│ Cultivar     │ Yield  │ Quality│ Revenue│
│──────────────────────────────────────────│
│ Genovese     │ 4.2 lb │ 8/10   │ $42    │
│ Nufar F1     │ 5.1 lb │ 9/10   │ $56    │ ← Winner
│ Italian Large│ 4.5 lb │ 7/10   │ $40    │
│ Sweet Thai   │ 3.8 lb │ 8/10   │ $45    │
│ (specialty pricing)                      │
└──────────────────────────────────────────┘

Decision: Adopt Nufar F1 as standard, keep Sweet Thai for niche market
```

#### Seed Selection Criteria

| Factor | Importance | Notes |
|--------|------------|-------|
| **Germination Rate** | Critical | >95% ideal, <85% reject |
| **Disease Resistance** | High | Saves significant losses |
| **Uniformity** | High | Consistent harvest, quality |
| **Flavor/Quality** | High | Premium pricing driver |
| **Growth Rate** | Medium | Faster = more cycles |
| **Seed Cost** | Medium | Balance with yield |
| **Availability** | Medium | Ensure reliable supply |

**Seed Sources:**
- Commercial seed companies (Johnny's, Osborne, High Mowing)
- Specialty VF seed suppliers
- Custom breeding programs (advanced operations)

## Vocabulary

| Term | Definition |
|------|------------|
| **Cultivar** | Cultivated variety with specific characteristics |
| **Succession Planting** | Staggered planting for continuous harvest |
| **Days to Harvest** | Time from seed/transplant to harvest |
| **Yield per Sq Ft** | Pounds produced per square foot per cycle |
| **Cycles per Year** | Number of complete grow-harvest cycles annually |
| **Cut-and-Come-Again** | Harvest method allowing regrowth |
| **Baby Leaf** | Young, tender greens harvested early |
| **Determinate** | Plant with limited, predictable growth |
| **Germination Rate** | Percentage of seeds that sprout |
| **Premium Pricing** | Higher price for quality, local, or specialty |
