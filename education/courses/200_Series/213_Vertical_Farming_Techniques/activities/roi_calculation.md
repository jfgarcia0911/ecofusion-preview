# Activity: Vertical Farm ROI Calculation
## Course 213: Vertical Farming Techniques

---

## Overview

| Field | Details |
|-------|---------|
| **Activity Type** | Financial Analysis Exercise |
| **Duration** | 1.5-2 hours |
| **Materials** | Calculator, spreadsheet, financial templates |
| **Deliverable** | Complete ROI analysis with sensitivity scenarios |

---

## Learning Objectives

By completing this activity, you will:
1. Calculate startup costs for a vertical farm
2. Project operating expenses and revenue
3. Determine key financial metrics (ROI, payback, IRR)
4. Conduct sensitivity analysis on key variables

---

You are evaluating a vertical farm investment with the following parameters:
