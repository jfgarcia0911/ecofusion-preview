## Quick Reference: System Specs

### NFT Systems
```
CHANNEL SPECIFICATIONS:
- Width: 2-4 inches
- Depth: 1.5-2.5 inches
- Length: 8-20 feet (max)
- Slope: 1-2% gradient
- Film depth: 1-3 mm
- Flow rate: 0.5-1 L/min

PLANT SPACING:
- Lettuce: 6-8 inches
- Herbs: 4-6 inches
- Microgreens: Not ideal

RECOMMENDED MATERIALS:
- PVC channels or NFT gullies
- Food-grade plastic
- White/reflective interior
```

### DWC Systems
```
TANK SPECIFICATIONS:
- Depth: 6-12 inches
- Size: 4' × 8' typical
- Water volume: 30-80 gallons
- Aeration: 1 air stone per 2-4 sq ft

PLANT SPACING:
- Lettuce: 6-8 inches
- Larger plants: 12 inches

RAFT MATERIALS:
- Styrofoam (1.5-2" thick)
- Food-grade rigid foam
- Net pots: 2-3 inches
```

### Aeroponic Systems
```
MISTING SPECIFICATIONS:
- Pressure: 60-100 PSI
- Droplet size: 5-50 microns
- Nozzle pattern: 360°
- Mist cycle: 5-10 sec ON / 3-5 min OFF
- Nozzle spacing: 12-18 inches

ROOT CHAMBER:
- Light-proof enclosure
- Humidity: 85-100% in chamber
- Temperature: 65-70°F

PUMP REQUIREMENTS:
- High-pressure pump
- Backup pump essential
- Accumulator tank recommended
```

### Tower Systems
```
TOWER SPECIFICATIONS:
- Height: 6-12 feet
- Diameter: 4-8 inches
- Plants per tower: 20-60
- Spacing: 16-24 inches between towers

DELIVERY METHODS:
- Drip irrigation (top-fed)
- Flood and drain
- Cascade system

PLANT POCKETS:
- 3-4 inch openings
- Spiral or staggered pattern
- 4-8 inches vertical spacing
```

## Hybrid System Approaches

### Nursery + Production Hybrid
```
STAGE 1 (Weeks 0-2): Aeroponic propagation
- Fastest root development
- Compact seedlings
- Easy transplanting

STAGE 2 (Weeks 2-4): NFT production
- Stable growth environment
- Lower risk than full aeroponics
- Cost-effective at scale
```

```
ZONE 1: DWC for lettuce (70% of space)
- Proven, high-volume production
- Simple operation

ZONE 2: Towers for strawberries (20%)
- Premium crop, vertical efficiency
- Marketing appeal

ZONE 3: Aeroponics for herbs (10%)
- High-value crops
- Faster turnover
```

## Troubleshooting Guide

### Common Issues by System

**NFT:**
- Root mat blocking flow → Trim roots, increase slope
- Dry spots in channel → Check level, increase flow
- Temperature rise in solution → Add chiller, insulate

**DWC:**
- Low dissolved oxygen → Add air stones, check pumps
- Algae growth → Light-proof system, reduce nutrients
- Root rot → Lower water temp, increase aeration

**Aeroponics:**
- Nozzle clogging → Install filters, clean regularly
- Insufficient mist coverage → Add nozzles, check pressure
- Rapid wilting → Check pump, backup power

**Towers:**
- Uneven watering → Adjust flow, check level
- Lower plants yellowing → Increase light, rotate towers
- Tipping risk → Secure base, reduce top weight

## Quick Decision Matrix

**Choose NFT if:**
- Commercial scale (5,000+ sq ft)
- Focus on leafy greens and herbs
- Want high vertical stacking
- Have moderate budget and expertise

**Choose DWC if:**
- Starting small (<5,000 sq ft)
- Single crop focus (lettuce)
- Limited budget
- Beginner to intermediate skill level

**Choose Aeroponics if:**
- Maximum yield priority
- High-value crop focus
- Advanced technical capability
- Budget allows ($80-120/sq ft)

**Choose Towers if:**
- Retail/restaurant visibility important
- Growing strawberries or herbs
- Small footprint needed
- Aesthetic appeal matters
