## Purpose

Build a functional temperature monitoring system using Arduino. This hands-on project develops practical automation skills.

## Project Requirements

**Build a system that:**
1. Reads temperature from a sensor every 5 seconds
2. Displays temperature on serial monitor
3. Lights an LED if temperature exceeds threshold
4. Logs data to SD card (bonus)
