## Course Description

Leverage technology to improve system reliability, reduce labor, and optimize production. This hands-on course covers sensors, controllers, automation systems, and data management for aquaponic and hydroponic operations. Build practical skills from DIY Arduino projects to commercial automation integration.

---

## Learning Outcomes

Upon successful completion of this course, learners will be able to:

1. **Select** and install appropriate monitoring sensors
2. **Program** basic automation controllers
3. **Integrate** automation systems for comprehensive control
4. **Develop** monitoring dashboards and alert systems
5. **Use** data for system optimization and decision-making
6. **Troubleshoot** common automation and sensor problems
7. **Calculate** ROI for automation investments

## Automation Decision Matrix

### When to Automate

| Function | Priority | Rationale |
|----------|----------|-----------|
| **Critical Safety** | Essential | Prevent catastrophic losses |
| Temperature monitoring | Essential | Fish/plant survival |
| Water level monitoring | Essential | Prevent pump damage, overflow |
| Power failure detection | Essential | Enable emergency response |
| **Production Optimization** | High Value | Improve quality and yield |
| pH/EC monitoring | High | Consistent plant nutrition |
| Lighting control | High | DLI optimization |
| Climate control | High | Optimal growth conditions |
| **Labor Reduction** | Consider ROI | Reduce repetitive tasks |
| Automated feeding | Medium | Consistency, labor saving |
| Irrigation scheduling | Medium | Precision, labor saving |
| Data logging | Medium | Decision support |
| **Advanced Optimization** | When Established | Refinement and edge gains |
| Predictive analytics | Low priority initially | Build data foundation first |

## Sensor Quick Reference

### Water Quality Sensors

| Parameter | Sensor Type | Price Range | Accuracy | Maintenance |
|-----------|-------------|-------------|----------|-------------|
| pH | Glass electrode | $50-500 | ±0.1 pH | Calibrate weekly, replace yearly |
| EC/TDS | Conductivity | $30-300 | ±2% | Calibrate monthly |
| Temperature | Thermistor/RTD | $10-100 | ±0.5°C | Check accuracy monthly |
| DO | Optical/Galvanic | $200-1000 | ±0.2 mg/L | Calibrate weekly, membrane replacement |
| ORP | Platinum electrode | $100-400 | ±10 mV | Calibrate monthly |

### Environmental Sensors

| Parameter | Sensor Type | Price Range | Accuracy | Notes |
|-----------|-------------|-------------|----------|-------|
| Air Temp | Thermistor/RTD | $10-100 | ±0.5°C | Shield from radiation |
| Humidity | Capacitive | $20-200 | ±3% RH | Avoid condensation |
| PAR Light | Quantum sensor | $200-600 | ±5% | Cosine correction |
| CO2 | NDIR | $100-500 | ±50 ppm | Calibrate in fresh air |
