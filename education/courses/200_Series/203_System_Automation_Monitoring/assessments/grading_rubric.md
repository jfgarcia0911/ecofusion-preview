## Grading Criteria by Assignment

### Assignment 1: Sensor Selection Exercise (15 points)

| Criterion | Excellent (4-5 pts) | Good (3 pts) | Fair (2 pts) | Poor (0-1 pts) |
|-----------|-------------------|--------------|--------------|----------------|
| **Sensor Selection** (5 pts) | Optimal choices with clear justification | Good selections, minor issues | Suboptimal selections | Poor choices |
| **Cost-Performance Analysis** (5 pts) | Thorough analysis of trade-offs | Good analysis | Surface-level analysis | Inadequate analysis |
| **Specifications** (5 pts) | Complete, accurate specs | Mostly complete | Missing key specs | Incomplete |

### Assignment 2: Automation ROI Analysis (20 points)

| Criterion | Excellent (5 pts) | Good (3-4 pts) | Fair (2 pts) | Poor (0-1 pts) |
|-----------|------------------|----------------|--------------|----------------|
| **Labor Savings Calculation** (5 pts) | Accurate, detailed calculations | Generally correct | Calculation errors | Poor calculations |
| **Cost Analysis** (5 pts) | Comprehensive cost breakdown | Good cost analysis | Incomplete costs | Missing costs |
| **ROI Calculation** (5 pts) | Correct payback analysis | Minor calculation errors | Significant errors | Incorrect method |
| **Recommendation** (5 pts) | Well-justified decision | Reasonable recommendation | Weak justification | Poor recommendation |

### Assignment 3: Arduino Monitoring Project (25 points)

| Criterion | Excellent (6-7 pts) | Good (4-5 pts) | Fair (2-3 pts) | Poor (0-1 pts) |
|-----------|-------------------|----------------|--------------|----------------|
| **Circuit Design** (7 pts) | Correct wiring, proper components | Minor wiring issues | Significant errors | Non-functional |
| **Code Functionality** (7 pts) | Code works correctly | Minor bugs | Significant bugs | Code doesn't work |
| **Data Display** (6 pts) | Clear, useful output | Functional but basic | Limited functionality | Not working |
| **Documentation** (5 pts) | Excellent documentation | Good documentation | Basic documentation | Poor documentation |

### Assignment 4: Alert System Design (20 points)

| Criterion | Excellent (5 pts) | Good (3-4 pts) | Fair (2 pts) | Poor (0-1 pts) |
|-----------|------------------|----------------|--------------|----------------|
| **Alert Thresholds** (5 pts) | Well-defined, appropriate levels | Good thresholds | Questionable levels | Poor thresholds |
| **Notification Strategy** (5 pts) | Multi-channel, escalation plan | Good notification plan | Basic plan | Inadequate plan |
| **Integration Design** (5 pts) | Comprehensive integration | Good integration | Limited integration | Poor integration |
| **Failsafe Planning** (5 pts) | Robust backup systems | Basic backups | Limited backups | No backups |

### Assignment 5: Complete Automation System Design (30 points)

| Criterion | Excellent (7-8 pts) | Good (5-6 pts) | Fair (3-4 pts) | Poor (0-2 pts) |
|-----------|-------------------|----------------|--------------|----------------|
| **System Architecture** (8 pts) | Comprehensive, well-integrated | Good architecture | Basic design | Poor design |
| **Component Selection** (7 pts) | Optimal components justified | Good selections | Questionable choices | Poor selections |
| **Implementation Plan** (8 pts) | Detailed, practical timeline | Good plan | Basic plan | Inadequate plan |
| **Budget & ROI** (7 pts) | Complete financial analysis | Good analysis | Basic numbers | Poor analysis |
