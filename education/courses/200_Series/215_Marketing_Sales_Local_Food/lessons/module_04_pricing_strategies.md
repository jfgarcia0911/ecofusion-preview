## Introduction

Pricing is one of the most challenging decisions for farm businesses. Price too high and you lose customers; price too low and you can't sustain your business. Local food commands premium prices—but only when you effectively communicate value.

This module provides frameworks for strategic pricing that balances profitability, competitiveness, and customer value perception.

## The Three Pricing Approaches

### 1. Cost-Plus Pricing

Calculate all costs and add desired profit margin:

```
╔════════════════════════════════════════════════════════════════════════════╗
║                      COST-PLUS PRICING FORMULA                             ║
╠════════════════════════════════════════════════════════════════════════════╣
║                                                                            ║
║  STEP 1: Calculate Production Cost per Unit                               ║
║  ────────────────────────────────────────                                  ║
║                                                                            ║
║  Direct Costs (variable):                                                  ║
║  • Seeds/starts           $____                                            ║
║  • Growing media          $____                                            ║
║  • Nutrients/amendments   $____                                            ║
║  • Packaging              $____                                            ║
║  • Direct labor           $____                                            ║
║  ─────────────────────────────                                             ║
║  Total Direct Cost        $____                                            ║
║                                                                            ║
║  Indirect Costs (overhead allocated):                                      ║
║  • Facility/rent          $____                                            ║
║  • Utilities              $____                                            ║
║  • Equipment depreciation $____                                            ║
║  • Insurance              $____                                            ║
║  • Marketing              $____                                            ║
║  • Management labor       $____                                            ║
║  ─────────────────────────────                                             ║
║  Total Indirect Cost      $____                                            ║
║                                                                            ║
║  TOTAL COST PER UNIT = Direct + Indirect = $____                           ║
║                                                                            ║
║  STEP 2: Add Desired Profit Margin                                         ║
║  ───────────────────────────────────                                       ║
║                                                                            ║
║  Price = Cost / (1 - Desired Margin %)                                     ║
║                                                                            ║
║  Example: Cost = $2.00, Desired Margin = 40%                               ║
║  Price = $2.00 / (1 - 0.40) = $2.00 / 0.60 = $3.33                         ║
║                                                                            ║
║  Or: Price = Cost × (1 + Markup %)                                         ║
║  Example: Cost = $2.00, Markup = 67%                                       ║
║  Price = $2.00 × 1.67 = $3.34                                              ║
║                                                                            ║
╚════════════════════════════════════════════════════════════════════════════╝
```

**When to Use Cost-Plus:**
- Establishing minimum price floor
- High-volume, commodity-like products
- Wholesale pricing negotiations
- Internal benchmarking

**Limitations:**
- Ignores customer willingness to pay
- Doesn't account for competitive positioning
- May leave money on the table for premium products

### 2. Value-Based Pricing

Price based on perceived value to the customer:

```
┌──────────────────────────────────────────────────────────────────────────┐
│                    VALUE-BASED PRICING FRAMEWORK                         │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  Customer Value Drivers:                                                 │
│                                                                          │
│  1. QUALITY PREMIUM                                                      │
│     Superior taste/freshness vs. conventional                           │
│     → Justifies 20-40% premium                                           │
│                                                                          │
│  2. CONVENIENCE VALUE                                                    │
│     Pre-washed, ready-to-eat, delivered                                 │
│     → Justifies 25-50% premium                                           │
│                                                                          │
│  3. VALUES ALIGNMENT                                                     │
│     Organic, sustainable, local                                         │
│     → Justifies 15-35% premium                                           │
│                                                                          │
│  4. UNIQUENESS                                                           │
│     Heirloom varieties, specialty items                                 │
│     → Justifies 30-100% premium                                          │
│                                                                          │
│  5. STORY/EXPERIENCE                                                     │
│     Know-your-farmer, farm connection                                   │
│     → Justifies 10-25% premium                                           │
│                                                                          │
│  VALUE CALCULATION EXAMPLE:                                              │
│  ────────────────────────                                                │
│  Conventional romaine lettuce (grocery): $2.50                          │
│  + Quality premium (superior freshness): +30% = $0.75                   │
│  + Local/sustainable values: +20% = $0.50                               │
│  + Story/relationship: +15% = $0.38                                     │
│  ──────────────────────────────────────                                  │
│  Your value-based price: $4.13                                          │
│  Round to: $3.99 or $4.00                                               │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

**When to Use Value-Based:**
- Premium positioning
- Unique/specialty products
- Strong brand identity
- Target customers less price-sensitive

**Requirements:**
- Clear communication of value drivers
- Strong branding and marketing
- High-quality, consistent product
- Customer education

### 3. Competitive Pricing

Price relative to competitors:

| Strategy | Description | When to Use | Example |
|----------|-------------|-------------|---------|
| **Premium Pricing** | 10-30% above competitors | Superior quality, strong brand, unique products | Heirloom tomatoes at $6/lb vs. $4.50 conventional |
| **Parity Pricing** | Match competitor pricing | Similar quality, differentiate on other factors | Organic lettuce at $3.50 (same as other vendors) |
| **Penetration Pricing** | Below competitors initially | New to market, building customer base | New vendor at $3/lb vs. $3.50 average |
| **Economy Pricing** | Consistently lower prices | High volume, lower costs, broader access | Seconds/imperfects at discount |

## Pricing Calculations Worksheet

### Example: Head Lettuce Pricing

**Production Data:**
- Seeds: $0.15 per plant
- Growing media: $0.20 per plant
- Nutrients: $0.10 per plant
- Labor (growing): $0.30 per plant
- Labor (harvest/pack): $0.25 per plant
- Packaging: $0.15 per plant
- Overhead allocation: $0.40 per plant
- **Total Cost: $1.55 per head**

**Cost-Plus Calculation (40% margin):**
- Price = $1.55 / (1 - 0.40) = $1.55 / 0.60 = **$2.58**
- Round to: **$2.50** or **$2.75**

**Competitive Analysis:**
- Conventional grocery lettuce: $1.99
- Organic grocery lettuce: $2.99
- Other farmers market vendors: $3.00-3.50
- High-end farmers market: $4.00

**Value-Based Calculation:**
- Base (organic grocery): $2.99
- Freshness premium (+25%): $0.75
- Local/sustainable (+15%): $0.45
- **Value-based price: $4.19**
- Round to: **$3.99** or **$4.00**

**Final Price Decision:**
- Minimum (cost-plus): $2.58
- Competitive range: $3.00-4.00
- Value-based: $3.99
- **Selected price: $3.50** (strong value communication) or **$3.99** (premium positioning)

## Pricing by Sales Channel

Different channels have different cost structures and price expectations:

```
╔════════════════════════════════════════════════════════════════════════════╗
║                    CHANNEL-SPECIFIC PRICING                                ║
╠════════════════════════════════════════════════════════════════════════════╣
║                                                                            ║
║  FARMERS MARKETS                                                           ║
║  ───────────────                                                           ║
║  Price Position: Premium (highest retail)                                 ║
║  Typical Margin: 100-200% of wholesale                                    ║
║  Costs: Market fees ($20-50/day), labor, transportation                   ║
║  Advantages: Direct customer contact, full margin, cash flow              ║
║                                                                            ║
║  Example: Lettuce at $3.50-4.00/head                                      ║
║                                                                            ║
║  ────────────────────────────────────────────────────────────────────────  ║
║                                                                            ║
║  ON-FARM SALES/FARM STAND                                                  ║
║  ───────────────────────────                                               ║
║  Price Position: Premium (similar to farmers market)                      ║
║  Typical Margin: 100-200% of wholesale                                    ║
║  Costs: Farm stand infrastructure, honor system risk, staffing            ║
║  Advantages: No market fees, customer farm visit, relationship building   ║
║                                                                            ║
║  Example: Lettuce at $3.50/head                                           ║
║                                                                            ║
║  ────────────────────────────────────────────────────────────────────────  ║
║                                                                            ║
║  CSA PROGRAM                                                               ║
║  ─────────────                                                             ║
║  Price Position: Moderate (bulk discount vs. farmers market)              ║
║  Typical Margin: 80-150% of wholesale                                     ║
║  Costs: Packing labor, delivery, box depreciation                         ║
║  Advantages: Guaranteed sales, cash upfront, loyal customers              ║
║                                                                            ║
║  Example: 20-week share at $500 = $25/week (~20% discount vs. retail)    ║
║                                                                            ║
║  ────────────────────────────────────────────────────────────────────────  ║
║                                                                            ║
║  RESTAURANT/CHEF SALES                                                     ║
║  ─────────────────────────                                                 ║
║  Price Position: Wholesale+ (premium wholesale)                           ║
║  Typical Margin: 40-100% above standard wholesale                         ║
║  Costs: Delivery, small order minimums, invoicing/collections             ║
║  Advantages: Consistent volume, prestige, steady income                   ║
║                                                                            ║
║  Example: Lettuce at $2.00-2.50/head (vs. $1.25 commodity wholesale)     ║
║                                                                            ║
║  ────────────────────────────────────────────────────────────────────────  ║
║                                                                            ║
║  RETAIL PARTNERSHIPS (Grocery/Co-op)                                       ║
║  ─────────────────────────────────────                                     ║
║  Price Position: Wholesale (store takes 30-50% margin)                    ║
║  Typical Margin: 50-100% of production cost                               ║
║  Costs: Packaging, labeling, invoicing, delivery, shrink/spoilage        ║
║  Advantages: Volume, consistent orders, brand exposure                    ║
║                                                                            ║
║  Example: Wholesale to store at $2.00/head → Retail at $3.99             ║
║                                                                            ║
║  ────────────────────────────────────────────────────────────────────────  ║
║                                                                            ║
║  ONLINE/DELIVERY                                                           ║
║  ─────────────────                                                         ║
║  Price Position: Premium+ (convenience premium)                           ║
║  Typical Margin: 100-200%+ (but higher delivery costs)                    ║
║  Costs: Delivery labor/vehicle, online platform fees, packaging          ║
║  Advantages: Customer convenience, subscription potential                 ║
║                                                                            ║
║  Example: Lettuce at $4.00/head + $5-10 delivery fee                      ║
║                                                                            ║
╚════════════════════════════════════════════════════════════════════════════╝
```

### Multi-Channel Pricing Strategy

```
Product: Head Lettuce
Production Cost: $1.55

Channel Pricing:
• Farmers Market:      $3.50 (126% margin)
• On-farm stand:       $3.50 (126% margin)
• CSA allocation:      $2.80/head equivalent (81% margin)
• Restaurant:          $2.25 (45% margin)
• Retail wholesale:    $2.00 (29% margin)
• Online + delivery:   $4.00 + delivery fee (158% margin before delivery costs)

Weighted Average Margin: ~85% across all channels
```

## Psychological Pricing Techniques

### Charm Pricing (9-ending)

- $3.99 instead of $4.00
- Creates perception of better value
- Common in retail environments
- **Use for**: Competitive products, price-sensitive customers

### Prestige Pricing (round numbers)

- $4.00 instead of $3.99
- Conveys quality and confidence
- Simplifies transactions (farmers markets)
- **Use for**: Premium products, upscale positioning

### Price Anchoring

Display higher-priced items first to make others seem reasonable:

```
Market Display:
┌─────────────────────────────────────┐
│ Heirloom Tomatoes      $7.99/lb    │  ← Anchor (high)
│ Cherry Tomatoes        $5.99/lb    │  ← Looks reasonable
│ Slicing Tomatoes       $4.99/lb    │  ← Great value!
└─────────────────────────────────────┘
```

### Bundle Pricing

- 3 heads of lettuce for $10 (vs. $3.50 each = $10.50)
- Salad kit (lettuce + tomatoes + cukes) for $12
- CSA share (pre-paid bundle)

**Benefits:**
- Increase average transaction size
- Move inventory faster
- Simplify customer decisions

### Volume Discounts

```
Pricing Tiers:
• 1 bunch kale:        $4.00
• 3 bunches:           $11.00 ($3.67 each, save 8%)
• 5 bunches:           $18.00 ($3.60 each, save 10%)

Or:
• Retail (1-5 lbs):    $8/lb
• Small wholesale (6-20 lbs):  $6/lb
• Large wholesale (20+ lbs):   $5/lb
```

## Pricing for Profitability

### Contribution Margin Analysis

Which products are most profitable per unit?

| Product | Price | Variable Cost | Contribution Margin | Margin % |
|---------|-------|---------------|---------------------|----------|
| Lettuce head | $3.50 | $1.15 | $2.35 | 67% |
| Tomatoes (lb) | $5.00 | $2.20 | $2.80 | 56% |
| Basil bunch | $4.00 | $0.80 | $3.20 | 80% |
| Microgreens (4oz) | $6.00 | $1.50 | $4.50 | 75% |

**Insight:** Basil and microgreens have highest margins—promote these aggressively.

### Break-Even Analysis

How many units must you sell to cover fixed costs?

```
Formula: Break-Even Units = Fixed Costs / Contribution Margin per Unit

Example:
Monthly Fixed Costs: $3,000
Lettuce Contribution Margin: $2.35/head

Break-Even = $3,000 / $2.35 = 1,277 heads of lettuce per month
           = ~294 heads per week
```

## Dynamic and Seasonal Pricing

### Peak Season Pricing

When supply is high (peak summer):
- Lower prices to move volume
- Promote bulk sales
- Focus on value messaging

### Off-Season Pricing

When supply is limited (winter, if applicable):
- Premium pricing justified by scarcity
- Emphasize year-round availability as value
- Smaller pack sizes at higher per-unit prices

### Demand-Based Pricing

- **High-demand days** (Saturday farmers market): Premium pricing
- **Lower-demand days** (Wednesday): Slight discount to move inventory
- **End-of-market** (last hour): "Happy hour" discounts to avoid waste

## Pricing Mistakes to Avoid

```
┌──────────────────────────────────────────────────────────────────────────┐
│                     COMMON PRICING ERRORS                                │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  ❌ Pricing too low out of fear                                          │
│     → Undervaluing your product and sustainability                      │
│     → Can't cover costs or grow business                                │
│     → Creates "cheap" perception hard to escape                         │
│                                                                          │
│  ❌ Ignoring your costs                                                  │
│     → Not tracking true production costs                                │
│     → Forgetting to include labor and overhead                          │
│     → Pricing below profitability threshold                             │
│                                                                          │
│  ❌ Being inconsistent across channels                                   │
│     → Confusing customers who shop multiple channels                    │
│     → Creating channel conflict                                         │
│     → Solution: Justify differences (delivery fee, convenience, etc.)   │
│                                                                          │
│  ❌ Competing only on price                                              │
│     → Race to the bottom with no differentiation                        │
│     → Erodes margins across entire market                               │
│     → Better: Compete on quality, service, story                        │
│                                                                          │
│  ❌ Never raising prices                                                 │
│     → Costs increase over time (labor, inputs, inflation)               │
│     → Falling behind market                                             │
│     → Solution: Small annual increases (5-8%) less noticeable           │
│                                                                          │
│  ❌ Failing to communicate value                                         │
│     → Expecting customers to "just know" why you're worth more          │
│     → Not educating about quality, methods, benefits                    │
│     → Solution: Signage, conversations, marketing materials             │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

## Module Summary

### Key Takeaways

1. **Three pricing approaches** - Cost-plus establishes floor, value-based sets ceiling, competitive positions you in market

2. **Different channels require different pricing** - Farmers markets command premium, wholesale requires volume discounts

3. **Psychological pricing matters** - Small changes ($3.99 vs. $4.00) influence perception

4. **Track contribution margins** - Know which products are most profitable per unit

5. **Avoid underpricing** - Calculate real costs and don't be afraid to charge for value delivered

6. **Communicate value effectively** - Premium pricing requires premium marketing
