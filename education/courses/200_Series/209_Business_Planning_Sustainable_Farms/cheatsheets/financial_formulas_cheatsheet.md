# Financial Formulas Cheatsheet
## Course 209: Business Planning for Sustainable Farms

---

## PROFITABILITY METRICS

### Gross Margin
```
Gross Margin % = (Revenue - COGS) / Revenue × 100

Example:
Revenue: $200,000
COGS: $90,000
Gross Margin = ($200,000 - $90,000) / $200,000 × 100 = 55%

Target: 40-60% for sustainable farms
```

### Operating Margin (EBITDA Margin)
```
Operating Margin % = EBITDA / Revenue × 100

Example:
EBITDA: $45,000
Revenue: $200,000
Operating Margin = $45,000 / $200,000 × 100 = 22.5%

Target: 15-25% for healthy operation
```

### Net Profit Margin
```
Net Margin % = Net Income / Revenue × 100

Example:
Net Income: $30,000
Revenue: $200,000
Net Margin = $30,000 / $200,000 × 100 = 15%

Target: 5-15% at maturity
```

## PRICING FORMULAS

### Cost-Plus Pricing
```
Selling Price = Cost per Unit + (Cost × Desired Margin %)

Example:
Cost: $5.00/lb
Desired Margin: 40%
Price = $5.00 + ($5.00 × 0.40) = $7.00/lb
```

### Markup Calculation
```
Markup % = (Selling Price - Cost) / Cost × 100

Example:
Cost: $5.00
Price: $8.00
Markup = ($8.00 - $5.00) / $5.00 × 100 = 60%
```

### Margin from Markup
```
Margin % = Markup % / (1 + Markup %)

Example:
Markup: 60%
Margin = 60% / (1 + 0.60) = 60% / 1.60 = 37.5%
```

## BREAK-EVEN ANALYSIS

### Break-Even in Units
```
Break-Even Units = Fixed Costs / (Price - Variable Cost per Unit)

Example:
Fixed Costs: $120,000/year
Price: $10/lb
Variable Cost: $4/lb
Break-Even = $120,000 / ($10 - $4) = 20,000 lbs
```

### Break-Even in Dollars
```
Break-Even Revenue = Fixed Costs / (1 - (Variable Costs / Revenue))

Or: Break-Even Revenue = Fixed Costs / Contribution Margin %

Example:
Fixed Costs: $120,000
Variable Costs: $80,000 (at $200K revenue)
Variable Cost % = $80,000 / $200,000 = 40%
Contribution Margin % = 1 - 0.40 = 60%
Break-Even Revenue = $120,000 / 0.60 = $200,000
```

## LIQUIDITY RATIOS

### Current Ratio
```
Current Ratio = Current Assets / Current Liabilities

Example:
Current Assets: $45,000
Current Liabilities: $25,000
Current Ratio = $45,000 / $25,000 = 1.8

Target: > 1.5 (healthy liquidity)
```

### Quick Ratio (Acid Test)
```
Quick Ratio = (Current Assets - Inventory) / Current Liabilities

Example:
Current Assets: $45,000
Inventory: $8,000
Current Liabilities: $25,000
Quick Ratio = ($45,000 - $8,000) / $25,000 = 1.48

Target: > 1.0
```

### Cash Burn Rate
```
Monthly Burn Rate = (Monthly Revenue - Monthly Expenses)

Example:
Monthly Revenue: $15,000
Monthly Expenses: $22,000
Burn Rate = $15,000 - $22,000 = -$7,000/month

Runway = Cash on Hand / Monthly Burn
$50,000 / $7,000 = 7.1 months runway
```

## DEBT & LEVERAGE

### Debt Service Coverage Ratio
```
DSCR = Net Operating Income / Total Debt Service

Example:
Net Operating Income: $48,000/year
Annual Debt Payments: $36,000
DSCR = $48,000 / $36,000 = 1.33

Target: > 1.25 (lenders typically require)
```

### Debt-to-Equity Ratio
```
Debt/Equity = Total Liabilities / Total Equity

Example:
Total Debt: $150,000
Total Equity: $100,000
Debt/Equity = $150,000 / $100,000 = 1.5 or 1.5:1

Target: < 2:1 for farms
```

## EFFICIENCY METRICS

### Revenue per Square Foot
```
Revenue/Sq Ft = Annual Revenue / Growing Area (sq ft)

Example:
Revenue: $250,000
Growing Area: 2,000 sq ft
Revenue/Sq Ft = $250,000 / 2,000 = $125/sq ft/year

Benchmarks:
- Leafy greens: $80-150/sq ft
- Tomatoes: $120-200/sq ft
- Microgreens: $200-400/sq ft
```

### Revenue per FTE (Full-Time Equivalent)
```
Revenue/FTE = Annual Revenue / Total FTE Employees

Example:
Revenue: $280,000
Employees: 2.5 FTE
Revenue/FTE = $280,000 / 2.5 = $112,000

Target: $75,000-$125,000 per FTE
```

### Customer Acquisition Cost (CAC)
```
CAC = Total Sales & Marketing Costs / New Customers Acquired

Example:
Marketing Spend: $12,000
New Customers: 80
CAC = $12,000 / 80 = $150 per customer
```

### Customer Lifetime Value (LTV)
```
LTV = Average Purchase × Purchase Frequency × Avg Customer Lifespan

Example:
Average Order: $40
Orders/Year: 20
Customer Lifespan: 4 years
LTV = $40 × 20 × 4 = $3,200

Target: LTV/CAC > 3:1
```

## WORKING CAPITAL

### Working Capital
```
Working Capital = Current Assets - Current Liabilities

Example:
Current Assets: $65,000
Current Liabilities: $28,000
Working Capital = $65,000 - $28,000 = $37,000

Positive = Good (can pay short-term obligations)
```

### Working Capital Requirement
```
Working Capital Needed = Monthly Operating Expenses × Months to Break-Even

Example:
Monthly Expenses: $22,000
Months to Break-Even: 18
Working Capital = $22,000 × 18 = $396,000
```

## RETURN ON INVESTMENT

### ROI (Return on Investment)
```
ROI % = (Net Profit / Total Investment) × 100

Example:
Net Profit (5 years): $250,000
Total Investment: $400,000
ROI = ($250,000 / $400,000) × 100 = 62.5%

Annual ROI = 62.5% / 5 years = 12.5%/year
```

### Payback Period
```
Payback Period = Initial Investment / Annual Cash Flow

Example:
Investment: $380,000
Annual Cash Flow: $65,000
Payback = $380,000 / $65,000 = 5.8 years
```

## PRODUCTION METRICS

### Production Capacity
```
Annual Capacity = Plant Sites × Crops per Year

Example:
Plant Sites: 2,500
Growing Cycle: 35 days
Crops/Year = 365 / 35 = 10.4
Annual Capacity = 2,500 × 10.4 = 26,000 plants

Accounting for loss:
Marketable = 26,000 × 92% success rate = 23,920
```

### Utilization Rate
```
Utilization % = Actual Production / Maximum Capacity × 100

Example:
Actual: 18,000 lbs
Capacity: 25,000 lbs
Utilization = 18,000 / 25,000 × 100 = 72%

Target: 85-95% at steady state
```

### Cost per Unit
```
Cost per Unit = Total Costs / Units Produced

Example:
Total Costs: $180,000
Production: 22,000 lbs
Cost/lb = $180,000 / 22,000 = $8.18/lb
```
