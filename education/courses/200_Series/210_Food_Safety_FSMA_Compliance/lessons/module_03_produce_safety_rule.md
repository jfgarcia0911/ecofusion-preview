## Lesson Content

### 3.1 Agricultural Water - Overview

Agricultural water is the #1 source of produce contamination. The PSR establishes standards based on water use.

#### Water Use Categories

```
AGRICULTURAL WATER CATEGORIES

┌─────────────────────────────────────────────────────────┐
│                                                         │
│  1. WATER USED DURING GROWING ACTIVITIES                │
│     • Irrigation (soil-based only)                      │
│     • Dust abatement                                    │
│     • Frost protection                                  │
│     • Application of pesticides/fertilizers             │
│                                                         │
│  2. WATER FOR HARVEST, PACKING & HOLDING                │
│     • Hand washing                                      │
│     • Produce washing                                   │
│     • Ice making                                        │
│     • Equipment/surface contact                         │
│                                                         │
│  3. WATER USED FOR SPROUTS                              │
│     • Seed germination                                  │
│     • Growing sprouts                                   │
│     (Strictest requirements)                            │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

#### Quality Standards by Use

| Water Use | Standard | Testing Required |
|-----------|----------|------------------|
| **Post-harvest (direct contact)** | Potable/no detectable E. coli | Yes - regular testing |
| **Harvest (hand washing)** | Safe & adequate sanitary quality | Yes - as needed |
| **Growing activities** | No detectable E. coli in 100mL | Yes - agricultural water |
| **Sprouts** | No detectable E. coli, Salmonella, Listeria | Yes - extensive |

#### CEA-Specific Considerations

**Hydroponics/Aquaponics:**
- Water that contacts produce during growing = harvest/packing water
- Must meet "no detectable E. coli" standard
- More frequent testing recommended
- Recirculating systems need careful monitoring

**Key Difference from Soil-Based:**
```
SOIL vs CEA WATER REQUIREMENTS

Soil-Based Agriculture:
├─ Irrigation water touches soil, then roots
├─ Time/distance between water and harvest
├─ Less stringent standards for growing water
└─ Testing timeline allows for remediation

CEA (Hydro/Aqua):
├─ Water directly contacts edible portions
├─ No time/distance between contact and harvest
├─ Same standard as post-harvest water
└─ Real-time monitoring critical
```

### 3.2 Agricultural Water Testing

#### Testing Requirements for Growing Water (Soil-Based)

**Initial Survey:**
- Minimum 4 samples over time
- Represents seasonal variation
- Establishes baseline

**Ongoing Testing:**
- Annual minimum (5 samples/year typical)
- More frequent if risk factors present
- After significant events

**Microbial Quality Profile:**

Calculate Geometric Mean (GM) and Statistical Threshold Value (STV):

```
WATER QUALITY CRITERIA

Acceptable if BOTH:
├─ Geometric Mean (GM) ≤ 126 CFU E. coli/100mL
└─ Statistical Threshold (STV) ≤ 410 CFU E. coli/100mL

If exceeds:
├─ Stop using source immediately
├─ Investigate cause
├─ Implement corrective measures
└─ Re-test before resuming use
```

#### Testing for Harvest/Packing Water

**Standard:** No detectable generic E. coli

**Frequency:**
- At start of season
- At interval adequate to ensure quality
- After any system changes
- After weather events

**Testing Methods:**
- Presence/absence tests
- Colilert
- Lab culture methods
- Approved rapid tests

#### CEA Water Testing Protocol

**Recommended for Hydroponics/Aquaponics:**

| Parameter | Frequency | Action Level |
|-----------|-----------|--------------|
| **E. coli** | Weekly | 0 CFU/100mL |
| **Total coliforms** | Weekly | <10 CFU/100mL |
| **pH** | Daily | 5.5-6.5 (crop dependent) |
| **Temperature** | Continuous | Species-specific |
| **Turbidity** | Weekly | <5 NTU |

### 3.3 Water Sources and Treatment

#### Source Risk Assessment

**Lower Risk Sources:**
- Municipal water
- Deep groundwater wells
- Protected springs
- Treated water

**Higher Risk Sources:**
- Surface water (rivers, ponds)
- Shallow wells
- Untreated sources
- Sources near animal operations

#### Water Treatment Options

```
WATER TREATMENT METHODS

┌────────────────────────────────────────────────────────┐
│                                                        │
│  CHLORINATION                                          │
│  ├─ Most common for produce washing                   │
│  ├─ Target: 50-200 ppm free chlorine                  │
│  └─ Monitor pH, contact time, concentration            │
│                                                        │
│  UV TREATMENT                                          │
│  ├─ No chemical residue                                │
│  ├─ Requires clear water                               │
│  └─ Validate dose and maintain lamps                   │
│                                                        │
│  OZONE                                                 │
│  ├─ Strong oxidizer                                    │
│  ├─ No residual protection                             │
│  └─ Expensive equipment                                │
│                                                        │
│  FILTRATION                                            │
│  ├─ Removes particles, some microbes                   │
│  ├─ Requires regular maintenance                       │
│  └─ Often combined with other methods                  │
│                                                        │
│  HEAT TREATMENT                                        │
│  ├─ Effective kill step                                │
│  ├─ Energy intensive                                   │
│  └─ Used for nutrient solutions in CEA                 │
│                                                        │
└────────────────────────────────────────────────────────┘
```

### 3.4 Biological Soil Amendments

#### What Are BSALs?

**Biological Soil Amendment of Animal Origin (BSAO):**
- Manure (raw or composted)
- Blood meal, bone meal, fish emulsion
- Any amendment from animal sources

**Biological Soil Amendment of Non-Animal Origin:**
- Plant-based composts
- Cover crop residues
- Wood chips, sawdust

**PSR Focus:** BSAOs carry higher pathogen risk

#### Application Requirements

```
BSAO APPLICATION INTERVALS

RAW MANURE (Untreated)
├─ 120 days: Soil contact with harvestable portion
│   (lettuce, strawberries, low-growing crops)
│
└─ 90 days: No soil contact
    (trellised tomatoes, staked peppers)

TREATED MANURE (Properly Composted)
└─ 0 days: Can apply at any time
    (if process validated)
```

#### Composting Standards

**Proper Composting Process:**

1. **Temperature Requirements**
   - 131-170°F maintained
   - 15 days minimum in windrow (turned 5+ times)
   - 3 days minimum in static pile/vessel

2. **Validation**
   - Temperature monitoring logs
   - Time tracking
   - Turning records
   - Moisture and oxygen levels

3. **Testing**
   - Pathogen testing recommended
   - Salmonella, E. coli, fecal coliforms
   - Before first use and periodically

**Compost Tea Considerations:**
- If contains BSAO: follow manure rules
- If non-animal origin: no restrictions
- Monitor for contamination during brewing

### 3.5 Worker Health and Hygiene

#### Health and Hygienic Practices

**Farm Must Take Measures to Prevent:**
- Contamination of produce by ill workers
- Contamination from lack of hygiene
- Transfer of microorganisms to produce

#### Required Practices

```
WORKER HYGIENE REQUIREMENTS

HEALTH SCREENING
├─ Workers must notify supervisor if:
│  • Vomiting or diarrhea
│  • Jaundice
│  • Infected wounds/boils
│  • Diagnosed with illness (Salmonella, E. coli, etc.)
│
└─ Action: Exclude or restrict from produce contact

HAND WASHING
├─ Before starting work
├─ After restroom use
├─ After breaks/eating/smoking
├─ After handling trash/manure/animals
└─ As necessary to prevent contamination

GLOVES
├─ Clean and intact
├─ Changed when contaminated
├─ Hand washing still required
└─ Not substitute for hand washing

EATING/DRINKING/TOBACCO
├─ Prohibited in production areas
├─ Designated areas only
└─ Hand washing before returning to work
```

#### Restroom and Hand Washing Facilities

**Requirements:**

| Facility | Standard | Location |
|----------|----------|----------|
| **Toilets** | Adequate number, clean, stocked | Readily accessible |
| **Hand washing** | Running water, soap, towels | At/near toilets AND fields |
| **Portable toilets** | Serviced regularly, secured | Close to work areas |
| **Hand wash stations** | Potable water, dispensed soap | Within 1/4 mile of workers |

**Inadequate Examples:**
- Communal hand washing bucket (no running water)
- No soap or drying method
- Facilities locked or too far away
- Unserviced portable toilets

### 3.6 Equipment, Tools, and Buildings

#### Sanitation Requirements

All equipment and tools must be:

1. **Adequate for intended use**
2. **Cleanable** (smooth, non-porous surfaces)
3. **Properly stored** (protected from contamination)
4. **Maintained** (in good repair)
5. **Cleaned and sanitized** as needed

#### Equipment Categories and Standards

```
EQUIPMENT SANITATION STANDARDS

FOOD-CONTACT SURFACES
├─ Harvest containers
├─ Packing equipment
├─ Washing/cooling systems
├─ Cutting/processing tools
│
└─ REQUIREMENTS:
    ├─ Cleaned before use
    ├─ Sanitized as necessary
    ├─ Maintained to minimize contamination
    └─ Inspected regularly

NON-FOOD-CONTACT SURFACES
├─ Floors, walls, ceilings
├─ Drains
├─ Equipment exteriors
│
└─ REQUIREMENTS:
    ├─ Kept clean
    ├─ Maintained in good repair
    └─ Not harbor pests
```

#### Building and Structure Standards

**Packing Houses/Storage:**

| Area | Requirements |
|------|--------------|
| **Floors** | Smooth, cleanable, adequate drainage |
| **Walls/Ceilings** | Maintained, cleanable, prevent contamination |
| **Lighting** | Adequate for sanitation and operations |
| **Ventilation** | Adequate to minimize condensation |
| **Pest Control** | Exclude pests, evidence of control |
| **Waste** | Properly stored and removed |

**Bathroom/Break Areas:**
- Separated from produce handling
- Proper drainage away from production
- Regularly cleaned and maintained

### 3.7 Domesticated and Wild Animals

#### Animal Intrusion Risks

Animals can contaminate produce through:
- Direct contact (defecation on crops)
- Indirect contact (soil/water contamination)
- Equipment contamination (footprints in packing area)

#### Monitoring Requirements

**Farms Must:**
- Monitor for animal intrusion
- Assess potential contamination
- Take corrective actions when needed

**Not Required:**
- Eliminate all wildlife
- Fence all production areas
- Remove all animal habitat

#### Risk-Based Assessment

```
ANIMAL INTRUSION DECISION TREE

Evidence of animals in/around production area?
         │
         ├── NO → Continue monitoring
         │
         └── YES
               ↓
   Significant potential for contamination?
         │
         ├── NO → Document, continue monitoring
         │
         └── YES
               ↓
   What was potentially contaminated?
         │
         ├── Equipment → Clean & sanitize
         ├── Growing area → Assess crop proximity/timing
         └── Harvested produce → Evaluate lot, may discard
```

#### Prevention Strategies

**Domesticated Animals:**
- Keep working animals away from production
- Control farm pets
- Fence cattle/livestock separate from crops
- Prevent animal access to water sources

**Wild Animals:**
- Remove attractants (fallen fruit, garbage)
- Maintain borders (mowing, clearing)
- Use wildlife exclusion where practical (netting, fencing)
- Adjust harvest timing after intrusion events

#### Intrusion Documentation

**Record When:**
- Significant intrusion observed
- Assessment conducted
- Actions taken
- Produce affected (if any)

**Example Log:**
| Date | Location | Animal Type | Assessment | Action Taken |
|------|----------|-------------|------------|--------------|
| 6/15 | Field B3 | Deer | Minimal contact | Increased monitoring |
| 7/2 | Pack shed | Rodent droppings | Equipment exposure | Deep clean, set traps |

### 3.8 Implementation Planning

#### Compliance Checklist

**For Each Requirement:**

1. **Understand:** What does the rule require?
2. **Assess:** Does it apply to my operation?
3. **Evaluate:** What am I currently doing?
4. **Identify Gaps:** What needs to change?
5. **Plan:** How will I implement?
6. **Document:** What records are needed?
7. **Train:** Who needs to know what?

#### Example: Water Compliance Plan

```
WATER COMPLIANCE IMPLEMENTATION

CURRENT STATE
├─ Using municipal water for washing
├─ Well water for greenhouse irrigation
└─ No current testing program

GAP ANALYSIS
├─ Municipal: Likely compliant (verify annually)
├─ Well water: Needs initial and ongoing testing
└─ No written procedures or records

ACTION PLAN
├─ 1. Request municipal water quality report
├─ 2. Develop well water testing protocol
├─ 3. Collect initial well water samples (4x)
├─ 4. Establish annual testing schedule
├─ 5. Create testing record template
├─ 6. Train staff on water handling procedures
└─ 7. Post water quality requirements

BUDGET
├─ Testing: $50/sample x 8 samples/year = $400
├─ Backup treatment system: $2,000
└─ Training materials: $100
```
