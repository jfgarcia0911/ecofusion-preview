## Lesson Content

### 5.1 Biological Soil Amendment Categories

#### BSAO vs. Non-Animal Origin

```
BIOLOGICAL SOIL AMENDMENTS

ANIMAL ORIGIN (BSAO)          NON-ANIMAL ORIGIN
├─ Raw manure                 ├─ Plant composts
├─ Composted manure           ├─ Cover crop residues
├─ Blood meal                 ├─ Wood chips
├─ Bone meal                  ├─ Sawdust
├─ Fish emulsion              ├─ Straw/hay
├─ Feather meal               ├─ Green waste compost
└─ Animal-based composts      └─ Biochar

High Risk                     Lower Risk
PSR Standards Apply           Fewer Restrictions
```

#### Why BSAOs Require Special Handling

**Pathogen Risk:**
- E. coli O157:H7 in cattle manure
- Salmonella in poultry litter
- Listeria in various animal sources
- Parasites and other pathogens

**Historic Outbreaks Linked to Manure:**
- 2006 spinach outbreak: Cattle nearby
- Multiple lettuce contaminations
- Fresh herb contaminations

### 5.2 Application Interval Requirements

#### The 90/120-Day Rule

```
BSAO APPLICATION INTERVALS

RAW OR INADEQUATELY TREATED MANURE

┌────────────────────────────────────────────┐
│                                            │
│  120 DAYS                                  │
│  ────────                                  │
│  Before harvest if harvestable portion     │
│  has direct soil contact                   │
│                                            │
│  Examples:                                 │
│  • Lettuce, spinach (leaves on ground)    │
│  • Strawberries (fruit touches soil)      │
│  • Carrots, radishes (root crops)         │
│  • Melons (resting on soil)               │
│                                            │
└────────────────────────────────────────────┘

┌────────────────────────────────────────────┐
│                                            │
│  90 DAYS                                   │
│  ───────                                   │
│  Before harvest if harvestable portion     │
│  does NOT contact soil                     │
│                                            │
│  Examples:                                 │
│  • Trellised tomatoes                     │
│  • Staked peppers                         │
│  • Tree fruits                            │
│  • Vining crops (on trellis)              │
│                                            │
└────────────────────────────────────────────┘

TREATED MANURE (Properly Composted)
└─ 0 DAYS: No waiting period if process validated
```

#### Calculating Application Dates

**Example 1: Spring Lettuce**

| Date | Activity | Interval |
|------|----------|----------|
| March 1 | Apply raw manure | Day 0 |
| March 1 + 120 days | = June 29 | Earliest harvest |
| July 15 | Planned harvest | ✓ Compliant |

**Example 2: Summer Tomatoes (Staked)**

| Date | Activity | Interval |
|------|----------|----------|
| April 1 | Apply raw manure | Day 0 |
| April 1 + 90 days | = June 30 | Earliest harvest |
| July 20 | First harvest | ✓ Compliant |

### 5.3 Composting to Meet PSR Standards

#### Validated Composting Process

**Two Acceptable Methods:**

**Method 1: Windrow Composting**
```
WINDROW COMPOSTING REQUIREMENTS

Temperature: 131-170°F
Duration: 15 days minimum
Turning: 5 times minimum during 15-day period

Monitoring:
├─ Temperature: Daily minimum
├─ Turning: Record each turn
├─ Time: Track total duration
└─ Moisture: Maintain 50-60%
```

**Method 2: Static Pile/In-Vessel**
```
STATIC PILE COMPOSTING REQUIREMENTS

Temperature: 131-170°F
Duration: 3 days minimum
Aeration: Forced air or equivalent

Monitoring:
├─ Temperature: Daily minimum
├─ Time: Continuous at temp
├─ Aeration: System function
└─ Moisture: Adequate levels
```

#### Temperature Monitoring

**Critical Requirements:**

| Parameter | Specification |
|-----------|--------------|
| **Temperature** | 131-170°F (55-77°C) |
| **Measurement** | Compost thermometer, 18-24" deep |
| **Frequency** | Daily during active composting |
| **Documentation** | Written temperature log |
| **Action** | Re-heat if falls below 131°F |

**Temperature Log Example:**

| Date | Pile Location | Temp (°F) | Turn? | Moisture | Initials |
|------|--------------|-----------|-------|----------|----------|
| 5/1 | Pile A, Center | 145 | No | Good | JD |
| 5/2 | Pile A, Center | 152 | Yes | Good | JD |
| 5/3 | Pile A, Center | 158 | No | Good | JD |

### 5.4 Compost Process Management

#### Recipe and Ingredients

**Carbon:Nitrogen Ratio:**
- Target: 25-30:1
- Too high (>40:1): Slow decomposition
- Too low (<20:1): Ammonia loss, odor

**Ingredient Examples:**

| Material | C:N Ratio | Category |
|----------|-----------|----------|
| Manure (fresh) | 15-25:1 | Nitrogen |
| Food scraps | 15-20:1 | Nitrogen |
| Grass clippings | 20:1 | Nitrogen |
| Straw | 80:1 | Carbon |
| Wood chips | 400:1 | Carbon |
| Leaves (dry) | 60:1 | Carbon |

#### Moisture Management

```
MOISTURE CONTENT TEST

Squeeze Test:
├─ Grab handful of compost
├─ Squeeze firmly
└─ Assess:
    ├─ No water drips, doesn't form ball → Too dry (add water)
    ├─ Few drops, forms ball → Optimal (50-60%)
    └─ Water streams out → Too wet (add dry carbon)
```

#### Turning Schedule

**Purpose of Turning:**
- Mix materials
- Add oxygen
- Distribute heat
- Move outer material to center

**Windrow Turning Protocol:**
- Minimum 5 turns during 15-day period
- More frequent turning accelerates process
- Turn when temperature drops or every 3-5 days
- Move outside material to inside of new pile

### 5.5 Verification and Testing

#### Process Validation

**First-Time Composting:**
- Document full process
- Temperature logs throughout
- Consider pathogen testing
- Review with food safety expert

**Ongoing Validation:**
- Continue temperature monitoring
- Annual pathogen testing (recommended)
- Process review if changes made
- Documentation maintenance

#### Pathogen Testing

**Recommended Tests:**

| Pathogen | Method | Frequency |
|----------|--------|-----------|
| E. coli | Culture | Initially, then annually |
| Salmonella | Culture | Initially, then annually |
| Fecal coliforms | MPN or culture | Optional verification |

**Interpretation:**
- Non-detect: Process effective
- Present: Re-compost or extend intervals

### 5.6 Application Best Practices

#### Incorporation Methods

**Surface Application:**
- Higher risk if not incorporated
- Weather-dependent (rain splash)
- Use for trees, established perennials

**Incorporated:**
- Till into soil
- Reduces contamination risk
- Better nutrient availability

**Banded/Side-dressed:**
- Away from edible portions
- Minimum 6" from plants
- Good for fruiting crops

#### Application Records

**Required Documentation:**

```
SOIL AMENDMENT APPLICATION LOG

For each application, record:
├─ Date of application
├─ Location/field
├─ Type of amendment
├─ Source (if BSAO)
├─ Treatment method
├─ Amount applied
├─ Application method
└─ Applicator name

Harvest tracking:
└─ Earliest allowable harvest date
```

**Sample Record:**

| Date | Field | Amendment | Amount | Treatment | Harvest After |
|------|-------|-----------|--------|-----------|---------------|
| 3/15 | A-2 | Chicken manure | 2 tons | Composted (validated) | 3/15 (no wait) |
| 4/1 | B-1 | Cow manure | 500 lbs | Raw | 7/30 (120 days) |

### 5.7 Alternatives for CEA Operations

#### Why BSAOs are Challenging for CEA

**Issues in Soilless Systems:**
- Risk of system contamination
- Difficult to flush from recirculating water
- Temperature/moisture favor pathogen growth
- Limited application interval options

#### CEA-Appropriate Amendments

**Safer Alternatives:**

| Amendment | Type | Application | Risk Level |
|-----------|------|-------------|------------|
| **Synthetic nutrients** | Liquid concentrate | Injected into system | Minimal |
| **Fish waste (from system)** | Integrated | Natural (aquaponics) | Managed |
| **Seaweed extracts** | Plant-based | Foliar or root | Low |
| **Compost tea** | Plant-based only | Foliar or drench | Low (if no BSAO) |
| **Mycorrhizae** | Biological | Root inoculation | Minimal |

#### Aquaponics-Specific Considerations

**Fish Waste as Amendment:**
- Continuously applied via system
- Biofilter conversion to plant-available forms
- Monitoring water quality = monitoring "amendment"
- System sanitation between crops recommended

**PSR Application:**
- Fish waste = animal origin
- But integral to system design
- Water testing serves as verification
- No specific "application interval" applicable

### 5.8 Compost Tea Considerations

#### Compost Tea Safety

**Risk Assessment:**

```
COMPOST TEA SAFETY DECISION TREE

What is compost source?
        │
        ├── Plant-based only
        │   └─ Low risk, no special requirements
        │
        └── Contains animal manure
            └─ Treated as BSAO application
                ├─ Use on crops with harvest intervals OR
                └─ Test tea for pathogens before application
```

**If Using Animal-Based Compost Tea:**
- Apply 90/120 day intervals, OR
- Test each batch for E. coli/Salmonella, OR
- Use only on crops with processing kill step

#### Brewing Best Practices

**Contamination Prevention:**
- Start with validated compost
- Use potable water
- Clean brewing equipment
- Brew time <36 hours (prevents pathogen growth)
- Adequate aeration
- Apply immediately after brewing

### 5.9 Record-Keeping Requirements

#### What to Document

**For All BSAOs:**

1. **Source Information**
   - Origin of material
   - Supplier name and contact
   - Date received

2. **Treatment Documentation**
   - Composting method used
   - Temperature logs
   - Duration at temperature
   - Process completion date

3. **Application Records**
   - Date, location, amount
   - Method of application
   - Person responsible
   - Crop/field designation

4. **Harvest Calculations**
   - Application date
   - Required interval (90 or 120 days)
   - Earliest harvest date

**Retention:**
- Minimum 2 years
- Longer if crop storage extends beyond
