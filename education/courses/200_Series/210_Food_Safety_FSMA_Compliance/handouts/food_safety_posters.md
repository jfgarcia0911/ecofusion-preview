## Poster 6: Temperature Control

```
┌───────────────────────────────────────────────────────┐
│                                                       │
│           KEEP IT COLD!                               │
│        Temperature Control Required                   │
│                                                       │
│   DANGER ZONE: 41-135°F                               │
│   Bacteria grow rapidly in this range                 │
│                                                       │
│   TARGET TEMPERATURES:                                │
│   • Leafy greens: 34-36°F                             │
│   • Tomatoes: 50-55°F                                 │
│   • General produce: 34-38°F                          │
│                                                       │
│   MONITOR TEMPERATURE:                                │
│   ✓ Check coolers twice daily                         │
│   ✓ Check product core temperature                    │
│   ✓ Record all readings                               │
│   ✓ Report if out of range                            │
│                                                       │
│   Cool produce quickly after harvest!                 │
│   Keep cold chain from harvest to customer!           │
│                                                       │
└───────────────────────────────────────────────────────┘
```

│        WATER QUALITY MATTERS!                         │
│                                                       │
│   For washing produce:                                │

│   • Must be potable or treated                        │
│   • Sanitizer maintained (50-200 ppm)                 │

## Printing Instructions

**Recommended Specifications:**
- Paper: Heavy cardstock or laminated
- Size: 11x17 inches (or larger for visibility)
- Colors: High contrast for readability
- Location: Post prominently at:
  - Hand washing stations
  - Restroom entrances
  - Production area entrances
  - Break areas
  - Packing facilities
  - Time clock/punch-in area

**Maintenance:**
- Replace when faded or damaged
- Update contact information as needed
- Translate to worker languages
- Review with workers during training
