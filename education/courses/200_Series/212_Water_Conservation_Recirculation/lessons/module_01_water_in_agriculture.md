## Introduction

Water is agriculture's most critical input and increasingly its most limiting resource. While conventional agriculture accounts for approximately 70% of global freshwater withdrawals, controlled environment agriculture (CEA) offers revolutionary potential for water conservation through recirculation and precision management.

This module establishes the foundation for understanding why water conservation matters and how recirculating systems represent a paradigm shift in agricultural water use.

**Key Statistics:**
- Agriculture uses 70% of accessible freshwater globally
- 40% of global food production depends on irrigation
- Only 40-60% of irrigation water reaches crops in conventional systems
- Groundwater depletion exceeds recharge in major agricultural regions

### Efficiency Metrics Explained

**Water Use Efficiency (WUE)**
```
WUE = Crop Yield (kg) ÷ Water Applied (m³)

Example - Lettuce Production:
Field agriculture:     0.5 kg/m³
Recirculating CEA:     50 kg/m³
Improvement:           100x more efficient
```

**Water Productivity**
```
Water Productivity = Economic Value ($) ÷ Water Used (m³)

Conventional field:    $0.50-2.00/m³
Recirculating CEA:     $50-150/m³
```

## Recirculation Fundamentals

### What is Recirculating Agriculture?

**Definition:** Agricultural systems that recover and reuse water, minimizing discharge and fresh water inputs by continuously cycling water through treatment and back to crops.

### Basic Recirculation Cycle

```
┌────────────────────────────────────────────────────────────────┐
│              RECIRCULATING SYSTEM WATER FLOW                   │
└────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────┐
    │                                                     │
    │  FRESH WATER INPUT (5-10%)                          │
    │  (Replaces evapotranspiration + minor losses)       │
    │                                                     │
    └──────────────────────┬──────────────────────────────┘
                           │
                           ▼
              ┌────────────────────────┐
              │                        │
              │   GROWING SYSTEM       │
              │   • Plants consume     │
              │   • Evapotranspiration │
              │                        │
              └──────────┬─────────────┘
                         │
                         │ Return flow (90-95%)
                         ▼
              ┌────────────────────────┐
              │                        │
              │   TREATMENT SYSTEM     │
              │   • Filtration         │
              │   • Sterilization      │
              │   • Nutrient balance   │
              │                        │
              └──────────┬─────────────┘
                         │
                         │ Recirculated (90-95%)
                         │
                         └──────────────┐
                                        │
                    ┌───────────────────┘
                    │
    ┌───────────────▼────────────────────────────────────┐
    │                                                    │
    │  DISCHARGE (minimal)                               │
    │  • Filter backwash: <2%                            │
    │  • System cleaning: <3%                            │
    │                                                    │
    └────────────────────────────────────────────────────┘
```

### Key Performance Indicators

**Water Recirculation Rate (WRR)**
```
WRR = (Volume Recirculated ÷ Total Volume Used) × 100%

Target: >90% for efficient systems
Excellence: >95%
```

**Makeup Water Ratio (MWR)**
```
MWR = Fresh Water Added ÷ Total System Volume per Day

Target: <10% daily
Excellence: <5% daily
```

**Water Footprint**
```
Water Footprint = Total Water Input ÷ Production Output

Example - Lettuce:
Recirculating: 1-2 gal/lb
Conventional: 25-40 gal/lb
Reduction: 90-95%
```

## Module Summary

### Key Takeaways

1. **Agriculture is the largest consumer of freshwater globally** - accounting for 70% of withdrawals, with conventional systems achieving only 35-40% efficiency

2. **Recirculating systems achieve 90-99% water efficiency** - representing a 10-100x improvement over conventional agriculture

3. **Multiple drivers support water conservation** - environmental pressures, economic costs, regulatory requirements, and social expectations

4. **Economic case varies by region** - strongest in water-scarce areas, but improving everywhere as water costs rise and technology costs decline

5. **Recirculation requires active management** - water quality, filtration, and sterilization are essential for long-term success
