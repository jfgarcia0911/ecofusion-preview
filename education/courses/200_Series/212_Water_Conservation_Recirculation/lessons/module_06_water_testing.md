## Essential Testing Parameters

### pH Testing

**Measurement Methods:**

| Method | Accuracy | Cost | Best For |
|--------|----------|------|----------|
| **Test strips** | ±0.5 pH | $0.10/test | Quick checks only |
| **Liquid reagent** | ±0.2 pH | $0.25/test | Backup verification |
| **Digital pen** | ±0.1 pH | $30-100 | Daily testing (small systems) |
| **Lab-grade probe** | ±0.01 pH | $200-500 | Continuous monitoring |

**Testing Procedure:**
```
1. Calibrate meter (pH 4, 7, 10 buffers)
2. Rinse probe with distilled water
3. Immerse in sample (actively mixing)
4. Wait for stable reading (30-60 sec)
5. Record result
6. Rinse probe, store in storage solution

Test frequency: Daily (minimum)
```

### EC/TDS Testing

**Understanding the Measurement:**
```
EC (Electrical Conductivity) = mS/cm or µS/cm
TDS (Total Dissolved Solids) = ppm

Conversion:
EC (mS/cm) × 500 = TDS (ppm) [approximate, factor 0.5]
EC (mS/cm) × 700 = TDS (ppm) [factor 0.7]

Example:
EC = 2.0 mS/cm
TDS = 2.0 × 500 = 1,000 ppm (0.5 factor)
TDS = 2.0 × 700 = 1,400 ppm (0.7 factor)

Use consistent conversion factor!
```

**EC Meters:**
- Temperature compensation essential
- Calibrate with standard solution (1.413 mS/cm typical)
- Cell constant varies (0.1 for low EC, 1.0 for high)

### Dissolved Oxygen Testing

**Testing Methods:**

1. **Optical DO Meter** (Best)
   - No membrane/electrolyte
   - Fast, accurate
   - $300-800

2. **Electrochemical Probe**
   - Traditional method
   - Requires membrane replacement
   - $200-600

3. **Chemical Test Kit**
   - Winkler method
   - Accurate but time-consuming
   - $40-80

**DO Levels and Temperature:**
```
TEMPERATURE EFFECT ON DO SATURATION

Temp (°F)    DO Saturation (mg/L)
─────────────────────────────────
   50             11.3
   60             10.1
   70              9.1
   80              8.2
   90              7.4

Higher temperature = Lower DO capacity
```

```
1. Use lab-provided sterile containers
2. Rinse container 3× with sample water
3. Fill completely (minimize air)
4. Label clearly (date, location, sample ID)

6. Ship with ice pack if mailing
```

## Calibration Procedures

### pH Meter Calibration

**Two-Point Calibration (Minimum):**

```
STEP-BY-STEP pH CALIBRATION

1. Prepare buffers (pH 7.0 and 4.0 or 10.0)
   • Use fresh buffers (replace monthly)
   • Bring to sample temperature

2. Rinse probe with distilled water

3. Immerse in pH 7.0 buffer
   • Wait for stable reading
   • Adjust to 7.0 (calibration mode)

4. Rinse probe thoroughly

5. Immerse in second buffer (4.0 or 10.0)
   • Wait for stable reading
   • Adjust to buffer value

6. Rinse and test with third buffer to verify
   • Should be within ±0.1 pH
   • If not, repeat calibration

7. Store probe in storage solution (NOT distilled water!)

Calibration frequency: Weekly (daily use) or before critical measurements
```

### EC Meter Calibration

```
EC CALIBRATION PROCEDURE

1. Obtain standard solution (1.413 mS/cm common)

2. Rinse probe with distilled water

3. Immerse in standard solution
   • Ensure temperature compensation active
   • Wait for stable reading

4. Adjust meter to match standard value

5. Rinse probe

6. Verify with second standard if available

7. Store probe in distilled water or dry (check manual)

Calibration frequency: Monthly minimum
```

## Monitoring Protocols

### Testing Schedules

**Daily Testing Protocol:**
```
TIME: Morning (before feeding/adjusting)

□ System walk-through (visual inspection)
□ pH reading (reservoir)
□ EC reading (reservoir)
□ Temperature (multiple zones)
□ DO reading (if available)
□ Record all values

TIME: 5-10 minutes
```

**Weekly Testing Protocol:**
```
All daily tests PLUS:

□ Nitrate (NO₃)
□ Phosphorus (P)
□ Potassium (K)
□ Iron (Fe)
□ Zone-specific pH/EC (multiple points)
□ System flow rates
□ Filter pressure differential

TIME: 30-45 minutes
```

**Monthly Testing Protocol:**
```
All weekly tests PLUS:

□ Calcium
□ Magnesium
□ Sulfur
□ Micronutrient panel
□ Alkalinity
□ Source water comparison
□ Equipment calibration

TIME: 1-2 hours
```

**Trend Identification:**

```
WEEKLY pH TREND EXAMPLE

pH
7.0 ─  ●
     │   ╲

     │     ╲   ╲  ●
6.6 ─      ●    ╲   ●
     │            ╲
6.4 ─             ╲  ●
     │              ╲
6.2 ─               ●
     └─────────────────────────
     Mon Tue Wed Thu Fri Sat Sun

Observation: Steady pH decline
Action needed: Increase pH correction frequency
Possible causes: High nitrate accumulation, low alkalinity
```

**Red Flags in Data:**
- Rapid changes (>0.5 pH or >0.3 EC in 24 hrs)
- Divergence between zones
- Steadily declining DO
- Rising EC despite no nutrient additions

## Module Summary

### Key Takeaways

1. **Match equipment to scale and budget** - basic meters suffice for small systems; invest in advanced monitoring as you scale

2. **Calibration is non-negotiable** - uncalibrated meters provide false confidence with inaccurate data

3. **Consistent testing schedules** - daily basics (pH, EC, temp) plus weekly nutrients catch problems early

4. **Record and analyze trends** - individual readings matter less than patterns over time

5. **Laboratory verification** - periodic professional testing validates your equipment and technique
