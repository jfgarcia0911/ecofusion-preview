## Daily Testing Protocol

**Time Required:** 10-15 minutes

**Equipment:**
- pH meter (calibrated)
- EC meter (calibrated)
- Thermometer or multi-probe
- DO meter (if available)
- Logbook or digital tracker

**Procedure:**

```
1. SYSTEM WALK-THROUGH (5 min)
   □ Visual inspection (color, clarity, smell)
   □ Listen for unusual pump/equipment sounds
   □ Check for leaks or wet spots
   □ Verify all equipment operating

2. RESERVOIR TESTING (5 min)
   □ pH reading - record
   □ EC reading - record
   □ Temperature - record
   □ DO (if equipped) - record

3. ZONE CHECKS (5 min for multi-zone)
   □ Test each zone or representative samples
   □ Compare to reservoir values
   □ Note any significant differences

4. RECORDING
   □ Log all values with date/time
   □ Note any observations or actions taken
   □ Flag values outside target ranges
```

**Target Ranges (General Leafy Greens):**
- pH: 5.5-6.5
- EC: 1.5-2.2 mS/cm
- Temp: 65-72°F
- DO: >6 mg/L

## Weekly Testing Protocol

**Time Required:** 30-45 minutes

**Additional Equipment:**
- Nitrate test kit or meter
- Phosphorus test kit
- Potassium test kit
- Iron test kit

**Procedure:**

```
STANDARD DAILY TESTS (10 min)
Perform all daily testing first

NUTRIENT TESTING (20-30 min)
□ Nitrate (NO₃) test
  - Target: 100-200 ppm
  - Method: Colorimetric or ion-selective electrode

□ Phosphorus (P) test
  - Target: 30-60 ppm
  - Method: Colorimetric test kit

□ Potassium (K) test
  - Target: 200-300 ppm
  - Method: Colorimetric test kit

□ Iron (Fe) test
  - Target: 1-3 ppm
  - Method: Colorimetric test kit

SYSTEM CHECKS (10-15 min)
□ Filter pressure differential
□ Flow rate verification
□ UV lamp hours check
□ Backwash cycle count

PLANT ASSESSMENT (10 min)
□ Scout 10% of plants for deficiency symptoms
□ Check roots (white, healthy vs. brown, slimy)
□ Note pest/disease presence
□ Growth rate assessment
```

## Monthly Testing Protocol

**Time Required:** 1-2 hours

**Equipment:**
- All weekly equipment PLUS:
- Secondary macronutrient kits (Ca, Mg, S)
- Alkalinity test kit
- Turbidity meter (or visual comparison)
- Calibration solutions

**Procedure:**

```
EQUIPMENT CALIBRATION (20-30 min)
□ pH meter: 3-point calibration (4, 7, 10)
□ EC meter: Standard solution calibration
□ DO meter: Calibration (if equipped)
□ Verify all meters within spec

COMPREHENSIVE WATER TESTING (30-45 min)
□ All weekly tests (pH, EC, Temp, DO, N, P, K, Fe)
□ Calcium test (target: 150-200 ppm)
□ Magnesium test (target: 40-60 ppm)
□ Sulfur test (target: 50-100 ppm)
□ Alkalinity (target: 50-100 ppm CaCO₃)
□ Turbidity (<5 NTU ideal)

SYSTEM MAINTENANCE (30-45 min)
□ Clean all filter housings
□ Inspect UV quartz sleeve - clean if needed
□ Check all sensors and probes - clean
□ Verify pump performance
□ Inspect plumbing for wear/leaks

DOCUMENTATION REVIEW
□ Analyze trends over past month
□ Compare to targets
□ Identify any patterns or concerns
□ Plan corrective actions
```

## Quarterly Testing Protocol

**Time Required:** Half day + lab fees

**Includes:**
- All monthly testing
- Professional laboratory analysis
- Equipment inspection
- Performance audit

**Laboratory Analysis:**

Send samples to certified ag water testing lab for comprehensive panel:

```
BASIC PANEL ($75-150)
□ pH, EC, TDS
□ All macronutrients (N, P, K, Ca, Mg, S)
□ Sodium, Chloride

COMPREHENSIVE PANEL ($150-300)
□ Basic panel +
□ All micronutrients (Fe, Mn, B, Zn, Cu, Mo)
□ Alkalinity, Hardness
□ Heavy metals screening

SPECIALIZED TESTING (as needed)
□ Microbial analysis ($50-150)
□ Organic compound screening ($100-300)
□ Pathogen-specific tests ($50-200 each)
```

**Sample Collection for Lab:**
1. Use lab-provided sterile containers
2. Collect from well-mixed reservoir
3. Fill completely, minimize air space
4. Label with date, location, sample ID
5. Refrigerate if >24 hrs to lab
6. Ship with ice pack if mailing

**Performance Audit:**

```
WATER USE ANALYSIS
□ Calculate monthly water consumption
□ Calculate recirculation rate
□ Water use efficiency (gal/lb crop)
□ Compare to benchmarks
□ Identify improvement opportunities

EQUIPMENT ASSESSMENT
□ UV lamp replacement schedule check
□ Filter media condition evaluation
□ Pump efficiency test
□ Sensor accuracy verification
□ Overall system performance rating
```

## Calibration Procedures

### pH Meter Calibration (Weekly)

```
1. Prepare fresh buffer solutions (pH 4, 7, 10)
2. Rinse probe with distilled water
3. Immerse in pH 7 buffer
4. Wait for stable reading, calibrate to 7.0
5. Rinse probe
6. Immerse in pH 4 (or 10) buffer
7. Wait for stable reading, calibrate
8. Rinse and verify with third buffer (±0.1 acceptable)
9. Store probe in storage solution (NOT water)

Replace: Buffers monthly, probe annually or when won't calibrate
```

### EC Meter Calibration (Monthly)

```
1. Obtain standard solution (1.413 mS/cm typical)
2. Rinse probe with distilled water
3. Immerse in standard solution
4. Ensure temperature compensation active
5. Wait for stable reading
6. Adjust to match standard value
7. Rinse and verify
8. Store probe in distilled water or dry (per manual)

Replace: Standard solution every 6 months, probe every 2-3 years
```

### DO Meter Calibration (Weekly if in use)

```
OPTICAL DO:
1. Sensor in air (100% saturation at current temperature)
2. Allow equilibration (5-10 min)
3. Calibrate to calculated saturation value
4. Verify in water

ELECTROCHEMICAL:
1. Check membrane condition
2. Check electrolyte level
3. 100% calibration in water-saturated air
4. Or 0% calibration in sodium sulfite solution

Replace: Membrane every 6-12 months, electrolyte as needed
```

## Troubleshooting Decision Tree

**IF pH dropping steadily:**
→ Check alkalinity → If low, add K₂CO₃
→ Check nitrate accumulation → If high, partial water change
→ Verify calibration → Recalibrate if needed

**IF EC rising with normal feeding:**
→ Calculate evapotranspiration rate → Likely salt accumulation
→ Perform partial water change (10-20%)
→ Reduce nutrient concentration

**IF cloudy water despite filtration:**
→ Test turbidity → If >10 NTU, clean/upgrade filters
→ Check UV function → Clean sleeve, verify lamp hours
→ Test for bacterial bloom → May need ozone shock treatment

**IF nutrient deficiency symptoms appear:**
→ Test specific nutrient → Adjust if deficient
→ Check pH first → May be lockout, not deficiency
→ Review uptake patterns → Ensure balanced feeding
