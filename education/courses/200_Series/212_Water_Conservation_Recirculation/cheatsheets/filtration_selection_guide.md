## Filter Types Comparison

### Screen Filters

**Best For:** Pre-filtration, debris removal

**Specifications:**
- Mesh: 100-500 microns
- Flow: Up to 100+ GPM (size dependent)
- Materials: Stainless steel, nylon
- Cleaning: Manual brush or backwash

**Pros:**
✓ Low cost ($100-500)
✓ Easy maintenance
✓ Long service life
✓ No consumables

**Cons:**
✗ Coarse filtration only
✗ Requires regular cleaning
✗ Can clog quickly with heavy debris

**Sizing:** Match to pipe size; 1.5-2× diameter of inlet pipe

---

### Bag Filters

**Best For:** Medium systems, easy maintenance, variable flow

**Specifications:**
- Microns: 5-500 (common: 50-100)
- Flow: 10-100 GPM per unit
- Materials: Polyester, polypropylene
- Life: 1-4 weeks (loading dependent)

**Pros:**
✓ Inexpensive ($2-15 per bag)
✓ Very easy to service
✓ No backwash water waste
✓ Good for variable flows

**Cons:**
✗ Regular replacement required
✗ Operating cost (bags)
✗ Not ideal for high solids loading

**Sizing:**
```
Flow Rate: 10-30 GPM per standard bag housing
Use multiple housings in parallel for higher flows

Example:
60 GPM system = 2-3 bag housings
```

---

### Sand Filters

**Best For:** High-quality filtration, large systems, automated operation

**Specifications:**
- Filtration: 20-50 microns
- Media: Silica sand (#20 or #16 grade)
- Depth: 24-48 inches minimum
- Backwash: Automatic (pressure or timer)

**Pros:**
✓ Excellent filtration quality
✓ Long media life (3-7 years)
✓ Automated backwash
✓ Handles high solids loading
✓ Low operating cost

**Cons:**
✗ Higher capital cost ($2,000-6,000)
✗ Requires backwash water (1-3% of flow)
✗ More complex installation
✗ Larger footprint

**Sizing:**
```
Filtration Rate: 15-20 GPM per sq ft of filter area

Example:
60 GPM required
Rate: 15 GPM/sq ft
Area needed: 60 ÷ 15 = 4 sq ft
Tank diameter: ~28 inches
```

**Backwash Requirements:**
- Frequency: When ΔP >10 psi
- Duration: 3-5 minutes
- Flow rate: 15-20 GPM/sq ft (upflow)
- Water use: 60-150 gallons per backwash

---

### Drum Filters

**Best For:** Aquaponics, high solids, continuous operation

**Specifications:**
- Mesh: 50-200 microns (common: 100 µm)
- Rotation: Continuous or intermittent
- Backwash: Spray bar (continuous)
- Solids removal: 90-95%

**Pros:**
✓ Excellent for aquaponics
✓ Continuous self-cleaning
✓ Handles very high solids
✓ Automated operation
✓ Solids easily collected

**Cons:**
✗ High capital cost ($3,000-10,000)
✗ Requires constant water for spray
✗ More complex setup
✗ Moving parts (maintenance)

**Sizing:**
```
Match to system flow rate
Typical: 40-200 GPM capacity
```

---

### Cartridge Filters

**Best For:** Polishing, low-flow systems, pre-RO/UV

**Specifications:**
- Microns: 1-100 (common: 5-25)
- Flow: 5-30 GPM per 10" cartridge
- Materials: Pleated polyester, spun polypropylene
- Life: 1-6 months

**Pros:**
✓ Fine filtration (down to 1 micron)
✓ Compact size
✓ Easy replacement
✓ No backwash needed

**Cons:**
✗ Regular replacement cost
✗ Lower flow capacity
✗ Frequent clogging with high solids
✗ Not suitable for primary filtration

**Sizing:**
```
Flow capacity: 5-10 GPM per 10" cartridge (conservative)

Example:
20 GPM = 2-4 cartridges in parallel
```

## Multi-Stage Filtration Design

### Recommended Configurations

**Basic System (Budget-Conscious):**
```
Stage 1: Screen (200 µm) → Stage 2: Bag Filter (50 µm) → UV
Cost: ~$500-1,500
Maintenance: Moderate
```

**Standard System (Best Value):**
```
Stage 1: Screen (200 µm) → Stage 2: Sand Filter (30 µm) → UV
Cost: ~$2,500-5,000
Maintenance: Low (automated backwash)
```

**Premium System (Maximum Quality):**
```
Stage 1: Screen → Stage 2: Sand → Stage 3: Cartridge (10 µm) → UV
Cost: ~$4,000-7,000
Maintenance: Low to moderate
```

**Aquaponics System:**
```
Stage 1: Settling → Stage 2: Drum (100 µm) → Stage 3: Biofilter → Stage 4: UV
Cost: ~$5,000-12,000
Maintenance: Moderate (biofilter care)
```

## Sizing Quick Calculations

### Required Filter Capacity

```
Filter Capacity ≥ System Flow Rate + 20% safety margin

Example:
System: 40 GPM
Required filter capacity: 40 × 1.2 = 48 GPM minimum
Select: 50-60 GPM rated filter
```

### Backwash Water Budget

```
Daily Backwash Volume = Number of Backwashes × Backwash Volume

Example (Sand Filter):
Filter: 4 sq ft
Backwash flow: 15 GPM/sq ft × 4 = 60 GPM
Duration: 4 minutes
Volume per backwash: 60 × 4 = 240 gallons

If 2 backwashes per day: 480 gallons
As % of 5,000 gal system: 9.6% (high - optimize triggers!)
```

## Maintenance Schedule Template

```
DAILY
□ Check pressure gauges (clean vs. dirty side)
□ Visual inspection for leaks
□ Verify backwash automation functioning

WEEKLY
□ Clean screen filters/pre-filters
□ Check and log pressure differential
□ Inspect drain lines for clogs
□ Verify flow rates

MONTHLY
□ Replace bag filters (if used)
□ Deep clean all accessible filter surfaces
□ Check media depth (sand filters)
□ Inspect valves and seals
□ Clean filter housing

QUARTERLY
□ Replace cartridge filters
□ Inspect sand media (clumping, channeling)
□ Pressure test system
□ Backwash valve function check

ANNUALLY
□ Media replacement (cartridges, bags)
□ Sand replacement evaluation (3-7 year life)
□ Complete system inspection
□ Performance verification testing
```

## Troubleshooting

**Problem: Rapid pressure increase**
- Filter undersized for solids loading
- Backwash frequency too low
- Media degraded or clogged
- → Increase backwash, check sizing, replace media

**Problem: Poor filtration (cloudy water persists)**
- Channeling in media bed
- Bypass leak around filter element
- Media worn out
- → Inspect for leaks, replace media, check installation

**Problem: Short filter element life**
- Inadequate pre-filtration
- Solids loading too high
- Wrong micron rating selected
- → Add coarse pre-filter, reduce loading, upsize elements

**Problem: Excessive backwash water use**
- Timed backwash (vs. pressure differential)
- Backwash duration too long
- Trigger setpoint too sensitive
- → Switch to ΔP trigger, optimize duration, adjust setpoint
