# Light Spectrum Quick Reference Chart

**Course:** 205 - LED Lighting Science

## Wavelength Effects on Plants

```
Wavelength  Color      Plant Response           Recommended %
═══════════════════════════════════════════════════════════════
280-315nm   UV-B       Secondary metabolites    0-1% (optional)
315-400nm   UV-A       Anthocyanins, compact    1-3% (quality)
400-500nm   Blue       Compact growth, stomata  15-30%
500-600nm   Green      Canopy penetration       20-40%
600-700nm   Red        Photosynthesis, flower   40-60%
700-800nm   Far-Red    Elongation, flowering    2-10%
```

## Spectrum Ratios for Morphology Control

```
RED:BLUE RATIO GUIDE
═══════════════════════════════════════════
R:B     Morphology         Use Case
──────  ─────────────      ─────────────────
0.5-1.5 Very compact       Microgreens, seedlings
1.5-2.5 Compact            Lettuce, leafy greens
2.5-4.0 Balanced           Herbs, general veg
4.0-6.0 Elongated          Fruiting crops, flowering
>6.0    Very elongated     Cut flowers, specific apps

RED:FAR-RED RATIO GUIDE
═══════════════════════════════════════════
R:FR    Effect             Application
──────  ────────────────   ──────────────────
>10     Very compact       Prevent elongation
5-10    Moderate compact   Standard production
2-4     Balanced           General growth
1-2     Elongation         Cut flowers, triggers
<1      Strong elongation  Avoid (weak plants)
```

## Wavelength-Specific Functions

```
BLUE LIGHT (400-500nm)
━━━━━━━━━━━━━━━━━━━━━━━
Peak: 440-460nm
✓ Compact growth, short internodes
✓ Thick leaves, dark green color
✓ Stomatal opening
✓ Antioxidant production
✓ Cryptochrome activation
Target: 15-30% of spectrum

GREEN LIGHT (500-600nm)
━━━━━━━━━━━━━━━━━━━━━━━
Peak: 510-550nm
✓ Canopy penetration (30% reaches lower leaves)
✓ Photosynthesis in shaded areas
✓ Shade avoidance modulation
✓ Natural appearance for workers
Target: 20-40% of spectrum

RED LIGHT (600-700nm)
━━━━━━━━━━━━━━━━━━━━━━━
Peak: 650-670nm
✓ Maximum photosynthetic efficiency
✓ Flowering promotion (long-day)
✓ Leaf expansion
✓ Biomass accumulation
✓ Phytochrome activation (Pr→Pfr)
Target: 40-60% of spectrum

FAR-RED LIGHT (700-800nm)
━━━━━━━━━━━━━━━━━━━━━━━
Peak: 720-740nm
✓ Stem elongation (shade avoidance)
✓ Flowering (some species)
✓ Emerson enhancement effect
✓ Phytochrome conversion (Pfr→Pr)
✓ End-of-day treatment
Target: 2-10% of spectrum

UV-A LIGHT (315-400nm)
━━━━━━━━━━━━━━━━━━━━━━━
✓ Anthocyanin production (color)
✓ Terpene enhancement
✓ Compact morphology
✓ Stress tolerance
Target: 1-3% (quality crops)

UV-B LIGHT (280-315nm)
━━━━━━━━━━━━━━━━━━━━━━━
✓ Flavonoid production
✓ Pest/disease resistance
✓ Thicker cuticle
⚠ Use cautiously (0.5-1%)
⚠ Can cause damage if excessive
```

## Quick Calculations

```
CALCULATING PHOTON PERCENTAGES
────────────────────────────────

Example Spectrum (PPFD values):
Blue (450nm):  150 μmol/m²/s
Green (550nm): 200 μmol/m²/s
Red (660nm):   350 μmol/m²/s
Far-red (730): 50 μmol/m²/s
────────────────────────────────
Total:         750 μmol/m²/s

Percentages:
Blue:  150/750 = 20%
Green: 200/750 = 27%
Red:   350/750 = 47%
FR:    50/750 = 7%

R:B Ratio:  350/150 = 2.33
R:FR Ratio: 350/50 = 7.0
```

## Troubleshooting with Spectrum

```
SYMPTOM                    LIKELY CAUSE           SOLUTION
──────────────────────     ────────────────       ─────────────────
Leggy, elongated growth    Too much far-red       Reduce R:FR ratio
                          Low blue %             Increase blue to 20-30%

Dark green, stunted        Excessive blue         Reduce blue to 15-20%
                          Low red content        Increase red percentage

Pale, yellow leaves        Insufficient blue      Increase blue to 20%+
                          Low total PPFD         Check DLI targets

Premature bolting          Long photoperiod       Reduce day length
                          Too much far-red       Increase R:FR ratio

Poor flowering             Insufficient red       Increase red to 50-60%
                          Wrong photoperiod      Check SDP/LDP needs

Weak flavor/aroma          Lack of UV             Add 1-3% UV-A
                          Low DLI                Increase light intensity
```
