## Course Folder Structure

Each course follows a standardized structure:

```
XXX_Course_Name/
├── course_overview.md      # Course description, objectives, prerequisites
├── lessons/                # 12-14 lesson files
│   ├── lesson_01_*.md
│   ├── lesson_02_*.md
│   └── ...
├── quizzes/               # Module quizzes
│   ├── module_01_quiz.md
│   └── ...
├── tests/                 # Final examinations
│   └── final_exam.md
├── cheatsheets/           # Quick reference guides
├── activities/            # Hands-on exercises
├── handouts/              # Reference materials
└── resources/             # Glossary, additional materials
    └── glossary.md
```
