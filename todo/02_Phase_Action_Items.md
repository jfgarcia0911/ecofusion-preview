## Action Item Management

### Weekly Review Process
1. Review all action items for current week
2. Update status (Complete, In Progress, Blocked, Delayed)
3. Identify blockers and escalate
4. Add new items as identified
5. Adjust timelines as needed

### Monthly Review Process
1. Aggregate weekly progress
2. Review milestone achievement
3. Update executive dashboard
4. Identify resource needs
5. Adjust quarterly priorities

### Quarterly Review Process
1. Phase progress assessment
2. Strategic alignment check
3. Resource reallocation
4. Risk assessment update
5. Plan adjustments

---

## Status Definitions

| Status | Definition | Action |
|--------|------------|--------|
| Not Started | Work not begun | Schedule kickoff |
| In Progress | Active work | Monitor progress |
| Complete | Finished successfully | Verify and close |
| Blocked | Cannot proceed | Escalate immediately |
| Delayed | Behind schedule | Develop recovery plan |
| At Risk | May miss deadline | Increase monitoring |
| Cancelled | No longer needed | Document reason |
